Tags: #digital-platform #material-supply #urban-mining #reuse #interview-source #priority-high

## Type

Public-sector reuse marketplace for building components (Berlin state properties).

## Why This Is a Strong Interview Pick

One of the clearest sources for the gap between what is listed and what designers actually need. Exposes real components from Berlin properties with direct relevance to metadata, availability, and reuse transaction logic.

## What This Source Can Contribute

- Which metadata fields are realistic in practice
- Which fields are missing for planning and structural verification
- Where marketplace logic ends and design-tool logic begins
- How public owners manage component release into reuse streams

## Research Relevance

Direct relation to:

- Component data structure and machine-readable metadata
- API potential and digital workflow gaps
- Supply-side reality checks for early-stage design decisions
