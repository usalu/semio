# Neural

Neural is headless procedural programming language that follows the philosophy dictionary in - dictionary out.

# Tree

A tree is a directed acyclic graph of neurons and synapses.

# Dictionary

A dictionary is an immutable, unordered, collision-free, collection of key-value pairs.

# Kvp

A key value pair.

# Key

A key is string of dot-separated camelCase segments.

```
"segment"
"segment.childSegment"
```

# Value

A value is either an atom or a dictionary.

# Atom

An atom is an imumtable non-dictionary value.

# Integer

An integer number atom.

# Decimal

A floating number atom.

# String

A string atom.

# Neuron

A neuron is an instance of a neuron kind that processes concrete data.

# Neuron Kind

A neuron kind is definition for a neuron.

## Function

A function is computational unit that transforms one dictionary into another dictionary.

# Synapse

A synapse is a directed connected between two neurons.
