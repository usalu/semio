<Aside type="note" title="Are you a Mac user?">
  The code of semio is compatible with Windows, Mac and Linux but currently compiled for Windows only ⚠️ [Reach out to us on Discord](https://discord.gg/m6nnf6pQRc) if you want to help us extend it for Mac 👐
</Aside>

semio has two user-interfaces:

- Grasshopper 🦗
- sketchpad ✏️

### 🦗 Grasshopper (Rhino 8)

<Aside type="tip" title="Are you interested in the latest version?">
  Then hit `Include pre-releases` and download `5.3.0-beta` ⬇️
</Aside>

The Grasshopper plugin can be installed over the Rhino Package Manager 🟢

{/* ![Rhino Package](../../../../../assets/images/rhinopackage.gif) */}

1. Open Rhino Package Manger ⌨️
2. Search for semio 🔎
3. Install the latest version ⬇️
4. Restart Rhino 🔄

That's it!
