Trinity is for working directed property port graphs where edges connect on ports.
Nodes, Edges and Ports can have properties (data and derived).

# Graph

A graph has a manifest at compile time and nodes and edges at runtime.

# Manifest

A manifest is a schema for a graph compile-time.
A manifest has node kinds, edge kinds, port kinds.
A kind has a name and defines what properties exist.
