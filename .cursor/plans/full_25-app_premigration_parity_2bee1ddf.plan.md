# Full 25-App Premigration Parity — Corrected Plan

## Why a new plan, not the existing draft

`.cursor/plans/restore_app_parity_post-migration_e255a2e1.plan.md` is an unstarted audit draft (`todos: []`) claiming severe gaps across 12 "Tier 1" apps. I re-verified every one of its Tier-1 claims against the current code with parallel read-only audits (cited below). Several claims are **stale** — real work already landed in other sessions since that audit was written (`lowpoly` is essentially fully fixed; `puzzle3d`/`flow`/`sequence` are much further along than claimed). Executing the old draft as-is would waste large effort re-doing finished work and mischaracterize what's actually left. This plan replaces it with the **corrected, current** gap list.

`lowpoly` is dropped entirely — verified fully fixed (paint, extrude/inset/bevel, halfedge mesh, fixture all real and tested).

## Execution waves (each ends with cargo test + wasm rebuild + E2E)

1. **Wave 0 — E2E infra**: strengthen `.repo/🎫/26/07/05/SUPPORT-REACT-AND-WGPU-RENDERERS-IN-PLAYGROUNDS/verify-react-playgrounds-e2e.ts` (and the wgpu twin) with real functional assertions per touched app in later waves (non-placeholder geometry signature, scripted command-dispatch + document-state-changed checks) instead of "canvas painted" — this is what prevents another false-green.
2. **cad**: wire `kernel-3d-brep` for typology→solid generation + tessellation, replacing `typology_mesh_kind` box/cylinder mapping; load `cad/asset/play/*.model.json` for the forest-left example instead of `forest_play_document()`.
3. **gis2d**: wire `MapHost::build_render_scene`/tile upload for real tile rendering; implement real pointer pan/zoom via `MapHost` wheel/pointer API; auto-run `fit_world_camera` on load.
4. **puzzle2d**: restore dropped command surface by wiring `puzzle/2d/rs::BoardHost` (tools/LOD/engagement), give edges/wires real line-segment geometry in `canvas_layers_json` so `canvas-2d` renders them.
5. **puzzle3d**: switch mesh resolution to real GLB `url` loading (framework/plugin/rs/world3d_host.rs mesh-by-url path already exists for other plugins); drive `precompute_step` each frame/command; expose `brush_candidates`/`fill_progress` through commands so candidate cycling and fill progress are live.
6. **puzzle5d**: port the brush/fill precompute pattern from `puzzle/3d/rs` into `puzzle/5d/rs` (new engine code, not a reuse — 5d fixture shape differs); add `grips`/`fasteners` to the fixture model and consume them.
7. **flow**: wire the async eval-bridge/worker path (`set_eval_bridge`, `apply_eval_outputs_json`, `set_computing_progress`); replace the hardcoded 8-entry catalogue with `host.catalogue_json()`; route undo/redo through `FlowHost::undo/redo` and snapshot `moveMediaNode`.
8. **procedural3d**: wire flow evaluation through `kernel-3d-brep`/`flow/module/brep` for real tessellated preview meshes, replacing the `neuron_mesh_kind` placeholder map.
9. **procedural2d**: wire evaluated flow output into real vector/path canvas geometry instead of placeholder rects/text.
10. **trinity-rewrite**: restore visual LHS/RHS via `build_node_graph_scene`; re-wire the existing hover/select state into `hover_json`/`selection_json` on the scenes it already computes.
11. **trinity jack**: give Trinity a real LOD-aware canvas (or confirm generic node-graph is acceptable for jack's design — flag if so); wire proper VCS (reuse the `vcs`/`DocumentVcsEnvelope` pattern already used by `writer/rs/document_vcs.rs`).
12. **sequence**: surface nested control/slot/collapse in document/catalogue/graph UI (collapse toggle, slot drop target, "add to slot" catalogue actions); fix `setStepParams` inspector arg shape mismatch.
13. **Final verification**: full 25-plugin suite both renderers, `cargo test` workspace-wide, side-by-side screenshots for every app touched.

## Constraints carried over

- No new files outside ticket folders; extend existing files with region/subregion comments.
- No compatibility layers/adapters — real native re-ports per repo rules.
- Each wave: `cargo test` for touched crates, plugin WASM rebuild, E2E rerun before moving on.
