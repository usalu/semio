Concept 1: Variables 5 questions

Q1.1 — Multiple Choice
What is a variable in programming?
✅ Correct Answer: A
A variable is like a container with a label. You put data inside it and can access it later by using the variable's name. Think of it like a labeled box in a warehouse.
Q1.2 — True/False
In JavaScript, 'let' and 'const' are used to create variables, but 'const' variables can be changed after creation.
✅ Correct Answer: False
'const' stands for 'constant' — once you assign a value, it cannot be changed. 'let' variables, however, can be changed at any time.
Q1.3 — Multiple Choice
Which of these is a valid variable name?
✅ Correct Answer: C
Variable names must start with a letter or underscore, cannot contain spaces or dashes, and cannot start with numbers. 'userName' follows all these rules.
Q1.4 — Short Code
What does this code print?
let x = 5; let y = 10; let z = x + y; console.log(z);
✅ Expected Answer: 15
The code creates three variables: x = 5, y = 10, z = 5 + 10 = 15. When it logs z, it prints 15.
Q1.5 — Multiple Choice
What is the difference between a regular variable and a state variable in React?
✅ Correct Answer: B
In React, when a state variable changes (using setState or hooks), React automatically re-renders the component to show the new data. Regular variables don't trigger updates, so the screen won't change even if the variable does.

Concept 2: Functions 5 questions

Q2.1 — Multiple Choice
What is a function in programming?
✅ Correct Answer: A
A function is like a recipe you can use multiple times. You write the instructions once, give it a name, and then call it whenever you need those instructions to run.
Q2.2 — True/False
In JavaScript, arrow functions and regular functions always behave exactly the same way.
✅ Correct Answer: False
While they work similarly for most cases, arrow functions and regular functions have some differences (like how 'this' is handled). For beginners, they're functionally equivalent, but there are edge cases where they differ.
Q2.3 — Short Code
What does this function return when called with greet('Alice')?
function greet(name) { return 'Hello, ' + name + '!'; }
✅ Expected Answer: Hello, Alice!
The function takes the parameter 'name' (which is 'Alice'), concatenates it between 'Hello, ' and '!', and returns the result: 'Hello, Alice!'
Q2.4 — Multiple Choice
What is the difference between a function parameter and a function argument?
✅ Correct Answer: B
Parameters are placeholders defined in the function (like 'name' in function greet(name)). Arguments are the actual values you pass when calling the function (like 'Alice' in greet('Alice')).
Q2.5 — Short Code
Convert this regular function to an arrow function:
function add(a, b) { return a + b; }
✅ Expected Answer: const add = (a, b) => a + b;
Arrow functions use the '=>' syntax. For simple one-liners, you can omit the curly braces and the return statement. Both const add = (a, b) => { return a + b; }; and const add = (a, b) => a + b; are correct.

Concept 3: Control Flow 5 questions

Q3.1 — Multiple Choice
What is control flow?
✅ Correct Answer: A
Control flow determines which code runs and in what order. It includes things like if/else statements (making decisions) and loops (repeating code).
Q3.2 — Short Code
What does this code print?
let temperature = 25; if (temperature > 30) { console.log('Hot'); } else if (temperature > 20) { console.log('Nice'); } else { console.log('Cold'); }
✅ Expected Answer: Nice
The temperature is 25. It's not > 30, so the first condition is false. But 25 > 20, so the second condition is true. The code prints 'Nice'.
Q3.3 — True/False
In JavaScript, '==' and '===' do the same thing.
✅ Correct Answer: False
No! '==' is loose comparison (5 == '5' is true), while '===' is strict comparison (5 === '5' is false). Always use '===' to avoid surprises.
Q3.4 — Multiple Choice
How many times does this loop run?
for (let i = 0; i < 5; i++) { console.log(i); }
✅ Correct Answer: B
The loop runs while i < 5. So it prints: 0, 1, 2, 3, 4. That's 5 times total. When i becomes 5, the condition is false and the loop stops.
Q3.5 — Short Code
Write a while loop that counts from 1 to 3.
✅ Expected Answer:
let i = 1; while (i <= 3) { console.log(i); i = i + 1; }
Start with i = 1, then loop while i <= 3. Inside the loop, print i and increment it. This prints 1, 2, 3.

Concept 4: Objects 5 questions

Q4.1 — Multiple Choice
What is an object in JavaScript?
✅ Correct Answer: A
An object is like a contact card with multiple pieces of information. Instead of having separate variables for name, age, email, you group them in one object.
Q4.2 — Short Code
What does this code print?
let person = { name: 'Alice', age: 25 }; console.log(person.name);
✅ Expected Answer: Alice
The code creates an object with two properties: name and age. Using dot notation (person.name), we access the 'name' property, which is 'Alice'.
Q4.3 — True/False
You can only access object properties using dot notation (person.name), not bracket notation (person['name']).
✅ Correct Answer: False
Both work! Dot notation is more common, but bracket notation is useful when the property name is in a variable or contains special characters.
Q4.4 — Multiple Choice
What is a nested object?
✅ Correct Answer: A
A nested object is an object that contains other objects as properties. For example: { address: { city: 'New York' } } has a nested object called 'address'.
Q4.5 — Short Code
Create an object called 'car' with properties: brand='Toyota', color='blue', year=2020.
✅ Expected Answer:
const car = { brand: 'Toyota', color: 'blue', year: 2020 };
Objects are created with curly braces. Inside, you list property names (keys) and their values separated by colons. Properties are separated by commas.

Concept 5: Arrays 6 questions

Q5.1 — Multiple Choice
What is an array?
✅ Correct Answer: A
An array is an ordered list. Each item has a position (index), starting from 0. Arrays are perfect for storing multiple items of the same type.
Q5.2 — Short Code
What does this code print?
let fruits = ['apple', 'banana', 'cherry']; console.log(fruits[1]);
✅ Expected Answer: banana
Arrays start counting at 0. Index 0 is 'apple', index 1 is 'banana', index 2 is 'cherry'. So fruits[1] is 'banana'.
Q5.3 — Multiple Choice
What does the .push() method do?
✅ Correct Answer: A
push() adds a new item to the end. pop() removes from the end. unshift() adds to the beginning. shift() removes from the beginning.
Q5.4 — Short Code
What does this code print?
let numbers = [1, 2, 3, 4, 5]; let doubled = numbers.map((n) => n * 2); console.log(doubled);
✅ Expected Answer: [2, 4, 6, 8, 10]
map() transforms each item in the array. It multiplies each number by 2, creating a new array with the transformed values.
Q5.5 — Multiple Choice
What does filter() do?
✅ Correct Answer: A
filter() returns a new array containing only the items that pass the condition. For example, filter((n) => n > 3) keeps only numbers greater than 3.
Q5.6 — Short Code
What does this code print?
let numbers = [1, 2, 3, 4, 5]; let bigOnes = numbers.filter((n) => n > 3); console.log(bigOnes);
✅ Expected Answer: [4, 5]
filter() keeps only numbers greater than 3. So from [1, 2, 3, 4, 5], only 4 and 5 pass the test. Result: [4, 5].
