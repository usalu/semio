# Layout

Layout is a browser-based document editor for aggregating content into exportable documents (PDF, SVG, PNG).

# Document

A document is a persistent graph of pages, spreads, layers, frames, stories, styles, and linked assets — all addressable by stable IDs.

# Page

A page is a sized artboard with margins, columns, and placed objects.

# Parent Page

A parent page is a reusable template; document pages inherit its objects until explicitly overridden.

# Frame

A frame is a placed object (rectangle, text, or image) on a layer with bounds and transform.

# Story

A text story holds content and style runs; text frames reference stories and can thread across frames.

# Preflight

Background validators surface overset text, missing assets, and other publish blockers.
