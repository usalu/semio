# PDF Base 14 Outline Programs

The unmodified CFF tables come from the URW Base35 OpenType fonts at release 20200910 (c15105598aa7eb256b1ebfcecd3d078801521e73).
The repository's PDF encoding, widths and original glyph names still determine text positioning and decoding.
The upstream license and corresponding font programs are available with the same release.

[Pinned complete corresponding font sources](https://github.com/ArtifexSoftware/urw-base35-fonts/tree/c15105598aa7eb256b1ebfcecd3d078801521e73)
