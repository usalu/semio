# Liège elevation samples

The terrain example uses a 33 × 33 regular WGS84 grid around Sart Tilman, Liège. Rows start at the southwest corner. Each value is an elevation sample in whole meters from the N50E005 Mapzen Skadi tile. The crop keeps every sixth sample in each direction and preserves the selected heights without interpolation. [Source tile](https://s3.amazonaws.com/elevation-tiles-prod/skadi/N50/N50E005.hgt.gz)
