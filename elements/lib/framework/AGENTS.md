A completly declarative (pure typescript), render-detatched (no-dom, no react) framework for building clean, safe and extendable uis.

[core](./core/) contains all the code.
We currently implement one [react renderer](./renderer/react).

UI, App, Mode, WindowKind (table, board, scene), Window, Panel (Workbenchs, Details, Settings, Chat) Toolbar, ToolCategory, Tool, Command, Extension
