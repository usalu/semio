# Summary

Elements contains shared React UI bundles for reusable semio interface elements and their visual documentation.

### Specs

- The `elements` technology owns reusable UI elements that are consumed by other technologies instead of living inside feature bundles.
- Shared element development and Storybook hosting belong in `elements/ui`.

# 📦 Bundles

- [ui](ui/README.md) – Storybook and shared React components
