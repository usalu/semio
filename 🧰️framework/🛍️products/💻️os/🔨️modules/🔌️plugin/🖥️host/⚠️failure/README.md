# Actor Failure Receiving

This owner contains the actual fault buffer, sealed capsule, rooted recipient and fetch frontier. It depends on the existing GuestRuntime and Wake contracts and never on Postturn, which reexports the same capsule.

Every scoped action is184-byte SAF1 under a real Infrastructure subloan and the existing History. BorrowActorFailure is six scalar values with no guest subloan or fabricated header: the four data prefix values are failed epoch, semantic kind, offset and length; the caller inserts its actual operation and generation between the pairs.

The frontier copies only a genuine frozen producer header and accepts its actual issuer settlement and Core Deallocate-return proof. Fault bytes cross the actual frozen scalar-memory borrower into a Source-owned native fault root. Sealing yields a non-clone witness from its actual native borrow. A capsule moves into a preborn recipient Home through the two genuine OriginalActorReturnSlot return claims. Acceptance is minted only through an actual rooted producer projection after the written target settles and contains the matching capsule. Final cleanup-only acknowledgment additionally requires the actual GuestAck frame and physical header return.

All partial owners remain retained on refusal. Source retirement refuses unfinished fetch state; it cannot silently discard a live fault lease, donor, capsule or receipt.
