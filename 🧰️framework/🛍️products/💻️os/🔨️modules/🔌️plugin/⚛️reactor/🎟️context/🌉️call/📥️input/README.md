# Actor Input Receiving

The semio-plugin-actor-input crate owns the one nominal input receiver, its opaque failure identity, borrowed full-cause projection, and paid close. GuestContract and reactor-context reexport this owner. It depends on the kernel, ABI, Job and Pack receiving contracts and never on GuestContract.

The wire allocation remains with its original host donor until the real input-return proof. Failure projection borrows all present original outcome and settlement branches inside the same authenticated Source callback. Failed input remains cleanup-only until the actual cause recipient accepts it.
