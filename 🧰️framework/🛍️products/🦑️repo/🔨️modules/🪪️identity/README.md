# 🪪️ Identity

Who and what a thing is: the entity emoji vocabulary, semantic identifiers, `repo://` URIs, artifact
references, the compose-id codecs, humanisation, identifier generation and the leading-grapheme rule
every emoji-prefixed path segment obeys.

## 📦️ Packages

- `📦️packages/🦀️rust` — `semio-framework-repo-identity`
- `📦️packages/🐹️go` — `github.com/usalu/semio/repo/identity`

## 🧪️ Tests

One `🥒️.feature` per case under `🧪️tests/` with an adapter per implementation, run through the
`🧪️test` harness; `Intl.Segmenter` is registered as the Unicode standards reference for grapheme
segmentation in `🔮️oracle/🔣️.json`, and the owned codecs are a recorded no-oracle decision.

`😀️entity-emoji-codec`, `🧬️compose-id-codec`.
