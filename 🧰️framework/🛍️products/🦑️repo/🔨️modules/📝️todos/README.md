# 📝️ Todos

Todos and drafts: the markdown round trip, the scan that finds them in the tree, the draft lifecycle
and the promotion of a todo into a ticket.

## 📦️ Packages

- `📦️packages/🦀️rust` — `semio-framework-repo-todos`
- `📦️packages/🐹️go` — `github.com/usalu/semio/repo/todos`

## 🧪️ Tests

One `🥒️.feature` per case under `🧪️tests/` with an adapter per implementation, run through the
`🧪️test` harness; the third-party references are registered in `🔮️oracles/🔣️.json`.

`📝️todo-markdown-roundtrip`, `🔍️todo-scanning`, `✏️draft-lifecycle`, `🎫️todo-to-ticket`.
