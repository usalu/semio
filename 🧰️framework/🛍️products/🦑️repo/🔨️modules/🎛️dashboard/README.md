# 🎛️ Dashboard

The terminal dashboard: the command tree it discovers from the workspace, the wizard and workflow it
drives, the playground catalog and session, the root-script delegation, the usage presentation, and
the daemon that owns the pseudo-terminal sessions behind a unix socket or a windows named pipe.
Rust only by design — it consumes the repo domain crates in process.

## 📦️ Packages

- `📦️packages/🦀️rust` — `semio-framework-repo-dashboard`

## 🧪️ Tests
