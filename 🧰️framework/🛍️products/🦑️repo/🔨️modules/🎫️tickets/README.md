# 🎫️ Tickets

The ticket lifecycle — open, close, reopen, change, search, purge — the ticket document codec, the
important-document transaction that keeps a ticket folder consistent, the GitHub issue, milestone and
label shapes, and the file resolution behind `ComputeTicketFiles`.

- `📦️packages/🦀️rust` — `semio-framework-repo-tickets`
- `📦️packages/🐹️go` — `github.com/usalu/semio/repo/tickets`
