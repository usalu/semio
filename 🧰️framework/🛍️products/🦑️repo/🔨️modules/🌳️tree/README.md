# 🌳️ Tree

The monorepo, goal, statute and territory trees: the walk that builds them, the filters and the child
ordering that make a walk reproducible, and the Mermaid rendering the documentation embeds.

## 📦️ Packages

- `📦️packages/🦀️rust` — `semio-framework-repo-tree`
- `📦️packages/🐹️go` — `github.com/usalu/semio/repo/tree`

## 🧪️ Tests

One `🥒️.feature` per case under `🧪️tests/` with an adapter per implementation, run through the
`🧪️test` harness; the third-party references are registered in `🔮️oracle/🔣️.json`.

`🌳️monorepo-tree-build`, `🎯️goal-statute-territory-trees`, `🔎️tree-filtering`, `🔀️child-sorting`,
`🧜️mermaid-rendering`.
