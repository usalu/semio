\begin{Abstract}
  This template shows how a dissertation is written against the semio print framework: one document kind, one title page carrying the examination metadata, and the same window chrome, registers and visualization library every other semio document uses
\end{Abstract}

\begin{Kurzfassung}
  Diese Vorlage zeigt, wie eine Dissertation im semio-Drucksatz entsteht: eine Dokumentart, ein Titelblatt mit den Prüfungsangaben und dieselben Fensterelemente, Verzeichnisse und Diagramme wie in jedem anderen semio-Dokument
\end{Kurzfassung}
