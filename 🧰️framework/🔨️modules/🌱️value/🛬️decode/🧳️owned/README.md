## 🌳️value/🦀️.rs

🌲️ The actual immutable shape header selects one accessor without speculative errors.
🧷️ Every child is a reference into the original immutable input and preserves its enclosing lease.
🫴️ A typed child retains its receiver and output independently through every normal and cancelled frontier.
🧵️ `Send` is stated, not derived: a slot owns only (1) its receiver, `Send + 'static` by the `NativeReceiver` contract, (2) its output `T`, `Send` because `NativeReceive: RetireOwned: Send`, and (3) a `RetainedCloneClose` frame holding `Box<dyn ErasedSnapshotRetirement>`, `Send` by that trait's supertrait. No field is shared by reference, so moving the slot moves every owner it holds. Re-deriving `Send` through the receiver type graph overflows the trait solver on deeply nested schemas (E0275), which is why the implementation is explicit; the law test `native_receive_slot_send_rests_on_the_receiver_contract` fails to compile if any of the three contracts is weakened.
🔢️ A scalar or unit enum constructs only its declared native value under original source binding.
❔️ Optional receiving distinguishes an actual null source from a missing parent field.
📋️ A sequence declares its actual fixed or allocated native backing independently of wire conversion.
