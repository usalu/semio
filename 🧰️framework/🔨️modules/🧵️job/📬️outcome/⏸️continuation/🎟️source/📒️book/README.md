# Original Return Book

The source owns one finite return budget, escrow table and publisher. Claims retain the actual reserved currencies until their one-shot capture and receiving witnesses settle. Borrowed child turns reuse this book.

OriginalReturnCaptureContext supplies validated, read-only metadata from the defining source and borrows its resident book. Capture derives the receiving identity from that actual borrowed book. A cached capture retains the original stock; binding validates the same receiving address.

Mutable counters and physical owners remain private. Selected table, publisher, delivery, claim, redemption and closing ports preserve source ownership through admission refusal and pending return custody. StepContext owns the higher execution, cancellation and receipt posting.

The co-located neutral schema and SQLite oracle describe stock conservation. The native law executes the real source, table, credit and witness owners; upper Job tests retain the genuine Source and StepContext integration.
