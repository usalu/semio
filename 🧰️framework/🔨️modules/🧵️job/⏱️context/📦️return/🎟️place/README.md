## CoreWire sized claim reservation

The Source-owned quote validates the actual target claim and held-update metadata against the portable ceiling `OriginalSizedClaimReserve::CEILING` (640 bytes: the native 64-bit actual is 565, wasm32 is no larger by layout). The quote's immediate copy equals the ceiling and the lifetime bound is extent plus the ceiling; the law `core_wire_sized_claim_metadata_stays_within_its_portable_ceiling_and_the_quote_equals_it` fails with a named cause when the metadata outgrows it. Its item and work amounts cover one claim placement and both held return phases; the lifetime copy bound includes the exact destination extent. It excludes table birth, free-cell reclamation, capture preissue, receipt metadata and guard permits. The quote reserves authority and does not report actual spent effects.
