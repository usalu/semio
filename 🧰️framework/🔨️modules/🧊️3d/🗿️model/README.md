# 🗿️ Model kernel (`semio.model/v1`)

A domain-neutral, engine-neutral 3D model kernel: one JSON schema for procedural solids, rigs, poses, animations and materials, and the code that turns it into triangles, GLB and FBX files and a picture. It has no runtime dependency on any engine or library (three, Blender, FBX SDK, glTF libraries); third-party libraries are test oracles only (`🔮️oracles/🔣️.json`).

Staffage builds its documents from the asset volume (`🎓️teaching/🏛️architecture/🧍️staffage`, `modelOf`); nothing in this folder knows staffage.

## Contract

- Frame: right-handed, +Y up, +Z ahead, +X left, metres, radians, quaternions `[x, y, z, w]`, column-major 4×4 matrices. All text is `{ en, de }`; there is no default language.
- `🧬️schema/🔣️.json` is normative (JSON Schema draft-07, 32 `$defs`), `🧬️schema/🟦️.ts` its typed twin. A document is procedural (`solids`, no meshes) or resolved (`tessellate` turned every solid into primitives skinned to its node; `Primitive.solids` keeps which solid made which triangles). Scenes: the optional `scenes: Scene[] { id, title, nodes, tags? }` are named sets of mesh-carrying nodes over the one shared skeleton; a document without scenes (or with `[]`) is one implicit scene of every node that carries a solid or a mesh. Membership belongs to the node, never to the solid: a bone that needs different solids per scene gets one identity child node per scene, and a node listed in several scenes shares its solids. Rules: `unknown-node`, `duplicate-id`, `unscened-node` (a carrier in no scene while scenes exist), `empty-scene`. Solids support `box`, `ellipsoid`, `capsule`, `revolve`, `extrude`, `loft` and `polyhedron`, each with an optional `repeat`. A polyhedron supplies metre-space vertices and outward triangle indices for one closed, connected shell.
- Every long function takes an `Operation { report(fraction), cancelled() }` and stops by `CancelledError`; polling cannot interrupt a synchronous function that never yields, so deadlines and the async variants (`tessellate`, `featureEdges`, `sceneOfAsync`) are the way to cancel.
- Identical input gives identical bytes.

## API (`./🟦️.ts`, package export `@semio-tech/framework-3d-js/model`)

| Call | Result |
|---|---|
| `validateModel(document)` | `Issue[]`, no throw for invalid data |
| `tessellate(document, quality, operation, { scene? })` | resolved document; `tessellateSolid` for one solid; weighted solids are grouped by scene set (one skinned node per set, one shared skin) |
| `poseModel(document, selector, { scene? })` | node world matrices at a pose or an animation time; `sampleMaterials(document, animation, timeS, { scene? })` for colour channels of the scene's materials |
| `scenesOf`, `selectScene`, `nodesOfScene`, `solidsOfScene`, `materialsOfScene`, `boundsOf(document, selector, { scene? })` | the scene cut: a single-scene, self-contained document (scene nodes, the skeleton they need, their solids, meshes, skins, clip channels, poses), node and solid provenance of a scene, posed bounds; `UnknownSceneError` |
| `meshIntegrity(positions, indices)`, `outwardNormals(positions, indices)` / `outwardOrientation(positions, indices, { openWinding? })` (normals, closedness and oriented volume in one pass), `solidIntegrity(solid, quality)` | the queries of a solid validator: is the mesh a closed 2-manifold (every edge used twice, no pinch vertex), consistently wound, its signed volume and area (vertices welded by position, 0.1 µm); the unit normal of every triangle oriented out of the solid (consistent winding by a walk over manifold edges, a closed piece turned by the sign of its volume, an open piece such as a loft with a cap off keeping the outward winding of the tessellator); it looks at one mesh only, so solids that touch exactly are judged one by one |
| `revolveClosure(profile)`, `taperFault(taperTo)`, `loftFault(sections)` | the classifiers behind the validation warnings `revolve-implied-closure`, `taper-degenerate`, `taper-uniform`, `loft-fold` |
| `featureEdges(document, angleRad, { material?, scene? }, operation)` | the document with `lines` primitives (with a scene: that scene only) |
| `encodeGlb(document, options, operation)` | glTF 2.0 binary, one glTF `scene` per model scene (default = first; `options.scene` writes one) sharing meshes, accessors, materials, variants, skin inverse-bind matrices and animation samplers; glTF has one parent per node, so a node a scene needs is written once per scene it serves: skins, animations (`KHR_animation_pointer` for material colours), `KHR_materials_variants`, `KHR_materials_unlit` |
| `encodeFbx` / `encodeFbxDetailed` | FBX 7.4 binary, one scene per file (`options.scene`, absent = the first, with a notice when there are several); (zlib arrays from the owned deflate): `LimbNode` skeleton, skin, bind pose, animation stacks, joint limits; the notices list what FBX cannot hold (lines, loop, events) |

The viewer (`./🖥️viewer`, package export `…/model/viewer`) is an owned WebGL2 renderer with a software reference rasteriser, orbit and presets, picking by solid, follow camera and root motion, model scenes (`sceneOf` prepares the shared buffers once; `FrameInput.scene` / `ModelViewer.setScene` select the active scene by filtering the draw list, so a switch rebuilds and re-uploads nothing; `scene` attribute), and the custom element `semio-model-viewer` (`defineModelViewerElement`; the client sets `strings`).

## Tests and oracles

## Solid semantics that were silent traps

- **Revolve closing rule.** A profile whose first point equals its last (at least three distinct points) is a closed loop: the solid is the body enclosed by the loop and the axis plays no part (wall, tube, bead, ring, torus). Every other profile is open and is closed through the axis: its end points are dropped perpendicularly onto the axis and the solid is everything between the polyline and the axis. So a shell is written as a loop (repeat the first point as the last); an open profile that stays off the axis at both ends is a filled body. The warning `revolve-implied-closure` fires for an open profile whose both end points are farther than 2 % of its largest radius from the axis and whose straight chord from last to first point closes it into a simple polygon of non-zero area (the author drew a loop and forgot to repeat the first point); a plain two-point cylinder or a profile that reaches the axis never fires.
- **Loft orientation.** The sections are the path in order; every ring runs counter-clockwise about the local path tangent whatever the order of the sections, the bends of the path (also a path whose first tangent opposes its overall travel) and the handedness of a section `rotation`; so the skin is always counter-clockwise seen from outside, a closed loft has positive signed volume, an end cap faces away along its end tangent and a loft with a cap off is an open tube whose faces still look outward. `loft-fold` flags consecutive sections whose rings overlap (the path turns back or bends tighter than the section is wide).
- **Extrude taper.** `taperTo = [scale at from, scale at to]` about the area centroid of the outer ring, never a scale along u and v; `[1, 0]` is a pyramid with its apex at `to`. `taper-uniform` flags equal factors other than 1 (no taper, only a prism of the scaled profile, what a misreading as [scale u, scale v] produces), `taper-degenerate` both factors 0 or a factor in (0, 0.001).

Language-agnostic vectors are in `🧫️fixtures/` (one folder per solid kind, skinning, animation, polygon triangulation, GLB and FBX digests); the cases are in `🧪️tests/` and next to each encoder and the viewer. Scenes (`🧫️fixtures/🎞️scenes`) are checked by the Khronos validator, glTF-Transform and three `GLTFLoader` (scene count, per-scene node sets, sharing, `Box3` bounds with skinning), assimp and three `FBXLoader`; digests recorded from bun reproduce under node. Mesh integrity and the solid traps (`🧫️fixtures/🩻️integrity`, `🧫️fixtures/🪤️traps`, tests `🧪️tests/🩻️integrity`, `🧪️tests/🪤️traps`) are checked against analytic volumes and against trimesh (watertight, winding consistency, signed volume, `contains` probes along every claimed outward normal, Pappus volumes) and shapely (profile areas) from the locked `geometry` group of the staffage oracle project through `uv` (`🧪️tests/🧰️support/🐍️oracle`). Oracles: Khronos `gltf-validator`, `@gltf-transform`, three `GLTFLoader`, `FBXLoader` and geometry classes, `assimpjs`, Ajv, fflate, fast-check. Direct run (bun): `bun node_modules/vitest/vitest.mjs run --configLoader native --config <vitest config>` per folder (`🗿️model`, `📤️export/🧊️glb`, `📤️export/🎬️fbx`, `🖥️viewer`); the repo command is `repo run @semio-tech/framework-3d-js:test`. The WebGL2 backend is checked in a real browser, not in headless runs: its one test is skipped with that reason.
