# Actor Receipts

One data-only owner implements SAC3 scope receipts, SRE1 escrow snapshots, real job SJH2 frames and dedicated actor-failure SAF1 frames. Parsed bytes remain untrusted; Source, producer, clock, opaque failure reference, physical return and retirement qualification stay with their actual lifecycle owners. Guest facade namespaces reexport these same implementations; no parallel codec or authority constructor exists.
