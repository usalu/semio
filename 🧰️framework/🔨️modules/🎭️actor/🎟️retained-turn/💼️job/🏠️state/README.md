# Actor Job State

This first-party owner retains actual pending job sources, registered owners, output bodies and page loans. Its allocation-free declaration belongs to the admitting actor payload before producer work. Every mutating body receives the actual caller StepContext and returns complete failure owners; Entry supplies context, publication and fixed-header orchestration.

The production methods serve both native and guest callers without depending on GuestContract. Entry wrappers preserve the existing WIT calls; Owned calls borrow the same state through one Source header checkout. Page views exist only during their exact offered loan, and cancellation retains physical bodies until paid retirement. Shutdown must close both pending unregistered input and actual registered children before the state becomes terminal.

The canonical output corpus and native laws remain under the reactor context output owner and execute through Entry into this package. No assertions or byte/identity cases were removed during extraction.
