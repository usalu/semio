# CW7 Sweep C — vcs::Operation/OpText/OperationDiff/Edit -> protocol:: import-path surgery

Scope: pure import-path migration of `vcs::Operation`/`vcs::OpText`/`vcs::OperationDiff`/`vcs::Edit`
to `protocol::` direct imports across 7 crates. Trait/type shapes unchanged (confirmed against
protocol/rs/lib.rs, which re-exports `Edit, Operation, OperationDiff, OpText, CollectionOperation`
etc. from protocol_command). No crate in this group constructs or matches `vcs::CollectionOperation`
(grep-verified — zero hits for `CollectionOperation` in all 7 files), so no shape-migration steps
from cw7-instructions.md applied to any of these; that document's crate list (imperative/*, layout/*,
architect/*, sequence/core, dag/*, gis/plugin, shooting/*, process/*, flow/core, animate/*,
lowpoly/core) is a disjoint set from this sweep's 7 crates.

`s/plugin/rs` (kernel wave, sibling agent) was not touched — only `s/rs` from this group.

All 7 crates already carried `protocol` as a direct Cargo dependency (from CW3's earlier mechanical
sweep) — no Cargo.toml edits were needed anywhere.
