What was implemented (against the contract's "## pack_value" section verbatim):

- 🔖Tags: all wire tags 0x00-0x16 as private consts.
- 🔖Canonical: shape-context helper extractors (elem_shape_of/table_spec_of/record_spec_of/
  block_inner_shape/statements_variants/map_inner_shape), f64 normalization (-0.0 -> 0.0, NaN ->
  0x7ff8_0000_0000_0000), homogeneous-numeric-kind detection for packed Tuple/List eligibility,
  and the deterministic string-interning pre-pass (build_symbols): walks the whole document once
  (shape-aware where a shape is known, generically otherwise), counts occurrences, and forces
  interning for Statements keywords and TableSoA Text columns (both unconditional per the wire
  format — bare symrefs, not self-describing string tags); the final symbol table is *sorted*
  (not first-occurrence order) so encode_document is a pure function of (spec, record) regardless
  of HashMap iteration order, satisfying the contract's purity LAW unconditionally (not just when
  options.canonical == true — there is no looser non-canonical code path; canonical only gates the
  OPTIONAL_CANONICAL header bit).
- 🔖Encode / 🔖Decode: encode_value/decode_value dispatch on an `Option<&Shape>` — Some(shape) for
  known spec fields (disambiguates Tuple vs List, resolves nested Record/Block/Statements/Map
  sub-shapes, reinterprets PackedVarint as UInt/Enum), None for field ids absent from the caller's
  RecordSpec, decoded/re-encoded purely from the self-describing wire tag. This is what makes
  unknown-field preservation work without ever having seen the original schema. Every FieldValue/
  DslValue/WireValue variant round-trips; Bytes64 chunks through the live PackWriter once len >=
  chunk_threshold; Map/DslValue::Object entries always sorted by key bytes; DslValue::Object keys
  are always TAG_STR_INLINE (forced inline, never symrefs) per the contract's explicit callout.
- 🔖Table: TableSoA (0x14) columnar encode/decode for Shape::Table, columns sorted by field id,
  per-column presence (dense/bitmap), and 6 elem_tag kinds (F64/Int/UInt/Enum/Bool/Str) plus a
  self-describing fallback for anything else. Decode is fully self-describing (field_id + elem_tag
  live on the wire per column) so it never needs a RecordSpec — verified in
  table_soa_round_trips_with_sparse_columns (mixed dense/sparse columns in one table).
- 🔖SchemaHash: schema_hash(spec) = blake3 over (field id, key, shape-tag) tuples sorted by id;
  verified order-independent and content-sensitive.
- 🔖Document: EncodeOptions/DecodeOptions/DecodeReport per the contract's exact field lists and
  defaults; encode_document/decode_document as the sole entry points, splitting the Document body
  across frame_size-sized KIND_DOCUMENT segments and reassembling via pack_format::PackFile.

Wire-format choices left to this crate's discretion by the contract ("your choice" scope):
  - Wire literal (0x13) sub-layout: presence byte (bit0 = edge present, bit1 = directed) + node
    layout (presence byte for optional kind/port + self-describing id/kind/port strings) + props
    as a bare recursive DslValue (no extra 0x11 wrapper inside Wire, since the context already
    establishes it's a DslValue). Internally consistent and round-trips; not cross-crate pinned.
  - TableSoA non-Bool columns compact to present-row-count elements (skip absent slots entirely,
    in row order); Bool columns instead always write a full row-aligned ceil(rows/8)-byte value
    bitmap (kept simple rather than bit-compacting a sparse bool column separately).
  - preserve_unknown semantics: encode-side drops (never encodes) ids not found in the current
    spec when false; decode-side still consumes/reports unknown ids into DecodeReport regardless,
    but only inserts them into the returned RecordValue when true. Both covered by tests.

  - round_trips_scalar_edge_cases — empty string, NaN, -0.0 sign, i64::MIN, u64::MAX, unicode,
    empty list/map/bytes.
  - packed_numeric_list_and_tuple_round_trip_and_use_packed_tags — homogeneous Int/Float/UInt
    List/Tuple through the packed 0x15/0x16 forms, plus a non-homogeneous (Value) list staying
    plain 0x0C.
  - table_soa_round_trips_with_sparse_columns — TableSoA with a sparse Text and sparse Bool column.
  - wire_literal_round_trips_bare_node_and_undirected_edge.
  - canonical_encoding_is_byte_stable_across_shuffled_insertion_order — two independently-built
    equal RecordValues (reverse HashMap insertion order) encode to byte-identical output, and the
    same RecordValue encodes identically twice.
  - schema_hash_is_order_independent_and_content_sensitive.
  - unknown_field_round_trips_through_decode_then_reencode — decode against a narrower spec than
    what encoded the bytes, confirm unknown ids reported + preserved, re-encode, decode again,
    confirm they still survive.
  - preserve_unknown_false_drops_unknown_fields_from_decoded_value_but_still_reports_them.
  - large_bytes_field_is_chunked_and_round_trips — 600KB Bytes64 field through chunked encoding.
  - document_body_splits_across_multiple_frames_when_frame_size_is_small — multi-frame Document
    body reassembly via pack_format::PackFile::body_bytes.
