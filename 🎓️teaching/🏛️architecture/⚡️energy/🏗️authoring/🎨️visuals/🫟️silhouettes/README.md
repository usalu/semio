# Silhouette Sources

Standing entourage adapts the CC0 photo trace by pitr: [source and license](https://commons.wikimedia.org/wiki/File:Man_standing_silhouette.svg). Only its outer body contour is retained and normalized to the architectural height.

Walking adapts the CC0 Muybridge-based lateral silhouette by Mette Aumala: [source and license](https://commons.wikimedia.org/wiki/File:Silhouette_of_a_walking_man.svg). Running adapts [runner4 by shokunin](https://openclipart.org/detail/76993), under the [Openclipart CC0 policy](https://openclipart.org/share). The activity SVGs retain the existing head-to-foot reference size.

Seated, sleeping, equipment, industrial and atmospheric profiles are hand-authored. All runtime artwork is local portable Bezier data or SVG, with no network requests or added runtime dependency.
