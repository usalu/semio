## 🦗 Grasshoper

1. [Download the example file `starter.gh`](https://raw.githubusercontent.com/usalu/compose/example/starter/starter.gh) ⬇️

2. Open the `starter.gh` file 📂

   In Grasshoper you should see:
   ![Definition](../../../../../asset/image/starter-grasshopper.png)

   In Rhino you should see:
   ![Preview](../../../../../asset/image/starter-grasshopper-preview.png)

3. Change the connectors from 1:`red` to `white` and 2:`cyan` to `black` 🎨

   In Grasshoper you should see:
   ![Connectors](../../../../../asset/image/starter-grasshopper-ports.png)

   In Rhino you should see:
   ![Connectors Preview](../../../../../asset/image/starter-grasshopper-ports-preview.png)

   <Aside type="tip" title="👀 Do you see what connectors are?">
     They are a connection point with an out direction that is aligned ↗️
   </Aside>

4. Change the connection parameters (1:`Gap`, 2:`Shift`, 3;`Rise`, 4:`Rotation`, 5:`Turn`, 6:`Tilt`) 🎛️

   In Grasshoper you should see:
   ![Connectors](../../../../../asset/image/starter-grasshopper-connection.png)

   In Rhino you should see:
   ![Connectors Preview](../../../../../asset/image/starter-grasshopper-connection-preview.png)

   <Aside type="note" title="🤯 What just happened?">
     The connection parameters are applied one after each other 🔢
   </Aside>

That's it! Your first compose design 🎉
