# ui

The `ui` bundle holds the shared interface layer consumed across semio's framework-facing packages: the `js/react` design system (components and Storybook source), the `styling` token pipeline (generated JS/Rust/Python/.NET/Tailwind theme output from a shared source), the `wgpu` widget primitives, and vendored `asset` fonts, icons, and cursors.
