CW7 sweep A — import-path surgery: vcs::{Operation,OpText,OperationDiff,Edit,...} -> protocol::
Scope: cad/rs, cad/plugin/rs, draw/rs, fem/2d/rs, fem/3d/rs, norm/core/rs, note/plugin/rs
None of these 7 crates construct/match vcs::CollectionOperation (grep-verified, empty match in
every crate) — so this was pure import-path surgery for all 7, no shape migration needed, no
cross-reference to cw7-instructions.md's Add{id,item,at}/Move{to} steps required.

Method per crate: grep vcs:: usages in lib.rs, move only the trait/type names that protocol/rs/lib.rs
actually re-exports from protocol_command (Operation, OperationDiff, OpText, Edit, CollectionDiff,
ItemPatch, Identified, Patchable, CollectionOperation, apply/invert/collection_diff_from_operation)
to `protocol::`, leaving vcs-only concepts (DocumentVcsEnvelope, DocumentVcsStore,
DocumentVcsCommand, create_document_vcs_envelope, apply_operation, DocumentDsl, Backbone family,
TextError/TextSpan (from dsl_core, re-exported by vcs, never moved to protocol), vcs::test_support)
on `vcs::`. Added `protocol` as a direct Cargo dep only where genuinely missing.
