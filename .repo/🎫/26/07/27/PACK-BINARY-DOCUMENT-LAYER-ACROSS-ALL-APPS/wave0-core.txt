- 🔖Ids: ContentHash([u8;32]) with hand-written Display (lowercase hex) + Debug ("ContentHash(<hex>)"),
  Clone/Copy/PartialEq/Eq/Hash. ChunkId(u32), SegmentKind(u8), CodecId(u8), ByteRange{offset,len}
  all with the derives the contract specifies.
- 🔖SegmentKinds: implemented as top-level `pub const KIND_*: u8` constants (not wrapped in
  SegmentKind) since pack_format's PackWriter::write_segment/Manifest usage takes/refers to a
  bare u8 kind — this matches how KIND_MANIFEST etc. are used in the pack_format section of the
  contract. All 10 constants present with contract values (0x00..0x08, 0x7F).
- 🔖Errors: PackError enum, all 12 variants verbatim (BadMagic, UnsupportedVersion,
  UnknownRequiredFlags, Truncated, ChecksumMismatch, ContentHashMismatch, LimitExceeded,
  Malformed, NonCanonical, UnsupportedCodec, Schema, Io) via thiserror::Error, Debug, Clone,
  PartialEq.
- 🔖Limits: PackLimits with the 6 fields and contract-specified Default values.
- 🔖Varint: LEB128 unsigned varint (write_varint_u64/read_varint_u64, max 10 bytes for u64),
  zigzag signed varint (write_varint_i64/read_varint_i64 via internal zigzag_encode/decode
  helpers), is_minimal_varint (decode-then-reencode-and-compare). read_varint_u64 rejects
  >10-byte sequences and a malformed 10th byte (only bit 0 may be set, matching u64's 64-bit
  budget = 9*7+1) with PackError::Malformed; truncated input returns PackError::Truncated at
  the exact failing offset. Never panics.
- 🔖Bytes: ByteReader<'a> (bounds-checked cursor over &[u8]; read_u8/u16_le/u32_le/u64_le/
  f64_le/varint_u64/varint_i64/bytes(len)/array32, remaining()/position()) and ByteWriter
  (Vec<u8>-backed; matching write_* methods + into_bytes()). All reader methods bounds-check
  before slicing — verified never-panics-on-truncated-input in tests.
- 🔖Crc: crc32c(bytes) -> u32, CRC-32C (Castagnoli, poly 0x82F63B78 reflected), in-crate 256-entry
  table built by a const fn at compile time (no runtime init, no external crate). Verified
  against the standard test vector crc32c("123456789") == 0xE3069283.
- 🔖Source: PackSource trait (len/is_empty/read_at/read_exact_at with a default read_exact_at
  looping over read_at) implemented for &[u8] and Vec<u8> (delegates to &[u8]), both fully
  bounds-checked (short reads return the actual byte count, out-of-range offset returns
  PackError::Truncated, never panics/never reads OOB). PackSink trait (write_all/position/flush)
  implemented for Vec<u8>.
- 🔖Codec: CompressionCodec trait (id/compress/decompress) and NoCompression (CodecId(0),
  identity compress, decompress validates raw_len > limit BEFORE allocating/copying and validates
  stored.len() == raw_len).
