# Normative Correction — Package Entry Is Glue (2026-08-06)

Packages are **glue only**. Package-level entry files MUST be named **glue**, never `lib` or `component`.

## Layout

```
<owner>/
  🦀️component.rs                    # domain (and nested <component>/🦀️component.rs)
  📦️packages/🦀️rust/
    Cargo.toml                       # [lib] path = "📦️glue.rs"
    📦️glue.rs                        # #[path] wiring + pub use + cfg ONLY
    📋️project.json
    📜️script.ts
  📦️packages/🟦️typescript/
    🟦️glue.ts                        # reexports ONLY
```

## Forbidden

- `⚡️implementations` anywhere in owner trees
- Domain bodies inside `📦️packages/**`
- Package-level files named `lib.rs` / `component.rs` (use `📦️glue.rs`)
- Framework root folders other than `📦️packages`, `🔨️modules`, `🛍️products`

## Path rules

- Leaf `#[path = "../../…/🦀️component.rs"]` needs `../../` from packages/rust.
- Grouping `#[path = "."]` must **not** get an extra `../../`.
