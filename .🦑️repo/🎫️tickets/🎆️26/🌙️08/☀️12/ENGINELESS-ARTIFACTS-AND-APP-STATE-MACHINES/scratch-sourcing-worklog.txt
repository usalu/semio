2. THE SHADOWING HAZARD — how it was handled
--------------------------------------------------------------------------------
The artifact root 🗿️artifacts/🗂️curate/🦀️component.rs carries its OWN
`pub mod io_registry` whose entries() returns &'static [&'static ComposerEntry]
(a .iter().collect() VIEW), while the relocated real one returns
&'static [ComposerEntry] — different types, silently swappable.

Handled by fully qualifying BOTH remaining references to the real registry:
  declaration() .composers(...) ->
    crate::artifacts::curate::standards::v1::subsets::any::io::io_registry::entries()
  the shadow module's own alias ->
    use crate::artifacts::curate::standards::v1::subsets::any::io::io_registry as v1;
No unqualified `io_registry::entries()` call survives anywhere.
(Module nesting was verified against 📦️glue.rs's #[path] mounts first — `engine`
was mounted at standards::v1 level, NOT under subsets::any, so the naive
"swap engine->io" substitution would have produced a wrong path. Checked, not assumed.)
