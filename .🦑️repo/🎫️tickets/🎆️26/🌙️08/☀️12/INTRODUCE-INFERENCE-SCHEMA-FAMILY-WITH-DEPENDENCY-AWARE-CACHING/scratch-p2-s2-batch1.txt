=== PLY ===
Slug: 📦bounds
Real fields used: PlyBounds{ min: [f64;3], max: [f64;3], vertex_count: u32, face_count: u32 } —
generic by-name lookup, NOT hardcoded to any element: locates the element with name == "vertex",
finds property indices for "x"/"y"/"z" within that element's own `properties` (via
PlyProperty::name()), folds every row's cells at those indices (converted via a hand-written
ply_value_as_f64 matching every numeric PlyValue variant: Char/UChar/Short/UShort/Int/UInt/Float/
Double, with List honestly None) into min/max. vertex_count = row count of the "vertex" element
(independent of whether x/y/z were found). face_count = row count of an element named "face", if
present (also generic, no assumption it exists). PlyBounds derives Default (empty elements list ->
all-zero, matches [f64;3] default [0.0,0.0,0.0] — verified by inference_default_law test).
