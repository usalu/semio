## bcf — BcfTopicStats
- Real fields used (from 📸️snapshot/🦀️component.rs, re-verified): `BcfSnapshot.topics: Vec<BcfTopic>`,
  each `BcfTopic.comments: Vec<BcfComment>`, `.viewpoints: Vec<BcfViewpoint>`, `.creation_author:
  String`; each `BcfComment.author: String`.
- Derivation: topicCount = topics.len(); commentCount = sum(topic.comments.len()); viewpointCount =
  sum(topic.viewpoints.len()); authorCount = size of BTreeSet<&str> built from every
  topic.creation_author PLUS every comment.author (no filtering of blanks — literal per spec).
- BcfTopicStats derives `Default` (plain `#[derive(Default)]`) — all-zero matches empty `topics`,
  confirmed by `inference_default_law`.
- Module paths: schema `crate::artifacts::bcf::standards::v2_1::subsets::any::schema::snapshot::
  BcfSnapshot`; builder `crate::artifacts::bcf::standards::v2_1::subsets::any::schema::BcfBuilder`.
- Slug dir: 🗒topicstats (emoji: 🗒️ tag character variant, dir literally `🗒topicstats`, matching

## epw — EpwClimateSummary
- Real field used: `EpwSnapshot.records: Vec<EpwRecord>`, each `EpwRecord.dry_bulb_temp: String`
  (all EPW record columns are String by the snapshot's own deliberate lossless-retention design,
  confirmed reading the snapshot's module doc comment).
- Derivation: iterate records, `record.dry_bulb_temp.trim().parse::<f64>()`, skip (no
  panic/error) on failure; recordCount = total records seen; parsedTempCount = successfully-parsed
  count; min/max/avg fold only over parsed values; if parsedTempCount==0 all three temp fields
  default to 0.0 (guards divide-by-zero AND matches `EpwSnapshot::default()`'s empty `records`).
- EpwClimateSummary needed a HAND-ROLLED `Default` (not derive) — explicit all-zero, since the
  "no data" identity logic lives in `compute_epw_climate_summary`'s guard, not derivable
  structurally. Confirmed via `inference_default_law`.
- Module paths: schema `crate::artifacts::epw::standards::energyplus::subsets::any::schema::
  snapshot::EpwSnapshot`; builder `crate::artifacts::epw::standards::energyplus::subsets::any::
  schema::EpwBuilder`. Standard mod segment: `energyplus` (bare, no `v_` prefix) — confirmed via
  live grep of pre-existing `crate::artifacts::epw::standards::energyplus::subsets::any::...`
  usages already in 🚪️io/🦀️component.rs and ⚙️engine/🦀️component.rs.
