# W1 glTF Mutation Frozen-Tree Audit

Scope is limited to `change-material-alpha-mode`, `change-material-double-sided`, `create-scene`, `bind-node-child`, `unbind-node-child`, `bind-scene-root-node`, and `unbind-scene-root-node`. This is a read-only static audit; Cargo was not run. The decision rule is the ticket checklist: a leaf is accepted only if every item in `📋️leaf-acceptance-checklist.md:5-17` is true. Therefore a local leaf implementation that is otherwise coherent remains **not accepted** when assembly, wire, vector, parity, or current-tree gates fail.

## Gate findings

### Root assembly and glue

- Rust root assembly imports and registers exactly the two material leaves at `✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/🧊️gltf/🏅️standards/🔖️2.0/🪆️subsets/✳️any/🧬️schema/🧬️mutations/🦀️component.rs:3-4,46`; the JSON assembly repeats exactly those two members at `.../🧬️mutations/🔣️component.json:4-14`. None of the five other candidates is in the registry.
- The glTF subset roots are empty in both languages (`.../✳️any/🟦️component.ts:1-2`, `.../✳️any/🦀️component.rs:1-2`), so there is no TypeScript root descriptor assembly or Rust top-level delegation for these leaves.
- Rust glue mounts only alpha and double-sided (`✏️s/🔌️plugins/🗄️stdio/📦️packages/🦀️rust/📦️glue.rs:2264-2292`). It has no mounts for create-scene or either node/scene-root relation pair. The mutation dispatch and text/binary modules are mounted at `.../glue.rs:2295-2303,2321-2325`, but cannot discover the unregistered leaves.
- Rust dispatch is descriptor-based and recomputes application paths before comparing the envelope (`.../🔨️modules/🧭️mutation-dispatch/🦀️component.rs:145-172`), but its registry is built from the incomplete root at `.../🧭️mutation-dispatch/🦀️component.rs:180-186`. The TypeScript dispatch remains a frozen 0–27 aggregate union importing `NoMutation`, `SetSnapshot`, `SetAsset`, and every `Set*`/insert/remove variant (`.../🔨️modules/🧭️mutation-dispatch/🟦️component.ts:1-29,52-80`). This is a direct OCP breach and forbidden no-op/snapshot/set vocabulary.
- The same legacy aggregate remains in JSON Schema, GraphQL, and Proto (`.../🔨️modules/🧭️mutation-dispatch/🔣️component.json:3-35`, `.../🔨️modules/🧭️mutation-dispatch/🔗️component.graphql:3-44`, `.../🔨️modules/🧭️mutation-dispatch/🛰️component.proto:7-37`). The global diff also retains a weak whole-item collection type (`.../🧬️schema/🔺️diff/🟦️component.ts:14-20`, `.../🧬️schema/🔺️diff/🔣️component.json:33-40`, `.../🧬️schema/🔺️diff/🔗️component.graphql:74-85`, `.../🧬️schema/🔺️diff/🛰️component.proto:65-66,91-122`) and the private TS helper still constructs generic collection diffs at `.../🧬️mutations/🔒️top-level-collections-private/🟦️component.ts:35-45`; Rust `family_diff` computes every collection regardless of its family argument at `.../🧬️mutations/🔒️top-level-collections-private/🦀️component.rs:17`. These are frozen aggregate/generic remnants even though the material leaves do not use them directly.

### Text and binary transports

- Rust text is a generic envelope codec with unknown command/version validation through the registry (`.../🚪️io/🧬️mutations/📝️text/🦀️component.rs:46-75`), but TypeScript is only an alias and imports the legacy aggregate `GltfMutation` (`.../🚪️io/🧬️mutations/📝️text/🟦️component.ts:1-4`).
- The canonical Semio grammar describes `gltf-mutation commandId=... version=... phase=... payload=...` (`.../📝️text/📖️component.grammar.semio:7-12`), while EBNF and ANTLR still accept old no-mutation/set/insert/remove keywords (`.../📝️text/🔤️component.ebnf:1-12`, `.../📝️text/🅰️component.g4:1-8`). The text JSON schema still references the legacy mutation aggregate (`.../📝️text/🔣️component.json:3-10`).
- Rust binary implements marker/phase/id/version/payload lengths, trailing-byte, budget, and registry checks (`.../🚪️io/🧬️mutations/💾️binary/🦀️component.rs:14-57`). TypeScript still exposes the old 0–27 tag map (`.../💾️binary/🟦️component.ts:1-12`), and KSY/ABNF/Spicy describe that old format (`.../💾️binary/🥋️component.ksy:5-17`, `.../💾️binary/🔠️component.abnf:1-6`, `.../💾️binary/🌶️component.spicy:3-7`). The protocol comment claims a generic envelope but is only a partial description (`.../💾️binary/📡️component.protocol.semio:8-16`). Thus no candidate can satisfy checklist item 16 or the current-tree wire/parity gate.

## Bottom line

No audited leaf is accepted in the frozen tree. Alpha and double-sided are the only locally mounted generic descriptors and have the strongest sparse semantics, but still fail the complete registry, TypeScript, vector, transport, and current-tree gates. Create-scene fails the generic descriptor/OCP and package schema assembly gates in addition to incomplete inverse/path coverage. All four relation leaves fail registration, inverse dispatch wiring, and vector/parity gates; both unbind leaves additionally fail explicit target-reference validation and exact inverse stale-state protection.
