AcDbEvalEdgeInfo Methods

Methods
Method 
Description 
from 
Returns the originating node ID of the edge.
 
isInvertible 
Indicates whether the edge is invertible; in other words, whether the originating and terminating nodes can be swapped depending on which of the nodes is activated.
Returns true if the edge is invertible.
 
isSuppressed 
Tests whether an edge is suppressed; that is, temporarily considered removed from the graph during activation and/or evaluation. This flag applies only to an invertible pair of edges, where during activation one of the directions is active and the complementary one is suppressed.
Returns true if the edge is suppressed.
 
refCount 
Returns the reference count for an edge; in other words, the number of times it was added to the graph. 
to 
Returns the terminal node ID of the edge.
