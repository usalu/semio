Regions (all inside `mod native`):
- //#region 🔖️File — FilePackSource (wraps Mutex<std::fs::File> + cached len; PackSource::read_at
  dispatches to std::os::unix::fs::FileExt::read_at on unix, std::os::windows::fs::FileExt::seek_read
  on windows (both &self, no lock contention issue beyond the mutex itself), and a seek+read
  fallback on any other native target — single Mutex<File> field keeps this to one code path).
  FilePackSink (std::fs::File opened write+create+trutruncate, tracks its own `position: u64`
  field since File exposes no position without a &mut seek; write_all delegates to
  std::io::Write::write_all, flush() calls file.flush() + file.sync_all()).
- //#region 🔖️Atomic — write_atomic(path, bytes): writes to `<path>.tmp-<pid>-<AtomicU64 counter>`,
  fsyncs the temp file (File::sync_all), then std::fs::rename into place. No rand crate; counter is
  a private static AtomicU64.
- //#region 🔖️Stream — StreamingPackWriter wraps pack_format::PackWriter<FilePackSink>; create/
  write_segment/write_chunk/finish all thin delegations, matching the contract signatures exactly.
  finish() discards the returned sink after PackWriter::finish's internal flush (which triggers our
  FilePackSink::flush's fsync).
- //#region 🔖️Recover — recover_file(path, limits): FilePackSource::open + pack_format::recover.
- //#region 🧪️Tests (inside #[cfg(test)] mod tests, no level submodules — nothing slow/exhaustive):
  7 tests, all passing:

  2. write_atomic_produces_full_content_and_no_stray_tmp_file — successful write, content verified,

mirrors pack_format's private (non-exported) segment framing arithmetic for the CodecId(0)
(no-compression) case only (`kind(1) + flags(1) + varint(seg_len) + payload + crc32(4)`, no
raw_len field since not compressed) — needed only to hand-build a `Manifest.doc_span.len` that
satisfies `PackFile::body_bytes`'s `doc_span.len > 0` gate. This is scoped to `#[cfg(test)]` and
does not affect the public API.
