`create_process3d_app`) and confirmed "cursor" is genuinely absent from
ui/asset/icon/generated/icon_name.rs, while sibling plugins (puzzle/plugin, remodel/plugin) already
use valid replacements ("mouse-pointer" / "mouse-pointer-2"). Fixed by changing to
`"mouse-pointer"` (confirmed present in the icon catalog), matching current puzzle/plugin usage.
This file is within my allowed process/** scope; the icon catalog itself (ui/asset/**) was not
touched.
