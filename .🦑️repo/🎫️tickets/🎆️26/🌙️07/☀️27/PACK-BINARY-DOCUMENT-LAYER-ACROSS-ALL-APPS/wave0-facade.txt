Reconciliation vs. contract's illustrative re-export list
-----------------------------------------------------------
The contract's `## pack (facade)` code sketch lists only a subset of each sibling's public
items (e.g. omits pack_format's flag/magic constants, encode_symbols/recover/read_footer_only,
DeflateCodec; omits pack_io's recover_file; omits pack_async's ReadRequest/BoundedDemand/
DemandPermit — the last two of which are structurally required to actually call
`ReadScheduler::read`/`BoundedDemand::acquire` from a `pack`-only dependent; omits pack_http's
RetryPolicy/UreqRangeTransport). Per the task instructions ("re-export the full public surface"),
this implementation re-exports every top-level `pub` item each sibling crate actually exports,
using the sibling lib.rs files as source of truth. No sibling crate was missing anything the
contract promised — all reconciliation was "contract's list was a subset of the real surface",
handled by re-exporting more, not less.

Added two facade-owned Cargo features (not in the contract, needed to make the extra reexports
compile safely):
- `deflate` (default-on) — forwards to `pack_format/deflate`, gates the `DeflateCodec` reexport.
- `ureq` (off by default) — forwards to `pack_http/ureq`, gates the `UreqRangeTransport` reexport.
