Design choices made where the contract said "your choice"
-----------------------------------------------------------
1. Timestamp round-trip heuristic (scalar::write_timestamp): tag 1/2 is used only when
   `format_rfc3339_ms(parse_rfc3339_ms(raw)) == raw` byte-for-byte. The parser/formatter is a
   self-contained UTC RFC-3339 implementation (Howard Hinnant's days_from_civil/civil_from_days
   proleptic-Gregorian algorithm, no external date crate) that canonicalizes to
   `YYYY-MM-DDTHH:MM:SS[.fff]Z` (fraction present iff nonzero ms). Anything that doesn't already
   match that exact canonical grammar (non-Z offsets, non-ms-truncating fractions, non-canonical
   padding, leap seconds, etc.) safely falls back to tag 0 raw text — correctness never depends on
   the formatter being calendar-complete, only on the equality check before committing to tag 1/2.
   A pre-1970 timestamp with no `prev_epoch_ms` base (tag 1 needs an unsigned varint) also falls
   back to raw text rather than attempting a lossy absolute encoding.
2. Id tag selection (scalar::write_id): priority order is edit-ordinal (tag 3, cheapest) >
   prefix+uuid split (tag 2, 16 raw bytes beats a 36-byte string even after interning) > dictref
   (tag 1, general fallback via the caller's intern closure). Tag 0 (raw) is never emitted by this
   writer — it exists in the format purely so `read_id` stays forward-compatible with ids written
   directly by another layer; a test confirms it's still readable. The prefix+uuid split requires
   a canonical lowercase-hex-with-dashes UUID tail so the decode round-trips byte-exact (an
   uppercase-hex UUID falls through to dictref rather than risking a lossy canonicalization).
3. `DocumentKind` is mentioned in the amendment's 🔖️Policies prose ("MergeStrategyKind +
   DocumentKind moved from framework/core...") but the frozen Rust signature block only defines
   UndoPolicy/MergeStrategyKind/ConflictRule — no DocumentKind struct. I implemented exactly what
   the code block specifies and left a comment noting the prose/code mismatch rather than
   inventing a signature not in the contract.
