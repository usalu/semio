Public API (FROZEN):
- Types: AxisAlignedBox { min, max }, PointSolidClassification { Inside, Outside, OnBoundary }
- Solid: solid_volume(body, solid, chord_tol), solid_surface_area(...), solid_center_of_mass(...), solid_bounding_box(body, solid)
- Face/edge: face_area(body, face, chord_tol), edge_length(body, edge)
- Distance: distance_solid_solid(body, a, b), closest_point_on_solid(body, solid, point) -> (Pnt3, f64)
- Classify: classify_point_on_solid(body, solid, point) — multi-ray parity stub; Wave 3 classify module may replace internals

Implementation:
- Planar faces: Newell area + signed tetrahedron fan (exact box metrics).
- Parametric faces: 5×5 Gauss-Legendre over UV bounds with loop UV polygon trim; volume via P·(∂u×∂v) (divergence theorem).
- Pure Sphere shells: analytic (4/3)πr³ fast path when all faces share one Sphere surface.
- Separated solids: distance_solid_solid uses AABB gap before surface sampling.
- Planar closest point: infinite-plane projection then boundary edge refinement when projection falls outside trim.

Tests (inline, quick tier): unit box volume=1 area=6; 2×3×4 box vol/com/bbox; edge length; face area; sphere vol ~ analytic (fast path); separated box distance/closest; classify inside/outside.
