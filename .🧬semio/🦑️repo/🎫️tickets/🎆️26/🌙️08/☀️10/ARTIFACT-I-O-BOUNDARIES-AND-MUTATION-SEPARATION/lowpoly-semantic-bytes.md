# Lowpoly Semantic Octets

Canonical PixelRun is owned once by schema and reused directly by mutation and delta owners. Paint buffers and runs bind intrinsic DslValue bytes. Physical compact base64 belongs to text IO JSON conversion; obsolete serde modules are removed. Existing committed physical JSON fixtures remain in their declared base64 representation and law helpers decode through the explicit IO boundary. Rust tests compare neutral octets and physical JSON against serde_json and test-only base64.
