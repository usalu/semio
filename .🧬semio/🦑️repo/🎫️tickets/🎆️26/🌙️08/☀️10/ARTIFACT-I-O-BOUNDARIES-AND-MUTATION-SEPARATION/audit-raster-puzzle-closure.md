Puzzle2d and Puzzle3d canonical Snapshot and Diff own mutation algebra. The old production MutationDiff<serde_json::Value>, DiffAlgebra<serde_json::Value>, Mutation<serde_json::Value> and document-delta bridges were removed. Native value decoding refuses malformed roots, never substitutes an empty document. Puzzle5d schema bridge removal and initial root relocation were completed here; its broader host conversion and tests are owned by the host peer.

Puzzle2d native host JSON uses the first-party Pack JSON implementation. Its actual dispatch compares canonical typed authority against an explicitly admitted candidate. Board-tool releases retain typed Arc snapshots for both base and outcome. Cut commands derive canonical typed changes directly. Puzzle3d prologues retain typed Arc authority, use direct host projection and explicitly admit host scale/catalog fields. Host changes preserve canonical fields absent from the host scene vocabulary. Cut uses typed roots, and engine projection refusal no longer turns malformed attraction or target-volume rows into an empty collection.
