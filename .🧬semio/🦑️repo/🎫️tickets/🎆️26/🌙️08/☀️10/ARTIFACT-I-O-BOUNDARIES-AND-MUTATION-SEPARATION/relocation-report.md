# Artifact Codec Relocation

## Implemented Ownership

Plugin artifact standards now locate native representation sources in `🚪️io/<representation>/<semantic-facet>/[member]`. Filesystem census included ignored representation files and identified 1,371 binary/text directories containing 7,046 files. SQLite extension relocated 347 directories containing 1,371 files, including SQLite-owned tests and fixtures. Native owner modules assemble representations and then snapshot, diff, mutation, and inference facets. Semantic schema roots no longer mount binary, text, or SQLite module declarations.

Four destination collisions were existing Writer/Curation mutation codecs and semantic mutation identity registries. Registry declarations were merged into the existing actual codecs and members mount directly from their IO facet.

Thirty-nine separate operation grammar files moved from semantic mutation owners into text mutation owners as `📖️mutations.grammar.semio`, alongside their distinct document grammar. Ten schema grammar metadata declarations moved into IO under `MUTATION_GRAMMAR_*`, and two dedicated conformance tests moved with them. Forty-six TypeScript schema owners no longer reexport SQLite or JSON IO APIs; named-import consumers directly address IO.

Rust paths, TypeScript imports, local include paths, fixture references, package verification routes, and authored physical path strings were rewritten. Representation module references resolve under `io::binary|text|sqlite::<facet>`. Removed 404 root and semantic-facet codec aliases; consumer rewrites now address their actual IO modules. A separate shorthand-reference correction changed 56 Rust files. The final public IO member mapping contained 2,087 symbols and required no additional rewrites after those changes.

The remaining WFC facet placeholders were verified empty before removal. glTF facet descriptors now belong to binary/text representation metadata. Lowpoly, Wires, and Curation JSON snapshot codecs now belong to `🚪️io/📝️text/📸️snapshot/🔣️json`; JSON stays a textual dialect within the three representation roots. Their imports and the Lowpoly SQLite mesh test were updated to the canonical paths.

## Validation Evidence

Prechange filesystem inventory proved 1,371 representation directory ownership violations before edits. The final static Rust module/include and TypeScript import resolution check passed: 7,833 IO paths resolved and zero references were missing. Rust Unicode-escaped include paths were decoded before validation. A VDI3805 fixture import and a Lowpoly mesh test JSON codec import were corrected during this verification.

The migrated Generation3d semantic-wire Nx task passed with exit code zero and runtime output `generation3d-semantic-wire checks=83 independentAjv=true`. Its initial rerun identified two dynamically assembled semantic fixture paths, which were corrected before the successful rerun. Native compilation has not been confirmed by this agent. Framework architecture fixture/regression checks and wider native validation are owned by the infrastructure agent and parent respectively.

## Scope And Coordination

The runtime agent owns inline semantic codec extraction, native snapshot pack modules, Generation3d host extraction, and GeoJSON controlled conformance closure. The parent owns framework artifact SQLite and print product extraction. A dedicated diff agent owns explicit/generated DiffCodec extraction.

The ticket `📜️script.ts` preserves inspectable temporary processing commands. Generated inventories and diagnostics remain under `🗑️generated` until the parent finishes validation and removes generated outputs. Relocation changed files across plugin artifacts, codec tests, fixture assets, package scripts, cross-artifact callers, and authored documentation; generated inventory records preserve exact moved paths. No modifying Git command or worktree was used.
