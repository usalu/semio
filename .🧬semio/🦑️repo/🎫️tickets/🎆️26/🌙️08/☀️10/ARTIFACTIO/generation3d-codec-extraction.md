# Generation3d IO Codec Extraction

## Ownership Target

Generation3d native artifact, snapshot, preview camera, mutation payloads and inference records retain their semantic fields and laws in schema. Their actual value representation declarations move to `🚪️io/📝️text/🔣️value/🦀️.rs`. A first-party `value_codec!` procedural macro emits the same projection, admission, controlled traversal, edit and retirement implementations as the existing derives, without declaring another native owner or cloning retained dictionaries. IO explicitly imports each native type and states the wire keys and tags. Schema provides no representation reexport.

The schema-owned gumball projection moves to text snapshot IO and its live command consumer changes owner. Existing graph-editor layout forwarding uses typed options and control, matching the current host API. Host widget admission parses descriptors in IO and forwards a borrowed native descriptor to the semantic editor.
