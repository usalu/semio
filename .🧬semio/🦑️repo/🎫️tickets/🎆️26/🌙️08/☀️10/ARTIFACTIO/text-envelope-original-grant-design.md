# Text Envelope Original Grant Receiving

The current registered 100-law native run exposed a genuine ownership refusal in the existing text-envelope law. A three-byte payload quantum cannot perform an atomic structural header copy. The producer currently quotes capacity/release/depth from its retirement cursor, treats those quotes as authority, charges capacity even when no copy can proceed, and eventually exhausts its native ceiling without making progress.

The replacement will bind a mandatory independent caller RetainedCloneGrant at cursor construction, retain one cumulative RetainedCloneProgress across every step, and expose the actual performed receipt. The original native control remains borrowed at each operation. The fixture will keep its three-byte body quantum and original native ceiling; structural work comes only from the independent original copy grant. Quoted next demands can narrow an operation inside that grant and must never enlarge any currency.

Before output backing allocation, the producer checks remaining items/capacity/depth and forwards the original native charge. The admitted output stays in its actual field. Each copied UTF8 scalar settles actual bytes; the output span contributes its actual item receipt once. Before each retirement step, remaining copy/capacity/release/depth must admit the quoted next frontier, and the original native control receives the actual allocation charge. The actual step or refusal receipt debits the same cumulative wallet. A denied frontier cannot repeatedly consume allocation credit without allocation or work.

Publication requires funded final ownership transfer, empty retired source fields and original cancellation acceptance. Cancellation retains the actual source, partially filled output and any cursor scaffolding. Every existing caller will supply the explicit neutral caller policy; no constructor, helper or resumed step creates replacement authority. Controlled retirement after cancellation remains through the caller's actual supplied grant.

The language-neutral fixture/law will retain budgets 1/8/256, body quantum 3, original source/output pointers, zero-unit no-effect behavior, cancellation positions, exact cumulative physical allocation/release and an independent Bun TextEncoder oracle. The old metadata-derived capability must be removed completely once the receiving API is accepted.

The neutral fixture now declares the existing 1,000,000-byte native ceiling and an independent original policy: 65,536 items, 65,536 copy bytes, 16 MiB capacity, 16 MiB release and depth 64. The original depth and three-byte body quantum remain unchanged. The first proposed 256 lifetime items is explicitly retained as an undergrant: independent UTF8 input arithmetic gives 1,152 payload bytes and at least 384 three-byte retirement turns before scaffolding. There was no lifetime item grant in the previous API. The complete policy uses the existing canonical allocation-fixture item policy rather than deriving authority from a retirement demand. Separate architecture rows declare the 12/24-byte optional text header; this structural demand is independent of the body quantum and may only narrow the original copy allowance.
