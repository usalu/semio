# Owned Inference Dependency Carrier

The native RED3 test compiler rejected the new associated Dependency type (E0437/E0220). InferredField now returns an owned first-party semantic value; physical text encoding and cache decoding belong to framework IO. Every existing producer has an explicit dependency type. Remodel/Puzzle/Equation bodies are being converted by the TypeScript execution agent. Semantic Semio projections and native GREEN verification are pending.
