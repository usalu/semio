## Retired Physical Semantic Entrypoints

The directed force/hierarchy/redraw JSON/value helper modules and Normal root forwarders are removed. The undirected field-map snapshot layout module is removed. DAG typed layout no longer serializes its snapshot through JSON or DslValue. Puzzle engine has no unused redraw forwarding API. The tidy-tree law is moved beside its actual layered owner, rather than duplicated.

## Actual Native Scope

The actual first-party Value, Pack JSON, Graph, Geometry and UI Styling dependencies are linked with original Board snapshot/palette/visibility physical owners, current Board schema and all four current layout algorithms. The unchanged assertions of the original 22 Puzzle layout laws, original 9 Board IO laws and original tidy law are mounted alongside two new neutral/control laws. The harness does not compile the full Normal, DagHost, FlowHost, renderer or Puzzle editor/WASM receiving modules.
