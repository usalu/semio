# Canonical Scalar Ownership Closure

Twenty canonical artifact schema sources were still converting JSON/native numeric/hexadecimal IEEE transport. These now admit only owned scalar words with `parseBinary32`/`parseBinary64` from Value. Physical preconverters remain under I/O. Remodeling and Program were independently fixed after a regression exposed hex-string admission.
