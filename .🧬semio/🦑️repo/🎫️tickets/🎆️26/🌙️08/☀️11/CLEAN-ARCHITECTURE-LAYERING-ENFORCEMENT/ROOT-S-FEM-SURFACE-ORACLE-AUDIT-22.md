## Kernel and Semantic Preservation

The captured entire 2D kernel includes `triangulate` (line 1131, delegates to `owned_triangulate`), full owned/incremental constrained triangulation and helpers, `extrude_tri_mesh` (2437), `split_to_tets` (2522), `boundary_faces` (2568), and associated tests. Preserve these bodies as current behavior evidence, not a rewrite license.

Current surface traversal keeps document region order, uses outline plus holes, region mesh_size and min angle 20 degrees, silently skips each failed triangulation, extrudes by that region's own f64 thickness with one layer, splits wedge cells to tets, and extracts external faces. All tet points are retained, and face triples flatten without remapping. Region id survives as mesh id; primitive id is `${region.id}-surface`. Bar/beam members contribute no geometry, so no-region documents give an empty snapshot. Failed regions disappear while subsequent valid regions remain; the analysis path instead maps triangulation failure to `Fem2dError::MeshFailed`. Do not accidentally unify these distinct error behaviors during extraction.

Extrusion clamps layer count to at least one and emits planes z=height*l/layers. Tet splitting passes existing Tet4 through, uses minimum global node apex and consistent quad diagonal selection. Boundary extraction ignores non-tet cells, counts sorted face keys, keeps faces occurring exactly once, and flips winding when the face normal points toward its owning tet centroid. Its HashMap traversal means face order is not guaranteed: compare oriented triangle multisets, preserving cyclic orientation and multiplicity, not byte equality or an invented stable face order. Zero or negative thickness is currently passed through without an export-specific positivity check; characterize it before any intentional behavior change.

Proposed schema-first neutral contract (not an existing declared type): `RegionSurfaceInput { regionId: string, domain: PlanarDomain, thickness: f64, options: MeshOpts }`; `RegionSurface { regionId: string, points: f64[3][], triangles: u32[3][] }`; ordered `RegionSurfaceBatch { regions: RegionSurface[] }`. Keep region selection/failed-region omission in the artifact traversal policy; kernel accepts neutral geometry. The surface algorithm is triangulate → extrude → split → boundary, preserving f64 and triangle topology. `VolumeMesh { points: Vec<[f64;3]>, cells: Vec<Cell> }` has no region identity; do not claim it does. Retaining volume as an additional neutral field is a separately specified choice, not required by current exporters. Do not substitute Framework f32 MeshTransfer and silently narrow precision.
