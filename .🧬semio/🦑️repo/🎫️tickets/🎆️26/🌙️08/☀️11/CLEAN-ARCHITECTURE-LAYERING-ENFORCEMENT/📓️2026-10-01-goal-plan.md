## Neutral Catalog Admission

The framework catalog consumes declared owner publications. Each package's publication subtable names an owned JSON manifest. That manifest declares publication payloads, owned validation schemas, output names and protocol digest bindings. Framework admission validates containment, regular files without symbolic-link traversal, finite sizes, duplicate identities and outputs, schema validity and SHA-256 correspondence. It does not select Stdio, know its file names, require its editor or invent its factory roster. An empty optional owner inventory is valid. An installed malformed contribution fails its contract.
