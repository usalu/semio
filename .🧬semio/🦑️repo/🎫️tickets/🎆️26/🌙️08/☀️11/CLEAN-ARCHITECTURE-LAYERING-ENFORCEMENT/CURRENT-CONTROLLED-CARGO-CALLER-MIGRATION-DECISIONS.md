## Actual Command Boundary Composition

The concrete inventory shows three command hosts: the Repo entrypoint contribution, the Repo workspace entrypoint and independently owned Rust artifact package entrypoint, plus the direct Cargo script/preparation entrypoints. The neutral General ScriptRouter has no Repo operation dependency and will stay neutral. Actual Repo command hosts can bind a mandatory owned Cargo command scope around their dispatch, carrying the same signal, finite limits, progress, continuation and retained workspace into canonical async API calls. Public inventory and preparation APIs keep mandatory explicit operations; command consumers obtain their operation only from the explicitly admitted command scope. Tests must bind an explicit owner too. This plan has not yet been compiled or executed.
