# Closed Native Nx Cache Custody

Read-only audit of the actual current published General36–43 and Flow4–5 rows found all ten routes use the same Root Nx cache and workspace-data directories. They do not name private Native epoch leaves. These common paths serve unrelated Root and peer launchers, so closed Native process history alone cannot establish exclusive ownership of any directory or file.

The exact current row commands, environments and refusal reasons are preserved in native-closed-nx-cache-custody-audit-1.json. Eligible owned retirement paths: none. Eligible files and bytes: zero. Native deleted nothing, launched no retirement, and preserved every shared Cargo target/cache, input, source, receipt, journal and future General45/Flow6 path. A proposed finite retirement of these common directories would need Root's own complete shared custody proof; Native cannot honestly attribute them to these ten closed native operations.
