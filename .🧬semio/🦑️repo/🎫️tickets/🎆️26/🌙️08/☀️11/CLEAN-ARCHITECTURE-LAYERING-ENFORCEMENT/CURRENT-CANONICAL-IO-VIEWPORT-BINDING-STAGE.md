## Retained semantics and source ownership

ArtifactRef retains four ordered Text fields with IDs 0–3: artifact-id, artifact-kind, standard, subset. Its controlled schema producer copies field metadata under the same caller control; controlled projection copies the four literal text values, and controlled reconstruction admits their exact UTF-8 owned bytes. Empty, NUL, Unicode and delimiter-containing literals remain literal values. The original OS refusal law is transferred to the neutral IO owner alongside its existing canonical fixture. Pack owns removal of the old OS implementation and mount.

Viewport2d retains Float fields x/y/zoom with IDs 1–3. Viewport3dOrbit retains position/target three-component tuples, zoom, and optional up with IDs 1–4. Ordinary validation/projection behavior is transferred exactly. Both explicit controlled schema factories are preserved. Controlled projection and reconstruction continue to return typed UnsupportedOwner through canonical defaults; no uncontrolled fallback is added. Pack retains the two existing OS viewport Pack consumer laws.

The shared schema/source helper lives under canonical Record binding ownership. Its dependency direction is downward: IO and UI depend directly on semio-framework-dsl-record and Value. Record gains no IO/UI dependency. Viewport's existing Replication Value alias is removed in the production proposal and its schema/tests import Value directly. Type ownership remains in IO/UI; neither type is moved into Record. No public compatibility facade is introduced.

## Test-first phases

The closed schema and IO/UI fixtures cover three existing literal reference cases and all four valid viewport poses. Each owner gains three portable laws and two native laws. The portable laws validate the closed schema with Ajv, compare first-party field projection with independent JSON/SQLite observations, and exercise bounded source witnesses admitting formatting/private additions while rejecting owner/dependency substitution.

The native laws compare ordinary schema with successful controlled decoding AND encoding schema for all three types, including keyword, layout, field order, IDs, keys, shapes, optional/positional/flatten/definition/call-name metadata, and nonzero owned schema charge. IO additionally checks controlled round-trip ownership/refusals. UI checks typed controlled refusals plus invalid poses/foreign fields. The independent native oracle uses Serde JSON. These laws are authored, grammar-checked and uncompiled.

Four rows explicitly retain testAuthored/testPair overlays: IO/UI entries mount only the new tests first; their manifests admit canonical Record as dev-only dependencies (UI also dev-only Value) while production remains unchanged. The original IO refusal law transfers with production. Mount the test rows/routes plus those four test overlays first, retain genuine whole IO/UI native trait RED, then publish reviewed owner implementations/direct normal dependencies and replay the same whole selections. Existing IO test-native remains whole library; new UI test-native is whole --lib --no-fail-fast. Actual native rosters must be discovered, not assumed from historical counts.

Three GUI additions are localized insertion proposals. Root must retain current foreign configurations and rebase only these insertions at publication. Existing native GUI routes are preserved.
