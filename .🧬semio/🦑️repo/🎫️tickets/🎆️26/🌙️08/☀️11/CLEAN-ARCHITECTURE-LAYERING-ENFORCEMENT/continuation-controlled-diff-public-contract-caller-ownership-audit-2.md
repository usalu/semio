The existing General public DiffText/DiffBinary contracts expose ordinary unbudgeted methods. A canonical controlled contract must belong at the same General replication interfaces and require caller-owned controls through every implementation and dispatch join. Adding a second fallback API or projecting through generic JSON would leave the current public callers unclosed.
