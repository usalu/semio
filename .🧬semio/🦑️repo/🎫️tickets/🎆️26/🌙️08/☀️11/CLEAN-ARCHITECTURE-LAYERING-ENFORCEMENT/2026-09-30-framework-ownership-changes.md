## Implementation Details

- One shared corpus owns each of the lease, paint protection, and slider label witnesses. Old files were removed and consumers now resolve the nearest new relative path. The lease corpus descriptor is a frozen byte witness for lease validation. Native catalog tests now parse one complete, neutral framework manifest witness with first-party JSON and serde_json, canonically encode that typed descriptor, and bind its identity to lease fields; they no longer read installed GIS descriptors.
- The closed inference approval schema is authored in framework MCP `🧬️schema/✅️approval-request/🔣️.json`. Its Rust accessor reads this authority. Hub now owns the structural comparison with its projection.
- Domain preview, GIS undo, and Hub protocol parity tests were moved to `🌎️hub/💡️inference/🧪️tests/🔬️client-contract/🦀️.rs`. Generic framework inference tests retain transport, cancellation, ownership, and policy coverage using neutral service names. New neutral response vectors test running/cancelled pages, foreign jobs, incorrect wire schemas, and private proposal leakage. Ajv supplies an independent JSON Schema oracle; d3-hierarchy supplies the layer-lock oracle; native first-party JSON parsing is compared with serde_json.
