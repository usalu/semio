# Admitted Source Custody Defining Law

General25's original cancellation law drops the external retained source before closing its partial cursor. The current public source constructor allocates an Arc metadata frame and two type-erased Any boxes without a grant; source Drop destroys that authority implicitly. The current binding close rejects the final lease, so the actual original law fails. Keeping the external source alive would change the tested ordering and does not solve the receiving contract.

The new schema-first vectors retain original String allocations of8194 and1025 bytes for empty, Unicode and one-byte owners, plus work1/3/64. Admission must refuse zero items or one-short constructor capacity with both original owner pointers unchanged and no allocation or free. Exact admission records actual construction capacity. The source closes before the canceled cursor, and the last cursor lease then owns every original allocation until explicit full grants close it. Native Serde supplies independent original semantic output; physical allocator interception supplies original+born=freed.

The intended implementation replaces arbitrary Any authority with a typed custody payload whose root alias and authority have controlled retirement. The metadata Arc is immutable while shared; only the winner of Arc::into_inner may obtain its typed payload for close. Both source and binding retain inline shared-retirement controls, with independent logical work, scaffold capacity, actual release and depth queries. Alias drops conservatively require the whole Arc release authority even when a nonfinal alias actually frees zero bytes. A canceled source can relinquish its own aliases under full grants while its surviving bindings keep the actual root alive. No old public unadmitted source constructor or two-category factory is retained as final API.

Retained clone derives, paged fields/lists/maps, comparators, insertion lookup leases, projections and Store Snapshot source constructors must receive this custody contract. Fixture-only drivers may admit and drain real source objects using their actual published demands and allocator receipts; production Drop must require terminal-empty and must not become a scheduler. Weak leases require explicit coordination and cannot be silently omitted from physical custody. Full Flow/Store receiving readiness remains held until these real producers and complete original native package laws accept the closure.
