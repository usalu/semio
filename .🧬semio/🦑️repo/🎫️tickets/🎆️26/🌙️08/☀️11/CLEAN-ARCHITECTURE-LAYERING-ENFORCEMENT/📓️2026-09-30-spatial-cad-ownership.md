# Spatial and CAD Ownership Refactor

Implemented 2026-09-30 inside the existing Clean Architecture Layering Enforcement ticket. No Git writes, worktrees, Rust implementation edits, or AGENTS.md edits.

## Result

The general spatial-kernel TypeScript source and its task router no longer import deletable CAD or stdio plugin owners. The CAD package exports its general core only; artifact schemas, runtime, IO, and the OpenCascade differential kernel are no longer eagerly aggregated into that package. Specific test consumers import their actual owners directly. CAD package dependencies no longer require its four extension packages, and its TypeScript project includes only the general entry and engine roots.

The OpenCascade SpatialKernel and its oracle suite, CAD-composed geometry suite, and Semio integration/parity suite now live under CAD `🧪️tests/🔮️spatial-kernel`. The independent spatial mesh/diff suite stays in the spatial owner and requires no CAD bootstrap. No legacy facade remains at the removed source locations.

The former artifact registry moved to the CAD engine. Its duplicated asset interface/state/catalog machinery was consolidated into the general geometry owner. `registerModelDefinitionAssets` returns an idempotent removal operation; removing an owner rebuilds catalogs and invalidates every derived geometry cache. `onModelDefinitionAssetsChanged` supports independent removable subscribers instead of a public mutable singleton callback.

General spatial commands now have `SpatialKernelCommand`, `registerSpatialKernelCommand`, and `spatialKernelCommandFor`. Removing a contribution restores its predecessor; repeated removals cannot delete a later registration. Semio no longer recognizes domain constructor names by suffix. Building, energy, and structure extensions contribute their exact command IDs. Generic CAD construction belongs to `⚙️engine/🏗️construction`, separate from registry ownership.

Wall construction builds a rotated horizontal footprint with positive thickness. Semio closed-profile extrusion now uses its existing general `planarFaceFromPoints` and `extrude` session verbs: the earlier polyline-wire route always created an open native wire. The malformed boolean-difference test now supplies the model containing its operands, matching the runtime contract.

Final complete CAD rerun after canonical construction placement and temporary DEBUG removal passed: 13 test files, 339 tests. Scoped whitespace verification passed again. All output logs generated by this slice were deleted after their results were recorded here.

## Practical Limits

This establishes the TypeScript spatial/CAD source boundary and removable contribution APIs; it does not claim every monorepo dependency is canonical. CAD Rust plugin artifact dependencies/barrels and the artifact runtime's selected extension composition remain separate work. This slice leaves existing runtime composition selections intact. External test oracles are test-owned. The old spatial oracle AGENTS.md remains untouched, per the repository instruction.

Parent integration must refresh bun.lock for the removed required CAD extension dependencies. No new executable command was introduced: every verification used existing Nx/script routes, so no additional launch.json entry is required.
