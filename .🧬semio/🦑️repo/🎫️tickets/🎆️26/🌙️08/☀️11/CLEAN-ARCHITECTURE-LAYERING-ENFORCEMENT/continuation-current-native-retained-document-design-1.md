# Current Retained Intrinsic Document Design

The completed Body materializer is qualified separately in `continuation-current-native-pack-retained-materializer-tdd-1.md`. The next operation must retain actual Document framing instead of making a synthetic Body or calling the synchronous decoder inside one step.

The current General Pack owner already defines allocation-free constructors and bounded advances for `RetainedPackAnchorCursor`, `RetainedPackSegmentCursor`, `RetainedPackCatalogCursor`, and `RetainedValueCursor`. Segment and catalog providers publish exact allocation and physical-release demands. The catalog validates actual segment spans, counts and uncompressed document hash against the terminal manifest/footer. It exposes validated symbol spans and chunk entries by indexed borrowing. Anchor verification advances one CRC byte at a time.

The intrinsic assembly logic must be shared between Body and Document. It owns partially reconstructed containers/text/output and closes them with the real General controlled retirement authority. Framing drivers supply tokens and validated symbol scalar/UTF-8 queries. They retain their own defining close state. No Product, S or extension type belongs in this interface.

Document admission must check the canonical intrinsic schema hash and the one Value field declaration before successful output transfer. Existing controlled schema hashing is synchronous, so invoking it with a callback is not a resumable parser. The intrinsic schema is a fixed production field declaration: one required field, id 1, key `value`, shape Value. Its canonical graph emission can be borrowed and advanced under explicit work credit, with the existing schema graph/hash implementation and independent BLAKE3 oracle establishing the same result. No fixed fixture wrapper is a runtime schema authority.

The Document driver must support identity and DEFLATE segments, original frame boundaries, symbols, manifest/header/footer verification and chunked native bytes. It cannot assume symbols precede the value stream or infer codec flags from compressed length. A bounded verification/catalog pass and bounded document/chunk replay over the same retained immutable input is allowed; a cloned whole payload is not needed. Each pass remains visible in progress and cancellation. Reusing admitted inflater storage requires an explicit defining replay/reset authority after the first segment pass completes.

Transferred source Vec capacity, all parser/catalog/inflater allocations, intrinsic reconstruction and output belong to one cumulative admission ceiling. Typed retirement capacity and exact physical release remain independent per-call categories. Partial refusal preserves every born allocation; completion is withheld until schema/catalog/framing and the terminal value all agree.

Red-first neutral execution will retain the original eleven intrinsic cases and vary identity/DEFLATE, small frame boundaries and a low chunk threshold that forces the original octets case through real chunk custody. Malformed declared fields, schema, header/footer/checksums and explicit Body supplied as Document must refuse without heuristic fallback. One-unit advance, zero-unit inertia, cancellation in verification/replay/reconstruction, original input-pointer custody and allocator-versus-receipt close are required observations.

Surface will consume the actual General operation after this contract passes its complete owner suite. Surface's typed projection, all eight embedded Body fields, JSON materialization and scene commit remain separately metered stages; the Wasm/browser bridge must expose real resumable work and retained input admission rather than wrap synchronous callbacks.
