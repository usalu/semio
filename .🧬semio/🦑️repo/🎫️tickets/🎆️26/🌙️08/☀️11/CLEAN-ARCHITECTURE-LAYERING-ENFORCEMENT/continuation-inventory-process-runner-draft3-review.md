# Inventory Process Runner Draft 3 Review

Read-only source review of block-inventory-extraction-inputs/📥️inputs/🟦️.ts. No production publication or full route admission follows this draft review.

The runner retains the request, admitted argument/environment owners, process owner, backing handles, accumulated capture bytes, read buffers/text and refusal in one workspace. Capture from both pipes uses one serialized cumulative byte ledger; writes use complete short-write loops. Work and retained-payload limits are checked before admitted string copies and capture/read work. The zero-owned cancellation callback runs before admitted input storage. Process termination/join, backing close and lease release occur through refusal cleanup. Same-workspace reads require the exact returned capture object and check file identity, size and modification time; retained text and buffer reservations accumulate rather than reset. These are payload ledgers, not exact Node/V8 pipe-buffer heap bounds.

A concrete optional-compiler gap remains: compiler.buildDirectory and compiler.leaseDirectory bypass the string admission loop, NUL scan and byte/work charging. buildDirectory is not required absolute. These fields reach the existing lease implementation, so arbitrarily large or malformed strings cannot currently be described as admitted bounded input. Add them to controlled admission and test a real held lease/cancellation route. The actual optional lease case is untested in model3.

Storage ancestor lstat checks precede mkdir, but directory creation/opening does not establish durable ancestor identity across concurrent replacement. Capture read opens before checking final file identity; a linked path to the same inode is not distinguished by fstat. The opened file contents/identity are guarded, but a nonsymlink-path guarantee is not established. Do not promote that to stronger path ownership.

The receipt serialization/write and TextDecoder call are finite by admitted payload caps, but each runs as one synchronous step. Deadline uses Date.now rather than a monotonic clock; wall-clock adjustments are outside its current proof. Returned nonzero process codes use reason exit and remain actual outcomes rather than admission failures. Model1 refusal and model2 source advance remain historical; model3 results require their exact staged source/raw postframes audit separately.
