FixedCommandPage owns a fallibly allocated boxed4KiB block and its length. CommandPageSet/PagedCommand own VecDeque page spines and bounded page/item/byte metadata. PagedCommandReader reads bounded varints/bytes. CommandEnvelope carries instance u32/seq u64 plus PagedCommand. CommandBatch and CommandEnvelopeSet own primitive per-command metadata and page spines. The driver algorithms validate exact acknowledgments and release admitted page owners; they do not execute the encoded command.

Move this entire definition/algorithm region into a single canonical neutral Replication child, not merely the visible structs. Preserve private CommandBatchEntry, retention-slot/state/CursorShape helpers, the allocation primitive, constants and all error/serde/Value semantics. Use direct Value imports within the owner; add the missing normal neutral Trace dependency to Replication for the existing ceiling. OS channel and General Kernel then consume that same owner. A single definition avoids nominal type mismatches or duplicate page owners. Preserve language-neutral paging/cursor/budget fixtures and actual allocation/cancellation/close laws before validating the move.

The wider channel file contains AppCommand/AppFrame codecs, product-facing frames, ProtocolError routing and command processing after this region. Its package explicitly exposes ArtifactDialect, Dialect, StandardId, SubsetId, ArtifactRef, IoPayload, Confidence, IoFidelity, IoError/Outcome/Result, IoEntryDescriptor/Route and schema exports. Not every IO facade export belongs there: ComposerEntry, composition traits/futures, dispatch/registry functions, FormatDescriptor and validators are executable IO mechanisms rather than this schema package's current API.

Remove OS macro ownership only after complete consumer admission and compile validation.
