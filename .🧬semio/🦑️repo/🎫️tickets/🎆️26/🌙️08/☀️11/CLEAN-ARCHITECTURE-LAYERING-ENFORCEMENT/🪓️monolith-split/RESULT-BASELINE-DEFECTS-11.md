## 6. Hang of `🎭️actor-transport`

Cause: bun's `expect(promise).rejects/.resolves` blocks the test until the promise settles, vitest's returns at once. Ten tests of `🧪️shardclient-reserved-response-settlement` stored `const observed = expect(p).rejects…` before the statement that settles `p` (terminate, beginClose, revoke, release), so the awaited promise could never settle; the CPU stayed idle and the per-test timeout never fired because the test body never yielded. Fix without a timeout: `afterSettle(promise, () => expect(promise).rejects…)` asserts after the settle under both runners (the law is not about bounded time). Four vitest-isms then surfaced and were made runner-neutral (`spyGetter` for accessor spies, local `stubGlobal`/`unstubAllGlobals`, a directory per codec-bridge case because bun resolves a module imported from inside a query-loaded module without its query, so the bind-once host shim was shared).
