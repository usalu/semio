## Status in one paragraph

The split is done and applied to the live tree. `semio-framework-replication` (lib name `protocol`) is now a facade of 1 lib file (29,243 bytes, 214 active lines) that re-exports the old public surface explicitly from 16 new crates (`semio-framework-replication-{ids,codec,interaction,history-index,command-ingress,wire-core,local-interaction,format,mutation,presence,edit,causal,conflict,history,frames,mutation-messages}`). Every crate is inside 3,500 lines / 28 files / 230,000 bytes for its lib and its test closure on native, `wasm32-unknown-unknown`, `wasm32-wasip2` and with/without `deflate` (census below, 0 non-ok rows). The patched full-resolution differential is clean in six configurations. **Nothing was compiled by cargo:** the launcher got past its earlier refusals this time and then stopped at `Physical compiler admission refused` (`availableBytes 4291510272 < requiredBytes 4294967296`, 3.4 MB short; `Insufficient physical compiler initial headroom`), so no crate was type-checked or tested by rustc. Type-level properties (field and method privacy, trait scope, coherence) are covered by scans only, which is the main residual risk.

2. **Locks are hand-derived** and five locks plus ~180 plugin locks are not refreshed; accept cargo's version on the next `update --workspace --offline`. `verify dependencies write-baseline` was not run for the 16 new manifests (checklist item 2); they add `serde` (ids, codec, interaction, history-index, command-ingress, causal), the same literal external debt the old manifest had.
3. **Pack retarget touches peer-owned crates** (13 manifests, 30 sources); not compiled either. The pack facade identity test (`codec-authority`) now routes `protocol::PackRefusal` through the codec crate re-export.
4. **`history` test closure is at 98 percent of the soft byte target**; adding a test fixture there needs an offsetting move. `wire-core` has 23 and `mutation-messages` 24 of 28 test files.
5. **Facade keeps `pub use semio_framework_value::*`** to preserve names that cannot be enumerated.
6. **Unused-import warnings:** the crate-wide `allow(unused_imports)` of the old root is gone; a few warnings remain in untouched files (oracle count 6 after pruning, most are `use super::*` in retire modules whose macros the oracle cannot expand).
7. `Cargo.toml` workspace member order inside the replication cluster is not byte-sorted (it was not before).
8. Peers may edit replication files after the 18:50 snapshot; the apply was guarded (live equal to the pristine copy for every touched file) and ran clean.
