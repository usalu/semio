# Current Surface Retained Ingress Custody Design

The current Surface node-graph production code still decodes `sync_from_scene_pack` by trying OS Store Body then Document, projects the entire DslValue through Store JSON, and clones nodes/edges/viewport into Serde. Eight embedded text fields still call Store helpers. The published variable Scene contract and original neutral source wire vectors establish explicit Body/Document and `pk:` Body semantics; those production ports have not landed yet.

General Pack now has separate retained intrinsic Body and Document operations sharing one reconstruction owner. Current selected Document green3 is qualified in `continuation-current-native-retained-document-tdd-1.md`; exact schema, allocator and catalog witness laws still await their semantic execution after shared Canvas graph/manifests become coherent. No synchronous Document decoder is an acceptable retained fallback.

The outer source must transfer into the selected General operation once. Root DslValue ownership then supplies borrowed typed field views, so the scene path does not construct a complete foreign JSON tree. Typed node/edge/port validation must advance each field/element separately and preserve the original whole-vector malformed fallback. Present malformed viewport refuses. Allocation, work and cancellation refusals retain their classification and must never default nodes/edges. The real committed graph remains unchanged until a complete scene is admitted.

An embedded `pk:` field transfers its original String to retained Base64. The defining Base64 input currently accepts complete OwnedText only. Removing the prefix with String drain moves the complete remaining payload; a substring copy duplicates it; borrowing a slice inside retained Surface state creates self-reference. The requested defining authority is an explicit checked decoding range over original owned text, returning the original full String/backing through `into_parts`. Progress belongs to the decoding span; original capacity belongs to source custody. The parent owns this Base64 extension and was notified before any Surface consumption.

Decoded embedded bytes transfer into the explicit retained Body owner, then its value transfers into the defining General JSON writer cursor. That writer already accepts real first-party DslValue ordinal views and returns its original source only after completion. All writer/source/frontier/output births and independently granted terminal retirement must join the scene operation's real ownership ledger. Source backing, partial output and parser scaffolding cannot be silently freed or refunded together. Finite work and cancellation need real retained phases at each handoff.

The Wasm/browser API must expose request, advance, cancel and terminal close on the retained operation. JavaScript yielding must happen between actual Rust work grants. The real Engine NodeGraph caller, UI mock and graph session declarations require the same explicit format/control port and fresh registered Wasm binding generation. Wrapping the existing synchronous methods in a Promise does not satisfy this contract.

After coherent scene ingress and its complete owner run, Surface's remaining direct DAG/Infinite/Kernel integration belongs to a neutral graph/session provider interface with the actual OS implementation mounted at composition. Canvas extraction is owned by the parent and `/root/canvas_execution_1`; this lane will coordinate direct import patches without extracting Canvas itself.
