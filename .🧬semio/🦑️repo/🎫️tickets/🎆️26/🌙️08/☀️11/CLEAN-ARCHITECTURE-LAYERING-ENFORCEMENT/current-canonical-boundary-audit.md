## Concrete Findings and Ownership Cut

- Current normalization lines 1706–1720 caches an entire parsed object including pathMatcher by content digest across load calls. Re-reading the source snapshot survives, but equal bytes share the exact matcher, schema, discoverySchema, directoryKinds, fileKinds, and exclusions objects. Capacity is eight insertion-order entries, not access-order LRU; process lifetime is the owner. Readonly types do not freeze those reachable objects. This conflicts with the original independent session assertions at pattern-compiler-reuse lines 216–222: fresh matcher and discovery schema, two parses and validations. Preserve query/session matcher ownership when retaining immutable parsed-value caching; no mutable matcher should reside in the process cache.
- The same pattern-reuse AST harness at lines 183–213 still manually extracts loadTaxonomy plus constants. Its constant list must include PARSED_TAXONOMIES and PARSED_TAXONOMY_CAPACITY, but it presently does not; the closure executes an unresolved cache identifier. The function list also lacks requiredLiteral. The full canonical parse closure above is the actual replacement basis. These are observed source inconsistencies, not executed test failures.
- The source-admission IO stage-row harness at normalization/tests/source-admission-io lines 36–40 invokes sourceAdmissionGitRows with only execFileSync, sourceAdmissionGitRecords, sourceAdmissionSafePath, sourceAdmissionGitExclusions. Current implementation also needs canonicalJson, sourceAdmissionIndexObservation, sourceAdmissionIndexObservations. It cannot reach its malformed header assertion with its current lexical injection environment. For stage-format unit cases, inject canonicalJson, a receipt provider returning undefined, and a fresh Map; keep cache receipt laws separately in transaction-recovery-authority.
- The recovery-authority cache harness currently selects sourceAdmissionIndexObservation, sourceAdmissionGitRows, and sourceAdmissionIndexObservations together (lines 108–109), with the receipt filesystem/hash dependencies injected at lines 126–127. Moving cache ownership requires moving this provider AST to the concrete new owner; SourceAdmissionIndexRows is type-only and transpilation removes it.
- Current index receipt cache owns stage rows independently of untracked rows and physical observations. Receipt reads .git/index, config, HEAD, packed-refs, config.worktree, alternates and a direct symbolic reference; unsupported GIT environment, worktree pointer, split/shared indexes, included configs, alternates disable reuse. It checks before/after receipts and freezes stored row graphs. Carry sourceAdmissionIndexObservation and sourceAdmissionIndexObservations with sourceAdmissionGitRows; do not separate these lexical owners.
- The checker closure intentionally includes inventory/apply option type reachability; replace Pick<TaxonomyInventoryOptions, repoRoot|taxonomyPath> at the load owner with a small owned taxonomy load options interface. Source admission should likewise own its own minimal option and progress types rather than import TaxonomyApplyOptions indirectly through report. A host adapter supplies progress/cancellation.
- Pure admission has 23 top-level declarations and only posix imported, plus implicit Buffer built-in. It is independently removable from normalization. Keep sourceAdmissionRepositoryFences and sourceAdmissionContainingRepository in that owner and explicitly export them when IO consumes them. IO additionally needs sourceAdmissionAssertRepositoryPath, which is not in the pure projector closure.
- Parse has 59 declarations. The exact list above includes schema contracts and small lexical normalization/grapheme helpers; it does not need source admission IO, process execution, transaction logic, hashing, progress, inventory options, or cancellation. LoadedTaxonomy currently unnecessarily couples the pure parse result to optional input snapshot and filesystem path; split parsed taxonomy values from load receipt/session metadata. Export the actual parsed value type from this owner; avoid a forwarding facade.
