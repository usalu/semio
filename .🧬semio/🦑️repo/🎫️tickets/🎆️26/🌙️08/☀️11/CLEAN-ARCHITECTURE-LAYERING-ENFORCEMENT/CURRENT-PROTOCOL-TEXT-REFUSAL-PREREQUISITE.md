# Protocol Refusal Authority Prerequisite

Higher binary snapshot editor callers receive actual ProtocolError and currently erase it before TextError. Its owner is Framework Replication/🧾wire. Pack(PackError) can retain the canonical PackError cause; LimitExceeded(message) combines byte and count ceilings; Malformed combines overflow and physical grammar; Io(String) is a separate transport cause. A uniform InvalidValue conversion at higher editors would erase both controlled Pack authority and authored limit semantics.

The canonical typed Pack floor and producer-authored Protocol cause boundary are prerequisites. No source/protocol enum is changed by this audit, no defaults/classifier supplied, and no native proof claimed. 311 lexical candidate full source texts/hashes/inverses are retained in generated/value-refusal/protocol-text-refusal-frontier-full-before-1.json. Actual provider/syntax closure remains pending.

Actual closed error roster retains Pack, ChainMismatch, TornTail, UnknownCriticalRecord, DictMiss, DictOutOfOrder, VerifierRequired, SignatureInvalid, FrameFraming, LimitExceeded, Malformed, Io. Kind decisions for non-value transport causes must be authored at actual owner sites rather than inferred from display/code.
