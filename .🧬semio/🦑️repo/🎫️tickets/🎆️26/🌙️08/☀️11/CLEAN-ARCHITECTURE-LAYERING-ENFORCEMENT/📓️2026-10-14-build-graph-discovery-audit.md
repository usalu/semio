## Evidence and Bottlenecks

- Actor `🗑️generated/actor-public-canonical-gui-current5.log` ends in repeated `build:discover`; General `🗑️generated/gn/reserved-birth-repo-native-1.log` ends in repeated `build:projects`. These identify phases, not measured time attribution; interrupted runs prove no acceptance.
- `🏗️build/🕸️graph/🟦️.ts:58–79` inventories **every retained file and directory**, asynchronously in batches of 32. Membership subsequently stats every retained member (`160–167`); a successful cold attempt repeats the entire inventory and stat pass (`189–213`). This is broad work even for a source-only selected target. Current exclusions do remove tickets/generated/cache; deleting additional source trees to accelerate discovery changes membership and can force retry, so deletion must not become an optimization.
- `📥️inference/🟨️.mjs:1519–1610` builds all Cargo closures, command inputs, playground catalog and every project's full target/input assembly before selection. The project assembly loop is sequential; progress/cancellation yields occur only every 16 projects. Each project computation remains synchronous, so one expensive project can monopolize a deadline without an intervening cancellation check.
- `projectAssemblyAuthorityV1` (`1506–1509`) calls `nativeDependencyRoots` with fresh default maps **before** project cache admission, once for each native project. Earlier candidate enumeration shares maps, but this authority phase discards that sharing. On cache miss project assembly again creates fresh native preparation/dependency maps and fresh script/source maps (`1603–1605`). Sharing parser images does not share closure resolution or manifest ancestry probes across these phases.
- `relativeScriptInputs` (`477–505`) shares import resolutions only through its passed graph cache; project computation creates a fresh cache per project. `genericTargetCommandInputs` (`589–608`) revisits closure members for module analysis. `observedSourceAnalysisV1` still performs synchronous stat and byte read on every call (`👁️observation/🟨️.mjs:147–152`) even when its content image hits. Registered provider caches avoid repeated parsing, not repeated reads or resolver probes.
- Declared source contracts are a distinct uncached parser path: `declaredSourceInputs` (`935–943`) traverses every declared contract of every project; `🕸️dependencies/🟦️typescript/🟨️.mjs:28–53,80–100` reads and creates TypeScript ASTs for every reached module and every existing generated boundary. Its visited set is per contract and its runtime parser does not use the registered observed-analysis interface. Shared contract closures can therefore repeat source parsing globally. Existing generated data is read during graph inference even when its consuming target is not selected; deleting a boundary changes exists/read observations and project/graph admission, so generator cleanup and discovery are coupled.
- Graph dependency ownership uses `ordered.find` per file (`🟦️.ts:147–149`): O(files × projects), after project assembly. This cannot explain a log still at `build:projects`, but becomes the next cold-path bottleneck once assembly improves.
- Current graph receipts already validate membership and source observations (`194–196`, `208–211`). The explicit reuse branches (`182–188`) bypass those fresh validations; do not enable `SEMIO_BUILD_REUSE_GRAPH` as a fix.
