## Remaining public bypasses and ownership boundaries

1. **The operation is additive, not mandatory.** `🦀️.rs:655,658` publicly exports both raw source/grammar routes and the new operation. `JsonGrammarCursor::new` at 924 installs internally chosen unlimited bytes/allocation/items, and its public `step` at 955 accepts a new source and control each turn. `normal_step_demands` at 932 also accepts arbitrary source. This cannot enforce original source identity or cumulative normal/retirement wallets. `JsonSourceCursor::step` at borrowed source line 25 retains source but accepts replacement control and fresh grants. Public `into_grammar`/`from_grammar` at 18–20 permit extracting grammar and rebinding a different source without rerunning byte admission or installing limits. These are concrete accessible capabilities, not hypothetical private escape hatches.

2. **Public synchronous raw APIs still choose their own broad authority.** `parse` at 870–873 creates raw grammar, a `NativeDecodeControl` with `usize::MAX`, repeated per-turn grants with `isize::MAX` copy/capacity/release, and no retained cleanup operation. `parse_bytes` at 877–879 delegates to it. `from_json_str` at 1820–1822 uses this path then recursively converts through `to_dsl_value`. `Lexer::new`/`next_token` at 761/828 expose token production outside the operation. `from_json_str_controlled` at 1826–1833 is a distinct recursive `ControlledReader` path, with no `JsonReadPolicy`, caller semantic source limits, or separate retirement wallet. It has native control, which is materially better than `parse`, but does not establish the new operation contract.

3. **Actual output and error custody leaves the operation.** Operation `step` at 34–40 returns `Option<V>` and `JsonError`; successful grammar output is taken at `🦀️.rs:963,977`. Duplicate rejection moves the original key String into `JsonError::DuplicateMember` at 1041. `close_step` closes grammar custody only; it cannot close output/errors already returned to callers. `JsonError::into_value_error` at 94 converts non-native diagnostics by `error.to_string()`, allocating replacement diagnostic and ordinarily dropping the original duplicate-name backing. The public retirement implementation at 97–98 exists, but does not make caller custody mandatory. Thus claims that operation retirement covers every actual output/error would be incorrect.

4. **The wrapper does not seal source immutability.** `JsonReadSource` is publicly implementable at borrowed source 37–40, with arbitrary `byte_len`/`byte_at`; Copy retains a source handle but does not prove immutable octets for implementations using interior mutability. First-party str/slice/PagedList implementations at 42–53 are observable fixed views. The wrapper guarantees retained handle identity, not universally immutable byte content.

5. **Wrapper abandonment is assertion/leak enforcement.** Operation Drop at 58–59 asserts terminal emptiness unless already panicking and only releases ManuallyDrop fields when terminal-empty. It does not close abandoned partial grammar, output or diagnostics. This prevents silent normal Drop on the retained private grammar but should not be described as automatic controlled retirement or completion.
