Relative dependencies, dynamic imports, type imports and bare package aliases receive the same resolved verdict. Comments and misleading generated banners create no exemption.

## Explicit Scope and Follow-up

This gate parses TypeScript/JavaScript and their resolved JSON dependencies through dependency-cruiser. Zero forbidden dependencies applies to that framework source graph only. It does not enforce Cargo/Rust manifest direction, generic framework-module→OS product layering, or every root composition file. The portable graph contract is language-neutral, but its live resolver contribution is currently TypeScript/JavaScript.

The parent's fresh audit still finds Cargo framework→implementation manifest edges (including fixture-sweep, Flow dev dependencies and renderer-wgpu Puzzle dependencies) and generic-module→OS product edges. These remain visible follow-up work for the broader architecture goal. This increment does not accept or baseline them; it does not claim repo-wide Rust enforcement. Actual package role metadata remains authoritative for the framework-role OS kernel peer.
