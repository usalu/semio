# Editor neutral interface and law placement

[Actual caller frames and all 84 law slices](editor-interface-design-audit-inputs/current-callers-and-84-law-placement-1.json) retain hashes/inverses, linked to the prior complete model/build sources. Proposed placement is 48 neutral model laws and 36 OS consumer laws. This is design/source evidence, not executed extraction proof.

Current EditorHost mixes text/selection/token spans/annotations with camera/font/theme/GPU/scene transport. Neutral model should own UTF-8 byte offsets, directional anchor/caret, text positions/ranges, edits, semantic tokens and selectable spans, annotation lists, tab insertion and bounded retirement. Preserve original byte/character boundary rules and reverse-order multi-edit semantics; the schema must distinguish UTF-8 byte offsets from TextPosition's existing line/character coordinates rather than silently normalize them.

First-party schema records: ByteRange{start,end}, TextPosition{line,character}, TextRange{start,end}, TextEdit{range,newText}, SemanticToken{start,end,class}, SelectableSpan{start,end,kind}, Placeholder{offset,label}, Diagnostic{start,end,severity?,message}, and Selection{anchor,caret}. Use closed object schemas with exact existing field spellings and explicit array ownership. Neutral model settings contain tabSize; fontPx/lineHeight/showLineNumbers and gutter layout belong OS render settings. JSON codecs, if retained, use direct neutral Value/Pack JSON identities and first-party errors, never public serde_json::Error.

Concrete neutral signatures: `EditorModel::new()`, `text(&self)->&str`, `selection(&self)->Selection`, `set_text(&mut self,String)`, `set_selection_range(&mut self,usize,usize)`, `set_semantic_tokens(&mut self,Vec<SemanticToken>)`, `set_selectable_spans(&mut self,Vec<SelectableSpan>)`, `apply_text_edits(&mut self,&[TextEdit])->Result<(),EditorError>`, `insert_text(&mut self,&str)`, `backspace/delete_forward(&mut self)`, directional/line navigation with extend flag, `selection_text(&self)->String`, and a first-party page-grant retirement owner. Expensive admitted decode/edit/retirement work must consume existing first-party controls; do not hide OS callbacks in those parameters.

OS's actual EditorHost owns an EditorModel plus Viewport/Camera/theme/layout and translates screen picking into model offsets. OS build_scene returns OS Scene; OS browser EditorSession owns CanvasGpuSession/HtmlCanvasElement/wasm ABI. OS scene JSON/Pack decoding validates its transport and calls typed model setters. This is a real consuming implementation, not a neutral alias/facade exposing OS types. Model mutations must not scroll through canvas geometry: the OS consumer performs caret visibility after model mutation.

The retained roster assigns all direct scene/render/camera/wheel/screen/theme laws unchanged to OS, including the two mixed font/line/gutter settings tests. Pure tab-size minimum remains neutral. Neutral text/selection/annotation/position/retirement laws retain their assertions after only canonical model receiver and typed input rebinding; both original typing schedule laws stay neutral. Existing JSON codec assertions remain editor-owned neutral admission only when implemented against first-party schema records; renderer-specific options remain OS. No law disappears.

Actual callers: renderer TextEditor imports EditorWasmSession/createEditorSession from WasmSessionLoader; loader currently imports @semio-tech/framework-editor-rs and constructs EditorSession. That loader/package dependency must point to the actual OS session producer. Writer's wasm module currently wildcard-reexports framework_editor and aliases WriterHost=EditorHost; replace with direct actual OS consumer imports where Writer uses render/session, and neutral model imports where it only edits text. Do not preserve the wildcard under a new facade.

Neutral manifest loses OS-kernel/OS-infinite, browser target/GPU exports and public canvas wildcard; its whole model tests/build then need only retained neutral dependencies. OS package/script/project/GUI own all scene/render/session laws and browser build. Native deletion proof must run neutral package with OS absent; ordinary root membership/preparation is a separate known boundary. No compiler/native/source change occurred here.
