# Canonical Architecture Enforcement

The first canonicalization increment establishes enforceable dependency direction, shared artifact interfaces, mutation authority and explicit resource ownership. It removes old forwarding APIs and count baselines. Every architecture contract is contributed by its owning Nx project; the root verification gate discovers contributions, and the generated debugger launcher exposes the same owners. Canonical targets always run uncached. Native deliverables and compiler units share one dedicated canonical Cargo root, with portable regression coverage for caller overrides.

## Implemented Boundaries

- Framework JS/TS imports and exports resolve through physical and semantic taxonomy, including aliases, subpaths, type-only and dynamic references. Cargo direction covers normal, development, build, optional, platform and workspace-alias declarations. Missing roles are errors. Concrete branding, composition, fixture fleets and native geometry belong to their S or Hub owners.
- Artifact IO fidelity, entry descriptors and route schemas have one renderer-independent definition across JSON, TypeScript, Rust, GraphQL and Protocol Buffers. Sequence snapshot packing belongs to its artifact IO owner. Materialized lane-backed text is read through the canonical lane reader. Generation3d IO accepts explicit prepared geometry, exposes true declared graph text separately, and is checked by a parsed Rust authority guard. Computed media export receives the actual instance operation owner through the shared editor/viewer and VCS path.
- Artifact snapshots are immutable at the command boundary. Durable changes are inverse-bearing mutations; command tests exercise publication, rejected authority, cancellation and immutable contexts. Shared directory access policy and plugin deployment schemas belong to generic OS owners and are consumed directly by Hub and renderers.
- Flow accepts session-owned geometry and registry capabilities. Actual BREP kernels, handles, imports, retained tessellation and geometry families are owned by each S Session. Session, captured operator readers, registries and extension bundles have explicit bounded retirement, zero-grant preservation, pause/resume and terminal checks. Implicit live destruction is refused without dropping shielded payloads. Rejected extension installation preserves the caller’s exact candidate until explicit disposal.
- Neutral retained bevel and decimation jobs perform real bounded geometry work. Renderer media geometry uses the canonical numeric wire representation and source-owned schema; translation and editor consumers use current explicit contracts. Plugin build source freshness owns both active metadata sidecars and retains strict unexpected-file refusal.
