# General And OS Pack Complete Codec Consolidation Audit

The complete document codec can be consolidated into General at the defining value owner; this is a source-contract conclusion, not runtime equivalence credit. Both value modules import the same General RecordSpec, RecordValue, FieldValue, Shape, wire graph, and General Value types. OS changes the container primitive import to crate::os_pack; General imports its local container and PackRefusal owner. The OS facade wildcard-exports its value module and its explicit document/body functions dispatch to crate::value, which currently resolves the OS implementation.

Independently compared complete top-level public functions are identical after normalizing only the OS container crate path: schema_hash; encode_document; decode_document; decode_document_controlled; encode_record_body; decode_record_body; decode_record_body_exact; decode_record_body_exact_controlled; decode_value_record_body_exact; decode_value_record_body_exact_controlled. The three controlled encoding entry points have identical complete one-line delegates, but each currently selects its own local controlled_encoding module. General additionally exposes output/projection/borrowed-preflight and retained ingress APIs, so replacing General with the OS implementation would discard capabilities. The generated comparison records the precise limited comparison scope.

Consolidation must retain complete document framing: symbols, configured literal document frames, chunk segments, manifest/schema hash, footer, verification and schema-drift reporting, unknown field/segment treatment, controlled cancellation/materialization and allocation checks. Container-less record-body functions remain separate APIs. Equal entry-point bodies do not prove local encode implementations, every private wire helper, module exports, or error aliases equivalent; those full dependencies need comparison and closed runtime controls before deleting the OS owner. Redirect the facade/import resolution to the complete General document owner only after those joins, rather than substituting the operation/body codec.
