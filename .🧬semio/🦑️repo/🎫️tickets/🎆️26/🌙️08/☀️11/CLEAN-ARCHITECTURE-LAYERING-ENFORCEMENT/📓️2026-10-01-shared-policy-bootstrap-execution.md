## Canonical ownership

- Pure construction: Repo library `🕸️dependencies/🧭️direction/🏗️construction/{🟨️.cjs,🟦️.ts}`. The implementation receives taxonomy, present plugins, authored workspace packages and system builtin names; it performs no filesystem reads.
- Authority capture: `🕸️dependencies/🧭️direction/🚀️bootstrap/{🟨️.cjs,🟦️.ts}`. `loadDependencyDirectionPolicy(root, {signal?, onProgress?})` returns immutable `DependencyPolicySnapshot`: root, canonical relative taxonomy locator, parsed taxonomy, present package/role/export census, plugins, complete policy and typed source receipts.
- Receipts are closed file/directory/missing variants. Files retain SHA-256 and exact byte count; directories retain byte-ordered entry kind/name membership and digest; missing paths retain explicit absence evidence. Required JSON authorities refuse absence, links, malformed JSON and unstable/invalid UTF-8 input. Optional deleted owners contribute absence rather than a fabricated package.
- The existing Bun membership and explicit payload algorithms now have colocated Node-compatible canonical CJS implementations. Their typed TS bindings preserve public contracts and real `../framework/**` installation scopes. No duplicate membership implementation or Node-to-TS implicit execution is used.
- Dependency-cruiser CJS calls the same loader. Repo TS verification now takes policy, taxonomy and package membership from one snapshot. Each direct loader invocation creates new authority maps; no global require cache mutation or foreign configuration evaluation is used. A Node configuration object already imported in a process remains a normal cached object; gates use the explicit fresh loader API.

## Source authority

Raw roots reject dot/parent/NUL/drive-relative prefixes before normalization. Every root ancestor is checked from the filesystem root. Root nx/project markers are required real files. Root project `metadata.semio.taxonomy` selects the canonical slash locator; each ancestry component and leaf must be real and no-follow. Generic admission does not invent a hardcoded compose name ban. The actual taxonomy continues to define graph exclusions and rule owners.

Each capture traverses the current Bun declaration scopes and concrete export ownership. First-invocation directory proofs may be reused only inside that capture; fresh invocations and separate roots share no authority cache. Manifest reads recheck ancestry, use native no-follow file-open flags where available, and compare opened/post-read physical file identity. Progress and cancellation are owned interfaces. Source and plugin receipt ordering uses UTF-8 byte comparison.
