# General Entrypoint Ownership

The permanent source laws use one language-agnostic deletion-rule fixture and compare actual Cargo dependency channels through both Bun.TOML and independent Iarna. They require every umbrella dependency channel and exported registry/macro surface to be General-owned. Runtime caller/compile acceptance must be qualified separately; literal source laws do not resolve aliases or the full dependency graph. The source runner uses the existing bounded first-party process capture with cancellation and finite selected body custody.
