## Remaining Flow Snapshot Factory Seam

The exact unresolved production constraint is Product Store's implicit representation bound. `🏪️store/🚪️io/🦀️.rs` defines `ArtifactStoreSnapshot: ArtifactPack`; the actual Store and constructor paths require `P: ArtifactPack + ArtifactStoreSnapshot` (Store source around its 653/676 constructor bounds). Flow's concrete `FlowHostSnapshot` receives ArtifactDsl, ArtifactPack, ArtifactStoreSnapshot and ArtifactSqliteSnapshotHost implementations under the child IO producer. Its MemberStoreOwner implementation selects `PackMemberSnapshotOpen<Self>` and supplies the original typed retained/authoring factories. Moving that snapshot type alone into a Flow contract package would create illegal foreign-trait/foreign-type child implementations. The existing DocumentStoreOwners constructor accepts explicit retained factories, but does not remove the Store's implicit representation bounds.

A correct next source phase needs either explicit producer-owned store/codec/member-open capabilities over the Flow domain snapshot, or a first-party snapshot interface preserving the exact actual child owner and retained intake factory. It must carry actual command/reset/snapshot/history/retirement operations and exact original source custody; an uncredited copied projection, global codec fallback, Any-erased compatibility handle, relocated child codecs or duplicate store is not acceptance. This phase has not been implemented or qualified here.

No generated output files were authored by this subtask, and no shared ticket generated directory was removed because other owners may still hold it. The ticket and overall goal remain open.
