# Registry Rebuild Ownership

The neutral registry currently composes concrete S staging, S stdio preflight and Hub catalog publication. Its executor also imports development activation code to verify staging. The change will keep a schema-validated generic plan and runner in registry, author S guest stages and preflight in S, author catalog stages in Hub, and compose those explicit contributions in S. Staging convergence belongs to the general development owner.

Portable JSON cases cover deletion of every specific owner and each owner separately. Vitest compares composition output against a schema-driven reference ordering, with Ajv independently admitting every plan and malformed input vectors. The scoped Nx target is `@semio-tech/plugin-registry:test-rebuild-contract`; tests are authored before implementation.

Concrete generated catalog relocation requires a separate inventory: the existing registry projector emits TypeScript consumers whose relative imports and receipt-bound data are imported throughout framework development and renderer modules. Moving bytes alone would retain upward producer and consumer dependencies. This scope will record exact producer and consumer authority instead of presenting an asset move as ownership correction.
