General Value dependencies: String Bytes cursor has exact root birth, no-child zero birth, copy work minimum one, whole backing capacity release, and cursor terminal release. Vec<T> Collection has exact root birth and support gated on T; its per-element child births and final original-capacity release are explicit. Option<T> delegates Some birth/support and None empty Sequence birth; tuples of two/three use deferred children with exact birth and gated support. Box<T> has root BoxedOwner birth and whole sizeof T release, then T child birth, but controlled_retirement_supported currently returns true unconditionally: fix it to require truthful T authority.

The current generic std Vec IntoIter VectorIterator cursor has no retirement_birth_bytes/support, next_birth_bytes, or terminal_release_bytes; its terminal witness is only remaining len zero while backing allocation remains held in the iterator. Do not authorize this path merely by setting a support flag. The current RecordFields storage is explicitly std Vec; a Generic ValueVec declaration was not found by the targeted current declaration scan, so no invented ValueVec authority is used here.

DslValue ValueRetirement eagerly constructs its Box root, then dispatches one variant child. It currently lacks root birth/support, child birth and terminal-release authority; recursive arrays/objects and tuple member ownership must all close truthfully. This is mandatory for FieldValue Value and Wire properties before the Record family can claim complete controlled support.

Active erased port ErasedCursor currently forwards close and empty only. ## Recursive Permission Constraint

A blanket Box<T> support gate delegating T support cannot be combined with tagged-family support recursively querying Box of itself: FieldValue, Shape and ExprValue form recursive type cycles, so that function chain would recurse forever. The capability must use a finite audited recursive-family certification or structural marker, with every actual child constructor birth checked at step time. The earlier Box gate recommendation therefore requires this finite certification design; it is not a literal recursive boolean implementation. Current unconditional Box support likewise does not prove downstream births.
