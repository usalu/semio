## Smallest Concrete Extraction

Keep kernel operations; replace registry singleton/default import with an explicitly supplied OS composition contract. Author JSON schema first for the serializable catalog rows (plugin/extension role, dependency, contribution/consumption, activation, host, variant/app/aliases and resolved module addresses), including unique identities, finite row/string/edge limits and empty inventory. Define a first-party adapter from admitted rows to `PluginCatalog`; functions are runtime interfaces, not worker wire JSON. The existing plugin-module schema is authority for module identity/URL admission, but cannot represent all current catalog semantics by itself.

Require composition at outer application bootstrap: S/Hub-specific assembly owns generated inventory and injects it into dev boot and React boot options. ShellHost reads the supplied catalog throughout. WGPU browser transport receives serializable admitted rows and worker constructs its local catalog; bridge scoped consumption receives the same admitted catalog or explicit consumed topics. Remove the default generated argument on `isHostPlaygroundFilter` as well. General standalone assembly deliberately supplies empty inventory; Specific standalone assembly supplies only installed modules. Do not create a mutable module-global setter or compatibility fallback: multiple concurrent mounts must retain independent inventory.

Add finite bytes/rows/edges/work/deadline plus abort/progress at admission and descriptor-fetch turns. Do not increase worker capacity from global Specific counts: derive it from admitted rows under schema maximum. Empty inventory must mount an idle shell/renderer with no actor, no module fetch, no fabricated primary app or artifact owner. Current `assertWgpuPluginPlan` rejects zero plugins: distinguish deliberate unfiltered empty boot from an explicitly requested missing variant (the latter remains refusal), and preserve existing selected-module failure behavior.

Deletion proof should copy authored General/product sources and only necessary root manifests into ticket generated storage, exclude ignored node_modules/dist/compiled module outputs/caches, physically omit S/Hub/root Cargo, and import actual copied registry admission, React configuration path and worker planner/bridge receivers.
