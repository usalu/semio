# Graph Preview Identity Contract

The generic graph preview currently defaults to `graph-catalog`; Flow supplies `flow-graph-catalog` through an executable subclass. This leaves producer identity outside the closed schema owned by each catalog. The canonical interface requires an explicit catalog `contractId`, validates it, and uses the admitted identity for preview output. Each composition owns its identity in data; the general producer contains no specific branch, implicit identity, or compatibility subclass.

The existing generator targets remain authoritative. Tests will extend the current language-neutral graph fixtures and independently execute two owner profiles through a Node bundle with products, Hub, and S refused by the loader. Ajv validates the same catalog and output expectations. Existing corpus fields and tests remain, with full original texts retained in `graph-preview-identity-inputs/before.json`.

No native source or Cargo input is changed in this scope. The upstream Flow preview target and taxonomy correction were supplied by another developer before this cut and are retained.
