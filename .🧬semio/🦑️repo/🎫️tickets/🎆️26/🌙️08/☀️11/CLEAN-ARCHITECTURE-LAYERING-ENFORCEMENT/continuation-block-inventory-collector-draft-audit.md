# Block Inventory Collector Draft Audit

This is a read-only source review of five retained draft bodies. No Rust compilation or runtime test is claimed. The encoder uses only std in its implementation, borrowed descriptor projections, explicit work/output budgets, checked unit increments, per-emitted-byte cancellation callbacks, full JSON escaping and fixed five-outcome vocabulary. The eight portable cases and Serde comparisons are authored evidence, pending actual execution.

The following gaps should be resolved before source admission:

- Allocation precedes the first observation. encode_mutation_inventory reserves the entire maximum_owned_bytes before checkpoint; an already-cancelled caller can therefore allocate its whole allowance before refusing. Offer a zero-owned checkpoint before allocation, and account the requested allocation before granting it. Incremental bounded growth also avoids reserving a huge allowance for tiny output. Retained capacity is measured afterwards, which is useful but does not repair pre-allocation cancellation.
- Trait calls are not controlled operations. len, leaf and outcome receive no control state and may allocate, scan or block arbitrarily. A unit charged before a call bounds call count, not work performed by an adversarial implementation. The API must require controlled source methods or explicitly narrow its guarantee to independently witnessed constant-work borrowed production projections. The current wording should not claim bounded arbitrary trait-source work.
- Duplicate detection rereads prior descriptors. An interior-mutable source can return a different length/id/owner between the original emission and a later prior_source read, defeating first-observed-ID uniqueness or suppressing an unrelated row. Retain actual observed eligible identities in a controlled caller-owned workspace, or bind an immutable source contract with adversarial mutation/refusal laws. Current nested rescans are quadratic but at least charged; their source-method internals remain unbounded.
- Outcome uniqueness similarly rereads earlier source.outcome calls. Compare against the already observed outcomes in a fixed stack array of at most five enums. This avoids false refusal or accepted duplicate wire outcomes when a source changes answers.
- Several input scans run after precharging the whole length. identifier, strip_prefix, split/segment comparisons and coordinate path checks have no checkpoints during their actual byte traversal. A prior callback pass does not allow cancellation during the subsequent full scan. Fuse accounting/checkpoints into the actual scan, or bound each scan quantum explicitly. Empty-segment traversal is especially undercharged when there are no excluded segments.
- Only coordinate.owner is checked for empty/dot/dot-dot/backslash segments. Eligible leaf owners may contain traversal-like or empty segments after the coordinate prefix. If these are canonical repository owner paths, validate leaf owner shape before accepting scope; otherwise document that this is lexical-prefix ownership rather than physical ownership. Repeated excluded segments are accepted despite the portable corpus schema requiring uniqueItems.
- Duplicate leaves are skipped before their id/outcome-count validation, and excluded leaves are skipped without descriptor validation. State this first-wins/ignored-input policy explicitly in a closed corpus, including malformed duplicate and excluded rows, rather than implying all supplied descriptors are validated.

The native draft tests cover eight happy-path wires, one work refusal, one small output limit, cancellation at call ten, malformed coordinates/outcomes and command policy withdrawal. They do not yet cover cancellation before reserve or every frontier, unstable/adversarial trait answers, giant coordinate/id/owner scans, malformed duplicate rows, or cumulative source-call accounting. Add closed language-neutral cases with independent wire/refusal oracles and native implementations for these cuts.

The captured default library also declares an unconditional command module and optional replication module whose bodies were not present in this inspected input directory. Full staged source assembly must bind those actual endpoint bodies before a compilation claim. No missing module was invented or source edited.
