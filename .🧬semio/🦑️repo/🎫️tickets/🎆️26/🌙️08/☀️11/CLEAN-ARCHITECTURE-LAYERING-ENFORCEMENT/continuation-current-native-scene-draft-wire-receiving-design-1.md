# Scene Draft Wire Receiving Design

UI11 retained the real compiler refusal and full peer bodies. The four original draftJson vectors are the defining semantic corpus.

The canonical Scene boundary writes a borrowed slice through PackJSON JsonWriteSource and write_json_source_into. It receives NativeEncodeControl, byte/item/depth ceilings and the caller sink. Source integers are checked into UInt; keys remain offset, delete, insert. It constructs neither a JSON AST nor an intermediate string, and every refusal preserves the caller's exact accepted prefix.

EngineCanvas currently parses and serializes a String on each edit and history move, substituting empty changes on parse failure. That receiving representation must become the actual typed DraftChange vector. Serialization belongs to publication, where the caller provides cumulative ownership admission and progress/cancellation authority. Original explicit-draft edit/history/application behavior stays admitted. No demand-derived grant, runtime serde_json dependency, empty-string fallback or compatibility alias is admissible.

Current UI12 and Flow8/9 remain unconsumed; Scene7/8/9 require fresh Root registration before actual invocation. No Native process is live at this design cut.
