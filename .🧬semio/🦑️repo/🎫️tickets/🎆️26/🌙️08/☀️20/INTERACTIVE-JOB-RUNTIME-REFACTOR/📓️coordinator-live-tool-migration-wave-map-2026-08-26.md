## Universal packet gates

Every packet must leave on disk:

- truthful request/event/page/control schemas with English and German accessible progress labels and no declared default language;
- empty, single, maximum, maximum-plus-one, stale, wrong, duplicate, ABA, cancellation-at-transfer, fault, retry, close-interruption, and deterministic replay ledgers;
- an owned semantic result compared through an owned boundary with a test-only third-party oracle;
- fixed item, byte, page, event, control, child, output, and retained-owner capacities admitted before copy or allocation;
- one semantic unit per worker grant with fuel, deadline, cancellation, generation, revision, and publication checks;
- production factory registration and one explicitly admitted worker-session dispatch from the real app entry;
- lossless terminal ACK, exact handback, handle-loss recovery, and terminal-empty closure;
- proof that the old direct/whole reducer path is unreachable.

After each wave the coordinator regenerates the JSON ledger. Acceptance requires the cohort's exact rows to move from `remainingCommands` to `boundedRows`, no unrelated proof identity to disappear, and the hostile-mutation self-tests to remain green.
