# Opaque Copy Observation and Semantic Reader Decision R205

## Decision

Do not add a second opaque-transfer consumer. Source inspection does not identify a production destination for such a second copy. The existing OwnedUiOperationPayloadBuilder already performs the required opaque transfer from the original Kernel field fragment into independently retained, charged UI pages. The additional transfer consumer suggested in R204 is withdrawn as the preferred design; R204 and its frozen four declarations remain byte-preserved.

Keep opaque transport-copy tests separate from scalar semantic admission. Their existing exact byte goldens, source/page/receipt identities, cancellation/fault laws and no-InputAck assertions remain required. Do not reinterpret their generated bytes as f64 or any other scalar profile, add a raw scalar mode, mint a test-only consumer, or retain an optional unowned UI reader API.

The current scalar-only mandatory-reader proposal is not yet a globally complete semantic-consumer contract. A full operation-field grammar reader is required for variable symbols/containers and typed fields. The existing RetainedUiWireValueCursor/RetainedUiTypedCursor identify that real production role; they currently consume whole transferred buffers and do not yet consume the paged reader. Scalar primitives belong inside that semantic path. This report neither mounts the full parser nor silently reprices or rewrites the frozen scalar declaration.

## No-Fake-Consumer Transport Test Architecture

The original source producer, payload, builder, destination pages and copied proof remain real. Test instrumentation only observes exact objects/returns from original methods; it never returns synthetic success, installs a substitute object, exposes a new getter, or supplies a semantic consumer.

1. Call through the genuine field/payload/builder admission. Observe the actual UI page installation at OwnedUiOperationPayloadBuilder.installPage and the actual intrinsic page result at OwnedResidentOwner.reservePage. Both shells are already strongly registered by their real parents before the observed return. Match the current UI page and original intrinsic page through the nested real allocation/write call, not equal lengths or a fabricated field identity.
2. Observe each real source-read and destination-write turn. The builder source read at pages:193 and destination write at190 are separate existing grants. Capture a successful original neutral writeByte result; do not count attempted writes or an after-write throw as builder-accepted progress.
3. Preserve the exact Buffer golden. For direct storage confirmation, use the existing neutral owner.beginRead on the genuine sealed destination page and a genuine admission cell on that same injected ledger. The neutral owner strongly registers the actual read lease before return. This is the existing intrinsic storage API, not a new positive UI consumer, scalar receipt or private-proof mint. The test owns and closes that real cell/lease using the existing alias admission/retirement contract. No second page or payload copy is required.
4. Read back one bounded destination window through that real neutral read lease, compare the actual stored octets with the unchanged expected payload slice, and close the lease/cell completely. The test must also compare observed writes with that readback so a wrong write destination, ignored write, wrong stored value or skipped byte fails.
5. Drive the original payload.closePage(exactPage, grant) with its existing page/builder close phases. At resident:633–652 the original page slot and private witness detach its actual builder binding and retire its real storage. This operation does not close the payload. A still-live intrinsic lease blocks backing retirement at neutral page:332, so it cannot be bypassed by a test observation. Once the original page and slot are terminal, the real producer can admit its next window.
6. Complete the existing copied-evidence/source-consumption handshake from that original fragment. Preserve exact field.consumed, field.complete, fragment detachment, original raw page/envelope, unchanged worker post count, and absent InputAck. Destination page retirement is not semantic parse success or native page acknowledgement.

For the257-byte law, compare both256+1 destination windows against the original opaque payload. For the8193-byte/first-source-page law, preserve the exact original fragment boundary. Compare every actually written destination octet with the corresponding unchanged source slice; preserve the existing full-window golden separately from the partial/unsealed tail. Do not fabricate a next source range, EOF, seal or copied completion. A partial tail may be observed as actual writes but does not authorize a sealed neutral read lease. Cancellation closes its real original page without pretending it was a complete readable window.

This is a source-grounded future test architecture, not an executed rewrite. Existing public neutral page/read admissions and exact payload.closePage already supply the required ownership. A future fixture change must derive all costs from those existing declarations and explicitly account its real lease; no new grant, capacity increase, hidden test allowance or price is proposed here. The current tests and all byte goldens remain unchanged.

## Cursor and Fault Laws Are Not Replaced by Write Observations

Write/receipt observation alone cannot prove read-cursor correctness. Split the existing law into the following exact assertions rather than deleting it or claiming a producer test covers a reader:

| Current law family | Retained transport assertion | Required semantic-reader assertion |
| --- | --- | --- |
| Opaque byte preservation/two windows | Actual destination readback and unchanged Buffer golden using real neutral leases | Canonical grammar-valid field produces the expected typed value; no opaque acceptance claim |
| Before/after intrinsic byteAt throw | Same original neutral lease/read index, unchanged data, real first fault/cell ownership | Actual original consumer receipt, source cursor, serial and latch remain unchanged or permanently faulted; no byte skip/retry |
| After cursor commit/receipt wrapper throw | Not a transport write law | Genuine privately minted consumer/receipt retains the exact committed result for observation, or quarantines with the original root |
| Alias close before/after work | Exact neutral lease/cell close and backing blocked until actual final alias retirement | Original parser/reader binding, private terminal observation and parent ownership remain; child work/refunds are forwarded exactly |

The proposed43 scalar vectors can exercise primitive cursor/receipt fault laws under their own declared profile/provenance. They cannot substitute for the opaque8193-byte field or prove an entire operation grammar. Existing scalar fields of up to10 bytes also cannot alone execute the existing257-byte UI reader window transition. That full UI reader window law must remain pending for a genuine schema-valid full-field parser with the original source ownership. It is not discharged by lower-layer readback, nor by treating arbitrary bytes as a sequence of unrelated f64s.

The old raw-value73 read-fault golden may remain a neutral storage test. A semantic cursor test should use a genuinely declared scalar vector/context and preserve its expected scalar result, not claim the opaque component field is a natural merely because73 has a valid encoding. No fake consumer is needed in either layer.

## Consequence for Global Cutover

Retain the113-site inventory and map each site to its original law before any edit. Transport-specific sites move to observed real page writes/readback/receipts. Real semantic cursor, alias, fault and cross-window sites require the genuine grammar owner. The latter role is already required by RetainedUiWireValueCursor/RetainedUiTypedCursor; it is not an additional opaque-copy consumer.

Do not mount a scalar-only global replacement and keep an old overload for the remaining tests. First complete and review the actual grammar-owned reader/receipt contract and exact field/frame/symbol/variable-owner census. Then handcraft the caller/test cutover in one coherent source boundary, with the existing opaque goldens and separately executed semantic laws. The frozen scalar arithmetic and closed transaction declarations remain useful scoped design evidence, but are not a certificate for that larger ownership join.
