## Exact Ownership Design

Keep the typed node in its already-owned arena slot while closing it. A private fixed-depth field cursor visits one text/value/list leaf per grant. It does not allocate a generic traversal stack, clone a node, serialize it, scan a whole list, or move a large enum into a fresh queue. Struct fields and all 18 Component / 11 UiPatchOp variants are exhaustive typed matches. List elements retire in place, then a separate step removes the empty element; a final step releases the empty backing allocation. Small numeric metadata is separate from semantic string/byte accounting.

Nested UiValue leaves move into the existing exact UiValueRetirement cursor. The enclosing slot retains this cursor until all last-alias descendants finish. Shared aliases release only their own reference. The slot cannot publish terminal while a leaf cursor or initialized typed field remains. Arena access in the normal close path uses try_lock and reports blocked without moving an owner. An exact slot/epoch claim prevents global maintenance from consuming a locally claimed document; exception handoff retains the same slot instead of silently forgetting its payload.

The private traversal depth is a bound on the nonrecursive typed schema, not a cap on user JSON nesting: UiValue uses its existing arena-linked descendant cursor. Each typed field declaration carries its exact Rust type and destructures the whole struct exhaustively; the associated depth is derived from those field types. Option, fixed list and pair add their own frame; every Component/Layout/Patch variant contributes to the maximum. Compile-time assertions reject roots exceeding the 16-frame envelope. Current snapshot and patch depth is eight. Copy-only scalar implementations statically reject a future heap-owning field. Future typed schema additions cannot fall through to ordinary Drop.

Drop records only its already-admitted ownership obligation, without taking the arena mutex, allocating a queue node, or draining payload. The arena's normal bounded closer consumes one handback obligation instead of a payload unit on that turn. A slot cannot be reused while unreleased aliases or a claimed final root remain, so queued old ownership cannot target a new epoch. Exact initial value closure drains pending releases for that same handle before deciding whether it is the final alias; nested final-alias descent does likewise. The strict live-Drop guard still panics after recording the recoverable ownership obligation. No exception waives the guard.

The ready projection uses a fixed atomic bitset (four words for 256 value slots, one word for eight document slots), not a global pending-count sum or a full slot scan. Producers first record the per-slot obligation, then set its bit. The arena consumes one obligation under its existing exclusive guard, clearing the ready bit before decrementing and restoring it if another obligation remains. A racing producer may leave a harmless empty ready bit, but cannot lose an obligation. A round-robin starting slot avoids a frequently returned slot monopolizing handback work. Neither producer loops on compare-and-swap nor waits on a lock. If an arena invariant rejects a consumed obligation, it must put that exact obligation back before returning the error.
