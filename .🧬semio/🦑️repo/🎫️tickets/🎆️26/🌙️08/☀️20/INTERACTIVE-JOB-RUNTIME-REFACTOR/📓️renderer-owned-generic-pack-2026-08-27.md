## Retained Grammar and Document

`OwnedUiGenericPackCursor` validates the original binary pages one byte at a time. It stores UTF-8 strings as source spans, uses a fixed eight-byte f64 scratch, retains a numeric-indexed symbol table, and writes immutable flat token records into a separate numeric index. Explicit map/list frames preserve the original key order and duplicate pairs. Synthetic record-field tokens preserve unknown and repeated value fields; a later field-1 projection can implement the existing null/last-field semantics without discarding input records.

Each index update uses the existing persistent dual-AVL edit cursor and explicitly retires the previous root and edit. The code never clones a complete index, retains an overlay chain, converts an entire text field, or builds a nested JS compatibility object. Only full successful parsing can mint `OwnedUiGenericPackDocument`. Issued readers capture the exact token/page root and remain valid after document close; a separately captured source owner also remains independently valid.

Cancellation first releases the suspended fixed-depth program references, then one explicit container frame per step, active index/reader retirement, token/symbol roots, and original pages. Tokens contain only fixed metadata, static kind strings, numbers and spans. Their final release charges 96 bytes in addition to the underlying numeric retirement step. Actual over-grant yields are reported with their real byte count and rejected, not reduced to a small error count.

## Domain and Accounting

There is no inherited 512-byte UI scalar or 256-item collection limit. Counts and text spans must fit the exact admitted binary source. The neutral suite separately exercises an 8-KiB Unicode key, 16-KiB Unicode string, 1,024 booleans and 4,096 nested arrays. Generic f64 bit patterns, including negative zero, infinities and NaN, are preserved as codec data; host geometry validation remains separate.

The synthetic scene-field parser accepts DSL `VALUE` record fields; other native `FieldValue` tag dialects are not silently treated as JSON. It rejects trailing bytes rather than ignoring them. Counts/field ordinals must be exact safe integers; there is no rounded conversion. These are explicit parser admission boundaries, not a claim that the entire native general-purpose record decoder has been reproduced.

For the executed deep test, `B` bounds bytes and therefore symbols, scalar records, map keys and container starts. At most `3B + 4` indexable events are budgeted. The test reuses the numeric-index transition bound with height `2 ceil(log2(B+1))`, nine reference slots across three allocation nodes, and the existing allocation/reference/retirement phases. Every advance asserts monotonic input position, no more than one consumed byte, one item, and at most 4,096 reported bytes. This is a finite work bound, not an 8-ms VM/runtime certificate.
