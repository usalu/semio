## Writer Implementation

It preserves actual Vec capacity on unexpected allocator overgrant and reports that retained delta with AllocationFault. Validation consumes one source byte into fixed UTF-8 state and one pending scalar; a separate copy phase initializes exactly one destination byte. One-byte grants can progress through multibyte scalars. The private primitive accepts a scalar byte; the eventual public facade must select it exclusively from its installed original source. This primitive alone does not enforce source identity.

A separate seal preflights four descriptor-sized transfer debits, then converts already incrementally validated Vec bytes to String without a final whole validation scan. The debit is a declared bounded header-transfer allowance, not an empirical compiler memory-access count. Pointer and actual capacity must remain unchanged. The unsafe conversion is private and reachable only after all declared bytes were copied, no pending byte remains, UTF-8 state is complete and no sticky fault exists.

A subsequent step preflights full actual capacity release plus fixed descriptor work, clears logical payload then releases only empty allocations. Partial validated-but-not-copied scalar is included in inspection. No general parent Drop/unwind/funding claim is made; actual partial-copy panic tests retain both source and buffer outside the callback.
