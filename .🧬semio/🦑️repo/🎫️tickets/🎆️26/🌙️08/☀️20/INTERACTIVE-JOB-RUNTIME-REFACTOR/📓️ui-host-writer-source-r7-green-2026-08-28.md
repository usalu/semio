## Native Representation Constraint

The one-byte frontier splits both the2-byte and4-byte Unicode scalars. A public String-only append that refuses whenever a complete scalar exceeds the grant would never make progress under a1-byte grant. The private candidate therefore needs retained partial UTF-8 construction state before it becomes a DispatchEvent String, or an existing equivalent bytewise owned decoder. Neither whole String::from_utf8 validation at finalization nor uncharged whole-source memcpy is acceptable as a hidden tail. Exact physical Vec/String backing remains owned across that transition, and the final descriptor move is a separate admitted step.

Existing pack::RetainedUtf8Cursor is private decoder state; math sampling UTF-8 helpers are async whole-slice classification. These names alone do not provide a callable retained writer. The native implementation must either factor the actual small reusable state with owner coordination or implement the bounded writer state in its domain; no imported helper has been claimed as proof.
