# Canonical Output Pool — Concrete Retained Seam

The implementation will keep exactly 64 shared payload entries, each holding at most one `SurfaceReconcileReadyPatch`. A queue owns only bounded entry keys, not 64 copies of ReadyPatch. There is no per-queue payload pool and no additional payload byte quota.

An affine `SurfaceReconcileOutputReservation` is acquired before a surface presenter is invoked. Its slot/epoch stays in the transaction's structural owner through source production, cursor work and candidate seal. Insertion takes `&mut Option<SurfaceReconcileReadyPatch>` and refuses before detachment if the exact slot, physical grant or target is unavailable. Collection insertion transfers the affine reservation; FIFO handoff transfers one ReadyPatch into an already-admitted target and only then releases its empty pool entry. Failed handoff keeps the original entry/source. Normal close performs one typed ReadyPatch step, then releases the empty slot separately. Reservation/queue Drop records fixed atomic handback; reuse is impossible until the occupied exact epoch is terminal and its marker drained.

The pool's fixed backing is charged once to the existing resident ledger alongside document/value arena metadata, not reserved as a second dynamic owner. Queue-key storage is part of the actual enclosing transaction/output header footprint. A once-only metadata registration must refuse inconsistent size/domain or aggregate exhaustion before producer work; dynamic root1/output2 permits keep their existing 64-slot and 8MiB/32MiB limits.

The current cfg(test)-only transaction oracle still has raw `Transacted.patches: Vec<UiPatch>` and synchronous clear paths. Runtime glue excludes that module and its exports from production; the read-only git diff there is empty, and this report attributes neither an author nor timing to that boundary. Oracle migration remains separate debt, not the live product seam. The production PatchTracker is the priority for pre-producer/output-pool admission. Existing Ready/Published/ACK ownership remains its downstream output authority, and its handback reservation must be admitted before producer work too—not acquired after seal. The existing handback allocator's blocking mutex is an additional exact preadmission issue to fix in this join, not a reason to bypass the reservation.

The current five canonical tests and 158 UI tests do not certify this unimplemented pool. Schema-first pool tests and actual transaction constructor/saturation tests are next. The original inline census failure remains the decisive independent resident-accounting gate.
# R63 Implemented Primitive and Remaining Resident Join

The pool now exists and its exact two laws pass. `SurfaceReconcileOutputs::static_backing_bytes()` derives the actual `Mutex<Registry>` plus both fixed atomic return arrays; no caller-supplied logical capacity substitutes for physical storage. This backing is not yet included in the shared resident ledger, so the primitive is not a complete resident-admission claim.

Proposed same-ledger join: account the contract's own resident ledger/return arrays, canonical 64-slot document arena/return metadata, and UiValue fixed arena backing once in the resident baseline. Register the runtime's fixed reconciliation/output metadata under one exact domain identity before the first runtime reservation. Repeated registration must match the original byte count, consume no new dynamic slot, and never release static backing with an individual root. Dynamic permit shrink/final-root return subtracts only the permit's own limits; the fixed baseline remains. Existing 32MiB aggregate and 8MiB surface ceilings remain unchanged. Tests must compare against the measured fixed baseline and assert aggregate refusal with baseline included, not pretend all 32MiB remain available to payloads.

Current source additionally cfg(test)-gates `transaction.rs` in runtime glue (not changed by this lane). Its ownership migration is still necessary for the oracle, but cannot be reported as live product-host adoption. The pool remains a reusable exact Ready-output authority for the live reactor seam.
