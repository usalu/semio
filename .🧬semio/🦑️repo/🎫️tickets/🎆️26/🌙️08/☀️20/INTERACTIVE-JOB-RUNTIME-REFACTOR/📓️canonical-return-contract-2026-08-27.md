# Canonical Retained Return Contract

## Released Schema Boundary

The canonical source is `🧰️framework/🔨️modules/🎭️actor/📤️return/🧬️schema.json`, with language-neutral `🧪️fixture.json` and its `🧪️schema.json`. This is a new protocol, not a second output ABI or a compatibility union. TypeScript consumers are owned by Demonstrator; Rust, WIT and native producer mounting remain in this lane. The neutral storage schema remains `actor/📄️page/🧬️schema.json` and is reused without any command authority.

Public names and schema definitions:

| Public type | Definition |
| --- | --- |
| `ActorReturnOrigin` | `origin`: `{ activationGeneration, requestSequence }` |
| `ActorReturnIdentity` | `identity`: `{ origin, returnSequence }` |
| `ActorReturnPageReceipt` | `pageReceipt`: `{ identity, pageSequence, length, final }` |
| `ActorReturnControl` | `control`: `poll(identity)`, `inputAck(receipt)`, `cancel(identity)`, `retiredAck(identity)` |
| `ActorReturnDrive` | `drive`: `execute(origin)` or `control(control)` |
| `ActorReturnResult` | `result`: `refused`, `pending`, `page`, `retired`, fixed `control`, or authority-free `protocolFault` |

JSON u64 authority fields are canonical positive decimal strings; TypeScript uses exact `bigint`, Rust uses `u64`. `requestSequence` is a checked positive JavaScript-safe integer and occupies at most eight ULEB bytes. It is the exact transport poll id: the `N` already allocated by `ShardClient.nextRequestId` for `rN`. Open/Close has a distinct semantic request sequence. It must never substitute for this transport origin. For example, semantic Open sequence 9 dispatched as `r13` has return origin requestSequence 13, not 9. Every actual later poll/ACK dispatch has its own checked transport id, but controls retain the original return identity in their payload. The current transport id correlates the fixed response; it does not remint the original return.

The numbers alone confer no authority. Admission must be performed through the original captured activation/worker object and its native registered activation. `returnSequence` is issued by a checked native runtime counter, never derived from request ids, page ordinals, revisions, instance ids or a host counter. It survives same-id app replacement. One original captured activation has at most one active native return and one retained source page. Parallel actors retain independent slots; a new semantic turn for the same activation is backpressured until its previous raw return is retired and acknowledged.

## Existing Poll Attachment

The canonical existing `reactor.poll` receives a mandatory `return-drive` alongside its existing events, command page and budget. WIT uses a type-only `return-page` interface with the records/variants named above in kebab-case. The existing poll result becomes that fixed `return-result`; old variable WIT result lists do not coexist with it. Kernel keeps its native typed content root behind the retained return owner, before any conversion or lifting. Actor's external transport result uses the same fixed return result, not opaque whole Vec fields.

`execute(origin)` reserves native owner, page backing and host response ownership before semantic work. Duplicate origin replays the original fixed result/page without repeating semantic work. A retry keeps the original frozen origin even when its transport envelope has a newer correlation id. Another origin while active is a fixed refusal. Each captured activation retains one checked monotonic last-admitted originating request sequence even after final ACK and later admissions. Equal origin replays the active result or last retired tombstone; any older origin refuses as stale. Thus evicting the last retired tombstone when admitting a newer execute cannot make an old execute new again. Refusal before admission has no minted identity and carries `{kind: refused, origin, fault}`. No variable error string is carried in control responses.

`control(poll(identity))` performs only bounded encoding/retirement and can return `pending`, the exact currently issued `page`, or `retired`. Input ACK, cancel and retired ACK return only `{kind: control, control, outcome, fault}`. They must never execute semantic events, command ingress or create another paged response. A nonempty semantic event list or command page paired with any return control is refused before work. This also applies to malformed controls. Ordinary semantic/lifecycle/UI ACK events remain separately admitted execute turns; raw-return retirement must not depend on sending those semantic acknowledgements.

A poll whose identity is invalid or whose control is mixed returns a fixed poll `control` result with outcome `refused` and the exact fault. A poll prevented by clock/owner failure returns outcome `blocked` and the exact fault while retaining the owner. Successful poll never returns control `accepted` or `duplicate`; those contradictory poll results are forbidden by the schema. Ordinary resource contention of an otherwise valid poll can remain `pending(reason=blocked)`. Every accepted/duplicate control requires fault `none`; blocked/refused controls and refused admission require a non-none fault.

“Invalid identity” above means structurally valid but foreign/stale authority that can be echoed. Malformed authority itself, such as activation zero, request zero, return sequence zero or overflowing/noncanonical input, cannot inhabit that result. It instead returns the fixed authority-free result tag 5 `{kind: protocolFault, fault: malformedControl}`. An envelope that cannot select one control because it structurally mixes controls can use `mixedControl`; a single valid selected control mixed with semantic events still returns that exact control's refusal. The protocol-fault result is exactly two bytes, has no fabricated origin, and correlates only through the already captured outer transport request. It executes no semantic work, admits no new return and retains all existing owners. There is no variable plugin-error fallback. Three malformed-origin vectors and both protocol-fault result vectors are included in the canonical fixture.

## Page And Final Retirement

`page` contains `{kind, receipt, page: ActorBytePage}`. Receipt length must exactly equal neutral storage length. Its fixed final flag belongs to the original issued page. Non-final pages cannot have zero used length. The sequence starts at one and never wraps. Repeated delivery must have exactly the same receipt and bytes; a duplicate page does not create a second input owner.

Input ACK is permitted only after that exact host input and all decoder/borrowed-input descendants have been consumed or cancelled and retired. It checks the entire receipt including used length and final flag. It does not imply UI publication, read lease release or lifecycle retirement. Native retains the issued page until the accepted control result passes the callback's final strict clock verdict. A duplicate of the last accepted input ACK is idempotent and cannot release the next page. Cancel retains an outstanding page until its exact input ACK; polling a cancelling owner still exposes that page so the host can close its input. No receiver is expected to guess an unseen page identity.

Final page ACK starts bounded retirement of the typed source and encoder cursors. `retired` may be published only after exact raw source descendants and final root release are complete and the final clock verdict succeeds. A semantic publication owner transferred earlier remains in the original lifetime aggregate and is not credited as released by this raw-return receipt. This separation prevents a deadlock in which raw return close waits for a semantic ACK that cannot itself be admitted yet.

The final `retired` receipt remains until exact `retiredAck(identity)`. On accepted retired ACK, the fixed last-accepted identity is retained as a tombstone until the next new execute is admitted for that captured activation. Retrying after a lost ACK response returns `duplicate` without allocation or repeated release. The host must observe accepted/duplicate before admitting another semantic execute. A source fault or clock fault never erases the outbox or staged ACK. The exact structural owner remains outside unwind closures. Unknown host wrapper ownership is not discharged by selected-field validation.

## Binary Projection

All integer authority fields use shortest unsigned LEB128. Origin field order is activationGeneration, requestSequence. Identity appends returnSequence. Page receipt appends pageSequence, length, then a single canonical boolean byte 0 or 1. Reject zero authority, unsafe requestSequence, overlong/overflow/truncated integers, trailing bytes, invalid booleans and non-final empty pages before mutation.

Control tags are poll=0, inputAck=1, cancel=2, retiredAck=3. Drive tags are execute=0, control=1; a control drive then embeds one control tag, not a second transport request id. Maximum sizes are origin 18, identity 28, receipt 41, control 42 and drive 43 bytes. Fixture vectors include the exact 43-byte maximum. Result tags are refused=0, pending=1, page=2, retired=3, control=4, protocolFault=5; each record follows the field order in the schema. Pending reasons, completion, outcome and fault enums use zero-based declaration order. `page` emits its receipt followed by exactly 4096 neutral bytes with zero tail; receipt length is the single wire length, not a second length field. WIT still carries the neutral page's checked length. Maximum result size is 1+41+4096=4138 bytes, excluding language/runtime object overhead. Each allocation, header copy and page placement still needs its actual physical admission; 4096 payload bytes is not a 4096-byte total-owner certificate.

## Semantic Content Sections

The single semantic format is `semio.kernel.return-content.v1`, now declared at `🧰️framework/🔨️modules/🎠️kernel/📤️return/📦️content/🧬️wire.json`, with `🧬️schema.json`, `🧪️fixture.json` and `🧪️schema.json`. The first four bytes are `73 72 74 01`. Each record is one tag byte, shortest u64 ULEB body length, and that exact body. Records may span any number of raw pages. End-of-return is exactly the final end record, not a page boundary or implicit EOF.

Canonical section order is metadata(0), optional lifecycle(1), optional uiBegin(2)/exact counted uiOp(3)/uiEnd(4), declared effect records(5), declared presence records(6), commandIngress(7), conditional statusPayload(8), end(9). The declaration pins every body field and eleven UI opcode ordinals. Effects, command ingress and checkpoints use the exact existing WIT declaration's field/variant order with the primitive binary rules recorded in that file. WIT `pack` means only length-delimited opaque exact bytes; semantic interpretation belongs to each declared field, never to the generic alias. UI packed fields and presence use their independent store wire-value document format. SendMessage payload from app exchange remains the exact `protocol::encode_app_frame` bytes, including Invocation output, diagnostics, UI scope, history and messages. It is an effect associated with its original request, not a UI ACK. This is not generic whole-WIT lifting. Native typed encoding must validate the same invariants as the semantic WIT projection, without using its allocating conversion helpers.

`uiBegin` contains the original canonical `ActorUiPatchReceipt`, an opaque exact surface string, base revision, revision and operation count. The lifetime is taken only from the receipt; no surface prefix, current instance lookup or guessed generation establishes authority. `uiOp` preserves the actual eleven WIT operation forms: independent PACK node/component/layout/activity/style/accessibility/bindings/menu fields; direct exact u64 children; direct scalar Remove/SetRoot. Activity's existing packed `{activity, disabled}` wrapper is preserved. Scene document bytes inside Surface retain their separate existing child dialect. Canonical wire u64 values are never silently cast through floating point; renderer-specific representability checks remain explicit before semantic publication.

The native cold `pack_patch_field`/`store::pack_rt::encode_wire_value` is an output oracle only. Live encoding must borrow the original typed source and measure/encode incrementally. It may not materialize the whole `DslValue`, whole packed field or whole return. Declared record/field length is never allocation admission. Each host semantic page is independently pre-admitted and owns copied bytes before raw input ACK. A decoder cannot keep a borrowed raw page while waiting for another page: otherwise any operation larger than 4096 bytes deadlocks the one-page source. The fixtures explicitly require an 8193-byte Surface child, every UTF-8/varint split, cancellation after uiBegin before uiEnd, and exact private ownership during raw-to-semantic transfer. uiEnd permits final validation/publication; it is not itself a publication ACK.

The content declaration unblocks schema-bound host/UI tests. Its native incremental encoder, incremental semantic decoder, complete effects field coverage and actual cross-page/close laws have not run. No production old/new result branch or whole-result encode/decode fallback may be mounted as a substitute.
