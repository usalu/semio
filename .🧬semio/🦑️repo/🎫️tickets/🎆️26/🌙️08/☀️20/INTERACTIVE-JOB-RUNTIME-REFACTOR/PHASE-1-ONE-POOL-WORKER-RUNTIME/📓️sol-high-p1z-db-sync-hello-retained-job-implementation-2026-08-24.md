## Production Cutover

- Database::hello_retained is the exact pre-admission facade.
- Database::hello awaits only the retained terminal witness and returns DatabaseSyncHelloSession.
- The hub transfers owned hello inputs, takes Welcome once, awaits one next_frame per socket send, cancels on send loss, and never materializes all follow-up frames.
- Native and Wasm share the same authority and state machine; no target fork, nested executor, subsystem pool, or compatibility layer was introduced.
