## Ownership and Teardown

`RetainedUiTypedCursor` consumes the exact full transport buffer through the existing owned decoder, then retains a typed normalization generator. Its profile is private and immutable. A partial or rejected result cannot be taken. The fixed schema has bounded structural delegation; arbitrarily nested UiValue uses an explicit frame chain, not recursive generator delegation. Cancellation drains each explicit JSON frame before releasing the suspended fixed-depth program, partial objects and decoder.

Every returned `OwnedUiPayload<T>` has a private reference-counted root. `capture()` retains that exact immutable root in O(1). Consumers must retain this owner while using its borrowed value. `beginClose()` moves the owner into `UiPayloadRetirement`; only `advance(1,4096)` reaching `complete` plus `terminalIsEmpty()` witnesses full retirement. Detaching or deleting a registry entry is not completion.

For a surface field the builder calls `UiSurfaceBytes.capture()` before exposing the typed root. The read model exposes only `UiSurfaceByteView.length/byteAt`, with the owning handle hidden in a private field; callers cannot close the bytes through that view. Decoder retirement can therefore release its separate original handle safely. Tests retain two older snapshot owners, close the decoder and current publication owner, cancel another candidate, and verify the old bytes remain exact until the last older owner retires. Zero-grant close does not mutate ownership. The final close zeroes/releases the pages; the now-borrowed view rejects access.

Normalized records/objects are frozen; array/map members are individually immutable, with sealed lengths/shape. Completed containers are registered in reverse postorder, so retirement releases parent references while child owners still exist. Partial frame/program objects remain bounded by native fixed-slot envelopes. Scalar text is already bounded by the decoder's native 512-byte UTF-8 admission; ordinary containers have at most 256 slots, node children 128, bindings 32 and grid tracks 32. Surface bytes use distinct 256-byte pages up to the native 32-KiB domain. No full payload concatenation, JSON stringify/parse, recursive decode or map clone occurs in the production typed path.

The grant accounting covers actual bounded encoding/decoding work and conservative fixed schema/object-slot phases. It does not certify physical JavaScript GC latency or an eight-millisecond allocator maximum. Full-buffer transport ownership still requires the caller to provide an actually owned, non-shared, whole buffer; unrelated aliases, WIT lifting allocation and Wasm-memory ownership are not magically solved by transfer.
