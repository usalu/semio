# Canonical Return Source Admission — First Neutral Packet

This is a staged source-owner design/test packet, not a mounted native owner, producer, or poll cutover. Kernel message/framing/dialect seven and Actor return-wire five are independently recorded native passes; they do not certify this new packet.

## Original Structural Owner

The next native owner must be attached to the exact embedding PluginRuntime, retaining its one activation origin frontier and checked native serial. Before any semantic producer step, it reserves the original input/producer cursor, one typed TurnResult root and the page/response capacity. A refused or zero-grant admission performs no producer work and leaves the previous owner/frontier untouched. A valid retry uses the original frozen origin even when its transport correlation envelope changes. Same numeric instance reopening is not another native source lookup.

The producer stores only explicit phase state and owned app-job handles, not a future borrowing a sibling field of the same object. The original output root lives in the slot throughout producer failure, decoding, encoding and cancellation. Every append/transfer preflights its destination and physical allocation before moving the corresponding owner; constructing a whole result elsewhere and installing it after encoding is insufficient. All fallible execution operates on the structural slot in place; no take-before-catch ownership hole is allowed.

The current ReturnMessageCursor borrows an Effect and is safe only while that borrow lives. Native mounting must split its fixed progress state from source borrows and reborrow the exact immutable effect by the owning root's private index on each bounded write. It must reuse the same encoder grammar. No unsafe self-reference, public rebindable cursor, cloned payload, or whole-result serialization is proposed. Source mutation is allowed only during the producer phase; encoder access ends before typed retirement begins.

## Exact Page And Terminal Boundaries

Host admission clarification: no native/worker one-response producer credit or page issuer is mounted yet. A real, pre-reserved host composition byte lease could own an exact raw-backing custody transfer before semantic field consumption, independently of UI binding (which cannot precede Open). A selected field token, a count-only slot or an arbitrary wrapper is not that lease. Every byte must remain owned and credited, and the next page needs independently available host capacity. This is not a new wire variant or a semantic UI ACK. Native InputAck remains exact, staged and clock-committed; its fixed control response cannot recursively produce the next variable page. Retiring/copying the original raw backing into that exact host owner is also not evidence that the native typed source or Published owner has retired. Host composition custody is a proposed producer/consumer join, not an implemented credit claim.

An issued page and receipt remain unchanged until the exact staged input ACK passes the final clock verdict. Cancel cannot retire an unseen/outstanding page. Late/missing/backward clocks preserve that page and staged control. Raw input ACK is not the semantic UI ACK: the original lifetime aggregate must separately retain the published semantic UI owner before raw return release. Final typed descendant and source-shell destruction occur before the final clock; an explicit released-shell state must survive late failure so retry neither demands a destroyed source nor repeats destruction. Empty source slots alone never create a Retired receipt.

The scalar admission/frontier and source placement tests must use the actual typed root and exact original payload allocation, including fault/unwind, parent movement, source reborrow and refused destination handoff. Unsupported source retirement remains retained and visibly nonterminal; no generic callback whose boolean emptiness asserts completion is accepted.

Before selecting physical source backing, one canonical native diagnostic is mounted as `return_source_native_layout_census_before_backing_admission` in `🏠️source/🧪️component.rs`. It prints actual size/alignment of the current TurnResult, Effect, PresenceUpdate, UI patch owner, fixed Actor page/result and borrowed message cursor, plus Vec page descriptor widths. This is a layout inventory, not a behavioral source-owner acceptance test; its output explicitly marks `sourceBackingAdmitted` and `nativeOwnerMounted` false. It is pending the sole compiler. Existing callback-local Vec growth must not be relabeled as pre-admitted storage merely because the outer root/header has a small fixed size.
