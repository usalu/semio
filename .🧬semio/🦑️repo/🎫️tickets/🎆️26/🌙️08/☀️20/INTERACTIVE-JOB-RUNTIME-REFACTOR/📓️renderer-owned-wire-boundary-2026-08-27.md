# Renderer Owned Wire Boundary

The shared actor `wire-turn.ts` is not merely a duplicate applicator: it still decodes obsolete recursive Replace/InsertChild/RemoveChild/SetProps tags, while React handles the current flat semantic patch tags. The wgpu bridge then retains one body per actor and reads it without instance/body-key qualification. This entire shared consumer must join the new semantic retained path, not retain a permissive old-tag fallback.

The actual current native UI schema provides relevant bounds: `UI_TEXT_MAX_BYTES=512`, `UI_FIXED_LIST_ITEMS=32`, `UI_VALUE_MAX_ITEMS=256`, with UiNodeRecord keys and UiValue text using UiText. Current component option lists/row actions use UiFixedList; data/drag attributes use UiFixedMap. This is distinct from the pre-existing TypeScript semantic test boundary with 65,536 text bytes and 20,000 nodes. The large Unicode preparation fixture deliberately exercises that existing semantic algorithm; it is not evidence of a legal current native wire payload.

The private live decoder must take ownership of transport bytes, decode one bounded scalar/member/field at a time, and build immutable fields before a publication authority can be minted. It must not serialize/clone a whole mutable typed input merely to seal it. Fixed per-member non-writable definitions plus terminal prevention of extensions avoid a whole deep-freeze walk; explicit private metadata retains traversal/retirement ownership. The exact native property/list capacities must be verified before using this path; generic old whole-object decode is not an authority substitute. Byte-buffer transfer/admission and remaining jco materialization remain explicit transport frontiers.

Native host timing remains a separate open obligation reported by the coordinator: `reconcile_step_opportunities(fuel).max(1)` still drives at zero fuel; the 1,024-opportunity loop checks deadline every 64; PatchTracker uses an internal unlimited-deadline StepBudget. A static one-drive symbol is not a proof that a whole reactor poll meets eight milliseconds. That future fix needs zero-fuel/expired-deadline fake-clock laws before additional admission, and is not credited by this TS work.
