## Required Narrow Refinements Before Source Mount

1. The shared clientAdmissionPurpose word is used by UI as well as workers. Specify its exact funded original parent before either lane uses it, including UI-first construction with no worker bootstrap. Charging this word only in a later worker-root subset is not enough for an early live UI cutover. Price it exactly once and retain that owner through both consumers; do not simply duplicate controller208 or borrow a spare cell. Current actual UI recovery uses preparedAdmission(this), so the cross-purpose hazard is real, not resolved by identity strings in the model.
2. Declare all gate endings: short/blocked preparation, known no-cell refusal, prepare-after-return fault, claim-after-return fault, claimed observation, cancellation and first fault. A foreign purpose must neither claim nor erase the original pending cell. Reset must follow exact original claim/no-cell observation, not a public phase value. Add neutral and then actual same-client interleaving tests against the existing retained cells.
3. The written factoryResult obligation has no matching normative trace. Add undefined success, a returned object/Promise, before/after construct faults and first-versus-distinct subsequent fault cases before implementing that boundary. Runtime proof must retain the exact value without reading getters/then or replacing the first root.
4. Binding-before-mutation traces currently skip an attempted binding and list no handler root. The contract requires all handlers/binding pairs to be owned before Worker creation and the exact attempted pair before property mutation. Extend the model to represent those states (or explicitly label partial projections), then require actual before/after failures to preserve the original precreated owners. A success-only bind event does not test this boundary.

These refinements are limited to the existing ticket declaration/controller and source-first test preparation. They do not authorize a new compatibility factory, arbitrary adopt(worker), live callback routing, generic handoff verifier or worker constructor cutover. The exact source construction/phase inventory must be repriced if implementation needs more state.
