# UiDocumentStore Diagnostic Reproduction

One-off coordinator verification, not a permanent task script. Run the following JavaScript through Bun from the repository root under the explicit Nx workspace project; Nx exec needs embedded double quotes escaped because it reconstructs a shell command. Use the absolute module path when executing from another project. The successful command was Nx exec with projects=workspace. Timing assertions were deliberately not used: this collects evidence while checking functional results, and is not an isolated performance gate.

```javascript

```

The document shapes have depth two, five root branches, at most 4,096 children per branch, unique sibling keys and 20,000 nodes at the larger limit. All thirty one-node patches per size were accepted and advanced the exact expected revision.
