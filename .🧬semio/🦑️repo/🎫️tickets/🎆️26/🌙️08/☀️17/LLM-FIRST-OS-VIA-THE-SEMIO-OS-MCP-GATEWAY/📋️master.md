# LLM-First OS — one `semio-os` MCP gateway over the semantic action/artifact/plugin system

## Context

`s` today has no machine interface: the React shell (`ShellHost/🟦️component.tsx`, 6.9 k lines) and the wgpu shell (`Shell/🧊️component.rs`) are the only clients of the OS; every artifact edit is an `AppCommand` dispatched from UI chrome; the only MCP servers in the repo are the Go **repo** tooling server (`🦑️repo/🔨️modules/💻️client/{🔌️mcp,⌨️cli}`, mark3labs) and six **legacy** neo4j/compose entries in `.mcp.json`. ## 2. Design — gateway, topology, shell bridge, ShellState (source of truth for P1/P6/P7/P9/P10/P11)

### 2.1 Process topology
```
MCP client (stdio) ──►┌ semio-os-mcp (Rust, tokio) ───────────────────────────────┐
MCP client (HTTP)  ──►│ McpServer (JSON-RPC 2.0, MCP 2026-07-28, behind McpTransport)│
                      │ Catalog + Search │ ContextBroker │ ActionAdapter │ Policy+Audit│
                      │ HeadlessWorkspace: 🎭️actor::Kernel + WasmtimeRuntime          │
                      │   + store::sync::ArtifactHost (Folder | Hub bindings)          │
                      │ ShellBridgeServer  ws://127.0.0.1:6300/bridge?token=…          │
                      └──────────▲───────────────────────────────▲────────────────────┘
        ShellBridge frames      │                                │ ClientFrame/ServerFrame (unchanged)
   ┌────────────────────────────┴───────┐                 ┌──────┴──────┐
   │ React shell / wgpu-web / wgpu-native│◄── DocumentChanged ─┤   os-hub    │
   │ (AgentBridge element)               │                 └─────────────┘
```
- CLI: `semio-os-mcp stdio|http [--port 6300] [--folder <space dir>]… [--hub <url> --space <id> --token <t>|--token-file] [--plugins <dir>] [--principal agent:<name>] [--scopes a,b] [--auto-approve never|readonly|all] [--bridge-token-file ~/.semio/agent/bridge-token] [--promote <cap>…]`. Port 6300 (outside catalog 6012–6205 and the 7300+ bench pool). `bun ./📜️script.ts dev mcp stdio os …` / `dev mcp http os …` spawn it (mirrors `os run`).
- Browser shells cannot listen → they **dial** the gateway's loopback WebSocket bridge (token minted at start, 0600 file, `Origin` must be loopback/`null`); wgpu-native dials the same bridge (in-process embed deferred so there is exactly one bridge contract). N shells may attach; each gets a `ShellConnectionId`.
- Headless mode (no shell): open artifacts via `ArtifactHost` bindings (`FolderSqliteStorage` with `watch_external`, or hub), activate the owning app actor through the Kernel (`ActivationEvent::OnArtifactKind`, `Event::InstanceOpen{actor:"agent:<principal>#<session>", capabilities: scopes ∩ plugin requests}`), drive `AppCommand`s, commit through VCS/backbone → live shells receive `DocumentChanged` like any peer. Mixed mode: `ui.*` over the bridge; mutations prefer the headless authority when the artifact is backbone-reachable; only React-web with browser-local storage relays `AppCommand`s through the shell instance (same frames, `RelayAppCommands` flag) with provenance via new `ActionInvocation.origin: InvocationOrigin{Shell|Agent{principal,invocation_id}}` (manifest, default `Shell`; `VcsArtifactApp` stamps `ActionMeta.actor`).

### 2.2 `ShellBridge` frames (`🌉️mcp/🧵️bridge/🦀️component.rs` SSOT, TS twin `🧵️bridge/🟦️component.ts`)
Hand-rolled binary (`tag:u8` + fields, primitives from `os_spr::wire` / the `🔖️Combinators` region of `💻️os/🟦️component.ts`), `BRIDGE_VERSION=1`.
- Shell→Gateway: `Hello{bridge_version, shell_kind: react|wgpu-web|wgpu-native, shell_session_id, principal_actor, flags: RelayAppCommands|SharedBackbone|Elicit}`, `ShellState{revision, state: pack}`, `ShellStatePatch{revision, base_revision, patch}`, `Instances{entries: Vec<BridgeInstanceRef{plugin_id, app_id, instance_id, artifact_ref, window_ids}>}`, `AppFrames{in_reply_to, instance_id, frames}`, `ShellCommandResult{in_reply_to, ok, fault}`, `Approval{approval_id, decision: deny|once|session, note}`, `Ping`, `Bye`.
- Gateway→Shell: `Welcome{bridge_version, connection, principal}`, `ShellCommand{seq, command: pack}`, `AppCommand{seq, instance_id, command}`, `ApprovalRequested{approval_id, summary}`, `ApprovalResolved`, `AgentPresence{active, label, invocation_id}`, `Pong`, `Bye{reason}`.
- Full `ShellState` on Hello and on `base_revision` mismatch, patches otherwise; the UI thread never awaits the gateway.

### 2.3 Kernel-owned `ShellState` — new OS module `💻️os/🔨️modules/🖥️shell`
Files: `🦀️component.rs` (Rust SSOT, mounted into `semio-framework-os-kernel` glue as `os_shell`; pure serde + reducer, wasm-safe), `🟦️component.ts` (TS reducer twin), `🤖️generated/🟦️shell.ts` (ts-rs), `🧫️fixtures/*.json` (`{state, command} → {state, events}` parity fixtures run by `cargo test` and the in-source vitest block), `📦️packages/🟦️typescript/…`.
```rust
pub struct ShellState { revision: u64, session: ShellSessionInfo, locale, terminology, theme_id, appearance, driver_id,
  layout: LayoutTree /* WindowLayoutNode + panel anchors visible/size/path, dock override, mobile path */,
  windows: Vec<WindowInstanceState{id, window_kind_id, plugin_id, app_id, instance_id, artifact_ref, title, icon, active_utility_id, split_parent}>,
  focus: FocusState{window_id, active_mode_id, active_tool_id}, action_pane: Vec<ActionPaneState>, command_panel: CommandPanelState,
  overlays: OverlayState{dialog, notice, search_open, find_open, context_menu}, introduction, tutorial,
  sync: SyncState, merge: MergeState{merge_policy, conflicts, selected_conflict_id}, agent: AgentChrome{connected, working, pending_approvals} }
pub enum ShellCommand { OpenWindow{kind_id, params, focus}, CloseWindow, FocusWindow, SplitWindow{axis}, ApplyNamedLayout, SetPanelVisible{anchor}, SetPanelPath, SetPanelSize, ResetDock, SetDockOverride,
  SetActiveMode, SetActiveTool, SetActiveUtility{window_id}, StageActionArg{window_id, action_id, arg_id, value}, ResetActionArgs, ExpandAction,
  OpenDialog{dialog_id, args}, CloseDialog, Notify{message, level}, ToggleSearch, ToggleFind, SetLocale, SetTerminology, SetThemeId, SetAppearance, SetDriverId,
  Navigate{uri}, RevealArtifact{artifact_ref, target: Window|Panel|Selection}, SetActiveExample, SetMergePolicy, SelectConflict,
  AgentConnected, AgentWorking, AgentApprovalCount }
pub enum ShellEvent { WindowOpened, WindowClosed, FocusChanged, DialogOpened, LayoutChanged, PrefsChanged{key} }
pub fn reduce(&ShellState, &ShellCommand, now_ms) -> Result<(ShellState, Vec<ShellEvent>), ShellError>;
pub fn shell_capabilities() -> Vec<CapabilityDefinition>;   // one `ui.*` capability per variant (schemars on the payload)
```
Render caches (window `UiNode`s, engagements, measures) stay in the microkernel `SceneStore`. The TS `ShellAction` semantic subset (windows/focus/mode/tool/utility/panels/dialogs/prefs/sync/merge) is **replaced** by `ShellCommand` dispatch; the informal `shell.*` verbs in wgpu `ShellCommandHistory` (`shell.windowClose`, `shell.applyNamedLayout`, …) become these variants so history rows and agent capabilities share one vocabulary. Adoption in ShellHost/Shell (P10/P11) happens **after** the microkernel H1/H3 land; the module + twin + fixtures land immediately (new files only).

### 2.4 Sessions & handles (`🌉️mcp/🎫️handles`)
`AgentSession{id, principal, scopes: Vec<kernel::CapabilityId>, attachment: Headless{workspace}|Shell{connection, workspace}, locale, terminology}`; handles are ULID strings prefixed by kind (`prep_`, `txn_`, `undo_`, `job_`, `appr_`, `cont_`), each `HandleRecord{kind, owner session, bound_to, expires_ms, payload}`; TTLs prepared 10 min, txn 30 min, undo 24 h, job terminal+1 h, continuation 5 min; authorization is never derived from a handle alone. `context.resolve` creates/refreshes the implicit session for stdio clients.

### 3.3 Mutation protocol (`🌉️mcp/🎬️actions`, `⚠️errors`)
| Step | Mechanism |
|---|---|
| Observe | `context.resolve` → `semio://ui/active-context`; `RevisionStamp{artifact_id, head_edit_id, cursor}` from `AppCommand::ReadHistory`→`HistorySnapshot` |
| Prepare | `SchemaCatalog::validate` → resolve target instance/window → policy check → mint `prep_` |
| Preview | `AppCommand::PureCommand{command: wire(ActionInvocation{origin: Agent}), document/config/draft packs from the authority mirror}` on a pooled **preview instance** (never backbone-attached, rehydrated per preview) → `AppFrame::Emit{document_ops, config_ops, draft_ops, output, diagnostics}`; diff text via `ArtifactCodec::print_mirror` on `apply_ops_binary` (host) else guest job `semio.diff` |
| Approve | `ApprovalMode`/destructive/scope gate → `APPROVAL_REQUIRED{approvalHandle}` (§3.4) |
| Commit | `TransactionPrepare{txn_id, prepared_ops, label, origin: MutationOrigin::Agent{..}}` → `TransactionPrepared` → `TransactionCommit` → `TransactionCommitted{edit_id}`; `transaction.generation-mismatch` ⇒ `REVISION_CONFLICT{expected, actual, diffUri}`; `instance-busy` ⇒ bounded retry then `PRECONDITION_FAILED`; config/draft ops via plain `Command` |
| Verify | re-read `RevisionStamp` + `DispatchReport`/`MergeReport` → `InvocationReport{invocationId, capabilityId, status, affectedResources, revisionBefore/After, diffUri, warnings, undoToken, postconditions, replayed}` |
| Undo/Redo | `undoToken` ↔ `txn_id`; `history.undo` → `TransactionUndo{group_id}` on every member; `history.redo` → `TransactionRedo` |
| Multi-provider | `HostTransactionCoordinator::run_transaction` (reverse-order commit, compensating undo) ⇒ `COMPENSATION_FAILED` when compensation itself fails; never claim atomicity across providers |
| Idempotency | `IdempotencyStore(principal, idempotencyKey) → InvocationReport` (24 h, persisted in the audit lane), replay flagged |
| Cancel | prepared → drop; job class → `Effect::CancelJob`/`Envelope.cancel_of` → `CANCELLED` |
`GatewayError{code: INPUT_INVALID|PRECONDITION_FAILED|REVISION_CONFLICT|PERMISSION_DENIED|APPROVAL_REQUIRED|PLUGIN_UNAVAILABLE|SIDE_EFFECT_REJECTED|CANCELLED|COMPENSATION_FAILED|NOT_FOUND|BUDGET_EXCEEDED|INTERNAL, message, details, retryable}`; `Fault` code table (`viewer.read-only`→PERMISSION_DENIED, `mutation.rejected`→SIDE_EFFECT_REJECTED+report, `capability-denied`→PERMISSION_DENIED).
