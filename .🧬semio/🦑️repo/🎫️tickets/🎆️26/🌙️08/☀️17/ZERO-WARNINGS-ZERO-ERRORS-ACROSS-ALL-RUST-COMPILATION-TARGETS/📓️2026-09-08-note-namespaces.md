# Note Namespaces

Pass576 fixes Note's framework/document namespace collisions, which caused a large cascade of native560 import and type errors. Framework descriptors and derives use framework_schema. The document schema is directly reexported from the artifact's standard, and its text codec facade is named document_dsl. Save-download and fixture parsing call that facade; kernel DSL parsing and derives retain their dsl alias. No field definitions, wire formats or command behavior changed.
