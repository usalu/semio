# Fixed Owner and Decoder Contracts

The energy queue keeps admitted packet pages and leases in fixed slots. Saturation, mismatched identity, incomplete acknowledgment, rejected numerical admission, stale restore, and retry all return the same live owner. A lease Drop transfers its packet into the static recovery registry. Boxing these refusals would introduce new allocations into capacity failures and destructor recovery. Added exact-site lint expectations to those inspected functions and the two packet-owning enums; no ownership, allocation, or retirement behavior changed.

Presentation adoption likewise returns its exact unadopted snapshot. Its two cleanup helpers use the framework diagnostic whose path is an inline 256-byte Copy record. GIS, raster, drawing, and presentation decoder states already own an admitted hex buffer and keep its fixed diagnostic path inline; no second wrapper allocation is needed for their decode transition. Each affected enum or function has an individual expectation with the contract rationale. There is no module-level suppression.

The combined regression catalog retains the energy wire maximum/plus-one and exact restore-owner laws, plus the existing codec and ownership tests. Runtime and strict cross-target verification remain pending.
