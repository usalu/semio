# Stdio Handler Signature Validation

The native604 compiler reported missing view-state parameters in Stdio ArtifactEditor and ArtifactViewer implementations. The current framework traits require an optional ViewModel between InteractionView and DraftView/EngineHandles. A source audit found 96 adapters missing this parameter; 40 additional shapes need review. No source changes have been applied in this audit.
