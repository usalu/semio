# Retained Domain Type Names

Pass 454 names the existing copy factories, fixed map pages, drawing rebuild owners, studio port lookup, AVC configuration, FEM load/contour tuples and Norm retained results. Storage shapes, ownership and serialization remain unchanged. The imperative mutation decoder now returns immediately from the first converter that accepts its owned wire record; rejected records move to the next converter, with the same unreachable exhaustive case. No wrappers, allocations or lint suppressions were introduced. Compiler validation is pending.
