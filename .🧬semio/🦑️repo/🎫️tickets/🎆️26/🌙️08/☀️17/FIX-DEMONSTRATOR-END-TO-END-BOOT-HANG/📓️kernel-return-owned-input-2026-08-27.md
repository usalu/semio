# Kernel Return Owned Input

## Grammar And Ownership Plan

The existing canonical return content declaration owns all eleven operation layouts. The header parser selects opcode, optional exact-u64 node, field name and payload range one byte at a time. Packed fields retain only their opaque field bytes; direct children retain the count prefix plus children, not a fabricated packed document. Scalar remove/root records have no payload and must end exactly. Length is never allocation permission.

Neutral vectors cover every operation, maximum-u64 scalar, empty children and empty opaque payload. Independent webassemblyjs LEB128 and Node Buffer reconstruction validate those headers against the canonical declaration; strict Ajv validates the fixture. The parser is only format validation, not private input authority or semantic UI validation.

The next owned cursor must register strongly under the original privately minted OwnedShardReturn, verify its exact concrete host owner/activation/lifetime, and exclusively consume the captured page. It must mint Field/Fragment/Release only after that cursor has selected an actual field range. Neither a public header result, public receipt, arbitrary offset nor callback reader can mint authority. The source holds one exact fragment until private UI copied/cancelled proof is verified. A copied token and raw input acknowledgement do not constitute semantic UI publication.

UI owns the independently admitted destination builder and its private proof tokens. Its concrete resident scope must match the same host owner and lifetime before binding. No positive copy/retirement proof can be claimed until those actual private brands are joined. Strong response-envelope retention is already staged; response disposal, page input ACK, final retired ACK, live PluginRuntime/generator/native mount and all-six runtime acceptance remain separate unfinished boundaries.

The source module is Kernel/📤️return/📦️content/📥️input/🟦️component.ts. UI must validate the actual resident scope against these exact owners and strongly register its admitted builder before invoking bind; this source does not invent that positive admission.

The field's fragment exposes field, offset and length. Its static matches(receipt, exactFragment, exactProof) checks the private triple; kind distinguishes copied from cancelled. Forged records, getters and boolean callbacks never discharge input.

This initial source owns and stops at its selected field. It does not yet advance a whole multi-page payload, release any original response/page or expose InputAck/RetiredAck.
