# CLI Plan Cancellation

## Finding and Change

The root taxonomy CLI validated `--cancel-file` and forwarded it into inventory, but its subsequent `planTaxonomy` call omitted the guarded path. A request arriving during the expensive incoming-reference scan therefore did not reach the planning API.

The call now forwards `cancelFile: cancelArgumentPath`. No cancellation grammar, no-follow guard, transaction state, timeout, or failure handling was weakened. The existing path-validation boundary remains authoritative.

## Test-first Proof

The language-neutral contract at `🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/📦️packages/🟦️typescript/🧫️fixtures/🧪️taxonomy-cli-cancellation/🔣️.json` declares the source fixture, cancellation sentinel, incoming phase, and execution registration. The permanent test extracts the actual CLI plan-options expression with TypeScript, compiles it independently with Bun and TypeScript, and uses each resulting options object with the real planner.

Before implementation, the packet reported **0 passed, 3 failed, 5 assertions in 2.67 seconds**. The options lacked the cancellation field; the real callback wrote its sentinel but planning continued until an unrelated missing fixture registry input was rejected. The execution registration was also absent. No production source bytes were changed by these tests.

After the one-field fix and registration, the packet passed **3 tests, 21 assertions, zero failures in 6.14 seconds**. Both compiled options forms caused the real incoming-reference scan to stop with cancellation after its `[DEBUG]` callback. The sentinel existed and the isolated source bytes remained unchanged. The absent-option case remained `undefined`.

The gate is registered through the existing library router and Nx target `@semio-tech/repo-lib:test-taxonomy-cli-cancellation`, with both launch catalogs in group `4_gate`, order `410.09`. Its Bun test path is absolute. The ordinary fifteen-second gate budget is unchanged. Actual uncached Nx execution passed **3 tests, 21 assertions, zero failures in 5.17 seconds**, exit zero (session `28856`).
