# Call-Local JSON Reference Owner Lookup

## Measured scope

This implements only the coordinator-approved per-`jsonTokens` owner lookup optimization. The [original parser profile](../📓️reference-parser-profile/📝️.md) contains 5,091 samples. Following node-child edges attributes 858 inclusive samples to `jsonTokens`, of which 527 belong to its `artifactRootForPath` child subtree: **61.42% of the JSON parser subtree and 10.35% of all profile samples**. That subtree includes repeated path normalization and emoji folding. These are sampled call-tree counts, not exact wall-time percentages or a claim about the complete repository scan.

The production change adds one local `string | null | undefined` variable. The first existing non-key, unescaped string-value branch initializes it. Subsequent values reuse it, including a `null` result. No eligible value means no lookup; a bad path still throws at its first eligible value. The undefined sentinel distinguishes “not computed” from “computed and no artifact owner.” No global cache, grammar, token dispatch, Rust function, schema/catalog authority, or transaction behavior changed.

## Test-first and independent evidence

The authored [language-neutral contract and cases](../../../../../../../../🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/🧪️tests/🧪️json-reference-owner-lookup/🔣️.json) precede the implementation. Thirteen cases cover artifact, standards-derived, NFC/variation-selector and absent owners; duplicate keys; scalar strings; JSONC; embedded commands/globs; escaped and malformed strings; deferred errors; and empty input. Three explicit structural-projection vectors preserve all owner-dependent metadata.

The permanent [test implementation](../../../../../../../../🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/🧪️tests/🧪️json-reference-owner-lookup/🟦️.test.ts) extracts the actual source declarations, not copied production logic. Both Bun and TypeScript compile and execute the parser with its actual helpers; an observable lookup verifies once-per-call behavior and fresh ownership across separate calls. Independent `jsonc-parser` visitors and the TypeScript JSON AST reproduce exact string values, UTF-16 spans, ordinal labels and ordering. Four current JSON/JSONC corpus inputs additionally compare complete token objects between the two implementations. These external libraries are existing test-only dependencies; production gains none.

After correcting the test-only TypeScript AST traversal to pass explicit parent nodes, the unchanged production implementation produced the intended red result: **3 passed, 4 failed, 69 assertions, 3.05 seconds**. Failures were repeated null/root lookups, call isolation counts, and missing execution registration. The actual registered uncached gate then passed **8 tests, 0 failures, 216 assertions**, **693 milliseconds** within a **4.10-second** Nx invocation:

`NX_DAEMON=false bun nx run @semio-tech/repo-lib:test-json-reference-owner-lookup --skip-nx-cache`

The package router, Nx target and both launch catalogs register the same test under group `4_gate`, order `410.12`. Existing short/long/watchdog budgets were not changed.
