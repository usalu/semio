# Scoped Incoming-Reference Closure

## Contract and Scope

This bounded lane extends scoped normalization to account for repository-wide incoming consumers and outgoing references from moved consumers. The schema declares Git tracked/untracked plus explicit-ticket candidate membership, lexical opaque filtering before no-follow filesystem access, exact digest-and-token authority for frozen source coordinates, unsupported-syntax errors, drift rejection or rollback, and UTF-8 byte ordering. Actual `compose/**` and `temp/compose/**` remain opaque; all fixtures and evidence stay in this ticket. No production move or real Git mutation is authorized by this packet.

## Implemented Authority

`referenceClosure` is a strict schema-owned contract in `🔣️taxonomy.json`, the discovery interface, and its validator. The normalizer inventories source moves without widening their source scope, then builds a repository-wide incoming candidate set from Git tracked/untracked entries and the explicitly selected ticket. It reads text candidates without following symlink ancestors, admits external symlinks separately, and uses the same closure for pre-apply derivation and terminal disposal checks. External edits carry exact byte/mode/size preimages. New or drifted consumers reject the original plan or cause rollback without overwriting concurrent content.

An internal inventory context preserves the exact active transaction root and explicitly authorized plan artifact across terminal inventory copies. This is not a wire-format extension or a permanent inventory exclusion. Ordinary ticket JSON, Markdown, source, and external consumers remain candidates.

Verified independent Git roots assign reference coordinates only: exact no-follow metadata and `git rev-parse --show-toplevel` must establish the owner. They do not exclude files from inventory or scanning. An outer verified fixture owns deeper negative-fixture Git metadata as payload. Explicit relative and repository-absolute references escaping that fixture are still found. Fake, symlink, and escaping root metadata do not establish ownership. Explicit `./` references resolve relative to their consumer before root lookalikes.

A further negative reproduced Git reporting the nested current directory when its `.git` file merely pointed to the calling repository's own Git directory. That shared-parent identity no longer establishes an independent owner; its incoming consumer remains captured. Genuine independent roots and their deeper test payloads retain their coordinate behavior.

Frozen package and README/source catalog coordinates reuse the other integration lane's exact digest-and-JSON-span authority. Retained schema-v2 plans additionally require strict parsing, a valid self-digest, and exact canonical JSON plus newline. Only schema-assigned source/destination, ancestor, preimage, input/output, and reference-coordinate value spans are frozen. Invalid digests, extra keys, noncanonical bytes, and unowned path-bearing plan prose fail closed with `immutable-plan-reference-unowned`; ordinary JSON named `sourcePath` is still rewritten.
