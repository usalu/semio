# Cargo Discovery Opaque Exclusions

Read-only preparation for the native Energy gate found that the shared `getCargoWorkspaceIndex` walker did not consult taxonomy opaque exclusions before recursively enumerating directories. The native gate has not been launched. The bounded correction will reuse the existing schema-driven `taxonomyRelativePathIsExcluded` function and load its taxonomy once per index build. Existing package-name resolution and aliases are outside this correction; no new fallback or compatibility behavior is introduced.

The permanent language-neutral vector contains the two exact opaque roots, ordinary manifests, literal `temp-compose`, similarly named non-opaque roots, a nested same-name directory outside those roots, and file/directory symlink sentinels. The permanent test executes the actual private index implementation with Bun and esbuild against an in-memory filesystem that throws on any excluded access. Independent fast-glob reproduces the four allowed manifest paths. No real Compose node is constructed, probed, or read.
