## Proposed Separate Syntax Authority

Use a separate schema-owned syntax-evidence contract, not a broadened JSON declaration or filename exemption. Each document must bind its exact repository path, full-byte digest, mode, and a closed disposition:

- retained compiled snapshot with explicitly retired current execution and recorded provenance status;
- historical authored Markdown coordinate spans, with exact inline-code syntax and historical heading context.

Each selected coordinate must bind exact UTF-16 and UTF-8 spans, raw value digest, decoded value digest where JavaScript escapes occur, and the appropriate syntax identity. Compiled snapshots require a real string literal in the declared function/array context; Markdown requires an exact inline-code node under the declared historical heading. Independent TypeScript and MarkdownIt parsers must reproduce those facts. The production implementation must not introduce either library as a runtime dependency.

The document stays visible to inventory and incoming-reference discovery. Only validated coordinate spans are historical. Relevant unowned content fails closed rather than becoming a silent edit that changes a frozen document. Digest/mode drift, wrong syntax/context, forged or partial spans, unsupported escapes, and live callers block. Recorded source code is not executed to validate evidence.
