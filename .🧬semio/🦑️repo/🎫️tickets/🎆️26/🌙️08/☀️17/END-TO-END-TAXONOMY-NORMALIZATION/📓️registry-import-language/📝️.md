Both complete Energy and Draw incoming-reference captures ended before plan publication because the registry compiler adapter parsed every implementation as TSX. The valid numeric-index TypeScript source contains a generic arrow in a static class block. Its later private method produced Bun's misleading `input.tsx:69:5 Unexpected if` diagnostic.

The production scanner now requires an owned compiler-language value, derived from each visited physical leaf's extension. TypeScript (`ts/mts/cts`), TSX, JavaScript (`js/mjs/cjs`) and JSX remain distinct. Unsupported extensions and syntax errors fail with the actual source path; there is no retry under a different grammar. Unicode import decoding, static-only membership and deterministic deduplication/order remain unchanged. The numeric-index implementation, schema, catalog pins and Compose are untouched.
