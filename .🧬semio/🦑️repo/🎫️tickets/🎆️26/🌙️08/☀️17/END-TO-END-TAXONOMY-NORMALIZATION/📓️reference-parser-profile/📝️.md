# Reference Parser Profile

## Scope

A bounded diagnostic loads the actual normalization implementation through a generated, ticket-local bundle exposing three private reference functions. Production exports and source remain unchanged. It reads three explicit source files, checks their hashes before and after, and resolves their tokens against 130,003 in-memory paths. Synthetic index entries are strings, not filesystem accesses. This is a parser attribution experiment, not a repository acceptance gate or a representative end-to-end benchmark.

The retained input is `📜️script.ts` in this directory. Bundling and profiling run through the existing workspace Nx exec runner. CPU profiles and the generated bundle are disposable output. No Compose path is accessed. The Energy, Draw, and repository captures were running during the original experiment.

## Results

The first `bun nx exec` invocation failed before the diagnostic because the package wrapper's inherited lifecycle name made Nx look for a target named `nx`. Invoking the existing Nx executable with Bun avoids that wrapper context: `NX_DAEMON=false bun node_modules/nx/bin/nx.js exec --projects=workspace --parallel=1 --skip-nx-cache --skipSync -- bun <ticket-script> <mode>`.

## Completed Output Retirement

After the profiling and paired-corpus experiments had terminated and their owner confirmed these originals were no longer needed, both exact generated files were checked with no-follow regular-file and ancestor validation, size/mode/SHA-256 checks, and `lsof -nP` (no open handles, exit 1 without output). `apply_patch` removed only the 6,123,280-byte `🟨️profile.generated.js` and 90,797-byte `🔬️.cpuprofile`, totaling **6,214,077 bytes**. Their hashes match the recorded experiment above. Both final exact-path `stat` checks returned ENOENT; the authored `📜️script.ts` and this Markdown report remain. The bundle can be rebuilt from its input; the sampled CPU profile was not backed up and a rerun will produce a new profile, not identical samples. No active capture, transaction evidence, or Compose path was removed.
