## Invariants and Implementation

Folding remains exactly NFC, then `toLocaleLowerCase("und")`, then removal of U+FE0F. Distinct exact output strings are folded once per invocation; each occupied occurrence is folded once. Matching remains equality or occupied ancestor followed by `/`. The allowed-directory set retains exact, unfolded identity. Input ordering and duplicate collision diagnostics are preserved. No global cache or broadened exclusion exists.

The normalizer reuses its already constructed, unchanged `admitted` set instead of rescanning candidate objects for each inventory key. Both predicates use exact `sourcePath` equality and retain inventory-key insertion order.

Tests execute the exact two production expressions extracted with TypeScript's AST and transpiled only in memory. Direct calls also exercise the full exported pure package authority with empty node facts and the current digest-locked catalog. Missing-node diagnostics are deliberately preserved; this is not a live source-preimage acceptance test. No real package source is read by those calls.

Independent minimatch literal escaping and ancestor matching reproduce all collision outputs; Ajv checks the language-neutral vector schema, and fast-json-stable-stringify binds complete diagnostic records. The 16 collision vectors cover NFC, case, VS16, Kelvin normalization, locale-neutral dotted-I behavior, sharp-S non-equivalence, exact allowed-directory identity and rejected aliases, ancestor/descendant boundaries, literal glob punctuation, adapters, derived leaves, duplicate outputs, ordered duplicate diagnostics, and empty input. Three membership vectors preserve exact identities and order. Successive invocations test changed output/allowed sets without stale reuse.
