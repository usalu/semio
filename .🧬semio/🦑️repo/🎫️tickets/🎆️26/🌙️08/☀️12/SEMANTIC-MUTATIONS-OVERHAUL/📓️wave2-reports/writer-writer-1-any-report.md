# Wave 2 fan-out — writer/writer (standards/1/subsets/any) mutations facet report

Facet: `✏️s/🔌️plugins/✒️writer/🗿️artifacts/✒️writer/🏅️standards/🔖️1/🪆️subsets/✳️any/🧬️schema/🧬️mutations`
Crate: `semio-s-plugin-writer`

## Source shape (before)

`WriterSnapshot` has exactly five persistent scalar fields — `schema: String` (fixed artifact-schema-id
constant, `WRITER_DOCUMENT_SCHEMA`), `id: String` (document identity; `open_document`'s app handler
derives it from the last path segment of `uri`), `language_id: String`, `uri: String`, `text: String`
(the authored body) — no id-keyed collections, no ordered lists, no relationships, no hierarchy. The old
`WriterMutation` enum had two struct-variants (`SetText { text }`, and the banned `SetSnapshot
{ snapshot }` whole-document replace) plus two "leaf-shaped but actually generic" triad dirs
(`✍️set-text`, `📄set-snapshot`) that were thin apply/diff/inverse delegates back onto a hand-written
`impl Mutation` — not real `MutationKind` payloads.

## Derivation applied

Per `derivation-rules.md` recipe §1 (document-level scalars, `id` as the identity field):

- `id` → `rename-writer` (verb `rename`, entity `writer`, record `RenamedWriter`) — the identity field.
- `uri` → `change-uri` (verb `change`, entity `uri`, record `ChangedUri`).
- `language_id` → `change-language` (verb `change`, entity `language`, record `ChangedLanguage`).
- `text` → `edit-text` (verb `edit`, entity `text`, record `EditedText`) — taxonomy's `edit` verb is
  explicitly "replace an authored content body (text, cell, code)", a better fit than `change` for a
  free-text document body.
- `schema` → **no mutation**. It is the fixed artifact-schema-id constant (`WRITER_DOCUMENT_SCHEMA`,
  always `"writer.document"`), never user-authored; giving it a `change-schema` mutation would invent
  structure the app never exercises (task guidance: don't invent structure not in the schema).
- `SetSnapshot` → **deleted, no replacement**, per taxonomy's banned-vocabulary rule (whole-document
  replace has no in-history mutation; it belongs to `ArtifactStore::reset`, entirely outside the
  `Mutation` enum).

## Triad leaves created

- `🏷️rename-writer/{🦠️mutation,🔺️diff,↩️inverse}/🦀️component.rs`
- `🔗change-uri/{🦠️mutation,🔺️diff,↩️inverse}/🦀️component.rs`
- `🌐change-language/{🦠️mutation,🔺️diff,↩️inverse}/🦀️component.rs`
- `✏️edit-text/{🦠️mutation,🔺️diff,↩️inverse}/🦀️component.rs`

Each `🦠️mutation` payload struct derives `dsl::DslRecord` (needed for `dsl::DslEnum`'s tuple-variant
newtype delegation, with its own `#[dsl(keyword = "...")]` matching the variant's kebab form) and
implements `protocol::MutationKind<WriterSnapshot, WriterMutation>` with a real `SEMANTICS` const;
`diff`/`inverse` delegate to the sibling `🔺️diff`/`↩️inverse` leaf functions. `rename-writer`/
`change-uri`/`change-language`'s diffs build the sparse `WriterDiff{ id | uri | language_id: Some(...),
..Default::default() }` directly (real handcrafted construction, no apply-then-capture).
`edit-text`'s diff delegates to the pre-existing, already-tested `diff_set_text` sparse-diff builder in
the sibling `🔺️diff/📝️text/🦀️component.rs` facet (kept as-is, unrelated to the banned
`SetSnapshot`/`diff_set_snapshot` path, which also stays — it backs the `WriterDiff` type's own
whole-artifact-override absorb behavior, independent of which mutation variants exist). All four
inverses read `base` (never the diff) and always return exactly one restoring mutation — a document
scalar always has a prior value, so none of these ever return `Vec::new()`. None override
`target()` (whole-artifact scope is correct: this is a single-document artifact, no addressed
sub-entities).

Old dirs `✍️set-text`, `📄set-snapshot` deleted entirely.

## Dispatch rewrite

`🧬️mutations/🦀️component.rs`'s `WriterMutation` enum is now four single-field tuple variants —
`RenameWriter(rename_writer::mutation::RenameWriter)`, `ChangeUri(change_uri::mutation::ChangeUri)`,
`ChangeLanguage(change_language::mutation::ChangeLanguage)`, `EditText(edit_text::mutation::EditText)`
— deriving `dsl::DslEnum` (kept, for the facet's already-handcrafted `OpText`/`OpBinary` impls in
`🧬️mutations/📝️text` which need `DslVariants`) **and** `dsl::Mutations`
(`#[mutations(snapshot = WriterSnapshot, diff = WriterDiff, schema = "writer.writer")]`, matching the
snapshot's own `#[dsl(id = "writer.writer", ...)]`). Hand-written `impl Mutation<WriterSnapshot> for
WriterMutation` (the old `diff`/`inverse` match against `super::set_text::...`/`super::set_snapshot::...`)
deleted — generated by the derive now. Kept `apply_writer_mutation` (now diff-first:
`mutation.diff(snapshot).apply(snapshot)`, matching wave 0's confirmation that the store's own apply
path is already diff-first) and `inverse_writer_mutation` (still used by `🏗️builder`).
`semio-s-plugin-writer`'s `Cargo.toml`/glue.rs only alias `dsl`/`store`/`protocol`/`dsl_lsp` to
`semio_framework_os_kernel` (no `vcs` alias, unlike `gis`), so `apply_writer_mutation` uses the
diff+apply pair directly rather than `vcs::apply_mutation`.
