# Mutation Structural Source View

## Current Read-Only Finding

The root read the complete direct-leaf structural scanner, its descriptor loader, aggregate reachability and runnable-test readers, and the mutation inventory's fact-collection loop. The source index's new canonical admission does not yet govern those reads. Structural checks still enumerate child directories, reopen sources, consult a process-global descriptor-schema cache, and fall back to the real workspace when a fixture lacks its schema. The inventory also rereads aggregate sources and uses filesystem existence to label direct, nested and central-only records. Endpoint hashing alone cannot make those unadmitted reads part of the captured input.

The existing canonical admission owns candidate membership. A second filesystem inventory or permissive reader is not proposed. The next internal structural view must be a projection of that admission and the already-captured regular source bytes.

## Required View

- Retain the complete admission result in the source index, including absent observations, exact origins, index tuples, generator matches, and schema identity. Regular source bytes remain the one captured content authority.
- Derive directory facts only from explicit admitted directory observations or the proper ancestors of admitted regular files whose canonical observer established no-follow ancestry. Record the supporting observation paths; do not fabricate an empty filesystem directory from an arbitrary basename.
- Resolve existence and child membership from those facts. A symlink is not a regular source or directory, and an absent tracked path cannot satisfy a required mount or payload.
- Read the taxonomy and mutation descriptor schema from captured bytes. Require the taxonomy bytes to match the admission's parsed input hash. Remove fixture-to-workspace fallback and process-global schema substitution from this path.
- Pass the same view through structural checks, direct-owner checks, wrapped-type provenance, leaf-owned runnable-test discovery, codec/schema parity, and inventory record classification. Pure syntax inspection remains unchanged. No helper may fall back to the filesystem when a path is absent from the view.
- Keep public standalone policy entry points by having them acquire one canonical source index at the boundary, then invoke the same pure projection. This is not a compatibility implementation or a second membership policy.

## Test-First Cases Before Mounting

1. An otherwise valid leaf's ignored, unadmitted descriptor/test/codec cannot satisfy a requirement; injected filesystem reads throw if attempted.
2. Missing, symlink and absent-index nodes remain distinct and do not create phantom mutation directories or source origins.
3. Two requested roots retain a captured external consumer and the same schema identities, with no second admission call.
4. A mounted child outside the captured view stays unresolved even if a real file exists; a captured exact child resolves without any IO.
5. A fixture missing its captured descriptor schema fails explicitly instead of borrowing the live workspace schema.
6. Final new/removed/mode-changed membership and changed content are rejected by the existing endpoint comparison; structural facts use only the first captured view.

Neutral cases must be executed against the actual current functions before edits, then against the same functions after the cutover. Structural source-shape checks alone do not establish these outcomes. The root-file splice remains coordinated with the disjoint source-index/fallback executor and taxonomy's unrelated scaffold/registration regions. No production structural-view edit has been made for this report.
