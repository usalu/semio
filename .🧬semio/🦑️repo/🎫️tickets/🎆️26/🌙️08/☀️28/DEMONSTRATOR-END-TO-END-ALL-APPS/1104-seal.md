# Canonical Seal Terminal Contract

## Contract and Scope

The canonical cursor owns the original source, traversals, edit and retirement through counted/framed SHA256 sealing. Ready with an original is already idempotent Complete. A successful take transfers the exact original Box and digest once; terminal_is_empty then becomes true, while phase remains Ready and closing false. next_demand correctly quotes zero there, but advance rejects the state through the missing-traversal invariant. Cancellation empty polling already returns Complete. The store NativeBatchDigest wrapper legitimately polls its retained cursor until independently closing its frame; the cursor must recognize its own actual terminal custody rather than fabricate another traversal.

Only production change: canonical seal advance terminal guard accepts actual terminal emptiness independent of closing. Nonterminal traversal validation, quota admission, original source ownership, one-shot take and digest validation remain strict. No wrapper change currently needed.
