## Redesign (compute pool)
- Worker model: job callbacks run only on the original caller (`WorkerJobSessionAdmission::advance` then `MountedWorkerJobSession::pump_one_for_interactive_turn(cx)`); the pool no longer submits or pumps sessions. `ComputePool::run_job`/`run_io` keep the pool only for blocking I/O.
- New `ComputeOriginalCaller` (`🛎️services/🧮️compute/🎟️original-caller/🦀️.rs`, exported): production sibling of the job fixture caller. Owns the paid cancellation root, `JobPayloadAuthority` and `OriginalCallerSourceParent`; `turn`/`turn_paid` lend a genuine `StepContext`, `turn_paid` debits the `ComputeRetainedRecipient` wallet with the actual per-turn receipt (also on failure); `admit_alias`, `retire_paid`.
- `ComputePool::run_job(runtime, ctx, caller, job, params, wallet, completion, recipient)`: staged birth (one admission action per turn, `Ok(false)` + untouched `job`/`params` when a turn cannot be funded), then pump/ack/resume per turn. Dropped params: `scope`, `retained`, `control` (identity now from `ctx`).
- `ComputeJobCompletion` now holds `WorkerJobSessionAdmission` + `Option<MountedWorkerJobSession>`; `close_step(cx)` ladder: fault, session (cancel-alias witness / `close_step`), permit, admission.
- Router caller `drive_router_effect_job`/`run_router_effect_job` (public signature unchanged) builds a `ComputeOriginalCaller` from its grant, closes completion, leftovers (job/params) and the caller through paid turns.
- Tests ported: 3 compute-pool async tests + quote test; the "stopped pool => WorkerLost" tests were premise-obsolete (callbacks no longer touch the pool) and now assert the job completes on its original caller.

## Post-turn-relay port (written, type-checks, behaviour UNVERIFIED)
- `🔀️post-turn-relay`: sessions are now born by `GuestRelayAdmission<J>` (new, `🧾️mounted-session-types-and-registry-struct`): alias of the wake driver's original root via `admit_original_cancel_alias`, `BatchJobParams` built from the driver context identity/clock, then `WorkerJobSessionAdmission::advance` per registry opportunity; owner variants `Admitting`/`AdmittingProbe` replace `Rejected`; `GuestRelayRefusedSource` and `admit_guest_relay_session` removed.
- Stepping and acknowledgement run through `GuestRelayWakeDriver::dispatch_step` + `finish_turn` (`dispatch_returning`), `step_guest_relay_owner(owner, cx)` uses `try_step_on_original_caller`; `pump_close` returns the cancel alias via `close_relay_session` (witness check) before the physical close. Admission refusal detaches the slot for the reaper and returns the failure.
- Publication (`📡️relay-attempts-and-publication`): `advance_initialization`/`append_original`/`seal`/`close_step_granted` go through `receive_original_retained_work`; `close_original_source` returns `RetainedWorkOutcome`; cold/probe jobs wrap `step_callback` in `InteractiveJobStep::from_callback`.
- Trade-offs: an `Idle` step relies on the previously registered session wake (as before); an occupied driver (`dispatch_step` -> `None`) re-wakes immediately.
