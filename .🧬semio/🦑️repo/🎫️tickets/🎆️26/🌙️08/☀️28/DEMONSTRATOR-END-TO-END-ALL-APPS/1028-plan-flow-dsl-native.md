# Plan: make the persisted flow model DSL-native (1028, executor flow)

Goal: `FlowHostSnapshot` satisfies `NativeReceive<RecordValue> + BorrowedDslRecord + ArtifactDsl + Send` by derive, so `FlowSnapshotPackProducer::SnapshotOpen = OriginalRecordMemberSnapshotOpen<FlowHostSnapshot>`; the twin (`FlowHostSnapshotDsl`, `WidgetDsl`, `TreeDsl`, `NeuronNodeDsl`, `SynapseDsl`, `ValueDsl`, `component_dsl`, `*_to_dsl/*_from_dsl`) is deleted. Greenfield: no adapters.

## Facts (checked)
- Opener parses the member pack into a `RecordValue` in the DSL grammar and calls `S::begin_receive` on it. Grammar today = twin (`io/text/snapshot/*`): widgets are statements (`WidgetDsl`), `params`/`preview` are `Option<BTreeMap<String, ValueDsl>>`, `expanded` is `Vec<String>`, synapses are wire-literal rows (`a.p -> b.q`), Cluster `tree` is a nested `TreeDsl` block and `flow` an untyped `DslValue`, layout is a `BTreeMap`.
- Model types derive only `ToValue/FromValue/CanonicalJsonTree` (JSON shape). `Dictionary`/`Value`/`Atom` (neural engine, hand `ToValue`/`FromValue`, untagged) have `RetireOwned` but no `NativeReceive`/`DslField`/`BorrowedDslField`. `Neuron.tree: Option<Box<Tree>>`; `Box<T>` has `RetireOwned` but no `NativeReceive`. `OrderedMap<V>` has `NativeReceive` (needs `V: NativeReceive<dyn NativeValueSource> + Sync`). `OrderedSet` does not.
- Derive `NativeReceive`: no generics, supports flatten/default/rename/tag/scalar enums and `#[value(receive_recursive)]` (draw `DrawingLayerNode` is the recursive precedent; the cycle goes through `Vec`).

## Target grammar (flow text/pack, version bump of the artifact envelope)
Model types are the grammar; rename to match derive output, no twin.
- `FlowHostSnapshot { schema, camera: CameraJson (#[dsl(block)]), widgets: Vec<Widget> (#[dsl(statements, block)]), synapses: Vec<SynapseSpec> (#[dsl(table)]), layout: OrderedMap<WidgetLayout> }`.
- `SynapseSpec { id, from, to, from_port, to_port }` becomes a plain table row (the wire-literal sugar `a.p -> b.q` is dropped; no migration).
- `Widget` = `DslEnum`; `params`/`preview`: `Dictionary` printed as an object (`key: value` map, recursive `Value`); `expanded: OrderedSet` printed as a string list; `Cluster { tree: Tree (block), flow: FlowGui }` typed (replaces the untyped JSON escape hatch) which requires `FlowUi/FlowNodeGui/NodeChrome/FlowPreviewGui/FlowChannelRef` to derive `DslRecord/DslEnum/NativeReceive`.
- Neural engine: `Tree`, `Neuron`, `Synapse` derive `DslRecord` + `NativeReceive` (`receive_recursive` on `Neuron` since `Tree -> Vec<Neuron> -> Option<Box<Tree>>`); `Dictionary`: hand `NativeReceiveMap<OrderedMap<Value>>` + `NativeMappedReceiver` (label precedent); `Atom`: hand `NativeScalarValue`; `Value`: hand shape-selecting receiver (record -> `Dictionary`, scalar -> `Atom`, modelled on `NativeOptionReceiver`); `DslField`/`BorrowedDslField` for these by hand.
- Value crate (generic): `impl<I,T: NativeReceive<I>> NativeReceive<I> for Box<T>` via `NativeMappedReceiver` + `NativeReceiveMap<T> for Box<T>`; `NativeReceive` for `OrderedSet` via `OrderedMap<()>` mapping.

## DECISIONS (grammar; helpers follow these)
DECISION D1: `Dictionary` (and `Value`/`Atom`) bind as `Shape::Value` (free-form nested value, wire form = JSON object/scalars via existing `ToValue/FromValue`). `DslField for Dictionary` = like `DslField for DslValue` (shape Value, `to_value` -> `FieldValue::Value(ToValue::to_value(self))`, controlled variants via `ToValue::to_value_controlled`/`FromValue::from_value_controlled`, `projection_view` by rank navigation over `Dictionary::entry_at_rank`, `retire_decoded` = existing `retire_decoded`). `BorrowedDslField::SHAPE = BorrowedShape::Value`. Lives in the neural model crate (add dep `semio-framework-dsl-record`). The receivers I wrote (`⚙️engine/📥️receive`) read exactly this `FieldValue::Value(DslValue)` source (FieldValue delegates to DslValue's `NativeValueSource`).
DECISION D2: `Tree` (and `Neuron`, `Synapse`) are NOT given a typed nested DSL grammar: a cluster's `tree: Tree` and `flow: FlowUi` bind as `Shape::Value` too (same trick as the old twin's untyped `flow`). `DslField for Tree`/`FlowUi` = via `ToValue/FromValue` exactly like D1 (`projection_view` may return the default refusal; the borrowed projection of a cluster is not on the print path). Their `NativeReceive` derive reads the same JSON names (neurons/synapses, id/kind/params/tree, fromPort/toPort) as their hand `ToValue`.
DECISION D3: `OrderedSet` binds as a list of strings (done in dsl-record, see PROGRESS 3a). Its `NativeReceive<I>` (native-owned crate, next to `🗂️map`): `NativeSequenceCollection<String> for OrderedSet` with `Storage = Vec<String>`, `finish` = collect into the set; receiver = `NativeSequenceReceiver<I,String,OrderedSet,SequenceRows>`.
DECISION D4: `OrderedMap<V>` binds as `Shape::Map` (done, PROGRESS 3a). `FlowHostSnapshot.layout: OrderedMap<WidgetLayout>` keeps its type.
DECISION D5: synapses are plain table rows (`SynapseSpec { id, from, to, from_port, to_port }`, `#[dsl(table)]`), the wire-literal sugar is dropped; fixtures regenerate.
DECISION D6: `Widget` derives `DslEnum` (statements, block) + `NativeReceive` + keeps `ToValue/FromValue/CanonicalJsonTree`; field names follow the existing `#[value(...)]` attrs; defaults via `#[value(default)]` (`Dictionary`/`OrderedSet`/`String` have `NativeDefault`; add `NativeDefault for OrderedSet`). `FlowHostSnapshot` derives `DslRecord` + `DslArtifact` (`#[artifact(id="flow.flow")]`, `#[dsl(layout="lines")]`) + `NativeReceive`, replacing the hand `ArtifactDsl` impls.
DECISION D7: `FlowUi/FlowNodeGui/NodeChrome/FlowPreviewGui/FlowChannelRef/WidgetLayout/CameraJson` derive `NativeReceive` (+`DslField` via value, D2 for `FlowUi`).
