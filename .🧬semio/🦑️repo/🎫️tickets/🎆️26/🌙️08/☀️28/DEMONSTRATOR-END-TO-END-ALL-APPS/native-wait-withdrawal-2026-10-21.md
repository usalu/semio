# Native Maintenance Wait Withdrawal

The optional third maintenance argument is a synchronous predicate over immutable `{version:1,availableBytes}` DATA. Request DATA remains unchanged. Ordinary deferred admission remains `{acquired:false}`; only exact privately signaled withdrawal after acquisition/queue cleanup settles returns `{acquired:false,withdrawn:true}`. It grants no image, lease, port, control or capacity.

The Native owner saved closed observation/result and neutral-case schemas before implementation. The shared helper derives a zero-renewal child control with a private cancellation signal, observes only progress for its own exact resource, validates/detaches/freezes DATA and rejects nonboolean predicates. It checks Original cancellation/deadlines before treating a private stop as withdrawal. It explicitly drains the observer continuation even when the lease continuation races interruption; late parent failure releases any already acquired lease and retains release errors, including a primary thrown undefined.

The persistent macOS backend brackets actual space reads with privately captured receipt, ancestry, backing, root and volume facts in its exact maintenance gap. Fixed directory backends bracket the same DATA with their existing captured physical/mapping identity checks. Both bind successful leases and writer proofs to the actual derived control. Withdrawn receivers remain consumed/closed; the graph owner must use fresh ordinary shared admission and verify the floor independently. No Native floor, budget, receipt, writer eligibility or foreign request changes.

The existing maintenance suite statically registers the new Native wait tests:18 neutral cases with actual helper AST, owned schema validation, Ajv and SQLite; two actual backend AST/control binding and physical bracketing comparisons; and an extension of the real macOS retained-reader physical case. That proof withdraws an actual queued writer while another actual reader remains live, checks the writer body never runs, independently verifies the retained reader through Node SQLite locking, and opens a later shared receiver. Runtime separately owns graph-level fresh-SH/revalidation race proofs and bounded churn handling.

All defining sources are saved for independent review. No native check has executed this boundary, and no passing claim is made.

Independent review identified the late own-withdrawal counterpart to late parent cancellation. Two neutral vectors were saved first; after draining the observer, the helper now checks Original control and then its derived child. A private stop arriving after acquisition therefore releases the just-acquired lease before returning withdrawn; a release failure remains an error. The queue normally serializes this path, but the Native contract now closes the race explicitly.
