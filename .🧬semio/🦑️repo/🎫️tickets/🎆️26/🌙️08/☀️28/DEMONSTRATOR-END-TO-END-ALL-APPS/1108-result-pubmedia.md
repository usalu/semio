## BLOCKED: media snapshot encode (document-media 20 errors)
`🎞️media/🛫️intrinsic/🦀️.rs` and `💥️fault/🦀️.rs` drive `NativeSnapshotEncodeOwner::{receive,receive_nested}` with a wallet + synchronous `BorrowedProjectedPackCursor::{advance_intrinsic,close}`. Both cursor calls now need a `RetainedAllocationEffect`, which io-control only creates inside `NativeEncodeControl::effect_allocated` (resumable, marker/failure slots, `Option<()>` pending). `receive` is now `receive(&mut out, &mut |slot,result,marker,failure,native,wallet| ..)`; `NativeSnapshotFailure::into_value_error` is gone (use kind()+message()+retained_progress()); `IntrinsicMediaEncoding` needs `derive(RetireOwned)` instead of the hand cursor. A faithful port is a redesign (resident resumable encode job with marker/failure slots, as the iocontrol/packout lanes sketch in 1108-result-iocontrol.md), not a mechanical edit. Public API affected: `MediaArtifact::encode_intrinsic`, `receive_media_output`, `receive_media_artifact_fault`, `copy_media_text_parts` (only tests + wp2 mounts call them).
