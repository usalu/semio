# Bounded Gumball Selection

Root owns the same-base gumball splice. This first schema defines the selection classifier and component grouping used by that splice. It preserves the actual cold rule: no parseable component selects basic mode; any parseable component requires component_group on the entire ordered selection. Analytic handle/revision equality and conflicting duplicate component labels remain observable.

The new owner will scan bytes, parse bounded numeric fields, compare original borrowed spans and maintain a sorted component frontier under the initiating physical source binding. It must retain all allocations and metadata until explicit closure. No native validation or completed gumball splice is claimed here.

## Selection Cursor

The mounted P3 retained_gumball_selection now owns this prerequisite. It pins OriginalSourceBinding, original ids slice and current/first String buffers. Parsing uses bounded 64-byte structure scans, at most 20 numeric bytes per event, fixed 64-byte analytic hash validation and bounded borrowed-span comparisons. The actual ComponentTarget is reconstructed as a borrowed view only after genuine caller authentication. Cursor close retains and retires the component allocation before releasing borrowed-source metadata; Drop is unconditional terminal-only.

## Splice Overlay Plan

The full splice remains pending. Its planned source is the immutable context-overlaid scene base plus private generated-widget, rewired-source and preview-off metadata. Every freshly generated basic transform has the same operation suffix and kind, so selecting it again reuses it; repeated original-source selections reuse the deterministic generated id. Therefore a base synapse can be rewired once within one gesture, fresh anchor links stay unchanged, and a full per-gesture host clone or fake contiguous FlowSnapshotSource is unnecessary. Existing FlowAuthoringWork AddWidget can build default native Widgets against the actual immutable base after checking the private overlay for collisions. Original preview-off widgets can clone only their genuine owned base projection. Every open gesture derives from this same immutable base; no previous gesture working scratch becomes the next gesture source. This is design evidence, not an implemented full splice or native proof.
