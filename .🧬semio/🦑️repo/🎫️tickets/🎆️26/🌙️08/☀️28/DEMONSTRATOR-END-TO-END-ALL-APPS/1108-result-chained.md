2. Quote bug (store/read/retirement, shared file of snapshot-read): the returned-lease quote was capacity+depth only. `admit_arc_lease` (via `admit_typed_controlled_retirement`) charges copy = `size_of::<Option<ArcLease<T>>>()+size_of::<ControlledRetirement<ArcLease<T>>>()`, capacity = the frame, depth 1. New `arc_lease_admission_demand::<T>()` states exactly that; `SnapshotReadRetirement::demands` and `artifact_retirement_shared_lease_birth_demands` (value/snapshot/read, +1 parent depth) use it. Test: `returned_arc_lease_quote_equals_receipt_and_a_short_axis_admits_nothing` (replay operation native tests) asserts receipt copy/capacity/items == quote, heap == capacity, and one byte short on items/copy/capacity admits nothing and allocates nothing. `drain_returned` split into `close_active`.
3. Unpaid reply handoff (`invoke_original`, value/control/contract/authoring): a child that spent past its extent leaves `transfer_reply_into` unfunded (`Ok(None)`) or refused (`Err`). Both arms now record the handoff unit with `effect.performed(ORIGINAL_INVOCATION_WORK)` before taking the reply, so the receipt carries child + handoff and the Work commit reports the whole overshoot (typed WorkLimit "authoring work commit was refused"). Refuse-before-run is impossible: `performed` records before it checks, so the overshoot is unknown until the child returned. Also fixed a latent bug: every exit except `into_producer` panicked in `OriginalEffectAuthority::drop` (the old `Err` arm always did); the tail now always disarms the authority and returns the deferred refusal. Test `an_overshooting_child_still_pays_the_reply_handoff` (spend 2, 3, 5 against a narrow max of 2: receipt = spend + 1, commit refused above 2).
   Replay-op test D (`original_retirement_preserves_child_and_work_commit_failures`) encoded the old unpaid handoff (commit passed at actual 2). `retire_with` now stashes the child's turn outside `with_effect`, so the child failure (primary + workRefusal, `turn.work == 2`) survives the refused commit, and D asserts the commit refusal via `OriginalLawCaller::refusal`.
