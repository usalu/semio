--- 4. space crate: real zip store wiring ---
File: 🧰️framework/🛍️products/💻️os/🔨️modules/🪐️space/⚡️implementations/🦀️rust/📦️lib.rs
Dependency direction confirmed via Cargo.toml: space depends on store (not the reverse) — so the
bridge lives in space, calling store types directly; putting it in store would need store -> space,
a cycle.
Added new region 🔖️ZipStoreBridge (nested inside 🔖️Zip, right before its #endregion):
- real_artifact_reader(&HashMap<String, store::DocumentPackFiles>) -> closure matching
  export_collection_zip's read_artifact signature.
- real_blob_reader(&dyn store::BlobStore) -> closure matching read_blob's signature.
- import_document_artifact::<P, Operation>(pack_bytes, spr_bytes) -> reconstructs a real
  store::DocumentStore<P, Operation> via store::parse_document_pack (generic — this crate never
  knows a document artifact's concrete schema type, only the schema string, so callers supply P/
  Operation at the call site, same genericity store::parse_document_pack itself already has).
- import_blob(&dyn store::BlobStore, &store::BlobRef, bytes) -> puts bytes, verifies the freshly
  computed hash matches the recorded BlobRef (tamper/corruption check).
Added test zip_export_import_round_trips_real_store_documents_and_blob (🧪️ZipStoreBridgeLaws region):
builds a REAL store::DocumentStore<SpaceProjection, SpaceOperation> nested-space document artifact
(applies an edit + commits a checkpoint), a real blob via a small in-crate TestBlobStore test double
(store::BlobStore impl, non-cryptographic hash — this crate has no framework_hash dependency and
doesn't need one for a test double), exports via real_artifact_reader/real_blob_reader, imports back,
and asserts:
  - collection structure round-trips exactly (imported.collection == original)
  - artifact pack+spr bytes are byte-IDENTICAL to the original snapshot_pack() output
  - reconstructing a DocumentStore from the imported bytes yields an equal projection to the original
  - blob bytes round-trip byte-for-byte, re-import into a fresh blob store recovers them
  - export -> import -> export stays byte-stable with this REAL data (not just the pre-existing
    fixture-string test's mock bytes) — the same law zip_export_import_export_is_byte_stable already
    proved with format!()-based mock bytes now holds end-to-end.
