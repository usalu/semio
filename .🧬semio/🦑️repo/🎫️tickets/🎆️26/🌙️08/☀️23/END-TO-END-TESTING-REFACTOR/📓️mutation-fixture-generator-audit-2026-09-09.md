# Mutation Fixture Generator Audit

This bounded, read-only audit asks whether the plugin fixture tree repaired earlier and the 14 current SPR malformed Rust paths are regenerated from repository writers or templates. It examines only those semantic owners and their direct module callers; it does not claim a repository-wide generator census.

## Result

No writer or template that emits either `#[cfg(test)]` bodies or a nested `🧪️tests/.../🧬️mutations` tree was found in scope. The inspected paths are static Rust/JSON sources mounted by literal `#[path]` and `include_str!` references. Therefore the current evidence supports concurrent source authoring, not a known persistent generator that will restore the malformed layout.
