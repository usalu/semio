Goal: lowpoly editor working end to end in the react playground (port 6078): boot, selection
(object/vertex/edge/face, pick/rectangle), mesh tools, transforms, undo, paint, import/export of real
low-poly meshes. Evidence only from observation.

Round start commit: a4cda597ea (2026-09-17 01:10 +0200).

## Log

- Playground row lacked `app` (layout fault #1) → added `app = "s.lowpoly.lowpoly@1/*#editor"`.
- No `command_from_action` (layout fault #2) → added `args_bridge` in `✏️editor/🦀️.rs`.
- No store owners/disposers for any lane (raster/gen3d fault) → added document/config/draft owners,
  transient preparation + root retirement, presence retirement, all five disposers (gen3d pattern).
- **Selection was dead end to end** (explorer + code read): the Model scene set no `domainId`, no
  `targets`/`selectionMode`/`componentIds`, and `World3dHost` sent face/edge/vertex picks and
  component marquees only through the legacy `worldPick`/`setSelection` lane lowpoly never handles.
  Fixed both sides:
  - host (`World3dHost/🟦️.tsx`): under a domain, component picks, component hover and component
    marquee commit go through `interactionSelect`/`interactionHover` with target id
    `<instance interactionId>.<granularity>.<componentId>`; lasso reports `method: "lasso"`.
  - plugin: scene binds `domain_id = "mesh"`, instances carry `interactionId = lowpoly-document.<id>`,
    selection JSON carries targets/selectionMode/ids/componentIds/gumballActive/gumballTarget from the
    live `InteractionView` (`render_with_request_context`). Active object follows the selection
    (`view::active_object_for_selection`), so a pick on another object edits that object.
- **Geometry was not persisted** (by design of the 08/12 round): `LowpolyObject` held only a content
  hash handle; content lived in a session transient cache, so undo/redo (`StaleMeshWorkspace` → silent
  no-op + "Failed to load lowpoly document"), page reload and any import lost the mesh. No guest can
  resolve child documents. Fix: `LowpolyObject.mesh_content` persisted by text codec (7th slot, 6-slot
  legacy decodes) and pack format 2 (format 1 decodes); `LowpolyObjectPatch.mesh_content`; create-mesh /
  delete-mesh diffs set it and their inverses carry the base content; engine reload prefers it. Schema
  facets (ts/json/proto/graphql, diff, create-object) updated.
- Host `setCamera` shape `{windowId, camera:{position,target,zoom}}` and gumball `{mode, ids:[string]}`
  handled by the bridge.
- IO audit: OBJ/PLY import only read lowpoly's own embedded DSL comment; real third-party meshes are not
  importable. Kernel has `HalfedgeMesh::from_faces` (n-gons). Next: real geometry import/export.
