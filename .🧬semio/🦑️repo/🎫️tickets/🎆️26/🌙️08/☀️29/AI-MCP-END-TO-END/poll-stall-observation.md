# Poll Stall Observation

The rebuilt Note guest returned a cold-open wall-budget fault while the host was waiting for capture. The last state reported stage 0, a 144-byte header and 1,023,980,902 spent VM instructions. A separate larger-batch trial reached frozen Poll history stage 10. A final snapshot cannot distinguish a persistent unpaid step from work that simply reached the deadline at that frontier.

Set `SEMIO_MCP_POLL_TRACE=1` when running the ticket's official SDK probe. It forwards the switch and inherits the gateway stderr. The host emits the first eight Poll drive steps and every 8,191st drive step as `[DEBUG]` lines. Each row records elapsed wall time, both session stages, committed issuer History appends, held loan purpose and epoch, the frozen receipt frontier, and the committed treasury, drive, work and interpreter balances.

When a sampled step already enters the acknowledgment callback, the trace copies the current Poll phase, receipt kind, retained grant and work balance from that callback. It reports whether the existing acknowledgment still needs control and whether the callback ran. The copied diagnostic is formatted and written after Source handback. The trace uses the normal scheduled turns and immutable balance reads.
