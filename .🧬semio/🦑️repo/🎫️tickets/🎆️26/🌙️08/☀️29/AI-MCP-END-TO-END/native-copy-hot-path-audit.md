# Native Copy Hot Path Audit

The existing live WFC sample at first Input reports 168 interpreter `advance_scalar` frames and 63 `memmove` leaf samples, 38 immediately associated with return-budget snapshot/remaining or source grant. This is sampling evidence of host CPU cost, not an elapsed-time benchmark or evidence that VM work, receipts, or stock consumption can be reduced.

`OriginalReturnBudget::origin()` returns `Option<I>` by value. `snapshot()` selects this value and only reads its grant and fuel; `is_bound()` also invokes it just to check presence. `OriginalReturnSourceInput` contains identity, clock, grant, spend and work fields, so this copies more than the observations require. A private borrowed selector can provide `Option<&I>` to these two reads. Preserve snapshot’s special selection of the new origin when commit exists and prior does not, and preserve `is_bound()`’s existing committed/prior visibility; they are not interchangeable. Do not change the existing owned origin API where ownership is required.

`StepContext::retained_grant()` computes the unreserved current progress and `original_source_total_grant()` computes the same expression again. A private helper accepting that already-computed progress can remove the duplication while keeping the public method and all live budget observations. Do not cache remaining values across calls: mutations to spend, work, held currencies, source renewal, or failure can alter them. `raw_remaining` and `remaining` differ by holds; preserve both and their existing refusal/error order. These are candidate host-only changes, with no demonstrated elapsed speedup yet.

Before accepting either, compare exact grants, fuel, errors and consumption/hold provenance against the existing language-agnostic escrow conservation fixtures and independent arithmetic oracle across zero, exhausted, overdrawn, held, renewal and pending-commit states; include random boundary cases and actual typed Note and WFC completion. Measure matched native profiles and elapsed times with the same compiler configuration and workload. The existing optimized-host experiment may already eliminate these copies, so do not assume savings from the sample alone.
