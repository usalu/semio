# WFC Cancellation Fixture Audit

The 64 × 64 cancellation input has a single periodic 1 × 1 black sample, hence one 2 × 2 pattern. It does not guarantee an active observation. The harness delays its first `inference_events` call by 10 ms, while the real worker can advance independently through preview and completion; even a larger or multi-pattern input cannot establish a scheduler or timing guarantee. The bitmap worker stages actual previews during compilation and on child completion, but their availability does not ensure the job remains active when polled.

For meaningful multi-pattern work, the existing bitmap inference unit fixture `stripes()` uses two palette indices in alternating columns, 2 × 2 windows, symmetry 1 and periodic input. A minimal schema-valid input is width 2, height 1, pixels `AAE=`, black and white opaque palette, patternSize 2, symmetry 1 and periodicInput true; wrapped windows are `[0,1,0,1]` and `[1,0,1,0]`. Keep an even 64 × 64 output and seed 11. This increases work but remains a timing-dependent integration fixture. For deterministic cancellation, inject a test-owned scheduler barrier after a real progress publication and before the next real worker turn; observe the active event through MCP, issue cancellation, then release the barrier so normal cancellation handling runs. No mock progress, altered solve result, worker policy changes, or pre-cancellation are needed. Compare both original Pack and SPR bytes before and after.

Existing language-neutral vectors include `⚙️engine/🔍️search/🏃️batch/🧪️tests/🧫️phase/🔣️.json` (one-fuel yielding) and `⚙️engine/🧪️tests/🧫️fixtures/🎲️solver-contracts/🔣️.json` (grid assignment contract). The bitmap inference unit test independently enumerates input and output windows in `expanded_input_windows` and `output_windows`, then checks all solved windows against the input window set. This is an in-repository property validator, not a third-party implementation: no third-party validator was established in this audit. The identity-symmetry stripe vector can additionally be validated by any independent base64 decoder and direct 2 × 2 wrapped-window enumeration.
