# MCP Note Export and Snapshot Replay

The Note editor publishes `io.artifactSchema = "note.document"`. Its explicit media output and IO port lists are empty in both the committed descriptor and the optimized guest descriptor. The framework supplies `artifact:out` to every app through `AppIo::artifact_out_port`, and the headless gateway's `installed_artifact_kinds` includes that implicit output for every editor. The trigger to change the existing gateway route would be a reproduced error on the exact live Note session.

The owner-side `VcsArtifactApp::produce_media` handles `artifact:out` through `document_archive`. The gateway issues a stepped archive load to the resolved editor, followed by the guest's `MediaOut`. The guest's retained exchange handles that command, and the host's retained frame receiver admits frame tag 7 as `Media`. The MCP untrusted envelope holds base64 of the resulting UTF-8 `pk:` string. Its inner base64 decodes as the archive already supported by the framework's `decodeDocumentArchiveBytes` codec. The separate retained download interface uses `SubmitMediaExport`, `PollMediaExport`, and `TakeMediaExportChunk`.

The archive parent Pack is immutable genesis. `document_archive` delegates to `print_document_pack`, which reads `envelope.vcs.genesis.pack()` and encodes the current journal separately as SPR. The archive retains owned member pairs. The SPR includes the live history cursor and the transition journal, so neither parent Pack equality nor full parent-pair equality establishes the materialized undo/redo result.

`note-mcp-replay.rs` uses the canonical `parse_document_pack` and Note snapshot encoder. The parser reinstates the saved history cursor and replays Note's real typed mutations before JSON encoding. Each input to its persistent process is a line containing the exact `untrusted.content.packBase64` and `sprBase64`, separated by one tab. It returns one JSON document per line and retires the parsed owners. Deep JSON equality checks that the baseline equals undo and that invocation equals redo and rollback. The invocation check can independently verify precisely one new block, with the expected kind and coordinates from the real Add Block input. The archive's parent pair can also be fed to the same oracle.

The ticket's direct linker resolves the existing native MCP Cargo fingerprint closure, compiling only missing domain libraries in the ticket's generated directory. The source also has a standard ticket-local Cargo manifest. The isolated repo Cargo gate was canceled when the host lacked its requested free-space reserve and started collecting caches. Live acceptance remains distinct from compiling the oracle or reading the owner's source.

The direct native link completed successfully on macOS arm64 against the existing MCP Cargo fingerprint graph. The executable starts and exits cleanly with empty input. The production Note schema, diff, mutation families and complete mutation registry were compiled from checkout source in ticket scratch. No files in the native-host Cargo tree were written.

Run the direct linker with `repo tools exec bun -- <ticket>/note-mcp-replay-link.ts`. Use the executable path it prints as the existing journey runner's `--note-replay=<binary>` value. To replay a retained live capture, run `repo tools exec bun -- <ticket>/note-mcp-replay-verify.ts <binary> <capture.json>`. The capture contains the artifact ID, actual Add Block arguments, and exact baseline, invoke, undo, redo and rollback Pack/SPR pairs. The independent verifier checks block identity, kind and coordinates and compares the remaining materialized Note content. The committed editor descriptor and the owner’s Add Block command both supply text and origin coordinates when arguments are omitted. The strict MCP client’s minimal input supplies the text kind and omits both coordinates, so the verifier expects the inserted block at (0, 0).

The standalone executable links only to system libraries. After verifying that it starts, the direct-link workflow releases the intermediate Rust archives. The first successful link’s intermediates occupied 1,963,042,616 bytes and were removed without touching the executable, inputs or the native host.

Both ticket TypeScript helpers passed Bun transpilation. The observed exact SDK run at the default limits reached the owner’s typed create and received a Poll copy-budget refusal before an artifact snapshot. The widened run reached the guest Poll wall budget. Those runs establish no export or undo/redo result. No capture from either run was substituted.
