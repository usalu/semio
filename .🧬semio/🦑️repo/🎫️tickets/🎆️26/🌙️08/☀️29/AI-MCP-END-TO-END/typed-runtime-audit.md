# Typed Runtime Audit

Read-only source audit; no runtime execution or Cargo writer lane was used.

- The Note journey creates the typed artifact, exports and snapshots it, prepares `note.s.note.note@1/*#editor.addBlock`, invokes it, checks that the Pack/SPR pair changes and the head advances, then checks undo and redo through head IDs and member counts. The owner's add-block unit test requires exactly one semantic edit and one added text block. The journey does not inspect that semantic projection, nor snapshot after undo or redo. A history implementation that changes head metadata without replaying the intended content could pass. Compare the projected block count/content before invoke, after invoke, after undo, and after redo; raw SPR equality is inappropriate if history records legitimately change. The restart check compares the post-redo Pack and SPR pair across process restart, but does not independently establish that redo restored the block.
- The WFC solve fixture has a single input pixel and a one-entry palette. Bitmap inference resolves the bound canonical document, performs sample/extract/topology/fixed, child solve, decode and retained output publication. The expected `AA==`, `false`, `[0]` is consistent with its one-pattern 1×1 case, but the real gateway run is needed to establish the owner path and receipt budgets. Watch the first failure separately at artifact creation, document binding, owner job construction, child solve, output publication and paid cleanup.
- The cancellation fixture only expands output to 64×64 with the same one-pattern sample. It does not create unresolved search choices. `verifyActiveInferenceCancellationV1` requires observing an active job with at least one progress row before cancellation; the owner emits previews on timing/yield and child transitions, and a fast valid job can finish before the first poll. Such a failure is not evidence that cancellation is broken. Use a deterministic multi-pattern workload or a controlled active-work boundary, and preserve the requirement that cancellation follows observed work and leaves both document byte strings unchanged.
- The isolated WFC probe returns immediately on a failed solve, so its cancellation test is not attempted in that case. The combined journey continues after a failed inference response but records all failed steps. `--check-initial` verifies malformed import reports the specific owner validation error and leaves the requested ID absent; a budget refusal with an absent ID does not establish validation.
- The Note restart check runs only after a passing redo step; it checks exact persisted Pack and SPR after restarting the gateway. A failed earlier step still marks the overall run failed, even if redo happened to pass. The restart itself is not a separate returned step: an exception aborts the invocation, as expected for a strict gate.
