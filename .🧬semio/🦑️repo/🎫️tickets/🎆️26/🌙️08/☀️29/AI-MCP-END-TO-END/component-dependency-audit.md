# Component Dependency Audit

The existing standalone unit plans use `cargo build -p semio-hub-{note,wfc}-component --target wasm32-wasip2`, not test mode. The Note composition explicitly declares DWG, DXF, PDF, PNG and SVG under normal dependencies. WFC declares its five artifact aggregate crates, which themselves declare stdio formats. Some packages named `tests` are normal dependencies: for example, the WFC 3D aggregate unconditionally reexports its `tests` crate's artifact definition, app, languages, standards and viewer. These crates therefore currently own production catalog symbols, despite their names. Removing them or blindly moving them to dev-dependencies would break the existing public surface. The declared dependency closure is broad and warrants a separate catalog/ownership audit; the evidence does not justify an untested dependency edit as part of the MCP qualification.
