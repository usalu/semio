# Guest Compiler Input Snapshot

The active Note component build resolves `🌎️hub/Cargo.toml` from the live checkout, compiles a `wasm32-wasip2` CDYLIB, and explicitly disables `RUSTC_WRAPPER`. A Cargo lockfile pins dependency resolution and the target store holds compiler outputs. The repository Cargo input scope admits manifest, working directory, configuration and dependency views. It preserves the original source paths. No path in this entry point gives the in-flight guest build ownership of an immutable manifest and complete Rust source selection. [Guest build entry](wfc-native-diagnostic.ts) [Cargo input scope](../../../../../../../🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/🏃️process/🦀️cargo/📥️dependencies/🟦️.ts)

The repository Native snapshot does materialize a finite hash-checked source inventory in cache storage and leases it through the child. The connected Nx selection requires literal inputs for supported Rust `compile` units. Its compiler recipe accepts one RLIB output. The Note component declares a CDYLIB and uses the Cargo build route above, outside this selection. Cargo offload accepts WASIp2 CDYLIB actions and can ship the inputs of an individual compiler invocation to a compatible remote worker. That path needs the compiler wrapper, the endpoint and its admitted worker. Even for successfully offloaded units, Cargo still resolves its graph before those action snapshots. The active local build bypasses this wrapper. [Offload policy](../../../../../../../🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/🏗️build/🌐️remote-execution/🚀️offload/🧬️schema/🔣️.json)

`repo incremental prepare` uses a read-only Git inventory and copies files into a disposable directory outside the live checkout, then provisions general build tooling. Its inventory and copies occur in separate, cancellable batches. This protects a later invocation from edits made after the copy but offers no coherent selection across edits during the copy and has no contract to adopt an in-flight component build. This audit inspected the code and help without preparing a copy or changing permissions.
