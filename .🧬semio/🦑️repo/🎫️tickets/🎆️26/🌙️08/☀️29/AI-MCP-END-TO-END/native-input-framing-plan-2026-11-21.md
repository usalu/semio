# Native Input Framing Audit and First Slice

## Verified reuse boundaries

* `🧰️framework/🔨️modules/🎒️pack/🌱️intrinsic/🦀️.rs:20` decodes either Pack framing to `DslValue`. Its retained implementation (`🎮️retained/🦀️.rs:16-25,61-107,142-180`) borrows original bytes, uses bounded original effects and requires paid close, but explicitly materializes frames, strings and `DslValue` output. Replacing JSON with this API does not remove the generic tree or typed receive. Its record token cursor and closure are design references, not a drop-in direct receiver.
* `🧰️framework/🔨️modules/🌱️value/🛬️decode/🧳️owned/🧩️record/🌳️source/🦀️.rs:34-60` allows ordinal record keys and actual Source queries, but provides stable borrowed `&dyn NativeValueSource` children and `&String` text. A raw binary or JSON byte range does not implement those stable child/text contracts by casting; it needs legitimately admitted stable projections, or a distinct streaming typed receiver. Its original effect producer (:65 onward) validates Source and turn identity and retains actual replies. Do not replace those checks with a synthetic budget.
* The WIT `ActorInputWire` schema (`🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🧬️schema/🎟️actor-input/🦀️.rs:22,151-216`) represents Poll as `events` plus three shape maxima. Its `to_value` and `from_value` use a generic `DslValue`, and the WIT admission route calls `ActorInputWire::decode` (`⚛️reactor/🎟️context/🎟️admitted-input/🦀️.rs:75-86`). It does not contain the eight frozen request fields needed for Core narrowing. It cannot directly replace owned-Core Poll or prove its custody lifecycle.

## Recommended next slice

Keep the pending eleven-scalar tuple change as an independently measurable baseline. For a larger reduction, specify one owned-Core schema envelope with a fixed, checked Poll header (eight little-endian u64 and three u32 fields) and an explicitly length-delimited JSON payload for events and pages. It is a coordinated wire cutover, not an interpretation of the existing WIT format. Keep the entire input allocation as the original borrowed Source; the suffix is only a subordinate projection. Read the fixed header with a dedicated resumable receiver that pays actual bounded reads and writes, checks extent, tag, integer conversion and payload boundaries, then constructs the existing typed `PollRequestLimits` and applies existing live `narrow`. Feed the suffix to existing JSON receiving machinery under the same source binding; only return the full original allocation after all child receivers and cleanup complete. This removes JSON tokenization, generic-tree allocation and twelve record-key lifecycles for the limits subtree; it does not yet remove the event tree. A staged owner must explicitly retain partial header, child parser, typed output, original return place, refusal and retirement, and do no mutation when a grant is denied. Cancellation and errors must close each born owner using real release and work grants. The header is data, never authority.

This is a design proposal, not an existing implementation. The current `OriginalJsonOutputSource<ActorInput>` owns the whole JSON parse; introducing the staged owner, source projection, new schema and paired producer is a substantial change. Retained Pack has useful token and close patterns but does not implement it. Reusing a full binary tree parser instead would still pay generic materialization. Direct typed event decoding could follow only after this first slice proves lifecycle and cost; it would need stable projections or a true streaming receiver for nested variable payloads and strings.

## Measurement and gates

The exact canonical live-grant Note first Input costs 1,352,007,195 scalar instructions for 681 bytes and 21,590 work units; empty 284-byte Poll costs 525,525,103. The 821,493,623 difference from neutral 601-byte Note includes different event fields and numeric policies, so it does not quantify the header or estimate a speedup. Tuple removes twelve key admissions and replaces the prior 86 modeled comparison/finish actions with eleven scan positions, but all eleven scalar receivers and generic parser remain. No speedup for either proposal is measured.

Use schema-first neutral vectors with an independent binary decoder, including maximum widths, malformed extents, truncation, trailing bytes, source replacement, frozen-versus-live limit narrowing and unknown tags. Exercise zero/partial grants, denial/resume, cancellation at each frontier, output return and full paid close. Compare actual Note and WFC rebuilt components through the existing scalar interpreter and real actor admission, same original loan and clock oracle; verify semantics, byte-stable original input, actual physical receipt conservation, return place and cleanup. Updated truthful receipt totals need not equal the old wire receipt. Track first Input raw instructions and clock imports separately for empty Poll, tuple, and header cases. Complete the shard admitted-Core routing separately; neither framing change fixes its incompatible old Poll dispatch.
