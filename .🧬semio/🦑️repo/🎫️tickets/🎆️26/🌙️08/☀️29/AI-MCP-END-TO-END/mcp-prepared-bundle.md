# Prepared Guest Bundle Custody

The exact Note codec sentinel used 500.8 million interpreted instructions in 145 seconds outside the original actor path. Removing actor receipt scheduling alone cannot make that constructor fit the current interactive limit.

## Existing Owners

- `OwnedCompiledGuest` keeps immutable parsed Core under the exact component artifact. `OwnedCodecOriginCell` already provides a single writer, shared progress, cancelable wait, and reset after failure. Its cached payload is a live codec-origin guest after a channel probe and a sentinel `PackSchemaHash` call. It permits a guest fault, retains diagnostics and context/resource counters, and clones the actor wholesale. That is not evidence of a successful context-free bundle preparation.
- `CoreInstanceOpening` creates its own original Source loan and owns every resource addition and fenced close. `OwnedActorStartup` creates fresh host import state, drives the start and channel export, and transfers the exact ready Core together with a fresh final Source loan. The MCP compiled parent already pins the exact artifact across these steps.
- The component model publisher binds compiled bytes and semantic descriptor digests to package, build profile, Wasm target, compiler identity, source tree digest and provenance under retained writer custody. The checkpoint codec knows the Core memory, table, global and passive-segment representation. Its ordinary restore allocates directly and accepts live machines and pending host calls.

## Narrow Implementation

Add an explicit, versioned prepare export in the owned Core ABI for components declaring this preparation capability. Its body invokes the same static constructor and success check used by the normal `plugin_exports!` runtime. Return a scalar readiness status without a guest-handle or allocated response. The compiler publisher invokes the export once under finite execution and storage grants. Feed it only compiler-bound input. The preboot runner denies guest-observable time, randomness, environment, external/file/identity access, operation authority, and host-handle acquisition. Reject imports outside a closed deterministic allowlist rather than supplying placeholders. Preparation must not touch the original actor entry, UI arena, workspace, artifact or user state. Plain plugin exports have a no-op refresh. Extension construction and activation do not qualify without a separate purity contract.

Publish only the quiescent image of the same Core module, with no active machine, pending host calls, imported external references, host resources or runtime context counters. Tables may contain the module's own immutable function indices. Include the image hash and length and the preparation/export/import-validation and image-format versions in the verified model receipt extending the existing exact Wasm, descriptor, mode, target, toolchain, source and package identity. Use the actual artifact publisher and reader lease. The codec cell's state protocol is suitable for coordinating a single preparation, while its sentinel and clone are not.

Open each actor from the immutable image through the existing `CoreInstanceOpening` phases. Quote actual destination capacity, transfer bounded slices of memory, tables, globals and passive segments under the actor's genuine Source, and keep partial allocations with the existing close owner. Publish only when complete. The host creates a fresh import owner, clock, actor identity, return credits and guest Source. Run the actual ChannelVersion and SAB1/SRE1 admission. Only a start proven part of deterministic preparation can be omitted during restore. Bundle installation is already complete by ordinary guest `Once` semantics. Actors never share writable state. This first cut changes first open for eligible actors. Existing codec/export operations retain their own custody, and live command, inference, snapshot and retirement callbacks keep their current authorities.

## Verification

Before publishing a first-party image, run the explicit constructor twice and compare the exact canonical quiescent image. Test a deliberately impure constructor refusal and a model digest mismatch. Use a neutral Wasm fixture checked independently that retains initialized memory and deterministic globals, then prove two actors receive independent mutations, new Source identities, unchanged channel/output, exact paid transfer and cancellation at partial placement. Compare measured cold activation on Note and WFC. The 500.8M codec measurement does not yet prove that either exact constructor passes the deterministic import policy.

## Downstream Implementation and Checks

The interpreter now owns a sealed `PreparedCoreInstance` with private payload and single process identity. Sealing rejects active execution, malformed resources, host references and passive resource changes other than dropping. The issuer is crate-private. `begin_prepared` and `advance_prepared` require the same exact compiled module and the same image identity. A borrowing daughter retains no image owner and cannot publish partial state. It copies logical memory and typed table entries, global values and surviving passive data and element segments in the existing paid Source phases. The reusable baseline is never mutated, and every actor starts with a fresh machine and host call sequence. Closing the actor still retires only its own allocation graph. 

Pinned rustc checked this production source against the exact linked dependency identities without reserving a Cargo target. The neutral Wasm fixture passed 11 Bun/WebAssembly and Ajv assertions for start mutation, independent actor writes and passive preservation or drop. The Rust owner fixture exercises real original caller accounting, two isolated actors, substituted image and module refusal, denied backing, partial transfer cancellation, exact paid heap conservation and retirement. A current full native test execution depends on the producer and admitted build lane.

Both exact existing Describe probes invoke `wasi:random/insecure-seed` early, at approximately 40,116 Note and 5,079 WFC interpreted instructions. Current Describe output cannot qualify as a deterministic persisted image without a separately proven pure preparation path. The core transfer is independent of which lawful producer supplies the sealed resource graph.
