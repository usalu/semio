# Native Admission and MCP Consumer Audit

Source inspection only; none of these observations is a native pass.

The Native Source `prepare_return` currently reserves a ReturnCell and initializes a NativeReturn before the ReturnPlace admission and Source loan succeed. `NativeSources::reserve` itself has no StepContext parameter. Admission's final root allocation receipt includes one item and NativeRoot capacity, but currently reports zero copied bytes for root/slot/output metadata. Existing heap laws compare physical capacity and release receipts; they do not independently validate every typed control-field write. A follow-up should quote/pay actual reservation and root-placement metadata before effects, retain partial cells on denial, and validate cancellation under zero-copy stock. Context is at 262104/262144 bytes; a genuine independent owner split is required before substantial new context APIs. Do not raise the cap, erase tests, hide Source files or add a guessed reserve.

The process UI arena now uses an actual two-phase mount: genuine Source/native admission retains its partial owners; only afterward does body preflight check actual residual currency before UI backing allocation. This avoids inventing a generic 512-item native allowance. Arena opening/closure quotes describe arena-owner work; Root callback/native/failure overhead must remain covered by separately declared currency and actual per-effect checks. Server is auditing phase-only UI transitions and typed metadata copies; do not describe quoted maximum rows as observed writes.

Session address audit: Driver's active execution pointer is scoped to synchronous callbacks, and its admitted roots/return budget use stable backing. Driver can move after scope handback. Pending-issued destinations were the actual address-bound outer field, now moved into stable History. Poll/control/failure destinations remain in actual native homes. Whole Session pinning and an extra parent-funded Session box were rejected after inspection, not implemented. New Session input should be an Event-array JsonWriteSource; Session composes limits from authenticated actual policy and held guest loan.

Actual MCP consumers remain raw GuestInstance / Arc Driver / ordinary event and frame collections until the new Session API is mounted. InstanceOpen currently clones declared capability requests into owned grants and reads asset vectors before the native path. A new borrowed opening view or Source-owned input receiver must preserve real descriptor/asset provenance instead of adding an uncredited event mirror. AppFrame is its own binary channel, not a JSON DTO: do not attach a JSON NativeReceive derive and claim it decodes binary replies. The new bounded reply-prefix classifier removes preliminary full frame materialization; PendingResponsePage still performs the complete binary decode at delivery and remains to be made Source-native.

Final guest close cannot recursively wait for another SRE after every last header handback. The planned terminal protocol is an explicit parent-authorized quiescence-for-Core-retirement barrier: drain all app/output/native/external I/O recipients, disable body/lending, capture the final genuine receipt/SRE/causes and physical header handback, physically retire the exact Core, then use the original strong native-retired proof to forfeit residual control escrow and close History. This must not be represented as an empty SourceClosed reply or zero actual closure progress. Server and Launch are coordinating the typed phase; it is not qualified yet.
