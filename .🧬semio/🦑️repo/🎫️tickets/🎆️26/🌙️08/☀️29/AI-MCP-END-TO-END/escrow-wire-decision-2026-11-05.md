# Cross-Loan Return Escrow Wire Decision

Use a Source-owned, preborn sideband snapshot capsule and keep the fixed receipt maximum 184 bytes. SAC gains one u32 pointer/u32 length to the capsule; TurnOutput carries that pair and its existing output pair. SJH removes redundant operation/generation body words only after writer validation that they equal the authenticated embedded input, and uses the available word for its escrow capsule pair. Host/guest/schema/tests change together; no legacy decoder or guessed identity is permitted.

The Source return budget owns a bounded 32-cell claim table. Each cell is bound to the actual Source identity, actual recipient/destination identity and exact extent, unique claim serial and original issuing actor epoch. Operation/generation come from the authenticated actor Source and must remain the same; the Host records original purpose from the actual origin descriptor. Each row publishes cumulative held, redeemed and unused-released items, copied bytes and work units. Native captures keep their exact sized destination binding. The implementation must use actual existing identity fields or add a genuine issuer-owned identity at Source birth; a pointer from unrelated state or caller-supplied stamp is not evidence.

Snapshots include every live or unacknowledged tombstone row, so nested callbacks do not lose a second transition. Rows may update in place cumulatively; no append-only event queue is required. Closing a claim leaves a tombstone until the exact snapshot/header handback is observed. A slot cannot be reused before acknowledgement. Source claim admission must reserve a free cell before effect and refuse/yield before producer work when capacity is unavailable; any already-admitted outer return destination remains available for that refusal. Source snapshots/encoding need explicit work and copy quotes. Native fixtures must cover all 32 cells and denied admission, rather than assuming one transition per call.

The fixed receipt reports fresh progress/work separately from reserved redemptions. Host validates fresh usage against the current descriptor, diffs cumulative claim counters against its last accepted snapshot, debits each redemption against the claim original purpose, preserves held currency in physical/logical availability, and refunds only authenticated unused release. Missing or refused receipts keep holds. Replay of the same exact snapshot is idempotent; a changed replay or foreign source/recipient/serial/extent/origin fails. Retirement forfeiture remains distinct and requires the genuine physical retirement witness.

The snapshot bytes remain borrowed from their preborn Source owner until fixed-header handback. Host must copy/capture and validate the complete capsule before settlement or acknowledgement. Handback only makes its acknowledgement pending; claim-table reclamation occurs later under an actual funded Source callback. No raw pointer lease may outlive handback, and no resident capsule may be deallocated as caller-owned bytes.

Owners: Guest implements the actual Source table, origin binding, snapshots and guest encoding; Server owns common SAC/SJH wire/schema/fixture cutover plus Host Poll capture; Launch owns Host GuestLedger escrow composition, exact settlement witness, and cold controller consumption. Root coordinates and continues borrowed output writer plus MCP integration. This document is the implementation decision, not native qualification.

## Explicit Source Acknowledgement Header

Deallocate returning proves only that exact export completed. It cannot alone acknowledge Source-held claim tombstones. The coordinated next SRE1 header has 48 bytes: magic/count plus five u64 words for actual Source identity, birth serial, return-budget recipient, publication revision and acknowledged prior publication revision. The maximum snapshot is 4400 bytes with 32 rows of 136 bytes. Core header widths remain 144/152/184, with unchanged export arities.

Guest acknowledgement N requires its exact retained capsule N receiving witness to be accepted on the actual Source under the real paid/prepaid protocol. Host must validate the Source identity, contiguous publications, monotonic acknowledgement bounded by an actually handed-back publication, and issue opaque acknowledgement evidence before permitting row disappearance. This is a design decision under implementation, not evidence that handback works.

## Same-Call Core Reserve and Actual Header Owner

A withheld post-body receipt cannot wait for another guest loan merely to finish its SRE1 snapshot. Core crossings therefore require a structural current-loan reserve before body/claim work. The actual Source scopes the producer beneath the retained/work allowance, freezes and directly encodes the bounded post-body snapshot, and posts only exact actual effects after unlocking. No serialization claim mutates its own snapshot. The current provisional owner now quotes 10 items, 4400 + fixed header bytes + 384 metadata bytes, 2937 work, depth 1; the shared owner function is authoritative and native accounting remains unqualified. Native provider one-item/64-byte laws do not assert a whole Core crossing fits that smaller grant. Producer minima need a separate liveness check.

The actual post-Source fixed-header storage and loan state belong to the Source-owned publisher. Only that real backing can mint a non-Clone exact header-loan after paid write/freeze. The actor retains the prepaid token; exact Deallocate handback produces an opaque returned witness for same-Source acceptance. Freely constructible raw pointer/publication registration is forbidden. Explicit pre-Source bootstrap receipts cannot acknowledge a Source. The new header ownership/witness implementation is authored and uncompiled; prepaid token conservation and actual wasm32 acceptance are unqualified.

Entry.value_fault owns the complete OriginalTurnFailure from birth/publication/callback failures. Paid placement/failure state fences direct retries; Source debit bookkeeping is priced once as the accounting primitive rather than recursively charging its own counters. An outstanding paid publication descriptor also fences publication retry and close after callback failure.
