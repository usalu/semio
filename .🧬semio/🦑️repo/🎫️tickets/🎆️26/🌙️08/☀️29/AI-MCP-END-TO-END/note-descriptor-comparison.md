The editor's composite and navigator windows each lose ten identical actions, which appear once on the editor app: interactionSelect, interactionHover, clearSelection, selectAll, setSelectionMode, setInteractionGranularity, cancelTypedOperation, hostEvent, exportArtifactDocument and importArtifactDocument.
