# Portable prepared actor image

The wire starts with the eight-byte `SEMIOPA\0` magic, format version 1, the 32-byte SHA-256 of the retained component, and the exact actor Core fingerprint as a little-endian u64. The resource lists follow in order. They contain memory lengths and bytes, table lengths and function indices, checkpoint scalar encodings for globals, and flags for surviving passive data and element segments. List counts and lengths are little-endian u64 values. A table index of u64 maximum represents null. Surviving passive segments are reconstructed from the freshly parsed module, preserving exact bytes and function references without duplicating them on the wire.

The sealed writer emits at most 64 KiB per sink call and checks the wire cap before every write. The reader checks format, full component digest, actor module fingerprint, module vector counts, each resource extent, and exact wire exhaustion. It bounds physical reservations separately and checks cancellation between chunks. It rejects external live references and can reconstruct only the explicitly opted-in module's quiescent state. It creates no machine, pending host call, caller state or Source. The producer and launcher retain authority over the component and image digests and the provenance of the paired publication.

The neutral 65,683-byte image fixture exercises bounded memory, table references, integer and raw negative-zero bits, null external references, and surviving versus dropped passive segments. Its independently produced SHA-256 is `48b61426a5b596c9eaa18b9ca72ad32b7f070dfff6fb3446aa8b6aae905ea18a`. Ajv and Bun's Wasm engine passed the neutral wire test. Pinned Rust type-checked the exact Core source and passed the direct public API test through a freshly parsed complete owned component. The probe compiled from current source using retained dependency identities and used no Cargo or shared output path.
