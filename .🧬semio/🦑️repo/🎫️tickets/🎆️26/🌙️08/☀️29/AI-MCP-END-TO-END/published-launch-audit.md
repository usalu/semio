# Published MCP Launch Audit

The stock `.mcp.json` semio command selects the OS stdio route with an explicit composition catalog and its generate target. `🌉️mcp/🟦️.ts` implements a previous-publication path: `prepare` invokes `serveUsable` before staging either target. The probe requires the two catalog files, then admission obtains the gateway and catalog-selected component models concurrently. It fingerprints the gateway and catalog, snapshots the admitted executable, retains model readers and starts the server. If subsequent staging fails, the previously admitted server and model readers remain until shutdown. The catalog presence probe alone does not establish that the binary or models can be admitted or that the application works.

This path is not independent of host admission or queueing. `withAdmittedPublishedCargoExecutableV1` delegates to `withRepositoryPublishedCargoExecutableV1`, which enters `withRepositoryCompilerStoreV1` before taking the shared artifact lease and validating the marker, exact inventory, physical ancestry, executable identity and digest. Compiler-store opening includes tooling and pinned Rust toolchain custody, opening the Rust image, `repositoryCompilerReservationV1`'s queued exclusive compiler-charge lease and workspace lifetime before the publication callback. Model selection similarly enters the products cache store and retains and verifies available catalog models under shared artifact group custody. Therefore a host identity or capacity/queue failure in those prerequisites can prevent `serveUsable` from reaching `serving()`, even though its call precedes refresh staging. It is not a safe bypass for a failed admission.

The root entry creates fresh MCP native and descendant capability data before dispatching `DevScript`; this is distinct from actual artifact reader admission. The Go launcher also ensures its runtime before launching the workspace entry. Source ordering establishes no guarantee that all host acquisition occurs after the usable server starts. This audit did not launch a process, perform a build, alter custody, or prove that the present catalog and models are usable in this sandbox.
