# Paid Core Control Transfers

Use one funded action for an empty-result `end` or `else` on the current non-function label. The same action covers a taken depth-zero `br` or `br_if` with an empty branch signature. Decode and validate the opcode and condition as today, and prove the operand stack after any selector still contains the prefix through the label height. If removing the label, prove both type vectors have zero capacity. A backedge leaves the loop label and its type vectors in place, so the zero-capacity condition is unnecessary there.

Charge the live Source once for two `usize` writes to the operand extent and PC, plus the existing `ControlFrame` debit when retiring a label. Charge one work unit and one retained item, with zero allocation and release. After successful payment, truncate values to the label height, remove the label when required, and set PC to its end plus one, or its start for a backedge. Truncation includes the paid conditional selector. The outer dispatch consumes one Wasm instruction. This bounded action needs the existing cancellation and deadline checks before admission and before starting the next instruction.

The retained path handles a failed direct quote, function return, deeper targets, result movement, branch tables, and type backing that needs release. A direct refusal precedes all mutation. A one-item grant can fund the direct action when its complete byte quote fits. The implementation can complete the action with one guest fuel remaining. The next instruction still waits for another slice and its cancellation and deadline checks. A short grant can still admit and resume the original transfer in bounded phases. In that case a conditional selector can be consumed during the paid retained admission, while the label and PC remain available to the continuation.

The current empty-label retirement posts three items and copies `size_of::<Transfer>() + size_of::<Value>() + size_of::<ControlFrame>() + size_of::<OriginalControlPlan>() + 2 * size_of::<usize>()`. The direct action saves two items and the copy charge for the retained transfer, its final clearing, and the operand-sized admission allowance. An empty loop backedge saves the same bytes and one item. Neither change reduces allocation or release. Use exact `size_of` values in receipt assertions.

The canonical ordinary retirement reported 11,003,158 control items and 5,819,031 control Wasm instructions, with 1,220,726,165 copied bytes, 574,114,480 allocated bytes and 454,255,988 released bytes. The difference bounds eligible one-label retirements at 2,592,063 even if every excess item came from two removable phases. At approximately 128 bytes saved per retirement on a 64-bit host, that represents an upper bound of about 332 MB for label removals. The trace combines label births, branches, return plans and all other control work, so the eligible frequency and total savings require a measured rerun. Its observed failure was the shared ordinary Poll copy budget running below the acknowledgment quote. The acknowledgment failure alone does not reveal the total remaining copy the canonical request requires.

The direct action reuses transfer validation and the normal `charge` function. It added 820 authored bytes. The checked production closure including the concurrent control-vector and return-refusal work was 261,854 of 262,144 bytes across macOS, Linux, and Windows.
