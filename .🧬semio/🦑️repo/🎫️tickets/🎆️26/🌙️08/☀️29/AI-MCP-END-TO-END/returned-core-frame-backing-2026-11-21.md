## Accounting

- An eligible return parks its uniquely owned vectors only after charging the fixed metadata move and frontier updates. It spends a host work item and zero execution instructions. Its capacity and release receipt entries are both zero. Keep the function label as the sole control in the spare. Rebuild its logical contents at the next admission.
- For each fitting vector, copy and initialize exactly the new logical length after charging. Copy parameters from their validated stack window, initialize all declared locals, and update the label metadata, bounds and type lengths. Reuse includes zero-length declarations, which must clear any previous logical contents. For each undersized vector replaced, charge the full new allocation and the old actual capacity released, multiplied by the element width. Derive relocation bytes from the active or spare prefix actually moved. A reused vector does not copy its unused backing. Keep operand consumption, parent PC and spare ownership untouched on a denied call.
- Charge scratch directory capacity, relocation and release only when those events occur. Optional cache growth should be folded into the call's paid transition only when the combined quote fits. A call that fits its existing cold path must remain runnable when its turn lacks optional cache credits. An ineligible return can use the existing paid vector-by-vector release. Bound each fallback and keep any partially retired vectors under their original owner.
- `StepContext` debits capacity and release independently against both the turn and the Source. Do not net a swap or treat release as a capacity refill. Keep all spares with the same original invocation until `close_invocation_step` pays their actual vector releases, slot metadata and directory release. Drain one releaseable extent at a time using `retirement_charge`, before taking the machine or returning the Source. This also covers a canceled call with a parked frame, active nested frames, or an interrupted return. Extend the pending-return diagnostic to report the actual selected park or release quote.
