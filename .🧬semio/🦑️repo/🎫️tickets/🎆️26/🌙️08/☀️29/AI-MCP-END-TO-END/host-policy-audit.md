# Host Policy Audit

The configured `.mcp.json` launches `repo dev mcp stdio os`; `🧰️framework/🛍️products/💻️os/🔨️modules/🌉️mcp/🟦️.ts` injects `🎚️config/🏛️host-driver-policy.json` if no driver argument is provided. Its operation stock is 48 million items, 3 billion copy bytes and 2 GiB each for capacity and release. The independently supplied host operation policy reserves cleanup, transit and infrastructure stock.

`🔌️plugin/🖥️host/🔔️wake/📃️policy/📥️operation/🦀️.rs` binds elapsed time to the smaller of requested and host lifetime, reserves physical stock, and intersects guest authority with the fixed `u32::MAX` Core guest ceiling. Host stock can rise independently, subject to finite reserves and real clock/cancellation, but a 12 billion byte stock cannot deserialize into the native `usize` on 32-bit hosts. Larger capacity also changes actual memory admission, not merely throughput; prefer varying consumable currencies independently and validate real execution.

`🧫️initial-document/🦀️.rs` requests the 150-second document-load budget; `🔁️native-poll/🦀️.rs` requests the host lifetime, currently 24 hours, while per-command polling is bounded by 60 seconds. `📂️documents-and-backbone/🦀️.rs` allows up to another 60 seconds for cancellation settlement after document load. Therefore a 150-second source lifetime for every wake is not established by current policy.

If an actual end-to-end run proves a new budget, the policy JSON is the production owner. `🧪️tests/🏛️host-driver-policy/🟦️.ts` validates it independently with AJV and SQLite and checks a historical Note readiness measurement; update `🧪️tests/🏛️host-driver-policy/🧫️fixtures/typed-note-open.json` only with fresh matching observations, not by merely relabeling its old issued and remaining measurements. Its historical drive minimum and current configured drive are both 4096. Add meaningful positive end-to-end and exhaustion/deadline/cleanup cases with actual guest cap and clock, not just arithmetic. The closed host policy schema permits safe integers and does not mirror the configured values; no schema edit follows solely from changing values. The separate MCP test driver fixture is independent and should not be silently synchronized. Preserve tests of reserve conservation, original non-renewal, cancellation, source handback and wasm32 narrowing.
