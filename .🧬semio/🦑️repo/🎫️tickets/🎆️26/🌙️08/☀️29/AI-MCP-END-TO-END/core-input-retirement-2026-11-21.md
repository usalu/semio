# Core Input Retirement

A failed input unit can issue a fresh canceled admission only after the runtime receives the actual acknowledgment and its exact header deallocator returns. The runtime now sends that continuation's receipt epoch with the already-verified wire and budget arguments to the Core using its private embedding authority. Core seals that authority at opening and marks just the admitted frame through its paid closure.

Core verifies the actual unaliased admission export, canceled budget, causal epoch, operation, generation, clock binding, and source deadline. VM execution retains the ordinary fuel and physical accounting. Retirement host replies still accept only the actual operation clock import with its bound clock and destination.
