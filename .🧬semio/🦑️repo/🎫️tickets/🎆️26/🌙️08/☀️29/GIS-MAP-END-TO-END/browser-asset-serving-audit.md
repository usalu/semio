# Browser Asset Serving Audit

Read-only source audit; no server or browser run. The retained loopback measurements supplied for this task are 1.32 s Chrome and 3.47 s Firefox streaming compilation of the 138,445,673-byte extracted core. They do not establish first paint, wide-area transfer, or warm reload time.

- Play's Vite dev mounts use `serveFileWithValidatorsV1` (`🧰️framework/🔨️modules/🖱️ui/🎨️styling/🏗️builder/🌐️vite/📤️file-serving/🟦️.ts`). It sends `application/wasm`, content length, a size/mtime ETag, and `no-cache`; matching validators return 304. The file is streamed, not buffered or chunked by this handler. `no-cache` means revalidation, not no storage. Because staging rewrites files at stable paths, this policy is justified; there is no source-supported unconditional full redownload fix here.
- Production page generation (`🏢️semio-tech/🎡️play/🔨️modules/📦️site/📄pages/🟦️.ts`) writes `Cache-Control: no-cache` for all page files, including the modules page. It forces revalidation on warm requests, but does not alone imply 138 MB retransfers: actual CDN validators and header handling were not measured. A long immutable lifetime is safe only after URLs incorporate a content identity and references change with bytes; the current published path alone does not prove that. The module catalog records per-file SHA-256 but does not itself make file paths content-addressed. No production header change is justified without that URL contract and CDN evidence.
- The generated component bridge dynamically imports the component per actor and activation (`🌐️browser-bundle/🏗️materialization/🌉️component-bridge-source/🟦️.ts`); `rewriteJcoComponentAssetUrls` retains only the rebuild version on the core URL, not actor or activation. Thus distinct activations can address the same core URL, but independent module evaluation may still compile it again. Browser cache/engine reuse and actual activation counts were not measured, so duplication remains a hypothesis, not a demonstrated defect.
- The 138 MB core size is a material cold network cost; local streaming timings exclude real network limitations. This audit found no evidence of compression behavior in the dev file server or proof of a faulty transfer encoding. The production host's content encoding and warm response remain unverified.
