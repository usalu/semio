## P1 findings

1. **Snapshot operation-id deduplication does not remap the durable message ledger.** A snapshot rebroadcast after an Operations delivery can be rejected as structurally invalid, or fail to converge, because the remote ledger is keyed by the source edit id while local history is keyed by the previously ingested wire mutation id. The merge must either carry a canonical operation-to-edit ledger identity or remap ledger entries before authoritative validation.

2. **Host full-fidelity closure is unverified and the checked-in fixture is invalid under the new validator.** The host binary propagation code is present, but the test's arbitrary conflict id cannot pass content-addressed validation. The host DSL/text export also drops outcomes/conflicts because `ArtifactTextFiles` has no message/conflict representation. The binary host gate and package check must run on a corrected valid fixture; text behavior must be explicitly scoped as a lossy mirror or upgraded to preserve the authoritative `.spr` data.

3. **The low-level conflict codec accepts unknown kind/status bytes.** `decode_conflicts` catches duplicate ids and trailing bytes, but `read_conflict` does not range-check the two enum tags. Store-level conversion catches this only after the generic history codec has already returned a malformed `HistoryConflict`.

4. **Conflict message operation ownership is not validated.** Conflict messages are checked for frozen code/severity/text, but `op_index` is validated with no operation count. A persisted conflict can therefore carry an index that names no operation and still be printed. The conflict wire contract needs an explicit index domain (envelope index or edit operation index) and validation at print/parse boundaries.

5. **The contract still specifies a persisted conflict policy while code intentionally keeps policy local.** The implementation's runtime-only resolution policy is the safer data model, but the contract freeze must be changed or an explicit non-persisted policy rule must be ratified before this finding can close.

6. **If `.ops` is included in the strict codec boundary, its cursor parser is not strict and its reconstruction synthesizes metadata.** `replay_ops` silently skips unknown cursor ids and uses fallback operation ids/actors/timestamps (`store/🦀️component.rs:2983-3001`, `3084-3093`). The current authoritative `.spr` path does not have this fallback; the distinction must remain explicit in the contract.

## Serde/default and wire preservation audit

- `ArtifactEnvelope.edit_messages` and `ArtifactEnvelope.conflicts` are required fields with no `serde(default)` or `skip_serializing_if` (`store/🦀️component.rs:172-173`). Host `BackboneDocument` has the same required fields (`host/🦀️component.rs:336-337`). No legacy envelope test or compatibility default for those arrays remains.
- `MutationOutcome.messages` and `MutationMessage.target/op_index` retain defaults because they are optional message payload members, not envelope-level outcome/conflict collections. Their persisted SPR path is still validated against frozen codes, levels, text, and indices where an edit operation count is available.
- Rust `ApplyOutcome::Rejected.messages` and TypeScript `WireApplyOutcome`/`CommandAckOutcome` carry the opaque rejection bytes (`os/🟦️component.ts:405-410`, `815-836`, `1099-1112`). Existing ticket evidence records the Rust fixture and two TypeScript parity tests as passing; no fresh execution was performed here.
