# Shared Original Worker Receipt Preservation

The current actual authority step_on_original_caller records issued_retained = cx.retained_grant(), computes actual physical progress from the same caller before/after recipient, and leaves that receipt pending on its original checked-out authority. The mounted pump now captures the original before/grant, checks out and stores the exact owner first, BORROWS its pending receipt, verifies issued equality, fits(granted), and before.checked_add(progress) == cx.retained_progress(). It neither takes nor debits the receipt. Any verification refusal returns OriginalTurnFailure with the owner and pending receipt retained. Original producer failures still propagate whole through try_step_on_original_caller. No build, compiler, runtime or test was run.
