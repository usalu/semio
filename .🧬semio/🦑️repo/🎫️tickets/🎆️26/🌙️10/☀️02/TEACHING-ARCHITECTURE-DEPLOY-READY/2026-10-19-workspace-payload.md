## Contract and implementation

The existing Bun ownership JSON Schema now defines language-neutral `PayloadOwnershipCases`. A nested package belongs to its nearest real Source package owner when both have the same nonempty package name and a safe, literal, concrete authored export target lies below the nested package namespace. Ownership is independent of whether generated leaf files exist, are removed, or are links. This classifies Source identity; it grants no executable/content provenance or output symlink admission. Physical Source manifests, directory ancestry, nearest-owner selection, current Source fences, cancellation and controlled publication remain enforced by discovery callers.

The shared CJS predicate is now a pure declaration computation, with its obsolete output-state generator removed. Both TypeScript discovery and controlled Bun publication call it. Exact `./` targets are required; malformed dot prefixes, traversal, encoded paths, wildcard targets and prefix siblings remain ineligible. Default condition ordering and invalid mixed/numeric condition cases retain their refusals. Different-name/private nested Source and genuine unbound same-name duplicates retain their existing semantics.
