Prepared only; no command, test, pin, artifact read, container action, install or help probe was executed. Inputs are 🧰️native/schema.json and cases.json (written before implementation), script.ts and tests.ts. The schema admits exact generated/n/repo, n2/repo or n3/repo; no binary digest or successful publication is invented. Root must select an actually completed and provenance-reviewed publication.

The fixed host-only `pin n|n2|n3` action verifies descriptor/name stability, executable regular single-link mode, ≤64MiB SHA256 and static ELF64 little-endian machine62, then writes an exclusive actual-byte pin with random /tmp/semio-course-native-<nonce>/repo and reviewed input hashes. `install` only receives those bytes and probes that exact guest executable --help; no arbitrary guest command, Source mutation, start/stop/remove, managed-run cancellation or host Original replay. Docker implementation stays within the own Operation/Observation/ProvisionPort interface.

Retained identity uses fixed702-byte identity SHA90e45f2e… and plan name/image/volume/Source manifest/revision binding. Every receive/probe has projected exact-ID/image/created/ticket+token/unique Source mount/running-state inspections before and after, including bounded post-action inspection on operation failure/cancellation. Local authority and host binary are rechecked around operations. Guest receives only binary stdin into exclusive fresh directory/file, validates bytes/hash/ELF/mode, and invokes fixed --help with only destination environment, explicitly removing SEMIO_SCRIPT_PROCESS_INVOCATION. Guest receive timeout45s; help25s with internal help20s; host operation caps and120s primary total plus10s post-authentication grace. Host cancellation requests await the bounded current guest operation. A failed client transport does not establish guest terminal.

No guest cleanup deletion is attempted: failure closes only own file descriptor and may retain its fresh incomplete tool path. Final receipt states that boundary. This avoids deleting a peer-replaced path. No Source file is copied into ticket or guest. Prepared42 neutral cases cover own/Ajv pin-schema parity, ELF and Python struct/hashlib oracle, exact container refusal cases, semantic transport gates and execution of generated guest code through an in-memory syscall port. They are unexecuted and may reveal defects; no RED/GREEN is claimed.
