The inner/private engine needs its own network and image storage for the Dockerfile base and pinned Caddy runtime used by stack checks; installation of the docker executable alone does not establish that runtime.

These operations write only their test containers/volumes/state; they do not validate production by changing its data. The actual existing deploy checks own cancellation/cleanup.

Default output is package `dist/proctor`; `--out <absolute-private-export>` selects a concrete export folder. This is a local offline bundle; no push/upload occurs. Certificates are operator inputs for real deployment, not a production certificate emitted by the bundle.
