## L3 test coverage

- en1991 (80 leaves): every kind's `✅apply` module is registered in `🧬️mutations/🧪️tests/🔬️fixture/🦀️.rs` and calls `assert_vector`. That replays the leaf's inverse steps with `MutationDiff::apply` and asserts the result equals `before`. This is sequential replay, not `absorb`.
- en1995 (66 leaves): same as en1991, 66 of 66 registered through `assert_vector`.
- en1996 (58 leaves): the per-kind `✅apply` modules are compiled from each kind file but are shallow. 58 of 58 of them contain no `assert_vector` or `inverse` call; 10 assert one `diff()` value and the rest check the descriptor or a single outcome. Sequential replay comes from `committed_vectors_are_this_implementations_answer` in the fixture file, which walks every `🧫️fixtures/🧬️mutations/<leaf>/<scenario>` bundle. All 58 leaves have an applied bundle, so all 58 are replayed.
- absorb-sum (`Σ = d₁ ⊕ … ⊕ dₙ`, `Σ.apply(after) == base`, `Σ == m.diff(base).diff().inverse(base)`): no test in en1991, en1995 or en1996. `rg absorb` matches only the trait definitions and en1990.
- The results config test (`🪟️results/🎚️config/🧪️tests/🎚️config/🦀️.rs:84-86`) replays one inverse step with `diff().apply()`. It does not sum or use `absorb`.
