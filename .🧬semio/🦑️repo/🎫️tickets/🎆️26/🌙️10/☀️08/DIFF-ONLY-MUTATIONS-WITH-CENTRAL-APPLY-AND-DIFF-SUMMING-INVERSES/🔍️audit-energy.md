## 4. L3 law tests

- Coverage: all 297 kinds with tests have a folder with `fixtures::assert_laws(&case())` and `fixtures::assert_inverse(&case())`, and the 4 kinds in section 1 have none.
- `assert_inverse` (`🧬️mutations/🧪️tests/🔬️fixtures/🦀️.rs:224-234`) replays `Mutation::inverse(base)` in reverse, applies each step's `diff(..)` to the running snapshot, and compares with the committed before-snapshot. This is the sequential chain `s_k = d_k.apply(s_{k-1})` and it is present for every tested kind.
- `assert_laws` (`fixtures/🦀️.rs:320-332`) runs the framework's `assert_mutation_inverse_law` (sequential, correct chain, no absorb) and `assert_mutation_diff_absorb_law(base, first, second)` with `first` and `second` both the forward diff (`:328-330`). That checks `absorb(d, d)`, not inverse sums.
- No test calls `.absorb(` (0 hits in the energy plugin tests), and no test computes `Sigma = d1 + ... + dn` from inverse diffs or checks `Sigma.apply(after) == base`. L3's summation half is untested for all 301 kinds (systemic).
- `DiffAlgebra` is not implemented, so the `Sigma == m.diff(base).diff().inverse(base)` clause does not apply.
- Refused vectors skip the framework inverse law (`fixtures/🦀️.rs:320-327`) but still run `assert_inverse`.

## 5. Inverse analysis

- No inverse file in energy calls `.diff(` or `diff::diff(` (0 of 297), so V2-DIFF-DERIVED-INVERSE does not occur.
- Every standard inverse is per-kind in `↩️inverse/🦀️.rs`, computed from `base` with concrete vocabulary builders. Guard parity: each of the 297 standard inverses has early `Vec::new()` guards and each diff has refusal or no-op returns. Six were opened by hand and match (`create-space`, `rename-surface`, `change-glazing-material`, `change-daily-schedule`, `delete-plant-loop`, `change-infiltration`).
- `replace-airflow-network` restores the whole previous airflow network (`↩️inverse/🦀️.rs:27`), which is V2-RESTORE-INVERSE (borderline). Entity-level restores (`replace-*-vertices`, `replace-time-series-schedule-values`, `replace-daily-schedule-hourly-values`, `delete-*` via `create_*`) are concrete per entity and are not flagged.
- The 4 config/window inverses are concrete (`ChangeSimulationSettings(of(base))`, `ChangeResultField(of(base))`, `SetCamera{camera: base.camera}`) and are not V2-EMPTY-INVERSE.
