# 🔍️ Audit: Seven Mid Plugins (Diff-Only Mutations)

Read-only audit of `✏️s/🔌️plugins/` for 🎥️shooting, 📸️remodel, 🗒️note, 🖨️raster, 🖍️draw, 📐️cad and 🌍️gis against the laws and violation codes in [📋️design.md](./📋️design.md), including its later rulings (Minimality, Absorb soundness, Generic seams deleted, V5-ABSORB). Nothing outside `🗑️generated/` was written; no builds, tests or git modifying commands were run.

## 1. Summary

- **196 kind leaves** (`MutationKind`/`CompositeMutationKind`): **87 violating**, **109 clean** (the clean count includes 1 composite, `create-building-storey`, which only plans `CreateNode`).
- **14 hand-written `impl Mutation<P>`** (window configs, presences): **all 14 violate** (V1-SNAPSHOT-DIFF, V2-RESTORE-INVERSE, V3-HAND-MUTATION); raster and cad config also clone `base` in the diff (V3-LEAF-APPLY).
- **17 `MutationDiff` impls**: all implement `apply` and `absorb` as hand-written methods; **0 implement `DiffAlgebra`**. 8 artifact diffs carry a whole-snapshot `artifact:` carrier; 7 presence diffs are the snapshot type itself.
- **Dominant codes:** V1-GENERIC-DIFF (74 kinds, every remodel kind included), V3-LEAF-APPLY (74 kinds, base cloned and written in-leaf), V2-RESTORE-INVERSE (10 kinds + 14 hand), V1-SNAPSHOT-DIFF (9 kinds + 14 hand), V2-DIFF-DERIVED-INVERSE (4, all draw).
- **V2-EMPTY-INVERSE: none found.** Every empty-inverse arm sits on a guard where the forward diff is an error, fatal, refused or no-op.
- **V4 (no L3 test, name-based heuristic): 31 kinds + 10 hand impls.** Covered kinds are only "covered" in the heuristic sense; no test was run.
- **V5-ABSORB candidates:** shooting, note, draw, cad and gismap diffs `extend` same-key lists without create∘delete / patch∘patch coalescing. raster coalesces. Remodel and gisterrain are sound only because their diffs carry whole fields.
- **L4 breaches outside leaves:** `apply(` is called from the gismap diff (`apply_to_artifact`, 🔺️diff:128), the gisterrain diff (`apply_to_artifact`, 🔺️diff:35) and the gisterrain editor (`✏️editor/🦀️.rs:301`). Leaf code itself has zero non-test `.apply(` calls.
- **L5 is not implemented in the framework:** `MutationDiff::apply(&self, base)` is a required public method with no `ApplyCapability` (`🧰️framework/🔨️modules/📡️replication/🎮️mutation/🦀️.rs:104`).
- **Shared generic seams that the rulings delete:** `drawing_selection_inverse` (3 callers), `diff_set_snapshot`/`diff_from_snapshot` in four diff modules (0 leaf callers), whole-snapshot config/window diffs (shooting, raster, draw, cad, gis, note, remodel). `painted_inverse` (raster, 5 callers) is a borderline generic inverse builder.

## 8. Borderline (not counted as violations)

- **Raster `painted_inverse`** (`🖨️raster/…/paint-stroke/🦀️.rs:358`, 5 callers): the inverse is built from base and the `Painted` product, not walked from the diff. It is still a shared generic inverse builder, so the L5 policy gate may flag it.
- **Gisterrain `change-imported-features`**: the diff carries the whole imported map, which is the owned field. Its inverse restores that owned field. Read as a `replace-<entity>` kind under Minimality, so not counted.

## 9. Method and limits

- Scope: 196 leaves found by `impl … MutationKind<` / `CompositeMutationKind<` across the seven plugin trees (excluding `node_modules`/`target`). Hand impls: `impl … Mutation<`. Diff impls: `impl … MutationDiff<`.
- Each leaf's diff and inverse bodies were extracted with brace matching (comments stripped) from every non-test `.rs` file in the leaf. Classification used regexes over those bodies, then manual spot checks of every code group against source (for example `shooting/🔧set-defaults`, `remodel/🏁commit-reconstruction`, `note/📝edit-block-text`, `draw/✋drag-layers`, `cad/📎replace-references`, `gis/🎥set-camera`).
- Caveats: the V4 and V5 findings are heuristics. V5 is read from the `absorb` code only, not from a run of `assert_mutation_diff_absorb_law`. The V4 match is by name inside test blocks, not by executing tests. Confirm both with `verify mutation-outcome-law` and the existing protocol-law tests.
- Scratch scripts and extracted JSON are in `🗑️generated/` in this ticket (`leaves.py`, `analyze.py`, `bodies.py`, `classify.py`, `final.py`, `l3b.json`, `final.json`, `kind_table.md`, `hand_table.md`, `summary_table.md`).
