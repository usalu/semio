# 🔍️ Audit: stdio/semio diff-only mutation laws (read-only)

Ticket: `DIFF-ONLY-MUTATIONS-WITH-CENTRAL-APPLY-AND-DIFF-SUMMING-INVERSES`. Scope: `✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/🧿️semio`. Read-only: no source edits, no cargo or bun builds, no git modifying commands. Generated scanners live in `🗑️generated/`.

## Summary

- 271 mutation leaves in scope: 252 hand-written `impl protocol::MutationKind` plus 19 `🩹️patch-snapshot` leaves whose `MutationKind` impl is emitted by the contract macro `snapshot_patch_leaf!`.
- Clean on L1-L4 (no violation code other than the L3 gap): 175 leaves. Clean including the loose V4 test check: 140.
- V1-SNAPSHOT-DIFF: 80 leaves. Diff built by `between` of snapshots (set-snapshot, patch-snapshot), or by cloning base and mutating the clone before a whole-collection replace (text, table, graph, kit).
- V1-GENERIC-DIFF: 65 leaves. Whole-collection replace through `*List { values }` diff fields (text, table, graph, kit), or generic JSON patch payload (patch-snapshot).
- V2-RESTORE-INVERSE: 39 leaves. Inverse restores a whole snapshot (`SetSnapshot { snapshot: base.clone() }`) or emits a generic `PatchSnapshot` (mesh delete-texture, patch-snapshot).
- V2-DIFF-DERIVED-INVERSE and V2-EMPTY-INVERSE: 0 leaves. No kind-level inverse walks the forward diff. Two diff types (value, mesh) derive `DiffAlgebra::inverse` as `between(apply(self, base), base)`, see section 3.
- V3-LEAF-APPLY: 79 leaves. `🦠️mutation/🦀️.rs` facades take `&mut P` (7 set-snapshot, 11 image), clone-then-mutate diffs, and the patch-snapshot shared helper.
- V3-HAND-MUTATION: 0. No `impl Mutation<P>` in scope, every leaf implements `MutationKind`.
- V4 (L3 law test): no test in scope sums inverse diffs with `absorb`. The only test combining `absorb` with an inverse call is `material_texture_refs_roundtrip_sparse_clear_inverse_and_absorb` (mesh diff tests), and it sums forward diffs. So no leaf has the strict L3 test. The loose check (a test references the variant alongside `inverse`) misses 57 leaves.
- Shared dispatchers: `agg_diff` / `agg_inverse` in each subset `🧬️mutations/🦀️.rs` are called by about 136 leaf trees. Their `SetSnapshot` arms carry the set-snapshot violations, see section 2.
- Per-artifact contract issue outside the subset: `snapshot_patch_leaf!` (contract `✏️editing/🦀️.rs:1389`) and `apply_snapshot_patch(_checked)` / `inverse_snapshot_patches` (contract `✏️editing/🩹️patch/🦀️.rs`) are shared by these 19 leaves and by other stdio artifacts (docx, xlsx, ...), not audited here.

Reference violation check: the named `🧭️rotate-layers` leaf is in the `stdio/draw` plugin, not in this scope. Its `🦠️mutation/🦀️.rs` facade with a `&mut` snapshot entry point appears here in 18 leaves (7 set-snapshot, 11 image). Its diff-derived kind inverse does not appear in this scope (0 leaves).
