## Ported (old -> new)
- `AppActionRegistry::close_step(max_items,max_bytes)->PluginCloseStep` -> pair below. Identifiers are released whole on the release axis (`Vec::capacity`), no more logical truncation.
- `ArtifactInstanceOperationOwner` trait: `retirement_demands(&self, body)`, `maintenance_step(grant)`, `close_step(grant)` -> `Result<PluginLifecycleStep,Fault>`; `EmptyArtifactInstanceOperationOwner` and the handle follow. EXTERNAL implementors still on the old trait (compile break to be migrated in the artifact wave): drawing, generation2d/3d (editor+viewer), flow, puzzle3d, bim gestures, playbook procedural `ModuleGeometryOwner`.
- `ArtifactToolRawInput::close_step`: forwards `RetainedToolWireInput::close_step(grant)` (one turn frees the page backing; demand = `next_close_release_byte_demand`/depth).
- `ArtifactSnapshotDisposer<T>` and `ArtifactOwnedDisposer<T>` traits (shape as p1 specified): `retirement_demands(&self, [owner|snapshot], body)`, `close_step(.., grant) -> Result<PluginLifecycleStep,Fault>`, `terminal_is_empty`. `ArtifactDocumentStoreDisposer` delegates to `ArtifactStore::close_owned_demands/close_owned_store_step`.
- `drive_artifact_owned_disposer` (now `pub(crate)`, grant based) + new `artifact_owned_disposer_demands`; `ErasedArtifactSnapshotDisposer`/`TypedArtifactSnapshotDisposer`/`ArtifactSnapshotCloseRetention` ported; the retention releases its disposer shell in its own turn (release axis `size_of_val`).
- `ArtifactMediaExportCompletion`: slot struct (`value`, `chunks`, two metadata strings, `active` box). Close = hand result apart (copy), `artifact_retirement_admit_owned` the chunks (birth), step the controlled chunk retirement, release each metadata string (release axis). Deleted dead `close_take`.
- `BoundedConfigPreparationFactory/BoundedConfigPreparation`: now the exact twin of `BoundedWindowConfigPreparation` (factory children, `begin_demand`, `begin(request, grant)`, controlled close of mutation/prepared/base witness/authority/factories). Public constructor now requires `C: RetireOwned + Sync`, `M: RetireOwned`; `..._source_birth_demand` = three Arcs, depth 2; `..._birth_bytes` includes both child issuers.
- `BoundedStoreInitializationAuthority` + `ArtifactStoreInitializationAuthority` trait + `ArtifactStoreInitializationJob`: trait is now `retirement_demands(body)`, `begin_close`, `close_step(grant)->Result<RetainedCloneStep,ValueError>`, `terminal_is_empty` (apps with their own authority, e.g. the `host/owned` copies, must migrate). The authority owns its funded `DocumentStoreOwners` from birth (`funded_bounded_artifact_store_owners`), terminal order: displaced owner -> runtime -> edit index -> envelope frame -> envelope -> catalog. Displaced owners retire through `owners.retire_initial_snapshot_owned` with an exactly quoted self-grant (`retirement_self_grant`, new `pub(crate)` helper at chunk head). The job maps to `InteractiveJob` (`next_close_*_demand`, `close_step(grant)`, shell release as its own turn).
- `ArtifactReservedJob` is a marker; inherent `ArtifactReservedToolJob::{close_step,next_close_byte_demand}` deleted; `framework_reserved_job!` implements only `InteractiveJob` (release = `raw.capacity()` whole, depth 1) + `impl ArtifactReservedJob for $job {}`. `FrameworkConfigurationBinaryJob` likewise (decoded Arc released via `Arc::into_inner`, quote = Arc allocation extent; the decoded `ArtifactCommand` content has no controlled retirement authority (`ArtifactCommand` is not `RetireOwned`), it is dropped with that Arc - open item).
- `PluginApp` trait text and `PluginLifecycleStep`: already migrated by 677, untouched.
