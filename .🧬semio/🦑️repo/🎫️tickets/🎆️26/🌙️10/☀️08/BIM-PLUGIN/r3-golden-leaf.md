# Golden leaf recipe: adding a mutation leaf to `s.bim.model@1`

Audience: Wave M agents adding about 80 leaves in parallel. Author: f1-foundation. Reference leaves (both green): `set-storey-height` (the small golden leaf) and `delete-storey` (the cascade golden leaf).

Paths below use `S` = `✏️s/🔌️plugins/🏙️bim/🗿️artifacts/🏢️model/🏅️standards/🔖️1/🪆️subsets/✳️any` and `A` = `✏️s/🔌️plugins/🏙️bim/🗿️artifacts/🏢️model`, `T` = this ticket folder.

## 1. What one leaf is

A leaf is one directory `S/🧬️schema/🧬️mutations/<emoji><kebab-kind>/` plus one fixture directory `S/🧫️fixtures/🧬️mutations/<emoji><kebab-kind>/<case>/`. Files:

| File | Written by | Purpose |
|---|---|---|
| `🔣️.json` | `emitLeaf` | descriptor: `semanticKind`, `aggregateVariant`, `binaryTag`, `invertibility: explicit-mutation`, `outcomeClasses`, `composition: atomic` |
| `🧬️schema/🔣️.json` | `emitLeaf` | payload JSON schema, one `x-semio-ui` per property (widget, role, en+de label, group, order); `x-semio-inverse-rows` when the inverse emits more than one row |
| `🦠️mutation/🦀️.rs` | `emitLeaf` | payload struct, `MutationKind` impl (descriptor, `diff`, `inverse`, en+de `label`, `target`) |
| `🔺️diff/🦀️.rs` | HAND | `pub fn diff(payload, base) -> MutationOutcome<ModelDiff>` |
| `↩️inverse/🦀️.rs` | HAND | `pub fn inverse(payload, base) -> Vec<ModelMutation>` (storage order, see 6) |
| `🧪️tests/<case emoji><case>/🦀️.rs` | `emitLeaf` | one file per case, six tests each, all through `kit` |
| fixtures `<case>/{📸️snapshot/⬅️before,📸️snapshot/➡️after,🦠️mutation,🔺️diff,🎯️outcome}/🔣️.json` | `emitLeaf` (before, mutation, outcome) and `BIM_BLESS=1` (after, diff) | the committed quintet |

Every leaf needs at least one `applied` and one `rejected` case. A no-op case is welcome (`OutcomeCode::NoOp`), it is a `rejected` outcome with code `mutation.no-op`.

Write your own `T/r3-m-<slice>-leaves.ts` that imports `emitLeaf` and `Leaf`, build the leaf list, `emitLeaf` each, and write the concatenated mount text to `T/🗑️generated/<agent>/mounts.txt` for pasting. NEVER add your leaves to `r3-f1-leaves.ts` (it is the foundation spec; parallel appends would collide). Case `before` snapshots are plain data; the helper `scene()` is the two-storey house with three walls (`w-east`, `w-south`, ...). `emitLeaf` never overwrites a blessed `after` or `diff` (`writeOnce`), and never writes `🔺️diff` or `↩️inverse` (hand-written).

Emoji names are code-point exact: `emoji` is a code point, `em(...)` appends U+FE0F. Never type emoji paths in shell; locate directories by suffix as `T/r3-f1-paths.ts` does. `bun T/r3-f1-check-names.ts` verifies that no name drifted.

## 4. Bless workflow

1. `emitLeaf` writes `before`, `mutation`, `outcome` (and placeholders `{}` for `after`, `diff` of applied cases; for rejected cases `after` is a copy of `before` and `diff` is `{}`).
2. Hand-write `🔺️diff` and `↩️inverse`.
3. Bless from the code under test, privately built (see 8):
   `BIM_BLESS=1 cargo test -p semio-s-artifact-bim-model --lib <kebab_kind>` writes `➡️after` and `🔺️diff` of applied cases (canonical pretty JSON).
4. Review the blessed JSON by hand (it is the committed expectation, not an oracle). Run without `BIM_BLESS` and see all six tests per case green.

`🔺️diff/🦀️.rs` (hand-written):
```rust
//! 🔺️ Diff constructor for `SetStoreyHeight`: a one-field storey patch. Nothing downstream is written: every elevation above and
//! every wall resolved by this storey follows by inference.

use super::SetStoreyHeight;
use crate::{Entry, ModelDiff, ModelSnapshot, StoreyPatch};
use protocol::{MutationOutcome, OutcomeCode};

pub fn diff(payload: &SetStoreyHeight, base: &ModelSnapshot) -> MutationOutcome<ModelDiff> {
    let Some(storey) = base.storeys.get(&payload.id) else {
        return MutationOutcome::refuse(OutcomeCode::TargetMissing, format!("Storey \"{}\" does not exist.", payload.id), [payload.id.clone()]);
    };
    if !(payload.height.is_finite() && payload.height > 0.0) {
        return MutationOutcome::refuse(OutcomeCode::Invariant, "A storey height must be a positive length.", ["height"]);
    }
    if storey.height == payload.height {
        return MutationOutcome::refuse(OutcomeCode::NoOp, format!("Storey \"{}\" already is {} m high.", payload.id, payload.height), [payload.id.clone()]);
    }
    MutationOutcome::new(ModelDiff::storeys(payload.id.clone(), Entry::Patched(StoreyPatch { height: Some(payload.height), ..Default::default() })))
}
```

## 6. The cascade golden leaf `delete-storey`, verbatim

Descriptor differs only in `x-semio-inverse-rows` on the payload schema: `"x-semio-inverse-rows": {"bounded": 4096}` (the inverse emits one create per removed wall plus the storey, so the one-row default does not hold; declare the bound, the aggregate test pins it).

Cascade rules every delete leaf follows:
1. Cascade only over kinds that have a create leaf (their inverse can restore them). Everything else that depends on the target refuses with `OutcomeCode::TargetReferenced` (`mutation.target-referenced`), path `[id]`.
2. Properties and classifications belong to their element: EVERY delete leaf (single-element ones included) routes through `🌊️cascade` and removes the `properties`/`classifications` entries of the element and of every cascaded child; the inverse carries one `set-element-property`/`set-element-classification` row per removed entry (Wave Z ruling, replaces the earlier orphan-tolerant policy). Types and materials own no entries (data is keyed by element id).
3. A cascading outcome carries an info message `OutcomeCode::Cascade` with the count.
4. The inverse is storage-ordered: the store replays the vector reversed, so the dependants come first in the vector and the target LAST (it is recreated first).

`🔺️diff/🦀️.rs`:
```rust
//! 🔺️ Diff constructor for `DeleteStorey`: the storey and every wall on it leave in one sparse diff. A kind without a create leaf
//! cannot be restored by the inverse, so a storey that still hosts such an element, an opening on one of its walls, or that
//! another element's top constraint points at is refused as `mutation.target-referenced`.

use super::DeleteStorey;
use crate::{Entry, KeyedDelta, ModelDiff, ModelSnapshot, TopConstraint};
use protocol::{MutationOutcome, OutcomeCode};

fn constrains(top: &TopConstraint, storey: &str) -> bool {
    matches!(top, TopConstraint::Storey { storey: target, .. } if target == storey)
}

fn dependents(base: &ModelSnapshot, id: &str) -> Option<&'static str> {
    let on = |storey: &String| storey == id;
    let walls: Vec<&String> = base.walls.iter().filter(|(_, wall)| on(&wall.storey)).map(|(wall_id, _)| wall_id).collect();
    [
        ("curtain walls", base.curtain_walls.values().any(|row| on(&row.storey))),
        ("columns", base.columns.values().any(|row| on(&row.storey))),
        ("beams", base.beams.values().any(|row| on(&row.storey))),
        ("slabs", base.slabs.values().any(|row| on(&row.storey))),
        ("roofs", base.roofs.values().any(|row| on(&row.storey))),
        ("stairs", base.stairs.values().any(|row| on(&row.storey))),
        ("railings", base.railings.values().any(|row| on(&row.storey))),
        ("spaces", base.spaces.values().any(|row| on(&row.storey))),
        ("openings", base.openings.values().any(|row| walls.contains(&&row.host))),
        ("constraints", base.walls.values().any(|row| !on(&row.storey) && constrains(&row.top, id)) || base.curtain_walls.values().any(|row| !on(&row.storey) && constrains(&row.top, id)) || base.columns.values().any(|row| !on(&row.storey) && constrains(&row.top, id)) || base.stairs.values().any(|row| !on(&row.storey) && constrains(&row.top, id))),
    ]
    .into_iter()
    .find_map(|(kind, present)| present.then_some(kind))
}

pub fn diff(payload: &DeleteStorey, base: &ModelSnapshot) -> MutationOutcome<ModelDiff> {
    if !base.storeys.contains_key(&payload.id) {
        return MutationOutcome::refuse(OutcomeCode::TargetMissing, format!("Storey \"{}\" does not exist.", payload.id), [payload.id.clone()]);
    }
    if let Some(kind) = dependents(base, &payload.id) {
        return MutationOutcome::refuse(OutcomeCode::TargetReferenced, format!("Storey \"{}\" is still used by {kind}.", payload.id), [payload.id.clone()]);
    }
    let walls: Vec<String> = base.walls.iter().filter(|(_, wall)| wall.storey == payload.id).map(|(wall_id, _)| wall_id.clone()).collect();
    let removed = walls.len();
    let outcome = MutationOutcome::new(ModelDiff {
        storeys: Some(KeyedDelta::one(payload.id.clone(), Entry::Deleted)),
        walls: (!walls.is_empty()).then(|| KeyedDelta(walls.into_iter().map(|wall_id| (wall_id, Entry::Deleted)).collect())),
        ..ModelDiff::default()
    });
    if removed == 0 {
        outcome
    } else {
        outcome.info(OutcomeCode::Cascade, format!("Storey \"{}\" took {removed} wall(s) with it.", payload.id))
    }
}
```

```rust
//! the store (which replays the vector reversed) recreates the storey before the walls that reference it.

use super::super::create_wall::CreateWall;
use super::DeleteStorey;
use crate::{ModelMutation, ModelSnapshot};

pub fn inverse(payload: &DeleteStorey, base: &ModelSnapshot) -> Vec<ModelMutation> {
    let Some(storey) = base.storeys.get(&payload.id) else {
        return Vec::new();
    };
    base.walls
        .iter()
        .filter(|(_, wall)| wall.storey == payload.id)
        .map(|(wall_id, wall)| ModelMutation::CreateWall(CreateWall { id: wall_id.clone(), wall: wall.clone() }))
        .chain(std::iter::once(ModelMutation::CreateStorey(CreateStorey { id: payload.id.clone(), storey: storey.clone() })))
        .collect()
}
```

## 7. Diff algebra and outcome vocabulary

Diff constructors build sparse `ModelDiff`s (`S/🧬️schema/🔺️diff/🦀️.rs`):
- `ModelDiff::<collection>(id, Entry)` for one entry (`ModelDiff::storeys`, `ModelDiff::walls`, ...), struct update syntax with `..ModelDiff::default()` for several collections, `KeyedDelta::one(id, entry)` / `KeyedDelta(BTreeMap)` for a collection delta.
- `Entry::{Created(T), Deleted, Replaced{..}, Patched(<Entity>Patch)}`; patches (`S/🧬️schema/🔺️diff/🩹️patches/🦀️.rs`) hold `Option<T>` per field and `Assigned<Option<T>>` for optional entity fields (set vs clear). Property sets patch through `PropertySetPatch`.
- Never write derived values (elevations, areas, volumes): they are inferences.

Outcome codes (`protocol::OutcomeCode`) and their wire ids:

| Situation | Code | Wire id | Target path |
|---|---|---|---|
| id to act on is absent | `TargetMissing` | `mutation.target-missing` | `[id]` |
| referenced entity is absent (parent, type, material, top storey) | `TargetMissing` | `mutation.target-missing` | `["field", "ref"]` of the field |
| id already used by a create | `DuplicateId` | `mutation.duplicate-id` | `[id]` |
| still referenced by something that cannot cascade | `TargetReferenced` | `mutation.target-referenced` | `[id]` |
| value breaks an invariant (non-positive, degenerate, non-finite) | `Invariant` | `mutation.invariant` | `["field"]` |
| value already equal | `NoOp` | `mutation.no-op` | `[id]` |
| cascade performed | `Cascade` (info message, not a refusal) | `mutation.cascade` | |

`reference-missing` maps to `TargetMissing` and `in-use` to `TargetReferenced` (the outcome vocabulary of the framework has no further codes). A refused mutation yields NO diff. A `diff` must be pure (no clock, no randomness).

## 9. Traps

- Wire shape: no `rename_all` on data types (snake_case fields, externally tagged data enums `{"Line": {...}}`, PascalCase unit variants); only the aggregate and `Entry` differ. Aggregate tag values are camelCase variants (`setStoreyHeight`).

- Never type or `sed` emoji paths or `\n` through a Bash heredoc: backslashes get stripped. Use the Write/Edit tools.
- A leaf must not import from another leaf except for the exact create payloads its inverse restores (`use super::super::create_wall::CreateWall`).
- Foundation leaves that Wave M must not rename: the twelve in `KINDS`.
