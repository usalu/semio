## 3. Design

- Identity: every element carries its model id in `Tag` (spatial elements and grids: `ObjectType`); GlobalIds are 128-bit hashes of `<entity>:<id>` in the buildingSMART alphabet, so they are stable and unrelated edits do not move them. Types carry their id in `Tag` and the parameters IFC has no slot for in the `Semio_Authoring` pset (storey level, wall phase, layer functions, profile of column/beam types, window/door parameters, door hand).
- Walls: straight and unjoined = `IfcWallStandardCase` (rectangle swept along a two-point axis); curved or joined = `IfcWall` with the join-trimmed footprint of `wall-layout` as `IfcArbitraryClosedProfileDef` (composite curve with trimmed circles), so the exported volume equals the inferred one. All walls carry an `Axis` representation and an `IfcMaterialLayerSetUsage` (layers left to right, `NEGATIVE` sense, offset = left face distance). Openings: `IfcOpeningElement` + `IfcRelVoidsElement`; windows/doors fill them (`IfcRelFillsElement`) with a frame ring and a pane or leaf; `flip_facing` turns the filling by half a turn.
- Slabs: level slabs extruded downward from storey elevation + offset by Σ layers (holes via `IfcArbitraryProfileDefWithVoids`); sloped slabs, roofs (one `IfcSlab` ROOF per layer under an `IfcRoof`), railings, curtain-wall members and plates are faceted breps of the inferred element solids; stairs aggregate `IfcStairFlight`s that carry their share of the stair brep (the EXPRESS rule forbids a body on a decomposed element). Columns/beams use rectangle, circle, I-shape or arbitrary profile defs. Spaces extrude the inferred room outline (islands as voids). Grids: one `IfcGrid` per building (U = lines nearer the y axis).
- Roof types: IFC2x3 has no `IfcRoofType`; they are `IfcBuildingElementProxyType` with `ElementType = 'RoofType'`.
- Quantities: `Qto_{Wall,Slab,Column,Beam,Window,Door,Space,Stair,StairFlight,Railing,CurtainWall,Roof,BuildingStorey}BaseQuantities` from the layouts, room, run and curtain layouts (`🧮️quantities` is not used yet).
- Import: spatial structure, storey levels (from `Level`, else from elevation order) and heights (`GrossHeight`, else the gap to the storey above), walls (`Axis` representation, layer set usage -> type and location line, swept body -> height and base), openings (host via voids, fill via window/door, centre offset by projecting the placement onto the host axis), slabs, columns, beams, spaces (explicit outlines), grids, materials, types, psets, classifications. Anything else (roofs, stairs, railings, curtain walls, members, plates, furniture, proxies, brep slabs) is one diagnostic per class with its count. Derived values (bulge, offsets, headings) are snapped to a micro-unit so the 1e-9 rounding of the file cannot flip a digit on re-export.

## 4. Findings of the third-party oracle (fixed)

1. EXPRESS: `IfcAxis2Placement3D` needs `Axis` and `RefDirection` together -> `axis3` supplies the missing one.
2. EXPRESS: a decomposed element must not have a representation -> stairs carry no body, their flights do.
3. The kernel tessellates circles: round columns/beams and arc walls are counted but not measured (documented in the feature).
4. Planar windows on curved walls protrude by the sagitta of their width: the audit checks the centre inside the host bounds there.
5. `IfcRoofType` does not exist in IFC2X3 (the schema lookup raised).
