# Shipping audit

The canonical gbXML house contains 12 spaces and 2,817 surfaces, occupies 11,192,960 bytes, and its independently measured JSON occupies 1,558,843 bytes. The high surface count preserves the exact curved room ring. Its WASI production export took about three minutes in this environment. All four declared cases are required by the CLI and pass official 7.03 XSD, lxml/Shapely/NumPy geometry, space closure, opening containment, applicable energy differential, and measured table read-back. The house has zero export notes.

The registered `ModelIntoGbxml::serialize` in `🚪️io/📤️export/🌿️gbxml/🦀️.rs` ignores `IoRunControl` and calls the full synchronous `export_gbxml` operation. Although `StagedGbxml` exposes stage boundaries, the serializer does not use it; the real house demonstrates this can run for minutes with no progress or cancellation in that IO operation. The editor model-export dispatcher handles BCF, IFC, GLB, SVG and CSV, but has no gbXML format branch. General IO does register the gbXML serializer as XML; the absence of an editor command is distinct from registration.

Mounted model inference remains a known shipping blocker: `🕸️model-graph/📡️session/🦀️.rs` explicitly refuses funded graph planning, node production and projection publication with `UnsupportedOwner`. The detailed funded API and missing producers are recorded in `🔬️mounted-inference.md`. The standalone browser worker harness is not proof of the OS application's complete routing, quota enforcement, retained receipts, or actual edit/export interaction; see `🔬️browser-harness.md` for its scope. The ongoing application builds and browser work may provide newer evidence.

The native viewer test run completed 38/42 at the time of the audit. One failure was mounted window command funding, one concerned missing energy IFC fixtures, and two were stale energy assertions. Other agents are addressing these. The native IFC2X3 integration was 14/15 before correction of a stale test assumption; IFC4 was 25/32 before production regeneration of its three stale fixtures and the import authoring fix. Those fixes still need fresh native tests. Full evidence and fixture mapping are in `🔬️ifc-oracle.md`.
