# 🏙️ BIM Plugin — Target Design (r2)

Ticket: `26/10/08/BIM-PLUGIN`. Inputs: `r1-explore-*.md` (plugin anatomy, artifact mutations, inferences, editor/viewer,
tests/tooling, io/persistence, concurrent state, aec/geometry).

## 0. Principles (non-negotiable)

1. **Snapshot = authored parameters only.** Nothing derivable is stored. A wall stores its axis curve, type, location
   line, base/top constraints — never its height, its solid, its length, its area. A storey stores its height and its
   level — never its elevation.
2. **Derived = inferences only.** Every derived value (elevations, wall heights, wall footprints/joins, opening frames,
   solids/meshes, quantities, room areas, stair risers, validation diagnostics, plan linework) is a `#[derived]` field of
   `ModelInference` computed by `💡️inferences/<emoji><slug>/` leaves (`Inference<ModelSnapshot>` aggregate +
   per-entity `InferredField<ModelSnapshot>` DAG fields with real cross-entity parents: storey → wall → opening).
   Parametricity is *exactly* this: change a storey height (one sparse patch on one storey) and every wall / column /
   stair / space height downstream is re-inferred.
3. **Mutations = sparse typed diffs + concrete inverses.** Every leaf `🔺️diff` builds a `ModelDiff` sparsely from
   payload + reads of `base`; every leaf `↩️inverse` builds concrete `ModelMutation`s (absolute setters restoring base
   values, delete↔create with the full captured record). Only `protocol::apply_diff` applies. Every leaf has a
   `🧪️tests` case calling `assert_mutation_inverse_sum_law` (gate R15). No `.apply(`, `between(`, `&mut`, base clones in
   leaves (gate R8–R16).
4. **No bim module.** There is no `🔨️modules/bim*`, no engine crate, no state holder. Everything lives in the one artifact
   crate `semio-s-artifact-bim-model` under `🗿️artifacts/🏢️model/🏅️standards/🔖️1/🪆️subsets/✳️any/`. Pure,
   domain-neutral geometry helpers that are missing go to the framework (`🧰️framework/🔨️modules/◻️2d`, `📐️geometry`,
   `🧊️3d`) — never a bim-specific module.
5. **Everything adjustable**: each authored parameter has a mutation kind (or belongs to a `set-*` kind of its entity).

## 2. Snapshot (`🧬️schema/📸️snapshot`) — `ModelSnapshot`

Units: metres (f64), radians (f64). Ids: `String` (stable, generated by commands from document id + op id).
All collections are `BTreeMap<String, Entity>` keyed by id (canonical order, no index positions → no reorder kinds).
Hierarchy by reference (`site`, `building`, `storey`, `host`).

```
ModelSnapshot {
  schema: String,                         // "s.bim.model@1"
  project: Project { name, description, author, organization, phase_names: Vec<String> },
  materials:    BTreeMap<Id, Material { name, category: MaterialCategory, color: Rgb, density, conductivity, specific_heat }>,
  wall_types:   BTreeMap<Id, WallType { name, layers: Vec<Layer { material, thickness, function: LayerFunction }> }>,
  slab_types:   BTreeMap<Id, SlabType { name, layers: Vec<Layer> }>,
  roof_types:   BTreeMap<Id, RoofType { name, layers: Vec<Layer> }>,
  column_types: BTreeMap<Id, ColumnType { name, profile: Profile, material }>,
  beam_types:   BTreeMap<Id, BeamType { name, profile: Profile, material }>,
  window_types: BTreeMap<Id, WindowType { name, width, height, sill, frame_width, frame_depth, panes: u32, material }>,
  door_types:   BTreeMap<Id, DoorType { name, width, height, frame_width, frame_depth, leaves: DoorLeaves, swing: Swing, material }>,
  sites:     BTreeMap<Id, Site { name, latitude, longitude, elevation, true_north, boundary: Vec<Point2> }>,
  buildings: BTreeMap<Id, Building { site, name, origin: Point2, rotation, elevation }>,
  storeys:   BTreeMap<Id, Storey { building, name, level: i32, height, cut_height: Option<f64> }>,   // elevation = inferred; cut_height = plan view convention (default 1.2 m)
  grids:     BTreeMap<Id, GridLine { building, label, start: Point2, end: Point2 }>,
  walls:     BTreeMap<Id, Wall { storey, wall_type, axis: Axis, location: LocationLine, base_offset,
                                 top: TopConstraint, phase: Phase, name }>,
  curtain_walls: BTreeMap<Id, CurtainWall { storey, axis: Axis, base_offset, top: TopConstraint,
                                 u_spacing, v_spacing, mullion: Profile, panel_material, mullion_material, name }>,
  columns:   BTreeMap<Id, Column { storey, column_type, position: Point2, rotation, base_offset, top: TopConstraint, name }>,
  beams:     BTreeMap<Id, Beam { storey, beam_type, start: Point2, end: Point2, top_offset, name }>,  // top_offset signed: + above, - below the storey top, 0 flush
  slabs:     BTreeMap<Id, Slab { storey, slab_type, boundary: Loop, holes: Vec<Loop>, offset, slope: Option<Slope>, name }>,
  roofs:     BTreeMap<Id, Roof { storey, roof_type, footprint: Loop, shape: RoofShape, overhang, base_offset, name }>,
  openings:  BTreeMap<Id, Opening { host, kind: OpeningKind, offset, sill_override: Option<f64> /* replaces the type sill; doors/voids default 0 */, width: Option<f64>, height: Option<f64>,
                                    flip_hand: bool, flip_facing: bool, name }>,
  stairs:    BTreeMap<Id, Stair { storey, start: Point2, direction, width, flight: StairFlight, top: TopConstraint,
                                  max_riser, min_tread, stringer: StairStringer { kind: None|Closed|Open|Mono, width, depth },
                                  nosing, tread_thickness, riser: Open|Closed, landing_depth, name }>,
  railings:  BTreeMap<Id, Railing { storey, path: Vec<Point2>, height, post_spacing, profile: Profile, post_profile: Profile,
                                    baluster: Option<Baluster { profile, spacing }>, infill: None|Glass{thickness}|Panel{thickness},
                                    material, base_offset, name }>,
  spaces:    BTreeMap<Id, Space { storey, number, name, boundary: SpaceBoundary, usage: String }>,
  properties: BTreeMap<Id /*element id*/, BTreeMap<String /*pset*/, BTreeMap<String /*prop*/, PropertyValue>>>,
  classifications: BTreeMap<Id /*element id*/, Classification { system, code, title }>,
}
Axis       = Line { start: Point2, end: Point2 } | Arc { start: Point2, end: Point2, bulge: f64 }  // bulge = tan(θ/4); curve adjust = set bulge
Loop       = Vec<Vertex { point: Point2, bulge: f64 }>   // closed, CCW, bulged segments
TopConstraint = Unconnected { height } | StoreyTop { offset } | Storey { storey, offset }   // parametric hook
LocationLine = Center | Interior | Exterior | CoreCenter
Profile    = Rectangle { width, depth } | Circle { diameter } | IShape { width, depth, web, flange } | Custom { outline: Loop }
RoofShape  = Flat | Shed { pitch, direction } | Gable { pitch, ridge_direction } | Hip { pitch } | Mansard { lower_pitch, upper_pitch, break_height }
OpeningKind = Window { window_type } | Door { door_type } | Void { width, height }
StairFlight = Straight | LTurn { split, turn: Turn } | UTurn { gap } | Spiral { radius, sweep }
SpaceBoundary = Bounded { seed: Point2 } | Explicit { outline: Loop }      // Bounded = inferred from walls
Slope      = { direction, angle }
Phase      = Existing | New | Demolished | Temporary
PropertyValue = Text | Real | Integer | Boolean | Length | Area | Volume | Angle   (typed)
```

Referential integrity is checked in `🔺️diff` (refusal `mutation.reference-missing`, `mutation.target-missing`,
`mutation.duplicate-id`, `mutation.in-use`). Deletes of a parent are concrete composite-free cascades: `delete-storey`
emits removals of the storey **and** every element on it (and openings hosted by those walls) in one sparse diff; its
inverse recreates every captured record (one `create-*` per removed record — `x-semio-inverse-rows` declares the bound
as `"unbounded"`/per payload as the derive supports).

## 3. Diff (`🧬️schema/🔺️diff`) — `ModelDiff`

```
ModelDiff {
  project: Option<ProjectPatch>,
  materials: Option<KeyedDelta<Material, MaterialPatch>>, wall_types: ..., slab_types, roof_types, column_types,
  beam_types, window_types, door_types, sites, buildings, storeys, grids, walls, curtain_walls, columns, beams, slabs,
  roofs, openings, stairs, railings, spaces,
  properties: Option<KeyedDelta<PropertySet, PropertySetPatch>>, classifications: Option<KeyedDelta<Classification, ClassificationPatch>>,
}
KeyedDelta<T, P> = BTreeMap<Id, Entry<T, P>>   with Entry = Created(T) | Deleted | Replaced(T) | Patched(P)
<Entity>Patch     = one Option per field (absent = untouched)
```

- `apply(base, capability)`: validates every entry first (Created ⇒ absent, Deleted/Replaced/Patched ⇒ present), then
  builds the next snapshot; refusal `MutationApplyError` with target `[collection, id]`. Never clamps, never ignores.
- `absorb` (sequential, structural, total, base-free): per key — Created∘Patched → Created(patched),
  Created∘Deleted → ∅, Deleted∘Created → Replaced, Replaced∘Patched → Replaced(patched), Patched∘Patched → merged
  patch, Patched∘Deleted → Deleted, Patched∘Replaced → Replaced, Replaced∘Deleted → Deleted. Patch merge = later field
  wins.
- `DiffAlgebra::inverse(base)`: concrete negative diff (Created → Deleted; Deleted → Created(base record);
  Replaced → Replaced(base record); Patched(p) → Patched(base values of exactly p's fields)).
- `between` exists for sync/import only (never called from leaves).
- `DiffRegions::touches()` yields `/<collection>/<id>[/<field>]` so `infer_field_after_diff` gates inference fields.
- `KeyedDelta`/`Entry` algebra is written once in `🔺️diff` (pure, artifact-local); every `<Entity>Patch` implements a
  tiny `Patch<T>` trait (`write(&T) -> T`, `merge`, `negate(&T)`, `is_empty`).

## 5. Inference catalogue (`🧬️schema/💡️inferences/<emoji><slug>/`) — `ModelInference` (`s.bim.model.inference`)

| Field | Kind | Parents | Output |
|---|---|---|---|
| `🪜️storey-levels` | `InferredField` key storey | storey below (by `level`) | elevation, top elevation, building-relative and absolute |
| `🧱️wall-layout` | `InferredField` key wall | its storey (+ `Storey` top constraint target) | resolved base z, height, thickness (Σ layers), offset curves left/right per location line, length, join-trimmed footprint (L/T/X joins with walls sharing endpoints) |
| `🪟️opening-frames` | `InferredField` key opening | host wall layout | local→world frame, resolved width/height/sill, validity (inside host, no overlap) |
| `🧊️element-solids` | `InferredField` key element | layouts / storey levels | triangle meshes (walls with opening voids and reveals, curtain grids/mullions, columns/beams by profile sweep, slabs with holes/slope, roofs by shape, stairs, railings) + per-element bounds |
| `🏠️spaces` | whole-snapshot | walls layout | room outlines (from seed via wall-face arrangement or explicit), area, perimeter, volume, height |
| `🧮️quantities` | whole-snapshot | layouts, solids | per element: length, gross/net side area, volume, opening area, count; per type and per material totals; per storey totals (QTO) |
| `🪜️stair-runs` | `InferredField` key stair | storey levels | riser count, riser height, tread depth, going, landings (code-compliance flags: 2R+T rule) |
| `🗺️plan-linework` | whole-snapshot per storey | layouts, frames | cut-plane linework (cut walls poched, openings with swings, columns, stairs with arrow, spaces with tags) for plan windows and SVG export |
| `⚠️diagnostics` | whole-snapshot | all | clashes (overlapping walls/columns/beams), orphan references, openings outside host, overlaps, zero-length walls, storey gaps, stair rule violations |

Inference law tests: determinism, default, `infer_field_after_diff` gating (touch storey height ⇒ walls on that storey and
above recompute; touch a material color ⇒ layouts untouched), cancellation keeps finished values. Oracle: Python
(`shapely` for footprints/areas, `ifcopenshell` for IFC round trip/quantities) + TypeScript (`three` for mesh volume/area)
reproduce the committed `🧫️fixtures/💡️inferences/**/🔣️.json` outputs.

## 10. Rulings (Wave Z, mutation fixes)

1. **Ids are unique across every collection** (elements, materials and every type library). `mutations::elements::taken(base, id)` is the one predicate; every `create-*` diff and `split-wall`'s `new_id` refuse `mutation.duplicate-id` on a hit of any kind (the message names the kind that holds the id). Each create family has an `id-taken-by-another-kind` rejected fixture.
2. **A delete removes the element's data.** Every delete leaf (single-element ones included) routes through the shared cascade: the element, the elements that cannot exist without it (a curtain wall takes its hosted openings, like a wall), and the `properties`/`classifications` entries of every removed element leave in one sparse diff. The inverse is one concrete create per removed record plus one `set-element-property`/`set-element-classification` row per removed entry (`x-semio-inverse-rows` bounded). Types and materials own no entries (data is keyed by element id).
3. **`rehost-opening` is gone.** `move-opening` re-hosts with the fit and overlap validation; `split-wall` still hands openings over by sparse opening patches and its inverse restores the axis, moves the openings back with `move-opening` rows and deletes the created wall last.
4. **`set-*` leaves emit only fields that change.** `Patch::minimal(base)` drops restated fields; all restated is `mutation.no-op`; the inverse restores exactly the fields that changed.
5. **Whole-list replaces.** A list that is ONE owned value is replaced as one field: a type's layer stack (an ordered build-up without identities), the project phase names (one ordered vocabulary, exported as one IFC string), a railing path, a site boundary, a roof footprint, a slab's boundary and holes (one planar region validated together). A collection of independently addressable items would be keyed by id; no snapshot list is one.
6. **`PropertyValue` is the typed enum** `Text | Real | Integer | Boolean | Length | Area | Volume | Angle`, each variant `{ value }` (JSON `{"Length":{"value":2.5}}`); `PropertyKind` is retired. In the text language the value is carried as its schema value (intrinsic `Shape::Value` field).
7. **No inference engine in a diff.** A column's top check reads `placement::rise` / `storey_elevation`, a pure sum of stored storey heights along the building's stacking.
8. **Authored depth (Wave Z2).** An opening's sill is `sill_override: Option<f64>`: it REPLACES the sill of the window type (`None` = the type sill; doors and voids default to 0); it is never added to anything. A storey authors its plan view convention as `cut_height: Option<f64>` (`None` = 1.2 m, `validity::DEFAULT_CUT_HEIGHT`), set by `set-storey-cut-height` (an assigned null returns to the default). A stair authors its construction (`stringer{kind,width,depth}`, `nosing`, `tread_thickness`, `riser` open or closed, `landing_depth`) and a railing its sections (`profile`, `post_profile`, optional `baluster{profile,spacing}`, `infill` none, glass or panel); the standard values reproduce the former constants. A beam's `top_offset` is a signed distance of the beam TOP from the storey top: positive above, negative below, zero flush. Roofs over concave footprints come from the framework straight skeleton (`semio_framework_geometry::{skeleton, roof}`); see `r7-api-skeleton.md` and `r7-depth-inference-handoff.md`.
