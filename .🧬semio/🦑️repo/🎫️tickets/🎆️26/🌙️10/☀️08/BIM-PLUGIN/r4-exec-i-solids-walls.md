## 1. Result

`ModelInference.element_solids: BTreeMap<String, ElementSolid>` exists. One `InferredField` (`ElementSolidsField`, key `SolidKey { source, id }`, value `SolidNode::{Level, Solid}`), storeys are the roots, every element depends on its storey (and the storey its top constrains to), each family implements `SolidFamilyBuilder` (`plan`, `dependency`, `compute`). My three families:

| Family | What is built |
|---|---|
| walls (`E/🧱️walls`) | one closed body per layer (material + layer index), join-trimmed ends taken from `wall-layout` (`left_face`/`right_face`, layer interfaces cut on the straight miter line, also on arcs), every valid opening (window, door, void) cut through all layers as hole with reveals, sill-0 openings as bottom notches, arcs tessellated within `CHORD_TOLERANCE = 1e-4` |
| curtain walls (`E/🪟️curtain-walls`) | grid from `curtain-layout` (`u_panels` x `v_panels`), vertical mullions full height, horizontal mullions between them, outer ones inside the extent, 0.024 m flat panel per cell; mullion outline from `Profile` (rectangle, circle, I-shape, custom loop) |
| fillers (`E/🚪️fillers`) | window: frame ring (4 boxes) + `panes - 1` muntins + `panes` glass panes (material `""`); door: frame (2 jambs + head) + 1 or 2 leaves; void and invalid placements: none; placed with the `local` frame of `opening-frames`, centred in the host thickness, flip-aware |

Design decisions: solids are OWNED triangle meshes (flat `f64` positions/normals, `u32` indices, one group id per triangle) in building-local coordinates plus a `SolidPlacement` (building origin, rotation, datum) so a viewer instances them; colour is never stored (material ids only), so a colour edit never invalidates a mesh; the mesh arrays are exactly the `MeshData` arrays of a `World3d` inline mesh (`positions_f32`, `normals_f32`, `indices`, `vertex_colors`, `face_ids`). Layer order follows `wall-layout` (left face = interior first). Openings come from `opening-frames` (`frame_of`: validity, cut rectangle, local frame); curtain-wall hosts get fillers but their panels are not cut (limit).
