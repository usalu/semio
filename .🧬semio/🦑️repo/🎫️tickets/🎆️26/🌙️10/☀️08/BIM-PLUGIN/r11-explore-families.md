## Expression / formula evaluation in the repo
- No reusable domain-neutral formula language: no text parser (no Pratt/shunting-yard anywhere), no unit-aware evaluator,
  no formula dependency extractor.
- `semio-framework-math` (`🧰️framework/🔨️modules/🧮️math`): LLM sampling/noise engine — not usable.
- `📚️compiler/🧮️math`: typesetting layout — not usable.
- `semio-framework-number` (`🔢️number`): zero-dep big ints/rationals/intervals — usable substrate only.
- Equation CAS (`➗️mathematical/…/🌿️cas-internals`, 5091 lines): `Expr` tree, subs, simplify, diff, `free_symbols`; no
  parser, no units, no evalf; mounted inside the equation artifact crate (heavy deps: ui, plugin, os-kernel).
- CAD interaction-spec `Expr` (`📐️cad/…/🎬️interaction-spec`): JSON AST, `evaluate_expr → DslValue`, plugin-local.
- Forms `FormExpr`: closed boolean tree, `collect_condition_vars` dependency extraction; no arithmetic.
- Flow math operators (`🌊️flow/🧩️extensions/🧮️math`) on `neural_engine::Operator`: runtime dataflow, not a formula language.
- `semio-framework-graph` `topo_sort`, `would_create_cycle_ids`: index-based; crate pulls ui-locale/ui-contract.
- Units: none reusable (energy `Unit` enum without arithmetic; CSS lengths private).

## BIM today
- 8 `*Type` records: WallType/SlabType/CeilingType/RoofType (layers), ColumnType/BeamType (Profile, material),
  WindowType (width, height, sill, frame_width, frame_depth, panes, material), DoorType (… leaves, swing).
- `Profile` = Rectangle{width, depth} | Circle{diameter} | IShape{width, depth, web, flange} | Custom{outline}.
- `PropertySet` typed key-value table per element; `ScheduleKey::Property`.
- Snapshot/value files are generated by `T/r3-f1-gen-model.ts`.
