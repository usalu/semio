# r11-exec-store-s: stdio crates in the BIM dependency closure

Gate: `cargo check --keep-going -p semio-s-artifact-bim-model --lib` (logs `T/🗑️generated/r11-store-s/c1..c7.txt`).
Last run (c7): the only stdio crate still failing is `semio-s-artifact-stdio-pdf` (8 errors, delegated by r11-store to helpers; I only did a first pass there). The BIM crate itself was not reached because it depends on pdf. Every other stdio crate in the closure (deflate, txt, csv, json, xml, step, svg, gltf, ifc and their dependencies) compiled in c7.

## Patterns applied
1. `#[derive(semio_framework_value::RetireOwned, ...)]` (first in the list) on every Snapshot/Mutation type, nested leaf/field types and mutation-support path types of: txt, deflate, csv, json (base, i-json, mutation-support `JsonPathSegment`), xml (`XmlNodePath`), svg, gltf (multi-line derive layout handled with a small item-aware pass), ifc (mutations only; the snapshot already has hand-written retirement), step (mutations only), pdf (snapshot, mutations, stream-roles; first pass).
2. deflate `InteractiveJob` family (`DeflateEncodeJob`, `TunedDeflateEncodeJob`, inherent `RetainedZlibDecoder`/`RetainedZlibEncoder`): `close_step(grant: RetainedCloneGrant)`; flat owners are released whole per turn (`FlatBacking` helper: copied_items 1, released_bytes = capacity bytes), publication payload pages use the job crate writer with `JOB_PAYLOAD_PAGE_BYTES`; honest demands (`copy 0`, `capacity 0`, `release` = next physical backing, `depth` 1 until terminal-empty); a grant below any axis or `maximum_items == 0` yields `Pending{default}` without mutation; `Complete` only at the terminal-empty witness. Dynamic engine (`🗜️dynamic`) exposes `next_close_release_bytes()` / `close_step() -> Option<usize>`. The framework `semio_framework_deflate::Inflater` keeps its own items/bytes close API (unchanged, compiles) and is wrapped by the new grant.
3. Native cold retirement in `step`, `ifc4`, `ifc2x3` sqlite native modules (`close<T: RetireOwned>`): `owned_retirement` + `close_step(256,65536)` replaced by `ControlledRetirement::new(value)` driven with its own quoted per-axis demands.
4. 677 fall-out fixes: json i-json and xml valid `derived_construction` now import `crate::apply_mutation` (the import had been put into the wrong module); txt `splice-text` leaf used the unapproved verb `splice` (now `edit`, record `EditedText`, label already "Edit Text"); gltf `GltfNode` import in move/reorder node leaves and restored the removed `texture_info` helper that the top-level-collections module still uses; svg tiny `ReinstateNonTiny` variant vs kind mismatch (kind, KINDS, leaf JSON `semanticKind`/`displayName`, oracle JSON and oracle match arm now say `reinstate-non-tiny`); pdf: `stream_roles` path in the snapshot value decoder made absolute, `lift_document_with` partial move fixed with `mem::take`.
