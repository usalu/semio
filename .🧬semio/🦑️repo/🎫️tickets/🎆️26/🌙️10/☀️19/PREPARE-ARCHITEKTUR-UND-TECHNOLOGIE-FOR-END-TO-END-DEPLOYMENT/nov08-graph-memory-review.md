# Graph inference memory source review

Static review following one critical-pressure sample; it does not establish a leak or attribute the host peak. Observation source-analysis JSON images have a process-local oldest-first 16,777,216-byte accounting bound, excluding source buffers and parser trees; serialized project images have a separate 67,108,864-byte bound and 1,048,576-byte per-image bound (observation schema). These are not total-heap bounds.

The script-input files, closures and command-dependencies Maps belong to a graph/worker scripts environment. Process-level closure entries, flights, failures and known-input Maps persist in process; inspected creation/memo paths have no explicit aggregate byte or entry eviction bound. They retain observed values/rows with validity rechecks and explicit closure reset available. Precision context is keyed by scripts and retains Cargo maps, a lazy manifest list and tsconfig options. Per-project locals can leave scope after completion, but shared caches deliberately persist; source does not prove collection of every temporary object or live unbounded growth.

The optional long-lived TypeScript deriver reuse store in script-inputs/♨️reuse/🟨️.mjs retains compiler programs and parsed files. Its end removes unused parsed files for configurations touched in that question; programs and files for untouched configurations remain. Only a long-lived deriver installs it; this review does not establish whether it is active or its size in the sampled process. The ordinary precision program host map in project assembly holds parsed tsconfig options, not compiler Program objects.

Farm policy at project-nodes/🏊️project-farm/🏊️pool/🧬️schema/🔣️.json recycles workers after 96 completed projects or the declared RSS/growth thresholds. Checks occur on worker replies and therefore are not instantaneous peak limits during a long job. Bun worker heap setting uses 0.75 of assigned worker MiB; parent and whole-process memory are distinct. Recycling clears that worker process's memos; no actual recycling event was established here.
