# Native MSVC Acquisition And Extraction Contract

The native Go helper accepts `acquire --recipe <absolute pins.json>` and `extract --recipe <absolute pins.json>` with the same version 1 JSON request on stdin. The request contains `inputsRoot`, `stageRoot`, `catalogSha256`, `recipeSha256`, and `manifestSha256`. Acquisition requires an empty owned physical inputs directory; extraction requires an empty owned physical stage. Both emit JSONL progress and return nonzero on failure. The publisher must bind the helper build to admitted Source, retain its allocation and lease, hold the existing native short-path alias for the entire child lifetime, and verify the complete staged tree before publication. A forcibly terminated Windows process cannot be relied upon to run Go cleanup; the owner must clean the allocated directories by identity after the process exits.

Acquisition checks the pinned recipe before reading its URL, accepts only HTTPS Microsoft download URLs and redirects, checks the fixed catalog length and SHA-256, verifies every selected catalog entry against the recipe, then streams each payload into a newly created file with its exact length and digest. Cancellation and failed transfers remove files whose identities still match the files created by the operation. No MSI installation actions run. The extraction phase independently holds and verifies payloads and validates the resulting inventory.
