Scene file: `🎓️teaching/🏛️architecture/🦗️grasshopper/🎬️clip/💊️capsule/🐍️.py`. Binding rules: `morph-plan.md`. Status: Phase A (this storyboard) done. Phase B is blocked: `api.md` has no section 7 and `🎓️teaching/🏛️architecture/🔀️morph/` does not exist yet (MORPH-TOOLKIT not delivered). Nothing in the scene was edited.

All numbers come from the model/engine solution (`_read(solution)`, `capsule_types()`, `slots()`, `evaluate`); the numbers below are placeholders by name, never typed values. The 23 clauses and their en/de narration stay as they are (14-24 rule holds); only the on-screen change per clause is rewritten. Captions stay at most two lines.

## The through-line (one capsule, many forms)

The lit capsule of the tower is the same object for the whole video:
tower capsule (`silhouette`) -> output chip of Center Box (hook) -> the box that grows with the width token (parametric, box) -> rounded shell (rounded) -> shell with window (cut) -> plane-A token (orient) -> capsule at plane B -> type token "A" in the List Item list -> capsule on plane 0..7 -> legend icon "Geometry" (recap). Its colour is the type colour (`type_color`) once types appear; the slider colour bars (width red, length green, height blue, radius violet, window orange, offset teal) are the colours of the value tokens and of the dimension lines they become.

Directions: C->A = concrete to abstract, A->C = abstract to concrete. Used: C->A 8 times, A->C 8 times, many of them chained.

## Implementation plan (for Phase B)

- Use `🎓️teaching.🏛️architecture.🔀️morph.🐍️` helpers: `silhouette()` for the lit capsule and each capsule on the core, `proxy()` for the tower, `morph`, `gather`, `split`, `scatter`, `travel`, `tether`, `token`, `retext`.
- The scene stays driven by `ValueTracker`s and `Live` stages; morphs run as extra mobjects layered over the stage in the `step(...)` animation groups, then the stage redraw takes over (no jump: the target state at the end of each morph equals the stage frame).
- New scene helpers (concise, docstring emoji): a `_chip(value, key)` token factory (slider colour, language-aware number via `self.number`), a `_silhouette_of(drawing)` for `capsule_axon` groups, and a `_leader(a, b, color)` tether.
- Per-clause time budgets stay inside the existing `seconds=` of each step (hook 4 -> 5 s, sliders 5 -> 6 s, box 6 -> 7 s, cut 6.5 -> 7 s, bolts 7 -> 8 s, orient 6 -> 7 s, listitem 7 -> 8 s; matching narration length, no new clauses).
- German: tokens use language punctuation (`self.number`), labels via `self.tr`; no new strings except token labels (reuse the existing slider names).

## Risks and notes

- `capsule_axon` groups are heavy; morph from `silhouette()`, never from the full face set; the tower from `proxy()`.
- `_stage` redraws every tick from the tracker values; a morph target must be sampled from the same drawing (`drawing.at(...)`) so there is no jump at the handover.
- Foreign edits: a codex session edits the Nakagin model and drawings and this scene's transcripts; re-read this file immediately before each Edit and use small diffs. `bolts` depends on the shared drafting `P` (array return).
- Counts to take from disk: `len(slots)` (tower A 76, tower B 64 at the time of writing; the hook counter uses the total), item lists of one or two items per branch.
