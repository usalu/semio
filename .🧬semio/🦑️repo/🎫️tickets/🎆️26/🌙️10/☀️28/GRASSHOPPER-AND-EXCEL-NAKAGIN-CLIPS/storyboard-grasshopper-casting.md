# Storyboard: grasshopper_casting (`Beat4_Casting`, topic 🫗️casting)

Scene file: `A/🦗️grasshopper/🎬️clip/🫗️casting/🐍️.py`. Facts: `T/research-casting.md` (authoritative over `research-grasshopper.md` section 2.2).

## Learning goals

1. Every parameter has a type; a wire between different types makes Grasshopper cast the data, in a fixed order (same type, source converts, target reads, else error).
2. Casting changes data silently: Number to Integer rounds (ties to even, 2.5 gives 2), Point to Plane invents a world-aligned plane, Number to Domain invents a start at 0.
3. A cast can only map existing data: Text "Type A" to Number fails (red component, blank output); a Value List is the explicit fix.
4. Casts are no substitute for construction: a Point as Plane puts the capsule on the facade with the wrong orientation, which motivates explicit planes.
5. A casting matrix (source type by target type) summarises what was shown; the habit is to check the result with a Panel.

## Misconceptions addressed

- "A wire accepts anything" or "a wire builds missing geometry" (it does not: the cast only maps data types).
- "Number to Integer cuts off the decimals" (the verified source shows rounding with ties to even; 2.5 gives 2, 3.5 gives 4). Teach Round, Floor, Ceiling for deliberate rounding.
- "A Point as Plane keeps the facade direction" (it becomes a world-XY plane).
- "Text that looks like a label can be a number" ("Type A" fails).
- "Casting is harmless" (it silently changes values; check with a Panel).

## Evidence marker rule

VERIFIED rows are shown as fact: Text to Number failure and its message, ties to even (David Rutten, 5 Jan 2010), Boolean to Integer, Point to Plane (world XY at the point), Line to Plane (line becomes the Z axis), cast order. UNVERIFIED rows carry the on-screen marker `teaching assumption — check in Rhino 8` (en) / `Lehrannahme — in Rhino 8 prüfen` (de): Text "2.5" to Number success, Number to Domain, Circle to Curve, Box to Brep, Integer to Boolean. In the matrix those cells have a dashed outline and the marker in the legend.

- Slot used for the west facade and its plane come from `slots()`.
