# Morph storyboard: excel / 📋️program / `Beat3_Program`

Scene: `🎓️teaching/🏛️architecture/📊️excel/🎬️clip/📋️program/🐍️.py`. Plan: `morph-plan.md`. Toolkit: `🔀️morph` (api.md section 7). Status at writing: Phase A only (toolkit not yet `ready`).

## Decisions

- Keep all 24 clauses and their keys (transcripts are edited elsewhere; `sync-transcripts.py` stays valid). Narration text stays unchanged except where a beat needs a half sentence (marked "narration +"). Captions stay at most 2 lines.
- Every number stays from the engine/model (`self.vals`, `self.swapped_vals`, `self.typo_vals`, `_nk.slots()`); counts 36/35/34/35 = 140, towers 54 / 86 are read at run time.
- Morph sources are cheap: per-capsule `silhouette()` of `tower_axon(...).capsules[key]` (never the whole tower), fitting rectangles of `plan().fits`, cell texts of `Window.cell(a1).text`, bars of `xl_bar_chart`. Tower stays drawn at ghost opacity while copies travel.
- Colour carries always: type colour (A teal, B orange, C green, D violet), fitting colours, GOOD for areas, reference-frame colours for formula tokens.
- Chains (same object, several forms): **swap capsule** (type C row, `self.swap_row`): tower capsule -> table row (B7) -> lit capsule (B8) -> exchanged capsule + cell text (B14) -> delta chips -> bar (B14). **typo capsule** (type B): tower capsule -> counted in 139 -> red space dot -> ring (B15) -> TRUE. **Free floor of type C**: plan hatch -> cell C23 value (B11) -> product tiles/bar (B12) -> plan C hatch (B11 back via XLOOKUP).
