# Storyboard: excel_references (`Beat2_References`, topic 📍️references)

Series 📊️excel, file `A/📊️excel/🎬️clip/📍️references/🐍️.py`. Facts from `research-excel.md` §2, §3, §6 and `research-nakagin.md` §3. Cell addresses below are placeholders by meaning; Phase 2 binds each to the real address in the engine workbook (`Nakagin.xlsx`, sheets Program, Type A–D, Climate, Energy) and every number is read from the engine, never typed in the scene.

## Learning goals

1. A reference points to a cell, not to a value: change the source and every formula that uses it follows.
2. Relative references move with a copy; compute the offset (Δcolumn, Δrow) first, then apply it to the relative parts only.
3. `$` fixes a column, a row, or both (F4 cycles A1 → $A$1 → A$1 → $A1); mixed references make a two-way table from one formula.
4. A reference can leave the sheet (`'Type A'!B3`, quotes for the space) and span sheets (`SUM('Type A:Type D'!B12)`); a defined name (`Theta_i`) is a readable absolute reference.
5. Two typical failures and their cure: a relative copy that slides off its input (wrong values, wrong face lit) and a deleted sheet (`#REF!`).

## Misconceptions addressed (research-excel §7)

- 3: copying a relative reference shifts both column and row by the copy offset.
- 4: `$` only matters when copying; it does not protect against deleting or moving sheets.
- 9: `SUM('Type A:Type D'!B12)` adds the one cell B12 on every sheet in the span, not a block; moving a sheet out of the span removes it.
- Own: a quoted sheet name is text, so filling down does not turn `'Type A'` into `'Type B'`.

## Recap table (clause 20)

| Kind (EN) | Art (DE) | Example | Behaviour on copy |
| --- | --- | --- | --- |
| Relative reference | Relativer Bezug | `B5` | column and row shift by the offset |
| Absolute reference | Absoluter Bezug | `$B$1` | nothing shifts |
| Mixed reference | Gemischter Bezug | `$A5`, `B$2` | only the unlocked part shifts |
| Sheet reference | Blattbezug | `'Type A'!B3` | sheet name is fixed text |
| 3D reference | 3D-Bezug | `SUM('Type A:Type D'!B12)` | same cell on every sheet between the tabs |
| Defined name | Definierter Name | `Theta_i` | behaves as an absolute reference |
