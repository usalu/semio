# Morph Storyboard: Grasshopper Tower (Beat3_Tower)

Scene `🎓️teaching/🏛️architecture/🦗️grasshopper/🎬️clip/🗼️tower/🐍️.py`, class `Beat3_Tower`, folder 🦗️grasshopper / 🗼️tower. Source of truth for narration: the `NARRATION` list on disk (22 clauses, kept; no clause is merged or rewritten, so the transcripts that the codex session edits stay in sync). Numbers are read from the model/engine: tower A 76, tower B 64, total 140; `high` storeys from `Tree Statistics`; branches with one or two items; planes from `canvas("tower")` trees `mv`, `slots`, `cullp`, `ori`.

Toolkit names are those of `morph-plan.md` (`morph`, `scatter`, `gather`, `split`, `token`, `travel`, `tether`, `unfold`, `retext`, `proxy`, `silhouette`). Heavy tower groups always enter through `proxy()` or per-capsule `silhouette()`.

## Hero chain

One capsule is followed through the whole clip: tower B, storey 3, facade 1, item 0 (`capsules[(0,1,3,1,0)]`, `HERO`). Its identity: type colour, path `{0;1;3;1}`, index 0.

`series`: storey slab line -> list item (elevation) -> plane square. `facades`: plane -> facade frame. `orient`: frame square -> HERO capsule (arrives on its plane). `types`: HERO capsule tints with the pattern chip A. `count`: HERO lights up and flies into the sum. `fix`: HERO stays, the two culled neighbours shrink into index tokens. `total`: HERO is one of the 140 lights that gather into the number. The same orange/teal colour of the type chip is kept in every form.

## Replacements of fade-swaps

The current `stage()` helper fades out the previous network, drawing and note and fades in the new ones on every clause. It stays for the canvas frame and the note text, but each clause whose row above has a morph replaces the `FadeOut`/`FadeIn` of the drawing by the listed morph. Clauses without a morph (`mistake` caption, `why`) keep the fade of the note only. The `why` clause is the same building: the "5 components vs 49 components" cards turn into small silhouettes of the extrusion (one capsule) and 140 copies (`gather` 1.2 s), replacing the fade.

## Fallbacks

- If `scatter`/`gather` with 140 elements is too slow at 4 fps capture, morph from the `proxy()` of each tower storey (20 shapes) and keep the lag so the order is still visible.
