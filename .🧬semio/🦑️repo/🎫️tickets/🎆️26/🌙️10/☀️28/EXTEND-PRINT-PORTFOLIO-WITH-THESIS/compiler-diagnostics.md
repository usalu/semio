# Actual Compiler Failure Diagnostics

The first actual production script child reached real Tectonic after successful pinned compiler, TeX and font preparation. The child returned status1 with no signal. The compiler owner discarded its already captured stdout/stderr and threw only a generic OwnedCommandFailure. Its existing refusal hook retained a TeX log privately for the negative-probe inspector, but ordinary publication did not consume that protocol. Later cleanup admission failures therefore obscured the compiler reason. The own failed workspace remained temporarily, but no .log file was recoverable there during bounded read-only inspection; no concrete TeX root cause is claimed yet.

Added a pure bounded formatter for the already captured terminal result. On failure only, the production compiler emits its tail to stderr before calling the existing exact-primary refusal hook. It performs no new storage operation, does not renew/reopen Original admission, does not change compiler outcome or cancellation, and catches formatting/output exceptions so they cannot replace the primary. The stdout structured inspector record remains separate and unchanged.

The schema limits console diagnostic output to16384 UTF8 bytes and128 lines, further reduced by the actual caller's transport bounds. Tail truncation skips UTF8 continuation bytes at its start and preserves valid final characters. Success remains silent. The existing WeakMap refusal data, request digest checks, child inspector boundary and exact-primary rethrow remain unchanged. Parent publication capture is independently retained by the entry owner before its own failure.

TDD evidence: new neutral diagnostic vectors initially failed because the formatter did not exist. A subsequent explicit line-ceiling vector also failed before the line bound was added. Final full refusal suite passes10tests/107assertions, including existing AJV/SQLite refusal protocol and exact-primary checks, combined stream diagnostics, success silence, UTF8-tail boundaries, signal output, smaller caller line/byte transports, larger transport policy capping and source-order verification before the unchanged refusal hook. No compiler rerun was launched by this change.
