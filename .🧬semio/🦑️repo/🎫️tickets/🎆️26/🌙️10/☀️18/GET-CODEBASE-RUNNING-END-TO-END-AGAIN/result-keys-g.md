## Read oracle (law evidence, macOS)
`readoracle.py`: Seatbelt profile denying reads of every workspace file outside the declared list for the whole process tree (kernel enforced, native code included); denied paths come from the unified log (`/usr/bin/log show`; report mode is rate-limited, enforcement is not); `--rounds N` learns missing inputs; `--budget` complement mode because the compiled profile is limited to 64 KB. Results (`evidence/`): course-react `test` with the landed declaration: 0 denials, 1,051 pass / 2 fail where the UNsandboxed baseline fails 3 (ICU `Intl` list-format locale differences, not reads); dashboard `test-language` final set: pass, 0 learned. Findings by the oracle: (a) `workspaceTestAliasesV1` reads every Bun workspace `package.json`/ownership tsconfig, (b) course-react `test` reads generated mirrors (ui tokens, asset icons, ui axes) without `dependsOn` of their generators (pre-existing ordering gap, typecheck has it; left as is), (c) root `package.json` is read by `bun test` and is in no declared set (small; sharedGlobals). Linux/Windows have no implementation (a bwrap/Landlock backend is the interface slot): the law is macOS-only for now, stated plainly.
