## How to run a test that needs the process envelope (this is why most of them were "red")
Plain `bun test ./<file>` has no issued parent Script envelope, so every suite that calls `receiveScriptProcessInvocation` fails with `Original parent Script process invocation required` by design. Single-file recipes that work without the graph (tools: `C/red-g-tools/both.sh`, prints plain and envelope side by side):
- process-module suites: `VF_WALL=300 bun C/ver-f-tools/proc-run.ts file <abs test file>` (artifact dir issued, `artifacts` capability)
- caller-birth suites (authorizer memo, native caller): `sh C/chain-g-tools/run-test.sh ./<file>` (build bootstrap capabilities, no `artifacts`)
- Nx-gated library suites: `sh C/obsrows-g-tools/run.sh <build-relative file> <log>` (genuine birth)
