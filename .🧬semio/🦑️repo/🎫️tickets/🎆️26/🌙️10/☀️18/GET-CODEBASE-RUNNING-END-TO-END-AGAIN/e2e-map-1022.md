## 1. Orchestration model (from orch.py and run.sh)

- Entry: `sh C/e2e-orch-tools/run.sh <play|demo|course|all> --phase <list> --go --run-id <id> [--parallel N] [--rerun]`. Default `--phase all` = preflight, cold, warm, e2e, report. Probe runs only with `--phase probe` (or listed explicitly). Without `--go`, cold/warm/e2e/probe are refused.
- Per product: one sequential pipeline, phases in order cold, warm, e2e, probe; steps within a phase in plan order.
- Products run in a thread pool, bounded by `--parallel` (default min(products, Bazel build slots = 3)). Start stagger 20 s x (plan `order` - 1): play 0 s, demo 20 s, course 40 s.
- Child process: `bun repo --tool=bazel <args>` for kind `repo` (cwd = repo root, own process group). Kind `ticket-script` runs `sh|bash <ticket script> <args>`. Enforced timeout = plan `timeoutSeconds`: SIGTERM, 30 s grace, then status FAIL "timeout after ...". Cancel gives CANCELLED.
- Child env: SEMIO_LANGUAGE=en, NO_COLOR=1, SEMIO_CARGO_LANE = eplay / edemo / ecourse, E2E_STAMP = run-id-product, PLAY_BZL_STAMP and DEMO_BZL_STAMP = run id, E2E_SERVE_TIMEOUT default 3600. Probe steps add PLAY_BZL_GO=1 or DEMO_BZL_GO=1.
- Skip rules (SKIP-FAILED, no execution): an earlier step of the same group failed in cold or warm; a step's `needs` group failed; a warm step whose cold twin did not PASS. A step already PASS/WARN in the same run id is skipped unless `--rerun`.
- Verdicts: cold, e2e, probe = PASS iff rc 0 and no Playwright failed tests. Warm = spawns must be <= allow (+ warm-slack) for mode allow, or 0 for mode zero; over maxSeconds gives WARN. E2E: ports still answering after the step turns PASS into WARN.
- Preflight verdict FAIL gives exit 3 and nothing starts. Preflight checks tools, Playwright and tectonic pins, disk (cold 60 GB, warm 15 GB), memory, load, Bazel slots, ports free, applied markers, `bun repo --help`, `bun repo capacity status`, and graph verification (`bun repo --tool=bazel show project|targets ... --graph-policy=current`, 'graph targets' check).
- Thresholds: deadlineHours 14, heartbeat 60 s, snapshot 1800 s, memory floor 6553 MB, heavy run needs 3584 MB (from reports), terminateGraceSeconds 30.
