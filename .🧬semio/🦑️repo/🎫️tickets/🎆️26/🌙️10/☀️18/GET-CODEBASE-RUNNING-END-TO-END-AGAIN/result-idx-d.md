## Design (schema-first, language-agnostic, no cap change)
Binary columnar fact index inside the same brotli envelope: one global string table (sorted by UTF-8 byte order = code point order, front coded: lcp+suffix), kinds list, deduplicated fact table (tagged values: null/bool/uint/negint/float64/string-id/array/object/hex64 as 32 raw bytes), row columns (kind idx, path string id, fact id), classes as zigzag deltas. Decoder is bounded (every count <= remaining bytes, depth <= 64, strict ascending table, ids in range, no trailing bytes) and builds the logical index directly from the buffer (no 180 MB JSON string + parse). Logical in-memory shape (owners/rows/classes) unchanged, so inference/plan code is untouched.
Cross-lane consumers that read the index file and must change in lockstep: storage closure reader `⚡️caching/💾️storage/🔒️enforcement/📦️budget/🕸️graph/📏️headroom/🧾️closures/{👷️read.mjs,🟦️.ts,🗂️members/🟨️.mjs}` (regex `generations/x/<hex>.json.br` -> classification, and a token-level JSON validator that extracts SEMIO_SOURCE_CLOSURE_/SEMIO_CARGO_LOCK_ references); tests `🧪️tests/🕰️generation` fixtures.
