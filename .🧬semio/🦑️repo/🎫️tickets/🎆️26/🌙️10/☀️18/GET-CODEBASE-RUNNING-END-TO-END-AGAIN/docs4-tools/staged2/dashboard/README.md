# docs4 doc batch `dashboard`

Describes behaviour that is live (code: dashhot fresh + nestenv, audit5 profilefresh (live)). The dashboard no-op: installed binary returned when Cargo's own source list holds, the profile policy in the digest, the measured numbers.

```sh
python3 -I stage.py check|apply|revert [--root DIR]
```

Idempotent, anchored (see `stage.py`), refuses on drift (exit 2), writes nothing then. Independent of every other doc batch: no `old` text is shared with a docs3 batch.
