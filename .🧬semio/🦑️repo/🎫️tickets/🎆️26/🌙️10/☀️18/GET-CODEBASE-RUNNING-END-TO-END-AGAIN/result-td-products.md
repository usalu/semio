## 2. Dashboard PTY journeys 33/35 -> deterministic (batch `dashjourneys`)
Environment on the mirror: the crate `🧪️tests/🧭️journeys/📦️packages/🦀️rust` is a standalone workspace; plain `cargo test --no-run --locked --offline` with `RUSTC=<pinned nightly rustc>`, `RUSTC_WRAPPER=`, a COPY of the shared CARGO_HOME (`cargo-env.sh`, no private target dir, the mirror's own default) builds in 16 s; binary under test = a copy of an installed dashboard (`.cache/b/t/m/dashboard-cli/prototype/<hash>/semio`, 13:10). `journeys-mirror.sh <mirror>` builds and runs it single-threaded like `battle()`.
Reproduction first (the failures do NOT show on a quiet run: 35/35 at load 35 once):
- `native_files_browse_edit_unicode…` (`🦀️.rs:901`): reproduced 3/3 by `slow-terminal.py` (a pty proxy that shows every frame 100 ms late and apart; this is what load does to the render, made deterministic). Cause: `wait_for(label.dirty)` returns on the first frame that contains `unsaved`, before the queued keys Left, DEL, `中`, Enter are drawn. Fix: wait until the screen holds the dirty label AND the last typed glyph (`中`) AND the width-model form of `👩‍💻`. Green 3/3 behind the slow terminal; the whole suite 36/36 behind it.
- `maximum_native_document_stays_responsive` (`timed out after 1s waiting for text "DOCUMENT_END_終👩💻"`): reproduced under the live load (nice 19, load 31-45): 2/12 runs red with the quiet-host budget, 0/12 with the fix. Cause: the 1000 ms interaction and 5000 ms load budgets of the fixture are quiet-host SLOs measured in wall clock. Fix: the Rust journeys scale those budgets by the host (`steps::scaled`): `SEMIO_TEST_TIME_SCALE` (>= 1) when set, else 1-minute load average / logical cores (`/proc/loadavg` or `sysctl -n vm.loadavg`) clamped to 1..16, 1 where the host reports none (Windows). The fixture SLOs themselves are untouched.
New law (language-agnostic, schema-first): fixture `hostScale` (10 vectors: macOS and Linux report formats, clamp at 16, empty / unparsable / negative report, no report, zero cores) + schema entry in `🧬️schema/🧭️journeys/🔣️.json`; the Rust law `the_host_time_scale_follows_the_shared_vectors` and the Bun test `Host time scale follows the shared vectors, a TypeScript model and an independent SQLite computation` (SQLite `min(max(load/cores,1),16)` is the third-party oracle) both consume it. Red on base: the Bun law throws on the missing vector table, the Rust law does not compile.
Files: `🎛️dashboard/🧪️tests/🧭️journeys/🦀️.rs`, `…/🧰️steps/🦀️.rs`, `…/🟦️.ts`, `🧪️tests/🧫️fixtures/🧭️journeys/🔣️.json`, `🧬️schema/🧭️journeys/🔣️.json`.
