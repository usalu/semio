### 🚫️ IDE-free: no editor configuration, plans belong to tickets

Agents never use an IDE, humans use the dashboard (`repo dashboard`), and no editor or IDE configuration registers or runs commands. The repository enforces that instead of asking for it. {{?ide-free::::The following is a staged set that waits for the end of the cold graph build, because it touches the library and process trees. }}State: {{@ide-free}}.

- **No client directories.** `.cursor` is forbidden outright, as is `.github/hooks`; `.windsurf` is classified as retired. The census law `ide-census` walks the physical tree and classifies the relative path, not only the entry name (it was blind to `.cursor` before), with the same verdicts in a TypeScript classifier and a SQLite oracle (7 new path cases; `.github/workflows` stays accepted). The dashboard authority and the Go formatter mirror the rule (`.cursor` no longer has a plans exception).
- **Plans are ticket files.** A plan is a file `<name>_<id>.plan.md` in its ticket folder, the convention `ticket_close` already uses for 111 archived plans. The 429 tracked Cursor plans and `.codex/plans/declarative-actions.md` leave the repository root: 15 move to the ticket whose `plan.id` names them, 75 to the ticket their own section or todo names (53 by rule, 22 curated), 1 stale duplicate is deleted, and the remaining 340, which have no ticket evidence, go into one closed archive ticket `ARCHIVED-CURSOR-PLANS-WITHOUT-TICKET` (title "Archived Cursor Plans Without Ticket", goal `AI-OPTIMIZED-REPO`). Seven tickets swap `plan.source` (an absolute client path, some from other machines) for `plan.local`. The `.gitignore` rule `!.🧬semio/🦑️repo/🎫️tickets/**/*.plan.md` keeps ticket plans trackable (two plans had been silently ignored). Cursor no longer carries a `plan_id` on any MCP surface; Kiro specs remain a plan source.
- **`editor` became `agent-client`.** Types, fixtures, directories and the hook output format that said "editor provider" now say "agent client" (a fail-closed codemod over an allowlist of 44 files; texts that mean a text editor or `.editorconfig` stay).
- **Leftovers.** The LSP plugins in `.claude/settings.json`, the empty `.github/hooks/repo.json`, the IDE rules of `.gitignore`, `"$schema"` editor hints in 20 tracked `tsconfig*.json` and the notebook dependencies in `pyproject.toml` are removed (`uv.lock` is regenerated with the Python lock command).
- **A decision for the user.** Removing the VS Code extension (59 tracked files, its manifest rows in six `package.json` files and every dependent) is an opt-in group that is not part of the default apply; the history keeps the files.
- **Verified** on a copy: the census harness (3 tests, 206 expectations, a negative control that fails as it must), the dashboard authority fixture, Go vet on seven modules and the Go tests that exercise the change, 59 changed JSON files parse, the plan moves are reversible (`--undo`). Not run: the Rust edits (cargo is gated) and the library suites that need the installed dependencies.
