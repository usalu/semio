## 2. The test-environment API (one, schema-first, cross-platform)
`SB/🔣️.json` (protocol) + `SB/🧬️schema/🔣️.json` (closed schema, Ajv strict) + modules (all `node:` builtins only, inside `F`, so the existing `🎛️execution` closure-confinement test still holds):
- `📁️root`: `createTestSandboxV1({route,checkout,guard})`: private root `<tmpdir>/st/<8 hex>` (length-bounded, 0700) with `artifacts/<route>`, `tmp`, `images`, `cache`; `owner.json` (pid, heartbeat every 30 s); environment `SEMIO_TEST_SANDBOX`, `SEMIO_TEST_ARTIFACT_DIR`, `SEMIO_TEST_IMAGE_ROOT`, `SEMIO_TEST_CACHE_ROOT`, `SEMIO_TEST_CHECKOUT_ROOT`, `SEMIO_TEST_GUARD`, `SEMIO_TEST_GUARD_REPORT`, `TMPDIR`/`TMP`/`TEMP`. `withTestSandboxV1`, `testSandboxEnvironmentV1` (nested runs adopt the parent's sandbox), `testScratchRootV1` (caller-owned artifact dir, else a process sandbox). Disposal: detach images under the root, release ports, remove; runs on `dispose()`, process exit AND bun `afterAll`.
- `🔌️ports`: `reservePort()`: atomic lease directory per port shared by all sandboxes of the host (49152-65000), bind-checked, released on disposal, dead owners' leases reclaimed. Replaces probe-then-rebind.
- `♻️reclaim`: next sandbox creation (throttled 5 min, `force` for tools) detaches images and removes sandboxes whose owner process is dead or whose heartbeat is older than 1 h, plus stale port leases.
- Boot-sweep integration: sandbox root, `TMPDIR` and artifact dir lie below boot-sweep's scratch roots (`/private/var/folders`, `$TMPDIR`, `$SEMIO_TEST_ARTIFACT_DIR`), so images that survive even a dead-owner reclaim stay inside its 15-minute idle sweep; a test pins the two scratch policies equal against the live boot-sweep schema.
- `🛡️guard`: runtime guard, off by default, `SEMIO_TEST_GUARD=report|enforce`. A bun preload (inserted after `test` by `runBudgetedTestCommand` and genuine-birth) rewrites `node:fs`, `node:fs/promises` and `node:child_process` imports of non-`node_modules` TypeScript to guarded shims (Bun cannot patch builtin ESM exports; measured +50 ms on a 4-test file). Refuses/records: writes inside the real checkout (`.cache`, `.🧬semio`, `.git` as protected; `.cache/b/o/m/tests` allowed), `hdiutil`/`diskutil` verbs on non-sandbox paths, `pkill`/`killall`, fixed ports not leased by the sandbox (`net.Server.listen`, `Bun.serve/listen`, `Bun.write`). Report rows are JSONL (`GuardReportRow` schema) and summarised at sandbox disposal.
- `🔍️scan`: the static law. 23 rules (EN/DE messages) over TS/Go/Rust/Python/shell; line, file and owner scope; comments skipped; non-suite files skipped.
