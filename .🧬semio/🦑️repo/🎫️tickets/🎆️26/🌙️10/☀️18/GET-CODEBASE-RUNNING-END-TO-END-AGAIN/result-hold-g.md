## Design (what is built)
- New leaf module `🕰️generations/🧩️claims` (schema first, EN+DE texts): a claim = {token, base generation, implementation digest, sorted owner names, state running|done}, stored as one small file `claims/<token>.json` beside the generation documents (temp+rename); liveness = the claim's own lease `graph-claim:<root>:<token>` held exclusively for the whole chunk (a crashed computer loses it with the process: its claim is dead and its owners are open again, a joiner takes over); admission (read claims, drop dead ones, choose the chunk, write the claim) under a microsecond lease `graph-claims-admission:<root>`; compute slots `graph-claim-slot:<root>:<i>` (i < N, N = f(RAM), env `SEMIO_GRAPH_COMPUTERS`) bound memory; waiting for owners claimed by a live peer = shared wait on that claim lease (never while holding an exclusive lease: hold-and-wait safe).
- `prefetch({base, implementation, wanted, run, served, say, progress, signal})`: loop { served by a peer's publication => stop; choose chunk = first <= 128 open owners (not claimed by a live or done claim of the same base+implementation) under admission; compute it with `run(chunk)`; mark done } until nothing is open; then wait for the live peers' claims; return. A request whose stale owners are all claimed by a peer JOINS it (waits, no recompute); a request with disjoint stale owners computes at once; N requests on one big delta SHARE it chunk by chunk (cooperative parallelism bounded by slots and by the capacity governor).
- Wiring (last, one edit per site): `refresh` passes the plan to the builder callback (`needsBuild` carries `dirty` + owner roots); `loadGenerationGraphV1` calls `host.prefetch` between the shared attempt and `withBuilder`; `generationHostV1.prefetch` runs chunks through the new sibling `prefetchBuildGraphProjectsV1` under the generation shard writer SHARED; `withBuilder` takes the shard writer SHARED too (so computers and assembler coexist) and keeps the publication writer EXCLUSIVE; a prefetch failure is told to the user and never fails the command (the assembler computes and reports it properly); cancellation propagates.
- Sweep law (staged blocks of a live compute are never removed): holds by lock semantics: sweep/headroom take the shard writer exclusively with `timeoutMs:0` and skip while any computer holds it shared.
- Honest limit: when every waiting request is stale in the SAME owners (framework edit => all 566), claims only add cooperative parallelism and a bounded heap per chunk; they do not make the first compute free. The exclusive section shrinks from the whole compute to the warm assembly (~0.4 s per owner).
