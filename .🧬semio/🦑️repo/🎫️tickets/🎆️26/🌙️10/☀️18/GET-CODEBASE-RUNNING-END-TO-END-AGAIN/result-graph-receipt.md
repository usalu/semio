## Root cause (read from code + measured with the harness)
Five places key a graph record by the BYTES of the implementation instead of by inputs + a declared protocol:
1. `📥️inference/📦️project-nodes` `projectAuthority = sha([revisionIdentity.revision, contracts])` -> `revision` = sha256 over `sourceFiles` (all components) + ~60 `implementationFiles()` (`♻️revision`): any edit of ~90 files changes the key of every np record.
2. `👁️observation` `OBSERVATION_REVISION` (sha256 of the observation module bytes) is in the digest of every record and of the in-memory project identity.
3. `inferenceAuthorityDigestV1()` = digest of the module-load observations: measured 81 `file` rows, 55 of them executable code (`.mjs` 46, `.ts` 9), 26 `.json` (data).
4. `🧬️source-analyses` `prepareSourceAnalysesV1`: provider id `build:<role>:v1:<sha(url, implementation revision)>` and provider revision = sha(implementation revision, ...), so every `analysis` fact (5,008 in a 12-project sample) is invalid at the next revision.
5. Generation fragments: `loadedImplementationRowsV1` + `loadedGraphImplementationRowsV1` become `digest` rows of ~90 code files in the environment and every owner (`scopeImplementationRowsV1`: `all` = every project); one edit of any of them dirties 3,737 owners = cold rebuild under the builder custody `repository-graph-facts:shard:7` (all other builders queue: observed 4 waiting, 38 min).
