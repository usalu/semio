## Root cause
A `bun repo` command captures the implementation once (top process + captured child). Format/identity stamps (graph identity, record stamp, inferrer stamps, dependency `walkStamp`, cache image format) were compared only through the *artifacts* (cold rebuild on mismatch), never against the *live declaration*. So an old-code process admitted to an exclusive resource built or published an obsolete generation/receipt (and under the pin, even edited code is deliberately let finish).

## Design (schema-first)
1. Stamp table: `L/🏗️build/🧷️format-stamps/🧬️schema/🔣️.json` (`Protocol.const`): `stamps` (id -> declaring schema file + JSON pointer, optional `member` projection), `resources` (lease name prefix -> stamp ids), `exitCode` 75, `maximumReexecutions` 1, EN/DE `texts`. Stamps: `graph.generation`, `graph.record`, `graph.inferrers` (17 members, compared by their `stamp`), `dependency.walk`, `cache.graph-image`. Declarations stay where they were; the graph identity moved from a literal in the graph host into `L/🏗️build/🕸️graph/🕰️generations/🧬️schema/🔣️.json` `definitions.Identity` (same value `graph-generations-v3`, so the running cold generation stays valid).
2. Module `L/🏗️build/🧷️format-stamps/🟨️.mjs` (+ `.d.mts`): a producer calls `declareFormatStampV1(id, <its own imported schema document>)` at load = the captured value; the live value is a stat-cached descriptor read of the declaring schema (bypasses the captured `readFileSync`, 2 s racy-settle rule, 5 retries on torn JSON, fail-closed with EN/DE error). `StaleImplementationErrorV1` (code `SEMIO_STALE_IMPLEMENTATION`), one line per moved stamp (bounded to 6 + "n more"), language from `SEMIO_LANGUAGE`/`LC_ALL`/`LANG`, both when unresolved.
3. Lease layer (generic hook, `F/.../🔒️leases/🟦️.ts`): guards live in a `globalThis` registry (`semio.resourceLeaseAdmissionGuards.v1`). They run (a) when an exclusive lease is granted (`traceLeaseV1`, covers `acquireResourceLease`, `acquireQueuedResourceLease`, `withResourceLeases`, upgrade) and (b) every wait round of a queued exclusive request (a doomed waiter leaves the queue at once, ticket withdrawn). A throwing guard releases the lease and rethrows = "yield without producing". Bound resources: `repository-graph-facts:`, `build-graph-state:` (builder custody, facts lease = the pointer-swap publish gate), `javascript-dependency-build:|bindings:|generation-writer:`, `native-fixed-image:`.
4. Readers of a newer artifact refuse with the same message (kind `refuse`: "neither reads nor overwrites"): graph host `identity()` (every graph load), dependency receipt `protocol-changed` report (the best-effort publisher now rethrows a stale error instead of "receipt failed"), cache image format marker mismatch. Mid-build: graph host `discoverPart` checks too.
5. Re-exec: the captured child (`L/🏗️build/⌨️command/📥️entry`) turns the error (also wrapped/aggregated) into exit 75 after printing the message. The outermost `bun repo` process (`L/🏗️build/📜️script.ts` `runBuildMainV1` + `L/🏗️build/🧷️format-stamps/🔄️reexec`) starts ONE new process with the same argv and `SEMIO_STALE_REEXEC=1` (so a fresh capture; capacity grant and queue positions were given up first), forwards SIGINT/SIGTERM, mirrors the exit code; second stale -> "stamps moved again, run again", exit 75. Nested processes (`SCRIPT_PROCESS_INVOCATION_ENV` set) only pass 75 up.
