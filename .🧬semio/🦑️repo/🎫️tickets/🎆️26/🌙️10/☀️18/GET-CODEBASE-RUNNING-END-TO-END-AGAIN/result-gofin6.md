## 2. `📚️library` Go build
Cause (reproduced before the fix): the canonical plan listed `./🧹️normalization/🔮️oracles/📦️package-boundary-classification` as a Go package. That directory is a standalone `package main` oracle program run by `go run <file>` (the TS test does exactly that); an emoji directory is not a valid import path (`malformed import path ... invalid char`). Not stale code, not missing members.
Fix, language-agnostic in `📚️library/🧪️testing/🐹️go-plan/🟦️.ts` (python twin `gocanon/plan.py` updated identically):
- `canonicalGoLayout()` reads `taxonomy.testOraclesDirName` and adds it to `opaqueDirectoryNames` (oracle programs belong to the oracle host, never to a module's package set).
- A directory that holds its own `go.mod` is a nested module and is never mapped into the parent, checked before the registered-member rule (a registered name such as `🏖️sandbox` must not leak its `🐹️.go` into the parent package).
Test: `📚️library/🧪️tests/🐹️canonical-go-discovery/🟦️.ts` is now 3 tests / 32 expects (was 2 / 21). Vector `🧪️tests/🧫️fixtures/🐹️canonical-go-discovery/🔣️.json` gained `🔮️oracles` in the layout, `oraclePrograms` (a standalone `package main` is excluded from packages/overlay and `go run` as Go-toolchain oracle succeeds), `packageModule.nestedModule` (registered-name nested module excluded from the parent plan, own plan maps only its members, `go vet -overlay` passes) and a real-module test (`canonicalGoPlan(📚️library)` = `["."]`, `go vet -overlay` exit 0, `GOWORK=off`). Mutation check: dropping the oracle name or the go.mod rule fails 2 of 3 tests; restored.
Library result in the copy: before `exit=1 [setup failed]`, after `go test` = `?  github.com/usalu/semio/repo/go [no test files]`, exit 0, `go vet` clean. The module has no Go tests of its own (its package is the event-kind file); its Go-related tests are TS: `bun test ./M/📚️library/🧹️normalization/🧪️tests/📦️package-boundary-classification/🟦️.ts` = 107 pass, 1 skip, 13 fail: 12 are the `rust-*` oracle cases (they shell out to `cargo run`, refused by the compiler ingress gate, not run), 1 is the cancellation timing case that passes alone (`-t "cancellation fail-fast"` 1 pass) and failed under load.

## Open
- The nested-module registration relies on the new go.mod rule in the library; any other tool that enumerates registered member names without honouring a nested `go.mod` (none found) would map the module's `🐹️.go` into `workspace`.
- `workspace.ObserveRootResolution` stays in production as an observability hook whose only consumer is the sandbox; removing it would need the guard to wrap `FindRepoRoot` itself.
- A module whose `go.mod` requires another module that requires the sandbox does not list it transitively (relies on `go.work`, like every other first-party edge in the closure; the plan follows replaces itself). A `GOWORK=off` build of a dependent would need the extra replace.
- The library has no Go unit tests of its own; the 12 `rust-*` oracle cases need a cargo run by the executor.
