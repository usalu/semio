🧷️ The native installation (`repo run repo-mcp:install`) is the only owner of the PATH `repo`; the bootstrap launcher installer (`🚀️launcher/📥️install/🐚️.sh|🔵️.ps1`) never creates or advises a second PATH command and ends by chaining into the native installation with the new launcher (`--launcher-only` / `-LauncherOnly` skips it: CI action, full bootstrap), its shadow check names every PATH repo that is not the native receipt's executable with `repo run repo-mcp:install` (no `ln -sf`). The native installer replaces a destination symlink whose chain ends in the semio bootstrap launcher directory (the 10-26 state) atomically, refuses every other foreign file or link with an EN/DE message, and on Windows drops the bootstrap launcher directory from the user PATH. Policy (receipt directory, launcher directory, hop bound, refusal texts) is in the installation schema; tests and the language-agnostic features cover the symlink, foreign refusals, the chain, launcher-only, failure, cancellation and the shadow check.
