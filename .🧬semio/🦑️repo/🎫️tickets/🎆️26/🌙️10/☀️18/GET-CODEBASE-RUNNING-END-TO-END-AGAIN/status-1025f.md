## Method

- Run start = the start column of the lane `chain.tsv` (Bazel rows) or the log header (Nx rows, from the result file). Verdicts from the lane's `chain.tsv` (rc) and from the result file's FINAL/status lines. Where a result-file table disagrees with `chain.tsv`, `chain.tsv` is used (e.g. fin-d print p5 is GREEN in `chain.tsv`, PENDING in the stale table).
- Predates = count of files in the closure directories with mtime later than the run start (`find <dirs> -type f -newermt "<start>"`, excluding `node_modules`, `.cache`, `target`, `🗑️generated`, `.🧬semio` and `.🧾️store` build caches). Counts are over the full closure directories, not sampled. The closure is a superset of the true dependency closure, so a count of zero is conclusive, and a non-zero count means "possibly touched by an edit in the closure", not proof that the run used the edited file.
