🧩 Staged batch `consumers` (lane peeredit2, forward fix after providers + tools): every consumer of a command closure that needs literal files expands the shared references through one library function (`expandedCommandInputsV1`); owner discovery admits a provider reference as a named input dependency on the providers project instead of reading it as a path; the course read-oracle law and the extracted-function source-demand law follow the bounded walk.
usage: python3 -I stage.py check|apply|revert [--root DIR]   (default root: walk up from this file to the directory holding 🧰️framework)
check : exit 0 when every file is `base` or `applied`, 1 otherwise.
apply : every live file must hold its base hash or already the new one, else exit 2 (drift: rebuild with `python3 -I ../../build.py consumers <root>`); atomic replace that keeps the mode of the file it replaces.
revert: every file must hold the new hash (or already base), else exit 2; restores base bytes.
