## Findings (file:line, each has a test.failing witness unless noted)

- F1 dependencies/inventory/🟦️.ts:175 dependencyParseCargoToml ignores `[dependencies.<name>]` table-form deps (test.failing witness).
- F2 dependencies/inventory/🟦️.ts:889 dependencyCollectPython reads one requirement string per line; `dependencies = ["a","b"]` yields nothing (test.failing witness).
- F3 dependencies/inventory/🟦️.ts:937 dependencyCollectDotnet reads only the Version attribute, not a `<Version>` child element (test.failing witness).
- F4 commit/📊️metrics/🛤️path-rules/🟦️.ts:2 METRICS_LOCK_FILES lists `cargo.lock` compared case-sensitively; the real `Cargo.lock` is never skipped (latent; `.lock` has no language). test.failing witness.
- F5 commit/📊️metrics/🔀️deltas/🟦️.ts pathsFromNumstatRow drops the old side of a brace rename with an empty half (`{ => sub}/x.ts`). Dead in practice (git runs with -z) but wrong. test.failing witness.
- F6 commit/📊️metrics/🔢️uloc/🟦️.ts physicalLineCount counts the empty segment after a final newline: every newline-terminated file counts one more line than `wc -l`/git numstat, so repo code totals (💯️, ➗️ ratio base) disagree with the numstat deltas. test.failing witnesses (3).
- F7 commit/📊️metrics/🧮️summary/🟦️.ts validateMicroCommitLangMetricsDeltaSum compares sums of the rows with a total computed from the same rows: vacuous, it can only throw on NaN. Tested as such.
- F8 commit/🔸️bullets/🟦️.ts:18 MICRO_COMMIT_BULLET_RE: `\S` may match the U+FE0F variation selector after backtracking, so `🧪️ x` (space after an emoji with selector) passes validateBulletSpacing; the "no space after emoji" check is dead for repo-style emojis. test.failing witness.
- F9 commit/🔸️bullets/🟦️.ts bulletEmojiValidationError: the timestamp branch is unreachable (a bullet starting with the 🎆️YY🌙️MM☀️DD pattern always leads with reserved 🎆️ first). Product-area coverage can never be satisfied for staged paths without a 4+ char token (e.g. `x/ui/y.ts`), and pathTokensForBulletCoverage keeps the emoji prefix in tokens of emoji-named dirs (test.failing witness).
- F10 commit/🔢️counter/🟦️.ts:5 COUNTER_RE spells each emoji with its FE0F and then an optional selector class: selector-less subjects never parse, and bumpCounterFromHistory then throws "refusing to reset counter" instead of continuing (test.failing witness).
- F11 commit/🔢️counter/🟦️.ts canonicalWipLine1Base applies a FE0F-carrying pattern to text whose selectors were just stripped (normalizeEmojiPresentation): it never matches, so the contributor prefix is never rewritten (test.failing witness).
- F12 🧼️workspace-cleanup/🛡️protection/🟦️.ts cleanIsNativeImagePath: only the path itself and its direct parent are tested, so a removal row for an ANCESTOR of a native image directory (`imgs` above `imgs/vm`) passes cleanRemovalProtection although it deletes the fixed.dmg/image.json pair (test.failing witness).
- F13 🧼️workspace-cleanup/🔍️candidate-discovery/🟦️.ts:~270 cleanGitignoredMapForTicketRoots runs `git ls-files --others -i --exclude-standard --directory -- <rel>` without `-z`/core.quotepath=false and splits on "\n": git C-quotes every non-ASCII path (`".\360\237..."`), so for every emoji-named ticket (all real ones) the map keys/paths are garbage and no ignored ticket file is ever found (ASCII ticket roots work; test.failing witness). cleanOversizedIgnoredRemovals uses -z and is correct. Also a fully ignored ticket folder lists the folder itself and cleanTicketFolderForPath(folder) (which starts at dirname) maps nothing.
- F14 commit/📜️body/🟦️.ts:parseCommitBundleBody tests isBundleScopeLine before validating a bullet: a bullet that is one emoji plus one lowercase word (`🧪️tests`, `🔥hotfix`, `🧰️toolbox`) is read as a NEW bundle scope, and the day then fails with the misleading "needs at least one bullet" (test.failing witness). Same function: bullet space check inherits F8.
- F15 commit/🪜️steps/🟦️.ts parseCommitSteps / isCommitPrepareOnly: the alias words `tag!`, `squash!`, `push!`, `+tag`, `+squash`, `+push`, `c.`, `prepare!`, `+prepare` can never match because `\b` needs a word character on the symbol side; only ct/cs/cp/long names work (test.failing witnesses).
- F16 commit/🏷️labels + 📜️body: a date-like line (`🎆️26🌙️10☀️22x`) counts three emoji clusters and is read as a scope (tolerated grammar, documented in corpus).
- F17 PERF 🏃️process/🔍️probe/🟦️.ts:39 spawnCapturedSync launches a full `bun -e` wrapper child (temp dir + spec.json + OS-file bridge) around EVERY captured spawn, git included: the commit/attribution pipeline issues dozens of git calls per commit, each paying a Bun start-up (hundreds of ms under load; the attribution corpus test needs ~5 s per scenario). Violates "maximum performance"; a direct `spawnSync` with piped stdio (or one long-lived git cat-file --batch) would do.
- F18 🧬️schema/🔍️field-discovery/🧱️contract/🟦️.ts:policyCanonicalScalar looks tokens up in a plain object literal (`scalars[token] ?? token`): a token naming an Object.prototype member (`constructor`, `toString`, `hasOwnProperty`, `valueOf`, `__proto__`) returns the inherited function/object instead of the token (test.failing witnesses). Fix: Map or Object.hasOwn.
- F19 🧬️schema/🔍️field-discovery/🟦️typescript/🟦️.ts policyExtractTypescriptSchemaFields (member regex ends at the first `;`, comments not skipped): (a) a member without a trailing `;` (last member of a one-line interface, semicolon-free style) is dropped or merged into the next member; (b) a `// name: type;` comment becomes a field; (c) an inline object type truncates at its first `;` and leaks inner members as top-level fields. TypeScript compiler API is the oracle (test.failing witnesses).
- F20 🧬️schema/🔍️field-discovery/🛰️protobuf/🟦️.ts: one global regex over the whole message body: fields of a nested `message Inner { … }` are reported as fields of the outer message (protobufjs is the oracle; test.failing witness).
- F21 🧬️schema/🔍️field-discovery/🔗️graphql/🟦️.ts: braceless-type fallback uses a negative lookahead for any later `{`: `type Empty` followed by another type definition is read as absent (test.failing witness).
- F22 🧪️testing/📊️coverage/🟦️.ts:coverageGlobToRegExp: `**/x/**` becomes `.*/x/.*`, which needs a leading path segment, so exclusions at the repository root (`generated/…`, `dist/…`, `target/…`, `pkg/…`, `x.test.ts`, `Button.stories.ts`, `s.wgsl`) are not excluded although `**/` matches zero directories (minimatch is the oracle; test.failing witnesses). The repo-root `target/` (Cargo output) is exactly such a path.
- F23 🧪️testing/📦️workspace-exports/🟦️.ts:publicRuntimePackageExportsV1 accepts `@s` (a bare scope) as a package name (`^(?:@[^/]+/)?[^/]+$`); also returns an unfrozen `[]` for no exports while every other result is frozen (test.failing witness for the name).
- F24 🏗️authoring/📦️crate-tree/🌳️module-tree/🟦️.ts:parseRustSourceTree skips `extern` but not the ABI string after it, so `pub unsafe extern "C" fn f()` is kind `other` with no name (tree-sitter-rust is the oracle; test.failing witness). useLeafNames: `self as d` inside a use group tests `tokens[a+2]==="as"` (is at a+1) and binds the parent name instead of the alias (test.failing witness). identifierSet/referencedItemNames include Rust keywords (`fn`, `let`, `self`) as identifiers (documented, tested as keywords plus tree-sitter identifiers).
- F25 🚨️policy/🔒️allowlist/🟦️.ts:policyDiscoveredAllowlist iterates `parsed[key]` with for-of without an array check: a string value contributes its characters (fails open, not closed). 🚨️policy/🧭️entrypoints/🟦️.ts:dispatchSubcommand uses `handlers[key]` on a plain object: `toString`/`constructor` run as handlers (same prototype-key class as F18). Both test.failing witnesses.
