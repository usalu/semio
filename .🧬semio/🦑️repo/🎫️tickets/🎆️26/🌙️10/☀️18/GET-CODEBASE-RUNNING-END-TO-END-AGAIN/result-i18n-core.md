1. One resolver. `resolveLanguageV1` is now generic (`resolveLanguageV1<T>(languages: readonly T[], ...)` returns `T`). Missing language = the existing bilingual refusal (EN line, DE line in one message). Exact mechanism in the code, in this order: `--lang=<en|de>`, `SEMIO_LANGUAGE`, `LANGUAGE` (first offered entry), `LC_ALL`, `LC_MESSAGES`, `LANG`, then the OS list (`defaults read -g AppleLanguages` on macOS, `Intl` locale on Windows); the refusal text names `--lang=en|de`, `SEMIO_LANGUAGE=en|de`, a locale such as `LANG=de_DE.UTF-8` and the order. There is no repo-config source in the code, so none is named. `runBuildCliV1` resolves once and exports `SEMIO_LANGUAGE`, which in-process modules and children read.
