# result-guard-g (wave 1026g): the Go sandbox guard compares roots by identity, scratch leaves the checkout

Tools `C/guard-g-tools/` (`oracle.py`, `gofails.py`, `out/`), official logs `C/🗑️generated/guard-g/`. All edits are LIVE and outside `📚️library/**`, `🏃️process/**`, `🚀️launcher/**` (Go test helpers of the repo workspace module and two Go test files), so nothing is staged for gate-g.

## Root cause chain (confirmed)
1. The official Go route issues TMPDIR / `SEMIO_TEST_ARTIFACT_DIR` below the checkout. A test directory without its own `.git` resolves (root discovery is `.git`-only) to the REAL checkout; tests then wrote fixture tickets / sessions into the real tree.
2. proof2-g's `BindRoot` fence (empty `.git` directory) fixed the bound roots but (a) git itself still answers for the enclosing checkout when `.git` is an empty directory (`git ls-files` / `check-ignore` in the graphql autofix tests saw the checkout), and (b) the guard in `sandboxed-run` flagged every resolution NESTED below the checkout, so `TestExplicitRepositoryRootUsesProvidedDirectory` failed although its fenced dir is a root of its own.
3. Direct `workspace.SetRootDir(t.TempDir())` / `RunHook{RepoRoot: t.TempDir()}` sites (about 40 in cli, hooks, move, tree, codebase, graphql tests) have no fence at all.

## What changed (files under `🧰️framework/🛍️products/🦑️repo/🔨️modules/`)
- `🏠️workspace/📦️packages/🐹️go/🏖️sandbox/🛡️root-guard/🐹️.go`: guard flags a resolution / binding only when it IS the checkout root: `touchesCheckout(path) = SameDirectory(real, ResolveRepoRoot(path))` (an unmarked dir below the checkout resolves to the checkout and is flagged, a marked nested repository is a root of its own and passes). New `SameDirectory` (deepest existing ancestors compared with `os.SameFile` = inode / Windows file index, so symlinks, separators, dot segments, case and Unicode-normalisation folding of the file system and drive-letter case all agree; missing remainders compared spelled) and `PathWithin` rebuilt on it. `Own` removed (no longer needed). New `AbortOnTouch`: the first resolution of the real root panics naming the test, BEFORE the offender can write anything.
- `🚧️sandboxed-run/🐹️.go`: guard aborts by default (`SEMIO_SANDBOX_GUARD=report` lists all offenders, only for already fixed modules); `RelocateScratch` moves an issued scratch dir that lies inside the checkout to a fresh dir under the first qualifying base (user cache dir, `/tmp`, `/var/tmp`: outside the checkout, no repository above, write probe ok), sets TMPDIR / TMP / TEMP, restores and removes it at exit; falls back to the issued dir (guard remains the defence); `SEMIO_SANDBOX_SCRATCH=keep` opts out. `SEMIO_TEST_ARTIFACT_DIR` is untouched (harness contract).
- `🌱️fixture-repository/🐹️.go`: `fenceRepositoryRoot` runs `git init -q` (real repository) instead of an empty `.git` directory.
- Tests: `🏠️workspace/🧪️tests/🏖️sandbox/🐹️.go` (law tests below), `🏠️workspace/🧪️tests/🧫️fixtures/📡️same-directory-vectors.json` (17 vectors), `🔗️graphql/🧪️tests/🔬️unit/🐹️.go` (`withMonorepoFixture` uses `sandbox.BindRoot`), `💻️client/⌨️cli/🧪️tests/🛡️hermetic-root-guard/🐹️.go` (held-binding law: real root carries a `.git`).
