## Decisions
1. Bare machine without Go: the launcher installer (`L/📥️install/🐚️.sh`, `🔵️.ps1`) is stage 0 and fetches the PINNED Go itself (decision: build from the checkout, no prebuilt binaries). Why: no release host exists for semio, a prebuilt launcher would need signing, a release process and a second trust chain, and would go stale against the registry; the Go pins (url + SHA-256 per OS/arch, same rows the bootstrap already pins and the toolchain-pins law ties to the policy `go` row) are the only new trust and the build is reproducible (`-trimpath`, `GOTOOLCHAIN=local`, `GOWORK=off`).
2. Lookup order for Go: PATH `go` whose `go version` is exactly the pin, the repository tools partition (`.cache/b/t/m/native/go/<v>/<host>-<sha16>/bin`), the user cache `${SEMIO_GO_ROOT:-$XDG_DATA_HOME/semio/go}/v<v>` (Windows `%LOCALAPPDATA%\semio\go`), else download.
