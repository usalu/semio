## 1. WFC headless driver (`✏️s/🔌️plugins/🀄️wfc/⚙️engine/💼️job/🏃️headless/🦀️.rs`)

Correction to `result-cstep.md` open item 1: `BatchJobSession::step(grant)`, `checkout_outcome`, `take_checked_out_retained_step_receipt` and `WorkerJobAdmissionContext` still exist; what had really gone is `session.close_step(grant)`, `WorkerJobCloseStep::Refused` and the grant-funded step. The driver is nevertheless moved wholly onto the original-caller model the layout export oracle (`run_layout_export_headless_batch` / `drive_job_batch`) and wgpu2 use, because `OriginalJobFixtureCaller` is `testkit`-gated and production needs its own caller.

* New private `HeadlessCaller` (the production analogue of `BrowserCaller` / `RendererIoCaller`): owns the operation id/generation, one root `CancelToken`, one `JobPayloadAuthority` (via the existing `admit_payload_authority`) and a sequence; `turn` lends a `StepContext::with_payload_authority` (the constructor `from_checkpoint` and `drive_batch_job` of the same crate already use) under a `StepBudget`.
  * `funded` = unbounded fuel/deadline over `HEADLESS_GRANT` (alias admission, session admission, acknowledgements); `step_turn` = `StepBudget::from_duration(site.fuel_per_step, now, site.step_budget_us, HEADLESS_GRANT)` on the injected clock, so `HeadlessSite.fuel_per_step/step_budget_us` keep their meaning (they now bound the caller's turn, which is what `step_on_original_caller` reads).
  * `admit_alias` (`cx.admit_original_cancel_alias()` + one fuel) gives `BatchJobParams.cancel`; admission is `BatchJobSession::try_admit_owned(&mut job, &mut params, cx)`; a refused admission closes the unadmitted job through `close_job` and keeps the old `<label>-admission-rejected` result.
  * `close_owner` is the production copy of the worker fixture ladder: alias witness -> `return_original_cancel_alias_step`, else `session.close_step(cx)`; Contention/Blocked yield, `Refused` is gone (a refusal is the `Err(OriginalTurnFailure)`).
  * `retire` closes the payload authority; the root token drops after the alias came back (same as the other two wfc drivers).
* `run_headless` / `HeadlessSite` / `HEADLESS_GRANT` / `payload_bytes` / `close_job` / `admit_payload_authority` / `close_payload_authority` keep their signatures, so the five artifact hosts (`grid2d`, `2d`, `grid3d`, `bitmap`, `3d` `solve_with_clock`) and the engine `drive_batch_job` / `from_checkpoint` are untouched. Order is unchanged: outcome bytes are copied, `finish(job, bytes)` runs while the job is still checked out, then the paid acknowledgement loop, then `begin_close` and the close ladder.
* `close_job` no longer says "original fixture" in its `expect`.

Not changed (still stale, not in this task): wfc grid2d/bitmap/grid3d/2d inference unit tests that build a bare `StepContext` for `step` (result-cstep open item 2).

## 2a. Microsecond step budget from `contract.max_step_micros`

Finding: the typed-command route steps its mounted worker with `pump_one_for_interactive_turn(cx)`, which reads the *context's* budget and ignores `BatchDriveConfig.fuel_per_step/step_budget_us`; `drive_worker_step` admitted with `fuel_per_step: cx.fuel_remaining(), step_budget_us: 0`. So the contract was only validated, never applied, and any path that did read the config (`drive_worker_job_authority`: `StepBudget::from_duration(fuel_per_step, start, step_budget_us, ..)`) would have had a zero-length deadline.

Production (all in `🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin`):
* `🧵️retained-command/🔄️full-operation/🦀️.rs`: `MountedTypedCommandFullOperation` gains `contract: Option<semio_framework::ToolExecutionContract>` (`None` only for the completed-output mount in `🎟️producers`, which never runs a worker). `drive_worker_step` now (1) refuses without a contract, (2) admits with `fuel_per_step: contract.max_work_units_per_step, step_budget_us: u64::from(contract.max_step_micros)`, (3) steps through `cx.with_original_work_loan(min(cx.fuel_remaining(), max_work_units_per_step), now + max_step_micros, |same| session.pump_one_for_interactive_turn(same))` (precedent: winit-app present step, inference gateway). The loan narrows fuel and the absolute deadline on the same original context and charges actual work, so the exact microsecond bound is enforced without renewing any budget; no division, no rounding.
* `🧵️instance/📨️dispatch/📥️staging/⌨️typed-command/🦀️.rs`: stores `contract: Some(admission.proof.contract())`.
* Literal sites updated with `contract`: `🎟️producers` (`None`), `🧾️typed-operations/.../inline-interaction-and-latest-wins`, `🧵️retained-command/🪟️mounted/♻️frontier` (2), and the test fixtures `🧪️tests/♻️publication-retirement-authority` (3), `🔬️app-typed-command-full-operation/{slot-and-publication-fairness (2), cancellation-publication-boundaries, document-cancellation-and-latest-wins-keys}`, `🔬️plugin-runtime-plugin-builder-contract/🪟️mounted-owned-child/📦️driver` (tests use `bounded_first_step(1<<20,1<<20,1<<20,1<<20,7_999)` so a 1 us budget cannot starve their jobs).

Law (`🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/⚖️laws/🎯️tool-job-coverage`):

Restated over `ToolJobMicrosecondSources {dispatch, mounted, operation, worker, job, trace, loan}` (new `toolJobMicrosecondWorkerSources(root)` reads the owning crates' module trees): contract stored at dispatch, output chunks from `max_output_bytes`, config from the contract, the exact work loan is the only stepping call, job-side decoded/work/output caps, `from_duration` checked add, worker budget derivation + fault admission, `drive_step` expiry preflight before `job.step`, `default_now_us` -> `try_now_us`, bare-Wasm `None` clock, native `as_micros()`. It no longer calls the stale `toolJobMountedDispatchOneTurnExact` / `toolJobRetainedDispatchSetup` (still red for their own reasons in `📤️publication`, other owner).
* `🏭️factory/🧪️tests/🔬️tool-job-microsecond-worker-binding/🟦️.ts` + `🧰️framework/🔨️modules/🧵️job/⏱️budget/🪢️binding.json`: mutation table keyed by source; two new hostile cases `unbound-step` (loan removed) and `zero-budget` (`step_budget_us:0`); all 11 cases reject as expected.

## 2b. Retained-work wiring

Finding (git, `0c3e78944af`): the Rust law `original_step_context_forwards_independent_work_funding` had already been migrated to the unified model (the context's own `retained_grant()` *is* the caller-funded normal-work currency, independent of fuel, charged by `consume_retained`); only the TS source-text law still demanded a second currency (`StepBudget.work_grant`, `BatchDriveConfig.work_grant`, `retained_work_charge`) that production never had. A second currency would also have stalled every tool (all contracts carry `NO_RETAINED_WORK`). So the wiring is completed in the unified model and the dead second currency is removed.

* `🧰️framework/🔨️modules/🧵️job`: `StepContext::retained_work_can_enter(demand)` (= `RetainedWorkBudget::new(self.retained_grant()).can_enter(demand)`, zero allocation); removed the always-empty `StepContext.retained_work` field and every copy of it (3 constructors, `⏱️context/⏸️park` wallet, `🎟️source/👶️child` loan tuple) and `NO_RETAINED_WORK`. Rust test `🏃️work/🎟️grant/🧪️tests` now asserts through `cx.retained_work_can_enter`.
* `🧰️framework/🔨️modules/🎯️action-bus/🦀️.rs`: removed the unused `ToolExecutionContract.work_grant` and `with_retained_work`.
* `🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🧵️retained-command`: the host now quotes `work.work_demands(&input, copy)` and gates `work.step(&input, cx)` on `cx.retained_work_can_enter(demand)`: an under-funded turn consumes one fuel and yields (`Ok(None)`); a demand that even the original total remaining grant cannot fund faults with "retained command normal-work demand exceeds its original funding" (no livelock). `ArtifactCommandWork::work_demands` default changed from the refusing "undeclared" to the minimal entry demand `{depth: 1}` (the `BoundedArtifactCommandWork` precedent), because 30 of the 66 `ArtifactCommandWork` impls (many wfc/flow/bim/fem/forms/note/...) declare nothing and a refusing default would have broken them at run time; their real effects remain bounded by the receipts `consume_retained` checks. Owners that need more declare it (unchanged).
* `🧰️framework/🔨️modules/🧵️job/🏃️work/🎟️grant/🧪️tests/🟦️.ts`: restated to the real boundary (`let demand = work.work_demands(&input` .. `let step = work.step(&input, cx)?;` with the gate, the original-total check, the two yield/fault returns, and a single `work.step` call; job source has `retained_work_can_enter` over `retained_grant`, `consume_retained`, and no `work_grant` / `NO_RETAINED_WORK` / second-currency field).
