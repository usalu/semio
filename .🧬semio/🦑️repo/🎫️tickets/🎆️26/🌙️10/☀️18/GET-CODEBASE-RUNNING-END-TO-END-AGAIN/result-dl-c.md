## The model (schema-first, one law)
- Law (budget schema `$defs.ProgressDeadlinePolicy`, code `⏱️budget/🟦️.ts`): `remaining = min(maximum - elapsedActive, idleWindow - min(sinceLastProgress, elapsed))`, expired at <= 0; reason `maximum` (checked first) or `idle`. `maximum` is nonrenewable (process envelopes never renew, "a repeated projection cannot renew its deadline" stays true) and derived from the declared cost: `min(86400000, base + perUnit * units)` per class (`native-child` 4 h + 10 min/unit, idle 30 min; `native-observation` 1 h + 30 min/unit, idle 10 min). Only the idle window is overridable (`SEMIO_PROGRESS_DEADLINE_IDLE_MS`, 60 s..24 h = four sampling periods).
- Progress signals (watchdog ledger `noteScriptProcessActivityV1`, never the process's own heartbeat): child-tree CPU time (sampled every 15 s while a renewable deadline exists; unreadable counts as work), child stdout/stderr bytes (`runOwnedCommand`, component-pass cargo/unit messages), declared lease/queue/capacity waits (`enterScriptProcessWaitV1` / `waitingDelayV1`), finished observation steps (physical control checks).
- Enforcement: a renewable control (`createRenewableIssuedResourceControlV1`) re-reads its remaining time whenever its timer fires, aborts its signal with `ProgressDeadlineExpiredV1` (EN+DE text naming idle/maximum); `watchResourceLeaseControlDeadlineV1` replaces every one-shot `setTimeout(cancel, snapshot)`; cancellation (AbortSignal) is untouched.
