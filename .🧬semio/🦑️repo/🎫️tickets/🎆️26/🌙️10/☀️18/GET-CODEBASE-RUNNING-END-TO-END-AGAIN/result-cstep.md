# Result CSTEP (executor `cstep`): plugin and remaining framework/os call sites onto the borrowed-cx close API

Static only. No cargo, no git write, no package.json / bun.lock / Cargo.toml edit. Tools: `cstep-tools/` (inputs); scratch and oracle logs: `🗑️generated/cstep/` (delete with the coordinator's folder). `C` = this ticket folder.

## 1. The current API (read from source and `git log -S`)

* `semio_framework_job::InteractiveJob` (`🧰️framework/🔨️modules/🧵️job/🚦️clock-stride-and-job-protocol/🦀️.rs`): `step(&'a mut self, cx) -> Result<Option<JobOutcomeBorrow<'a>>, OriginalTurnFailure>`, `close_step(&mut self, cx: &mut StepContext<'_>) -> Result<InteractiveJobCloseStep, OriginalTurnFailure>`; the grant is `cx.retained_grant()`.
* `InteractiveJobCloseStep` = `Pending{progress} | Blocked | Complete{progress}`. **`Refused` was removed** (`git log -S'Refused { kind' -- 🧵️job` -> 5487a5cce52 / 0c3e78944af). A refusal is the `Err(OriginalTurnFailure)` of the `Result`, built with `OriginalTurnFailure::debit_original(error, cx)`, which posts the error's own receipt to the context and keeps the whole `ValueError` (not a copied `kind`+`progress` pair).
* The same shape holds for `FixedOperationOwner::close_step(cx)` and `ArtifactCommandWork::close_step(cx)` / `step(input, cx) -> Result<_, OriginalTurnFailure>` (was `Fault`).
* Nested children are closed over a loaned context: `cx.with_retained_loan(child_grant, |same| child.close_step(same))`; the child posts its own effects, the parent debits only the remainder (framework precedent: `worker/🎟️authority` `receive_original_worker_close_effects`, `🎯️action-bus` erased job).

## 2. Framework additions (minimum needed by 103 mechanical ports; each with Rust law, TS law, schema + fixture)

All in `🧰️framework/🔨️modules/🧵️job/♻️retirement/🎟️context/` (re-exported from `🧵️job/🦀️.rs`):

| Item | Purpose |
| --- | --- |
| `close_original_granted_step(cx, \|grant\| -> Result<ICS, ValueError>)` | leaf close bodies: yields without running the body when fuel is out, spends one fuel, lends `cx.retained_grant()`, debits the reported progress once, turns `Err(ValueError)` into `debit_original` |
| `close_original_nested_step(cx, \|cx, grant\| -> Result<ICS, OriginalTurnFailure>)` | bodies that close nested interactive jobs: debits `reported - posted by nested callers` (checked; an under-report is `InvariantViolated`) |
| `SelfFundedCloseCaller` / `close_with_self_funded_context(grant, \|cx\| ..)` | throwaway caller for single-owner unit laws (grant = whole authority, unbounded fuel/deadline, one shared cancellation root so allocation oracles can build it before they observe) |
