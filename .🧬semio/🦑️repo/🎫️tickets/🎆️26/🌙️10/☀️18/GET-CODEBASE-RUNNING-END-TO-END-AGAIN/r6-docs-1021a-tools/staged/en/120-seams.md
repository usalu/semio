### 🔁️ Seams: what you can swap and how

Every external dependency of the build system sits behind a registry row and one interface, so that a different implementation is a new row plus one adapter module, not an edit of neutral code. Neutral code names no backend, runtime, package manager or storage format; laws keep it that way and count what is left.

| Seam | Registry | Swap | State |
|---|---|---|---|
| Runtime | the launcher registry, the facade `⚙️runtime` | `SEMIO_RUNTIME=<name>` | {{@launcher}} |
| Tools | the tool registry | `SEMIO_TOOL_<ID>` selects the executable | {{@tool-registry}} |
| Build backend | `🏗️build/🔌️backends/📋️registry/🔣️.json`: nx, bazel, semio | `--tool=nx\|bazel\|semio` or `SEMIO_BUILD_TOOL` | {{@backend-registry}} |
| Package manager | descriptors in `⚡️caching/🚀️bootstrap/📦️dependencies/🔌️managers` | `SEMIO_PACKAGE_MANAGER_<ECOSYSTEM>` | {{@pm-seam}} |
| Storage backend | the backend registry of the native storage layer | `SEMIO_NATIVE_STORAGE_BACKEND`, `_REQUIRE`, `_PREFER` | {{@storage-seam}} |

- **Build backend.** Neutral code reaches a backend only through `loadBuildBackendV1(id)` and the interface with `setup`, `reset`, `prepareStorage`, `cache`, `remoteCache`, `execute` and, optionally, `affectedProjects`. The registry row holds the titles in English and German, the adapter and conformance driver modules, the dependency model, the per-operation support, the claim for each of 17 capabilities and the native-snapshot protocol, so the 19 per-tool rows of the operations catalogue are gone. Neutral-literal hits (`"nx"`, `"bazel"`, closed unions) fell from 190 in 40 files to 63 in 16; the rest is classified: 40 in the pairwise comparison harnesses (`parity`, `incremental`), 19 in test fixtures, 2 in a schema and 2 single sites. `--tool=semio` is the third backend, an in-house engine with no external tool: the action key is the SHA-256 of the task identity, the contents of every selected input and the output digests of the dependencies (equal outputs cut off dependents, as in Bazel), a content-addressed store, single-flight locks across processes, a scheduler with a parallel bound, `--bail` and cancellation that kills the process tree, and a client for the shared cache server. It is fail-closed: any input it cannot interpret makes the task uncached. It refuses `run --watch=<target>` and continuous tasks, does not reproduce hermetic or `bazel test` classes, and its store is a ledger area collected by `repo cache gc --area=semio-actions`.
- **Package manager.** A manager is a JSON descriptor plus a lock reader: executable and probe, manifests, lock and configuration names, isolated environment, install recipe, argument templates per operation, installed layout and resolution profiles. The adapters are bun and npm (JavaScript), cargo, go, uv and dotnet. `SEMIO_PACKAGE_MANAGER_JAVASCRIPT=npm` changes the lock name (`package-lock.json`), the command (`npm ci ...`), the layout and the key, and nothing in the flow; generations and receipts are neutral. For bun the generation key, bootstrap key and sync arguments equal the old formulas byte for byte, so the swap itself causes no cold install. Package-manager literals in production code fell from 117 in 37 files to 25 in 12, all inside adapter-owned modules or ten declared data files that a law ties to the selected manager. Open: npm through the full JavaScript driver is unproven (the staged configuration text and the isolated layout are bun-shaped), there is no `--ecosystem` flag yet, and a real install proof for the other adapters is missing.
- **Storage backend.** The native storage facade has no `process.platform` and imports no backend: it asks the registry (`mounted-image`: macOS, a case-sensitive APFS image with a kernel quota; `directory-partition`: macOS, Linux, Windows, an unprivileged directory with an atomic exchange). The selection is a pure function of platform, explicit id, required and preferred capabilities; a child, a cleanup token or a maintenance call uses the backend recorded for its parent, never the ambient platform; a directory that holds the other backend's backing file is refused. Default selection on macOS stays `mounted-image`, so `.cache/b/*` is unchanged; selecting the directory partition on macOS needs a case-sensitive volume. 23 neutral-to-backend edges remain, pinned in a fixture that may only shrink; Linux and Windows execution is not run.
- **The adapter rule.** An external library or tool is used behind an interface of ours; no exported API names a type from outside the repository; a swap is proven by running the same conformance suite against the new row.
