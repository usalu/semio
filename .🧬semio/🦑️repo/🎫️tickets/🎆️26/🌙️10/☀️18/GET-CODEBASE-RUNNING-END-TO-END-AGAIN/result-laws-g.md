## 2. Silent platform greens -> explicit
Closed set of causes: `if(process.platform…)return;` as first statement of a test body = a test that passes without asserting. Fixed everywhere it was the first statement (`C/laws-g-tools/skipify.py`): the test header became `test.skipIf(process.platform…)(…)` so the runner REPORTS it skipped (21 sites, 21 files, all still compile: `bun build --no-bundle` over every touched file), plus hand splits where the guard sat mid-test (neutral half stays green on every host, the host-bound tail is its own named skipIf test): `cross-platform-bootstrap` (bash parse, package-manager listing), `publication` (symlink admission), `store-receipt` (link verification), `bazel/🧪️tests` (source identity symlinks, staged copy), `capacity/🧪️tests` (the single darwin image test is `skipIf`, the recovery entry export became its own neutral test), `retention/{generation,headroom}`, `workspace-cleanup/empty-folders`, `native-storage platform contract`, `history/{recensus,compact}` (the darwin tail of the history test is gone; the recensus file runs the same `detachedCompactLaw` as its own darwin test).
New suite-level tag: schema `platforms` (`darwin|linux|win32`) on a suite: on any other host the shared runner runs NO file of the suite and prints `SKIPPED, not passed: …` / `ÜBERSPRUNGEN, nicht bestanden: …` (text key `script.suite-platform-skipped`, EN+DE, exit 0 with the word SKIPPED first; targets of a tagged suite must be `cache:false` class `live` so a skip is never replayed as a pass). `processTestSuiteRunsOnV1(suite, host)`; law in the process suites test (Ajv strict + module validator agree on 4 admitted / 6 refused documents; Python reading agrees on 16 suite x host vectors; runner skip proven in both languages without starting a file). No suite is tagged yet: every darwin-only law found lives next to its neutral twin in the same file (injected-port Linux/Windows parsing, e.g. host-capacity sampling parses vm_stat, meminfo and PowerShell output on any host), where the per-test `skipIf` is the right granularity.
Left as is (documented): helper-level POSIX gates inside multi-purpose tests: `💾️cache/🧪️tests` (4 helpers, each has a named Windows test next to it), `cargo/📦️units`, builder `🔌️nx`, native-storage `🧾️metadata` (neutral half runs everywhere, the live half is inside one test body); `store-receipt` verification rows with a `symlink` mutation are still skipped per row on win32 (`continue`).
