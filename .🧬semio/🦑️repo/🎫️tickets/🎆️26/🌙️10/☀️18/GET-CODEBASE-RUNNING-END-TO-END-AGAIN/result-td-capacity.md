## Method
Mirror `tcap` (default `library process launcher`, 16,369 files; plus `git init` and the 3 census files). Every test file of the area (58, `td-capacity-tools/files.txt`) was run 4 ways: `plain` (`bun test ./file` from the mirror root, via `red-g-tools/mrun.sh`), `env` (ver-f `proc-run.ts file`, bootstrap capabilities plus an `artifacts` capability), official SUITE runner (`suite-in-root.sh`, the same birth as `repo run …:test-testing`: capabilities without `artifacts`, `SEMIO_TEST_ARTIFACT_DIR` as environment), and `chain` (`chainrun.sh`, `repo-lib:test` capabilities, realpath artifact dir; mrun's chain mode uses `/var/folders` and fails with "Exact bounded Native receiver ancestry required" because `/var` is a symlink). Logs: `C/🗑️generated/tc/`. Host load average during all runs: 36 to 50 on 10 cores.

## Fixes (staged in `C/td-capacity-tools/staged/<batch>/`; `mk_small.py` and `mk_envelope.py` rebuild them from the CURRENT live files, rerun `python3 -I mk_small.py` then `TD_BASE_ROOT=<root with the four small batches applied> python3 -I mk_envelope.py` if live moved)
1. `timeouts` (2 files): `⛓️cpu-last` three scan tests and `🔒️exclusive-writer` get an explicit 180000 ms test timeout. RED base (git work tree): 3 fail + 1 fail ("this test timed out after 5000ms", the child python scan was killed: `status null`). GREEN: 5/0 and 1/0 under the Bun default.
2. `launcherns` (1 file): the namespace law accepts `store` or `options` as the owner of both arguments (`/^(store|options)\.storage,\1\.control$/u`), nothing else weakened (`authenticatedPolicyReads>=1`, no constant namespace, no independent directory, `leaseDirectory` in the three global-guard calls). RED: suite `compiler-capacity-inheritance` 5 pass 1 fail. GREEN 6/0 + 5/0.
3. `psgate` (1 file): the real-process law expects `lent === (process table readable)`, with the reason in the message, plus a new in-process law "A waiting process whose process table cannot be read is never lent" (`children:()=>undefined`), the documented fail-safe. RED (sealed): 23 pass 1 fail. GREEN: 25/0 plain and 25/0 under `sandbox-exec` (verify.sh runs both on macOS). Oracle: the readability probe is the production function itself, the lending law stays asserted wherever `ps` runs.
4. `custodian` (3 files): the two idle-deadline children now start as genuinely independent processes (`node:child_process` spawn without the parent envelope, killed on abort), `wait()` fails at once with the child's end instead of polling until the budget, the deadline is the fixture value `idleDeadlineMilliseconds` (3000, was a hard 1000) in the fixture, the deadline script and both assertions, and the test/control budgets are 120 s. RED: suite 0 pass 1 fail (30 s). GREEN: 1/0 in about 20 s at load 45.
5. `envelope` (6 files): liveness, `🎟️capacity/🧪️tests`, units, inheritance, scope, custodian call `declareBuildTestEnvelopeV1({owner,maximumElapsedMilliseconds:300000,capabilities:{}})`; inheritance, scope and custodian use the shared test receiver `withBuildTestInvocationV1` instead of their own `receiveScriptProcessInvocation(process.env…)`; the files that write artifacts use `SEMIO_TEST_ARTIFACT_DIR ?? mkdtemp(tmpdir())` removed at exit; the marker race in `🎟️capacity/🧪️tests` waits for a non-empty marker. RED base bare: liveness 1/2, capacity 0/1, inheritance 4/2, scope 2/3, custodian 0/1, units 0/1 ("Original parent Script process invocation required"). GREEN bare (verify.sh, no envelope, no artifact directory): 2/0, 5/0, 14/0, 6/0, 5/0, 1/0.
