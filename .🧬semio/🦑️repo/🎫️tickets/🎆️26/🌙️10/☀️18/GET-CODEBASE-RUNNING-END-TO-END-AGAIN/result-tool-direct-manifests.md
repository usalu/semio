## 4. The codemod and the apply

`make.py` fails closed: only the 12 roots of `scope.json` are read and written (a missing or empty root, an empty file list, or a non-optional rule that matches nothing stops it), every in-scope file the law would read gets the rules in declared order, then the law runs over the whole tree with the new text (a finding outside every root or any residue stops it). `apply.py` is a dry run by default (`check | diff | apply [--write]`), per row `pending | applied | WAIT | DRIFT`, refuses on drift, WAIT (a row needs a set that has not landed: the catalogue rows wait for tool-iface), a path over 256 UTF-16 units (longest 164 in the repository, 216 in the ticket), or rows in the frozen library / process trees without `--allow-frozen`; writes through temporary siblings and atomic renames, all-or-nothing with rollback, originals saved by content hash (`--backup-dir`, `--undo`). Optional rules become sweeps (rule over every in-scope file at apply time), so text that later sets stage with `bun repo` or `repo repo` is rewritten too.
