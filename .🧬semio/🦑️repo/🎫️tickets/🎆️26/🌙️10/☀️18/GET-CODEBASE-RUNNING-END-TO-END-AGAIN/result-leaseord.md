## Deadlock analysis
A cycle needs every member to wait while holding. (1) Holders of the gate never wait: `picked` bodies (`sessions/🟦️.ts:96-125`) only read/write slot files, call `port.claim` (`acquireResourceLease ... timeoutMs:0`, `port.ts:36`, non-blocking, exempt from every wait rule), `port.spare/floorSpare` (`readHostCapacityStatusV1`, file reads, no lease) and `port.progress`; waiters release the picker before sleeping (docstring `sessions/🟦️.ts:93`: "nobody holds the picker while waiting for a slot"). A node with an empty wait set has no outgoing wait-for edge, so no cycle runs through the gate. (2) The pin is held shared; the only exclusive requests on `build-graph:` are the retention try-locks with `timeoutMs:0` (no waiter, no queued writer to block later readers). So pin-holder -> gate-holder is a leaf edge and nothing waits for the pin holder. The ranks claimed an order the gate does not need. Acquisition-order alternatives are worse: taking the slot first needs the plan (the slot key is `bazelSelectionV1(graph, request)`, line ~`📜️script.ts:834`), i.e. the pinned graph, and would hold a scarce one-holder Bazel server slot through graph load; releasing the pin while waiting would let retention evict the snapshot under a running build.

## Fix: declare the gate for what it is, the innermost (leaf) lock
`policy.json`: new class `bazel-picker` (rank 9, above `registry-fetch` 8; exact match `bazel-slot-gate`, `bazel-slot-gate:service`, EN+DE title) inserted after `tool-singleton` (exact beats the `bazel-` prefix; slots `bazel-slot-sN`, restore, metrics stay `tool-singleton`). Two incoming edges the old class had, so hold-and-wait behavior (rule `enforce`) is unchanged: `compiler-capacity -> bazel-picker` and `cargo-custody -> bazel-picker` (same reasons, EN+DE). No outgoing edge: while the picker is held, any blocking request of another ranked lease is now an out-of-order violation, so the leaf property is enforced instead of silently assumed. Any held pin (graph, rust-code, compiler-writer, toolchain, cargo, capacity, artifact, tool singletons) may now precede it. Schema unchanged (`schema-document-index.json` untouched).
