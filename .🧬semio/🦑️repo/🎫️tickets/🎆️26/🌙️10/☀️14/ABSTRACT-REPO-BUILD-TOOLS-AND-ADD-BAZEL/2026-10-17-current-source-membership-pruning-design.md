No such change is proposed here. Do not stop other agents or infer inactivity from a different scope's generation.

## Why The Current Observation Refusal Is Causal

`workspaces/🟦️bun/🟨️.cjs:84–112` walks actual nonhidden/nonopaque Source directories, notes package manifests, then applies positive and negative selectors to candidate package roots. `packagesPlan` evaluates nearest concrete export ownership with `📦️payload/🟨️.cjs` so embedded same-name payload packages are not fabricated independent owners. That classification cannot be replaced by directory shape or a cached list of historical packages.

`nativeOperations.list` retains direct child names/kinds for package.json, live ordinary directories and symlinks, excluding the existing explicit collection/output/hidden families. `retainOwnershipObservationV1` compares each retained list/state with its initial fact; `publicationPlan`, `currentFence` and live callback rechecks repeat actual facts/manifests. Adding an ordinary standards directory changes a retained membership frontier. A known empty new directory does not justify erasing that change or accepting the old complete Source witness. Rechecking only current manifest files would miss a new manifest/member below a previously unobserved directory.

The existing directory-observation unit/capacity fix and cheap-control progress batching remain separate qualified Source work. They preserve complete relevant scans and yielded control. This design does not reduce their counters, remove fences, raise caps, refresh an Original deadline or substitute a newer baseline into a retained witness.

## Contained Future Optimization With Unchanged Membership Semantics

For declarations that really have a finite rooted positive subtree or an authored subtree-wide negative, a schema-first selector traversal plan could prove a branch cannot contribute any descendant package. It must reason from the exact currently supported pattern grammar, including separators/negation, and retain the Source ancestors/current declaration needed to detect the branch becoming reachable after declaration changes. Prefix-collision and sibling cases must use path components, not startsWith. No general predicate callback or unproved glob feature may become pruning authority.

The existing `sourcePrefix` already avoids walking ancestors before the first wildcard. The remaining narrow candidate is early application of *provable subtree exclusions* before recursive `walkPlan`; current known opaque/hidden/collection exclusions already handle most authored negative patterns. A negative matching only a directory itself does not necessarily exclude every descendant. No excluded-branch performance estimate applies to actual standards because its broad positive and lack of corresponding negative admit it. A manual emitted list of current workspaces is not an equivalent declaration.

Required portable laws before any implementation:

1. Original and planned traversal produce identical complete package roots and nearest-export ownership for bounded synthetic trees, independently compared with existing picomatch/fast-glob for the supported grammar (unsupported grammar refuses rather than guessing).
2. Positives rooted at finite components, multiple overlapping positives, broad **, negative subtree, negative exact leaf, negative sibling prefix collision, hidden/output/collection exceptions, symlink, absent start and path256 cases remain explicit language-neutral vectors.
3. New package under an admitted previously empty directory and new top-level installation owner still invalidate the original witness. Changes under a *proved unreachable* branch cannot create a member under the unchanged declaration; changing the declaration still invalidates before reuse.
4. Actual state/list/readText counts and retained observation facts are compared independently with SQLite/Python on Generated Source fixtures. Every omitted recursive visit is justified by an unreachable subtree proof; original physical caps and all relevant rereads remain. Progress/cancellation and arbitrary primary failure/closure stay exact.
5. Test current root/✏️s declarations as counterexamples: standards remains reachable and is not pruned. No current physical/runtime speed claim is possible without measuring the actual accepted algorithm under the genuine owner.

A separate future domain decision could author narrower permanent membership patterns with complete package/consumer inventory and ordinary owner qualification. That would intentionally change the declaration and all exact generation identities, requiring fresh complete Source and dependency qualification. It is not approved or implemented by this performance design, and no migration/fallback/adoption layer is suggested.
