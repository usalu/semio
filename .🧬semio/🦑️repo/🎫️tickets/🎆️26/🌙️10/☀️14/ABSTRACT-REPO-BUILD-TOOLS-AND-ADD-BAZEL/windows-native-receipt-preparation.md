## Actual Current Contract Reads

- Shared platform/contract/📂mount currently stores only {dev,ino,mode}; its actual observer/empty checks use Node lstat/opendir. Ordinary Fixed ImageReceipt refers to that document. Windows must not fill those fields with synthetic modes.
- Publication/🧱fixed/💾metadata currently exposes legacy device/inode/bytes/allocation identities, prior slot/asset ACL SHA, current record SHA, actual principal/volume/mount, closed=true and numeric Flush return0. Its actions remain pending/published/settled, three real children, current4096 record/8192 output/32768 input/72 handle bounds. This fragment does not increase any limit or replace actual current-request/candidate validation.
- Existing X/H/C Facts carry actual full128 FileIdInfo, serial/GUID, simultaneous legacy device/inode/StandardInfo/BasicInfo views, attributes/creation/write/change/security/stream digests and final path. H already reads exact roster members up to4096 or same-backing footer512 with EOF/named/FD/ancestry checks. H currently has no native absence API; generic errors are not absence. HOST may read an opaque or zero-byte old receipt; publication admissibility is a separate owner decision.
- Metadata's current security hashes have distinct derivations: native C uses GetKernelObjectSecurity owner/group/DACL raw bytes; .NET full asset/slot ACL uses GetSecurityDescriptorBinaryForm bytes; receipt DACL uses UTF8 Access-section SDDL. Equal SHA text does not make these domains interchangeable.

## Proposed Closed Fragment

Fourteen complete definitions under one ticket-only draft07 root: native/method-specific security digests, directory/file identity, single-link file extent, WindowsUnderlyingMount, metadata current record/prior/receipt, complete cursor and present|absent HOST membership. All objects closed; full128 and uint64 remain strings. Actual uint32/uint64/int64 ranges and relationships require semantic admission in addition to schema shape. No equality between legacy inode and the low64 of FileIdInfo is assumed: they are simultaneous independent native views. Numeric image receipt projection alone must roundtrip <=Number.MAX_SAFE_INTEGER; a native mount identity may retain the fulluint64 legacy view.

WindowsUnderlyingMount is tagged win32, retains fullID/serial/GUID/attributes/creation/security/final path, and stores observed empty=true as DATA. It never supplies retirement/empty/custody authority. The future actual observer must prove same-host-volume canonical m and complete empty cursor again under its actual session. Metadata receipt envelope retains directory/backing/current/slot full native facts plus exact domain-specific digests; settled retains prior slot identity with slotPresent=false. Published envelope only models native identity fields: actual candidate JSON must still satisfy the fully updated canonical Fixed ImageReceipt before real dispatch.

HOST absent is only admissible after a complete exact parent cursor, STATUS_NO_MORE_FILES with Information0, known finite roster and no requested member/namespace. Access/error/incomplete/unknown/case-alias/duplicate paths cannot become absent. Missing backing is not an absence grant because this session requires authentic backing. Names are constraints, not an ownership proof. Present uses same-handle bytes/extent/EOF and full/native identities. The footer fixture is512 deterministic bytes and models tail transport only; it is not a valid VHD/interoperability assertion. Host sparse extent transport is distinct from metadata writer's current allocation/attribute eligibility and from physical charge proof.
