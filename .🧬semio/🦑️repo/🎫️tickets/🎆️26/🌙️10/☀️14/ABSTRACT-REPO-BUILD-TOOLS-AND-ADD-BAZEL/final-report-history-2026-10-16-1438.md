## Developer Interface

```text
bun repo run <project>:<task>[:<configuration>]
bun repo --tool=bazel run <project>:<task>[:<configuration>]
bun repo tools setup all
bun repo graph
bun repo show projects
```

The interface owns run-many, affected selection, execution, project/task inspection, watch, reset, strict portable flags, argument boundaries, progress and cancellation. Watch child ownership has focused real-child and lifecycle proof; Bazel reset has actual isolated physical busy-refusal, successful reset and managed-teardown proof. Their public aliases remain pending. `SEMIO_BUILD_TOOL` carries the chosen implementation through nested orchestration. English and German editor entries expose the infrastructure commands and tool selection.

Configurations override execution options. Executor kind, native ownership, dependencies, inputs, outputs and cache policy belong to the target; a configuration preserves its command form. Both backends enforce this contract and preserve base environment values when a configuration supplies partial overrides.

Task arguments use literal string arrays. All eight prior scalar defaults were converted by hand; authoring and graph admission reject scalar arguments. A private Nx bridge preserves array and caller boundaries through Bun's portable shell, using a digest-addressed source file bound to the original invocation. Configured command and directory alternatives contribute their full script closures and required conservative fallbacks to shared task inputs.

## Implementation

- Schema-owned project declarations, task graph, selection, execution recipes, inputs, configurations and resource grants live in the repo framework. Shared inference, input closures, observation, mode policy and catalog build contributions have neutral ownership. Private adapters translate to backend protocols; the Nx entry does not reexport shared inference APIs.
- Public package commands, dashboard, MCP agent instructions, setup, devcontainer, CI, native bootstrap, native producers, application orchestration and editor controls use the neutral interface. Package authoring no longer contains Nx project metadata.
- Bazel uses pinned 8.4.2 distributions with checksums for six platform/architecture combinations. Setup seeds a shared fixed-module cache and lock; new task namespaces run with downloads disabled. Uncached offline tool/module setup fails before network access. Current task execution uses batch mode; the authored server policy remains bounded at a 60-second idle limit. Its backend implements task dependency closure, configurations, arguments, source/lock/environment hashing, action products and restoration, nested orchestration, uncached actions, nonparallel operations, continuous service readiness and cancellation.
- Canonical graphs publish atomically with source authority and immutable digest pins. Task execution requires an authenticated graph for its exact selected owner closure; whole-workspace inspection and exhaustive planning use a separate complete graph. Nx graph/socket caches use that digest. Native Cargo discovery follows actual local owner dependencies and rejects stable missing owners. Concurrent unrelated crate additions do not invalidate each native owner's assembly key. Graph receipts preserve physical membership/type/mode plus consumed raw facts and registered structural analyses. Parser revision, current source SHA and nested observations guard semantic replay; execution caches continue hashing full input bytes.
- Artifact publication uses `.semio-artifact.json` across current publishers, consumers and schemas. Existing products with proven current ownership were corrected under their original publication leases, preserving marker and payload hashes. Unproven historical products and backend cache snapshots were preserved.
