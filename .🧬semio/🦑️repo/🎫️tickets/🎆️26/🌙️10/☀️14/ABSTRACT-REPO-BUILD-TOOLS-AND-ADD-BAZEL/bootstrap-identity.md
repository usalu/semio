# Native Bootstrap Workspace Identity

The native bootstrap now discovers a root from colocated regular, non-symlink `📋️project.json` and `package.json` files whose package has a top-level `workspaces` array or object. Both launchers stop at malformed paired package JSON, refuse absent identities after 32 ancestors, and validate an explicit `SEMIO_WORKSPACE_ROOT` at that exact directory. The old `COMPOSE_REPO_ROOT` override, Nx marker admission, and source-directory fallback were removed. Existing neutral public commands and exported workspace environment were preserved.

Bash runs before Bun or Node exists. It therefore uses a portable system `awk` recursive JSON parser, validating the complete package document and decoding escaped property names before classifying the root field. Nested properties and quoted text cannot impersonate a workspace. PowerShell uses its built-in `ConvertFrom-Json`, case-sensitive workspace property selection, and file attributes to refuse linked markers. Its UTF-8 BOM remains present for Windows PowerShell 5.1.
