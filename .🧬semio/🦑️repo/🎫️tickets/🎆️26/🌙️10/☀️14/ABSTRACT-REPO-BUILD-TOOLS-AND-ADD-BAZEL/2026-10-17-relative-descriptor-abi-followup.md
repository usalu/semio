# Descriptor-relative ABI follow-up

Darwin localSDK sys/stat.h __DARWIN_STRUCT_STAT64 and sys/_types.h confirm144-byte64-bit stat layout by field/alignment arithmetic: signeddev32 at0, unsignedmode16 at4, unsignednlink16 at6, inode64 at8; uid16/gid20/rdev24 then padding; atime32, mtime48/56, ctime64/72, birth80; size signed64 at96, blocks104, blksize112, flags116, gen120, spare124/128. Thus proposed seven-field offsets are correct for this declared64-bit ABI, not146bytes. fstatat declaration uses __DARWIN_INODE64 symbol mapping. An independent compiled offsetof/sizeof Source oracle remains appropriate; no compiler/runtime operation was performed here.

Material current Linuxarm64 bug: ARM64 overrides generic O_DIRECTORY to1<<14(0x4000), O_NOFOLLOW to1<<15(0x8000), O_DIRECT to1<<16. Current shared Linuxconstants use x64O_DIRECTORY0x10000 andO_NOFOLLOW0x20000, so anarm64 open could follow a leaf symlink and accidentally request direct IO instead of directory admission. Split architecture constants before qualification. [Linux arm64 UAPI](https://raw.githubusercontent.com/torvalds/linux/master/arch/arm64/include/uapi/asm/fcntl.h), [glibc aarch64 header](https://raw.githubusercontent.com/bminor/glibc/master/sysdeps/unix/sysv/linux/aarch64/bits/fcntl.h).

O_PATH remains1<<21, NONBLOCK1<<11, CLOEXEC1<<19 in generic64-bit Linux; AT_REMOVEDIR0x200. Glibc64-bit dirent field offsets inode0/off8/reclen16/type18/name19 follow its primary definition, but record bytes must remain validated from d_reclen rather than a fixed allocation. [Kernel generic header](https://raw.githubusercontent.com/torvalds/linux/master/include/uapi/asm-generic/fcntl.h), [glibc dirent definition](https://raw.githubusercontent.com/bminor/glibc/master/sysdeps/unix/sysv/linux/bits/dirent.h).

Declared absolute libc locations currently target Debian-like glibc directories, not every Linux distribution or musl. Loading a known validated soname can avoid distribution-specific directory assumptions, but must retain explicit libc/architecture ABI qualification and fail closed when unsupported. Official musl primary source fetch failed in this audit, so musl readdir64 symbol/dirent qualification is not asserted. Do not infer musl compatibility from identical kernel flags. Genuine Linux64/arm64/musl runtime and ABI Source-oracle gates remain separate from Mac acceptance.

No Source edits, FFI calls, Native invocation or protected reads were made. Root received the concretearm64 flag defect promptly.
