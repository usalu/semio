The real Bazel integration covers:

- Deleted-product restoration from the action cache without producer execution; changed source files trigger a rebuild.
- Nested orchestration delegates to a separate task selection, restores a cached inner product, and completes without holding the parent's namespace lease.
- Explicitly selected task arguments survive dependency discovery; project exclusions remove unwanted dependency owners.
- Uncached actions execute again even when the Bazel server already considers their outputs up to date. A fresh fingerprint nonce is required because Bazel's no-cache execution requirement alone does not bypass its in-memory up-to-date check.
- Continuous roots launch through native executables; continuous service dependencies honor readiness markers and are cancelled after their finite consumers complete. Both service and consumer can declare `parallelism: false` without deadlocking.
- A continuous service that exits successfully before emitting its required readiness marker fails the closure without starting its consumer. A service that emits its marker and exits successfully while a consumer is running also fails the closure. Service-failure and original-user-signal cancellation now inspect the actual consumer PID immediately after the backend returns and again after 1,500 milliseconds, beyond the consumer's original 1,200-millisecond completion delay; no completion product may appear.
- The startup callback fires after finite prerequisites are restored; authored argument defaults precede caller arguments; dotted owner environment output tokens resolve to real products.
- File symlinks follow target bytes, directory traversal is bounded, directory cycles terminate, and changed targets change source identity. Bun's independent CryptoHasher checked the authored source identity examples, while SQLite checked portable output examples.

Source enumeration now scopes Git's inventory to selected cacheable input prefixes. Uncached and no-op tasks avoid unnecessary source hashing. Cancellation uses an unguessable per-invocation loopback TCP capability and per-action identity, held only in the private runtime envelope and excluded from cache identity.
