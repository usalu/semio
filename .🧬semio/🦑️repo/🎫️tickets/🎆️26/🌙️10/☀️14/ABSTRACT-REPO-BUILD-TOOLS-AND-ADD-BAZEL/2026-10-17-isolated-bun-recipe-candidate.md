## Platform and funding consequences

| Platform | Concrete candidate obligation |
| --- | --- |
| macOS | Explicit hardlink stays distinct from the default clone strategy. Keep all package/cache writes on the actual funded volume and verify real link identities, cancellation and final Source imports. Do not infer link replacement safety from rename or Node convenience APIs. |
| Linux/devcontainer | Verify actual mounted device and runtime filesystem capabilities. Hardlink fallback/copy behavior may affect physical bytes and performance; the installed census and named-byte witness remain exact. |
| Windows | Qualify real NTFS directory junction/symlink targets, file IDs, component casing, reserved names and complete UTF16 lengths. Generic NT ABI Source models do not constitute actual mapped Native qualification. |

The package backend is independent of the isolated dependency-edge linker. Pinned package installation supports hardlinks, macOS clones and copying, with failure/fallback behavior that is platform-specific; keep the currently selected backend until a separately qualified identity changes it. [Pinned backend implementation](https://github.com/oven-sh/bun/blob/0d9b296af33f2b851fcbf4df3e9ec89751734ba4/src/install/PackageInstall.zig#L1407-L1475). Windows hardlinks are file-only and same-volume; junctions target directories and can cross local volumes, which is why their resolved ownership cannot be inferred from the link's location. [Microsoft hardlinks and junctions](https://learn.microsoft.com/en-us/windows/win32/fileio/hard-links-and-junctions).

The current Bun installer uses a symlink-or-junction abstraction with a fallback target, while global-store links use an absolute target. Disabling globalStore avoids that extra physical store authority and cross-project lifetime in the first candidate. It does not remove ordinary workspace/dependency links. These link forms must be covered by the domain inventory and Interfaces' conditional anchored Source transition, not by a fake Store. [Pinned link producer](https://github.com/oven-sh/bun/blob/0d9b296af33f2b851fcbf4df3e9ec89751734ba4/src/install/isolated_install/Installer.zig#L1777-L1803).

Whole Dependencies funding remains committed. Hardlinked aliases still count as separate named logical streams in canonical witness work, so physical free space is insufficient capacity evidence.
