## Actual Implementations

On POSIX, missing publication uses exclusive descriptor-relative symlinkat. Existing publication prepares a fresh sibling link and performs the platform atomic exchange (Darwin renameatx_np RENAME_SWAP or Linux renameat2 RENAME_EXCHANGE). The actual displaced inode, full seven facts and raw target are compared before any cleanup. Unexpected file/directory or target/roster drift leaves the displaced entry intact and fails without rollback. Cleanup holds the known displaced symbolic inode through unlink, checks its zero-link transition, closes it, then performs a real parent fsync and complete terminal name/target checks. This is compare/publish/verify under the caller's actual EX; POSIX does not provide an atomic inode-equality rename predicate.

On Windows, the actual owner uses ordinary no-reparse host root/ancestor handles, complete private128-bit ID/volume/security/stream facts and the existing bounded registry. A compatible directory reparse is updated through its exact held handle with a matching tag. Otherwise a fresh exclusive directory reparse is prepared; the exact old link is preserved by a relative absent-only NT rename, then the new object is published absent-only. The preserved old object is removed only through its retained known handle and constrained pending-delete transition. This controlled gap requires the actual domain-wide bindings EX. Failed/pending/ambiguous operations retain their staging/handles and provide no completed result.

The explicit target codec encodes DOS-drive targets as junction-compatible substitute paths. UNC and canonical volume-GUID targets select directory symbolic links; they are never claimed to be ordinary junction readlink targets. Extended drive syntax is encoded explicitly. Public generic Windows link observations retain raw NT substitute text; they do not pretend to equal Node-facing readlink text or Node lstat size/mode. The fixed domain must compare its prior Node snapshot with a fresh Node snapshot and bind that to the rooted private kernel facts.
