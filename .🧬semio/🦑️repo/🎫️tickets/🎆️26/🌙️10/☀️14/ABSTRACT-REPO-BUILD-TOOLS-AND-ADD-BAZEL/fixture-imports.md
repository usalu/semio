# Bounded Actual Fixture Import Census

Root authorized a read-only TypeScript AST census of the OS and repo-library subtrees after an actual selected-task stale fixture import. The retained fixture-imports/📜️script.ts uses the installed TypeScript parser to visit actual ImportDeclaration, ExportDeclaration and literal dynamic import nodes. Only relative specifiers containing the fixture emoji are resolved; source-template text is never recursively parsed as code. Physical URI query/fragment suffixes are stripped, escaped paths decoded and real file/extension/index candidates checked. Symlinks and generated/cache/dependency/Git directories are skipped.

The completed current snapshot read 4,598 JS/TS-family files, parsed 1,013 fixture-containing sources and checked 1,043 actual fixture references. **No missing physical fixture import was found.** It completed in 3,026 milliseconds with peak sampled RSS 476,577,792 bytes, within the original sixty-second/512-MiB bounds. Generated fixture-imports.json/log contain the exact result. This current snapshot does not claim that the earlier reported Host import was valid before Core's concurrent correction.

An initial full-AST approach correctly refused when sampled RSS exceeded 512 MiB before completion and supplied no complete census. The final harness prefilters text for the fixture emoji before AST parsing and performs diagnostic collection every sixteen parsed files. This is ticket-only census behavior, not production parser/performance policy. No graph inference/store, producer, product edit, source copy, peer signal or foreign authority was used.
