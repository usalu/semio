The closed invalidation data contract is defined under `$defs.candidateInvalidation` in the already fingerprinted admission schema. Runtime implementation stays in the existing graph owner, so the loaded authority's ordered nine input paths remain unchanged. No new runtime dependency or unbound helper was introduced. Permanent graph tests import the new candidate law entry.
