Root is taking Canvas runtime assets, Infinite fonts and Print from Storage's remaining mandatory-publication caller census. Source inspection found concrete producers and consumers; no product runtime or network operation has run for this scope.

Existing raw dist prerequisites are removed, with no alias or migration.

## Print

Four publication sites are part of a wider actual lifecycle: font staging, verified Tectonic tool download/extraction, range-fetched TeX bundle, and PDF compilation/probes. Their APIs currently accept workspace/signal rather than actual Original/storage and return unretained compiler/bundle paths. Correct relocation therefore includes actual invocation propagation, owned tools/dependencies readers through compiler effect, managed scratch and products publication, finite download/file bounds, owned extraction/compiler child settlement, and exact per-mode output consumers. Its current direct spawn and detached range-worker error handling must not be relabelled bounded merely by changing the final publication call.

The final shared layout/binding choice is being coordinated with Storage before these Source moves. Existing four managed Vite/Next/Storybook sites are handled separately in managed-artifact-caller-integration-current.md. No all-caller closure or runtime result is claimed here.
