## Semantics and Storage

Each descriptor owns an explicit source entry, exact Source/config/generated/toolchain file digests and byte lengths, package/target/host-or-target role/triple, mode/profile, selected features/cfg, compiler binary and target sysroot identity, command arguments, declared environment, direct dependency artifact identities, immutable output inventory and numerical Source/artifact boundaries. Reader refusal covers incomplete/unknown records, unsafe paths, duplicate identities/files, cycles, missing dependencies and oversized Source. The planner propagates Source/config/toolchain/environment changes through actual dependency units while preserving sibling identity. Storage and scheduling paths are excluded from the semantic digest. Output roots are required caller parameters derived from the single repository strict storage policy, not an alternate cache root.

A future dependency receipt cannot be preauthored before its producer compiles. An explicit null artifact digest is unresolved; the runtime binds it only to a verified current predecessor receipt under reader custody. A non-null authored digest must match exactly. Emitted receipts always contain concrete predecessor artifact digests. Nx projection declares actual direct producer predecessors and hashes their receipt outputs, exact files and semantic task option inputs. It never caches a mutable Cargo target/build tree. Cache enablement remains false until the authenticated frozen SDK constructor, database, cache, data, temporary paths and restored outputs are all confined to an actual enforcing backing.

The command runner opens Native's shared fixed image with the Root-owned `repositoryStrictStorageV1` policy. Compiler workspace reservations precede dispatch. Direct rustc verifies actual compiler/sysroot identities and current Source before and after execution. It supplies only declared environment plus original invocation and image-contained temporary paths. Exact output capture rejects stray files, symlinks, stale receipts and oversized artifacts. Canonical unit publication uses the bounded writer under an exclusive unit lease; dependency readers hold the same resource in shared mode. Workspace retirement follows actual compiler settlement and physical removal. Replaced committed allocations still need the unified cache owner/recovery/pruning integration; this prototype conservatively retains charges rather than inventing reclaimability.
