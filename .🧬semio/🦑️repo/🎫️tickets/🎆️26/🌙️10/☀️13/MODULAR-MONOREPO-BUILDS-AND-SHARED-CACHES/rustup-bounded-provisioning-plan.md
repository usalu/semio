A directory or old global installation without that issued intent cannot be adopted. Download the pinned bootstrap under bounded stream and integrity validation; all fetch buffers have finite request limits and controlled yields. Bootstrap writes only the tools generation, disables PATH edits and self-updates, and installs exact Source channel/minimal profile/components/targets. 5. Missing generation under an offline grant refuses before any HTTP or Rustup auto-install. A valid published generation can be reused offline under generation SH. Disable auto-install and self-update so a later compiler probe cannot introduce a fresh ambient or undeclared writer. An interrupted generation can resume only with its unchanged Original intent, issued store, Source identity and generation EX; absence, PID state or age do not acknowledge release.
6. Verify exact actual rustc -vV, Cargo version, host, installed components and targets, Source hash and physical directory identities before atomic authenticated receipt publication. Recheck again after publication and before returning. Transition the producer to original generation SH through compiler/loaded-shim child lifetime; escaped callbacks reject after the retaining scope closes.
7. Retirement requires the generation's exact EX after every genuine SH reader settles, matching receipt/inodes and awaited original removal. Safe immutable SDK retirement may create space only for generations whose existing borrower protocol is genuinely known. The old one-off tooling maintenance points at legacy paths and relies on physical PID inventory; it is not a portable retirement protocol and must not be used as evidence of owned release.
