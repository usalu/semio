After Root’s current helper freeze, ordinary withExactSourceReadBatchV1 remains issued Source/DATA observation and no longer creates inventory namespace roots. Add a separately branded ManagedGraphSourceReadBatchV1 extending ExactSourceReadBatchV1 and withManagedGraphSourceReadBatchV1<T>(root,control,run). Genuine ordinary causal laws use the existing received test Original and canonical requested0/accepted-operation primitives to demonstrate acceptance before callback return, unawaited-child drain, nested drain, cancellation, exact Error and undefined preservation. This supports the unchanged primitive used by enrollConsumer and is explicitly not a positive Native store law. Missing/copied/retired/pre-cancelled managed entry negatives run under isolated genuine received child Originals and must refuse before body or managed I/O. Positive real Native managed enrollment remains HOLD. Existing diagnostics-backed store lifetime tests remain statically retained, not executed as provider positives.

Implement the generic/Graph seam and these bounded Source/ordinary laws first.
