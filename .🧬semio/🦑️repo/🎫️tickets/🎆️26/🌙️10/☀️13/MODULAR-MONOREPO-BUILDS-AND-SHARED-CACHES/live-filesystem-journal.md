# Live Filesystem Journal

The warm launcher still spends seconds on source membership and tens of seconds preparing the whole project graph. A cached task taking milliseconds does not establish the requested fast iteration. This work supplies live, scoped membership proof before selected graph reuse is enabled.

## Ownership and Authority

The neutral filesystem owner is `🧰️framework/🔨️modules/📁️filesystem/🧾️observation/📥️journal`. Its schema closes scopes, changes, memberships, and live epoch witnesses. The source port registers a native watcher before census, drains pending changes around capture, reconciles physical membership, and admits no-follow scope ancestry. Query control includes the original cancellation signal, remaining deadline, progress, and continuation ports.

The repository extension is `🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/⚡️caching/🕸️graph/🔏️seal/📥️membership/📥️journal`. Its production census and incremental admission must come from the actual NativeWorkspaceContext effective file map. Raw Git membership is an independent oracle for the synthetic fixture, but is not the production authority: the real checkout has six membership differences. Explicit structural collection exceptions remain admitted separately.

The daemon RPC extension uses a closed versioned request and a response bound to the actual loaded immutable Nx tooling identity. A short dedicated client socket preserves caller cancellation and deadline; it does not reset the shared SDK queue or terminate another daemon. The persistent watcher belongs to the daemon, while individual queries belong to their original caller. Unknown events, watcher errors, overflow, epoch restart, changed ignore policy, and unsafe physical ancestry refuse reuse.
