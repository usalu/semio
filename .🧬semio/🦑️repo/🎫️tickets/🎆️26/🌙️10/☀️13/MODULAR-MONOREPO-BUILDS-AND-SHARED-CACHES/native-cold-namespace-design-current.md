## Actual Boundary And Proof Owner

The ten frontier callers remain layout, Volume, cache facade, cache policy/schema, repository partition opening, compiler enforcement, compiler-state wrapper/policy and units script. The same genuine enforcing parent reader is captured before custody waits; the same journal EX captures its accepted cleanup loan before reserve append. Namespace mkdir occurs only while that EX is held, after its child charge is durable. Only one literal namespace component directly beneath the authenticated parent is supported; direct children need no namespace.

## Durable Event And Recovery

Schema adds a closed namespace receipt with path, fixed bytes and exact parent/entry dev/ino/mode, plus a namespace-created event against the exact reserved compiler-state child. Reserved events cannot introduce a receipt. Duplicate same-directory child reservations and namespace owners refuse under the same journal EX. Existing path without this exact durable allocation is never adopted. A successful mkdir captures its actual identity, syncs namespace and parent through the genuine port while holding EX, rechecks exact identity, appends the receipt, then syncs the parent journal before creator entry. Crash/partial mkdir before durable receipt remains reserved and charged; it cannot be recovered by observing an empty path. Recorded recovery authenticates receipt under the original parent/journal/control and checks inode, parent identity, same device, non-symlink and bounded physical namespace metadata.

## Failure And Cleanup

The original funding scope retains successful mkdir receipt before any subsequent wait. Unborn failure uses its original captured journal loan and parent cleanup; entered failure additionally requires the original private backend retirement proof and settled original descriptor receivers. Before parent charge retirement, remove only the exact owned empty namespace with rmdir, verify actual absence and sync the original parent. Unknown entries, inode replacement, unknown mkdir outcome, partial journal bytes and durability failure remain charged. Error, thrown undefined and cancellation keep their original primary while ordinary work joins before cleanup. Namespace cleanup never issues backend retirement authority.
