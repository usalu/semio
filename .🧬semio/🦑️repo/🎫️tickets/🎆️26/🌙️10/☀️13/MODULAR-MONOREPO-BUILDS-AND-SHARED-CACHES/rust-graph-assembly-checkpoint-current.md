Work is linear in seed size and each selection's projects/references, plus metered text bytes, using ordinary amortized hash-map behavior.

Shared ancestors, disjoint roots, repeated references, overlapping selections, Unicode/delimiter-containing aggregate owners and already-present pairs are preserved. The index's nested source/target maps avoid ambiguous concatenated pair keys. Additive graph semantics are unchanged. The actual project conversion, aggregate target metadata, final `readBuildGraphV1`, compiler Store checks, final Source observations, descriptor publication, maintenance and stage retirement remain in the controller.

The DATA scope does not replace the caller's control or issue Native/compiler custody. Index setup and projection use genuinely issued child operations; the controller body retains its original control. The private index serializes projection, drains accepted unawaited work, preserves body Error/undefined primary failures, retires copied/escaped handles and clears membership before scope exit. Source, runtime policy and graph-budget epochs are checked before admission and after awaited work; stale implementation/policy DATA cannot be silently delivered.

Large strings are metered in bounded chunks without building a giant encoded copy. This is a dependency-DATA bound; the complete graph still includes project/configuration metadata and the later graph snapshot admission remains necessary. It is not a physical directory/quota or full repository bound.
