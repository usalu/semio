## Exact Proposed Private Source API

Keep issuance at the two actual producer scopes, rather than a public register-origin function. Native uses its existing CapturedCargoArtifactsV1 WeakMap token; Pass adds NativeBuildCompilationV1 tokens only for actual completed pass records, stored in a private WeakMap and retired after accepted outcome consumer drain, before cleanup. A copied outcome/origin object cannot create either token.

The shared neutral entry is `withCompletedCargoEvidenceV1(source: {kind:"native",capture:CapturedCargoArtifactsV1}|{kind:"pass",compilation:NativeBuildCompilationV1}, body)`; it imports the two genuine token checkers, not vice versa, and issues no Original/storage/lease authority. Its private implementation receives live actual writer origin/observation/control from the authentic producer scope. Native/Pass bounded read methods authenticate live token, current phase and exact declared roster before every physical effect. Public original-root fields are DATA only. No new exported origin registrar or caller-provided read provider is accepted.

The body receives an opaque evidence loan. Its publication copy operation takes an actual funded destination/reservation and carried phase, authenticates refinement and exact destination ownership, then copies only the closed complete roster with existing descriptor slots/no-follow/extent/identity rules. Actual observation bytes remain unchanged; index binds their SHA-256 and exact actual origin context. Accepted copy/recheck tasks enroll synchronously and drain before producer scope retires. Reader counterpart takes a genuine existing artifact-reader/group token and its exact index/receipt; it retains that private task for the full verification callback and rejects forged/copy/escaped tokens.

This avoids a custody gap in the existing outcome DATA: merely adding a raw storage path or `origin` field to NativeBuildOutcomeV1 would not establish the actual producer lifetime. The new pass tokens must be attached while its live producer still owns resources, and all scopes close in finally after accepted tasks settle. This is a narrow producer scope extension, not a lease/Original primitive change.
