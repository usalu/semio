## Smallest Real Custody Correction

Add a scoped Core-issued opaque source-set capability, not a public structural record of paths/fds. Its issuer opens the exact admitted regular sources before any destination EX wait, validates descriptor identity against admission and path/ancestor policy, freezes names, captured mode, per-file extent and aggregate byte budget, and retains every descriptor until accepted publication and cleanup settle. Partial admission closes all already opened descriptors. Descriptor count must remain under the declared finite file cap. The capability is consumed by the actual `stageOwnedArtifactsV1`/identical path, which must no longer reopen source names for content or mode.

Use bounded descriptor-to-new-destination reads/writes, explicit offsets and captured remaining extents. Refuse premature EOF, probe for growth, recheck descriptor identity/extent/mtime/ctime and relevant path identity before commit, enforce total bytes independently while copying, and carry original cancellation/progress through chunks. Derive destination mode from captured descriptor facts. The identical path must compare through the same retained source descriptors and exact captured extents. Hash captured/copied bytes if an exact content commitment is required; an fd alone pins an inode, not immutable content. Reject observed mutation before rename. If concurrent writes must be excluded rather than detected, the producer must retain a real source-owner lease or create an immutable/private bounded capture under that owner before handoff; no public shape can manufacture that ownership.

Opening must not silently turn a prevalidated leaf into a different symlink target. Compare opened fstat to the admitted lstat and retain identity; use the existing platform authority for any stronger beneath-root/no-follow traversal guarantee. Merely adding another lstat before `copyFile`, or replacing copyFile with a stream opened by pathname after EX, preserves the race. Path identity checks alone cannot make arbitrary writable ancestors atomic; do not claim descriptor custody grants that stronger namespace guarantee.

Required regression design: actual publisher waits behind actual destination SH, then source is (a) replaced, (b) symlink-substituted, (c) grown on the same inode, (d) changed during bounded copying. Confirm refusal/no new publication, old destination intact, all source handles drained, original cleanup retained, and bounded progress/cancellation. Include a small policy fixture rather than allocating 512MiB. These tests were not authored or run here.

## Reader Inspection

Current `👓️reading/🟦️.ts` is materially stronger: bounded manifest read opens one descriptor, compares pre/open/post identity, probes growth, and returns identity plus SHA256. Inventory hashes the manifest again and explicitly compares that fingerprint to the parsed manifest fingerprint. Payload hashing uses regular single-link descriptors, exact size enforcement and post descriptor/path checks. Directory inventory uses opendir iteration rather than an unbounded array, counts entries/depth/path units, captures directory fingerprints and rejects changed directories; final recheck compares the entire fingerprint inventory. No stale parsed-manifest substitution defect was found in this current code.

Residual namespace scope: directory lstat, opendir and post lstat are still separate pathname operations, and `requireNativeStoragePathV1` performs synchronous ancestor checks rather than atomic handle-relative traversal. A concurrent uncooperative ancestor swap can cause transient traversal/opening outside the checked tree before eventual refusal; shared artifact leases constrain cooperative publishers, not arbitrary filesystem mutation. The current checks detect stable changes and do not establish an atomic beneath-root traversal guarantee. This is not independently reproduced and does not erase the reader's current bounded work and fingerprint protections. The accepted consumer still receives paths and recheck, not retained immutable payload descriptors; its own irreversible effects cannot be rolled back solely by a final reader rejection.

A separate deterministic API validation gap: publisher accepts `.semio-artifact.json` as an input name, then Core overwrites that copied input with its own marker and lists the reserved name as an authored file. Reader excludes the marker from its authored inventory comparison, so such a successfully published tree cannot satisfy that reader. Reserve the marker name (and descendants) in source-name admission. No inspected production caller was shown to supply it; classify as input-contract correction rather than the principal P1.
