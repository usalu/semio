## Concrete Design Before Broad Changes

Add one repository artifact storage owner beside the existing TypeScript owner. Its schema owns finite namespace, file count, UTF-8 byte and path bounds; consumers submit authored package identity and mode, not output directories, temporary roots or env-selected cache roots. A package's actual canonical package.json/name and taxonomy source bind that identity before effects. Derive compact fixed products paths from that source owner and prototype/release. Keep one stable publication per package/mode, immutable for its actual SH consumer lifetime; do not create an unbounded content-hash generation history. The existing writer/reader resource for that exact publication coordinates replacement. This provides finite per-mode state and the physical 24 GiB cap without a new optimizer or output knob.

Open products and diagnostics under the same actual Original for the whole command/result consumer. Build/check/Bun/declaration temporary paths come only from an issued diagnostics scope, with one bounded per-operation directory. Force TMPDIR/TMP/TEMP and diagnostic test output from that scope after caller environment merge. Hold real generated destinations through every actual compiler and result reader. The owner uses private WeakMap issuance with exact allocation, control, owner, mode and live scope; public paths and copied/fabricated records cannot authorize a bundle or publication. Accepted operations register before effects and drain before scratch/image/binding release, including detached success/failure, thrown undefined and cancellation. Admission closes before drain; delayed work refuses. Preserve primary failure and report accepted/cleanup failures in deterministic order rather than using truthiness.

Change bundleJavaScript and its actual TypeScript callers together to require an opaque issued destination. Both esbuild --outfile and Bun file transfer resolve only that destination's privately accepted exact path. Source equal to or contained in generated output, foreign destination, escaped scope, wrong control or image substitution must refuse before mkdir/compiler effects. Remove SEMIO_TICKET_DIR/temporaryRoot path authority from Bun worker setup. bundleVirtualJavaScript may return bounded in-memory bytes, but its worker files still need actual diagnostics custody through final byte consumption; it cannot retain a loose temporaryRoot escape for unrelated browser callers.

Make shared repository publication require the actual storage/control, validate destination plus staging/rollback siblings under the same enforcing root, bound actual source file count/bytes, and keep existing publication resource/old-owner semantics. Update currently managed callers to pass their real store. For currently unbounded callers, open their actual products scope and relocate generated temporary/output first; do not wrap an ordinary output directory and call it bounded. This is an explicit shared API change with no optional raw-path fallback.

Package-facing dist and per-mode links need their own closed binding owner: authenticate the exact package/source identity and expected fixed product target under real package-binding EX. Create or update only a protocol-owned binding with a receipt stored in the finite product namespace. Hold the binding and actual artifact reader through real consumer callbacks/children. Existing unqualified directory or foreign link must be preserved and refused; no age/name-based adoption, deletion, or repeated relocation into an unbounded held-output area. A preexisting baseline that blocks binding is an honest admission frontier until its actual reader/writer custody is established. Arbitrary direct module consumers that never enter the binding reader are not proven safe by a successful managed test.

The declaration subprocess must not keep accepting raw output arguments. Prefer a bounded explicit in-memory emit response consumed by the parent issued sink, because the TypeScript emit callback already intercepts writes. If the retained declaration process writes files, it must open its own actual diagnostic scope and return a closed file receipt retained through a genuine cross-process loan; a copied parent path or environment marker is not enough. No new process receiver or structural authority registrar will be introduced.

Route dependency ContractCheckScript through the existing actual diagnostics/test-artifact owner, with the forced destination and awaited test child inside its callback. Incoming SEMIO_TEST_ARTIFACT_DIR is data to ignore/refuse, not storage issuance. This fixes the concrete active diagnostic writer without editing the installer generation protocol.
