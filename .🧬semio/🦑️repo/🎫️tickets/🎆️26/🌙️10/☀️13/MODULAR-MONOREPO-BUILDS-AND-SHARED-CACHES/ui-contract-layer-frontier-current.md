## First Real Cuts

1. Establish schema-owned budget constants and identity definitions below both model and document. Move `UI_DOCUMENT_NODES`, `UI_NODE_BINDINGS`, patch capacities, the shared page-width authority, and tree-window arithmetic with their actual formulas. Builder and value capacities must independently reference this authority, never each other. Move `SurfaceId`, `UiNodeId`, `UiRevision`, allocator and all their inherent/Serde/value impls from document lines 26–93. `SurfaceId` depends on text, so identity depends on the text leaf. Move `UiIntent` with action semantics to the model above identity, not into identity.
2. Extract text and fixed containers with complete nominal implementations. Action lines 73–265 contain `UiText`, `UiTextOriginalCopy`, formatting/conversion/Serde/ToValue/FromValue. Lines 283–894 contain `UiFixedList`, iterators, map, bytes, storage bindings and codecs. Preserve no canonical impl in the old action unit. Generic collection retirement/copy traits must live below their blanket/generic impls or those impls must remain with each nominal container owner. Reexporting a foreign nominal type does not permit orphan Serde/value impls in a higher crate.
3. Extract the action value arena with its exact retirement backend. Action lines 900–1678 own `UiCollectionHandle`, page/collection slots, `UI_VALUE_ARENA`, lists/maps/builders/cursors and codecs; `UiValue` lines 1836 onward belongs there too. Move `UI_VALUE_HANDBACKS`, `hand_back_value`, `UiValueRetirement`, `UiValueRetirementStep`, `close_ui_value_page_with_grant` and the `impl UiValueArena` blocks from retirement with that owner. Keep arena internals private. Define a narrow owned retirement/copy protocol as needed; never export raw arena handles/slots/mutex to make a cut compile.
4. Establish typed model ownership over Component/layout/accessibility/surface/action. Move component-local numeric predicates from limits lines 178–225 into this lower owner (or its number domain), keeping inherent props methods beside nominal props. Partition typed visitors: scalar/text/value/container pieces below model; `Label`, `Component`, layout/style/accessibility/action visitors with model; document visitors with document; built visitors with builder. The cursor/protocol must not import any higher concrete type. The existing `pub(crate)` trait cannot cross native crates unchanged; deliberately expose only the needed owned protocol or keep concrete visitors within owner crates.
5. Separate document data/storage from assembly/comparison/validation. Move `UiDocumentAssembly` and document-component compare above document rather than nesting their code into its source closure. Document exact retirement and patch storage remain with document because they inspect its private owner slots. Move resident aggregate accounting to an authority with explicit owner byte demands; its direct reads of action/document private static sizes cannot remain a reverse dependency.
6. Put BuiltNode/BuiltChildren, their Drop/Serde/copy operations and all built retirement under builder ownership. Component visitors must not own built retirement. Finally place validation over model/document, and assembly over document plus builder/validation as actually required. Schema export registration sits above the types, with independently scoped exports for fine Nx artifacts.

Desired dependency direction is foundations → model → document → builder/validation → assembly/export (arrows mean prerequisites precede consumers). Builder may depend only on model/document records when reconciliation demands it; no lower module may name builder concrete types.

## Tests And Visibility

Private arena/storage tests must stay in their nominal owner's crate: action fixed-list storage tests; retirement list/value/handback tests; builder built-children retirement tests; document resident/root/refresh/lease-owner/typed-document/patch storage tests. They inspect ownership state and cannot become external tests by publishing internals. Public fixture conformance tests can depend on the public assembly surface; copied fixture parsing should not pull the aggregate UI root back into every leaf. Copy/compare tests belong with the canonical algorithm owner and its concrete model dependency. Serde/value interoperability tests belong with the nominal definitions and their codecs. Preserve fixture-based cross-language comparisons, but count each test target's actual source closure separately when admitting it.

No native cut is validated by this audit. The next concrete edit should be budget + text + identity foundations, then relocate complete value arena ownership and split retirement visitors before extracting Component/document. Retain exact native Source refusal until each real compiler closure is below 262,144 bytes, 32 files and 4,000 active units.
