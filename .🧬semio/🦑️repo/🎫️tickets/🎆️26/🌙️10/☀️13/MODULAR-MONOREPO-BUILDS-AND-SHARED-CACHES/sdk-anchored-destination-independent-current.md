# SDK Anchored Destination Independent Review

2026-10-15. Source-only snapshot review of derivative `📤️copy/🟦️.ts`, derivative `🟦️.ts`, rooted source tree, layer executor and current tiny copy test. Concurrent edits may supersede this snapshot. No runtime, copies, builds, caches or frozen SDK work started.

## Actionable Findings

1. Destination enumeration has no preallocation bound. Both initial and final `readdir` calls materialize the whole directory array before any count check. Initial names are retained in a Set with no maximum, name/path validation or declared-input comparison. A staging directory containing an arbitrarily large unrelated namespace therefore consumes unbounded enumeration memory and has its initial names accepted as expected membership. Final checking also enumerates all unexpected names before refusing. Replace these reads with bounded iterative enumeration, cap total entries/path bytes and validate initial allowed publication inputs. Test by injecting more than the permitted names and proving iteration stops at the cap, plus a small unexpected initial entry that must refuse before copy birth.

2. Directory mode changes are invisible. Destination `check` and `checkChain` compare directory identity and kind but omit mode. Excluding mtime/ctime is appropriate for legitimately mutating directories, but chmod changes are independent of those mutations. Same-inode destination root or parent mode changes can pass final settlement. Retain/compare mode in directory checks (with explicitly authored legitimate mode changes if needed). Test chmod of an admitted parent during a paused accepted copy, requiring final refusal while all accepted copy operations settle.

3. Maximum-entry boundary includes an extra synthetic root. `created` refuses when `rows.size >= maximumEntries`, but rows already contains the staging root. The source schema admits maximumEntries actual source entries, so an otherwise admitted exact-cap index is rejected on its last entry. Source tree directory bookkeeping has the analogous synthetic-root limit if all admitted source entries are directories. Either define root-inclusive bounds consistently in schema/census or allow the separate synthetic root. Test the exact limit and one-over limit using a reduced injected policy/test fixture, validating the same count with the independent oracle.

## Parent And Lifetime Assessment

Path syntax rejects dot segments, backslashes, NUL and non-node_modules paths; absolute destination length is checked before returned path use. The destination helper registers every accepted parent/created promise, records first rejection using array length (including thrown undefined), closes admission and drains promises before retiring its live flag. The layer executor awaits every already-started worker before propagating first failure. The projection separately retains `state.copy` through callback failure. No new accepted-drain defect was found in that inspected wiring.

These are path revalidation helpers, not kernel-handle anchored mutation. `await destinationTree.parent(path)` returns a string after checking parents; subsequent async mkdir/copyFile/link/symlink resolves those parents again. A concurrent hostile actor can swap a parent during that gap, perform a redirected write and restore the original parent before final checks. Source `parent` has the analogous read gap. Persistent swaps are detected by later identity checks, but reversible substitution is not excluded. If containment against concurrent uncooperative mutation is a required guarantee, use owned native directory handles/relative no-follow operations rather than claiming this string API closes that threat. A deterministic tiny test can pause the filesystem operation after parent validation, substitute a parent symlink, execute the operation and restore it before final verification; assert no external mutation under the intended contract. This review does not infer that an uncooperative writer currently has admitted access to the staging namespace.

Current tiny tests verify concurrency, hashes/inodes/modes after normal copies and nested detached settlement. They do not exercise hostile destination enumeration, parent substitution or directory chmod. The new synchronous-source-ancestor counter measures traversal cost, not these destination safety properties. Root owns the in-progress cold-seal rewrite; this report does not qualify its latest source or runtime.
