## Concrete Review Proofs

- `…/🏗️build/📥️inputs/🧮️digest/📥️read/🟨️.mjs:12,28–32,46`: policy primitives are copied/frozen from schema; counters, maps, pending operations and ownership are private per batch. Extent admission checks safe nonnegative integer extent and both role/aggregate budgets before the metadata or chunk allocation at line 29. One live serialized descriptor and a maximum 64 KiB chunk; Source never allocates its whole body. Missing paths also consume the private unique-path/work budgets.
- Reader lines 15–21 and 30–32, plus digest lines 16–20: actual issued control authentication precedes caller closure/receipt/plan capture. The batch does not accept structural token/control copies. Only its factory-issued WeakMap token can reach reads; retired/foreign-root tokens refuse. Each accepted uncached read enrolls under `withIssuedResourceOperationV1` and the whole batch under `withRequestedIssuedResourceControlV1(control,0,…)`.
- Reader lines 22–25,32,44: relative names reject empty/dot/parent components, absolute paths, backslashes, colons, NUL, lone UTF-16 surrogates, excess UTF-16 length and excess UTF-8 bytes. Resolved absolute path length and containment are checked. Physical ancestor traversal is bounded, rejects symlinks and special blockers, and distinguishes missing ancestors from normal-file blockers. Existing ancestors/blockers are rechecked after a continuation before an absence result transfers. Root and fixed metadata namespace paths are bounded as absolute paths; namespace/key validation allows only two captured namespaces and 64 lowercase hex digits.
- Reader lines 28–29: lstat requires a single-link regular leaf, then descriptor open uses O_RDONLY plus available O_NOFOLLOW/O_NONBLOCK. Both linked path and opened descriptor must retain the complete captured dev/inode/mode/link-count/size/mtimeNs/ctimeNs stamp; ancestors must retain directory identity/mode. Every chunk runs these predicates, reads exactly the admitted length, then yields the actual control. An explicit one-byte EOF probe rejects growth; final identity checks precede return. Descriptor custody closes the exact admitted object before outer completion, and temporary retained/chunk buffers are wiped in finally.
- Reader lines 18–21 and 26–32,42: every asynchronous lstat/stat/read/open checks the actual control before/after; chunk, lexical metadata and immutable traversal continuations also check it. Counters expose progress DATA only. Admission closes when the body exits; already accepted reads drain before batch retirement and map clearing. A failure cannot be swallowed into successful batch completion.
- Reader line 32 and canonical `🧰️framework/🔨️modules/📁️filesystem/🧾️observation/📁️descriptor/🟦️.ts:15`: a sole original Error or thrown undefined is rethrown exactly, including when an accepted read completes during body failure; descriptor close cannot replace the body's primary. Distinct competing failures deliberately produce an ordered bounded AggregateError ledger, preserving the first failure as its first leaf and preserving an undefined leaf. The contract is not exact outer identity when multiple distinct failures compete. This matches the current competing-failure Source law and retained terminal evidence; interpreting “primary” as exact outer identity for every competing failure would overstate the implementation.
- Reader lines 26–29 and digest lines 11–14: metadata byte admission precedes decoder/parser allocation. JSON lexical depth/node validation precedes JSON.parse; TOML has conservative lexical container/work bounds before its parser; immutable traversal adds depth/node/plain-value checks. Closure JSON has a closed version/files schema, finite roster, bounded scalar names, uniqueness and immutable sorted capture before Source hashing. Inventory bytes must hash to their requested key. Selected Cargo manifests/locks use the same batch reader with a bounded repository-confined ancestor search (`…/🔒️lock/📥️read/🟨️.mjs:8–12`). Existing TOML parser remains behind this first-party interface.
- Digest lines 12–20 and reader lines 30–32: per-batch reuse is private; fresh public digest/task/receipt calls always create fresh batches. No public caller Map or cross-batch parsed-content/digest cache remains. Missing-to-present and package/lock-byte changes therefore re-enter descriptor observation. Same-batch dedup is intentionally not a filesystem-wide atomic snapshot.
- Actual `…/🔌️nx/📦️graph/📥️inputs/🟦️.ts:8–15`: namespace authority is required before DTO capture; the received task callback forwards its actual phase to awaited raw algorithms and checks terminal output DATA/abort. Actual Graph `…/📦️graph/🟦️.ts:82–88` enrolls the reader in its genuine namespace/task owner and passes the carried operation phase. This review does not physically qualify its store retention or eviction.
- Actual digest/lock script entrypoints receive Original and create their finite 120000 ms phases. Existing build-mode hash consumers await with phaseControl. Frozen runtime statically exports the real Graph adapter; patch calls at lines 1219,1281,1301,1338 all await. No compatibility branch, fake owner, alternate registrar or public reusable cache was found.

## Retained Evidence and Limits

All sixteen retained log hashes listed in `nx-source-hash-bounds-current.md` independently matched their files under the existing generated evidence directory. Inspected final prototype/release logs each contain 3 pass, 0 fail, 107 assertions and terminal identity/cancel `read:true`. The undefined child contains `same:true, completed:true`; competing failure leaves contain the original regularity Error then undefined. These are verified prior run records, not tests rerun by this audit. The test Source uses independent Node crypto/ordinary-file bytes, Ajv plus SQLite extent decisions, and Bun TOML selected projection. Historical failing checkpoints remain distinct from final evidence.

The complete caller strict logs remain failed: 32 diagnostics per mode in the two pre-existing build-mode/contracts owners, with extendedDiagnostics retained. This audit does not turn the strict aggregate green or assert a new compile result. New reader/adapter roots having no diagnostics in those captured runs is a narrower observation.

Finite synchronous JSON.parse/TOML parse, Buffer decode/allocation and selected-lock projection are not hard-preemptible. TOML delimiter counting can conservatively refuse valid input. Identity/ancestry checks do not provide same-user atomicity or an immutable multi-file filesystem snapshot. Platform no-follow flag availability varies; ordinary tests are macOS evidence, not Windows/Linux execution. EOF/extent and cleanup predicates were reviewed; no fresh adversarial runtime was executed here. Native lifecycle, physical cache funding, coupled eviction, frozen SDK callback identity and full managed Graph hash-completion retention remain unqualified.
