## Catalogues, Peaks And Pressure

Catalogue EX protects read/validate/admit/write/commit metadata only. Admission selects an existing exact clean context slot or a new bounded slot, records its dirty transaction and reserves its actual per-context image charge through the existing parent journal. Child image creation is completed while creation admission remains exclusive; fully allocated parent backing usage and unchanged floor are rechecked before releasing that brief admission. Other producers then operate entirely inside their own already-funded enforcing child images. Dirty/unknown prefixes remain charged and are never adopted, expired by PID, or healed from empty paths. Commit checks the exact selected slot transaction rather than requiring that the whole catalogue sequence stayed unchanged while distinct contexts committed.

Per-context Native maintenance resets only that producer cwd/output after all accepted work joins, while keeping its incremental data. Exact same-context queued EX prevents two agents resetting that producer simultaneously. Per-context reader/kernel EX and actual descriptor census still reject foreign readers. Pressure retirement requires the original whole-cache quiescent Native EX plus exact catalogue/context/child backing/charge/descriptor identity; only complete actual child retirement can release the parent's conservative charge. Never recursively remove an active Native subimage or blindly delete state based on DATA. If quiescence or authentic retirement cannot be established, retain bytes and refuse.
