## Pure Capture Inspection

captureSelectedTaskDataV1 privately copies and freezes the primitive schema Policy fields at module load. Traversal increments value/depth counts before descent; charges aggregate UTF8 key/string bytes; checks maximum members before processing container contents. Repeated acyclic aliases are traversed and charged again rather than bypassing maximumValues. The limits are depth 64, 1048576 visited values, 65536 members/container and 67108864 text bytes.

Proxy recognition precedes prototype/own-key/descriptor operations, so caller proxy traps are not used to inspect a proxy. Plain object/null prototypes and ordinary Array.prototype arrays are accepted. Symbols, accessors, nonenumerable members, functions, class instances, nonfinite numbers and ancestor cycles refuse. Arrays require bounded dense own indices with no additional properties, and explicit length consistency; a sparse array cannot compensate with an extra named member. Primitives including explicit undefined retain their values. Object.defineProperty supplies inert __proto__ DATA without prototype assignment.

All resulting containers are frozen. An already frozen container is reused only after every descendant has passed inspection and returned by identity; a shallow-frozen parent gets a replacement lazily upon the first copied child. Earlier validated siblings are copied through descriptors and later siblings are still traversed, so neither earlier/later mutable descendants nor repeated aliases evade capture. Ancestor tracking is removed in finally and does not misclassify acyclic repeated subtrees as cycles.

The implementation bounds synchronous traversal and aggregate accepted work. Reflect.ownKeys and UTF8 byte measurement can perform work/allocation before a limit rejection, and the caller already owns input memory. It is not a hostile-process heap guarantee or measured latency guarantee. Synchronous capture does not independently yield progress/cancellation during that finite traversal; genuine issued control is checked first and canonical asynchronous work keeps existing progress/cancellation behavior.

The Value schema deliberately describes portable JSON DATA, not all accepted JavaScript values. Explicit own undefined is a separate actual JavaScript law. Capture is inert DATA isolation and confers no graph/Native authority.
