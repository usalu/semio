## Concrete Ownership Plan

1. **Values and fixed collections.** Extract the actual `UiValue` arena, `UiFixedList`, `UiFixedMap`, original bounded list/map storage and Value retirement from the first part of `🎬️action`. Depend directly on existing Value/Text/Budget. Move their real tests and neutral expected-output corpus. These are real storage/ownership bodies, not aliases or copied declarations.
2. **Action data and intent.** The latter ActionId/Trigger/ActionBinding/MenuRef/UiIntent declarations depend on canonical values plus existing identity and text, not Component. Move component copy/compare mounts out of action into their operation owner. `UiIntent` names UiNodeRecord only in documentation at the inspected use; verify all real type/method references before asserting the cycle is absent.
3. **Presentation records.** Own actual accessibility/layout/style/overlay/surface and formatting primitives below Components. Avoid moving broad snapshot/builder access into this owner. Move concrete property types such as SurfaceProps to the lowest cohesive semantic owner that does not depend on Component/Document. Existing identity/text/budget owners remain canonical; do not duplicate them.
4. **Components.** Own concrete component/property algebra and numeric/text-input behavior, plus actual typed component retirement. Depend on Actions/Values/Presentation, never Document or Builder. Component-copy/comparison operations that currently reach UiNodeRecord must live above the document boundary or use an actual finite borrowed component view; no structural counterfeit tree or numeric resource handle.
5. **Document remains the actual upper `semio-framework-ui-contract` owner.** Retain real UiNodeRecord/UiSnapshot/UiPatch admission, exact paged patch storage and document assembly, along with direct Components/Actions/Values/Identity dependencies. Remove builder/typegen/whole-component operation bodies from its Source closure. The retained crate must still own substantial real document behavior; it must not become a reexport facade. Preserve original assembly, patch Returned/Retained handback and controlled retirement gates.
6. **Copy, comparison and retirement execution.** Move actual component/document progressive operation bodies and their custody tests into cohesive operation owners depending on canonical types. Split component versus document operations if the full test closure approaches4000lines. Public read/owned-transfer ports must preserve actual source witness and accepted Original lineage; no copied structural bridge, registry enrollment or integer authorization.
7. **Builder and validation.** Builder's108978B/2568 raw lines plus387-line direct tests is a meaningful actual owner. Its additional built-tree/retirement/test closure must be measured; split actual bounded tree assembly from the builder when necessary, never path-include it across owners. Limits'75996B/1500 raw lines is another real validator owner over canonical Document/Components. Resolve existing inherent methods by keeping type-invariant constructors in the type owner and moving higher policy checks to explicit first-party operation functions/traits; no foreign inherent impls or backwards-compatibility adapters.
8. **Typegen and scope schema.** Move the actual65kB versioned owned TypeScript projection implementation and export tests into a separate schema/typegen owner. Keep exact emitted TS/JSON expected bytes in a neutral corpus and validate through TypeScript/independent schema oracles. Runtime Presence/schema registration should consume its actual small declaration and normative metadata, not the entire typegen Source implementation.
