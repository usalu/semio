## Production Behavior

The descriptor-node factory previously captured a plan through the private plan owner and then recursively schema-validated that already owned plan again as part of every new node. The plan owner already captures inert raw DATA, fully checks its schema, normalized unit, semantic/context identity, exact dependencies and output namespace, and freezes it. Its WeakMap is private immutable DATA provenance and does not grant compiler, Native, filesystem, or cleanup authority.

The factory now prepares one node-envelope contract at module initialization. Before composition it requires the node schema’s plan branch to contain exactly the current plan schema reference and no sibling fields. A different reference or added sibling constraint fails preparation. Only that verified branch becomes true in a copy of the complete schema; root, definitions and all other envelope constraints remain in the compiled snapshot. Every node still passes through the existing plan capture first. Raw wire plans still receive full validation and semantic checks. Canonical bytes, SHA256 identity, predecessor correspondence, dense inert copies and reducing byte limits remain unchanged. The full published wire schema is unchanged. No global value cache, new disk cache, runtime dependency, legacy path, Native capability, or exported API was introduced.
