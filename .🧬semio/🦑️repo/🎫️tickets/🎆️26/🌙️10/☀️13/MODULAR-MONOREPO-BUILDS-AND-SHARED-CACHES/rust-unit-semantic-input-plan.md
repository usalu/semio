# Rust Unit Semantic Input Plan

Read-only proposal for Nx executor implementation. No runtime qualification or production change was performed. Paths below share `🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/⚡️caching/🦀️cargo/📦️units/` unless otherwise stated.

## Concrete Boundaries

`📥️descriptor/🎯️selection/🟦️.ts:32–33` currently returns every raw global manifest/lock fact as `configuration`. `📥️descriptor/🕸️graph/🟦️.ts:18` additionally puts raw `JSON.stringify(observed)` in `SEMIO_CARGO_UNIT_EVIDENCE`. `🟦️.ts:31` hashes the complete unit. `🟦️.ts:36` hashes raw file inputs again in Nx and embeds the descriptor path in command options.

The raw Cargo `compilationDigest` originates in framework `🏃️process/📦️artifacts/🏗️native-build/🕸️units/🟦️.ts:23` from a unit containing numeric dependency indices. That owner already produces stable dependency IDs in the same function. Keep the original raw digest for provenance; stop folding it into compiler artifact semantics.

A digest-only tweak is insufficient: `📥️descriptor/🎯️selection/🟦️.ts:35–36` names descriptor files by all encoded bytes, and the generated command contains that path. If the descriptor retains raw global facts, an unrelated edit still changes the Nx command hash even after `plan.digest` is repaired.

## Proposed Closed Contracts and Functions

Author language-neutral schema/corpus first for a semantic executable unit and a separate Original provenance guard. Update current closed contracts directly; no compatibility layer.

1. Materialization returns semantic units plus provenance facts. Extend `CargoRustUnitMaterializationPortV1` in `📥️descriptor/🕸️graph/🟦️.ts:7–10` so configuration admission can return both exact physical facts and canonical effective semantic facts. The production port in `📥️descriptor/🎯️selection/🟦️.ts:32–33` still reads/hashes/rechecks every current configuration file and compiler defining Source. Raw workspace manifest/lock/configuration facts go to provenance, not executable unit file inputs. Compiler defining implementation/schema/policy Sources remain semantic exact byte inputs.
2. Derive unit semantics from the actual fields consumed by `rustLibraryCompilerPortV1` (`🏗️compiler/🦀️rustc/🟦️.ts:20–26`): target/name/entry/kind/role/triple, package/version identity, mode/profile, ordered normalized arguments, cfg/features/cfgSnapshot, exact compiler/sysroot/linker identity, compiler environment, admitted source digests/boundaries, exact output contract, and stable predecessor IDs/extern names with semantic and actual receipt digests. Keep effective profile facts (`profileDigest`) until every Cargo profile field is explicitly handled/refused; do not silently drop an unsupported field. Keep provenance/public/noprelude evidence or refuse unsupported semantics if the adapter does not implement it.
3. Replace `SEMIO_CARGO_UNIT_EVIDENCE` with an explicit owned normalized compiler-evidence digest, excluding raw `compilationDigest`, global `configurationDigest`, graph roots/numeric positions, and observation-only absolute paths. Reuse `splitRustCompilerArgumentsV1` at `📥️descriptor/🕸️graph/🟦️.ts:26`; preserve argument order. Framework planning `readCargoCompilationGraphV1` already maps predecessor indices to stable IDs before this boundary. Do not change its original digest/census custody.
4. For lock resolution, use owned `🏗️build/📥️inputs/🔒️lock/🟨️.mjs` `cargoLockClosure` with exact selected package name/version from actual metadata, rather than raw lock bytes. Publish its canonical closure digest into explicit semantic configuration. Keep package version/source/checksum and selected resolved predecessors. If the existing closure conservatively includes inactive/dev dependencies, admit that limitation; do not claim perfect active-unit narrowing without an active graph correspondence corpus. Global workspace members/unrelated dependency tables are provenance only; actual effective inherited edition/profile/features/target/config flags remain in compiler semantics.
5. `planRustUnitsV1` and `rustUnitNxProjectsV1` (`🟦️.ts:28–36`) consume only executable semantic units. Nx inputs include exact source/defining-code files plus semantic environment binding and current dependency receipts; never raw provenance paths. Publish the semantic descriptor under its own exact byte digest; command path and per-unit descriptor closure remain identical after unrelated edits. Publish the separate provenance guard under its own digest and include it in `produceSelectedRustUnitProjectsV1().inputs` for original Source authority, not task hashing.
6. Preserve existing `selectedRustSourceFactsV1` and `prepareSelectedRustBuildGraphV1` (`🏗️build/🕸️graph/🦀️rust/🟦️.ts:30–42`) for all raw provenance facts before graph publication and after the native consumer. A cache hit still needs fresh planning/guard validation; cache reuse is never permission to skip original provenance checks.
7. Compiler dispatch currently invokes `verifyRustUnitInputsV1` before/after compilation (`🏗️compiler/🟦️.ts:14,19`). Add an Original invocation guard reference bound to semantic unit ID/digest through the existing authenticated process invocation owner, not generated target options/env/runtime hash inputs. The child resolves and validates that guard before any output/cache receipt acceptance, then rechecks after child settlement. Raw guard artifact path/digest may vary per invocation while semantic command remains fixed. This binding must also cover the managed-reuse early return in `📜️script.ts:34`; currently that return precedes compiler-level input verification. A naked unvalidated environment path is not sufficient authorization. Executor should thread the guard through its existing issued process capabilities; no mutable global lookup file.
