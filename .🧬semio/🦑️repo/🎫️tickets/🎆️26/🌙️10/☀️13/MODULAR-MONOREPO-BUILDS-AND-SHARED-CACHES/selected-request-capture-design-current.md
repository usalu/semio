# Selected Request Capture Design

The issued selected-task reader currently waits on nx.json before consuming its caller-owned graph, selection and planner methods. A caller can mutate these references while the actual descriptor operation waits, changing the task's Source set after acceptance. The SDK scope port also waits on genuine Graph task admission before invoking that reader. This is a Source finding, not an observed Native race.

Capture bounded first-party DATA synchronously after genuine control admission and before either wait. A private immutable schema policy bounds depth, visited values, members per container and aggregate UTF8 string/key bytes. Reject proxies, accessors, symbols, sparse arrays, cycles, nonfinite numbers and executable/class values without invoking their getters. Preserve explicit own undefined values as non-JSON Nx optional DATA; neutral JSON vectors cover portable cases and a separate JavaScript law covers undefined. Capture exact planner function references before waiting; these remain existing behavior ports, not newly granted authority.

The ordinary reader captures graph and selection before its canonical requested child starts. The actual SDK scope port captures graph before its genuine Graph admission wait, using the same pure defining helper. Fully checked deeply frozen DATA may be reused by identity, avoiding a second clone at the reader boundary; validation still traverses the finite graph. Captured DATA is never treated as a Native/store/control owner. Actual retained Graph task and descriptor custody remain unchanged.

Schema-first language-neutral mutation/refusal/extent vectors plus Ajv and independent SQLite JSON traversal establish the pure contract. An ordinary real filesystem law calls the actual reader and mutates graph, selection and planner immediately after invocation; it must still select original paths and tasks. Negative actual calls run in isolated genuine child Originals so the healthy observer is not poisoned. Source AST laws cover the SDK pre-admission capture order without a fake positive provider or installed SDK execution.

This cut does not implement coupled mandatory cache retention, atomic Source editor exclusion, full task completion reader qualification, Native effects or performance/platform acceptance. No compiler/provider/cache image/network operation is authorized by these tests.
