# Issued Control Deadline Signal Design

Finite actual issued controls currently authenticate their inherited deadline only when remaining time is checked. Their signal does not itself abort at the requested phase deadline; stalled fetch or stream I/O can therefore hold real resources beyond that deadline.

The canonical private control owner must schedule cancellation from its existing minimum Original, ancestor, absolute and monotonic requested deadline. This does not grant time, change an Original, or reconstruct authority from DATA. Finite requests receive a private immutable effective signal. A zero request without an additional signal inherits the exact actual parent signal. Cancellation reasons remain the actual reason.

Ordinary scope retirement must dispose its own and descendant timers only after accepted children drain. Actual process and signal-alias retirement must also dispose synchronous control timers. The preaccepted physical cleanup phase retains its separate existing funding, signal and lifetime; this change is confined to ordinary scope/control ownership.

Schema-first neutral eight-case corpus covers requested, inherited and ancestor deadlines; prompt scoped, alias and nested synchronous retirement; exact cancellation reason, and retained cancellation while accepted children drain. Each expected failure occurs inside an isolated real received Bun child. The healthy parent observes terminal DATA. Ajv independently validates the corpus and SQLite independently classifies the expected transitions. Tests wait a finite interval then inspect the actual signal, so the pre-fix RED cannot hang indefinitely.
