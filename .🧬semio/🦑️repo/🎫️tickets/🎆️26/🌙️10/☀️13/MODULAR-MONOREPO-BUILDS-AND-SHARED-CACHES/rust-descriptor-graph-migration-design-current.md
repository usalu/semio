## Publication and Retirement

Proposed design to evaluate: a shared descriptor-namespace lifetime through selected graph publication/backend consumption and through each actual CLI read, with immutable per-node publication locks; metadata GC needs the corresponding exclusive namespace lease, acquired without waiting while other genuine readers hold it. Never acquire an exclusive upgrade while retaining the same shared namespace scope. Reclaim/admit before borrowing the namespace, then retain exact paths/content through work. Do not infer that this proposal is already implemented or safe from deadlock.
