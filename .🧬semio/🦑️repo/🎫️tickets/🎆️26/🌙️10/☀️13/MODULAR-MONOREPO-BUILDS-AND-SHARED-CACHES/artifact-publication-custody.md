# Artifact Publication Custody

The repository facade deleted a retired foreign publisher's directory before acquiring a publication lease. Its default lease storage also differed from the native executable consumer's storage. The actual regression held the consumer's shared lease and observed early deletion and early settlement. The corrected facade uses `.cache/framework/leases` and delegates ownership decisions to the publication owner while holding its exclusive lease. A vanished foreign manifest does not confer ownership. Existing unmarked directories are refused and preserved.

The language-neutral policy corpus is validated by Ajv. SQLite independently supplies the expected preserved byte value. Both tests exercise the real facade and the real publication lease, rather than a mocked wrapper. Temporary fixture bytes remain within the ticket's generated output. The core publication fixture uses a short disposable lease namespace inside the canonical framework lease store because a SQLite sidecar below the full ticket output path exceeds the enforced 256-character bound.

Actual verification as of 2026-10-14 05:04 UTC:

- The initial foreign-owner regression failed because publication settled while the consumer held its lease. The corrected prototype facade passed both ownership tests.
- The unmarked-input regression initially resolved instead of refusing; the corrected core owner refuses it without deleting input bytes.
- The core prototype publication gate initially failed on a missing neutral schema, then on an overlong fixture lease path. After adding the closed schema and shortening the disposable lease namespace, the registered Nx gate passed in 5.8 seconds. It exercised independent Python byte comparison, identical EOF cancellation, transient/permanent rename faults, bounded contention, rollback, and initial publication.
- The final release facade gate passed three tests and 21 assertions in 960 milliseconds; the Nx duration was 1.0 second. It includes strict TypeScript validation of the defining facade and publication closure and parses both launch inventories through the independent JSONC parser.
- The final prototype facade gate passed three tests and 21 assertions in 931 milliseconds; Nx completed in 987 milliseconds. The release core publication gate passed in 5.7 seconds. Both prototype and release qualifications are actual executions through the registered Nx targets.

An additional actual pinning regression reproduced an omitted original control: a shared-lease waiter remained unsettled after its admitted 100-millisecond deadline while the publisher still held exclusive custody. Pinning now forwards the supplied control and its original signal into the shared lease and both executable hashes. Hash reads check the original deadline before and after their awaited read and emit awaited progress/continuations every 64 chunks. The real waiter law and a delayed hash-read completion law refuse without publishing output. The final release gate passed five tests and 30 assertions in 3.22 seconds (Nx 3.3 seconds). The final prototype gate passed the same five tests and 30 assertions in 2.51 seconds (Nx 2.6 seconds).

This qualification covers publication ownership, default shared lease custody, and pinning's supplied original control. It does not qualify the entire build graph or ordinary warm Nx latency. Publication control remains optional, rollback still needs original-authority propagation, and pinning's producer provenance requires a separate audit. Explicit caller lease-directory overrides remain possible and are not a universal canonical namespace guarantee.
