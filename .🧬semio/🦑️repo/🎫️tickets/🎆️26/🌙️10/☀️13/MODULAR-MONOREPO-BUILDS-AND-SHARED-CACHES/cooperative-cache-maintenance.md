# Cooperative Cache Maintenance

The shared-store lease now excludes active Cargo compilers, but the old scanner recursively measured a complete unit and the deleter used synchronous recursive removal. A large unit therefore prevented the original signal or deadline from being observed until the operation completed.

The schema declares a maximum of 64 filesystem operations before awaited progress and continuation. All four production scanners and the physical deleter are asynchronous and require the original resource control. The workspace facade, reporting, general pruning, and incremental compaction forward that same control. Reporting no longer constructs a replacement signal. Deletion uses a physical postorder walk, preserves symlink destinations, rejects escaping unit paths and symlink parents, and supports a fresh physical scan after interrupted deletion.

The neutral corpus uses 257 files. Ajv validates the policy and fast-glob independently inventories actual retained files and bytes. The scan preserves the exact custom abort reason and stops on the original deadline before publishing a complete unit. Deletion stops at its first continuation with 227 files retained, resumes to terminal, and preserves an external junction destination. Existing Python byte and eviction oracles now run asynchronously under the original control.

`cache-continuation-red.log` records the absent cooperative behavior. Subsequent probes expose a strict TypeScript bigint overload mismatch and stale fixture coordinates; those were repaired. `cache-continuation-green4.log` and `cache-continuation-release.log` each pass five real tests, 51 Bun assertions plus existing Node assertions/Python comparisons, and the focused strict pruning-core check through actual installed Nx, 2.7 seconds. `cache-command-source-cooperative1.log` passes the updated injected scanner law but fails a stale source-closure fixture coordinate. The corrected `cache-command-source-cooperative2.log` passes all eleven laws, 172 assertions, 4.7 seconds, including the acyclic owner-graph typecheck.

These focused results do not qualify the full orchestration import closure or either complete monorepo build. No canonical compiler cache was deleted by this work. Private fixture output is under the ticket generated directory and temporary lease databases are removed by their owner.

The stronger awaited-publication law records completion after a real event-loop continuation and requires that completion before the continuation callback. `cache-continuation-prototype5.log` passes five tests, 57 Bun assertions plus the existing independent byte/plan assertions, strict core checking, 5.0 seconds. Source-closure validation additionally checks every literal named input physically exists. Its real red finds an absent schema declaration. The command-source schema now lives beside its owning test, replaces a missing root schema reference, and uses Ajv against the existing unchanged neutral corpus. An unused absent command-boundaries schema declaration was removed. `cache-command-inputs-green2.log` passes eleven laws and 205 assertions in 7.5 seconds.
