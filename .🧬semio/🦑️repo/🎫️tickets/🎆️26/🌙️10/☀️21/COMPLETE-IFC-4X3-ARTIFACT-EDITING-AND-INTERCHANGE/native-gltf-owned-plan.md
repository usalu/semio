# Original-Owned Native glTF / GLB Plan

## Contract and scope

Replace the three registered IFC4x3 / glTF geometry routes with original-bound source receiving, retained geometry construction, and source-owned final publication. The actual receiving and publication type is `GltfSnapshot`; private wire records remain codec implementation details. Natural GLB input borrows its original JSON and BIN spans, validates framing and canonical padding in bounded turns, and receives typed document fields directly. No whole JSON DTO, body flattening, cloned buffer mirror, cold graph projection, inferred grant, or default native control is admissible on the normal route.

Supported semantics remain static triangle geometry, authored world transforms, SI metres / Y-up on glTF and declared IFC project length units / Z-up on IFC. Indexed and nonindexed dense FLOAT VEC3 positions, aligned unsigned scalar indices, interleaved views, exact authored matrices, reflected winding and selected-scene hierarchy must match the pinned Khronos sources. Unsupported animation, skinning, morphs, compression, sparse accessors, external resources, semantic IFC data and ambiguous coordinate/unit contexts produce explicit atomic refusal or declared geometry-only loss diagnostics as appropriate. Detailed direction tables will accompany implementation.
