## Ownership And Representation

The original request retains its captured `SnapshotSource` and immutable final mutation slice. A borrowed overlay addresses original entities, inserted entities and replaced original argument slots. It does not construct a second `IfcSnapshot`. Overlay rows contain only source/mutation coordinates and stable identities. References resolve against the resulting population, including forward references to insertions. Complex constituent positions retain their actual source address.

Released declarations become immutable borrowed slices generated from the pinned production catalog. No request invokes the `OnceLock` heap builder. The source generator is retained as an input in this ticket, checks every emitted field and compares its full serialized projection with the production catalog. This is a production metadata asset, not a migration.

Semantic receiving uses an arena of nonrecursive values and coordinates. Source strings remain borrowed coordinates; computed strings and aggregate vectors are individually retained owners. Receiving and evaluation use explicit frame stacks. Each transition checks original cancellation and fuel, quotes item/copy/capacity/release/depth demand before mutation, and debits the same original receipt. Allocations are exact contiguous requests; a smaller capacity loan may legitimately leave the transition pending.

## Continuation Execution Design

After the independent foundation audit, execution continues with Copy continuation records referencing only immutable static AST. Runtime values use nonrecursive arena handles, borrowed source/static text references, separately retained computed text, linked aggregate edges and linked scope bindings. Function/query locals share immutable value handles; assignment reconstructs aggregate paths and does not mutate aliased arguments. Entity constructors have release-bounded attribute slots, preserve ancestry, and remain distinct instances.

Expression, statement, callable, equality/matching, text and population cursors each advance one explicit transition. Dynamic table growth is a separate actual allocator event, quoted for its complete contiguous allocation, native reallocation copy and old backing release; it never encloses semantic recursion. Text construction first admits exact capacity, then copies bounded UTF-8 chunks. Scope lookup, loops, CASE labels, QUERY candidates, unordered matching edges and population/rule iterations have persistent cursor coordinates. Checked i128 overflow and unresolved aggregate membership produce explicit incomplete diagnostics matching the current admitted semantics.

The canonical expression/statement/binding/official fixtures are reused directly by new native tests before implementation. Their execution remains blocked by authentic compiler ingress. Production completion remains guarded separately from receiving readiness, expression success and partial rule coverage.
