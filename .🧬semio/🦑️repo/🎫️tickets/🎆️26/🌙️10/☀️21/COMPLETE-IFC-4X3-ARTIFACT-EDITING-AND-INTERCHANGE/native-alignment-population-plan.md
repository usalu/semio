## Concrete internal seam

The chosen `IfcMvdPopulationWork<R>` accepts one already-admitted `RetainedCloneSource<R, Arc<R>>` donor after the enclosing endpoint admits its request. Receive moves that exact donor and retains one original-paid snapshot Arc in a born-owner field before posting; advance moves that same alias into its sealed source. This prevents source pointer reuse between turns and creates neither another request alias nor a source clone per clause.

One original-paid `Box<IfcSourceIndex>` gives index identity a stable address when the containing Work moves. Construction stores the candidate before any fallible receipt reconciliation. A private `with_view<T: Copy>` higher-ranked callback borrows a fresh population view and the same original context for one turn. Its private constructor requires the actual completed shape cursor and same-source/epoch completed index identity; no caller-provided boolean can admit a view. Clause pins contain source/request/index equality identities and original caller provenance, without dereferencing stored pointers. No borrowed view or owned heap donor can be returned from this callback.

The generic owner exposes receive/demands/advance/status and explicit begin-close/close-demands/close-step. Closing first retires view/shape metadata, then the index, sealed snapshot, any born snapshot alias and the original request. Each retained terminal owner remains present until its own paid release is complete. Unknown declarations and duplicate identifiers stay prepared container/index outcomes and never imply schema conformance.

Introduce one private native MVD population owner beside concepts/native.rs, holding the original admitted snapshot alias, born-error alias, shape cursor, source-ID index, exact input source pointer/epoch and OriginalSourceBinding. It exposes original demands/advance and retained retirement. A completed private accessor returns a short-lived borrowed view containing the actual immutable snapshot and prepared source index plus original identity/provenance. Fields and constructor stay private; the view is not a captured DTO, separate authority, owned graph or public publication proof.

The view is borrowed only for one original turn. Clause cursors retain exact source/index pointer and epoch identities on first use and validate them on every resume; they store addresses/static metadata/scalar state, never references into their containing parent. A coordinator can therefore own population and clause cursors as disjoint fields, borrow a fresh view and mutate a cursor without self-referential storage or source Arc cloning per clause. The view does not escape into an async task or new wallet.

Container preparation is not schema admission. Duplicate IDs remain represented by the prepared index's missing/unique/ambiguous lookup; unknown declarations remain clause-level unknowns. An invalid header/container yields the existing global incomplete report behavior. Use names such as prepared population/container shape rather than valid IFC. Source epoch remains continuation metadata, not canonical document hash.

Extract endpoint-independent business and direct progression into retained clause cursors that receive this private view. Keep original endpoint public request/report shapes and their existing request-before-source validation. Each standalone Work owns one population owner and one clause cursor. A later joint owner can retain one population plus both cursors. Request indices remain request-owned; neither clause constructs another source index or captures a graph.

The shared PrimitiveZero and owner-qualified query remain the only numeric and field traversal implementations. Direct's explicit CurveMeasure SELECT constructor admission stays in its direct clause; business's list ordering and all-member checks stay in its business clause. No correspondence policy is introduced by this refactor.

## Original funding and retirement

The original caller owns all preparation, child cursor progression, report building and final take. The scheduler advances one bounded child frontier with the parent's original grant; it posts only actual accepted child progress and parent metadata, without cumulative double charges or forecast debit. Each born owner is adopted before a fallible post, including source aliases and partial output/report buffers.

Retirement closes clause queries/numeric/list/relationship/report metadata and any borrowed-view bookkeeping before population/index/source aliases. A denied close retains its retry owner. Cancellation/expired ordinary deadlines allow only the existing paid original retirement path. No arbitrary second caller may resume, take or close an original operation. Source/index/view pointer currentness is checked alongside original binding and epoch before debit.

A prepared view is unavailable until preparation completes and after closing starts. Whole-operation take remains disabled while any clause/report/close frontier is pending. There is no transfer-as-ACK, host mount or Store/publication capability introduced by this internal seam.

Relating a business terminal to geometry requires the authenticated same source identity and existing direct path; an unrelated zero curve, independent ordinal or parent-last-curve cannot supply that identity.
