# Original Borrowed Attribute Query Parity

The shared TS catalog query already preserves owner qualification, actual source ordinal/part/argument addresses, missing serialized values, at most two retained matches and an unknown constituent after those matches. Its ten data cases plus invalid-index, missing-value and original-control laws are the existing 25 selected query tests. Native tessellation currently repeats an unqualified attribute scan and discards unknown declarations in that scan; its separate membership cursor retains unknown ancestry.

Implement the native engine beside the shared TS query at `IFC/catalog/query` using the actual emoji domain folder. The schema-neutral interfaces borrow source parts and static declaration slices through repo-owned traits. The ADD2 catalog adapter supplies existing retained `validation::metadata` declarations and the actual native IfcSnapshot rows. No owned catalog is initialized, duplicated or parsed by a request, and no graph/value/declaration is cloned.

The original-funded work retains a fixed state, two source addresses and borrowed static declaration keys. Each original turn advances one name byte, constituent lookup or attribute decision. Names use the same 256-byte ASCII EXPRESS identifier grammar as TS. Source row names are admitted before static lookup; every constituent is still checked after two matches. Simple rows use flattened attributes; complex primary and secondary constituents use their direct declarations. Owner comparison uses `declared_by`, never the current row type as a substitute.

An exact source ordinal is part of the actual population lookup, not a separately guessed diagnostic address. The cursor pins the immutable source pointer, source epoch, request name/owner pointer and length, metadata profile and original caller. The epoch is the existing native MVD caller's revision value; it is not a canonical hash or publication certificate. The enclosing actual source owner retains its immutable Arc while the query runs. Completed accessors borrow the exact slot/declaration/type; absent values remain unique declaration matches with no value. Source addresses format only through a borrowed Display adapter; any owned diagnostic string remains the caller's funded responsibility.

The query has no heap-owned state. Refused items/copy/depth/fuel are stationary; cancellation refuses ordinary progress; original close clears fixed metadata under the retirement predicate and existing RetireOwned. Results are inaccessible before completion and after closing or source/request substitution. There is no new wallet, original-control clone or admission boolean.

Test first through the actual ADD2 adapter using the shared ten neutral data laws and native equivalents of invalid ordinal, missing values, exact borrowed pointer identity, owner mismatch, late unknown after ambiguity, control denial/cancellation/substitution and paid close. The existing TS 25-law entry remains the executable cross-implementation contract; independent external declaration metadata is used only through a test interface and cannot replace uncertainty statuses for malformed source structures.

After query tests/source stabilize, replace the native tessellation attribute loop with this cursor, preserving original pending/receipt/retirement custody. The released RepresentationIdentifier/RepresentationType/Items declarations are owned by IfcRepresentation; add schema-first owner/unknown consumer laws and matching TS consumption where needed rather than flattening the result. Root owns Alignment direct-* TS files, which remain untouched. Other MVD geometry and full-view/semantic validation stay not evaluated. Native compiler/runtime/heap/receipt and public transport flags remain false; no build changes or enforcing runner bypass is authorized.
