# Cooperative GLB JSON Writer

The physical writer no longer performs whole-tree native map/Object.entries conversion, complete JSON.stringify, complete TextEncoder.encode, whole JSON bytes.set or a fill spanning the full JSON chunk. io/gltf-json.ts provides schema-role-aware incremental conversion and bounded JSON/UTF8 fragments; gltf.ts frames/copies those fragments through the original context. The existing real GltfSnapshot source is private before this work starts.

Conversion visits one typed node/member per yielded step, preserves safe exact BigInt ordinals and finite Binary64 values, and builds safe own-data native objects. Duplicate values replace without moving first non-index insertion position; JavaScript's own integer-key order is preserved. Extras/extensions have their closed JSON namespace, so ordinary data names attributes/targets/bits/toJSON never receive glTF record conversion. Ordinary undefined/empty array defaults retain the prior omission behavior, while extras arrays/objects remain data. Explicit malformed plain nonfinite numeric fields now refuse rather than emitting null; valid schema-value behavior is independently byte-compared. No legacy API or third-party runtime serializer is added.

Quote escaping handles controls, backslash/quote, genuine Unicode pairs and escaped lone surrogate code units. A bounded fragment never splits a genuine pair before UTF8. Small syntax tokens coalesce into bounded encoded chunks rather than allocating one byte-array object for every punctuation mark. Number text uses the host's bounded finite scalar formatting, including signed-zero-to0 and exponent thresholds. JSON visitation, encoding and final byte-copy each retain the captured original signal/callback/batch and completion checkpoint. Only at-most-three JSON padding bytes use fill; BIN copy now also honors the original admitted batch.

Framing has an explicit early aligned JSON ceiling derived from min(caller maxValues, uint32)-28-alignedBIN. The encoder separately requires that finite<=uint32 ceiling and checks actual UTF8 bytes progressively before storing each bounded fragment. A caller Number.MAX_SAFE_INTEGER grant cannot permit interim JSON growth beyond physical frame capacity. Value/depth budgets remain explicit; host object enumeration/hashing, scalar formatting and array allocation remain JS primitives rather than invented native receipts. The intermediate native tree is retained until fragments complete; this is incremental materialization, not a zero-copy tree claim.
