The native MVD module now exports a retained evaluator for the root-owned explicit Body Tessellation request/report schema. It evaluates only RepresentationIdentifier='Body', RepresentationType='Tessellation', and every Items reference being an IfcTessellatedFaceSet subtype. Explicit false applicability skips target resolution, null produces incomplete applicability, empty Items has the vacuous predicate result, and schemaConformance/viewConformance always remain not-evaluated. These fixed native limits match the default scope rather than exposing the TS control customization surface. Native typed construction already proves container/discriminant/word shapes; arbitrary raw JSON request closed-field admission and raw container counting are separate ingress work. This public typed Work API does not claim that ingress is mounted.

Target/diagnostic Vec growth, target string copy, diagnostic path Vec, attribute/index strings, pointer string and diagnostic donation each have explicit admitted turns. No source value borrow survives a turn. Typed retirement owns output/candidate/index metadata before original source/request authorities.
