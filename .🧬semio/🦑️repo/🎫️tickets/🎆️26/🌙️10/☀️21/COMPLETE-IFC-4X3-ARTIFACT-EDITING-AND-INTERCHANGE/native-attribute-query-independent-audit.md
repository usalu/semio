## Custody and query semantics

The cursor retains fixed inline metadata only. Input pins include exact population address and TypeId, source epoch/row, query name and optional owner pointer+length, metadata profile TypeId and OriginalSourceBinding. Ordinary advance checks cancellation/source/request/profile/caller before its demand gate and before mutation. Completed access rechecks pins and cancellation, returns nothing before completion and refuses after explicit close. Results borrow actual source values and static declaration/type expressions; no unsafe dereference or owned clone occurs.

Request/source identifiers are checked with the same256-byte ASCII grammar as the TS query. A constituent is resolved through actual metadata before attribute selection; simple records use all_attributes, complex primary/secondary records use direct attributes. Attribute matching compares declared_by independently of the runtime row name. Two matches are retained at most, yet subsequent constituents still undergo name and metadata resolution: late unknown dominates ambiguity. A unique declared slot with missing serialized value remains Unique/None. Completed matches retain exact entity ordinal/part/argument; Display formats addresses through the caller's formatter rather than allocating an owned string itself.

The ADD2 adapter uses existing retained metadata::entity and StaticAttribute/StaticTypeExpression, never the cold owned catalog. Actual IfcSnapshot query_part_count/query_part borrow primary and secondary constituents directly. Source immutability/lifetime is an explicit enclosing-owner obligation; an epoch value is not a canonical document revision or publication certificate. Reusing the same mutable interior source under an unchanged epoch is not authorized by the trait contract.

## Funding and close

The published demand is a conservative fixed envelope (2×cursor scaffold plus4×256 scratch), not a minimal physical measurement. Each advance performs one source-name byte, constituent frontier, bounded static lookup or attribute decision and posts one metadata item/copy receipt/fuel. Static lookup and name comparisons are bounded by the released identifier/metadata contract; this does not assert one comparison or one machine instruction per turn. No heap capacity is born by the cursor.

Denied items/copy/depth/fuel is stationary at the gate. Explicit close uses close_original_retained_step, retains original context validation and resets only paid fixed metadata. RetireOwned leaf semantics cover the inline cursor when the enclosing work retires; it does not own or silently retire the population. Source/native physical receipt correctness remains unexecuted under the authentic compiler refusal.
