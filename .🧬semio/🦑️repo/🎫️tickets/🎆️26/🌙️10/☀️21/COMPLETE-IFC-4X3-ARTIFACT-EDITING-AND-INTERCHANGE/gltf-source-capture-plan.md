# Original glTF and GLB Source Capture Plan

The Low audit reproduced accepted output mutation in the actual pinned Khronos Box path. A gltf-import callback changed the product name through the caller node alias. A later gltf-accessor callback changed an unread POSITION float; the accepted maximum X changed from 0.5 to 123.25. These are real loaded-artifact adapter holes, not synthetic native execution.

Use the existing central own-data capture interface for the actual GltfSnapshot shape, including its number[][] buffers and exact BigInt/Binary64 words. Capture original controls first, complete owned source admission before document/semantic callbacks, and rebind both IFC import and GLB write to the private source. Count asset/family/primitive records through the shared cooperative external record interface. Validate private buffer bytes through bounded checkpoints; retain existing explicit unsupported-semantics/accessor behavior. Do not use a synchronous JSON roundtrip, getter reads, live caller aliases, external runtime library, or eager complete-schema clone/parse in render.

Raw GLB bytes require a schema-owned binary capture interface before parsing any header. Borrow Uint8Array internal slots through built-in typed-array getters (accept Node Buffer's genuine Uint8Array view, refuse proxies and other element types without invoking caller accessors), enforce the admitted value limit, and copy into a private byte buffer in bounded chunks with original cancellation. Completed parsing/checkpoints must use that private buffer. Cooperative copying permits caller changes before capture completes; the guarantee is a private stable completed source, not an atomic snapshot at function entry.

First add closed neutral cases/schema/feature and actual loaded Khronos source-mutation/getter/limit/original-control regressions. Record the red baseline before production changes. Validate supported complete positions/indices independently with the existing Three.js official fixture suite; produce an independent original/reciprocal mutation probe where useful. Native original-source owners are separate and remain unexecuted; this work does not raise native capability gates or claim complete glTF semantics.
