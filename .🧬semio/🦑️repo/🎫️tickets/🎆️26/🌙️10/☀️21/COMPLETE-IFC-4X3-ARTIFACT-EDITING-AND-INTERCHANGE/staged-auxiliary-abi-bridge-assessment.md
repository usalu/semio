## Existing Real Route

Kernel Event::SurfaceVisible currently owns surface/body_key/view_state only, at framework/modules/kernel/🦀️.rs. Plugin events.wit mirrors those three fields. Renderer PluginRuntime/module-loader createRefreshUi submits the real actor activation through submitTurn and settlePluginTurn; handle-ui-intake takes OwnedUiInstanceSurface only after actual patch acknowledgement and installs that exact facade. Public ownedUiRefreshResponse subsequently projects BuiltNode and does not transfer an owned source.

The native reactor event-dispatch SurfaceVisible branch calls native_close_key then plugin_mount_surface with a borrowed view slice. SurfaceContexts holds the actual real window source. Existing staged_context capture/with_context correctly bind the actual NativeCloseKey, original parent/recipient/cancel/clock/deadline and scalar SurfaceWindowLease; the retained cursor avoids an eager roster scan and final borrowing stays inside one synchronous registry callback.

StagedRequestInput already accepts an original-owned Option<Vec<u8>>, keeps the donor stationary on denied admission, drives retained Pack/census/typed request movement and closes its actual original loans. It is not attached to an event or PendingReserved owner. The private IFC source and generic body builder can consume its completed typed request, but no native auxiliary lifecycle currently transfers that output to a prepared render source.

## Actual ABI Gap

GuestRuntime::execute_turn still receives &[Event]. The Wasmtime adapter calls kernel_turn_inputs_to_wit, whose SurfaceVisible conversion clones body_key and view_state into WIT-owned inputs. A new stagedRequest byte vector must not simply be cloned in that branch. Existing command/cold-pair dedicated page branches also copy into WIT Vec inputs; their presence is not proof of a suitable staged donation authority.

The repository-owned interpreter path has a second concrete crossing: execute_actor_turn builds OwnedPollInput from borrowed events and encodes it as JSON under the current identity transport authority. A new byte vector there becomes a JSON byte array before guest receiving. Its exact JSON framing/allocation and original actor copy/capacity/depth accounting must be included; a Pack1MiB request must not be treated as a1MiB actor input. This distinct path must be handled alongside Wasmtime, not hidden by the earlier binary mount census. OriginalShardEvent already retains OriginalActorInput<Event>, actual checkout policy and raw guest receipts; this is the existing source authority to extend rather than creating a StepContext from Budget or borrowing an unrelated identity wallet.

The frozen browser wire intent remains stagedRequest:{contextWindowId,request:Uint8Array}, separate from the ordinary ViewModel. It is a desired closed protocol shape, not yet a funded ABI field. SurfaceVisible/kernel/WIT/public sender must remain unchanged until original byte ownership crossing is designed and tested together.

## Next Implementable Bridge

First implement one generic original auxiliary request owner inside the existing retained reactor work path, with no public sender or capability change. Its constructor must receive the actual StagedRequestInput output and StagedWindowContextLease under their same original parent; a plain deserialized StagedFormRequest or copied BuiltNode cannot authorize it. It retains input/source/request/context, exact target key/body/action/window/generation/full canonical document hash, and its per-render source alias through receiving, preparation, body construction, publication ACK and paid retirement. The artifact callback runs through staged_context.with_context and the existing retained render hook, then supplies the prepared private IFC source to StagedBodyCursor. Final context/actor/hash checks precede tree publication. Hide, source refresh, remount, cancellation and actor retirement revoke readiness and retire dependent work before the real context source is released. This is a concrete guest/controller integration slice using existing authorities; the public mount must still refuse when no authentic donated input is present.

Next extend the actual original actor input handoff at OriginalShardEvent/GuestRuntime with a retained, finite staged transport owner. It must account for host-side transport allocation/copy and guest receiving using the same checked original checkout, preserve the original raw failure and both receipts, retain source/candidate on refusal, and close transport backing only after receiving acknowledgement. Both Wasmtime lowering and owned interpreter framing need source-specific exact census and their real allocator/receipt tests. Do not reuse a borrowed-event cold Vec clone or raise a global JSON/Pack invocation cap. A separate dedicated retained parameter/page handoff is preferable to flattening opaque bytes into ordinary event serialization; its exact API should be schema-first and chosen after tracing the owned operation input receiver, not guessed from command-page transport.

In parallel, the domain-neutral acknowledged-facade accessor is implementable against already real ordinary surfaces. It belongs next to handle-ui-intake installation and handle-scope lifecycle maps, returns only an exact acknowledged current source lease with revocation/close, and is surfaced through the rich first-party handle. It must never return the private Map or construct a facade from refresh projection. A valid accessor for ordinary surfaces does not itself enable staged request mounting. WindowActionPane can consume that lease only after a real auxiliary target/ABI owner exists; its current static action rows remain until then.

## Planned Schema And Laws

Define a closed auxiliary lifetime matrix before code: donor-denied stationarity; wrong original parent/context/window/actor/body/action/hash; incomplete producer status; late generation/status; source refresh/remount; independent sibling surfaces; publication before/after ACK; hide during pending query/notification; failed unsubscribe/close retry; canceled/expired semantic deadline with paid retirement; and instance retirement waiting for dependent reads. The guest owner tests should use StagedRequestInput plus actual context/source/controller hooks, not an independently fabricated request wallet. The renderer accessor tests must use actual nativeInstanceFixture/OwnedUiInstance patch acknowledgement; synthetic facade and BuiltNode projection tests cannot prove ownership.

Exact intended source scope after this assessment: plugin reactor receiving/staged plus a new adjacent auxiliary owner, runtime-ops surface-render/staged context, existing PendingReserved/render source hook, and IFC editor render-work adapter. Actual protocol/kernel/WIT/host/interpreter changes come only with the concrete retained transport contract. Renderer handle-scope/intake/module-loader and WindowActionPane remain root-owned until coordinated. No such infrastructure edits have been made during this assessment.
