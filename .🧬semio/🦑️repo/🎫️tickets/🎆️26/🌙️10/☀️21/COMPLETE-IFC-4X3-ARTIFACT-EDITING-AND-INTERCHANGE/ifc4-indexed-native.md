# Native Indexed Profile Curves

The native shared geometry engine now implements the existing schema-first 📜️indexed-curves.json contract through GeometryValue::as_typed and native IFC4/IFC2x3 borrowed readers. IFCINDEXEDPOLYCURVE admission is IFC4-only, requires an exact 2D point list, validates typed segment cardinality and one-based indices, and retains source-index connectivity/closure. Omitted segments close by coordinate equality. Three-point arcs retain original middle/endpoints, choose signed major/minor spans through the middle, support exact collinear polylines and refuse numerically ill-conditioned arcs. Every sampled point consumes original caller work/cancellation.

Native source tests cover CCW/CW semicircles, major arcs and exact endpoints at scales 1e-120, 1 and 1e120; exact/near collinearity; original cancellation and work limits. The existing IFC4 native neutral fixture loop also reads the root agent's new indexed profile fixtures. Five owned native source files passed the existing independent Rust grammar without syntax errors. Native compilation/execution remain gated by the repo-routed Windows native-build cache case-sensitivity access denial; these source regressions are authored and not represented as executed native tests. The root owns the executable TypeScript implementation and its independent geometry oracle.
