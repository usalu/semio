# Staged Surface Receiving Source Checkpoint

The standalone receiving foundation is source-implemented and mounted in native modules/tests. It is not connected to SurfaceVisible, the guided body remains unadvertised, and no native execution or semantic publication admission exists.

## Private Receiving

Neutral request-cases.json and token-cases.json describe closed request and exact u64 generation boundaries. StagedFormRequestCursor performs the existing bounded reservation census before scanning the fixed three root/four token fields. It checks canonical generation one byte per turn using checked u64 accumulation. It moves owned strings and the entire args subtree only after successful validation. Invalid requests retain the original source unchanged. Its caller must own the source privately and keep its root stationary.

The original reactor input in receiving/staged.rs captures ReceivingSource and uses OriginalNativeDecodeSource for the existing retained Pack parser. It adopts raw bytes under an explicit original copy quote, retains their allocation/pointer, and leaves the donor untouched on refusal or denied admission. A separately funded Box keeps the private parsed root stationary when the retained input owner moves between turns. The consumed request and secondary producer errors remain in private ownership if receipt posting refuses. Decoder, parsed source, raw bytes and original loans have explicit paid close before terminal drop.

The decoder receives a separately explicit maximum_owned_bytes policy; this is an allocation ceiling, distinct from logical JSON reservation and wire bytes. The actual mount must supply and fund that policy. No maximum is silently derived from a requested demand or a fabricated grant. Native tests author an original finite fixture caller and compare per-turn actual heap births/releases with its ledger; they have not executed.

## Existing Pack Foundation

RetainedRecordReceiving gains take_value_into(field, output, grant), an additive exact single-field Value movement. It retains the emptied Record backing for its existing controlled close. OS pack_rt exposes static borrowed wire_value_spec plus take_received_wire_value. Default codec/capture/parser behavior is unchanged.

The generic Pack map receiver appends object pairs without enforcing unique canonical keys. The new staged input therefore selects an explicit wire-only census mode: every map must use strict UTF8 byte key order. Adjacent keys compare one byte per turn before typed movement, rejecting duplicates and reversed keys without a quadratic scan. Regular census retains its previous behavior. The actual production encoder already sorts these keys. wire-map-cases.json has native and independent system-byte-comparison tests.

## Retained Context Cursor Refinement

Runtime lease capture now uses SurfaceWindowLeaseCursor in surfaces/lease.rs. It advances one immutable roster row, resident slot, or string byte per funded metadata turn. It rejects duplicate source window IDs, duplicate mounted source windows, mismatched locale/kind and source/target substitution. Source identity, target-owner address/length, locale and global context version stay pinned through the cursor. The completed SurfaceWindowLease contains exact source address, global context version, slot and binding version. Completed borrowing performs direct scalar checks and slot lookup; it no longer rescans current rosters.

The original runtime helper also retains the initiating finance/root binding, parent, recipient, cancellation identity, current deadline, monotonic epoch and clock observation. A foreign caller or changed work lifetime cannot resume the capture or borrow its view. The original request owner must retain its parent/source loan and private target string while this scalar query runs; these metadata interfaces do not mint an independent source lifetime.

The conservative context policy invalidates auxiliary leases on any host-context mutation, including sibling remount. This avoids a second synchronous roster authority while preserving exact source provenance. The ordinary surface view/default projection behavior is unchanged. The final remove() version bump landed after Windows released its mapped reader. Removing any existing slot now invalidates in-progress scans and completed source leases too. No force/delete/rename or unmapping was used.

The native context-cursor.json fixture specifies8 mutation prefixes and3 independent substitution/update modes. Its actual source tests verify per-step0heap and direct completed borrow, while existing context-lease.json checks unchanged/refresh/update/locale/close/remount/ambiguity/exhaustion behavior. These source-only tests are mounted in reactor-turn unit3 using its existing dependencies. No new dependency/build enforcement change exists. No native runtime result is inferred from rustfmt parsing.

The complete protocol, host donated request handoff, auxiliary owner close coordination, native staged producer/body builder and browser/renderer route remain unmounted. The actual host execute_turn still accepts borrowed Event slices and clones ordinary WIT input without the new original receiving handoff. Native execution and semantic publication stay refused.
