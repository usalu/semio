## Geometry and lexical boundaries

glTF import admits selected-scene or inferred-root static triangle meshes, dense FLOAT VEC3 positions, indexed unsigned scalar triangles and nonindexed triangles. It resolves aligned dense/interleaved views directly per row; authored matrices and TRS are composed without decomposing authored matrices. Unique parenthood, scene roots, cycles/depth, affine finite transforms, exact orientation and reflected winding are checked. World coordinates change from Y-up to IFC Z-up as `[x,-z,y]`; newly authored IFC projects explicitly use SI metres. The builder writes real headers, project, SI unit, context, point lists, triangulated face sets and product proxies, rather than an invented foreign graph carrier.

IFC export uses static `validation::metadata::{entity,is_subtype}` and a funded sorted positive-ID lookup, without a cold catalog or warm-cache dependency. Only actual IfcProduct subtypes are interpreted as products. A unique explicit project LENGTHUNIT/METRE SI assignment is required; prefixes scale actual coordinates. Local placement chains, representation contexts/subcontexts and WCS are evaluated. IfcBuildAxes/IfcFirstProjAxis normalizes/projections are used for authored 3D axes. Explicit Body IfcTriangulatedFaceSet geometry, including PnIndex, becomes baked FLOAT positions and unsigned triangle indices; exported min/max derive from the actual quantized FLOAT output.

Animated/skinned/morphed, sparse, selected extension/compression and external-resource inputs refuse. All nonempty extension declarations currently refuse conservatively. Unsupported IFC mapped/swept/BREP/boolean/other representations, geographic/map conversion, unsupported true north and relational-void evaluation refuse. This is not complete IFC geometry, full foreign glTF validation, lossless identity reconstruction or MVD conformance. Nongeometry glTF record schema/syntax is admitted for custody; material, texture, camera and extras semantic correctness is not asserted by the geometry API.

Natural JSON supports escaped keys, duplicate effective last values, finite integer-valued decimal/exponent properties, optional leading BOM and exact Unicode/surrogate validation. Asset version must be 2.0; minimum version absent/2.0 is accepted. The shared eight JSON vectors are consumed. BOM tolerance is a client behavior; the parent `gltf-json-research.md` records Khronos producer validator rejection separately. GLB JSON padding is actual 0x20; BIN padding is actual 0x00 with declared extent. Unknown later GLB chunks are ignored; JSON must be first, BIN immediately second when present. Natural diagnostic causes currently carry bounded messages rather than exported exact source byte offsets.

Admission limits are explicit: source/resolved/final payload 64 MiB, JSON tokens 2,000,000, object members 4096, JSON/hierarchy depth 64, string payload 1 MiB, numeric token 4096 bytes, nodes 64,000, total projected vertices 200,000 and triangles 400,000. These are local geometry API bounds, not a claim that all source-owner/compiler limits are identical. Finite orientation uses bounded fixed-stack exact arithmetic (roughly 2.4 KiB); its call admits a fixed 32768 work span. The no-underflow classification remains source-written/unexecuted here.

## Original controls, publication and retirement

All normal operations borrow the actual caller IoRunControl pair and existing snapshot decode/encode owners. Each work port checks cancellation, admits items/copy/depth through the original body wallet, performs actual bounded byte/row work, records its accepted progress, then advances original native completed work. Actual allocations use original funded vector/string frontiers. Post-work cancellation retains accepted physical prefix progress and the corresponding partial owner. No whole cold operation is relabeled as a fabricated work turn.

Natural input retains offset metadata and borrows original JSON/BIN. Selected BIN/base64 bytes go into actual resolved storage. Native Pack input retains the original schema-received RecordValue source while selected fields are built, and moves actual buffer ownership; discarded semantic data stays under that source's controlled retirement. Private cold trait conversion implementations required by the DSL exist but are not the normal owned receiving path.

The IFC builder and glTF builder keep original source plus partial output in retained owners. The GLB publisher traverses borrowed fields twice (census/output), uses fixed numeric/escape scratch, and owns one final GLB Vec. Native Pack publication uses the existing original canonical writer and its controlled scratch/final output. Results transfer only after the receiver/writer terminal path; malformed/unsupported/canceled routes return no artifact outcome. Required failure/success retirement closes on the same original recipients; no default grant or replacement native control is created. The authored tests assert these properties, but runtime custody/heap proof is still absent.
