# Retained Original Reference Reduction Checkpoint

The mounted native details worker now reduces existing native argument references from its original event, captured source and admitted pointer ranges. It no longer builds decoded pointer/detail String vectors or a normalized replacement event for this route. Native value editing receives the admitted original prefix byte extent and a validated native scalar request, avoiding formatted owner prefixes and prefix reparsing. Original input remains retained until controlled close. Central mutation, progressive inverse and original Store publication remain the existing authority.

## Source behavior

`reference.rs` retains declaration, contextual derived-attribute, defined-alias/SELECT and subtype positions. Target lookup scans original snapshot rows and actual constituents, requires one matching identity and checks the declared reference domain. Canonical positive decimal IDs are reduced one byte per turn with checked u64 arithmetic; closed native reference/unset wrappers retain exact native IDs. Optional unset, virtual `reference`, `appendReference`, direct payload, SET/UNIQUE replacement/append, ARRAY refusal and declared upper cardinality are explicit. Array/source payloads are not truncated.

The independent audit found an imported typed constructor could initially replace its original domain before membership validation. The correction retains `owner_expression`, requires one constructor item and an actual declared type, then runs retained typed membership before adopting its child. Exact defined constructors and SELECT members remain distinct; legitimate aggregate alias constructors are accepted. The rejected entity constructor inside IfcValue and accepted IfcPropertySetDefinitionSet alias are neutral regressions. See [the independent audit](native-reference-reduction-independent-audit.md).

`pointer.rs` exposes an internal native argument address and borrowed delimiter extent from its existing ordinal/range cursor. `work.rs` drives reference validation before native source copying. Direct primary scalar replacement borrows the original preimage and seeds Unset. Constituent reference edits clone the actual constituent vector through its retained cursor, move the addressed argument into the native editor, restore it and emit SetEntityComplex. No graph DTO or normalized event is substituted. Nonreference constituent edits retain their existing separate reducer route.

Original event, snapshot and addressed input identity pins are checked before progression. Cancellation, fuel and retained grant admission precede metadata/source movement. Inline metadata uses a conservative quoted envelope; bounded source-key copies add their actual length to the receipt. Original reference pins close before pointer pins and original event/snapshot owners. The implementation has authored denial/cancellation/close laws; actual physical accounting and scheduler behavior have not executed.
