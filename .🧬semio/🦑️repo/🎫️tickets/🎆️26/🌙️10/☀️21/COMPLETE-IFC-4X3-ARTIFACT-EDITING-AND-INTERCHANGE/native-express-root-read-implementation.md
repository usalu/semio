## Source and Identity

machine-root.rs adds original-owned LocalView records. Entity::View identifies storage while canonical_entity maps it to the exact original source ordinal for identity comparison and USEDIN/inverse addressing. Its fixed32-field record borrows the existing normalized Handle values. A source record holds a view-chain head; lookup checks one root/view link per original turn and materializes only an accessed original entity. There is no source population clone, second catalog, rollback, free SELF or caller-issued identity token. Local wrappers retain their original base for declared-domain and qualified-type metadata.

Scope carries an explicit root and active-memo provenance. Function and derived scopes detach lexical bindings while inheriting that root; QUERY inherits it normally. Entity/defined WHERE, derived population checks, bounds and inverse bounds establish fresh roots. A global rule's LOCAL/body/WHERE keeps its shared procedural root. Parameter/local entity handles remain aliases; aggregate indexed assignment still replaces its value-style edge chain before assigning the enclosing local field. Original source records remain read-only except their Store-owned view lookup metadata.

## Derived Values and Lifetime

Scalar memo keys now include canonical entity, rule and root. Each actual field read records the accessed entity's mutation version against every active ancestor memo, one link per turn. A cached scalar is reused only after its complete dependency chain validates; cached-child dependencies are imported into an active parent under the same continuation. Stamps are conservative per entity, so changing another field can cause extra recomputation. Active-cycle detection still checks the same root/entity/rule independently of completed-cache admission.

Completed entity/aggregate derived values are recomputed rather than reusing mutable constructor identities. This agrees with current TS derived evaluation and the fresh SDK case: mutate a retained first A.P direction to9; a later A.P computes1 while the retained first direction remains9. Old values, local field records, edges, memo records and wrappers stay in Store until close. Existing public result_scalar still exposes borrowed scalar/category results only; this does not introduce a detached arbitrary graph export or a public raw Handle API. Nested returned-reference evaluation retains its original root; consumers must not infer a context-free materialized graph from private field handles.
