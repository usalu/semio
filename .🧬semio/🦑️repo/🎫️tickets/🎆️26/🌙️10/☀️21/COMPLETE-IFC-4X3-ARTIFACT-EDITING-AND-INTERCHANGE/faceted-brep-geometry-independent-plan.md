## Small General Initial Family

Support exact basic FacetedBrep→ClosedShell→plain Face→FaceOuterBound/FaceBound→PolyLoop→finite3D CartesianPoint. Require one actual outer bound for the supported subset, use remaining bounds as actual holes and refuse unknown/missing/ambiguous roles. Reject unsupported FaceSurface/AdvancedFace/edge loops and WithVoids explicitly before publishing this item's triangles; never mesh only the outer shell while omitting voids. A valid Face without explicit outer marker may remain explicitly unsupported initially rather than guessing which bound is outer. Nonplanar/degenerate/self-intersecting/overlapping or outside holes refuse. Duplicate point references and zero-length edges retain declared distinctions; no silent point merge or source normalization.

Apply bound Orientation to each real polygon before deriving face normal. Find a robust noncollinear local plane, verify all outer/hole points against a scale-aware admitted plane tolerance, then project using deterministic dominant-axis or orthonormal basis. Reuse existing first-party ring continuation for holes/intersections/coverage, preserving oriented face normal when mapping triangles back to3D. Ring normalization must not silently reverse the entire face's semantic orientation. Per-face triangulation is not a certificate of a closed manifold solid; if the supported slice claims shell closure, add bounded shared-edge incidence/orientation checks and explicitly retain any unimplemented intersection/topology limits.

Reuse existing captured Graph/unit/placement/transform and controlled polygon/ring workflow, not a second source graph or triangulator. Every face/bound/point/coordinate/edge and triangulation output copy needs original generator/batch checkpoints including completion; central original fault identity and no partial item publication must hold. Preserve product placement and SI scale, reflected winding, private source custody and actual source pointers. Catalog owner/alias query may resolve declared slots but must not broaden unsupported physical typed/complex admission.
