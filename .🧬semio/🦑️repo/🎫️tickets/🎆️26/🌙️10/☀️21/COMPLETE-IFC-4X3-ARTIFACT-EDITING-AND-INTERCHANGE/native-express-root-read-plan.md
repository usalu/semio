## Proposed Owner and Identity Shape

One original-owned procedural root view must be shared by nested calls, QUERY bindings and derived frames. Root begins at an actual public query/rule evaluation boundary, not at every function call. Global LOCAL/body/WHERE continuation must keep its actual shared procedural scope. No ambient global current frame or caller boolean can certify provenance; frame/root identity remains tied to the existing environment pins and original initiating StepContext.

Storage and canonical identity need separate representation. A local writable view of an original source entity must retain its actual Original identity for :=:, TYPEOF ancestry and inverse/USEDIN lookup; treating it as a fresh ordinary Constructed instance is incorrect. The candidate implementation keeps a retained local field record with canonical origin plus root provenance, lazily materialized from the actual original32-field metadata only when accessed/written. Alias lookup in the same root resolves the same view. Constructor instances retain their own distinct identities. Untouched source nodes and aggregate branches stay borrowed through the admitted receiver, rather than a per-root population clone.

Use the existing original source ordinal/record metadata to locate a current-epoch view where possible; do not add a second source catalog/index. Any table needed for constructed-origin aliases must be quoted, grown and traversed through existing retained continuation patterns, with one bounded comparison/member transition per turn. A cold linear lookup or an uncharged HashMap is not justified by this plan. The exact representation must be checked against raw(), owner_at(), identity comparison, source inverse lookup, Attribute/Assign and typed/qualified wrappers before production; this document does not bless a speculative enum edit in isolation.

Derived memo needs actual root provenance as well as entity/rule. A same-root active entry still detects cycles, and same-root aliases must observe legitimate local updates. A different root must not reuse a mutated constructed derived value. Epoch stamping alone cannot solve same-root dependency invalidation; the cache test must decide whether mutable local fields require versioned memo keys or invalidation on affected local writes. The solution must preserve original source derived values and current qualified full runtime type metadata. Do not erase caches indiscriminately or reuse UNKNOWN to hide a stale result.

Returned computed views retain their actual Store fields and canonical identity through function return and the root/result read lease. Original retirement must first end/revoke borrowed result access, then retire view/memo metadata and children before receiver/source owners. A later mutable root transition must respect existing Rust borrow/owner boundaries; a scalar category or copied ID is not a new graph ownership certificate. No fully detached externally mutable graph is promised.
