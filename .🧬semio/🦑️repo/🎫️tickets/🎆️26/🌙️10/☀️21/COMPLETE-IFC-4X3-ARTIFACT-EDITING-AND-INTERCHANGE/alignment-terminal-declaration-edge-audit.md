## Declaration traps to freeze in neutral rows

1. Simple layout uses inherited allAttributes; horizontal/vertical have zero direct fields, Cant has direct RailHeadDistance. A complex partial layout stores only each declaration's own attributes. Never index a partial Horizontal/Vertical as if its full inherited args were present. Complex parameter StartTag/EndTag belong to IfcAlignmentParameterSegment; length belongs to its H/V/C subtype. RelNests inherits root fields but owns RelatingObject/RelatedObjects directly. Include actual complex target, relation, segment and design parameter in separate rows to expose positional mistakes.
2. Two constituents declaring the same required attribute are ambiguous, even if values agree. Unknown complex constituent must not be ignored to prove target domain. A malformed complex with both horizontal and vertical/cant layout kinds has ambiguous layout role; do not choose first matching class or let requested kind conceal another candidate. Full legal complex-chain validation remains outside this predicate, so resolve only unambiguous required evidence and report incomplete where not possible.
3. IfcRelNests.RelatedObjects is LIST [1:?] OF IfcObjectDefinition, not SET and not specifically AlignmentSegment in the EXPRESS declaration. Authenticate each relevant member as IfcAlignmentSegment for this selected concept. Attribute ownership is declaration-based; do not inspect some fixed args[5] or treat every inverse relationship as a list. IfcRelAggregates is not a substitute ordering source.
4. Multiple relations for the same layout have no cross-list order. Do not concatenate, sort by physical ID, pick the longest, or select the relation containing zero. Duplicate terminal IDs remain exact source references; duplicate graph entity IDs cause ambiguous lookup. An entity reference occurring in some other field of a relation does not make it a nesting owner.

## Numeric reader matrix

Declared chain is IfcNonNegativeLengthMeasure→IfcLengthMeasure→REAL. Support raw numeric representation and valid single-item wrappers at the exact named alias encountered; e.g outer NonNegative then Length then real, or raw number at declared measure. Do not infer unrelated IfcPositiveLengthMeasure/IfcParameterValue/IfcLabel wrapper from coincident scalar payload. Reject multiple items, typed entity tags, strings, unset/derived, booleans and aggregate scalars as unresolved shape. Case handling should match existing canonical IFC identifier policy, not locale casing.

Zero means arithmetic exact zero, including signedzero: no epsilon, decimal rounding, truthiness or bitwise-only check. Tiny positive/subnormal and huge finite values are nonzero. NaN and infinities are incomplete/resource/source refusal per frozen endpoint policy, never pass because a comparison fell through. Do not convert exact integer words to binary64 merely to compare zero; check exact integer zero first. Known finite negative nonzero fails the explicit zero predicate; leave underlying NotNegative schema conformance not-evaluated unless a separate domain-admission policy is deliberately documented. This keeps concept failure distinct from falsely claiming full alias-WHERE validation.

## Result/ordering traps

Explicit false→N/A before graph resolution; null→incomplete. Applicable missing/ambiguous target/list/design refs→incomplete. Business terminal is final RelatedObjects element only; zero earlier/nonzero last fails. If an earlier member is unresolved while terminal is known nonzero, retain incomplete precedence and diagnostic evidence rather than hiding uncertainty under fail. Empty list incomplete is a local predicate policy, not claimed new EXPRESS rule. Preserve caller target order and actual relationship/member pointers; deterministic output cannot depend on hash-map insertion order or discovered entity ID order.

Geometry is a separate unevaluated clause. A passed business row must not label the entire released child passed or full view compliant. Body Tessellation precedent marks schema/view not-evaluated; follow it. Explicit cancellation must throw io.cancelled at initial/interior/completion checkpoints and never publish partial rows as complete.
