# SET Child State And Quote Plan

The planned child owner reconstructs only the closed aggregate of ordinary raw reference records. This is a continuation of the selected constructor's original borrowed child, not a second generic model-copy authority. Root/source identity, child array pointer and length, original caller, and close state are checked before each mutation or debit. Every `demands` call only borrows these identities and the next original raw string length.

The retained Parts roster holds the output aggregate object backing, aggregate member backing, next member object backing, aggregate key strings, next member key/tag/raw strings, and completed output. No new String or Vec survives in an unretained local across a fallible receipt. The child owner and Parts descriptors belong to the parent typed copier's close ladder from birth.
