## Closed Semantic Contract

Export BIM Text as IfcText, finite Real as IfcReal, canonical signed32-bit Integer as exact IfcInteger and Boolean as IfcBoolean. Preserve arbitrary UTF8/empty text and Real signed zero through the existing exact binary64 codec. Physical units are unset. Imported IfcText maps to Text; IfcLabel/IfcIdentifier may map to Text only with an explicit lost-nominal-string-type warning. Imported finite IfcReal, IfcInteger within the actual BIM signed32-bit domain and IfcBoolean T/F map exactly. LOGICAL, unknown/unset nominal values, extra typed items, measures/unit-bearing values and unsupported property representations refuse the selected projection. Never round bigint or coerce UNKNOWN to false. Authored export Length/Area/Volume/Angle remain unsupported until their proper unit contract exists.

The initial plan assumed the TypeScript number representation implied a safe-integer BIM domain. Reading the actual canonical BIM JSON schema and Rust PropertyValue.Integer showed minimum -2147483648/maximum2147483647 and i32. The neutral contract was corrected before freeze, with explicit assigned out-of-domain public red tests preceding receiver guards. Original huge-integer physical observations remain separate; this BIM projection bound does not narrow IFC INTEGER.

Property sets/properties need nonempty exact names, no duplicate distinct same-name sets/properties, and nonempty representable containers. Empty names and empty authored containers refuse explicitly. Shared source set identity can project to each occurrence's own values, with an explicit identity-projection diagnostic; re-export need not recreate a shared IFC entity. Repeated assignment of the same set to one occurrence is deduplicated by actual source identity. Reserved semio_BimStorey and semio_BimProject names remain exclusively owned conventions: authored generic collisions refuse, and import skips only the proper existing holder's convention after its dedicated validation. The wrong-holder reserved name refuses.

Dangling, unsupported or ambiguous authored holder keys refuse rather than omit values. Import resolves exact source attribute owners through the existing prepared relation index and graph.indexed locators: RelDefinesByProperties.RelatingPropertyDefinition, IfcRoot.Name, PropertySet.HasProperties, IfcProperty.Name and SingleValue.NominalValue/Unit. Nonunique/unknown/lateunknown ownership remains refusal. No positional fallback or shadow entity index. Type assignments are queried separately and reported as unprojected inheritance; they never become occurrence-authored values. Selected quantity/predefined property definitions require an explicit omission diagnostic or refusal, not invented scalar properties.
