# Browser Source-Owned Staged Form Plan

Root owns canonical browser shell/manifest TS/wire schema integration; High owns native per-render source work/receiver/census and IFC producer, and the other High owns generic referenced enumeration/index/provider. Low audits actual interfaces and race/authority constraints. Shared contracts live in manifest arg-schema/staging; no direct IFC graph mutation occurs while staging. Native guided advertisement remains refused until the actual ViewContext receiving/clone frontier is guarded under original controls.

A consumed auxiliary form surface must have its own surface/cache identity and an explicit existing real contextWindowId. It is never another windowInstances roster entry and never overwrites the real viewport key/body. Extend closed refresh request/response contracts to carry form targets through the existing SurfaceVisible, original settlement, owned UiInstanceSurface, projection, hash cache and retirement routes. Each form target carries the exact finite staged request; each derived ViewContext is admitted before wire encoding, with the same declared UTF8/node/depth caps and explicit supported locale. Only expanded actions declaring source staging request a form surface. Static actions retain their existing general form behavior.

The action pane consumes the actual ordinary Input/Select/Button tree, not another disconnected field renderer. The small reserved framework.stagedFormStatus extension carries closed token/readiness and bounded explicitly addressed diagnostics. Missing/stale/faulted/cancelled/nonready status disables Execute even when static required arguments are present. Execute remains exactly one action descriptor containing current effective args; all input activity updates only window-local staging.

Staging events must be intercepted as original UiIntent before uiIntentToActionDescriptor discards origin and merges raw Map over fixed args. Verify current consumed surface/revision/node/nodeKey/trigger/enabled state and recover the authored resident binding. Never trust token/path/fixed values from merged intent args. The closed source-owned binding has token/layout and at most8 fixed edits or one text/choice input slot; choices are at most32 distinct string keys with exact source-owned values. Resolve raw string input only against that authored marker/options, then use the shared reducer. Readonly fields emit no editable binding. This avoids serializing full inventories or fabricating Response.fields.

Keep last verified resident layout proof separate from latest request readiness. Text edits preserving layout must continue while newer validation is pending; replace-layout/page/reset/revision/action/window/document changes retire old proof immediately. Latest args generation/revision alone can enable Execute. Inspect/retain existing input draft behavior or add an explicit local exact-value overlay so asynchronous older form trees cannot reset rapid typing. Preserve decimal i64/u64/Binary64 text without Number coercion; source choice payloads stay exact.

Tests precede implementation: closed language-neutral auxiliary target and exact token/state fixtures; actual source-context binding for two real windows/focus mismatch without fake roster or viewport collision; original UiIntent proof before descriptor flattening; rapid text, optional/list/table changes, pages, late generations/revisions/actions/document and source rejection; exactly-one Execute/no graph edit; actual owned retained projection/ordinary controls where environment supports import/render, with explicit blocked boundaries otherwise. Reuse existing registry/unit/renderer fixtures and third-party schema/diff checks. No synthetic actor/native receipt or unexecuted UI claim.
