csg-primitives-source-research.py uses a test-only owned interface around actual IfcOpenShell0.9.0.post1 and saves unchanged pinned primary pages, current ADD2 declarations and authored standalone physical files under generated/csg-primitives. The first run stopped after an empty Cylinder mesh reached a min/max calculation; the corrected adapter retains that empty result explicitly and finishes all four observations. Initial/final logs are preserved. These are representation-item files, not complete product/project exchange models; none is new production support.

All four have required IfcCsgPrimitive3D.Position. Current dimensions are Pyramid.XLength/YLength/Height, Cylinder.Height/Radius, Cone.Height/BottomRadius and Sphere.Radius, all positive length measures. The primary page hashes and exact metadata are in generated/csg-primitives/oracle.json. Every constructed standalone graph receives zero formal EXPRESS diagnostics.
