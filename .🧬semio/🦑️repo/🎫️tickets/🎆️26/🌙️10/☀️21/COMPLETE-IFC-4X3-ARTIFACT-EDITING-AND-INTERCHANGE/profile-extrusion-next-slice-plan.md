## Released declaration constraints

Pinned local primary IFC4X3_ADD2.exp:4069–4100: arbitrary closed OuterCurve is IfcCurve, Dim2, excludes IfcLine/IfcOffsetCurve2D; with-voids adds nonempty SET of inner curves, requires AREA, each Dim2 and excludes IfcLine. CircleProfile4905 has positive-length Radius and inherited optional2D Position. Polyline8642 has LIST[2:?] of CartesianPoints with SameDim; closure is not the generic IfcPolyline declaration itself. Extrusion6588 requires positive Depth and direction with nonzero dot against profile Z. Schema checks do not themselves supply polygon triangulation or validate every self-intersection/containment case. Proposed supported projection should explicitly admit simple closed finite planar rings and refuse degeneracy, open/mixed-dimensional/self-intersecting/unsupported curves before publishing a mesh.

## Existing implementation interfaces and control limits

Framework geometry/triangulation/🦀️.rs exports triangulate(outer:&[Point],holes:&[Vec<Point]])→Triangulation{vertices,triangles}. It implements hole bridging plus ear clipping, normalizes ring orientation, and silently ignores holes with fewer than3 vertices. It clones whole point/ring arrays, sorts holes and performs synchronous scans; no original-control continuation. It is a useful first-party algorithm/reference interface, not a directly admissible cooperative TS API and not a malformed-input validator. No production TS counterpart was found in that framework module; TS Earcut imports found are third-party test oracles only. FEM surface module here contains native schema/tests rather than a reusable TS runtime triangulator.

Mesh document/🔺️polygon-triangulation/🦀️.rs also exposes triangulate_polygon and has an indexed-with-holes helper; it is an existing Rust mesh implementation, not permission to add a runtime external library. Any shared TS/Rust polygon work should live in the domain-neutral geometry taxonomy and expose bounded continuations for input copying, area/orientation, intersection comparisons, ear tests/removal and triangle emission. A source-sized nested intersection/ear scan must yield within both loops, not only once per ring. Preserve original private graph/control and existing profile/solid/product/SI frame composition.
