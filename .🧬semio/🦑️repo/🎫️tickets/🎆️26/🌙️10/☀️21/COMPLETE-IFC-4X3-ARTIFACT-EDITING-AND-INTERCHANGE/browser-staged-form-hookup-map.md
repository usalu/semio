## Minimal schema-owned extension

The current target shape cannot represent a separate consumed action-form surface with the original window context. Reusing the actual window key with bodyKey=framework.action.form replaces/collides with its viewport surface and window cache. Inventing a form key in windowInstances just to satisfy windowHostContextBindings recreates the B56 unused-window alias error documented at surface-refresh lines 78–87. Treating it as an ordinary panel silently loses the real render windowId.

Add an explicit auxiliary window-bound target contract separating its consumed surface key from its existing real context windowId. A generic target contextWindowId field plus a distinct auxiliary/form target collection is one narrow design; it is a proposed schema change, not an existing API. Validate real roster membership with windowViewContext, reject unavailable contexts, fix bodyKey to the declared reserved framework.action.form for form targets, and route through the existing SurfaceVisible/owned intake/settlement pipeline. The distinct form key is a consumed sub-surface, never a fake window roster entry or bare :window alias. Mirror shared TS/Rust/schema/test contracts and include auxiliary targets in requested-surface settlement/projection, hash caching, dirty refresh and retirement.

Request only expanded actions that declare source-owned staging, using the real window and active action. Carry a finite exact staged request through the source-owned ViewModel/staged-form field, not arbitrary panelJson or hidden extensionInputJson. At this checkpoint PluginViewState TS has no stagedForm field; shared context parsing/wire capacity/admission must be updated together rather than adding an unvalidated spread property.

WindowActionPane needs a form-tree/status input keyed by current actor/document/window/action/generation/revision and must consume the actual returned surface. Ordinary controls carry bounded pages; only the small reserved framework.stagedFormStatus extension carries token/ready/diagnostics. Do not serialize the entire form schema or all choices into the extension. Validate closed status and exact token before enabling Execute. Missing, stale, faulted, cancelled or nonready status disables Execute even when static required args appear populated.

Intercept only the declared staged-form edit intents/events and apply the existing generic ephemeral reducer; do not dispatch IFC graph commands on field changes. Refresh the current form generation after edits, retaining staged args across pages and reconciling exact choices/constants. Execute remains one ActionDescriptor with the merged current command. Action change/Reset/window closure/document switch invalidates old status, cancels/retire old request/surface and prevents late completion from enabling another action. Preserve the existing generic static action pane for actions without source-owned staging.

## Required actual tests

- Two real windows with different actions/args: auxiliary SurfaceVisible carries each exact real windowId/kind/utility; no additional roster entry, no bare window alias, viewport identity/body unchanged.
- Only expanded eligible forms requested; each requested surface is actually consumed by its pane. Hash-unchanged response preserves tree identity; changed staging or revision forces refreshed readiness.
- Real retained patch→owned projection→ordinary interpreted control edits→ephemeral reducer→one Execute descriptor. No graph mutation on edit, Reset discards dependent staging, exact i64/Binary64 strings retained.
- Late old generation/action/window/document response/status cannot enable Execute; absent/fault/cancel/nonready disables it; actor instance retirement closes the form surface and outstanding reads.
- Window focus differs from target: context uses windowViewContext target, not focusedWindowId or panelViewContext. Preserve tree-window paging/focus, keyboard/label/error association and explicit English/German labels.
- Extend existing window-host-context/window-action-panel/surface-refresh law fixtures rather than invent a detached snapshot test as mounting proof.

This map is based on actual read source, not runtime browser interaction. Native compile/runtime gates remain false.
