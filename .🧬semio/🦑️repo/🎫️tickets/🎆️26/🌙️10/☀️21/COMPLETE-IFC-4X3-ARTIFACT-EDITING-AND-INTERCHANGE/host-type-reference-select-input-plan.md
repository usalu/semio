# Entity-Reference SELECT Follow-On Plan

The current scalar SELECT57 checkpoint is frozen for review. The adjacent read-only census in `type-reference-select-census.ts` identifies thirty-two required direct attribute occurrences across twenty-four SELECT declarations whose complete direct member roster contains only entities and is within the existing thirty-two-member bound. This agrees with, and narrows operationally, the earlier flattened reference-only count. No production change is authorized by this census alone.

The appropriate follow-on uses the existing Reference input when every member of the complete SELECT is an entity. The selected member is determined by the actual original source entity and its released subtype/component membership; IFC entity references do not need a fabricated typedValue wrapper or a separate caller-authored class tag. Mixed entity/scalar SELECTs, nested SELECTs and aggregates remain refused. Metadata classification must inspect every member before returning Reference, with no filtering or declaration duplication.

Concrete neutral models will exercise IfcMeasureWithUnit.UnitComponent (IfcUnit: IfcDerivedUnit, IfcMonetaryUnit, IfcNamedUnit) and IfcActor.TheActor (IfcActorSelect: IfcOrganization, IfcPerson, IfcPersonAndOrganization). The first source is rootless with two own/full slots; the second has one own and six full slots and therefore requires the actual IfcObject, IfcObjectDefinition and IfcRoot constituents. The pre-existing exact GlobalId and every inherited/sibling value remain original source data. Test targets include a valid IfcSIUnit subtype of IfcNamedUnit, a MonetaryUnit, all three actor alternatives, a known nonmember CartesianPoint, a missing target and incomplete/overflow reference drafts. Required target/source IDs are fixture inputs, never generated defaults.

The wire payload remains the existing exact decimal Reference carrier. Missing and partial references remain editable with no selected target or admitted default. Complete references must traverse the original strict receiver, private type witness, full candidate structural domains and existing issued same-name rules. Original source identity/revision/caller pins, source-index/query ownership, progress, cancellation, central sparse mutations, inverse and typed paid close remain unchanged. This adds no source scan in render and no new source/SELF authority.

Schema-first source cases, actual source-bound form-to-binding-to-diff/inverse tests and a separate physical IfcOpenShell membership oracle must precede production. New tests stay unregistered until green and independently reviewed. The already frozen scalar SELECT57 source and all native runtime/type/physical/capability flags stay unchanged during this planning work.
