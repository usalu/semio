## Standalone Pack Framing Derivation

The checked wire reservation is JSON UTF8 reservation + 32 × value/container nodes + 32 outer bytes, initially 3145760 bytes. This covers the actual production codec in framework/packs, not a JSON-size equivalence. Every dynamic container uses one tag and a u64 count varint (at most 11 bytes); each inline object key adds one tag and a length varint (at most 11 bytes), assigned to its member value node. Each string leaf is either inline (tag + length varint) or a symbol reference (tag + reference varint). Its unique symbol-table length prefix adds at most 10 bytes; the sum of all unique symbol UTF8 bytes and non-interned inline string UTF8 bytes is bounded by the reservation's leaf-string UTF8 bytes. Object key UTF8 bytes are also counted there. Thus a string member requires at most 11 key-framing + 11 reference-framing + 10 symbol-prefix bytes = 32 extra bytes; container members need at most 22. Numeric tags/payloads (at most 11 bytes) fit their existing 32-byte numeric reservation. Symbol count plus one field count/id/Value tag needs at most 32 outer bytes. A dynamic node has at most one member key; no separate uncounted member inventory exists.

The production Pack comparison tests include unique short symbols and 16000 object members. This wire bound is not a heap-capacity receipt, a decoder-work bound, a scheduler proof or a promise that malformed arbitrary Pack forms are admissible. Native Pack limits, original allocation quotes, source lifetime and controlled retirement remain separate obligations.
