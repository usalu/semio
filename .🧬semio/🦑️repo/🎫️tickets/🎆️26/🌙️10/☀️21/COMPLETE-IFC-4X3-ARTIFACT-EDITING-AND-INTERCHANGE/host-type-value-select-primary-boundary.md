# IfcValue Primary Source Boundary

The pinned repository catalog records released IFC4X3_ADD2 EXPRESS bytes at SHA256 f67c8762b13a099c28082061e6f16b9ef1284ceec34069792afc702725675860. Its source link is [the released EXPRESS artifact](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/HTML/IFC4X3_ADD2.exp), with its explicit mirror recorded in the actual catalog. Local census and independent IfcOpenShell0.9 released metadata both match109 unique leaves and the same ancestry. This pinned artifact remains the implementation authority.

The requested [IfcValue documentation URL](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcValue.htm) currently redirects to a DEV page identifying itself as a working draft build20261012. The analogous [CompoundPlaneAngleMeasure documentation URL](https://ifc43-docs.standards.buildingsmart.org/IFC/RELEASE/IFC4x3/HTML/lexical/IfcCompoundPlaneAngleMeasure.htm) does the same. They corroborate the nested SELECT and integer-list/sign concepts, but their current DEV bytes must not silently replace the released pinned asset or certify released leaf counts. No catalog/source change was made from those pages.

The [ISO10303-21 edition3 source](https://www.steptools.com/stds/step/IS_final_p21e3.html) is the separate exchange-token authority. Existing parent verification of12.1.1.7 distinguishes NUMBER's graph integer semantic arm from its required REAL exchange token. Raw SDK acceptance of NUMBER(integer) remains an explicit parser observation, never a token-conformance certificate. This feature does not edit the serializer or coerce a numeric source to fit an external constructor.

The public input contract deliberately selects exact non-SELECT leaf constructor names and never offers the intermediate SELECT branch names as values. That is the planned closed control/receiver policy; the current red refusal test does not claim to be an exhaustive independent Part21 grammar proof for every possible typed parameter nesting. General syntax import remains separate from this authored type-input control contract.
