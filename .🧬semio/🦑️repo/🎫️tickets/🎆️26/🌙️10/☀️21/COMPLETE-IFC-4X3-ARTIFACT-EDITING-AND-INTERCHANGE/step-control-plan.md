# Owned Cooperative STEP Exchange

The TypeScript STEP writer currently reads caller-owned arrays after yielding and formats whole nested arguments/text synchronously. Parsing has large uninterruptible trivia, Unicode-block and binary scans. Replace those active paths with owned central graph capture, actual bounded scanner/encoder checkpoints and a chunked output interface. Keep the explicit scalar formatter as a pure reference utility, with production document export using the new cursor.

Align the mandatory header order and field types with the written native codec. ISO 10303-21 clauses 8.1 and 8.2.3, as [published by STEP Tools](https://steptools.com/stds/step/IS_final_p21e3.html), require ordered FILE_DESCRIPTION/FILE_NAME/FILE_SCHEMA and nonempty author and organization lists. This structural check does not establish timestamp validity or complete physical encoding conformance. Repair invalid handcrafted test inputs manually; never rewrite original official fixtures.

Add neutral cases for header admission, long comment/whitespace/Unicode/binary processing, one-entity aggregate output, source-alias isolation after capture and bounded stream chunks. Use official source regressions and IfcOpenShell to compare the exact authored graph/header output. Do not modify the native receiving/codec work owned by the interchange worker or bypass build ingress.
