# Original Domain Metadata Admission Checkpoint

Native DomainWork now admits its inline declaration metadata under the initiating StepContext before transition. It binds actual event, snapshot, prepared mutation slice pointer/length, admitted PathAdmission and static catalog identity. Original cancellation and owner mismatch precede admission/movement. Work forwards the demand and charges its completion metadata separately. Original close clears the binding and active metadata before address/event/source/mutation retirement; the remaining declaration/equality/membership frame data contains only inline counters, indices and static catalog references and retires with the original Work frame. It holds no source value/name reference.

The metadata route no longer allocates a draft path Vec, per-turn uppercase entity String or formatted original argument/complex prefix. Bounded 256-byte ASCII normalization borrows already canonical names or uses stack scratch. Selected argument suffixes borrow the actual admitted PathAdmission prefix and require matching source ordinal/constituent/argument. Original source and event addressing is not re-encoded or normalized into another event.

Inspection found that the actual domain cursor's generic membership helper entered allocating catalog subtype BTreeSet construction. The mounted cursor now owns `catalog/domain/membership.rs`: fixed metadata resumes exact named declaration matching, SELECT member traversal and entity subtype ancestry one edge/parent per call. Exact defined aliases remain admissible before primitive/aggregate descent, including IfcPropertySetDefinitionSet selected through IfcPropertySetDefinitionSelect. Entity constructors excluded from IfcValue remain excluded. The prior membership depth convention (root 0 through 128) and finite ancestry refusal are retained. There is no lazy index, heap set, graph DTO or recursion hidden inside a membership turn.

The current copy admission is an explicit conservative envelope: four inline DomainWork sizes plus bounded name/path scratch. It covers cursor/frame/default and bounded path copying but is not a minimal measured byte total. It may reserve substantially more than a particular scalar transition needs. Successful fixed metadata turns request no capacity/release; ordinary failed domain validation still uses the existing error transport and is not claimed to have allocation-free error construction. Genuine native heap/receipt/wallet execution is required to validate the envelope and actual host loans. No runtime or performance total is fabricated.
