# IFC4 Standards Scope

Official IFC examples page points implementers to the buildingSMART sample/test repository: https://technical.buildingsmart.org/standards/ifc/ifc-examples/. Official IFC4 fixtures added in this work retain their original bytes with pinned upstream revision, checksums and CC-BY provenance (see ifc4-conformance.md).

The normative computer-interpretable EXPRESS listing is published in Annex A: https://standards.buildingsmart.org/IFC/RELEASE/IFC4/FINAL/HTML/annex/annex-a.htm. Current official IFC schema release table: https://technical.buildingsmart.org/standards/ifc/ifc-schema-specifications/. These distinguish IFC4 ADD2 TC1 (4.0.2.1) from IFC4x3, which remains another remote agent scope.

The existing generic STEP graph and official-example roundtrips do not establish full EXPRESS entity/attribute/type/select/WHERE/UNIQUE or MVD conformance. Such claims require a normative catalog, semantic rule implementation and comprehensive conformance suite. This work must report supported syntax, structural validation and tested geometry separately from full standards certification.
