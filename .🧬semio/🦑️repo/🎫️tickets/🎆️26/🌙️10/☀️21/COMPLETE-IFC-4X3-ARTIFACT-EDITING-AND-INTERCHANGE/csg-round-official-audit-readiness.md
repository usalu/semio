## Ready independent producer interface

Existing csg-round-three-oracle.ts is test-owned and returns only arrays/scalars. It measures actual Three182 CylinderGeometry/cone points, triangles, bounds and volume across11 supported frozen rows. It does not require external types in production. Frozen JSON expected fields supply independent analytic segment/bounds/polygon-volume expectations. Symbolic known-parametric seam topology is explicitly scoped and is not a general exact-welding or arbitrary-solid validator.

Existing gltf-normal-actual-oracle.ts provides a proven pattern for actual public ifc4x3ToGltf→writeIfcGltfGlb bytes, cached Khronos validator2.0.0-dev.3.10 and Three GLTFLoader through an owned observer. The cached validator is generated/gltfval/package/index.js. No installation or build-policy change is needed. A new circular audit input should consume real root fixture snapshots, retain source snapshots before/after, emit actual GLBs under generated/csg-round-actual, and compare loaded bounds/absolute and signed volume against the independent Three/analytic observations. It must tolerate a different valid cap triangulation and vertex roster. It should validate triangle count/vertex count against the producer's chosen reservation contract separately, not claim matching Three's centre-fan count.

Each produced GLB needs actual Khronos errors/warnings/raw messages and hash; a valid GLB alone does not establish correct IFC source interpretation. Readback float32 geometry must be compared with float32-aware tolerances. Reflected source frames require outward signed volume after one central orientation correction. Exact STEP source and MVD metadata claims remain separate from mesh validation.

The later frozen producer review will replay the new public red/green tests, previous Circle/world-basis controls and selected mapping/CSG Block baselines, with before/after owned+reference hash observations. It will include private exact grants and cumulative distinct-product grants, per-phase caller failures/cancellation, required source roles, world collapse and the combined negativeZ/profile-offset/reflection regression. No runtime/native/full-view certificate follows. No production source was imported or edited for this census.
