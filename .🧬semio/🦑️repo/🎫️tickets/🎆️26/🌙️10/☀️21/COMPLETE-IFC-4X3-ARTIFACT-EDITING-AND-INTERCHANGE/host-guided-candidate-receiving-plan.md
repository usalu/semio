# Guided Candidate Receiving Plan

The source-loan seam supplies the actual original source projection needed by `ConstituentRoster`. Native form readiness must advance the same closed receiving, remap, strict declaration admission and issued local-rule machinery as the eventual central edit; a placeholder `DomainCursor` or arbitrary SELF is insufficient.

## Retained Ownership

A private `GuidedCandidate<C>` temporarily takes the exact donated `StagedFormRequest` into `RetainedCloneSource<StagedFormRequest>`. Its existing DslValue clone cursor projects only the request's args. The completed cloned args move into a retained slot before posting; the cursor then closes its projection leases. Only after those close does `take_authority` return the exact original request to its original slot. The original source holder remains available to context checks throughout this temporary donation. No whole snapshot/entity clone or text serialization occurs.

The closed args object has only `path` and `value`. Move those exact original-owned cloned values into `SnapshotEditEvent::SetValue` using bounded descriptor moves; retain original key strings and empty array/object scaffolds for paid retirement. Do not use a local owning Option across a fallible receipt. Admit the actual event path through `PathAdmission`, then run the existing `ConstituentRoster` using the host-backed source lease and existing parts/value clone cursors. Its exact private `RetainedTypeAdmission` drives `DomainWork`; `IfcTypeCandidate::new` then supplies the existing same-name complete-candidate local-rule owner. All contexts retain the initiating caller, snapshot identity, full revision, request/source and profile pins.

The helper prepares mutations privately only to determine readiness; it does not emit them or mint a publication certificate. Successful form submission still takes the existing central mutation/diff/inverse route. No dummy name mutation, new policy boolean or inferred candidate is introduced.

## Readiness and Failure

Blank, partial, unsupported or locally invalid user values remain editable and ready=false. The original request and exact raw UTF-8 drafts are restored before any body construction. Actual cancellation, receipt, allocation, original-context or stale source failures propagate with exact `OriginalTurnFailure` ownership; semantic diagnostics may be retained as editable refusal only when they contain no transport/context refusal. Unknown local rules never imply ready=true. Differing type/remap support and full complex legality remain the existing strict central scope, not a new full-schema claim.

Retirement is rules/machine/receiver/overlay first, then declaration/address/roster cursors, retained clone cursors, pending candidate values/events/scaffolds, request-source leases and host source projection. Every action must publish its real child demand plus its own metadata before mutation; a delegated child item must not be charged a second synthetic item. A born owner is always retained before posting can fail.

## Test-First Laws

Consume the existing REAL/NUMBER/BINARY neutral models and their independently generated IfcOpenShell outputs. Authored laws must exercise valid exact words, preserved inherited primitive/alias failures, missing/ambiguous complex owner, local Unknown, actual source substitution, original request handback including raw UTF-8 sibling drafts, every denied physical axis, every cancellation prefix and paid child-before-owner closure. The request's path/value and raw strings must match before/after preparation, and central output/inverse must remain the already independently tested output. Controller body laws continue to test actual donated request→private prepared source→existing domain-neutral body controls.

All native laws remain unexecuted until authentic compiler ingress is available; source/syntax review cannot prove runtime allocation, type checking, receipt or retirement sufficiency.
