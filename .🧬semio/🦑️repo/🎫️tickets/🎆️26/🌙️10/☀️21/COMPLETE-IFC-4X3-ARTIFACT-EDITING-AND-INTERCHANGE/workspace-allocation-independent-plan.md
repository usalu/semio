## Narrow Owner API

Capture one finite nonnegative safe-integer maxValues once; zero should permit only empty logical residency. Keep private live/peak/closed/failed-presence/value and Map lease identity. Expose immutable lease value observations, not mutable Map entries or public caller-spent totals. reserve(n), grow(lease,n), split(lease,n), merge(a,b), release(lease) and close are permission transitions only; caller operands never acquire validity/source authority merely by reserving their count. Rename grow's argument explicitly additionalValues versus targetValues to avoid accidental replacement/refund. A decrement/shrink operation, if needed for actual popped buffers, must be explicit and stationarity-tested.

Validate all integer arithmetic/ownership/lifecycle before mutation. Use n<=limit-live rather than potentially overflowing live+n. Split/merge must preserve live exactly, consume/update exact old identities atomically, and reject same-lease merge, stale/cross-owner handles and combined-count overflow. A failed grow must retain the old lease/live/peak unchanged. Valid release of previously entered leases remains allowed after failure, while unknown/stale release must not mask the original primary. close releases permission and makes all handles stale, preserves historical peak/spend observations, and never reopens the owner or replenishes the session work counter.

A zero-value lease still creates Map metadata: either avoid retaining it or document its independent handle/work/frame bound. This mesh-values ceiling cannot bound an arbitrary number of zero handles. Map.clear is logical invalidation, not proof of synchronous physical reclamation. Many per-mesh leases should have cooperative cleanup one lease/frame per original turn; prefer a small number of phase-buffer leases that can be invalidated without scanning every scalar. Cleanup after cancellation cannot rely on new successful ordinary-work admission or invoke progress callbacks that mask the primary; its bounded retirement contract must be explicit.

## Counted Storage Contract

Choose an exact count convention before tests. Recommended conservative mesh-buffer logical entries are3per retained coordinate triple and1per retained scalar index, for every simultaneously retained buffer occurrence. This includes intermediate remap/index/ring buffers if they store mesh indices, even though they are not final triangles. Coordinate objects shared by two arrays can either be conservatively counted twice or have explicit backing-lease sharing; do not silently count references as free while claiming all logical mesh carriers. Fixed-size arithmetic vectors/planes may be separately bounded fixed scratch. BSP polygon/plane/frame metadata and spatial maps need their stated work/polygon/depth bounds and must not be mislabeled fully covered by mesh values.

JS Array.length is not physical backing capacity. Reservation before push/new row covers logical entries, not engine over-allocation, hash bucket memory, string keys, GC timing or native bytes. Do not claim a physical heap ceiling. Typed-array future exact allocation would require reserve before its whole birth; current dynamic arrays need reserve-before-push plus explicit release when retained references actually disappear.

## Integration Shape

Pass one private workspace through the already shared session/kernel, alongside Control; never accept a caller numeric claimed count as a completed mesh lease. Internal phase-buffer owners pair exact arrays with leases, use try/finally for every temporary, and transfer the actual final lease out on success. The public generic mesh API can reserve its borrowed inputs for the operation lifetime without cloning; the future IFC adapter must separately retain child lease handles across sibling evaluation and transfer them into/out of kernel calls without double-minting capacity. A workspace handle is permission only, so declaration/source/query and geometric admission remain mandatory.

Do not catch a workspace refusal and retry with standalone kernel/default limits or silently drop a child/normal. First failure belongs to the original session, cleanup preserves it, and publication occurs only after both complete geometry and reservation transfer. Current session.close refuses active work, so the adapter must return the entered cursor before close; workspace cleanup must follow the same owner order without resetting failed work.
