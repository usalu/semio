# IFC Edit Publication and Reference Guards

The full user goal and shared ticket remain active. This report records a completed guard slice and its verification boundary.

## Actual Row Authority

The current SnapshotEditingEditor capacity/work hooks stay on the existing retained command factory and mounted completion route. IFC4/IFC4x3 derive a bounded capacity from the selected catalog's maximum explicit inherited arity: two times that arity plus three point-invertible items. The custom work now checks the actual emitted forward rows plus Mutation::inverse_rows declarations against that capacity before Complete. Empty no-op emission remains allowed. IFC4 currently declares 45 primitive items / 90 rows.

TypeScript now has the same catalog capacity and exhaustive primitive inverse-row metadata. Its type-switch planner refuses an oversized batch. A new actual source regression first showed that shrinking a malformed 1,000-argument entity returned a batch beyond the native declaration; it now refuses. The neutral publication fixture checks exact row boundaries, with independent existing AJV maxItems acceptance over the same point-invertible primitive arrays. Existing four mutation groups pass after asserting all ten valid primitive inverses match their declarations; independent fast-json-patch results and exact undo still agree.

## Retained Ownership and Original Control

Original cancellation/fuel/deadline remains the only initiating StepContext. Pending mutations remain owned by the custom work after argument ownership transfers. Copy and planning stages skip them on a later turn, and completed publication prevalidation is not repeated after a final yield. Final cancellation/yield guards precede Complete. All pending/displaced/source owners use the existing retained close path.

Native real-work regressions use one existing OriginalWorkFixture through source/copy/final/cancel/close. They cover a real multi-primitive type change and central inverse restoration, zero/final fuel, cancellation, malformed tuple capacity refusal, and a pending single-argument edit whose source value has already moved. These tests are authored and grammar-checked, not executed. Mounted Store publication/history/undo still needs authentic native execution.

The shared per-item byte precheck computes inverses against the original snapshot. It is not the sequential batch undo authority. The existing mounted Store preparation independently measures the actual gesture, evolves sequential inverse authority, and enforces final footprint/bytes; no parallel publisher was added.

## Reference Admission

Recognized decimal reference fields reject numeric input instead of falling through to generic scalar handling. Whole Reference/Unset values at declared native reference slots normalize through the same virtual decimal reference route. Existing target, optionality, positive-u64 and admitted constituent type checks therefore apply to both representations. The whole-value path is explicitly an ordinal value path, distinct from virtual fields.

Replacing an existing member now checks its enclosing SET/UNIQUE direct-reference collection, excluding the current slot. Self replacement remains valid; replacing it with another existing member refuses; replacing it with a new admitted target produces the existing stable-id mutation and exact inverse. Independent AJV uniqueItems agrees with the neutral duplicate/distinct vectors. TypeScript reference parsing also rejects JavaScript numeric coercion.

The shared IFC4/IFC4x3 Details suite passes 13 actual groups with zero strict TypeScript diagnostics. Additional native reference tests cover decimal fields and whole wrappers, duplicate/self/new targets, numeric payloads, zero/missing IDs and wrong wrapper kinds; they parse successfully but remain unexecuted. Own IFC2x3 applies the same reference policy with its own Part21 values and mutations.
