# Cooperative GLB JSON Reader Implementation

2026-10-21. The overall IFC/all-MVD goal and ticket remain active. This checkpoint changes the actual TypeScript GLB endpoint; it is not native runtime or complete geometric/MVD coverage.

## Actual Production Route

readIfcGltfGlb retains private original raw-byte capture and all existing GLB framing/BIN rules. Its JSON chunk now enters decodeIfcGltfJson: one fatal streaming UTF8 TextDecoder consumes original bounded slices and keeps immutable text segments without a complete source-text join. The existing public pack-json decoder consumes those segments with explicit Replace policy, finite byte/node/depth limits, captured original signal/callback/batch and syntax checkpoints. All raw bytes, including a stripped leading UTF8 BOM, were already bounded by original GLB capture. Malformed JSON has the domain code glb.json; budget refusals use glb.limit and original cancellation remains io.cancelled.

The glTF-owned wire combinators now have a syntax-step projection sharing the same member/default/role tables as their existing synchronous readers. Declaration metadata is registered once in a private WeakMap; no graph/source-content cache exists. Objects check closed member sets, tuples/arrays/maps retain the exact declared roles, omitted defaults retain their original order and extras remain open JSON. A progressive heapsort orders canonical ECMAScript array-index names before other first-insertion members, including decoded duplicate names and prototype-like keys. Primitive numbers still use Number(text) and the existing finite Binary64/safe-index readers; arbitrary exact integers are not newly admitted. A yielded numeric extent precedes Number conversion, letting the IFC adapter refuse retained conversion tokens over original maxNumericCodeUnits. Overwritten numeric members still consume syntax work/byte/depth limits but are not converted or subject to this retained-conversion cap.

The actual route emits glb-json-decode, glb-json-syntax and glb-json-project interior/completion checkpoints. Projection total=0 denotes unknown total during work, matching the existing STEP writer convention; completion supplies the actual total. Caller options are captured before callbacks, only private byte input is read after capture, and no partial typed document escapes cancellation. The shared segmented decoder now uses the length accumulated during its controlled segment capture, removing its redundant synchronous whole-segment reduce.

## Explicit Remaining Boundaries

The shared syntax reader still assembles individual string tokens with parts.join and numeric lexemes with source.slice; host string/hash/allocation and bounded Number conversion remain scalar primitives. Streaming and progressive schema projection do not prove zero-copy, native physical heap funding or cancellation inside those primitives. Native original-owner receiving/JSON projection, broader geometry/semantics and genuine native execution remain open. No semantic publication or full MVD flag changed. Authentic native Cargo continues refusing before rustc; rustfmt is syntax inspection only.
