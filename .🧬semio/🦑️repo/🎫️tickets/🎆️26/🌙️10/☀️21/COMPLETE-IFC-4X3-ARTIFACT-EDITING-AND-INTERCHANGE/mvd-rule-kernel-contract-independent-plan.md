## Exact Inspected1.2 Structures

Use only final-named1.2 XSD at buildingSMART/mvdXML commit bd158e10901a2a49c067e3f57449431cab7130f0, SHA750008ce7ba59cc98614f7cb340fb262e747928cb2b1d0c05a0bd93bcc16412f. AttributeRule requires AttributeName, optionally RuleID/Description, and may contain EntityRules plus Constraints. EntityRule requires EntityName, optionally RuleID/Description, and may contain References, AttributeRules and Constraints. Its References contains one Template GenericReference and optional IdPrefix. TemplateRules is a recursively nested choice of TemplateRules/TemplateRule; operator enumerates and/or/not/nand/nor/xor/nxor. Therefore a loader cannot flatten child rules to an implicit AND or discard a group whose operator is unimplemented. TemplateRule Parameters remains an expression string requiring its own closed grammar; XML shape validation does not interpret it.

GenericReference/template UUID and IdPrefix resolution must be checked against the actual document owner. Detect missing/duplicate references and cycles before any traversal. RuleID references are scoped by template/prefix, not a global unqualified dictionary. Namespaces/dialects are part of document identity; do not normalize draft9's different namespace into final1.2 implicitly. XML namespace prefix spelling itself is not identity.

## One Source-Qualified Kernel

A private issued normalized rule owner supplies immutable template identity, exact source-document hash/dialect/schema and a closed traversal program. A separate original captured IFC source/index supplies source entity identity. For each traversal frame retain current source row, declaring entity, attribute name, result status, aggregate member ordinal and next expected entity membership. Reuse the common owner-qualified query and released membership logic; no fresh source clone, second index or caller-supplied success certificate.

An AttributeRule name must resolve through the current entity declaration to the actual inherited declaring owner; the XML itself does not carry that owner. Inverse FillsVoids needs the common relationship/population index, not a whole-model scan per candidate. EntityRule filters actual referenced entities through known ancestry, preserving unknown after any matches. Absent declaration, ambiguous/unknown query, dangling reference or unknown constituent remains incomplete. Distinguish a known empty inverse value from missing metadata. Scalar/reference/aggregate roles and source pointers stay explicit.

The proposed first kernel exposes traversal evidence only. Its test-only exists-matching-entity probe is explicit and is not the inferred complete meaning of an MVD concept or _asSchema cardinality. Full execution must later interpret actual template constraints/cardinality/grouping/parameter metrics and requirement applicability. Known failure and incomplete evidence may coexist, following current requirements coverage conventions.
