## Numeric Storage Convention

Count actual retained numeric backing identity:3 for each retained coordinate triple,1 for each retained mesh-index scalar slot, and2 for each spatial-axis row's coordinate/index pair. Reusing the same point/triangle backing through polygon or mesh reference arrays does not mint another numeric backing; independently copied triples/rows do. New polygon intersection points, normalization candidates, remap/ring/ear-clipping arrays, Weld cell index lists, output triangles, spatial-index rows, compact remapping and world coordinates all acquire permission before their actual birth/growth. Original borrowed operand backing is reserved before traversal without cloning it. Two separately built Block operands therefore retain120 numeric values before any kernel temporary.

Planes, normals, frames, reference-only arrays, string keys and map/set bookkeeping remain explicitly metadata under the original work/polygon/depth bounds. Fixed arithmetic scratch vectors are separately bounded by those entered frames. This workspace is not a physical heap ceiling and does not quantify JS Array engine over-allocation or GC timing. Numeric arrays retain their logical high-water slot permission until the actual owned buffer/phase retires; popping a ring does not quietly refund reserved spare slots. The policy names this conservative reserved numeric backing, rather than minimal current element count.

Each entered phase arena keeps strong private ownership of the actual allocated numeric backings it charges. This permits conservative bulk retirement, but prevents charging dead, unowned allocation history. In particular, a normalization arena may retain discarded duplicate point candidates until that normalization phase exits; a BSP arena may retain split positions later clipped away until BSP/output conversion exits. Their retained cost is part of measured peak and documented, not represented as minimal residency. The arenas release at concrete nested generator scope exits, not at an arbitrary later session checkpoint. Clearing their private maps is logical retirement, not a claim of synchronous physical reclamation.
