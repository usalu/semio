# FEM Self-Weight Interchange

Status: schema-first implementation is active. BIM occurrence-property files remain under separate audit; this slice owns IFC `io/fem.ts`, adjacent `fem/self-weight` neutral contracts/tests, and ticket evidence only.

The FEM target has Bar and Frame members, extruded continuum solids and per-case `selfWeight: boolean`; it has no plate/shell member category. Existing canonical ChangeLoadCaseSelfWeight CQRS, inverse and adjustable controls already carry the boolean. The actual 3D engine `fem3d_solve_all` passes each case flag and global gravity `[0,0,-9.81]` to the multi-case solver. The single-case frozen solver does not currently consume that flag; this interchange slice does not claim to repair that separate engine behavior.

The released [IfcStructuralLoadCase declaration](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/HTML/lexical/IfcStructuralLoadCase.htm) defines optional LIST[3:3] OF IfcRatioMeasure. Its semantic description identifies upright global `[0,0,-1]` as self-weight and requires geometry, section and material based weight calculation. The overall case Coefficient does not multiply this vector. Pinned ADD2 EXPRESS is authoritative for its width/type; this is a representable projection policy, not an extra EXPRESS WHERE rule.

Export true as three REAL ratio values `[0,0,-1]`; retain false as unset. Import unset and explicit zero triples as false, exact `[0,0,-1]` (including signed zero components) as true. Refuse other vectors, unknown/derived/malformed width, all typed-value wrappers and non-REAL values. Initial tests admitted typed IfcRatioMeasure wrappers; genuine full EXPRESS external validation rejected those wrappers in this directly defined REAL attribute. That counterexample is retained and the neutral policy corrected before freeze. This boolean cannot represent arbitrary magnitude or direction. Existing global identity placement and SI material/section rules remain authoritative; no additional point/member loads are synthesized and Coefficient remains independently checked. Import uses the existing owner-qualified SelfWeightCoefficients query, original source/index, control/cancellation and immutable source capture.

First add closed language-neutral vectors and genuine public endpoint red tests. Cover true/false and mixed cases, explicit actions without double creation, exact source immutability, mutation/diff/inverse and third-party JSON patch comparison; foreign vector refusal; original cancellation and exact callback failure; STEP parse/write round trip. Reuse canonical FEM native mutation/receiver laws as source evidence, explicitly retaining native IFC self-weight parity as unimplemented until original-funded native adapter integration is authored. No native execution or capability claim follows from TypeScript support.

Physical evidence will use exported unchanged STEP through an owned IfcOpenShell interface, checking ADD2, exact case coefficients, explicit actions, material mass density/section units and complete EXPRESS diagnostics. Official primary semantics supports the mapping; authored structural source is identified as authored, never official sample evidence. Root owns package registration after coherent freeze and independent audit.
