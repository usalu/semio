# Native Geometry Audit Fixes

Added Rust regressions before production changes for small nonsingular scales and malformed JSON/BIN padding. The conversion no longer uses an absolute determinant epsilon or a determinant product that may underflow. It obtains the exact sign of the six Binary64 dyadic products in the 3×3 determinant using bounded fixed-size unsigned limbs. Zero means exact singularity of the represented finite matrix; negative means reflected winding. The range of three finite Binary64 mantissas/exponents fits the fixed 100-word accumulator, including subnormals. Tests admit scales `1e-6` and `1e-200`; output coordinate representability and finite transform composition remain checked separately.

GLB admission now checks raw JSON chunk trailing bytes and actual raw BIN padding before shared decoding can strip them. This route requires canonical trailing JSON spaces and zero BIN padding, and refuses noncanonical whitespace tails rather than interpreting them as padding. Native tests cover valid framing, NUL JSON padding and nonzero BIN padding.

The retained audit tiny input is preserved. Its generator added `scale` to the official Box root, which already has `matrix`; that particular file is invalid under exclusive matrix/TRS admission and would refuse before determinant classification. The corrected test and retained `native-exchange-fix-inputs.ts` remove the root matrix before adding scale. The script independently loaded that corrected official-derived GLB with three.js GLTFLoader and verified bounds ±`5e-7` metres. It emits `tiny-scale-valid.glb` and `three-tiny.json` under generated/native-audit-fixes and explicitly records `nativeExecuted:false`.
