# Original Khronos Geometry Interoperability

Four original self-contained sample files are permanently retained beside the IFC IO tests from [KhronosGroup/glTF-Sample-Assets commit 15cd02d304e54cb42a4db4eefe719f76190f4b68](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/15cd02d304e54cb42a4db4eefe719f76190f4b68): Triangle and TriangleWithoutIndices in embedded glTF form, BoxInterleaved and NegativeScaleTest in GLB form. Source bytes and original README files are unchanged, with exact SHA-256/length provenance and original CC0/CC BY 4.0 attribution/license links. No screenshot or external texture was downloaded. The acquisition input pins immutable commit and asset hashes; fixture attributes preserve original bytes.

The closed neutral contract records exact primitive/vertex/triangle counts and IFC world bounds. The registered TypeScript suite compares every decoded world coordinate and exact reflected triangle index sequence against three.js, verifies original asset/README hashes and checks counts/bounds. All **four tests / 58 assertions pass**, including 11 primitives, 3,958 vertices and 7,724 triangles in the original negative-scale sample. Focused strict TypeScript checking passes. The companion written native test consumes the same four original files and neutral counts/bounds, plus a STEP reference roundtrip; Rustfmt accepts the source, but native compilation/execution remains unavailable.

The retained independent oracle runs the official Khronos validator `2.0.0-dev.3.10` on all four original source files and all four actual owned IFC-to-GLB re-exports: **zero errors in all eight files**. Triangle counts, vertex counts, primitive counts and reflected index order all agree. Original sample and output files remain under generated output for the fleet. The test-only three.js texture plugin supplies empty texture objects to avoid a DOM image decoder while preserving all original geometry/transform/index input; this verifies geometry, not material, normals, lighting or visual rendering fidelity.

One independent numerical difference is preserved in evidence: three.js decomposes/recomposes BoxInterleaved's authored matrix, changing exact 0.5 bounds to 0.5000000000000001. IFC's route preserves the authored matrix coefficients. The shared coordinate tolerance is eight binary64 epsilons relative to max(1, magnitude), and every coordinate passes; the oracle separately records exact bounds as false for that source. The other three bounds are exact. No runtime geometry was altered to imitate the independent loader's rounding.

This broadens original-source coverage of the admitted static triangle projection. It does not establish complete glTF rendering/extension behavior, native physical ownership or IFC MVD conformance. The High interchange worker now owns actual retained original-native glTF/GLB receiving, geometry construction and output publication; existing cold reference helpers and these fixtures remain available for differential checks.
