# Retained Whole-Model and Mesh Frontiers

Extend the accepted primitive foundation without a one-shot fallback. Keep one immutable captured-source binding and one paid source index for the whole operation. A model selector visits one original source entity per bounded unit, creates one current product frontier, retains complete product results and diagnostics, and does not expose render payload until the requested model preparation finishes.

Introduce a schema-owned retained mesh buffer contract with separately funded payload pages, point/index access and bounded close. Point/triangle writes are independent units. Native should reuse the existing first-party PagedList allocation/reservation/return interface rather than introducing a second generic allocator. TypeScript has no matching admitted PagedList surface; its existing NumericIndex supports Number keys and its scratch hash preallocates/loops synchronously, so neither can replace u64 source indexing or a paused mesh buffer. Use geometry-owned numeric page storage only where no first-party controlled interface exists.

Tessellated work keeps original point-list ordinal, face ordinal, corner ordinal, PN-index mapping and remap state, and creates vertices only for referenced points. Copying every point would incorrectly include unreferenced far-away points in camera bounds. Every face/point traversal, lookup probe, page allocation, triangle and diagnostic is resumed from retained indices. Polygon and BRep ring frontiers must feed resumable triangulation, with explicit refusal until its corresponding worker exists.

Move primitive output through the same numeric mesh storage to share append/close semantics. Whole-model results retain original product/representation IDs and source ordinals; labels remain immutable source borrows. Result access stays scalar so no typed backing escapes controlled close. No mounted viewer switch occurs while retained profile/ring/Boolean/payload families are missing.

Neutral tests first cover multiple products, interleaved metadata, sparse u64 IDs, unused points, PN index mapping, multiple allocation boundaries, one-item/one-work turns, budget/cancel checkpoints at every phase, atomic per-product results and paid empty close. Independent Three BufferGeometry/BoxGeometry outputs supply matching bounds/area/volume; existing source suites guard the immediate path. Rust remains authored/grammar checked until the repo native gate changes.
