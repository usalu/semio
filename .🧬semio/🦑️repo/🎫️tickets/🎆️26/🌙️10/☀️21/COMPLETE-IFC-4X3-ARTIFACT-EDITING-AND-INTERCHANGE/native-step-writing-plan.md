# Original-Owned Native STEP Publication

The next source task is the actual registered native IFC4x3 → UTF-8 artifact route. Current public reference helpers still clone complete headers/entities into Part21 documents, format whole records and construct a TxtSnapshot from the complete output. The existing `ComposerEntry` source route does not establish physical receiving/publication ownership. These helpers cannot be promoted to proof by putting a nominal work turn around them.

Use the original `IoRunControl` pair and `NativeSnapshotEncodeOwner`. Receive the source IFC native pack with the shared model's actual `ArtifactPackReceiving`; use its same original recipient and five independent currencies. Export directly into the actual UTF-8 artifact's documented binary envelope, with one retained final backing and no intermediate whole text or lines model. Normal output transfer occurs only after funded scratch retirement and final cancellation. Preserve the caller's original ledger direction through nested phases.

Implement an owned inline STEP emitter cursor that stores source positions and small fixed value traversal frames. Resolve at most the admitted nesting bound through borrowed original values. Store no lifetime-bound references inside an erased retirement owner and no generic record DTOs. A cursor turn emits a small bounded fragment, including exact integer/scalar syntax, escaped Unicode and canonical binary strings. Count and validate with the same emitter before allocating the final backing, retaining exact source/reference indexes under the original wallet. Prefer shared model-owned value locators if the interchange worker's stable implementation exposes a suitable interface; retain STEP syntax independently from the Pack record schema.

Write neutral contracts and actual original-wallet tests before implementation: original IFC/UTF-8 pack roundtrip; full headers, complex rows and nested values; binary and signed-zero preservation; every cancellation/publication prefix; zero item/copy/capacity/release/depth denial; real allocation versus receipts; original source pointers; successful scratch draining; official source graph roundtrips and independent IFC reader comparison. Authentic compilation remains pending on external compiler ingress, so source/runtime claims must remain distinct.

After export, implement retained original source receiving for native STEP import. Existing TxtSnapshot `ArtifactPackReceiving` already owns line storage through its original decoder; do not introduce another default decoder or flatten it with `to_body`. The importer must carry source position across actual line/ending spans, decode bounded token fragments into retained native graph slots, validate identifiers/references with funded indexes and publish through the actual IFC pack writer. Cold grammar fixes and callbacks do not replace this import work.
