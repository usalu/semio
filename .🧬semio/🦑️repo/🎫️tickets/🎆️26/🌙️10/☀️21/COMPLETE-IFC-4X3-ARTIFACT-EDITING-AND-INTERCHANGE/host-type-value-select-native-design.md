# Native Recursive SELECT Cursor Design

This is design-only during the parent's bounded registered-source verification hold. Native Measure86 has independently closed source review; its syntax-only/native-proof limits remain unchanged. No native or current TS production changes are authorized by this file alone.

The current Kind cursor stores one SELECT declaration and direct member ordinal. That is sufficient for the closed23-member Measure domain, but not IfcValue's nested three-branch109-leaf roster. Removing its32 guard without changing traversal would advertise branch names and still reject legal leaf constructors. The correct shared private continuation is a bounded borrowed SELECT stack: each frame holds the original declaration name, direct member count and next ordinal. Every turn advances one metadata member or alias node under the original context. It must detect active ancestry cycles, repeated leaf identity and fixed depth overflow; a metadata failure cannot publish a partial menu. The actual109-unique-leaf schema census is the neutral authority, not a hardcoded case list.

All reader roles must consume the same traversal law. Kind classification completes every leaf before declaring the selected domain supported; all-entity SELECTs retain the ordinary reference carrier. The original closed receiver searches the complete leaf roster before accepting a typed name and then checks the actual selected leaf expression. Source-guidance name discovery and option creation use the same leaf ordinal semantics. Central DomainCursor and issued candidate rules still decide membership and readiness, so a control selection never becomes its own admission certificate.

The shared six-hook metadata identity remains sufficient: select_count/select_member, defined_type_expression, enumeration_count/enumeration_member and rootless_attribute_count, with normalization/direct-arity binding separate as before. Every new retained child, traversal frame and field-role discriminator must join the actual owned state and close roster. No original caller/profile substitution may advance metadata, allocate, debit or donate. Pure demands must remain read-only, and actual transition logic belongs only in advance; the previous corrected duplicate-demand failures provide exact regression motivation.

The native guide should retain a completed leaf count and exact selected leaf ordinal, not allocate a109-element descriptor vector. The active option continuation seeks the requested start and emits31 actual choices into the existing original-funded Choices owner. One selected leaf may be pinned when outside that range, keeping the cap32. The last page emits16 ordinary choices. The page0/31/62/93 laws and exact selected constructor need native tests before implementation. Borrowed leaf names stay tied to immutable profile metadata; source/donor/full revision and original source loan are independent required identities.

Selected BOOLEAN/LOGICAL require a second explicit choice control under the typed constructor. The alias cursor resolves its actual enum domain (BOOLEAN or LOGICAL) for T/F/U enumeration without replacing the root SELECT identity. An itemless constructor offers explicit enum choices and appends only the caller's chosen typed enum child; no hidden initial T/F value is permitted. Typed BINARY stays a distinct closed binary child with the existing canonical bit lexer and exact raw string receiving. TypedCopy may share its string-backed retained frame across String/Integer/Enum/Binary carriers, with exact kind tags and compatible-child checks; it must never turn a binary or enum into STRING.

The existing REAL ListCopy should gain an explicit original-bound primitive mode for INTEGER-member lists. Its existing source pointer/length/target identity must also bind that mode before work. INTEGER members use the same retained object/string frames but omit the nested bits object, retaining raw i64 text instead. ARRAY REAL retains its original nested bits path. The actual CompoundPlaneAngle LIST3:4 is selected metadata, not a special entity-name branch. The source form reuses Create/Add/Remove structural controls, inserts blank INTEGER drafts only on caller Add, and keeps all original values editable. Required min/max and four alias WHERE rules remain strict complete-candidate authority.

Native tests must cover one complete actual MeasureWithUnit source, Unit#7 preservation, all109 exact names/ancestors and every page, selected off-page pinning, leaf-vs-branch rejection, ordinary reference branches unchanged, enum/binary/INTEGER-list exact carriers, all primitive modes with invalid UTF8, wrong mode/profile/source/caller before debit, repeated demand purity, every denied axis/fuel, cancellation at each traversal/copy prefix, failed receipt custody, controller bindings and child-before-source retirement. Authentic Cargo type/runtime/grant execution remains false until the enforcing ingress itself succeeds; source parsing and independent TS/physical evidence cannot substitute for it.
