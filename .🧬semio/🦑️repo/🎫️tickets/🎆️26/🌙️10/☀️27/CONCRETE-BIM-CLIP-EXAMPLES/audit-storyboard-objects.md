# Audit: Storyboard Objects (`Beat2_ObjectOrientation`, "From Schema to Object")

Scope: `storyboard-objects.md` checked against `research-ifc.md`, `research-villa-savoye.md`, `audit-current.md` (Prior Decisions To Keep), `agent-rules.md` (quality bar) and `api.md`. Read-only; this report is the only file written.

Length counts are characters (`wc -m`, UTF-8). Caption limit used: about 115 characters, as requested. The real gate is the toolkit: `caption_bar` raises when a clause wraps above 2 lines (`CAPTION_MAX_WIDTH = 11.5`, `CAPTION_MAX_LINES = 2`, toolkit `🎨️visuals/🐍️.py` lines 2027-2068). Run it on every clause before accepting any text.
