# Toolkit ready (first usable version)

Scenes do `from ...🎨️visuals.🐍️ import ClipScene` as before and call widgets as `self.<widget>(...)`. `present(topic)` now calls `self.present_<topic>()`, which each scene class defines (the old `_information` ... `_consistency` bodies are gone). Colours `INK MUTED ARCH STRUCT SERV DATA GOOD WARN GLASS CONCRETE GREEN_GROUND` are module attributes of `C/🎨️visuals/🐍️.py`. Contract, module pattern and every signature: `T/api.md` section 3.

**Ready now (verified in `T/🗑️generated/toolkit/*-en.png`, `*-de.png`, layout report `toolkit-<lang>-layout.md`):**

- `ClipScene`: `language() tr() number() quantity() label() text() mono() live() live_label() step() present()`.
- Drafting (`📐️drafting`): `dimension`, `level_mark`, `leader`, `hatch`, `badge`, `north_arrow`, `scale_bar`, free functions `segments polyline polygon region hatch_pairs dashes`, shared `View` (plan / axon / elevation / section) and `Drawing` (`parts`, `layers`, `anchors`, `at(...)`), `Live`.
- Panels (`🧾️panels`): `class_box`, `class_tree` (leaf classes, per-attribute and per-row access, expanded attribute box), `property_table` (sourced / assumed column), `step_panel` (monospace, role colours, `only=`, `wrap=`, `token(...)`, width up to 12.4), `model_card`, `guid_chip`.
- Wired and callable through `ClipScene` (owned and still being refined by their agents; the showcase boards `plan-ground`, `plan-first`, `plan-roof`, `section`, `elevations`, `axon-*`, `piloti-detail`, `slab-strip`, `analysis-axon`, `tributary`, `mesh`, `load-arrows` render them): `villa_plan`, `villa_section`, `villa_elevation`, `piloti_detail`, `slab_strip`, `wall_detail` (ORTHO, `🏛️savoye/📋️plan`, `✂️section`, `🔩️detail`), `villa_axon`, `axon_point`, `axon_view` (AXON, `🏛️savoye/🧊️axon`), `analysis_view`, `load_arrows`, `tributary_view`, `mesh_view` (ANALYSIS-VIEW, `🧮️analysis`). Model cards already use `villa_axon` for their thumbnails.

**Still pending in other modules (guarded import, so a missing module never breaks the others):** ORTHO: `bay_detail`, `car`, `swept_path`, `roof_detail`, `draw_primitives`, section cuts other than `"salon"`, elevation faces other than south; AXON: `element_axon`. Signatures and ownership: `T/api.md` section 3.5 and the owners' own notes `ortho.md`, `axon.md`, `analysis-views.md`; the requests already collected in 3.5 are the scope. Argument order differs between modules (plan: `level, point, scale`; others: `point, scale`), check the owner's note, not a guess.

**Known limits:** text uses the ladder 16.2 / 19.2 / 21.6 only; a `Text` squeezed to a width keeps its ladder size scaled, so keep widths realistic; `Live` rebuilds a whole drawing, so for 30 fps pass a `key=` that changes only when the value changes; `class_tree` leaf rows list at most `leaf_attrs=2` attributes per leaf (the rest reads `+n`). Stage: content band y 2.58 ... -2.60, x +-6.8. `T/toolkit-stub-model.py` is a stand-in for the model functions (only used when the real module lacks a name); the real model is live now.
