# Projection Integration R11

The axonometric provider now draws each registered column section with its actual contour and each regional slab with its actual physical depth. The previous bounding cylinder and uniform maximum slab depth no longer define these solids. Basement foundations and beams receive structural discipline membership and cellar geometry participates in the model framing extent. Real finish surfaces render after their floor and before furniture; invented space-fill planes were removed.

Generic solids now require a source base_level and resolve locally authored z coordinates against the storey datum. Explicit stair step_parts use from_level; landing_parts use to_level. All non-stair solid representations consume this resolved geometry. Roof finish_parts produce a level finish above the mixed structural regions, with the regional reserve reducing from 9 cm above 17 cm structure to 3 cm above 23 cm structure. A paving thickness event raises the continuous finish consistently.

The measured ramp thickness of 6 cm (Zaparaín et al., 2022, section 8) is authored through a positive geometry.thickness quantity for ramps, flights and landings. The API exports these dimensions to drawings, replacing independent thickness guesses.

Mesh comparison reference outlines now use actual high resolution source profiles, or the supplied mesh section rims for an unbound mesh. Rectangular sections are not displayed with bounding circles.

Validation: local placement and roof finish contracts: 3 pass; axon profile/regional slab contracts: 2 pass; true mesh contour contract: 1 pass. These use NumPy and Shapely as independent numerical and polygon oracles, through the ticket Python WASM harness. All three edited geometry modules compile. New contracts are registered in the standard BIM test target. Shared-source integration and native frame rendering remain pending; passing pure geometry tests is not evidence of native rendering.

Native rendering remains blocked by the repository runtime registry error documented in runtime-verification-r7.md. No product runtime dependencies were added for the test harness.

Strict AJV2020 compilation caught missing object types in the newly introduced slab conditional and composite/regional quantity restrictions. Those schema nodes now declare object types and required field property references; strict compilation passes. The portable ramp fixture and its independent NumPy/Shapely check also pass, bringing the local placement/roof/ramp contract to four tests. The combined isolated projection/surface batch passed seven before this additional ramp check.

Post-publication integration: all16 independent geometry groups pass against the measured source after replacing one planter cavity fixture absolute Z with its storey-relative probe. Source strict AJV validation passes. The four-storey source QA sheet is reproducibly generated by geometry-qa.mjs and reviewed; it remains a geometric review artifact, not native rendering. The six chapter syntax checks and four chapter/transcript contracts pass.

Repeated occupied slab subdivision now uses a content-sensitive cache with bounded24-entry storage and isolated copied outputs. A regression first failed before implementation, then passed for reuse, input mutation invalidation, output mutation isolation and unchanged Shapely volume. Convex mesh caps now use linear-time triangles without centre vertices; the existing independent six-profile volume/manifold suite passed afterward in2.95seconds on the WASM worker, including the concave fallback and variable vertical sections.
