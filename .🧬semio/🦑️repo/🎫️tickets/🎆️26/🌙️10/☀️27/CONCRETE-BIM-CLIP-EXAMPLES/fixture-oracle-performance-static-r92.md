The expensive repeated operation is the independent SciPy hull topology: _cut_points recomputes ConvexHull and its edge set for every requested Z, and _band calls it twice for each complex component. Placement additionally computes a hull for component volume. Cache vertices, hull edges and volume once per immutable component within one frozen test context, while retaining exact section cuts and GEOS intersection. This avoids geometric approximation and keeps the independent oracle distinct from the producer. Do not substitute one convex hull for a whole hollow fixture or a concave polygon with holes.

The route method already caches each fixture/body-height band union. Its hits comprehension computes the same passage intersection twice for every positive candidate. Compute that intersection once. A per-storey/body-height union is a sound broad pass/fail acceleration when disjoint, with lazy per-fixture evaluation for collision tags. Preserve the current per-fixture1e−8 area threshold: a combined union’s aggregate tiny contacts are not automatically equivalent to the old per-object threshold. AABB/prepared geometry may reject disjoint candidates, but must not replace exact occupied acceptance for possible hits.

Placement precomputes column projections, then tests every fixture component against them. Spatial indexing or simple bounds rejection can avoid most exact pair checks; overlapping candidates still require the same Z-overlap and actual band intersection. Cache band results for repeated part/Z intervals within the frozen source context. The quantity call used in the assertion message is evaluated only on failure; it is not a second success-path quantity call.

Laundry reuses the same physical walls, columns, frames and fixtures for route and standing domains, and many repeated part-height intersections. Reuse their immutable bands for the same interval and spatially reject disjoint pairs, retaining every cavity, mounting and material-separation assertion. Several tests request full building geometry; retain the native geometry memo’s correct dependency scope rather than allowing source/producer changes to reuse stale outputs.

No speedup should remove operated leaves, ignore structural members, fill holes, discard small features or relax source dimensions/tolerances. The separately verified chauffeur-bath collision is a genuine occupied-shell collision and is not a reason to weaken the hull oracle. See chauffeur-bath-doors-independent-r92.md when finalized.
