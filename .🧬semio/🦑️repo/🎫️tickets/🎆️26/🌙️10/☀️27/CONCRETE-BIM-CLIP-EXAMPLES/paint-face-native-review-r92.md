## Causal SDK appearance limit

Original selected-face styling yields54 WHITE mesh buffers in both languages, even though GetLine returns all correct face/style/shading/RGB references. In an isolated audit copy only, retargeting exactly five IfcStyledItem.Item references from each selected FACE to its containing BREP produces five blue buffers and49 white buffers. Every other STEP line, including all geometry, remains byte-identical. Thus the same valid RGB/style is recognized at body level but ignored at face level by this GetFlatMesh version. This A/B is diagnostic only; painting the entire substrate BRep would misrepresent unpainted return faces and is not a proposed production fix.

The normative data model supports face styling: [IfcStyledItem](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/HTML/lexical/IfcStyledItem.htm) accepts IfcRepresentationItem, while [IfcFace](https://standards.buildingsmart.org/IFC/RELEASE/IFC4_3/HTML/lexical/IfcFace.htm) inherits StyledByItem through IfcTopologicalRepresentationItem.
