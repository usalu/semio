# Analytic Stock Difference Contract

The colocated contract is `model/🧊️solids/➖️difference/🧬️.schema.json`; its portable vectors are `🧪️tests/🔣️.json`. A part has one authoritative `csg` expression and explicit material/role. Difference nodes retain original stock and recursive cutter operands. Prisms retain their actual source outline/holes and finite z band. Original circle or ellipse extrusions retain explicit world axis, rotation, radii, local bore offsets and finite z band. Declared material and reserved bore-air cutters have distinct roles and source owner identities. GUIDs alone never establish geometric exclusion. Display tessellation is a separate display-only product.

Eight vectors cover an edge-crossing beam end, occupation between inscribed facets, a strictly positive two-nanometre exterior strip, annular material with retained donor bore, separately reserved bore air, nested finite-height bearing and rotated offset circular/elliptical profiles. Schema single-authority controls passed. The first runtime RED was followed by a second measured quadrature RED at a circle support; a sine parameterization removes the endpoint square-root singularity without changing the implicit curve or increasing the numerical comparison tolerance. The first-party runtime then passed three functions in 1.898 seconds, including progress, cancellation and input isolation. It uses only the standard library and returns an explicitly labeled numerical error estimate, not a certified bound.

Independent GEOS/SciPy real-curve integration is supplied by the root-owned analytic-difference-oracle-r95.py. The first-party runtime does not import it. The cross-implementation proof retains both volumes, both error estimates and actual owned/cutter intersection volumes. The two-nanometre strip remains positive in both implementations at 4.000000330961484e-18 m³; the between-facet stock is fully removed by the real circle. No polygon buffer or larger clearance is used.

Native owns exact IFCBOOLEANRESULT serialization, optionally wrapped in IFCCSGSOLID. Root owns independent semantic capture/exclusion auditing. The API now exposes `reference_parts(key, model)` for original product-scope structural stock; ramp geometry also exposes `reference_parts`. Flight references bypass all joints, and assembly references retain only their own uncut landing stock while each child retains its own section. A neutral affine reference independently measures 0.144 m³ in SciPy and is unchanged by interface declarations or caller mutation. Thirteen structural functions pass in 3.259 seconds.

Runtime constructor integration and source publication remain pending. Actual finite sloping/polyhedral stocks and construction-boundary cutters need an explicit neutral extension, rather than flattening CSG owners in roof material construction or inventing a product owner for geometric clipping. These extensions have been coordinated with root before changing the frozen initial operand shape.
