For a uniform regular field with rib pitch p=.25m, rib width b=.06m and compression layer t=.05m, an explicitly simplified material estimate is:

RC equivalent depth = t + (b/p)×(h−t) = .24h+.038.

This gives .0788mRC-equivalent for h=.17, .086m for h=.20 and .0932m for h=.23. The rest is the gross ceramic/air unit envelope, not solid clay. This is an engineering simplification of the repeated field, not a measured total including all solid edge beams, trimmers, capitals and unusual local sections. If used in quantities, those additional RC members must be accounted for without double counting overlap. Source17/23cm totals must never simultaneously be counted as full RC and full ceramic layers.

## Roof Soil and Teaching Events

There is no support here for a blanket .10m soil layer over the whole upper roof. Main hanging garden planting and its2 documented planters are different from a universal upper-roof soil assembly. Remove the universal upper-roof soil product/layer from the as-modelled1931 source state. A soil-thickness lesson may be an explicitly hypothetical renovation/planter scenario with a different source-defined role; alternatively replace the lesson with a paving/weathering-reserve thickness event and update every clip, event case, API schema and fixture together. Do not retain a soil API alias under a new name.

## Density and Historical State

Current material density values are assumed teaching inputs. Retaining25kN/m³RC or an equivalent ceramic-unit-envelope density is permissible only with basis=assumed and a statement that the values are not measured Villa Savoye material tests. Hollow clay bulk density must not masquerade as solid brick density. The exact original/restored glazing frame state and missing original chimneys must be declared separately; present source reconstruction does not assert that later aluminium replacements were original timber frames.
