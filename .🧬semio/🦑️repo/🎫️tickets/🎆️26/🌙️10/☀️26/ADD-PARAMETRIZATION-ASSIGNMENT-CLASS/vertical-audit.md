Independent PDF measurement uses pdfplumber native cell rules and a separate PDFium raster renderer at 288 dpi. Each filled cell is inset from its borders, its local canvas is sampled, and the first/last visible foreground ink rows determine the actual glyph-envelope midpoint. This covers accented labels, math variables, numeric values and category words rather than assuming that font bounding boxes describe visible glyphs.
