## Converter Investigation

The tool registry does not include Inkscape, svg2pdf, usvg or resvg executables. Framework typeset wraps usvg to first-party vector paths; the OS media export module rasterizes through resvg and extracts polylines, so neither is an existing standard vector SVG-to-PDF CLI. Relevant print/build/teaching TS, JSON, TOML and Python source searches found no svg2pdf or CairoSVG implementation. The historical ticket converter instead uses svglib, reportlab and pypdf with a hardcoded host Python path in its launcher. It is useful as provenance evidence and a test oracle, not a portable production pipeline.

## Resource and Producer Wiring Review

Read-only inspection confirms the course builder relative imports resolve to the course registry and domain icon plan. All sixteen canonical SVG SHA256 values match their actual source bytes and all pass the self-contained resource guard. SourceRoot stages the four localized/common authored files only. PNG resources are generated beneath compiler scratch and PDF publication uses the course namespace, architecture-parametric-parametrization language id, and explicit matching course target receipt producer. Declared target output slots match the managed print document layout. Target inputs include domain files, builder files, Print sources and canonical metabolism assets; prerequisite targets retain fonts, compiler, TeX and generated shared assets.

The generic document resource branch in printCompilationIntentV1 currently lacks the normalized casefold duplicate-output check already present for probes. A.png and a.png can therefore produce different outcomes on case-sensitive Linux and Windows. Same-name outputs and collision with staged source files fail late at exclusive write rather than intent validation. This does not affect the sixteen current distinct icon names but violates the portable resource interface; reported to root and build owner.

The resource renderer checks cancellation before and after Sharp toBuffer rather than interrupting native rasterization. Width-only resize also does not cap output height or total pixel count for an extreme-aspect-ratio SVG; the byte cap is applied after materializing PNG bytes. These generic bounds/cancellation concerns were reported to owners. No heavy builds or production edits were performed.
