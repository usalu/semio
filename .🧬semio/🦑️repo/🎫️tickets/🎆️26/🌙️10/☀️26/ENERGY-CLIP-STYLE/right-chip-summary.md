# Right-Side Fullscreen Chip

The View/Ansehen chip is fused into the bottom-right of every teaching card silhouette. The fullscreen maximize icon is inside that same chip, replacing the chevron. The expanded window has one right-cap Restore/Wiederherstellen chip with its minimize icon inside the same native button. Shared spacing, typography, tint, silhouette and parent hover behavior are preserved. Other products keep their existing shared-card defaults.

[Updated 7-second preview](./right-chip.mp4), [overview](./right-chip-overview.png), [expanded chip](./right-chip-fullscreen.png).

Eight focused test invocations passed after the bilingual placement test established RED. Verification covers English/German right alignment, exactly one embedded icon, fused restore pointer down/release/click, hover preview geometry, shared default behavior and generic square-control geometry. The 56-frame preview also decodes fully, records all four native actions and has identical first/last images.
