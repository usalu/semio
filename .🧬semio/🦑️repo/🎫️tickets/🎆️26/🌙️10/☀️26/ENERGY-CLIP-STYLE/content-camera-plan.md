# Content-Only Playback Camera

Keep the actual virtual UI only in opening and closing transitions. Preserve the existing three-second native topic/video interaction route, then add a schema-owned 0.6-second uniform camera zoom into the actual contained source-image rectangle. At the reverse transition, restore the UI camera for 0.6 seconds before the existing native restore route. Source playback fills the output directly with no shell, navbar, footer or outer window chrome.

The source-image ink rectangle, rather than its letterboxed viewport, is the camera target. Exact source snapshots own the inward endpoint and outward start, matching fullframe body composition. Source frames, audio timing, cursor and common root boundaries remain covered. Root owns a focused real-content preview and ticket closure; high agents own production and portable/independent tests; low agents audit geometry and output.
