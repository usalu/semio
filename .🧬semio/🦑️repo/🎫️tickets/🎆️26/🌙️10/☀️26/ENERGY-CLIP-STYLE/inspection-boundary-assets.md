# Exact Shared Boundary Assets

Fresh actual browser processes produced pixel differences of up to four RGB levels in nested backdrop-filter fields despite identical DOM geometry, styles and source identities. A process-local raster LRU did not establish exact independent chapter endpoints and could evict earlier ancestor states.

Each canonical media-free ancestor overview now has an immutable actual-UI raster asset keyed by complete UI source/CSS/font/icon fingerprints, captured catalog, locale, viewport, ancestry, camera and cursor. The first native producer atomically publishes its PNG digest and original DOM metadata through an exclusive hardlink commit; competing producers load the same winning bytes. Every read verifies the record shape, full digest, PNG format and dimensions. Source hashes are still checked before and after actual browser capture. Corrupt assets fail explicitly. The existing output-root port owns cache placement; no external runtime library is introduced.

Portable fixtures and independent PIL/NumPy tests cover first-writer identity, version changes, concurrent races and corruption; native fresh-process integration remains required.

Regression status: missing boundary-asset API produced three RED errors; implementation passes four tests in0.610s, including four simultaneous first writers. Existing native fresh-process uncached captures remain evidence of backdrop paint jitter; a new producer/consumer process test must demonstrate the shared asset guarantee rather than pretending uncached browser paint is bit-deterministic.
