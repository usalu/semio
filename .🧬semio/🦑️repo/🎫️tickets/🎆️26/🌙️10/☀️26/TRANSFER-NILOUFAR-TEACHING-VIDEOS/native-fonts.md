# Native Font Provision

The fresh native Linux bootstrap needs an installed serif face in addition to Cairo/Pango headers. The devcontainer already installs fonts-liberation. Native package choices were verified against primary package registries on 2026-10-26: [Debian fonts-liberation](https://packages.debian.org/trixie/fonts-liberation), [Fedora liberation-serif-fonts](https://packages.fedoraproject.org/pkgs/liberation-fonts/liberation-serif-fonts/), [Arch ttf-liberation](https://archlinux.org/packages/extra/any/ttf-liberation/), and [openSUSE Slowroll liberation-fonts](https://build.opensuse.org/project/show/openSUSE%3ASlowroll). These supply a concrete Liberation serif family already supported by the source font resolver. macOS and Windows use their existing system serif faces.

The Linux font requirements are added to the language-neutral native prerequisite fixture before implementation, alongside the existing Cairo/Pango requirements. No font files or new runtime library API are added to the repository.

## Mathematical Symbol Coverage

Actual Windows glyph testing found Georgia lacks ϑ and several arrows and the contour integral. Symbol-only fallback uses a math-capable installed face. Cambria Math covers the complete tested symbol set on Windows. For other native environments the bootstrap provisions DejaVu Math TeX Gyre through system packages: [Debian fonts-dejavu-extra file list](https://packages.debian.org/trixie/all/fonts-dejavu-extra/filelist), [Fedora dejavu-serif-fonts file list](https://packages.fedoraproject.org/pkgs/dejavu-fonts/dejavu-serif-fonts/fedora-45.html), [Arch ttf-dejavu file list](https://archlinux.org/packages/extra/any/ttf-dejavu/files/), and [Homebrew font-dejavu artifacts](https://formulae.brew.sh/cask/font-dejavu). openSUSE uses its [dejavu-fonts package](https://build.opensuse.org/package/show/Documentation%3ATools/dejavu-fonts), based on the upstream DejaVu font set. These remain system fonts; no runtime font library or font binary is added to this repository.
