# BIM and Parametric Concept Content

The independent fixtures were authored before quiz content. They assert data/information, all six object-oriented concepts, interface/coordination, parameter domains, functional consistency, complexity layers, four radar axes and three automation levels.

All geometric and workflow cases are original teaching exercises with explicit assumptions. Radar values are illustrative ordinal ratings on a common 1–5 scale rather than measured software comparisons. Few independent parameters can cover a broad coherent design space; redundant controls do not imply versatility.

Primary references: [Python class semantics](https://docs.python.org/3/tutorial/classes.html) for terminology; [buildingSMART BCF repository](https://github.com/buildingSMART/BCF-XML/tree/release_3_0) for the collaboration exchange distinction. The IFC semantic object distinction is expressed as a self-contained exercise rather than a claim about a particular authoring product.
