# Optimization Test Plan

Create portable JSON examples and fixture expectations before implementing the numerical interface or clips. Six standalone scene contracts cover extrema, grid/random sampling, factorial experiments, a normalized scalar index, Pareto dominance, and an evolutionary generation. English and German narration must be nonempty and distinct; no exact prose is prescribed.

The numerical interface uses standard Python only. NumPy independently reconstructs polynomial stationary points, sampling coordinate transforms, least-squares factorial effects, normalized weighted indices, dominance matrices and evolutionary offspring scores. AJV independently validates the JSON model and rejects authored invalid mutations.

The clip contract checks Manim scene discovery, dedicated entry routing, shared curriculum/presentation registration and playlist order. Parent integration owns shared runner and global fixture changes. Tests are first run against the absent model/scenes to establish failure, then rerun as the implementation arrives.
