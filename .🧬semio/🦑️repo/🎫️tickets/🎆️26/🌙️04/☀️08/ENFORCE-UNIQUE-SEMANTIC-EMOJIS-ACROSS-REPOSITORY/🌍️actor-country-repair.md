# Actor Country Naming Repair

## Reviewed Structure

Each country receives its own flag identity. Every entity receives an individually handpicked semantic directory containing its preserved legacy asset ID and readable entity name. A light logo is `☀️logo.png`; an existing dark variant is `🌙️logo-dark.png`. Thus paired PNGs have meaningful distinct sibling identities without assigning arbitrary dark-version discriminators to hundreds of organizations.

The actual print compiler-name function was executed: these carrier names stage to `logo.png` and `logo-dark.png`, preserving the existing dark-variant lookup convention. Country flags likewise stage to literal ISO country codes. No reserved-subtree exclusion was introduced.
