# glTF Hand-Reviewed Emoji Repair

## Planned Format-Root Cutover — Not Yet Applied

The current main `🧊️gltf` root collides with its sibling `🧊️obj`. OBJ retains the solid-geometry identity; glTF is a transport for complete scenes, animation, node graphs, materials, cameras, skins and mesh data, so the handpicked format identity is `🎬️gltf`. A physical census finds exactly 19 current glTF format roots: the main Stdio owner, 14 import/export carriers across Procedural, GIS, Process, Lowpoly, CAD, Remodel and Puzzle, and four Stdio Semio mesh/animation carriers. Every corresponding `🎬️gltf` destination is absent and every sibling group is free of `🎬️`.

The cutover must be a single coordinated source batch, not a substring replacement. Its exact consumers include:

- Stdio and seven foreign Rust package mounts, the Stdio TypeScript export, registry, artifact catalog, native-codec registry, oracle mount and setup documentation.
- The artifact definition's physical `directory` field while retaining the semantic artifact ID `s.stdio.gltf`.
- All 120 production mutation descriptors' explicit owner paths.
- All 120 aggregate fixture `generator.command` paths. These are executable reproduction authority, not frozen prose: the repository test runner splits and executes each recorded command under `SEMIO_FIXTURE_OUT`.
- The policy allowlist, root script inventory, DSL fixture sweep coordinate, taxonomy format kind, neutral naming fixtures, MIME registry, mesh-engine root documentation, and exact feature/document references.

The separate `🧊️gltf-codec` mesh-engine fixture kind is not a format-root carrier and must not be renamed merely because it shares a textual fragment. Generator versions, fixture hashes, semantic IDs, wire identities and payload bytes remain unchanged. No one should apply the 19 moves until the root, carrier, descriptor, runnable-command and shared-registry edits are owned and qualified as one bounded batch.

## Domain Contract Investigation

The existing Architect domain registry only admits `<verb>-<domain>` IDs and a one-word operation stem. glTF already has legitimate plural and compound identities such as `reorder-cameras`, `change-node-name`, and `bind-node-camera`.
