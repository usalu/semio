# Shared Asset Delivery Hand Review

Source assets already have individually reviewed names, but the build copy hook emits them under the raw `asset` directory. The public route and output directory will share one explicit asset-owned name, `🖼️assets`. This is a coordinated consumer/producer change, not a palette or heuristic migration.

The schema-first authority and neutral request cases live in the existing asset resolver. They distinguish raw/encoded valid requests from malformed encoding, traversal, separator injection and old-route requests. Runtime admission must not depend on a third-party library; tests compare the authority with Ajv and valid requests with the independent WHATWG URL implementation.

Root owns the asset transport helper, middleware/output directory, exact CSS/generator URLs, stale native cursor coordinates, one renderer font URL and relevant documentation/tests. The parallel development agent owns seven build-hook write guards and the OS in-memory output plan. Old distributions remain untouched until verified. Native cursor assets are resolved case by case against the actual handpicked cursor families; no old-path alias is permitted.

The spatial-kernel `modelDefinitionAssetPathRest` compatibility markers are not current shared-asset HTTP consumers and will not be mechanically rewritten. That separate compatibility parser still needs its own semantic review.

The shared route cutover is implemented. The real HTTP test failed first with 404 for the new encoded route, then passed after the asset-owned authority was wired into middleware and output copying. The full Styling suite passes 38 tests/1,291 assertions, including all 18 neutral request cases, independent Ajv/WHATWG checks, two actual HTTP source-byte SHA comparisons, rejection of the old route, all seven no-write/normal-write/default hook cases, 42 CSS cursor URLs and 25 native cursor URLs. PostCSS independently parses the cursor declarations; every referenced source is an actual SVG. Evidence: `🗑️generated/asset-delivery-red.txt` and `asset-delivery-styling-tests.txt`.

The native cursor mapping now uses the exact reviewed source family and light/dark/editor-original file for each case. Existing hotspot coordinates, fallback CSS keywords and branch choices are unchanged, including the shared grabbing image and the pre-existing dark NESW image in both modes. The two existing native URL assertions were strengthened to full expected-string equality. The focused native run completed: one passing cursor test, 381 filtered out, in `asset-delivery-native-cursor.txt`. The focused React introduction-logo run also passed one test, with 691 unrelated tests skipped, in `asset-delivery-react-test.txt`; this was not a fresh full React suite.
