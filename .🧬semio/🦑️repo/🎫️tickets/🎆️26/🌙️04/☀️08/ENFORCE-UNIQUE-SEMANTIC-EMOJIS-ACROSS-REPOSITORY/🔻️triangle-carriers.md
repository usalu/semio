# STL Triangle Carriers

Twenty-two physical foreign STL carrier directories were individually reviewed and moved from `🟪️stl` to `🔺️stl`. The triangle identifies the format's triangulated surfaces; the purple square did not. The new name was absent and its emoji free in all twenty-two sibling groups. Twenty owners contain codecs, while two FEM import scaffolds are empty and remain empty.

Each exact carrier below lives under `✏️s/🔌️plugins/<plugin>/🗿️artifacts/<artifact>/🏅️standards/🔖️1/🪆️subsets/✳️any/🚪️io`, in both `📤️export/🧵️serializers/🗿️artifacts/🟪️stl` and `📥️import/🧩️deserializers/🗿️artifacts/🟪️stl`. Both final basenames are now `🔺️stl`.

The two real FEM exports triangulate each region/solid footprint, extrude using its own thickness/height, and bridge through the Semio mesh to ASCII STL. Lowpoly's documented incomplete bridge remains intact. No codec body, current async implementation, semantic ID, byte payload, reserved filename, or empty-scaffold behavior changed.

All forty codec files match the captured SHA-256 hashes and lengths. All twenty existing Rust mounts now reference their exact physical targets. The two FEM oracle rationales and two probe comments received only the corresponding path identity correction; both JSON documents parse identically through native JSON and `jsonc-parser`. Seven glTF documentation references now identify the same triangle-prefixed STL owner. No old `🟪️stl` reference remains in these seven plugin trees or the glTF tree. This is bounded coordinate and byte-preservation verification, not a native test pass for these plugins.

Moves were individually written `mv -n` commands and all text changes exact patches. No migration script, automatic emoji selection, deletion, Git mutation, or restoration was used. The parent owns the main Stdio STL root and other agents' carrier batches.
