# Independent Semantic Census

Read-only review after the Semio, Hub, and glTF passes. Scope: Framework and other plugins; Stdio, Norm, Mit-Bestand, and Print were excluded because they have separate owners. No names were selected or renamed by the census.

A deliberately narrow animal, fruit, flower, and color-prefix filter returned 215 candidate path components across 22 other plugins. This is a review queue, not a breach count: shell emojis for shell concepts, JavaScript yellow, Linux penguins, macOS apples, color-labelled assets, and geometric circle icons are legitimate. The filter cannot prove semantic completeness or detect every unrelated object emoji.
