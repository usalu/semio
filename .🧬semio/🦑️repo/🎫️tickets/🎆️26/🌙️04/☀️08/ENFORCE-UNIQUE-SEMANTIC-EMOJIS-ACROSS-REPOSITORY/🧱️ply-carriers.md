# PLY Carrier Repair

## Decision

PLY stores ordered element, property, and row blocks. The handpicked identity is therefore `🧱️ply`, distinguishing the format from its sibling `☁️las` point-cloud carrier. The `🧱️` identity and destination basename were absent from every affected sibling group before the moves.

## Exact scope

Eight carrier roots were moved literally from `☁️ply` to `🧱️ply`:

- GIS terrain import and export
- Lowpoly import and export
- Remodel import and export
- Puzzle 3D import and export

The eight matching Rust `#[path]` mounts were updated in the four owning package roots. No module names, wire identifiers, codec bodies, format versions, or leaf filenames changed.

## Verification

- All eight new carrier roots exist and all eight old roots are absent.
- All eight exact Rust mounts reference the new roots.
- The 16 leaf files retain their pre-move SHA-256 values byte-for-byte.
- Every affected sibling group contains exactly one `🧱️` identity.
- No `🗿️artifacts/☁️ply` reference remains in the four owned plugin trees.

## Coordination

This is the assigned outside-Stdio carrier batch only. The main Stdio PLY owner and the Procedural and Semio carriers remain with the root agent for the coordinated 13-owner family cutover.
