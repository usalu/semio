# Weak Link Removal (2026-10-07)

A weak link is a reference that names its target in prose (`Anlage „Bauteilbörsen”`, `siehe Leseschlüssel`, `im Haupttext`, `in den Anlagen`) without a label behind it: not clickable, and silently wrong once the target is renamed or renumbered.

## Framework changes

- `semio-core.sty` — `\appendixref` takes an optional fallback wording. The appendices under `📋️bericht/📎️anhang` are shared with the Forschungsbericht, which carries no Bauteilbörsen, Hürden or Typologie appendix; a strict reference would print `??` there. With the fallback the Zwischenbericht gets the live link and the Forschungsbericht reads `der Anlage „…“ des Zwischenberichts`. Without the optional argument the command is strict as before.
- `semio-window.sty` — nested paragraph headings (`SemioNest`) compose their number by hand and never called `\refstepcounter`, so a `\label` after one resolved to the enclosing subsubsection (`Abschnitt 1.2.1.1` for both new section references, pointing at „Recherche“). The renderer now publishes the composed number and an anchor.
