P8 scope note (2026-07-26) — implemented ahead of P6/P7 to complete the three-solver core sooner.

Implemented: Grid3dTopology (Face6/Edge18/Vertex26/Custom stencils, per-axis Boundary reused
directly from grid2d.rs, mask/inactive-voxel handling, FixedOutside init-time restriction,
z-major-then-row-major NodeId layout), Grid3dSolver/Grid3dSolverBuilder (fix/domain/config/
solve/solve_all/solve_cancellable/get/decode_tiles — mirrors Grid2dSolver's API exactly),
cube symmetry group in symmetry.rs (Transform3d, 24-element proper rotation group and 48-element
full group, both generated by BFS closure from generators and verified for exact closure/order/
determinant in tests, not hand-enumerated). Validated by graph-vs-grid3d strict equivalence
(byte-identical assignments + observation counts across 10 seeds) — the same rigor as the
2D equivalence gate.

Deferred (not part of this phase, tracked for a later pass):
- extract_3d (3D overlapping-pattern extraction) — the 3D analogue of extract.rs's extract_2d.
- FaceSockets / socket-based tile authoring for 3D tiles.
- support(SupportConfig) / navigable(NavConfig) solver presets (these are ReachabilityConstraint/
  ConnectivityConstraint presets — blocked on the constraint framework, phase 7).
- Octree/sparse-volume adapters (phase 12 scope).

None of these block using Grid3dSolver today for explicit tiled models (TiledModelBuilder +
declare_stencil_relations_3d_tiled), which is fully working and tested.
