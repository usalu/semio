CONFIRMED MANUAL-IMPL CASE
  ImperativeDocument carries a hand-written `impl vcs::DocumentDsl for ImperativeDocument` (not
  `#[derive(dsl::DslDocument)]` on ImperativeDocument itself — the derive lands on a local structural
  mirror `ImperativeDocumentDsl`, per the region's own doc comment explaining the orphan-rule
  constraint on foreign `Value`/`Step`/`Path`/`Dictionary` types). It therefore did NOT automatically
  gain `vcs::DocumentPack` from wave 1's dsl_derive expansion. Added a manual
  `impl vcs::DocumentPack for ImperativeDocument` in the `//#region 🔖️Pack` subregion of `//#region
  🔖️Dsl`, mirroring the derive-emitted shape from wave1-report.txt §2 exactly: routes through
  `vcs::pack_rt::{encode_document,decode_document}` using `ImperativeDocumentDsl::__dsl_spec()` /
  `mirror.__dsl_to_record()` / `ImperativeDocumentDsl::__dsl_from_record()` (the mirror type's own
  derive-generated trio, since `Self` has none), `.map_err(vcs::text_error_to_pack_error)` on decode,
  same mirror-struct construct/destructure the existing `parse_dsl`/`print_dsl` impl already uses.
