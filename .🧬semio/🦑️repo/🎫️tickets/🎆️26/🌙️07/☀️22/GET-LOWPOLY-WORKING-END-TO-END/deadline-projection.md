## Final Authority Semantics

An envelope is deadline DATA, not a serialized resource-control capability. Its schema has no issuing-scope or cancellation identity. The actual CURRENT privately issued control, its parent ancestry and any explicit followed control remain the cancellation/lifetime authority. Caller environment materialization occurs before a final current-control check, so an enumerable getter cannot cancel that current control and still return a handoff.

A live broader control may use valid narrowed envelope data emitted by another now-retired or cancelled scope, subject to every numeric bound and its own actual authority. Cancellation of another independent scope does not cancel this live control. An application that requires another control's lifetime must explicitly retain/follow that control through the owned APIs. Cancellation or retirement of the CURRENT actual control always refuses projection, regardless of identical wire data.
