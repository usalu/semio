# Flood Cursor Grant Protocol

Common authored schema: framework/pixels/✍️editing/🪣️flood/🧬️schema/🔣️.json. This records the shared turn data projection, independent of Rust Result representation or TypeScript object syntax.

## Exact TypeScript API To Match Native

Constructor remains metadata-only new FloodRegionCursor(width,height,x,y). demands(maximumWork) quotes {copyBytes,capacityBytes,releaseBytes,depth}. advance(source,maximumWork,grant,cancelled=false) returns {work,result:{ok:true,value:{work,completed,total,done,progress}}} or {work,result:{ok:false,error:{kind,message,progress}}}. Grant fields are maximumItems/maximumCopyBytes/maximumCapacityBytes/maximumReleaseBytes/maximumDepth. Progress receipt fields are copiedItems/copiedBytes/retainedCapacityBytes/releasedBytes. Error kinds match native ValueRefusalKind.as_str: invalidValue,canceled,ownershipLimit,allocationFailed. There is no old overload or missing/default grant; expected refusals are outcome data rather than thrown advance exceptions. Constructor/result-read precondition exceptions are not work turns.

Native equivalent is demands(maximum_work), advance(source,maximum_work,RetainedCloneGrant,cancelled)->RetainedWorkOutcome<FloodProgress>. ValueError carries the exact failed-turn retained progress. Allocation attempts consume one real work unit including refusal; buffers already retained remain owned for explicit close. All denied grant axes return0work/defaultreceipt before binding a source or allocating. Source identity/extent refusal also has no domain work or allocation. Cancellation revokes result availability while keeping every workspace buffer for closure.

Native allocation quote is one seen/mask buffer Nbytes or one queue4Nbytes. A retained allocation beyond its quote refuses after recording actual capacity and retains backing for paid close; failure never drops original buffers. Initialization quotes at most2*work+5 data bytes; BFS quotes at most32*work data bytes bounded by remaining whole pixel extent, not only starting frontier, because new neighbours can be consumed in this same turn. These data bounds and actual backing capacity are common. Actual receipts must be dominated by the current quote; successful outputs never become public before completion.

Metadata byte cost is representation-specific: native uses2*sizeof(cursor), including its retirement state.
