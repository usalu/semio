  - It filled up completely at least three times. Each time every agent stopped, and once the session restarted and all agents had to be resumed.
  - I prune build dirs repeatedly.
  - At one point someone deleted the ticket's `🗑️generated` folder mid-build, so its scripts were lost and had to be recreated at the ticket root.

- **Agent mistakes, caught and corrected:**
  - Weakened tests and raised fixture stocks without proof; both were reverted.
  - Debug code that allocated inside measured windows.
  - One agent's change broke `history_edits_end_to_end`; that was fixed.

- **Limits on adding more agents:**
