# Digest batching verification

Scope: `ArtifactCanonicalRecordDigest` (up to 64 encoder steps per unit) and `NativeEditDigest` (up to 64 framed bytes per unit), see `report-replay-performance.md`.

## Oracles

- Independent oracle: Python `hashlib.sha256` over the length-framed canonical JSON bytes (`json.dumps(ensure_ascii=False, separators)`), generated by `digest-batching-grid.py` into `store/🧵️canonical-edit/🔏️borrowed-digest/🔣️grid.json`. The Rust test additionally checks that `serde_json` produces the same canonical byte length as the fixture, so the canonical form is validated by a second third-party implementation.
- Whole-value reference: `CursorRevisionAccumulator::edit_digest` (non-batched, hashes the complete value in one call) for `NativeEditDigest`.

## Laws added

1. `batched_record_digest_matches_portable_oracle_over_the_size_grid` (canonical-json): strings of every length 0..139, 180..269, 500, 1000, 4095, 4096, 4097 (mixed escapes, multi-byte, control characters, so 64-step boundaries are crossed at every offset), each driven under grants of 1, 2, 3, 64, 65 and 1000 items per turn; the digest bytes must equal the hashlib digest.
2. `batched_edit_digest_equals_the_whole_value_reference_over_a_size_grid` (ledger): edits with 0, 1, 2, 3, 5 forwards, edit-id lengths 1..139, 255, 256, 257 (framed byte counts around the 64-byte unit), grants of 1, 2, 64 and 1000 items; must equal `CursorRevisionAccumulator::edit_digest`.
3. The pre-existing fixture laws (`native_edit_digest_preserves_single_and_chained_contracts`, staged inverse, effective digest, original id hash corpus) were kept unchanged and still compare against the hashlib fixtures.

## Port of the stale tests

All assertions were kept. API drift handled:

- `semio-os-store-canonical-json`: native text retirement test now steps the `ControlledRetirement` through `drive_reply` (`step_into`/`recover_step_into`) with the heap/receipt equality assertion kept.
- `semio-os-store-ledger`: new test-only adapter `🧪️effect/🦀️.rs` (`poll`, `advance`, `close_owned`) runs effect-shaped actions under a real original action via `semio_framework_value_clone_source_testing::drive`, which itself asserts the physical heap equals the receipt (stronger than the old `observe` checks). Depth is clamped to the effect bank stock depth (1024).
- Inverse settlement test: the test issuer implements the current `ArtifactOwnedValueRetirementFactory` (reply-shaped, quote = birth capacity, framed controlled retirement).
- Supersession test: a denied-axis step is skipped when the demand re-quoted at the denied grant is admitted (the body is now the grant's copy bytes, so a copy denial turns into a smaller chunk, not a denial).

## Product bug found and fixed

`ArtifactStoreOperationRowsRetirement::demands` quoted the paged-list backing release as `{release_bytes, depth: 1}` and omitted the list's header copy bytes and node-path depth, so a grant of exactly the quote was denied by `PagedList::release_empty_page` forever (non-terminating close at the final vector release). It now quotes `PagedList::next_release_demand` (`ArtifactStoreOperationRowOwners::release_demands`).
