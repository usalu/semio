# Note staging directory admission audit

Attempt 35 linked the Note WASI component successfully. The driver reported 878 compiled units, a successful linker exit and one linked component. Publication then failed while acquiring the shared `resource-directory-admission:v1` gate for the fresh artifact-capture writer. The typed refusal records 5,001 ms of gate waiting against the authored 5,000 ms admission patience. The named per-artifact resource remained a no-wait fresh claim. This log does not identify the exclusive gate holder and contains no observed sweep event.

The lease retirement code can hold that exact gate exclusively while it inventories the directory, filters and sorts names and probes a bounded slice. The idle policy permits 64 candidates per ordinary slice and 256 under pressure. Its 3,000 ms sweep budget is checked between slices, so it does not itself cut short a slice already holding the gate. The repository opener writes a cross-process sweep stamp before running the sweep. These facts explain how a slow slice could cause a fresh opener to miss its deadline. The evidence from one failed run does not establish a sweep as the holder or persistent starvation.

The publication helper admits both writers before it invokes the stage callback and releases any writer already held when acquisition fails. The fresh-writer acquisition does not automatically retry a directory admission timeout. Its SQLite replacement retry and full-store relief retry cover different errors. The managed staging invocation can be rerun safely after it settles, reusing eligible compilation outputs.

For a repeated gate timeout, the existing per-invocation `SEMIO_LEASE_ORDER_POLICY` option supports a file based on the authored policy with only `gate.admissionPatienceMilliseconds` extended. Its schema accepts a finite value up to 600,000 ms. This changes how long that process waits for the shared directory gate while the exact fresh target still uses one no-wait attempt. The repository's process-level admission tests exercise that distinction. No changes were made to the shared policy, lease state or production source.
