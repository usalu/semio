# Paged Natural Source Execution Contract

The staged paid natural-file factory uses ordinal 22 and schema `framework.reserved.import-natural-source.v1`, with Artifact and Child publication lanes. Declaration registers it for apps with a positive paged decoder extent. Mounted dispatch resolves its exact framework-owned row by tool key, schema, contract and factory type. The prepared request carries the same proof to the SDK builder and decoder. The mounted producer permit and Pack exporter both inherit the registered output ceiling.

The 9,437,877-byte PDF fixture is inside the editor’s 16 MiB selection bound. Decoder progress uses the exact authenticated source extent and the job permits up to 32 MiB of retained output, which covers the fixture’s 9,437,184-byte grayscale image. The factory allows 8,192 decoded items, 4,096 work units per step, and the existing 7,500 µs step deadline. The action bus requires positive raw-wire bounds, so this factory declares a one-byte ceiling. Both the SDK builder and the decoder handoff require an empty raw body. The ordinary `import-media` factory keeps its 8 MiB raw and output ceilings.

Ajv validated the neutral fixture. SQLite independently agreed on all 18 cases, and the Rust harness passed the same 18 plus a contract validity check using the production contract validator. The Rust harness compiles the staged request predicate and actual decoder progress method. The regenerating script also checks that the natural key reaches the staged wire headers, registered request, mounted producer and publication frontier, and that the registered output bound reaches the Pack exporter. The eight existing SDK admission cases and the combined patch apply-check also passed.

The combined SDK changes remain staged in the ticket. Mounted Store publication with the actual PDF is still pending. The host’s durable archive is a separate consumer of the first Store frontier.
