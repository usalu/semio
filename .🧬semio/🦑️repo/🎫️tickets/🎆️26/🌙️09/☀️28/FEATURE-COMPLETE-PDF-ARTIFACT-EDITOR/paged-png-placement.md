## Verification

The focused linked writer probe used two real repository `PagedBytes` sources reloaded from the paid fixture's output files. The 1,051,276-byte RGBA PNG supplied 786,432 straight RGB octets and 262,144 alpha octets. It wrote a 1,049,403-byte PDF with one image, one soft mask, and physical mask generation 9. The harness injected short writes, zero writes, interruptions, and backpressure. No source read exceeded 4 KiB and no emitted stream write exceeded the 911-byte test grant. Pillow 12.0.0 independently derived the exact paired digest. MuPDF 1.26.7 reopened the result without repair, resolved the soft mask and matched both streams byte for byte. Every composited RGB channel was within 2/255 of Pillow. The physical PDF dictionary and xref confirmed generation 9, which the MuPDF API normalizes on lookup.

All source files passed the repository-pinned parser. The ready-to-link `paged-png-placement-probe.rs` additionally exercises canceled Pack rejection, reopen from real paged custody, exact PDF mutation apply, undo and redo, and the authorized Save reloan. The current governed native cache has no linked Pack result, so that probe and the mounted app path remain unverified. The independent MuPDF test covered the actual writer and paged plane identity without going through the staged Pack.
