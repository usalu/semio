# Retained PDF Content Program

`ContentProgramCursor` consumes the production `ContentTokenCursor`, retains authored font selection and the graphics save/restore font stack, and publishes successive native `PdfOp` values in authored order. The reference `parse_content` retains its public API and shares the fixed operator interpreter, named and numeric operator construction, font transitions, and text-showing shapes with the cursor.

A controlled turn uses `advance(source, fonts, CosGrant, cancelled)` with the same borrowed decoded stream and font table across turns. `OperatorReady` lends one typed output until `take_operator` transfers native custody. The caller invokes `begin_close` and `close_step` after completion, cancellation, error, or a deferred operator. The cursor reports lexer and semantic work, specific allocation and release demand, and acquired and released capacities. It stages strings by byte, numeric arrays by item, and text arrays by item and nested string byte. It retires token values through the production COS retirement cursor. Nested text-array operands and unsent typed output drain without a whole-array drop in one turn.

Supported operations include fixed vector geometry, line and clipping controls, device and component colour, dash arrays, selected resource names, text controls, font selection, and graphics save/restore. The retained string branch preserves printable ASCII text and binary numeric codes for unresolved fonts across `Tj`, `'`, `"`, and `TJ`. Resource references such as `Do` preserve their authored names as typed operations. Resource resolution and rendering occur downstream.

`Deferred { start, end }` retains exact operator position and operand custody for font-backed transcoding, inline-image framing and sample decoding, unknown operators, property lists, and resource names longer than the 128-byte atomic copy bound. These stages still need controlled drivers. This cursor begins after stream decoding and is currently an importer prerequisite. Page assembly, mounted publication, and whole-document import are outside this change.
