The staged kind-241 receiver is an Original Source child of the exact live native instance. ## Paid custody and terminal receipt

Prepare moves only static descriptor and loan data under the granted Original Source and admits no body. Begin establishes paid destination custody. The raw page cursor includes the captured instance, generation, sequence, kind, exact extent and fixed page geometry. The guest validates those coordinates and the next unacknowledged page before taking the caller's fixed backing. It retains that backing across partial copy, returns it through controlled retirement, and advances the receipt frontier only after the backing is terminal. Duplicate and out-of-order input remains with its caller. Close retires staged raw backing before paged destination custody. The authenticated lifetime close already waits for the app and other close peers to become terminal, and then drives this receiver before returning the Original command Source.

Complete requires every selected page receipt. It leaves a sealed source pending for format admission and can move the same `ControlledRetirement<PagedBytes<N>>` under a paid source effect. The receiver keeps the terminal outcome pending while the format owner holds it. It records Published or Failed only through a guest format callback after actual publication settlement and format owner closure. A cancelled format owner must become terminal before the Cancel acknowledgment is accepted. The caller must retain the completion or cancellation receipt route across turns.

## Launch authority and ABI

The mounted starter Store makes `original_media_live_document()` return a revision immediately, even for a fresh app. Its revision provides no launch authority. The staged ABI adds typed `ActorInstanceOpenPurpose`, with `Ordinary` and a `NaturalSource` payload containing exact declaration and extent. The typed slot routes require a paid `arm_natural_source` call from the authenticated creation path. It compares the selected file to the app's real paged decoder declaration and budget, then binds the exact extent in a private instance slot. Prepare checks that slot before constructing a loan. The creation route still needs to carry the purpose and obtain the actual app's paged capability. The base PDF declares its codec fields today. It still needs a separately asserted source budget that fits the actual mounted decoder path.

The event contract has `natural-source-prepare` and `natural-source-control`. The ingress record has an optional `natural-source-ack` field. The owner is the numeric instance ID widened to u64, and the sequence remains one nonzero u64 from Prepare through the terminal turn. The exact operation and generation in the loan are 16 lowercase hexadecimal characters. The control enum is `begin`, `complete`, `cancel`. See the Rust DTO and WIT generator for the full shapes.
