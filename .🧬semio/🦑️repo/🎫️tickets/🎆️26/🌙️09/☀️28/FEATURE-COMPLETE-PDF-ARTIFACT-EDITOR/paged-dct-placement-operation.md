# Sealed PDF DCT Placement Operation

The staged [operation layout](paged-dct-placement.schema.json) places the exact native JPEG and the two registered PDF mutation frames in one closed Pack source. It extends the native install layout with a terminal, independently verified identity chunk containing the captured revision and bounded `SetImage` plus `AppendPageContent` or `ReplaceContent` frames. Both directions use the actual PDF 1.7 `PdfMutation::OpBinary` implementation. The typed image body holds the existing digest-based `ArtifactRef`. Opening the source checks the artifact reference, image metadata, paint name, operation shape, and exact DCT payload without inserting a body into `PdfSnapshot.objects`.

`PdfDctPlacementOperation` lends the verified source through the existing `ArtifactPreparedOperationSource::Pack` API as one `Bytes64` field. Its projection borrows `FieldProjectionView::BytesSource` from the retained paged owner and identifies the original allocation. Tag 61 is proposed in the draft schema. PDF 1.7's current mutation aggregate declares tags 1 through 60. The probe checks the real source variant, field identity and original address. It does not run the complete outer Original operation encoder or register the draft tag in the live aggregate.

## Verification

The probe links the repository's actual PDF 1.7 mutation aggregate, VCS reducers, SPR history codec, Pack, and paged value packages from the cached native build. It sealed the 2,125,603-byte JPEG with the two original PDF operations, dropped the input owner, and reopened the file into the real native paged byte owner. A stale revision was refused. The stored Pack was 4,498 bytes larger than the JPEG and transferred no source window larger than 4,096 bytes.

The probe applied the decoded `SetImage` and `AppendPageContent`, derived and applied the real inverse rows, and replayed the original forwards. It did the same for replacement with `SetImage` and `ReplaceContent`. The undo snapshots exactly matched their respective prior snapshots. Both redo snapshots matched their applied snapshots. The PDF native object lane remained empty. Replaying image edits reused the one immutable archived JPEG reference. The same archive produced the original native payload after the affected placement was restored.

The probe also serialized the actual forward and inverse rows as one native SPR edit with the backwards section, reopened that edit, and used the reopened registered operations to apply, undo and redo the insertion. This checks the production history codec and mutation semantics without invoking a mounted application store. Pillow 12.0.0 and MuPDF 1.26.7 independently matched dimensions, exact JPEG bytes, the PDF DCT artifact reference, and original crop. MuPDF reopened an independently assembled PDF from the recovered codestream without repair.

Run `paged-dct-placement-stage.py` to generate the isolated source and cached probe arguments under `🗑️generated/paged-dct-placement`. The native harness is in `paged-dct-placement-probe.rs`. Run `paged-jpeg-oracle.py verify-placement-pack` for the independent comparison.

## Mounted Registration

`ArtifactStore::resolve_operation_wire` consults the installed preparation factory's `operation_wire_source` before the document's default `ArtifactOperationWire::semantic`. The default Original PDF route supplies canonical JSON. Attach the sealed typed operation at this override and attach its matching native receiving descriptor to the PDF 1.7 aggregate. The generic `ArtifactOriginalOperationBytes::admit_paged` and original edit message owner can then retain the operation's paged result. The binary aggregate's current reference archive path and the Original projection path must both decode the installed leaf to the same document action. Adding the tag and outgoing projection alone would leave that receive path unsupported.

One canonical store compare-and-install must admit the original paged install owner and the two prepared image/paint rows against the captured revision before either is visible. The installed event needs a durable lookup lease indexed by its DCT digest. Undo should reverse just the visible reference and paint while the reachable history retains that same resource lease. Replay after reopen must derive the lookup from persisted history. A canceled, stale, or failed transaction returns the private original owner to paid retirement. The existing `Emit` only accepts typed mutation rows and still requires that exact prepared-mutation and native-source attachment authority. Mounted event publication, mounted history replay, and paid cancel under that joined contract remain open. The staged probe uses genuine codecs and mutations and leaves live package sources untouched.
