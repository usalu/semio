# VT Viewer History Input Labels

The native VT viewer replay reported four leaf mutation schema refusals. The TypeScript runtime resolver audited the same authored mutation and snapshot schemas and found 32 nested label paths. The three COS object mutations each needed labels for Removed Roles, Modified Roles and Added Roles and for shared nested stream identity fields they reach. Output Intents needed labels for the fields of its profile artifact reference.

The four live schema postimages carry English and German labels only. Before release, removing `x-semio-ui` recursively yielded exact object equality with each preimage. The actual TypeScript input reader resolved all four mutation payload schemas, and independent Ajv accepted the same valid neutral witnesses and rejected the same invalid ones before and after. The four paths and their exact SHA-256 preimages/postimages are in `🗑️generated/vt-labels/receipt.json`. The language-neutral cases are in `🔣️vt-input-cases.json`.

The replayed Rust binary predates these four schema files and remains the original failing receipt. The runtime TypeScript and independent schema validators cover the released postimages. The archive and semantic replay failures have additional independent owner boundaries.
