# Progressive page-tree traversal

The PDF 1.7 Lifter drives the page-tree cursor in the ordinary import path. The cursor follows direct and indirect Kids arrays in document order, admits one dictionary or child inspection per work unit, and cites inherited media box, crop box, rotation, and resources by object and dictionary position. It suppresses duplicate and cyclic object numbers using the existing bounded xref index. Cancellation stops further reads, and closing reconciles the visited index's retained capacity. The native graph source lends its existing object values for traversal.

Branch resource events preserve resource naming in encounter order. The lifter first records the complete page order for destinations and annotations, then applies the existing page resource and text lifting to each emitted leaf. Whole-page semantic lifting and snapshot publication still run synchronously.
