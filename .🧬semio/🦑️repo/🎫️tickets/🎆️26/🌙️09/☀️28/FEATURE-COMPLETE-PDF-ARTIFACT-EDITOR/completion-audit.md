# PDF Editor Completion Audit

Read-only source and existing evidence audit on 2026-11-20. No builds or production edits. The ticket requires end-to-end editing of text, images, vectors, pages and properties through the typed snapshot and real mutations. Findings are prioritized by user impact and may change as the shared worktree changes.

1. **Ordinary large PDF imports can fail.** The controlled lift currently qualifies resource-free, text-free content; its barriers include text-bearing programs, nonempty resources and annotations, and advanced fields (`📋️controlled-document.md`). The mounted importer treats deferred lift and `ReferenceRequired` as errors instead of using the synchronous reference route (`mounted-import-audit.md`). Extend bounded decoding, semantic lifting and publication to ordinary font, image, annotation and reference-path cases, with mounted progress, cancellation and reopen tests. The same audit identifies an insufficient-grant zero-progress path that can be classified as a stalled import; reproduce with actual grants and fix the yield/demand contract.

2. **Page paint substitutes content.** `✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📖️pdf/🏅️standards/7️⃣1.7/🪆️subsets/🧱️base/✏️editor/🖼️page/🗺️scene/🦀️.rs:72` maps all fonts to three unrelated UI font families. The same file at 115–126 paints a rectangle and label when image, form or shading preview fails and for annotations. Implement faithful font glyph and appearance/resource rendering, with independent raster comparisons for embedded fonts, image encodings, form/shading and annotation appearances. Existing verification also identifies general curves, multiple subpaths, text clipping and precise dashed stroke hit testing as remaining work.

3. **Registered end-to-end acceptance remains unproven.** `📋️verification.md` and `📋️mounted-pdf-e2e.md` document source-level and isolated independent checks but do not record a successful current mounted Open/edit/save/reopen and browser session. Run the registered native gate and real Chromium shell journeys, including text, image, vector and property edits, undo/redo, save/reopen, and independent checks of saved bytes. Other agents own the active native and browser gates.

4. **Named actions exceed direct end-user controls.** `✏️editor/🖼️page/🪟️windows/🦀️.rs:176` renders page fields and page ordering controls, or selected-object fields and delete; the larger command roster is not itself proof that each typed property has a discoverable, accessible editing control. `📋️page-editor.md` explicitly leaves raw snapshot fields for values without a named action. Audit the mounted command surface and snapshot details against the full typed schema, then expose direct typed controls and validate their persistence. The page inspector covers only a subset of object and document fields (`✏️editor/🖼️page/🔎️inspector/🦀️.rs`).

Existing fixture and harness evidence demonstrates real mutations and selected paint behavior; it does not establish complete rendering or user-facing reachability for all PDF details.
