## Authority through paid app creation

`select_turn_event` reserves the transfer of the natural open payload. `dispatch_turn_event` admits the exact actor lifecycle request and donates the typed purpose with app and actor to `PendingNativeCreation.source`. The existing opening runner authenticates that Original Source across turns. Once construction and issuer work finish, it asks the actual app for a static paged-decoder declaration and byte budget. It pays to project the exact offered declaration and extent into an inline launch grant, retires the dynamic original opening payload under the existing source close path, returns the opening loan, and installs the launch grant with the same `NativeLifetimeSlot` before exposing the native owner. The ordinary purpose takes the existing creation path. There is no revision placeholder in the natural grant.

The `PluginApp::natural_source_capability` default returns `None`. The actual PDF app has no paged decoder recipient on this branch yet, so a natural-source launch reaches a typed rejection and closes the unpublished partial instance. Its host receives no Prepare loan and must read no selected source body. The eventual mounted capability must name the real parser/format owner and its measured source bound. This is the remaining dependency for enabling the prepared Browser and native writers.

## Events, routing and retirement

The staged actor WIT carries `instance-open-event.purpose`, `natural-source-prepare` and `natural-source-control`, and optional `command-ingress-status.natural-source-ack`. Shared host/native event projection, retained component JSON lowering and inverse guest lift, WIT-to-kernel conversions, and canonical kernel reply projection preserve the shapes. Natural JSON lift checks the exact keys of the launch, declaration, Prepare, control and loan records. Operation and generation use nonzero, canonical 16-digit lowercase hexadecimal text for full `u64` fidelity.

The raw media prologue handles the natural controls and kind-241 fixed pages before generic command assembly. The lifetime's ordinary input authority, captured natural launch grant and mounted capability must all agree before issuance. The round-robin receipt lane advances staged pages, latched cancellation and completed format outcomes independently of host body reads. Cancel returns Retry until Closing can be paid. Once Closing is latched it suppresses the prior page or Complete receipt and drives the actual staged page and destination retirement before acknowledging Cancel. Generic assembly still observes its original command ceiling.

The format owner still needs to integrate `take_source`, continue under decoder and archive budgets, arrange cancellation of the donated source, and call `finish_format` only after actual publication and format retirement. The transport does not infer publication when the final byte arrives.
