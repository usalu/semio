# PDF Base 14 Outline Verification

The current page fallback renders unembedded Helvetica, Times and Courier with unrelated UI faces. The staged PDF font codec borrows the appropriate original CFF program from the pinned URW Base35 release for all fourteen standard faces. It keeps the document's original character encoding, Differences, explicit and standard widths, and embedded program. The repo's existing outline path carries the result to both renderers without adding a runtime library. The six resource crates each fit the source closure limit while keeping raw font data available without runtime decompression.

The asset preflight uses the upstream release commit `c15105598aa7eb256b1ebfcecd3d078801521e73`. Staged payloads are verbatim CFF tables of the corresponding OpenType sources, with the upstream license, license text, and original release provenance next to the font resource files. The repository itself uses AGPL-3.0. [Upstream font source](https://github.com/ArtifexSoftware/urw-base35-fonts/tree/c15105598aa7eb256b1ebfcecd3d078801521e73) · [Upstream license and document exception](https://raw.githubusercontent.com/ArtifexSoftware/urw-base35-fonts/c15105598aa7eb256b1ebfcecd3d078801521e73/LICENSE)

The production CFF interpreter returned all 54 sampled glyph IDs and geometry, including Greek Symbol and Zapf Dingbats. FontTools matched the IDs and contour boxes. MuPDF 1.26.7 matched the same 54 contour boxes and verified the PDF-to-viewport transform in the staged scene fixture. FontTools independently confirmed seven contours for the expected Hello glyph outlines. The source check ran 80 Linux, macOS, Windows and WASI library and test configurations. The largest asset closure is 247,499 bytes, and the largest code line count is 3,998 on the existing page editor test configuration. Pinned Rust metadata compilation used real cached PDF dependencies to check the staged font codec and all six WASI resource owners.

The source and asset overlays remain staged while the signed Open regression build runs. The actual page editor scene test and mounted PDF raster have yet to run with these programs. The separate symbolic stage admits canonical simple Symbol and Zapf Dingbats descriptors and preserves their original single-byte codes. The staged font codec resolves Dingbats text using the Adobe glyph names. FontTools and MuPDF agreed on 200 contour boxes for those Unicode mappings. The remaining a189 outline differed by 0.002 em. The PDF workspace manifest and lockfile candidate are generated by default. Other workspace lockfiles carrying the fonts crate still need regeneration together with installation.
