# Controlled Resource-Free PDF Document Projection

The production lift now exposes `DocumentLiftCursor::controlled()`. The controlled cursor borrows a stable native graph, admits exact work and memory effects through `CosGrant`, and returns a complete typed `PdfSnapshot`. Its result leaves the retained raw graph, raw trailer, and encryption lanes for the outer importer. The existing lift remains the cold route for documents outside the qualified subset.

The cursor reads catalog, Info, inherited page geometry, and shallow page dictionaries from retained storage. The admitted metadata includes catalog version, layout, mode, language, simple MarkInfo, direct normalized Info fields, document ID, inherited MediaBox/CropBox/rotation, other direct page boxes, UserUnit, duration, structure-parent index, and shallow device-space transparency groups. The expensive typed lanes stay empty only after qualification. Absent resources and explicit empty direct or referenced resource dictionaries qualify. The tested page supports empty annotations and page actions.

For authored `/Contents`, the cursor emits the canonical page/Contents operator role and ordered exact-generation dependencies. It walks the physical Parent chain to exclude font dependencies and resolves the stream owners in authored order, including direct or referenced arrays of indirect streams. It accepts normalized stream dictionaries with no remaining entries. The native snapshot owns two operator vectors, one for the page and one for the role, so the current route drives the measured program cursor a second time to construct the role. Typed snapshot and pending page ownership survive cancellation for outer retirement after the active page program and page tree close under grants.

Barriers preserve the cold route for unsupported resources, text-bearing programs, active and interactive features, nonempty annotations, foreign assets, advanced catalog or page fields, nonempty stream dictionaries, and provenance outside the controlled shape. The current qualification caps shallow dictionaries and role owners at 32, individual copied metadata at 128 bytes, and admitted declared page count at 16,384. A malformed undercount is refused. Normalized decimal page geometry and vector operands use stack scratch while preserving the reference conversion exactly. Oversized numeric operands defer with their authored operator span.
