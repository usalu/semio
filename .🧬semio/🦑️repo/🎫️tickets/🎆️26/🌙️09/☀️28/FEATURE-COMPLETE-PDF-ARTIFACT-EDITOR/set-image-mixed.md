## Remaining schema work

The staged intercept selects one numeric path from one tagged leaf. Applying it to other payloads requires a schema-selected projection plan for alternate variant layouts, nested arrays and dynamic records. Their entry access needs a paid view of the complete key/value tuple so map receiving observes the substituted child. The staged grammar's non-projecting paths still allocate their current contiguous JSON collections. Production also needs the archive cursor to validate the same backing and range on every turn across projection, typed receiving and retirement, and to deliver typed failure through its actual Original receiver. The measured copies justify replacing per-element generic ownership transitions with a grant-bounded primitive receive lane before mounting RGB.
