# Paged JSON Number-Array Source

`paged-number-array.json` declares the input as one numeric array within an exact borrowed source span. The parser borrows both the full source and the selected span for its lifetime. It advances one grammar action, one page reservation or one reserved placement per funded action. The implementation uses the existing JSON number cursor and paged-list reservation and push APIs. It preserves signed, unsigned and floating JSON numbers and their wire order. Its result implements recorded `NativeValueSource` scalar requests and borrows numeric children directly from their original paged backing. Errors and cancellation retain unpublished pages for paid retirement.

## Executed evidence

- The full neutral image JSON is 8,388,811 bytes. Its selected field contains all 4,194,304 original numeric items. The largest retained allocation was 4,096 bytes, compared with the mounted 16,777,216-byte capacity ceiling. The probe accounted for and released all 73,959,848 bytes of numeric page backing. Retirement wrapper allocations were funded and released separately.
- The probe checked exact signed, unsigned and floating numeric kinds, separators and malformed arrays. The existing JSON number lexer supplied values and the independent serde_json parser checked accepted specimens and their numeric values.
- Short copy and page capacity loans do zero work, touch no backing, and leave the quote intact. Cancellation after the first page reservation leaves that page for paid retirement. The source pointer remains the same through the selected nonzero range.
- A separate test passed the paged input through the actual `NativeSourceReceiving` machinery, including its Original Work recipient and source witness. The native output was `Vec<u32>` with values 0, 17 and 4,294,967,295. The full large-image run verified the paged source, while this smaller run verified typed selection, work and handoff.

The current per-action proof charges 60,711,495 source work units, 21,005,383 copied items and 2,726,105,912 cumulative copy bytes for the large sample. It fits the per-turn loan but exceeds the native acceptance fixture’s cumulative 16,777,216 item and 134,217,728 copy stock. The proof therefore uses a larger finite source stock while preserving the live outer turn quantum. Production needs a page-sized native field admission and chunked parsing/placement, or a compact retained source representation that can preserve logical numeric positions without placing a new native scalar node for every input element. The current framework paged push API prices the one-node handoff each time.

## Integration boundary

The pack JSON staging adds `JsonNumberArrayCursor` and `PagedJsonNumbers` with existing library dependencies. The archive cursor cannot retain a self-borrowing Rust field through its current lifetime-free `OpBinaryReceivingCursor` contract. The embedded grammar can own array state and borrow the corresponding bytes each turn, using its current Original source pointer, range, ledger and source-turn witness. It should enter an embedded form at the opening bracket and resume on the exact closing-bracket end offset. The standalone span parser requires exact consumption and only allows JSON whitespace after the closing bracket.

The existing PDF mutation tag identifies the leaf schema before body decoding. For tag 26 the schema can select `image.body.values` as the numeric array field. The enclosing grammar needs to retain its key path and duplicate checks, validate the image body discriminator and the outer mutation discriminator, and publish the paged array via the mixed object source’s recorded field and child queries. The standalone cursor does not select a path from a mixed object. The format-1 writer and tag table stay intact.

The production destination also needs a decision about field storage. The current grayscale fixture requires exactly 16,777,216 bytes for its typed `Vec<u32>`, consuming the full mounted single-turn allocation allowance. Larger allowed arrays need a page-backed typed destination or an independently quoted backing reservation that fits the actual host policy. The demonstrated small native binding uses the existing typed Vec receiver.

`paged-number-stage.py` stages two digest-guarded framework paths without applying them. `paged-number-check.py` builds the isolated executable using the cached native framework and pinned rustc. It derives the fixture’s exact array offsets outside the production parser and runs the tests against the full immutable JSON source.
