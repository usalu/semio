# Original Media and DCT Audit

The existing route is not an end-to-end bounded picked-image transfer to an existing PDF edit. WIT `🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🧬️schema/📜️reactor.wit` stages one command page per poll, and the original media branch in `⚛️reactor/🏃️runtime/🔄️exchange/🔀️plugin-exchange/🦀️.rs` locates the same instance and advances `advance_original_media_import`. Its retained command owner and paid retirement are in `⚛️reactor/🏃️runtime/🎞️command/📥️custody/🛂️manifest/🦀️.rs`. However `⚛️reactor/🏃️runtime/🧰️ops/🎞️media/🦀️.rs` still builds a media artifact from a contiguous Vec, while the original instance implementation in `🧵️instance/🔌️plugin-app-impl/🦀️.rs` delegates to the reserved media producer. The default natural-file route imports a document, not the selected image at a captured PDF target. I found no existing contract binding a picker stream to the insertion job and its full revision across transfers. Staging command pages alone does not establish that contract.

A PDF DCT image can reuse the existing representation without stored pixel arrays: `✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📖️pdf/🏅️standards/7️⃣1.7/🪆️subsets/🧱️base/🧬️schema/📸️snapshot/📐️model/🖼️xobjects/🦀️.rs` has Artifact reference bodies; `🔨️modules/🖼️images/🎞️controlled/🦀️.rs` hashes a qualifying DCT stream incrementally and makes two roles referencing it; `🚪️io/📦️foreign-artifacts/🦀️.rs` defines the exact DCT digest and native graph custody. This requires a matching graph object, not merely an ArtifactRef. Its current stream body is Vec<u8>, resolution clones it, and `✏️editor/🖼️page/🔆️image-preview/🦀️.rs` synchronously decodes full samples before reducing the preview. Thus the representation exists but bounded insertion, transfer, rendering, export and retirement are not established for a large photo. The DCT qualifier only checks simple dictionary/filter shape and JPEG endpoints; complete JPEG validity and dimensions require an actual bounded parser.

Smallest reusable schema-first direction: add an instance-scoped original media import ticket with immutable document identity, full base revision, edit target and generation; ordered bounded pages, explicit completion, progress and cancellation; source-to-job ownership and stale-publication refusal. Both React and WGPU picker adapters must drive that same contract. Add paged owned stream graph custody and an incremental JPEG validator/metadata/hash producer that installs exactly the existing DCT identity and image plus graph object in one revision-guarded history publication. Supply incremental/host-independent image preview and paged export/retirement paths; PNG requires bounded decode and alpha/mask handling. Add language-neutral multi-page, wrong-owner, duplicate/gap, stale and cancellation fixtures, independent JPEG/PDF comparisons and >=1 MiB host tests. Existing infrastructure supports pieces; this audit did not execute a build or prove host coverage.
