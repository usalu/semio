# Original guest ingress for a picked PDF image

The staged guest receiver accepts one real `FixedCommandPage` at a time. A one-shot picker intent keeps the target supplied by the Base editor, the instance, the document, and the complete 32-byte PDF revision before the host starts reading. Begin compares the intent with the live document and admits the actual caller Source. Every later page validates the Source and the captured transport cursor. Renewed turns borrow the same retained page and copy from its paid offset into the existing `PagedBytes` owner. A page is acknowledged after its entire body has landed and its incoming backing has retired.

Completed custody moves the original paged bytes, target, and live revision seal into one format input. Its Source and full PDF revision are checked again before the format job can borrow it. A stale observation cancels that input permanently. A foreign Source with the same numeric operation and generation fails before it can move a page or publish the format input. Cancellation closes the retained stage page and the partial destination with the existing original close effect.

The static actor state meters receiver birth and placement. One copy byte or one work unit short leaves the recipient empty. Staging under a one-byte-short physical copy grant leaves the caller's exact page in place. The staged Base adapter keeps the current product's sampled PNG admission ceiling of 24,546 bytes and uses the existing `ImagePlacement`, `check_image_placement`, and `AppOperationContext`. It rechecks placement on the live snapshot before yielding the placed format input. The generic command transfer is also capped by the repository's assembled command limit.

## Executed proof

Six focused tests passed on the repository-built command-ingress, value, job, and job-testing caller libraries. The caller test issues and consumes the intent through the real `OriginalJobFixtureCaller`, keeps one resident Source dispatch across polling turns, and rejects a different caller with identical operation and generation values. Its exact input is a neutral 4,196-byte, 32×32 RGBA PNG carried as 4,096 and 100 byte pages. Pillow 11.3.0 independently confirmed every decoded RGBA byte and the two expected hashes in `original-media-guest-cases.json`. The real caller returned the identical original PNG and the issued target. It refused a one-byte revision change after handoff and refused later attempts to use the same output at the earlier revision.

The fixed-command law also passes a 4,097-byte specimen through nine copy turns of at most 512 image bytes each. It retires 11,016 bytes of destination and close backing plus 8,192 bytes supplied by the incoming two WIT page owners. Canceling after 512 accepted bytes retires all 5,608 bytes charged for destination and close backing plus the single incoming 4,096-byte page. The standalone paged source law still passes its 1,572,881-byte specimen in 385 source pages. The focused test uses 512-byte copy slices during image copy and a full ordinary grant for page close and acknowledgment because the close must fund its own quoted placement. The primitive receiver has a 2,848-byte paid birth placement for the fixed two-word test target and consumes 1,025 work units.

## Smallest registration path

1. Issue the per-instance picker slot from the typed `Pdf17EditorCommand::PickImage` path before publishing its existing picker effect. The guest retains the placement. At the command admission boundary, take the app instance from the current authenticated runtime lease, the document from `stores.store.envelope().id`, and the full revision from `stores.store.content_revision()`. The current picker effect completion returns geometry through the host. The raw path needs the retained guest slot before the effect is exposed, with an opaque outstanding request identifier in the host effect.
2. Register one product-neutral raw-media command family and fixed payload shape alongside presence, before `CommandIngressTurn::admit_first_generic_page` and `continue_generic_assembly`. Use the real live `NativeCloseKey` and `OriginalCommandOrigin::admit_step/validate` that the reactor already drives. Dispatch raw Begin, Page, Complete, and Cancel to the same instance slot. A Begin consumes one outstanding intent. Keep the transport owner, sequence, and dedicated kind from the authenticated ingress admission. The receiver validates command index and count, item count, instance and generation, total extent, and every page ordinal. The existing generic branch requires zero metadata and item count and treats byte zero of the first page as its command tag. Those generic rules cannot recognize a raw PNG signature. The new branch needs its own schema-declared kind and validation before generic assembly, with no `MediaIn` object in this route.
3. Keep the active transport cursor and terminal acknowledgment in the existing command-ingress supervision. The app instance supplies the issued target and owns the typed guest receiver. Its Source remains borrowed until its live or retiring slot and the format input have both closed. Same-instance supersession and instance close must run the paired original closure before returning the origin loan. Retries must retrieve the already accepted page or terminal response without a second page copy or job publication. The staged receiver tests establish no double placement. Actual reactor receipt persistence and displaced-page disposal are still required.
4. Let the browser selection-only host adapter and the native path worker drive the existing bounded sender protocol after registration. The file selection, I/O worker, and native/WASI command drivers still need to submit the new command and observe progress, backpressure and cancel. The one-page WIT allocation remains bounded by the existing 4 KiB extent. No raw host transport tag is assigned by this staged evidence.
5. Bind the completed output to a raw PNG decoder input with the same Source and live PDF revision. The live `PdfLocalImageImport` uses a data-URL `ImageDecodeJob`, and the lower PNG job currently stores a contiguous "owned source" buffer. The new actor reaches format-job authority without materializing a generic media buffer. A paged decoder source and mounted format factory are still required. After the raster is ready, the existing placement validation and SetImage, optional mask, and placement transaction provide the small PNG application lane. Large JPEG still needs the real compressed graph owner and digest, paged rendering and Save, and atomic graph/image/history publication. The staged input alone does not create a format job or mutate the PDF.

The source captures for the running browser and native gates remain untouched. The future guest patch overlaps the reactor's command ingress and instance-lifetime ownership code and the Base editor's active schema-5 owner. The separately staged archive integration already puts that editor test closure at 4,000 active lines, so keep the generic raw receiver in the existing ingress owner and measure the exact active test and library closures before registering the small PDF adapter.
