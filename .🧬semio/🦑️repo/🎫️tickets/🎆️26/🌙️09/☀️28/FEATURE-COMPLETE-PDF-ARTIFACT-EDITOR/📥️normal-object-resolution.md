# Controlled normal-object resolution

The normal-object cursor drives the original indirect object frame and borrows its typed dictionary while scanning for the first Length entry. A direct length enters stream framing immediately. An indirect Length emits one request carrying the exact object number and generation. Subsequent turns park until the caller provides that reference's length or selects bounded marker search. A mismatched or repeated response leaves the original request or completed stage intact.

The completed owner transfers the typed COS object and its original source span. It keeps cancellation and all retirement in the same grant system. The regular indirect resolver uses this handshake and keeps its existing owned raw-stream result. Retained import can pass the borrowed span into the cooperating decoder without making an intermediate copy.

The genuine PDF fixture declares Length as 5 0 R and includes the word endstream in its page content. MuPDF independently resolved the 53-byte length and matched every content byte. The exact production harness passed 37 tests, including one-work grants, a parked length request with no measured effects, wrong-generation rejection, callback uniqueness, and cancellation with exact retained capacity retirement.
