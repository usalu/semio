# PDF canvas vector and image editing

The PDF 1.7 editor previously painted every vector with fill and stroke. Its canvas used untransformed path coordinates while object selection used transformed bounds. The canvas now applies the transform active at each path operator and preserves the specified fill, stroke, and fill rule. Cubic shorthand operators retain both control points. Unpainted paths are excluded from the scene and object selection. Text bounds use the composed page and text transforms.

The editor now renders explicit DeviceRGB and DeviceGray samples in image XObjects and inline images through the canvas image primitive. It preserves the PDF row order, honors decode ranges, and reprojects the pixels through image placement and page rotation. Large previews use a maximum edge of 256 pixels. The existing sample replacement command updates the pixels at the original placement. The existing image-mask command applies color-key transparency. A sample becomes transparent when all its original components fall within the inclusive ranges, before any Decode remapping. Referenced 1-bit stencils and grayscale soft masks sample their own grids on the base image’s unit square, at the most detailed supported preview density. Soft masks override the image’s color key or stencil, and matte-preblended samples are recovered before PNG encoding. [PDF 32000-1:2008, sections 8.9.6 and 11.6.5.3](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf) The runtime uses the repository’s PNG and Base64 codecs.

PDF page text and canvas labels specify an explicit catalog font. Times and Courier map to the available serif and monospaced catalog faces. Other text and labels use Anta. The PDF glyph baseline travels in the same affine transform as the text bounds, including horizontal text scaling.

Form XObjects paint their own content and nested resources at the position of each invocation. The editor applies the form matrix, inherits the outer graphics state, and intersects nested BBox clips. Browser paint clips to the projected form quadrilateral and native paint clips to its logical pixel-center coverage using merged scanline scissors. Form hit testing uses the same projected quadrilateral. Form children remain part of the containing selectable form. Form expansion is bounded by the current recursion path, a depth limit, and a per-scene content operation budget.

Axial DeviceRGB and DeviceGray shadings with exponential functions use canvas gradient layers. These layers honor the declared shading domain and range, bounding box, extension rules, and drawing matrix. Nonlinear functions use sampled color stops.

The shared sampler is owned by the existing PDF image package. Rust source closure now measures 30 inputs and 945 active lines in that owner, 29 inputs and 3,905 lines in the production editor owner, and 16 inputs and 1,316 lines in the page fixture suite.

## Remaining rendering limits

The PDF 1.7 scene uses outline hit testing for vectors and bounds for some imported object kinds. Transparency groups, text-outline clipping, non-axial shadings, exact font rendering, and standalone stencil paint and profile-dependent and foreign-artifact image previews still need coverage. Image previews sample the retained grids without interpolation and do not use opacity embedded in an image codec.
