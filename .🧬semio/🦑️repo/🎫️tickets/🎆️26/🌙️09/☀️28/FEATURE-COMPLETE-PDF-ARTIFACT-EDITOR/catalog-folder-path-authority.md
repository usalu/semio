# Catalog Folder Path Authority

The configured local test data root is the ticket’s generated directory. The ordinary Shell and staged streamed Open resolve the same 64-character SHA-256 directory under `os/local-documents`. The longest physical journal sibling used by the staged native writer is `/.semio/.genesis-4294967295-ffffffffffffffff.stage`, which adds 50 UTF-16 code units. The previous placeholder reserved 64 and refused valid long data roots before attempting journal I/O.

The catalog now reserves the actual physical suffix. A focused law builds the current catalog code, checks the destination against independent Node SHA-256, and covers Mac-style and Windows-style paths with 256 and 257 UTF-16 code units. The 256-unit destination is admitted and the 257-unit one is refused. The ordinary and streamed catalog ordering law also passed after this change.

The mounted test suite supplies an explicit local data directory and disables Vite hot reload unless asked for, so the mounted run can persist into ticket-owned data while shared replica edits do not replace its React actor.
