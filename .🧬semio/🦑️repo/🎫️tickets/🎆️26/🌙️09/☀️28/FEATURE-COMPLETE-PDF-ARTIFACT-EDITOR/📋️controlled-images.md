# Controlled PDF Image Import

The controlled PDF 1.7 base importer qualifies one indirect Image XObject per resource dictionary. Direct and indirect resource dictionaries and inherited resources use the same path. Qualified XObjects carry positive dimensions, eight bits per component and DeviceRGB or DeviceGray with exact raw or Flate-decoded packed samples. The page program binds each `Do` to the qualified name. Up to eight distinct image objects can be admitted in a document. Pages can share an object when they use its established resource name.

The importer uses the existing sample cursor twice to obtain independently owned typed and provenance sample bodies. Each capacity reservation is charged as retained backing. Each actual sample write is charged one work unit. Publishing both bodies charges their inline movement and two identifier allocations. The provenance role owns the exact source object number and generation and its root dependency. Metered adjacent swaps preserve the reference reader’s image-role order before page operator roles. Cancellation before publication retires both sample buffers under explicit release grants.

The qualified resource shape defers forms, masks, codec-backed streams such as DCT, multiple resource categories, alias names for a shared object, and collisions between different objects under the same name. Stream contents with a missing image binding defer at the program boundary. Inconsistent sample geometry returns a structural error. The mounted underlying graph reader separately enforces its current byte-stream capacity rules.
