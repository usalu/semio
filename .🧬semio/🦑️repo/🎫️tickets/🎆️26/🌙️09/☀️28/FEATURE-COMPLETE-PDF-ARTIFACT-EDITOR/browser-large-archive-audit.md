# Browser Large Archive Audit

The current Browser archive route is whole-buffer and rejects the large fixture. `📺️renderer/🧑‍🎨engine/🧱️elements/🏛️ShellHost/📤️document-transfer-tabs/🔶️scope/🟦️.tsx` checks the live host session and plugin handle, captures the document identity, and checks it again around `readAppDocumentArchive`. `🗂️local-catalog/📥️artifact/💾️opening/🟦️.ts` then admits the archive, writes and verifies it, attaches, records the catalog and publishes, with close/unlist rollback. Its `core.writeLocalDocumentRef` implementation in `🛂️directory-route/🔶️catalog/🟦️.ts` opens a scoped worker actor, serializes `Array.from(archive)`, asks for revalidation after persisted status, and accepts only an identical returned archive.

The catalog has an 8 MiB base64 bound per pack/SPR field; the decisive separate canonical `DOCUMENT_ARCHIVE_MAXIMUM_BYTES` is 4 MiB (`📡️spr/🧵️channel/📦️archive/🧬️schema/🦀️.rs`, codecs, and folder worker). The cold pair is separately capped to 4 MiB aggregate and 64 pages of 64 KiB. The ordinary Vite `/semio-backbone` PUT collects a whole body capped at 4 MiB + 10 before `writeBackbonePayload` decodes it. `🏪️store/👷️worker/📁️folder/✍️write/🟦️.ts` serializes writes, detects external divergence, retries failures and only clears covered mutations after success. The dev host `🧑‍💻dev/🔌️vite-plugins/🗄️backbone-storage/📜️event-log/🟦️.ts` appends a framed FNV64 record to shared `.semio/events.semio`, removes incomplete tails, and fsyncs; its current scan, append and readback use whole buffers.

The smallest complete bounded seam is an operation-scoped page egress from the exact mounted Shell instance and revision into a folder-binding-owned staged append, with incremental frame/checksum verification, ordered commit under the existing document queue and divergence guard, and bounded readback of the committed same record before catalog publication. It must also provide a matching bounded load/reopen path; merely increasing the transport cap leaves archive codec, actor message and journal reads blocked. Preserve cancellation, actor/instance/generation authority, integrity and revision revalidation through commit.

The canonical bootstrap mirror reserve/stage/publish/retire has server-minted capability, epoch, descriptor/frontier and SHA-256 gates, but stages a whole bounded archive in SQLite; it is not a streaming journal. Existing `📤️SegmentedDownload/🟦️.ts` handles bounded output chunks but its save-picker sink requires user file authority and its Blob sink buffers pages: neither owns the catalog folder, its ordered event log or readback. No OPFS folder implementation was found in the inspected source. A temporary OPFS writer can stage bytes but cannot on its own substitute for the shared journal, folder permission and isolation, fsync and verified readback. Ordinary dev middleware folder route as inspected does not present the mirror’s epoch/capability gate; avoid treating its URI alone as equivalent scoped write authority.

Read-only audit; no runtime tests were run. Paths above are relative to `🧰️framework/🛍️products/💻️os/🔨️modules`.
