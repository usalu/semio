# G5, G7, G10: Segmented Input, Large Archive and Save

Status at the time of writing: integrated source plus laws. Build results are listed under Evidence; anything not listed there did not run.

## What changed in product source

### G5 decoder reads segmented input

- Installed the 40-path segmented parser overlay (`🗑️generated/pdf-compressed-byte-install-overlay.json`) with `📜️install-overlay.py`, which refuses any path whose live SHA-256 differs from the staged preimage. The PDF header, xref, structured file, normal projection, indirect length, stream data, Flate, LZW, ASCII85 and xref-stream cursors now take `&(impl ByteReadSource + ?Sized)`. `ByteReadSource` gained `contiguous_bytes()` so an already contiguous encoded body keeps its codec path and a segmented encoded body never coalesces.
- Installed the paged-octet retirement overlay (value list discard, retained-clone, retirement) so a paged source retires per 4 KiB leaf instead of per octet (2,305 paid leaf operations for the 9.44 MB fixture instead of more than 147,000 payload turns).
- Installed the decoder overlay for `NaturalPdfDecoder`: `source` is now `PdfNaturalSource::{Contiguous, Paged(NaturalFilePagedSource)}`, `admit_pdf_paged_natural_decode` donates the sealed page owner, `PDF_PAGED_NATURAL_SOURCE_MAXIMUM_BYTES` is 16 MiB, close and retirement demands defer to the paged owner. The overlay row for `✏️editor/🦀️.rs` had drifted (other agents edited it), so its two hunks were re-applied by hand: `PAGED_NATURAL_SOURCE_MAXIMUM_BYTES` and `admit_paged_natural_file_decode_owner`, matching the trait that the natural-source work landed.
- New law `paged_natural_decode_round_trips_a_large_original_image_exactly` in the editor unit tests, with schema-first fixture `🧪️tests/🧫️fixtures/🏞️large-original-image/🔣️.json` (+ schema). It generates the 9,437,877-byte neutral PDF from the law, opens it through the production paged decoder under a 16 MiB capacity grant, checks the retained image stream byte for byte, saves with `encode_pdf`, reopens the saved bytes through the paged decoder, and checks equality again. `SEMIO_LARGE_ORIGINAL_IMAGE_SAVED=<path>` writes the saved PDF for the MuPDF oracle.

### G7 archive cap removed

The 4 MiB archive authority was a set of independent constants. All of the persisted-archive chain now agrees on 16 MiB (the paged decoder extent and 32 MiB reserved-job output already assume that scale):

| Authority | Before | After |
| --- | --- | --- |
| `DOCUMENT_ARCHIVE_MAXIMUM_BYTES` Rust (`📡️spr/🧵️channel/📦️archive/🧬️schema`) | 4 MiB | 16 MiB |
| `DOCUMENT_ARCHIVE_MAXIMUM_BYTES` TS (`wire-contracts`), now independent of the 4 MiB backbone genesis message | 4 MiB | 16 MiB |
| History decode allocation (`document-archive-load`) | 8 MiB literal | `2 * archive` |
| `admission.json` archive, history allocation, transport limits and cases | 4 / 8 / 8 MiB | 16 / 32 / 24 MiB, plus a 9,437,877-byte case |
| Browser cold pair (`COLD_DOCUMENT_PAIR_MAXIMUM_BYTES`, pages) | 4 MiB, 64 pages | archive limit, 256 pages |
| Kernel `COLD_PAIR_MAXIMUM_BYTES`, actor `COLD_PAIR_MAXIMUM_PAGES` (Rust and TS) | 4 MiB, 64 | 16 MiB, 256 |
| Cold pair corpus (`⚛️reactor/📥️cold-pair` fixture and law) | exact 2+2 MiB, 64 pages | exact 8+8 MiB, 256 pages, SHA-256 recomputed independently |
| Local catalog base64 per field | 8 MiB | 24 MiB |

`ARTIFACT_MAILBOX_BYTES` and the folder worker, native actor, Browser actor and Shell scope checks derive from the same constants. Deliberately untouched: the backbone genesis message (4 MiB, still asserted by `📡️actor-backbone`), hub pending channel (1 MiB) and the 16 GiB folder record framing allowance.

New language-agnostic law `📡️spr/🧵️channel/🧪️tests/🧫️fixtures/📦️large-archive/🔣️.json` (+ schema): deterministic SplitMix64 content, three cases (9,600,187-byte archive above the former ceiling, exact 16 MiB, 16 MiB + 1 refused). Rust (new `large-document-archive` test target of `semio-os-channel`, `🧪️tests/🔬️large-archive/🦀️.rs`; the companion unit crate `semio-os-channel-tests` already fails to compile on stale decode tests, so the law is standalone) and TypeScript (`admission.test.ts`) both frame, encode, decode and compare FNV-1a64; TypeScript also checks SHA-256 and the Ajv schema. Oracle: `g7-large-archive-oracle.py` (independent Python framing, hashlib SHA-256, FNV) produced and re-verifies every value.
