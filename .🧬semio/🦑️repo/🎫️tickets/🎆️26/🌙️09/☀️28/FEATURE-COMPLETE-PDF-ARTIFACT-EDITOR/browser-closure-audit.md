# Browser Component Closure Audit

The real Stdio component is a cdylib invoking semio_hub_stdio::plugin. Its normal dependency semio-hub-stdio unconditionally depends on semio-hub-stdio-catalog. That catalog is explicitly the feature-free full catalog and unconditionally depends on both semio-s-artifact-stdio-ifc-catalog and semio-s-artifact-stdio-semio-catalog, alongside all other format crates. The IFC catalog normally depends on the 2x3 base, subsets, model, mutations, descriptors and inferences as well as IFC 4 and 4x3. The semio catalog normally depends on all subset import and export conversions, including BREP, CAD, mesh and model. These are production dependencies, not test-only activation or the PDF component selecting IFC.

The full catalog features full-artifact-catalog and component-app-assembly have empty dependency lists; disabling them does not remove the normal dependencies. A definition-only catalog exists and advertises the same commitment, but is used as a dev-dependency of the full catalog, not as a selectable provider for the shipped Stdio component. Substituting it would change production assembly and is not an existing supported selective capture route.

For a subsequent capture, reuse the successfully published repository-issued Stdio component artifact and its verified provenance; build only the changed PDF component via the existing component-closure driver if the current admitted Stdio artifact remains valid, and retain both Stdio and PDF in the session. A source drift or missing compatible publication invalidates that shortcut; do not substitute stale artifacts or omit Stdio. The current joint build should be allowed to complete, since no pre-existing compatible Stdio artifact was established. No build was run by this audit.

## DCT Overlay Impact

The captured w8jCBpl prototype Cargo unit graph and source-admission memos show that all four staged DCT files belong to units reachable by both components. The image root and controlled image file belong to semio-s-artifact-stdio-pdf-mut-base-4; decoded-stream and foreign-artifacts belong to semio-s-artifact-stdio-pdf-inferences. The shortest Stdio dependency chain for each is semio-hub-stdio-component → semio-hub-stdio → semio-hub-stdio-catalog → semio-s-artifact-stdio-pdf → the respective owner.

Reverse reachability intersects 42 of 1,491 Stdio units and 29 of 772 PDF units for the image owner; the inference owner intersects 57 Stdio and 44 PDF units. These are graph reachability counts, not predictions of actual cache misses or compile time. Therefore the earlier conditional PDF-only reuse suggestion does not apply to this DCT overlay: the changed sources invalidate the Stdio closure as well. Retain and rebuild/revalidate both components under repository artifact custody.
