# Incremental COS container assembly

The PDF lexer now parses arrays and dictionary prefixes through a typed cursor. The cursor preserves dictionary entry order, parses nested containers and indirect references, handles escaped names and literal or hex byte strings, and keeps PDF decimals exact. The normal lexer drains the cursor before applying its stream framing logic. A retained importer can drive the same cursor and move its result directly.

Each grant separately admits work, new backing capacity, and release capacity. The scanner advances by at most one byte in a work step. Name and numeric validation at token boundaries use the configured scalar ceiling of at most 256 bytes. Array, dictionary, and byte-string buffers reserve the next backing separately, migrate one entry per work step, then retire the old backing under its release grant. The cursor refuses excessive nesting, entries, strings, and scalar widths. On cancellation or syntax refusal it retains partial ownership until the caller walks release steps through terminal emptiness.
