# 🔭️ PDF viewer and navigation features

## Layout
- New crate `semio-s-artifact-stdio-pdf-page-editor-view` at `…/✏️editor/🖼️page/🔭️view` (lib `🔭️view/🦀️.rs`, modules `🔍️search`, `🖼️thumbnails`). Carved out because the page crate sits at the repo source boundary (32 files, 262144 bytes; adding the code inline measured 268834). Registered in `📖️pdf/Cargo.toml` members and `Cargo.lock`, depended on by the page crate, re-exported from it (`pub use …_view::*`), so every editor keeps using `crate::editor::page::…`.
- Pure and ephemeral, no document access: `ViewState`, `ViewIntent` and `reduce_view` (zoom in/out, fit page, fit width, actual size, go to page, set query, toggle match case, next/previous hit), `resolve_zoom`, `page_viewports`, `scene_for_view`, `find_hits` (cancel before each page, progress per page, partial hits kept), `step_hit`, `highlight_hits`, `thumbnails`, `reorder_args`, `render_thumbnail_strip`.
- Page-side glue (`🪟️windows/🦀️.rs`, region ViewGlue): `render_view`, `search`, `hit_layers`. `geometry` lost its own `page_viewports` and `rect_segments` (now the view crate's).
- Camera is the view centre; fit page and fit width hand the host a `Canvas2dFraming` (bounds, padding, revision), so the host fits its own measured viewport. Mouse wheel zoom and pan stay with the host.
- `main::render_windowed` (base and the six 1.7 subset editors) takes `(document, &ViewState, viewport, highlights)`; the discarded `windows` and `locale` are gone.
- Thumbnail strip window `pdf.thumbnails` ("Pages" / "Seiten") is in the shared `document_layout` and registered in all seven 1.7 editors.

## Drag reorder (framework contract found)
A drop fires `Trigger::Drop` on the target row; the intent carries the dragged row's `drag_data` map (text values) as `input`, and the framework merges it into the action arguments (BIM outliner: `DRAG_ELEMENT_MIME`, `setField`). Thumbnail rows are draggable tree items with `drag_data {page: n}` and a Drop binding `move-page {x: n}`. `move-page` now accepts `page` as text (the payload is text) and its `page` argument is no longer declared required.

## Tests (language-agnostic)
`🧪️tests/🔬️unit/🧪️viewer-navigation.json` drives six tests in `🧪️tests/🔬️unit/🦀️.rs`: zoom modes and steps, camera and framing, search, cancellation, hit navigation, thumbnails and reorder, and the `script` of view intents. `viewer-navigation-oracle.py` (Python `re`) reproduces the search expectations and passes.
