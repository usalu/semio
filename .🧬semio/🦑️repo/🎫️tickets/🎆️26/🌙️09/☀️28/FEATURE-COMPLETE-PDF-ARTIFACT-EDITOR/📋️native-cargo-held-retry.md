The other reached the new retained ImageBuilder call before the matching shared provider landed. The existing warm browser component pass already requires an exact compiler read checksum mismatch before it retries under the held lease.

The staged native adaptation preserves both Cargo output contracts. The streaming launcher observes the diagnostic header it already forwards. The capture launcher observes its existing bounded stderr. Both require ordinary Cargo exit 101, an eligible Rust compiler diagnostic, and an actual failed compiler unit in the admission broker. The broker already records each unit's original extern artifacts. The existing bounded dependency checkout now accepts those actual filenames directly. It reads Rustc dep-info and compares the recorded BLAKE3 against the current source. Signals, cancellation, exhausted disk, failed tests, and diagnostics without actual checksum drift do not qualify.

The candidate keeps the native Cargo profile, storage, jobserver and broker leases through the retry. It captures a fresh compiler graph, repeats bounded source admission, and checks the graph again. It accepts the replacement only when both fresh observations agree with the original selection. Disk capacity stays on the existing retry path. The existing bounded attempt policy refuses repeated identical witnesses.

A focused executable compiled a real Rust provider with checksum dep-info, then changed the same source. Its consumer failed with E0599 against the earlier library. The staged scanner found the original compiler's exact changed file. The retry rebuilt the provider and the consumer then compiled. A current dependency and unrelated or quoted error headers produced no retry. The native launcher now uses the repair. Its exact staged module loaded with the repository's real imports before installation, and the repository Cargo entry point loaded after installation. The next governed native run uses the live implementation. Full ingress recovery still needs an eligible compiler failure and a verified held retry.
