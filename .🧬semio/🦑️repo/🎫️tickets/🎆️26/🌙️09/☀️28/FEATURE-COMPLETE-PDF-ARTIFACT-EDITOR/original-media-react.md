# Browser Original Media Picker Host Adapter

The staged React adapter consumes the original media descriptor under the existing RequestFileOpen effect's `args.originalMedia`. It uses the browser's selection-only picker and retains its File without reading it during selection. The actor issued the instance, document, operation, generation, full 32-byte canonical revision, byte ceiling and raw command kind. The editor keeps its image placement. An ordinary file-open effect continues to use its existing import path.

Each raw ingress exchange captures the exact existing activation, document binding and one actor transport sequence, then uses `PluginRuntime/🚚️handle-turn-drive/🟦️.ts` and the normal per-actor ingress serializer. The host reads one Blob slice of up to 4,096 bytes outside the serialized crossing. Begin, Complete and Cancel use the same actor event lane. Page uses a real `ShardCommandIngressPage` with the asserted amount, exact count and ordinal, host cursor, raw kind and original bytes. The actual component bridge hands that cursor and the bounded byte view to `reactor.stageCommandPage`. The existing fixed-page helper constructs the neutral record for the same bytes.

The browser checks the current effect owner and exact activation at the file-read and crossing frontiers. A mismatching full revision or cursor earns no progress. An authenticated retry reoffers the same page object. A funded pending page is polled until acknowledged. When the existing activation defers a turn for an intervening UI patch, it retains the control event in its own queue and leaves the unsubmitted fixed page with the host. The staged adapter polls a deferred control and reoffers only the fixed page that the activation did not cross. The next slice begins after the current page is acknowledged and the actor turn is settled.

The host cancels the captured request on picker dismissal, failure, explicit abort or stale ownership. A live old activation receives its own Cancel even if its document or presentation binding has changed. The actor's existing teardown is responsible for Original close once that exact activation is revoked. Progress covers accepted bytes. The native browser cancellation signal interrupts a pending sliced read, and a stale owner observed during a read is refused at its next bounded frontier.

## Exact guest join

The host overlay uses the existing Pack-backed `RequestFileOpen.args` effect field. It expects `args.originalMedia` to be emitted only after the guest retains the original one-shot picker intent. The full revision is the lowercase 64-hex-digit rendering of the actual canonical snapshot revision. The host never derives it from a short UI counter. The staged Raw wire JSON fixture uses a synthetic command kind. Product guest registration must issue its assigned kind. No live numeric kind was chosen.

The staged control/receipt fields are neutral in [Picker exchange schema](original-media-react.schema.json). The WIT control is one `original-media-control` event with `loan`, transport `owner` and `seq` as u64, `kind` as u8, `extent` as u32, and a typed Begin containing file name and MIME or an empty Complete/Cancel. The controlled actor input wire encoder already preserves exact unsigned numbers and bounded fields. Register the event in the WIT/schema and Rust `ActorInputWire` ingress path before the generic page reader. Use the actual reactor NativeCloseKey and Source, then construct the guest command binding from its captured loan. The host expects an optional typed `original-media-ack` in the current WIT command-ingress status record so the existing browser component bridge can normalize it. Acknowledgments echo the issued loan, owner, seq, kind, extent, phase and page ordinal if present. The result is retry, pending, accepted, stale or refused. An acknowledged Cancel may be stale because the named owner already retired. Control receipts may be retrieved after deferred UI turns. Guest cancel must handle an issued intent before Begin and a transfer interrupted during Begin.

The host changes do not mount the guest kind, WIT input/receipt and actor slot, or bind the raw input to the format job. The receiver's product mount and exact receipt/replay law remain in [Original guest ingress](original-media-guest.md). Confirm the guest can report idle while waiting for a subsequent source page and completes the paid cancellation before its terminal receipt. The shell's asynchronous codec and native WGPU implementations will need the same registered contract.
