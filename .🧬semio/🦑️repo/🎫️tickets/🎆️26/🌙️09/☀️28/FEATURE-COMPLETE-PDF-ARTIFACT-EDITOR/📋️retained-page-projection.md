# Retained PDF Page Projection

The document lifter now has a measured page-content stage before the existing semantic page-finalization turn. The stage resolves the graph's actual page dictionary and `/Contents` references, borrows the original decoded backing for a single stream, and measures split arrays before allocating an exact joined byte buffer. It preserves array order, the separator policy of the existing reference parser, and operators whose operands cross authored stream boundaries. The controlled parser reads the joining buffer in place.

`PageContentCursor` lends individually typed operators. `PageProgramCursor` assembles a native `Vec<PdfOp>` for supported vector programs and moves one operator per work unit when growing its backing. It can release pending decoded bytes, operand values, completed output, and interrupted migration under release grants. The production `DocumentLiftCursor` emits those effects in `DocumentLiftReceipt::content` under `DocumentLiftGrant::traversal`. The lifter consumes the ready vector during its existing semantic phase and derives page content plus canonical admitted stream roles.
