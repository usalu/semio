# Paid Graft for Page Rotation and Document Info

The staged ordinary graft walks the existing flat Pages/Kids order, comparing the typed rotation to the retained inherited or local rotation. It quotes the complete bounded page dictionary allocation before changing one scalar. A supported change owns only one replacement dictionary under the original object number and generation. It leaves the original page tree and all other objects borrowed. No image, content stream, or unrelated object copies into the graft.

The Info stage compares existing typed fields against the retained dictionary. When a field changes, it uses the same Info lowerer as conventional Save. The qualified ASCII encoder avoids the general text codec's initial cache allocation within the paid turn. A replacement keeps the original reference and generation. Adding Info uses the next free object number, matching the cold graft's numbering. Clearing the final field hides just the old Info row and removes /Info from the candidate trailer. A reference from another object or a private trailer entry prevents that cleared candidate from passing the graph quote. The initial profile permits a flat sorted graph, a single changed page rotation, and ordinary printable ASCII title, author, subject, keywords, creator, producer and Trapped fields. Structured Info extras and dates outside that profile stay on the reference route.

The candidate exposes a two-row sparse overlay over the original COS slice. Each loan resolves original generations and contains at most one replacement page, one replacement or appended Info object, and an optional removed Info slot. A separate paid turn transfers those rows into the revision-bound candidate. The classic quote, independent semantic receiver, and writer all use the same overlay. The exact typed proof must agree with the pinned snapshot before the Original producer can acquire an output page. A text or other typed edit not covered by this graft therefore stays private and is refused. Existing raw stream reuse remains the same.
