# PDF 1.7 Raw Image Picker Registration

The active Base image picker resolves `Pdf17EditorCommand::PickImage` in `✏️editor/📥️local-image/🦀️.rs`. Its `BoundedArtifactCommandWork` closure receives the trusted geometry, live snapshot and `AppOperationContext`. It has no `StepContext` or persistent ingress field. The existing effect emitter in `📄️document/🖼️image-authoring/📥️admission.rs` checks placement, then emits a `RequestFileOpen` with a data URL completion. The effect bridge already Pack-encodes `args`. The staged raw adapter projects only the issued descriptor into `args.originalMedia` and retains geometry inside the actor. It projects the exact operation and generation as lowercase 16-character hex and all 32 canonical revision bytes as lowercase 64-character hex. The control decoder reverses that representation before the guest compares the entire loan.

`raw-picker-receipts.rs` stages the distinct Begin, Page, Complete and Cancel transitions over the existing paid receiver. It verifies the actual caller Source independently of the host owner and transport sequence. The extent and kind remain fixed after Begin. A page is owned by the caller until the guest has paid to take it. The guest reports pending while it copies and retires the incoming page, then acknowledges its exact ordinal. Authenticated page retries replay by cursor without another page copy. Begin and terminal receipts can replay without donating another owner. Cancel before Begin and Cancel after a partial page both use the original command Source. A stale observation permanently disables the format handoff before cancellation finishes. Start and terminal receipts preserve the same document, instance and full revision the picker captured.

## Product seams

- **Picker issue and scope.** Give Base `PickImage` a retained command-work state. Before publishing the existing Pack effect, validate the current authenticated instance, `stores.store.envelope().id`, `stores.store.content_revision()` and the trusted placement. Under the current instance's admitted Source, issue the slot and project its descriptor with `raw-picker-pack.rs`. Keep a bounded replay receipt after the paired source/output close and before a subsequent picker can replace the slot.
- **Decoded controls and early fixed pages.** The current `ActorInputWire::Poll` carries admitted Pack event values, then the WIT bridge lifts the event. The staged WIT and `event_from_value` candidates recognize `original-media-control`. Dispatch the event as an ingress prologue operation, using `NativeCloseKey` and `OriginalCommandOrigin::admit_step/validate`. At `drive_command_ingress` in `⚛️reactor/🔄️turn/⌨️command-ingress-turn/🦀️.rs`, branch on the reserved raw kind before `command_page_invalid`. The current preflight rejects raw metadata, nonzero item count and a PNG signature that differs from the command tag. Presence and both generic assembly methods keep their existing checks. Avoid using `MediaIn`, which materializes a contiguous media payload. The native dispatcher and React law share the same fixture kind and leave the live allocation to the shared command registry.
- **Wire receipt and lifecycle.** The schema stage provides an optional named WIT `original-media-ack` in the existing `command-ingress-status` record. The reactor's `kernel_command_ingress_to_wit` and native host conversion need that result, while the staged browser bridge already consumes it. The actual incoming WIT page still needs controlled disposal on replay, rejection and revocation. An exact authenticated retry can leave its page with the caller while returning the retained acknowledgment. The command-origin close currently supervises existing descendants, so add the raw slot as a close peer before the origin can return its loan. Raw dispatch skips emitting an earlier receipt on unrelated idle/UI turns.
- **Format handoff.** The current `PngDecodeWork` feeds `ImageDecodeJob::new(ImageDecodeInput { data: payload, … })` and advances it with the same data URL. The next ownership seam is framework pixels' `📷️png/📥️decode/🦀️.rs`. `PngDecodeInput` and `PngDecodeJob` both own a `Vec<u8>`. A paged source needs checked fixed-width reads for `chunk_step`, a bounded read for the header, palette and transparency in `parse_chunk`, and octet access for the IDAT range cursor. The factory must borrow that exact source and revision before publishing the sampled image, alpha mask and placement. The staged Complete receipt covers transport custody at the format recipient.

## Verification

The final linked native law passed eight tests with the exact p980567 framework library hashes recovered from p5d2dcc. It exercised the real retained caller, another caller with the same operation and generation, both PNG pages, grant refusal, exact replay and terminal cancel. The native request uses the same operation and generation above JavaScript's safe-integer range and the same revision as the browser fixture. All nine React fixture cases passed with Ajv validation and used the actual selection adapter and fixed-page bridge with a real File. The independent PNG oracle uses Pillow to reopen all 4,196 bytes and compare the 32×32 RGBA samples.

The native test also reproduced a production `OriginalCommandOrigin` close defect using the live preimage. The first retirement turns returned the underlying loan, then the next turn called `validate_retirement_context` on that returned loan and failed with `original source loan has already returned`. The guarded candidate checks the caller Source binding on every turn and skips only loan validation once that specific loan is terminal, so paid metadata disposal can finish. The unchanged source failed one of eight tests, and the staged repair passed all eight. Pass `--live-command-origin` to the focused native runner to reproduce the failure on that preimage.

`raw-picker-schema-stage.py` passed guards for four candidates covering WIT, Pack event-lift and command-origin retirement, plus five active source anchors. The browser component and native product gates retain their original source captures. The product route remains pending the retained command and instance lifetime integration and the paged PNG factory described above.
