# Snapshot, Fixture, And Asset Terminology — 2026-09-15

## Definitions (authoritative)

| Term | Meaning |
| --- | --- |
| **Snapshot** | Persisted artifact state. No inferred fields computable from other persisted data. |
| **Fixture** | Test-only example data under `🧫️fixtures/`. Must not ship in runtime binaries as user-facing content. |
| **Asset** | Static runtime content under `🖼️assets/` (demos, icons, bundled DSL shown to users). |

Folder taxonomy for assets vs fixtures was largely completed in ticket `26/05/30/ASSETS-FIXTURES-SEPARATION`. This ticket addresses **symbol and API naming** that still calls persisted/runtime document state “fixture”.

## Measured violations (2026-09-15)

| Class | Count | Example |
| --- | ---: | --- |
| Rust parameter `fixture: &*Snapshot` | 48 lines / 29 files | `flow_context_menu_items(..., fixture: &FlowSnapshot, ...)` |
| Framework host document type misnamed `FlowFixture` | 409 references | `semio_framework_artifact_flow_flow::FlowFixture` |
| Bridge methods `to_fixture` / `from_fixture` on `FlowSnapshot` | plugin + tests | Host boundary, not test fixtures |

## Remediation plan

1. **Snapshot parameters** — rename `fixture` → `snapshot` wherever the type is `*Snapshot` (runtime editor/viewer/commands).
2. **Host document type** — rename `FlowFixture` → `FlowHostDocument` (framework `semio-framework-os-flow`); schema token `flow.fixture` → `flow.hostDocument`; mutations `ReplaceFlowFixture` → `ReplaceFlowHostDocument`.
3. **Snapshot bridge** — `FlowSnapshot::to_fixture` / `from_fixture` → `to_host_document` / `from_host_document`.
4. **Lint** — language-neutral source scan in flow `🔬️source-contract` (and repo-wide follow-up) rejecting `fixture: &*Snapshot`.
