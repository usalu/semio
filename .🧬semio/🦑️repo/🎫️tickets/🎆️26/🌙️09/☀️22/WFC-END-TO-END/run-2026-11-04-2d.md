## Behavior

- Grid2d and Wfc2d now honor the shell contract that an empty example selection loads the default document. All five artifacts consume the portable example-selection cases; the 2D cases compare every registered ID to independently constructed example documents.
- Grid2d stages localized forms for all 21 author commands. Portable cases pass non-default arguments through the actual form merge and typed bridge and compare every resulting field to independent JSON expectations. Its internal commit-fill callback is hidden from the palette.
- Bitmap exposes output-only, no-argument pin-preview, labeled Pin Solution / Lösung anheften. The previous pixels-bearing pin-solution action is an internal inference result transport. The public action refuses missing, contradictory, differently sized or stale previews and requires an addressed open output pane.
- Fill identity.base_revision travels through sourceRevision in the completion command and SetSolve into BitmapTransient. The captured source must match the current canonical document revision. Strict base64 revision comparison rejects unused padding bits and extra decoded bytes.
- Pin materialization builds a complete row-major Vec<BitmapPinnedPixel> incrementally and publishes one semantic PinSolution event. RestorePins retains the exact prior sequence for atomic undo. The parent and 3D agent own renderer freshness, durable-pin display and the canonical retained publication planner.

## Bounded Work

The snapshot schema permits output edges through 512, or 262144 cells. The cursor reserves its complete pinned-pixel payload (3145728 bytes) once under a quoted original grant. It materializes at most 16 pixels per turn and compares each prior row directly at the same sequence index. No per-pixel scan, Vec reallocation or partial document publication occurs. Fallible pixel lookahead precedes each mutating batch, so failure does not lose a partial receipt.

The semantic batch quotes two staged rows, forward plus inverse; cursor units are separate from this edit-row capacity. The remaining bitmap route capacity stays 4096 staged rows. The command wire bound is ceil(512²/3)*4+16384 = 365912 bytes. The independent producer result envelope reserves 128 bytes per cell for forward/inverse data plus a 16384-byte frame. These are transport bounds, not claims that the obsolete cold preparation adapter enforced a snapshot-size ceiling.

Cancellation preserves all staged pixels outside the document and retires the cursor through the same original caller. WFC component lifecycle policy is owned by the 3D agent and admits release of the same contiguous payload backing its capacity already allowed.
