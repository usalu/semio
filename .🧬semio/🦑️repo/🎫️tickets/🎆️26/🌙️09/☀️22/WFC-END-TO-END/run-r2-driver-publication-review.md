# WFC Test Driver and Publication Retirement Review

The shared TestJobDriver and publication owner allocator law were reviewed read-only. No concrete type, custody or allocator API blocker was identified from their current source; native execution remains required.

The test observer boundary is explicit. drive_step samples retained progress before job.step and immediately after it, finishes its Watchdog, qualifies the original receipt/admission and closes the claim before returning. TestJobDriver then calls the visitor with reply.original(). completed_output's observed_bytes therefore allocates a caller-owned test observation after producer qualification. Its lexical placement inside the original work loan does not make that Vec part of the qualified producer span. OriginalJobFixtureCaller.turn itself reconciles its actual lifetime receipt, loan and fuel; it does not install a physical heap observer around the callback. Its heap observations are at source admission/retirement. This resolves the proposed observer-allocation mismatch without changing code.

OriginalJobReturnOrigin acknowledge_outcome returns true only after both the descriptor ACK and its separate paid removal. Thus the driver's acknowledgement loop does not reuse a still-owned outcome. Pending empty callbacks retain their preclaimed unused capture credit, while actual outcome returns use the prepaid original witness; receive_outcome runs after the observer and returns that custody once. close returns the receiving place before closing the job and retires the original caller only after both are empty.

The publication owner helper quotes exactly size_of Publication for an already-empty Box. Inner retirement returns Pending before a distinct header drop. The allocator law constructs an actual empty boxed publication before observation, measures the real close turn, expects no allocation, compares released bytes with the actual Box layout and posted receipt, checks denied item/release budgets have no effects/work, then closes any denied case from the same driver source. A final empty-slot close must return zero progress. The oracle dependency installs the first-party testing allocator used by the trace observer.

The normal producer lifecycle uses needs_retirement rather than terminal_is_empty alone, so an initially empty staged payload can still be published, and an inner owner that cleared delivered state continues to its paid outer header removal. No source was changed by this review, and no build queue was started.
