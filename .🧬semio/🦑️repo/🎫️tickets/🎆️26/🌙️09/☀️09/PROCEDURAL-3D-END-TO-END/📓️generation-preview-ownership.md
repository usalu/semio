Equal evaluation bytes still acquire the new generation's identity. Removing the selection clears the retained lane on its next evaluation turn.

The renderer borrows the document's widget roster and connections. Generation inputs affect the evaluated values upstream, so rendering no longer clones and retires a patched document snapshot.

The generation identity is local to the window and has Rust, TypeScript, JSON Schema, GraphQL and Protobuf representations. The transient's original retirement and transfer account for both the evaluation buffer and generation identity. The updated registered native tests use the current controlled retirement interface with the original job caller.
