# Retained Flow solid primitives

Box, Sphere, Cylinder, Cone, and Torus share an analytic topology recipe for native construction and one retained Flow operator job. Each retained turn reserves or inserts one arena entity, links a topology record, or makes one separately funded shell allocation. The session reserves a persistent label range up front, protects unpublished topology against collection, and releases each unpublished entity on cancellation. Existing arena backing remains available for later operations.

The producer builds the `solid` dictionary under the caller's copy and capacity grants. Session publication inserts one inactive authority claim under its own retained item. The final live insertion activates the claim while both owners are locked. Cancellation releases the stored key under the original release grant.

## Preview and measurement

A complete live circular curve, full circle edge, or single-edge circular wire can also produce a certified cylinder in the source frame. The extrusion planner accepts either axial direction and rejects a transverse or degenerate vector.

The original Volume node evaluates live constructor-certified primitives using closed forms. For other native solids bounded by planar polygon faces, it integrates the oriented loops one coedge per turn with compensated summation and no heap scratch. The cursor checks the source and its in-place mutation revision throughout the calculation. A retained primitive preview uses the same analytic edge and surface recipe, binds its cursor to the same native solid arena identity, and checks live provenance again on every turn. Healing and NURBS conversion invalidate that provenance before starting their in-place edits. Authored Box planes, curved faces, caps and poles produce outward-wound triangles through separately funded position, normal, index, and edge buffers. Periodic seam coordinates and edge endpoints close exactly. Face, edge and vertex picking streams reference the persistent labels of the original native topology. Every component-label allocation is funded separately. Indexed triangle vertices use the viewport's sentinel ID and explicit topology points carry their own picking IDs.

The general validation path previously refused at ShellClosure because later validator phases have no original work producer. Its session branch also continued to return validating while a validator remained attached. The direct analytic preview uses constructor guarantees for its authored shape and leaves the general gate for arbitrary solids.

## Verification

- The language-neutral primitive cases specify dimensions, expected face counts and volumes. The retained tests use one item per turn, check physical heap allocations and releases against the original receipts, verify Box cancellation leaves no live handle or arena topology, and exercise the curved primitives through Volume and tessellation with outward winding and noncollapsed edges.
- The standalone Flow guest witness evaluates Box using continuation requests, tessellates the live handle, and compares triangle count and volume to the fixture and independent Parry cuboid.
- Three.js independently generated triangle meshes for the five primitives and a translated planar tetrahedron. Both independent tests passed with six volume assertions. Tree-sitter parsed the touched Rust modules. The exact test-crate Cargo build is waiting for the repository host capacity governor, so its native Rust and guest witnesses have no execution result yet.

Convex Hull currently has a logical Quickhull cursor. Its seed, horizon, merging, topology insertion and scratch retirement still require original physical funding. Volume for general curved solids outside the certified primitives requires a funded surface quadrature cursor.
