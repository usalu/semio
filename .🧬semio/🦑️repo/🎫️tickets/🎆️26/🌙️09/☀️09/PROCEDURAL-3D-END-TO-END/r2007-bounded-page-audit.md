# R2007 bounded page audit

Read-only inspection; no build or production edit. Source references below are to stdio dwg ac1024 any import/🧱️records/🗜️container/🦀️.rs.

R2007 selected section pages have two distinct paths (:410–417): encoding 1 copies size raw bytes directly and rejects a truncated page; other encodings call r2007_page with correction 1 and block size 251. Map pages call that same page function with header-specified correction and block size 239 (:654, :667). The header itself deinterleaves the 0x80..0x480 range as three 239-byte data blocks (:643), then chooses stored 0x110 metadata when the signed compressed length is negative, otherwise algorithm 2 (:645–650). Directory construction still includes maps, selected names and page rosters (:655–697).

Reed–Solomon here means only data deinterleaving, not error correction or parity checking (:436–451): for each block and data index, read encoded[block + index * factor], stopping at total; return the existing truncated/block-count error. Page setup aligns compressed length to 8, multiplies by correction with checked size and < 2^28, uses factor = ceil(total/block_size), bounds available encoded input to factor*255, and deinterleaves total bytes (:616–626). If compressed equals size the deinterleaved size prefix is returned, otherwise only its compressed prefix reaches algorithm 2. Do not conflate that stored-after-deinterleave map case with direct stored section pages.

Smallest native cursor boundary: own source identity and page parameters; phase plus deinterleave block/index and paid output frontier; then stored-prefix transfer or decompressor state {source position, opcode, literal remaining, literal layout/chunk and byte index, back-reference offset and remaining, output frontier}; finally bounded zero fill or truncate to expected. Literal reordering is table driven in 32-byte chunks (:453–515); copying in output order with a constant-size scratch chunk can suspend at arbitrary byte grants. Back-references can overlap and must read the dynamically growing output (:588–595). Extended literal lengths need resumable accumulation (:566–580), and opcode parsing must remain suspendable or explicitly quote the fixed worst-case bytes. Every output capacity birth, copied byte, intermediate retained deinterleave buffer and retirement must be funded; cancellation must drain both buffers. The cursor alone does not fund header/directory traversal, section ownership, records or projection.

Preserve cold errors for underflow, truncated literal, invalid zero/backward references and page/address/size checks (:491–492, :522–524, :588–592, :617–620). Cold resize(expected, 0) at :610 zero-fills a short decoded stream and truncates an overlong result; treat this as current behavior to preserve or deliberately test before changing it. Existing parsing also ignores parity, odd trailing bytes in UTF-16 name decoding and incomplete trailing page-map chunk; avoid describing stricter behavior as already present.
