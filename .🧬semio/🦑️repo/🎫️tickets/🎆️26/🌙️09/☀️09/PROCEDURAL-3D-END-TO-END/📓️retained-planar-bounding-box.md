# Retained Planar Bounding Box

The live Bounding Box operator retains its analytic fast path. When a planar solid or compound has no analytic bounds recipe, it visits the original straight-edge boundary under the existing planar traversal grants and accumulates the exact world-axis vertex extrema. The last demand quotes both corners. The standard native solid publication then creates one axis-aligned Box and returns it on the existing box output.

The reflected-stock Cut exercises all three disconnected members. Its extrema are [-1.8864754059871727, -2.587411369202087, -2.321963405885731] and [3, 3.6400997560097856, 3.552094473858273]. The compact source proof passed all 55 tests, and Manifold reproduced all six coordinates in the 20-test independent suite.
