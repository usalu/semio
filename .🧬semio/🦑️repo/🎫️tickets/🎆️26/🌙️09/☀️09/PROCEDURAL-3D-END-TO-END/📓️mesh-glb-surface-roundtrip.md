# Mesh GLB surface round trip

The contributed mesh GLB exporter now writes `TEXCOORD_0` from the tessellated vertex stream alongside `POSITION` and `NORMAL`. The existing cursor emits its UV samples and bytes with independent per-turn work and copy checks. It rejects malformed attribute dimensions and nonfinite values. The GLB reader validates the accessor's shape and count and accepts float VEC2 plus normalized unsigned byte or unsigned short VEC2. A primitive with missing UVs in a mixed asset takes the mesh's zero-UV value.

Retained reconstruction still welds equal positions. It now resolves imported UVs from the original index on each bounded corner turn, preserving two different UVs at one physical vertex. Authored normals remain in the corner attribute. GLB's standard represents discontinuities by duplicated vertex samples. Explicit seam flags on continuous UVs, original polygon boundaries, materials, and texture assets are outside this triangulated geometry route. See [glTF 2.0](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html).

The language-neutral fixture uses two triangles with four unique positions and six distinct attribute samples. Both welded endpoints of the shared diagonal have different UVs and normals on opposite sides. The registered Flow integration imports it, exports it and imports it again, comparing positions, attributes and corner samples. The linked Flow integration was not executed in this task while the official suite used the compiler.

The portable mesh suite passed seven tests with 3,777 assertions. An isolated compiler run registered the actual original GLB reader, writer and reconstruction sources against cached framework crates. It checked exact reference decode and encoded re-decode, a real triangle cap, and the resulting four vertices, two triangles and six UV and normal corners. The writer refused progress on all 995 deliberately undersized copy grants. Three.js GLTFLoader independently read the emitted GLB and matched all original position, normal and UV tuples. Rust compiler syntax admission passed on all six edited Rust sources.

The retained GLB import's base64 phase is sliced, but `BinaryMeshSource::step` still calls `mesh_from_glb_limited` as a single terminal source turn. The base64 text limit is 16 MB and the decoder caps triangles and active node visits. The JSON parse, copied container buffers, accessor decoding, traversal and transformed mesh allocation have no independent work/copy receipts or cancellation checkpoints within that call. Full decoder budgeting therefore still needs a resumable container and JSON intake, incremental accessor/scene cursors, and owned output and scratch retirement on the cancellation path.
