# Retained GLB scene and embedded accessor projection

The contributed original `brep.mesh.importGlb` path now walks the active glTF scene through a bounded node stack and counts dense embedded geometry before writing any output. It reserves the four output buffers individually from exact caller capacity grants. It then emits one position, normal and UV sample or one triangle per original funded turn. The supported geometry includes node-matrix and hierarchical TRS transforms, indexed and nonindexed triangle lists, strips and fans, interleaved dense layouts, authored or generated normals, and float or normalized VEC2 texture coordinates.

The two scene passes use the same immutable parsed document. The count pass validates active scene depth, walks, index extents and output limits. Each subsequent write requires available Work and its actual row copy extent before touching output. The scene cursor, its partial buffers and the parsed document remain part of the source retirement until completion or cancellation.

The shared language-neutral recipe builds a 4,096-triangle strip and two sibling list/fan primitives under nonuniform parent scale and nested translation. The strip has normalized U16 UV storage and non-axis-aligned authored normals. In native isolation, compiled production sources matched the existing codec's positions, index winding, normals and UVs exactly for 4,100 triangles and 4,106 output vertices. A copy grant of 31 bytes did not advance the funded 32-byte row. The full document and scene admitted 408,130 cumulative allocation bytes. Cancellation after 160 numeric output rows released 240,745 remaining bytes, balancing the cumulative original receipt after accounting for earlier parser releases. The independent GLTFLoader checked the emitted scene's oriented triangle geometry, bounds, UVs and world normals in 20,497 assertions.

The registered Flow cancellation test now reaches both JSON parsing and numeric accessor projection before cancelling. It checks one-item caller receipts, consumed Work, released backing, the retired job, and absence of geometry publication. The linked native integration remains unverified while disk gates the official build.

Sparse accessors, alternate URI buffers and unusually wide object metadata still take the existing extended projection route. The original shared decoder handles that route in one call. This change makes common binary projection cancellable and funded. It does not change base64 inlet accounting or lower the largest required contiguous output capacity grant.
