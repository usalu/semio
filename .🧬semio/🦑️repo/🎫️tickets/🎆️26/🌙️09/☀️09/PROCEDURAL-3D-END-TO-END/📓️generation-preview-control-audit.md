# Generate and Preview Control Audit

## Verified gap: valid text answers exceed the semantic record budget

Generation3d maps unconnected Flow text variables into editable Generate questions through 🧰️framework/🛍️products/💻️os/🔨️modules/🌊️flow/🌿️vcs/🦀️.rs (flow_host_snapshot_to_form_spec) and 🧰️framework/🛍️products/💻️os/🔨️modules/📖️playbook/🗿️artifacts/📖️playbook/🧩️extensions/🌊️flow/🦀️.rs (variable). The shared answer validator in 🧰️framework/🛍️products/💻️os/🔨️modules/📖️playbook/🗿️artifacts/📖️playbook/🦀️.rs accepts any string; generation_operations emits an UpdateValues mutation, and Generation3d routes that action through ✏️editor/🎮️commands/🧬️generation/🦀️.rs. However ✏️s/🔌️plugins/🌀️procedural/🫀️foundation/🖼️semantic-ui/🦀️.rs, generation_question, puts the entire published answer in UiText. UiText::try_from_str in 🧰️framework/🔨️modules/🖱️ui/🧬️contract/🔤️text/🦀️.rs refuses more than 512 UTF-8 bytes (schema budget textMaxBytes). The error propagates through generation_form. A valid generation containing 513 ASCII characters, or fewer multibyte characters totaling more than 512 bytes, therefore cannot assemble its visible form page. This applies to a stored/imported valid answer; the exact transport limit for committing such a draft was not tested here.

**Ownership and remedy.** The shared semantic input and renderer own this behavior. React's 🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🧱️elements/🗣️Interpreter/✍️input-views/🟦️.tsx InputView owns an ephemeral draft with useCommitDraft, revision/conflict/acknowledgement handling, and renders the framework Input or Textarea. The playbook generation value remains the persisted shared authoritative buffer; a renderer draft must not become the source of truth. Extend the framework schema and semantic input publication/commit protocol to carry long authored values through bounded chunks or an owned, addressable text buffer, including native WGPU's retained input path and action transport. Keep identity, revision, conflict and complete-value commit semantics; do not clip or overwrite the source. A 512-byte admission rule would be a product constraint, not a fix implied by the existing string schema: it would reject already-valid data and cannot by itself restore those forms. A shared bounded editor must let users navigate and edit the whole answer.

InputView's existing keyboard law specifies Escape to revert, Enter to commit a single-line field, and Ctrl/Command+Enter to commit multiline while Enter inserts a newline. Preserve this behavior, focus, accessible label, IME and mobile editing. Add schema-first language-agnostic coverage for 512/513 bytes, multibyte boundaries, initial stored value, full edit/commit/reload, draft conflict and keyboard interaction, then exercise shared React editable-controls and native retained-input receipt tests. Confirm that the action channel and WGPU text draft do not impose another bounded-record truncation before claiming end-to-end support.

## Verified gap: authored image sources share the same limit

The Flow bridge maps every InputImage's src directly into the shared playbook image block. generation_question passes the complete source to the same bounded UiText before creating the shared semantic image. An otherwise accepted source over 512 UTF-8 bytes, including a sufficiently long data URL, fails assembly rather than displaying the image. This is source-authored display, not an image-upload control; no upload path was established in this audit. Extend the shared image/resource contract with an owned addressable resource or bounded transfer protocol, so it can render the original source without truncation and without a procedural-specific renderer. Test long URLs and valid inline image data as well as unavailable resource fallback on React and WGPU; determine renderer resource capabilities before choosing the implementation.

## Scope and verification

The current Generate surface uses the shared generation form, semantic Input/Slider/Toggle/Select/Image and tree controls. Edit, Generate, and View preview controls use the shared scene and window measure routes, including source-owned show/LOD controls. Existing paging, labels, image mounting, typed defaults and generation edits were treated as implemented; no separate toolbar, mobile or keyboard defect was established by this read-only source audit. Preview runtime behavior, actual browser/native rendering, and image transport availability were not exercised. No Cargo or production files were changed.
