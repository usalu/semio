# DWG Logical Projection Audit

The existing native projection first collects entity bodies into a handle map, collects layer-record handles, then walks original objects in order (logical drawing Rust lines 655–742). HashMap collection replaces an earlier entity with the last entity of the same handle; non-entity objects do not replace an entity lookup. Missing handles and references to bodies of the wrong kind are omitted. Layer lookup uses the first matching layer-record handle in object order and defaults to index zero. Entities with TrueColor are omitted entirely, while ByLayer, ByBlock and indexed colors are retained (lines 733–740). Point vectors default absent coordinates to zero.

PolyfaceMesh resolves each item of its vertex_handles list twice, preserving the relative order of Vertex entries for positions and PolyfaceFace entries for faces; absent face index slots become zero (lines 664–673, 717–729). Face3d takes complete triples from its corner vector and fills missing corners with zero (lines 712–715). The current route constructs DwgLogicalGeometry through from_native and back through to_native (logical geometry Rust lines 49–58, 68–129); DwgLogicalDrawing::to_native clones layers, projects the complete entity vector, and requires exactly three stored extmin/extmax values (logical drawing lines 745–750).

For a minimally invasive sustained native-drawing projection, retain one source-bound owner with phases for entity-handle indexing, layer-handle indexing, object-order traversal, per-entity construction and extents. Use handle-to-object-index entries rather than borrowed references to avoid a self-reference; overwrite on duplicate entity handles and track the first layer ordinal. Hold an object and reference index plus partially built vectors in the owner so a long polyface or spline is not one turn; each map insertion, vector reserve/append and eventual release needs its actual grant, receipt and close path. Preserve source identity and order; never mark the existing whole entities()/to_native() call funded. Extracting a shared one-entity semantic helper would prevent drift, but its multi-element loops also need cursor-owned subdivision.

For the mesh-only consumer, native drawing layers and extents do not contribute to triangle buffers, but the current TrueColor omission and handle rules still affect the result. DWG geometry Rust lines 203–251 define checked f32 positions, one-based signed face indices using unsigned absolute value, triangle detection when the fourth index is zero or repeats the third, and quad triangulation. Face3d triangle detection compares the third and fourth points; normals are computed after all faces. A direct projection should match these semantics and validate against the existing native-drawing conversion as an oracle, including duplicates, wrong/missing references, TrueColor, and cancellation during long entities. Extents, when native output is required, are recomputed over all emitted entities (geometry Rust lines 71–124), with [0,0,0] retained for no finite point in the reader’s initial drawing.
