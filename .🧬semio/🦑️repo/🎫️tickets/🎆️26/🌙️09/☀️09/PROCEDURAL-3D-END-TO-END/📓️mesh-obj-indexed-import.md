# Indexed OBJ Mesh Import

The shared OBJ reader now captures each position, UV and normal index independently. Negative indices resolve relative to the count of their own stream when the face is read. Positive forward references are validated before source publication. The reader preserves n-gons as single topology faces and the existing tessellator triangulates those faces. UV-only and normal-only sources retain their respective authored channels. When a referenced stream is partial, missing UVs share a zero UV sample and missing normals share the geometric normal of their face.

Each parse event consumes at most 256 source bytes with at most one decoded token, or processes one face corner during projection. The original Flow and procedural Mesh routes require an admitted effect before executing these events and settle the performed Work. The Flow route transfers its partially parsed source to the existing owned cancellation path. Geometric reconstruction and Mesh publication continue through the existing polygon source and modeling jobs. Existing contiguous parser vectors remain subject to the format and topology size limits.

The faceted BRep Shape operator has a distinct contract. Its import cursor uses candidate normals only to choose triangle winding. The published faces have no authored shading-normal or UV channels. Arbitrary OBJ corner normals can disagree with a face normal and should not drive topology orientation. That operator retains its shape-only behavior.

The shared fixture checks a normal discontinuity and zero UVs through positive and negative index tuples, as well as topology-preserving import of a UV-only quad. It feeds the original evaluate, cancellation and native source witnesses and the independent Three.js OBJ loader. The linked Flow test target remains subject to host storage admission.

The pinned native witness demonstrated zero-source-progress on a zero Work effect, one performed Work unit per source event, indexed round-trip parity, mixed missing samples, and two retained triangles for the imported quad. Cancelling a 64-copy OBJ source after 128 funded parse events retired 8,603 bytes without publication. The independent Mesh suite matched the native OBJ outputs and passed all 14 tests with 3,877 assertions. Signed zero was normalized for geometry comparisons. Repository source admission remains within limits for Mesh Engine, Flow Mesh and the registered Mesh workbench target.
