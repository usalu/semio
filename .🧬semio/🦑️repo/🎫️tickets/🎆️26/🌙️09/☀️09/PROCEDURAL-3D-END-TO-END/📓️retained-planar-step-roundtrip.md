# Exact Planar STEP Roundtrip and DWG Exchange Scope

The registered BRep exchange catalogue contains OBJ, STL, STEP and DWG import/export pairs. OBJ, STL and STEP use original retained jobs. The remaining registered DWG pair exchanges AC1024 polyface meshes. Its export tessellates BRep and maps triangle positions and indices to DWG polyface records. Its import reads a complete DWG drawing, converts supported entities to a mesh and performs a cold native merge. The available DWG drawing oracle in this tree covers drawing entities. The registered physical DWG paths lack an exact authored planar solid codec and independent budgets for native pages and topology, so this slice extends the exact STEP route.

The retained STEP reader now certifies one directly authored closed planar solid as an axis-aligned box, a triangular prism, or an orthogonal cell boundary. Triangular prisms may be oblique. The prism proof requires two translated triangular caps, the three exact ruled quadrilaterals, native LINE trims and PLANE support, and shared opposite coedges. Authored non-axis LINE records must use an endpoint origin and the exact endpoint direction, as emitted by the retained writer. Authored oblique plane directions must exactly match the reconstructible native supporting planes. Common alternatives that represent the same direction with differently rounded components are outside the current proof.

The orthogonal proof collects at most four authored coordinate planes per axis. Each face must be a complete oriented patch of one cell boundary, with stable shared vertex and edge instances from its original STEP graph. The reader reconstructs occupied cells one ray per funded event, checks all faces against the resulting material selection, and funds a native grid recipe. The native publisher checks connectedness and one outer shell. No source profile or cell becomes an independent session address. Both branches retain their existing native solid transaction and the original decoder retires its index before publication.

The shared Part-21 index still limits statements to 1,024 bytes, original instances to 16,384, lookups to 32 hash probes, and the closed shell to 64 faces. Curved geometry, general planar profiles, non-cell-sized orthogonal patches, mapped assemblies, multiple solids, inner face bounds and void shells remain outside retained import. The retained writer continues to export additional certified planar shell shapes with linear trims, and its supported set is wider than the reader's. The original axis-aligned box import remains byte-exact against the existing Open CASCADE-authored fixtures.
