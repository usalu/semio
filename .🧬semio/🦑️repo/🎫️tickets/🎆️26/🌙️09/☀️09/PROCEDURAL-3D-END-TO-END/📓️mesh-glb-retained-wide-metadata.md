# Retained GLB wide metadata

The original Mesh GLB reader now admits metadata before scene traversal. The cursor visits one relevant object member or structural frontier per caller-funded turn. For a wide object it exchanges recognized schema members into an in-place bounded lookup prefix. It retains all members and array order, requests the native size of two member placements before exchanging them, and allocates no metadata index. Narrow objects keep their existing lookup results. Pack JSON's normal grammar, get, and writer semantics are unchanged. The GLB owner uses only the optional indexed borrow and exchange primitives.

All supported live GLB draws use the staged scene and accessor pipeline. The previous synchronous fallback for wide metadata was removed. Malformed noncanonical accessor shape now fails in the live accessor path. The existing synchronous API remains available to cold callers, and both paths reuse the same transform math.

The fixture puts 72 leading auxiliary members before used root, node and accessor fields. The exact production modules compiled with a freshly built Pack JSON and cached first-party dependencies. The funded reader matched the cold reader's triangle indices, transformed positions, normals and UVs. It posted 273 one-Work metadata turns and 15 in-place exchanges with no allocation attempt in the metadata phase. A below-quote copy grant did not advance the cursor. Cancellation after three real exchanges released 94,010 remaining bytes, balancing the original ledger and publishing no geometry. The existing large dense, sparse, mixed BIN/data URI and URI-only native fixtures passed.

The independent GLTFLoader checked both the wide fixture and the compiled native output. The portable mesh suite passed 11 tests with 24,418 assertions. Rust syntax, path length and scoped whitespace checks passed. The registered Flow suite now checks a wide draw and cancellation during metadata exchanges. Its linked Cargo run remains pending disk admission. The outer transport Base64 inlet and the size of the contiguous output allocation quantum are separate concerns.
