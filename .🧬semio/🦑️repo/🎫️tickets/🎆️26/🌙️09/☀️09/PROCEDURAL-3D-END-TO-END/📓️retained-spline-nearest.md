# Retained Rational Spline Projection

The registered `brep.eval.curveClosestParameter` and `brep.measure.closestPoint` operations use the same projection for continuous nonperiodic rational splines of degree one through three with at most 32 controls. A retained edge supplies the search interval and its supporting curve. The first operation returns the parameter, point and distance. The second returns the same point. Original analytic line and circular edge trims use the shared retained-source lookup.

The solver writes each knot span as a rational Bézier equation in a bounded local parameter. It isolates the degree-seven-or-lower numerator of the distance derivative and compares all isolated stationary points and retained endpoints using compensated arithmetic. It keeps the lowest parameter at an equal minimum and verifies results by evaluating the original rational control data. Common weight scaling preserves the geometry and prevents overflow when raw weighted control coordinates are outside the floating-point range. Retained plane and coplanar conic intersections share the relocated bounded polynomial and spline-span code.

Periodic splines, degree above three and more than 32 controls fall outside the admitted source domain. Invalid knots, weights or trims and unresolved finite arithmetic give explicit refusals. Elliptical edge projection continues to require its own trim-specific stationary solve.
