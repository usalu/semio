# Retained Generate Image Sources

Generate forms and the shared ImageWindow kit now use the same semantic Image builder. Short sources remain inline. A longer source uses a content-addressed child carrier with its exact UTF-8 byte count. React and native reconciliation release the image to paint only after the named carrier is complete. The carrier contributes no layout or visible text. Native paint checks its decoded raster against the current source before using the cache.

Generate charges each image's carrier to the existing form page budget. Forty examples with a retained source fit across two pages of 25 and 15 fields under the current 102-record page allowance. The framework's existing whole-document budget still applies to an individual large source.

## Verification

- Chromium mounted the actual retained Interpreter and shared window chrome. The English form decoded a 1,142-byte PNG data URI from its retained body. The German form decoded the short source. It verified the pixel dimensions, accessible alt labels, exact source values and existing owned form edits in both locales.
- The mounted React regression first failed because an incomplete carrier was used literally as the image URL. It now passes initial incomplete, complete, same-size replacement, hidden source rows and exact replacement assembly. The independent PNG decoder validated both neutral images and source byte counts.
- The compact Rust run rebuilt the actual UI Contract Components and Builder owners against the compatible managed dependencies. Both native witness tests passed. They verified exact long and short sources, accessibility labels, mismatched lengths, changed content keys at equal length and rejection of a previous source's raster. The proof uses the real funded UI arena and the retained reader with a small document adapter.
- Two cache-independent Rust page tests and ten independent portable pagination cases passed. The actual Generation3d form composition tests and WGPU image paint tests are registered and await a full linked run. The current source budgets pass for the sixteen measured app and framework owners.
