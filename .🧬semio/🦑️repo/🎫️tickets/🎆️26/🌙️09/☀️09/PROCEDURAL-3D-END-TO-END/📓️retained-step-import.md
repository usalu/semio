# Retained STEP Import

The registered `brep.io.importStep` original job reads the captured text through a STEP-owned cursor. It certifies one direct, closed, axis-aligned cuboid and hands the exact native box recipe to the existing transactional Solid publisher. The certified native coordinates are the authored Cartesian numbers, in the same model-space units as the existing STEP geometry codec. The import creates one new solid address and fresh native topology identities.

The cursor scans up to 64 source bytes plus one delimiter lookahead per event and keeps string quote and block comment state across turns. Its two passes count and index original DATA spans. It charges for the format cursor frame, exact plain index capacity, per-slot initialization, bounded indexed certification, and each owner release. An indexed statement is capped at 1,024 bytes and an open-addressed lookup at 32 probes. Single-document DATA extent is at most 16,384 instances. The face stage verifies one face per event with a fixed four-coedge bound. Certification checks all six extrema and face orientations, all eight shared vertex references, all twelve exactly opposite shared edge pairs, and a closed cycle for each face. Each trimmed edge must have an authoritative 3D LINE, directly or as the curve of a SURFACE_CURVE. Quotations on the Step-to-Solid handoff include the cursor release. Cancellation retires the plain index and parser frame before input retirement, or closes the existing unpublished solid transaction after handoff.

Two existing Open CASCADE-written Part-21 files exercise FACE_BOUND with orientation, a SURFACE_CURVE with 3D LINE and attached p-curves, conventional indexed topology, and placement away from the origin. Their headers declare AP242 and their certified BRep entities are shared with AP214. The geometry proof uses the 3D edge and plane only. It supports the specified direct manifold-solid subset and rejects additional manifold solids, void BReps, mapped or assembled instances, faceted BReps, shell-only geometry, non-axis-aligned curves and surfaces, holes, and unsupported boundary arity. STEP product metadata, units conversion, assembly transforms, attached p-curve semantics, curves other than LINE, and general STEP geometry are outside this original route. The cold exchange route still has its existing support.
