# Mesh editing and verification

The authored Mesh Workbench uses the contributed operator registry. Its \`brep.mesh.box\` output feeds inset and extrude, followed by analysis and B-Rep conversion. The contributed merge operator reads the indices in its \`selection\` array in order. The editor command sorted those indices before writing the graph input. The authoring command now preserves the primary vertex when inserting a merge so it is still available when the merge mode is edited later.

The typed \`mesh.edit.mergeVertices\` inference also sorted its authored indices before passing them to the kernel. First mode now keeps the first listed vertex as the anchor. The asymmetric-quad fixture checks the triangle's exact coordinates and winding, area and bounds. It distinguishes collapsing toward vertex 1 from collapsing toward vertex 0.
