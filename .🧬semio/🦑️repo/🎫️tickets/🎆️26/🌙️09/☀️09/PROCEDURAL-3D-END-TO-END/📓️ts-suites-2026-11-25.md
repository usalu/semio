Scope: 125 TypeScript test files (generation3d, procedural plugin-composition, flow host/wasm/registry, plugin registry and activation, NodeGraph and World3dHost elements, renderer world3d/node-graph/workflow-flow tests, actor/retained-turn only through the flow tests). Target list and runners: `ts-suites-tools/` (`targets.txt`, `run1.sh`, `vt.sh`, `vt-extra.config.ts`).

## Commands

- Bun route: `repo test-file <file>` per file, at most 2 in parallel (`ts-suites-tools/run1.sh`).
- `repo test-file` routes every file outside the build/caching/process tables to the plain bun route. The renderer files import `vitest` (`vi.hoisted`, jsdom `document`, `Element`) and cannot pass there. They were run with the owning config `🎯️targets/⚛️react/🧪️tests/🎚️config/🟦️.ts` through `ts-suites-tools/vt.sh` (node + vitest 4.1.12, `SEMIO_TEST_LEVEL=long`, `--maxWorkers=1`, synthetic `SEMIO_VITEST_POLICY`). NodeGraph hover and World3dHost `.test.ts` files that no include lists were run with `vt-extra.config.ts`.

## Root causes fixed (stale tests or stale schemas, never weakened)

1. `🧪️tests/📖️procedural-descriptors` expected `setLodMode` owned by `procedural-main` only; the Rust window refs, the published descriptor and the language-agnostic `generate-mode-interactions.json` all declare it on main, preview and generate-preview. Expectation updated.
2. `🧪️tests/🫳️node-graph-gestures`: host source moved to `self.dag.graph.*` and leaf-based journalling (`gesture_journal_leaves`); source-scan tokens updated.
3. generation3d `🖱️channel-hover.test.ts`: the test's direction model ignored the fixture field `incoming:false` (note text is an output-side handle, `h:note@text`). Model now honours it.
4. `✏️s/🧪️tests/🏘️plugin-composition/🌀️procedural-formats/🟦️.ts` `exportSourceChannels`: read `widget.type`, the schema discriminator is `kind`; and the whole-dictionary rule (empty port covers a source once, named ports deduplicated) was missing. Both fixed; the laws suite is 7/7.
5. flow host `📥️preview/🧬️schema/🔁️replacement`: schema lacked `toleranceRounds` and `admission`, and pinned `rounds` 2 and `sourceEpochs` [0,1,2] while the fixture and the Rust law use 3 rounds. Schema updated; the evaluation-source test now builds `law.rounds` meshes.
6. ui `📐️math/📦️resource/🧬️schema`: `turn.maximumCopyBytes` 64 vs fixture and Rust `TURN` 4096. Schema updated.
7. `🌐️geometry/🧪️tests/🎟️caller`: encoding now advances through `with_original_effect(grant,|_,effect|encoding.advance(effect))`. Token updated.
8. `🧹️retirement/🧪️tests/🧪️source-contract`: `close_step(&mut self.scene,body,effect)`. Token updated.
9. `🌐️browser/🏷️ownership` fixture: browser-types fixture path (`🧪️tests/`), ABI schema consumer moved to `🔬️protocol-unit`, host bindings consumers replaced by the publication and package script. Partly fixed (see remaining).
10. plugin registry `🎬️host-activation`: prepare targets are now orchestrators with empty outputs and `<crate>:component` dependencies; assertions rewritten over `dependsOn` (hub react/wgpu one component, native three, alpha only alpha).
11. plugin registry `🧩️composition`: `devServeCommandV1` yields `run @semio-tech/framework-os-dev:dev-custom-wgpu-prototype -- --port ... --composition ...`; expectation updated (the dev local-hub suite already agreed with the code).
