The React journey watcher accepts any pre-existing probe-canonical-react-live-*/summary.json merely by existence (canonical-react-journey-watch lines 5–13); it does not tie evidence to this launch or require successful bidirectional hover. A stale summary can launch it early.

The exact shell port and preview assertions will reject many wrong fixtures, but a slow replacement can be misclassified or stale same-fixture state mistaken for readiness. Require a fresh matching selected example and settled preview before exercising hover.

Inspect the current run’s result file and its exact bidirectional-hover record, not process exit status alone.
