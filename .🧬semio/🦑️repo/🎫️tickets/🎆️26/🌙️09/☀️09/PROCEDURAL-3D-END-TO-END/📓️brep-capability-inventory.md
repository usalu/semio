# Procedural BRep Capability Inventory

Read-only source audit, 2026-11-20. The shared tree can change during this audit. No Cargo or linked application tests were run. “Focused” below means fixtures or ticket reports exist, not that a registered suite has passed in this session.

## Registry and execution distinction

The Flow extension's `✏️s/🔌️plugins/🌊️flow/🧩️extensions/📐️brep/🦀️.rs` maps 93 BRep operator IDs to kernel methods. All 93 IDs occur in the registration modules under `🧾️register-operators`; no missing ID was found in that declared list. This is a source-text check, not a runtime manifest assertion. `register()` calls all registration groups and finalizes the registry. Mesh operators are outside this inventory.

The trait forwards to sync methods in `🧰️framework/🔨️modules/🧊️3d/📐️brep/⚙️engine/🔌️brep-kernel-implementation/🦀️.rs`; sync methods route through staged generic jobs in `⏱️operation-jobs/🦀️.rs`. Flow operators with `retained_geometry_job!` instead admit original retained jobs. Therefore a generic implementation or isolated kernel test is not proof the interactive retained path accepts that geometry. In particular Fillet, Fillet Variable, Chamfer, Chamfer Asymmetric and Defeature in `✏️s/🔌️plugins/🌊️flow/🧩️extensions/📐️brep/🧲️features-intersect-evaluate-and-topology/🦀️.rs` use immediate plan/evaluate rather than retained admission; expensive work runs synchronously through the generic API. Their presence is not evidence of funded cancellation.

## User-visible capability

| Registered family | Current evidence and limitation |
| --- | --- |
| Box, sphere, cylinder, cone, torus, lines, circles, basic transforms | Native constructors and methods exist, with primitive and transform fixtures. Broadest supported baseline, not a claim that every affine image or downstream operation is supported. Original affine publication refuses images requiring funded topology or spline production. |
| Fuse, Cut, Intersect, Compound Cut | Retained certified paths cover orthogonal boxes, specific sphere, cylinder and box combinations, and selected chains; unsupported relationships are explicitly refused. The recipe files under `⚙️engine/🧠️native-registry/🏗️solid-transaction/🧮️boolean-recipe` and ticket's sphere-cylinder report identify exact domains. General rotated and mixed curved Boolean parity remains open. |
| Sweep, Pipe, Loft, Revolve, Helical Sweep | Registered and retained, but focused domains: straight sweep requires a single line path and planar polygon or axial circular profile; Loft requires two matching translated line or coaxial circular profiles; Revolve handles certified circular or meridional rectangular faces; exact helical sweep requires zero pitch and one signed full turn. Native source in `⚙️engine/🧠️native-registry/🛤️straight-sweep/🦀️.rs`, `🥞️two-profile-loft/🦀️.rs`, `🔄️circular-revolution/🦀️.rs`. Tests include `✏️s/🔌️plugins/🌊️flow/🧩️extensions/📐️brep/🧪️tests/🔬️unit/🛤️original-straight-sweeps.test.ts`, `🥞️original-two-profile-loft.test.ts`, `🔄️original-revolve.test.ts` and adjacent JSON fixtures. |
| FilletEdges, ChamferEdges, Draft, Shell, Offset Solid | Retained focused constructions: selected box edges for fillet/chamfer and box faces for draft, box/sphere shell, box/sphere/ring torus solid offset. Source `⚙️engine/🧠️native-registry/🧊️solid-publication/🦀️.rs`, `🏗️solid-transaction/🐚️shell-recipe/🦀️.rs`, `↔️certified-offset/🦀️.rs`. | Volume, Area, Length, Distance, Closest Point, Classify | Focused supported analytic and planar cases; not arbitrary BRep queries. Classification explicitly refuses all certified non-primitive provenance except bore, including orthogonal results and spherical caps. Solid-solid distance is limited to two certified boxes; vertex/curve/surface cases have additional focused paths. `⚙️engine/🧠️native-registry/📍️certified-solid-queries/🦀️.rs`; `✏️s/🔌️plugins/🌊️flow/🧩️extensions/📐️brep/🧪️tests/🔬️unit/📍️original-solid-queries.test.ts` and JSON. |
| NURBS grid, Coons and curve fitting | Retained implementations refuse grids outside 2–8 samples/direction, Coons boundaries outside 2–4 samples, and curve fitting over eight samples. `⚙️engine/🧠️native-registry/🧮️spline-construction/🪡️grid-fit`. This is a user-visible data-size ceiling, not missing registration. |
| STEP, STL, OBJ, DWG | Registered. Existing focused STEP/OBJ/STL fixture reports cover specific import/export domains; they do not establish arbitrary CAD exchange. DWG names map to generic mesh import/export and require separate format-specific verification before claiming DWG support. |
