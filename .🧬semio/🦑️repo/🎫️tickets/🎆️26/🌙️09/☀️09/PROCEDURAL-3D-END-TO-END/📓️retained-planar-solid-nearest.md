# Retained Closest Point on Planar Solids

The existing Closest Point operator now opens an incremental boundary traversal on a retained planar solid or a bounded compound. The cursor visits each original shell, including void shells, and delegates one original face at a time to the exact face projection in the kernel. It compares euclidean distances and holds only the current face projection and the best result. Query reads retain the source handle and topology revision. Analytic primitive fast paths remain available.

The reflected skew Cut fixture verifies one point inside the retained material and one in the removed space. The compact native suite mounted the production nearest cursors and exact planar predicate on the three generated member boundaries and enforced the measured per-item demand. It passed all 53 tests. Manifold and Three independently reproduce both closest points to within the shared fixture tolerance. The linked Flow registry check and the registered analysis test with placed solids remain pending.

General unsupported curved surfaces still require their own exact nearest-point methods. The new traversal returns the original face error when that surface cannot project.
