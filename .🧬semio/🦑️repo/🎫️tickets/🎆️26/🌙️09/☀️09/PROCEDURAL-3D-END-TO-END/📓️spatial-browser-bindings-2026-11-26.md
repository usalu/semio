# Spatial browser session bindings

The web component failed with Rust E0308 because its JavaScript-facing close method passed a retained grant directly to `SessionCapture::close_step`. The geometry session now requires an original allocation effect. The browser method opens one finite authoring turn, lends the geometry session that effect and narrows the original effect to the physical grant supplied by the browser. The authoring turn pays for its own reply handoff. Grants with zero items or zero depth carry no authority to move the live session.

The component compiled for `wasm32-unknown-unknown` from the existing frozen reference workspace with the same component source change and warmed dependency store. The matching wasm-bindgen produced web JavaScript, the WebAssembly binary and the TypeScript declarations. The generated bindings were installed under the session Rust package's standard `🕸️bindings` directory and compared byte for byte. The WebAssembly binary was 34,783,055 bytes and had SHA-256 `f4de936ad40f1984afaed29f0b3e4669a4e028959a6306825db4774ebcaa82aa`. The JavaScript entry was 26,335 bytes and had SHA-256 `c057e8cf171d4fe7dde38c958186f4598681b04c4cff23992f452d10a19ce441`.

The generated binding test now requires the real installed prototype to admit every method in the shared fixture. It passed with 16 assertions. The source ownership fixture now names the actual physical-custody test module, which already contains the native law. All seven ownership groups were found in their pinned source files.

The portable browser lifetime laws ran on the installed WebAssembly and passed independent geometry volumes, cancellation and resume, zero-grant state preservation, close receipt schema and currency bounds, repeated close and post-close refusal. Ajv validated the portable schemas. The `spatial-browser-web.mjs` probe also imported the installed JavaScript and WebAssembly over HTTP in actual Chromium. The authored box had volume 24. The session returned 159,812 bytes of physical release in 3,546 bounded turns, reached terminal-empty and freed its handle. Chromium reported zero page errors.
