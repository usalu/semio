## TXT continuation follow-up

The TXT leaf calls ArtifactDsl::parse_dsl through TxtSnapshot::from_body synchronously. Framework 🗣️dsl/🧬️schema/🛬️decoding/🦀️.rs:281 exposes parse_exact_controlled with NativeDecodeControl, including checkpoint/refusal, but it returns the complete parsed value from the same call; no resumable TXT parse cursor was found in the scoped source. The existing export continuation has source-identity and cancellation checks, retained projection, writer, text envelope, explicit retirement, and returns progress from text_step. The import branch has none of the analogous staged identity, cancellation, parser or output-owner handling: it sets consumed before invoking the cold whole import. A scalar pre-scan before the synchronous parser would not satisfy the bounded-work law. A real fix needs resumable lexer/parser, typed snapshot conversion, funded LoadDocument encoding and controlled retirement with source identity revalidation.
