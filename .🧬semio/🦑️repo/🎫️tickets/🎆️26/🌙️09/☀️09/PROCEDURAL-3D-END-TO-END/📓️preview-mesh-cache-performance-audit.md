# Preview Mesh Cache Performance Audit

Edit's `preview_payload` rebuilds `PreviewMeshIds`, clones each distinct resolved `MeshData` (or regenerates inline mesh), applies show mode, makes pack values and serializes the full mesh array on every call (`✏️editor/🎭️modes/✏️edit/🪟️windows/👁️preview/🦀️.rs` 377–472). Generate calls that same function (`🧬️generate/🪟️windows/👁️preview/🦀️.rs` 102). Each hover refresh reaching the producer pays that cost; this is copying and encoding already tessellated session meshes, not proof that the tessellation job itself reruns. Component selection additionally parses mesh JSON in Edit's selection projection (325).

View already has a one-entry thread-local `PREVIEW_MESH_TABLE`, `preview_mesh_signature`, and `build_preview_mesh_table` (`👁️viewer/🎭️modes/👁️view/🪟️windows/👁️preview/🦀️.rs` 181–310). It caches JSON, bounds, instance-to-mesh IDs and exact hover aliases while rebuilding marks and instance JSON; it still clones the cached JSON string on each output. Its key hashes evaluation source, tolerance bits, show mode, visible widget IDs, `FlowEvalSession::preview_mesh_epoch()` and resolved handles. The epoch is explicitly the mutation epoch of that session's `preview_mesh_by_handle` (`🌊️flow/🖥️host/⏱️eval-session/🧩️extension-generation-and-preview-retention/🦀️.rs` 82–104), not a globally unique session identity. `PreviewEvaluation::mesh_lookup` also carries Current versus WithFallback source policy; `PreviewMeshLookup::resolve` may choose current, converged or previous-converged handles (`🧵️preview-eval/🧊️preview-geometry/🦀️.rs` 700–733).

Do not blindly share View's thread-local single entry between sessions/tabs: two app-instance sessions may have equal eval/handles and equal local epoch but different mesh bytes, and the 64-bit hash alone is not exact identity. No globally unique session ID was found in the inspected session API. Safest reuse is a retained table owned by the actual app/session or window authority, keyed by exact evaluation/source policy, preview widget census, quality/show mode, mesh residency epoch and resolved identity; include component-mode dependency because Edit intentionally suppresses aliases in component mode. Invalidate on source/revision, LOD, visibility, session replacement/reset and mesh arrivals. Retain per-window scope if evaluation/quality can differ; share immutable mesh source only with explicit exact source identity and lifetime. Keep instance marks, component pickability/pivot and selection live.

Small regression: render the same evaluated geometry with identical session and config twice, changing only hover; instrument mesh conversion/serialization count and assert no second build while marks change. Then replace a mesh at the same handle/epoch in another session with distinct bytes and interleave both windows, plus same-session epoch advance, source-policy, quality, show-mode and visibility changes; assert exact bytes and hover groups after each. A shared language-neutral case table and independent JSON comparison exercise output; focused producer tests can use existing preview fixtures without a full app build. No tests or builds run.
