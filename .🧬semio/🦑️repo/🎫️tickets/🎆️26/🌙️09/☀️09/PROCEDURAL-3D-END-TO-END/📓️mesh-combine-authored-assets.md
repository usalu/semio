# Authored Materials and Textures in Mesh Combine

The retained Flow Combine Meshes operator now merges both inputs’ authored material and texture bundles. It preserves the original keys, exact texture bytes and numeric/material data, and per-face material bindings on separate input components. A repeated key represents one binding when both payloads are identical. Texture equality covers MIME and bytes. Material equality covers the exact stored structure, including authored object field order. Same-key conflicts return a typed error before publication. The operation still requires matching named attribute definitions across both inputs.

Combine transfers the first source’s original maps and moves disjoint entries out of the second source. Asset-map reservations quote exact capacity and depth, and duplicate comparison advances a bounded structural event or up to 256 bytes per turn. Both sources and any staged asset remain in the same controlled retirement owner until publication.
