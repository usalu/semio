# Closed-curve B-Rep profiles

The procedural editor exposes Circle and Ellipse as analytic curve outputs. Generation 3D previously restricted its face and wire extrusion ports to wire topology. In the Flow plugin, the packaged ports already share the geometry type, but the kernel required a wire handle and the extrusion planner inferred its plane from topology vertices. A periodic curve may have just one seam vertex.

Generation 3D now accepts closed curves, edges and wires on the existing boundary inputs. The native B-Rep kernel derives the winding plane from oriented curve samples, retains exact edges in the generated boundary, and plans extrusion in a scratch body. Planar trim curves retain the full parameter range of each edge, including a conic’s full turn. Face filling and the Flow extension use the same native boundary support. The XY-only face operator checks its plane and the general face operator accepts an arbitrary planar orientation. An open profile produces a boundary error. An in-plane extrusion is rejected before building a solid.

## Verification

- The language-neutral cases cover a translated circle extruded into a cylinder, an ellipse filled on the YZ plane, and open-curve refusals. The independent oracle suites passed across the curve, evaluation, solid, surface and Boolean facets using Three.js and manifold-3d.
- The packaged Flow component declares `geometry` on Circle, Ellipse and Arc outputs and on the boundary inputs of Extrude Curve, Face From Wire and Planar Face Wire.
- The Flow registry regression exercises those production operator registrations through quantity measurement and preview tessellation, using the same language-neutral fixture.
- The initial Generation 3D native target stopped at compile errors in semio-plugin-tool-machine involving RetainedOwnedProjectionAdmission. One of the missing constructors is present in the current shared source. The focused B-Rep kernel and retained Flow tests are waiting for compiler capacity.

The existing exact extrusion planner still limits circular profiles to axial extrusions and refuses elliptical profile edges. Ellipse face filling is supported.
