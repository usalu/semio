# Original planar Thicken

The retained Flow Thicken node publishes a closed native solid from a live planar face with one circular or line-polygon boundary. It uses the face orientation and signed thickness to select the extrusion direction. Circular profiles produce an analytic cylinder in the source frame. Polygonal profiles use the existing bounded prism validation and publication. The source stays live throughout. Holed and nonplanar faces, other curve families, and thickness within the kernel tolerance remain outside this route.

The original node quotes its source arena paths before borrowing the face and advances the existing topology, dictionary and live-index state machines through the caller's grants. The native fixture covers negative rectangular thickness, positive circular thickness along a translated world X axis, exact Volume, source preservation, cancellation under one-item grants, and zero-thickness refusal.

The language-neutral fixture also feeds an independent Manifold extrusion oracle. Both cases passed all 16 assertions for bounds, enclosed volume and genus. Rust syntax parsing passed. The native fixture remains unexecuted because the host has insufficient space for Cargo admission.
