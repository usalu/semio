# Retained STEP Round Trip for Spline Cuboids

The existing `brep.io.importStep` operator now recognizes a closed shell with six degree-one spline patches and twelve degree-one spline edges. The retained reader checks shared vertices, opposite edge incidence, face orientation and all six cuboid limits using the existing box proof. It then verifies each native face's original U and V knot domains, control point order and outgoing edge parameter directions. The supported encoding uses complete unit-weight spans, with the native edge interval [0,1]. Equivalent STEP files can reorder faces and choose unrelated instance identifiers.

A distinct spline cuboid certificate opens the existing funded NURBS publication. The new solid owns its curve and surface allocations independently of the imported STEP text. The publication reconstructs the certified original rational geometry and face trims. The decoder inspects one spline face or one face certificate per turn and retires its instance table before publication. Altered knot intervals, reversed edge parameterization, mixed analytic and spline supports, rational composites and other unimplemented spline domains receive typed refusals.

The neutral cases cover rectangular and translated fractional cuboids. A Three.js geometry witness authored separate STEP documents with different instance identifiers, decimal spelling and face order. Open CASCADE read each as an oriented closed six-face solid and matched bounds, area and volume. The actual Rust reader and spline proof passed both spline documents, analytic cuboid regressions and the four negative cases in the isolated decoder harness. That run substitutes the unavailable geometry types and retained grant interfaces.
