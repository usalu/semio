# Live Image Transport Cross-check

## Contract and producers

The native ImageProps, field visitor, kernel borrowed JSON codec, TypeScript schema projection, and retained-wire typed fields include source_body_bytes/sourceBodyBytes. A source search across framework and procedural Rust, TypeScript and JSON found no stale ImageProps literal missing the new field and no consumer of the searched old framework.image.source key. This is a scoped source search, not a compile result.

Generate's semantic form and ImageWindowKit use the shared plugin window image_with_source. Short sources remain inline. Longer sources use a key derived from scene_lane_hash(source), a byte count, and a paged_text_carrier keyed by that same value; the builder requires a matching carrier key. Carrier size is bounded by the surrounding document and node budgets, so this is not proof of unlimited image size.

## React and native consumption

React ImageView selects the retained route when sourceBodyBytes is present. RetainedImageView rechecks the document revision until retainedTextBody finds the carrier and a complete UTF-8 byte count; changed content identity and size invalidate its cached text. It renders no URI until resolution, preventing an incomplete URI from being displayed. The native record projection resolves the same named carrier and byte count, and record_consumes_subtree includes Image, so carrier text is not mounted as visible child chrome. Native paint uses the resulting URI for image admission and draws a placeholder when unavailable.
