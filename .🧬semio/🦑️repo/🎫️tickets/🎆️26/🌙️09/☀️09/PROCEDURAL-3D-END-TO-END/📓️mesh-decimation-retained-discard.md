# Retained Mesh Decimation

The registry maps `brep.mesh.decimate` to the original mesh modeling job. The job already traces individual source rows, candidate checks, reconstruction and attribute propagation. Accepting or rejecting a candidate previously released the entire candidate working set in that event. Accepting a collapse also released the previous snapshot, edge index, build scratch and remap at once. Those releases depended on mesh size. The original Flow adapter ignored the native physical receipt and performed Work.

The decimator now moves those owners into a typed resumable retirement cursor. Each caller-funded turn does at most one discard event. The cursor provides the next physical copy, backing, release and depth demand before advancing. The Flow adapter posts the returned physical receipt and consumes performed Work. Closing a cancelled operator transfers the in-flight cursor into the existing whole-job retirement path. Direct synchronous authoring drives the same normal cursor under its own explicit invoked wallet.

The shared split-tetrahedron fixture defines the expected shortest-edge midpoint collapse and its oriented result. An isolated pinned Rust build ran the production decimator over 64 disconnected copies. Normal disposal released 3,518,711 bytes in 51,966 funded release turns. A deficient release allowance performed no discard work and left progress unchanged. Cancellation after two settled releases drained another 2,853,344 bytes through the original retirement ticket without publication. The production synchronous API completed the same small source, and callback cancellation preserved the original source. The independent Manifold check matched the native mesh and recorded nine passing assertions, including shape measure, topology and the midpoint.

The registered `retained-mesh-workbench` target now covers Construct, Simplify Mesh and Analyze through the original evaluator. Its direct operator test observes both performed Work and the reported physical release, cancels during disposal, and checks terminal ownership. The registered test source passed the Rust parser. The linked Cargo target remains unverified on this host because free storage is below its admission threshold.

The work covers release of rejected candidates and superseded decimation state. Existing scratch construction and geometric algorithms still have further allocation-accounting work outside this slice.
