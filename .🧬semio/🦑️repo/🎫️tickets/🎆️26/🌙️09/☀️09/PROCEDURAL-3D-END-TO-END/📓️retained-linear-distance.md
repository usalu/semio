# Retained Linear Distance

The registered `brep.measure.distance` operator now measures a pair of original lines or linear edges in either input order. A standalone line contributes its unbounded support. An edge contributes its authored finite interval. A zero-width edge or a degenerate bounded linear support contributes its point. Nonlinear curve pairs, invalid trims, nonfinite geometry and a zero unbounded direction give explicit refusals. The existing vertex, face and certified box routes remain available.

The fixed-size solver compares the supporting common perpendicular with the projections of all retained endpoints. Directions and relative coordinates use powers-of-two normalization and compensated products, which preserve the distinction between parallel supports and near-parallel supports with a distant crossing. The common perpendicular contributes only when both operands retain it. Parallel and antiparallel pairs use the same endpoint comparisons and supporting projection. The solver uses the existing original source-depth and funded scalar path.

The 17-case neutral fixture covers interior skew and crossing edges, finite endpoint cases, collinear and antiparallel edges, excluded supporting intersections, near-parallel spans and a large translation. The registered Flow test builds original lines and imports authored edges, then calls Distance in both orders. Its full run remains deferred under the disk gate.

The compact native witness compiled the production solver against cached curve types and passed all 17 cases in both orders, the subnormal direction check and three refusal checks. Three.js independently minimized point-to-line distance over the retained fixture domains and matched all 17 cases in both orders. The source parse and whitespace checks passed. Engine measured 3,989 active lines, Native Registry measured 3,971, and the registered curve test closure measured 15 files and 92,733 active bytes. The native witness removed its temporary files.
