# Retained Spline and Plane Contacts

The registered `brep.intersect.curveSurface` operation now intersects a live plane with rational B-splines of degree one through three and at most 32 control points. It accepts continuous nonperiodic knot vectors with positive finite weights and takes the finite authored edge interval when an edge owns the source. The same source resolution now keeps authored line, circle and ellipse trims. A polyline is a separate wire topology in the application.

The solver forms the signed homogeneous plane equation from the original control points and weights. It applies de Boor's affine recurrence to obtain a scalar polynomial on each retained knot span and isolates roots using the shared compensated polynomial solver. It verifies each original curve point on the plane, counts a shared knot once and keeps distinct nearby roots. Positive-duration plane overlap, more than four distinct points, unsupported degree or size, periodic knots and invalid rational data give explicit refusals. Other surface kinds retain their existing original refusal.

The operation publishes a single contact as a vertex or two to four ordered contacts as an open wire on the existing `wire` output. It uses the same retained publication and cancellation path as curve–curve contacts.
