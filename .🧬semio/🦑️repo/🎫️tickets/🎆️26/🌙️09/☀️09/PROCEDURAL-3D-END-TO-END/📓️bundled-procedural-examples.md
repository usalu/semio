# Bundled Procedural Examples

The portable example suite passed 33 tests and 622 assertions across nine example files. It exercised rectangle wire and extrusion, face sweep, analytic sphere, box and torus, rounded and shelled boxes, the hexagonal column, and the mesh workbench.

This suite verifies the example data and portable behavior. Canonical React and WGPU runtime verification is tracked in the [completion ledger](feature-completion.md).
