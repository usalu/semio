## Second compiled requester

The browser profile after the Math completion contained the original retained response shell but no `CompletedInput::step`. Source inspection traced this to the WIT bridge passing a stack-local event option to a receiver that initially admits a retained witness and leaves the original event in that option. When the original turn returned, the event disappeared before the next admission phase. The upcoming requester links the persistent pending event queue and a context quiescence check across closure and succession.

The frozen source snapshot and live project generated different Cargo unit hashes for shared packages whose package IDs name absolute source paths. The build therefore uses the original live project path and warmed cache. The linker relay saves and hashes every final rustc object, drives the pinned core linker with one thread, and runs the validated direct-call deduplication and pinned component encoding before staging. It can replay the exact linker command from its receipt after an interrupted final link.
