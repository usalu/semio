# Retained STEP Export

`brep.io.exportStep` now admits an original Flow job over one native certified solid. It preserves native vertex sharing, original LINE curves and edge senses, planar face frames, oriented coedges, original face subdivision, and optional inner face bounds. The writer emits millimetre-valued STEP Part 21 using the existing AP203 geometry entity vocabulary. It preserves native coordinates with round-trippable 17-significant-digit numeric literals. The route covers certified planar primitives, planar prisms including oblique extrusions, and single-shell orthogonal results. Curved edge or face geometry, multiple solids, and inward cavity shells receive an explicit original-job refusal. The existing cold format API remains available.

The Session supplies a narrow read-only view of the exact original native body, solid identity, and shape revision. The format cursor rechecks the same original handle allocation, body, solid, and shape revision for sizing, writing, and final transfer. Both passes walk the original native topology with one bounded record or reference group per event. It quotes arena lookup depth, copied native values, and the fixed 2,048-byte ASCII scratch bound. Output chunks are at most 64 bytes. The sizing pass verifies the subset before funding an exact output allocation. Shared edge and vertex rows are deduplicated in a fixed 2,048-slot index with at most 32 probes per key. The other limits are 256 shell faces, 128 bounds per face, 512 coedges per bound, and a 4 MiB document. The output string transfers once to the existing Flow output dictionary owner. Cancellation funds disposal of the writer frame and pending string without changing the native source.
