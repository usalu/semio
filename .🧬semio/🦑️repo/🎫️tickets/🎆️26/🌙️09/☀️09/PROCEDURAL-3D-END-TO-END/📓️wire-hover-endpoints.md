# Procedural Wire Hover Endpoints

Edit, Generate and View project both endpoint addresses of a hovered graph wire into the viewport. Named endpoints retain their own directions. A whole-dictionary connection expands each endpoint's visible channels on that side of the widget. Hovering an individual inlet still follows its upstream producer.

The language-neutral Flow fixture covers named endpoints, whole-dictionary endpoints, direct marks, and irrelevant values. An independent SQLite query matched all six cases. The isolated native graph and viewport projection witness passed three tests. The registered preview-eval test was added with the same fixture.

Chromium initially reproduced an ambiguity at coincident input and output geometry. Both were visible as separate directional records, while the viewport ray published only the input address. The subsequent grouped-hover work covers that geometry interaction.

The linked preview-eval Cargo run remains active in the framework dependency build. Canonical application verification remains open.
