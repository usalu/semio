# Retained OBJ Parser Buffer Growth

The original OBJ reader now quotes replacement of its full position, face, corner-reference and attribute buffers before mutating the source cursor. A replacement is its own Work event. It allocates a new exact backing, moves the charged existing rows, releases the previous backing and publishes all three physical extents. The source position changes only on subsequent parse or projection work. A bounded lexical check avoids requesting a new buffer at a row delimiter that cannot append to it.

Flow exposes the next replacement through its normal step demand methods and posts the observed physical receipt. Both Flow and the procedural Mesh adapter keep the parser parked when the current grant cannot admit the replacement. Flow also uses the existing typed retirement path to close a cancelled source. Fixed-size scalar attribute rows and the two bounded schema map entries remain separate from geometry-sized buffer replacement.

The language-neutral fixture repeats the independently indexed OBJ specimen 2,048 times. The native witness checks zero Work, allocation attempts and source progress when any one currency is short, then accepts the same replacement under its exact physical quote. It compares native capacity observation and copy/backing/release receipts, checks attribute positions and normal identity at widely separated rows, and retires a partially parsed source without publishing. Three.js OBJLoader independently compares sampled native data and the existing positive, negative, UV-only and normal-only round trips.

The registered Flow test covers quoted and settled capacity/copy/release, a deliberately short capacity turn and terminal cancellation. The full linked target remains storage-gated. Independent native builds and portable geometry checks use the actual Mesh Engine, mesh document and reconstruction sources.

The original native cursor reported 785,936 copied bytes across the wide fixture, with 131,072 bytes in the largest admitted replacement. Cancelling after 128 events retired 8,077 bytes without publication. Three.js matched all nine native position, normal and UV samples, and the portable Mesh suite passed 15 tests with 3,898 assertions. The Mesh Engine closure remains at 14 files, 240,691 bytes and 3,705 active lines. The edited Flow and procedural adapter sources passed the Rust parser.
