# Geometry channel direction and mesh history

Before two-direction spatial previews, the shared geometry enumeration took populated outputs first. It read inputs for a sink only when there were no output channels. The channel value tree reads both directions. This means a preview-enabled operator with an evaluated geometry input and populated scalar or geometry output can show the input data in the tree while its spatial input stays absent from the viewport. A graph wire hover can find the connected source identity, and a hidden source still supplies no canvas instance.

Previous mesh lookup now goes directly to the item's recorded direction, channel and structural path. An older evaluation can contain the requested input and a same-named output. The fallback then keeps the input's cached pack, even if that other direction would ordinarily be selected for viewport enumeration. A history entry from the other direction cannot substitute its geometry.

The actual native source witness passed the ten neutral history cases. The SQLite JSON-path oracle passed both of its checks and the registered Flow session fixture now holds both previous directions simultaneously for this case. Official linked verification remains gated by the disk reserve.
