The registered Fillet Edges operation accepts one to four distinct original parallel edges of a certified box. Opposite corners can use radii above half the short section dimension when every wall span stays positive. Selected edge labels must belong to the original box. Duplicate selections, mixed directions and collapsed spans are refused.

The shape uses one shared cross section with five to eight native vertices per cap. Each selected corner produces two exact quarter-circle edges and one additional cylindrical face, with shared opposite halfedge uses. The construction and funded primitive preview use the same ordered profile and arc ranges. Selection order does not change published correspondence. The retained preview labels each curved face and cap arc for deconstruction and individual preview. The original solid publisher owns all topology creation and cancellation.
