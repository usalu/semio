# Document Import Preview

The mounted editor import now evaluates servability against the replacement snapshot already decoded by the import command. A valid incoming graph can rearm an attached preview even when the old graph contains an unserved operator. A changed texture still uses the current graph. Importing an identical texture emits no mutation and requests no preview run. The load effect precedes the preview-start dispatch.

React awaits the archive load and stops the rest of that effect batch if loading fails or is cancelled. WGPU now parks the pending document load and its remaining effects. On success, it queues the rest of that batch ahead of newer held batches. It waits for preceding dispatched actions before starting any later load. A failed or disconnected load drops its own dependent effects. A change of application instance drops stale work, while a window focus change within the same instance retains the continuation.

The [portable import fixture](../../../../../../../✏️s/🔌️plugins/🌀️procedural/🗿️artifacts/🧊️generation3d/🏅️standards/🔖️1/🪆️subsets/✳️any/✏️editor/🧪️tests/🧫️fixtures/🔣️import-preview.json) covers two directions of graph servability, an unmounted replacement, identical texture and changed texture. An isolated Rust witness compiled the production import decision against that fixture and passed all five rows. The registered native editor test uses the actual mounted command and fixture. It was not linked in this pass.

The [WGPU witness](document-load-order-proof.py) ran the production queue with manually delivered load completions. Its [neutral cases](document-load-order.json) cover two ordered loads with intervening dispatches, failed load and independent later batch, a window focus change, and an application instance change during a load. It passed four cases under each native and wasm scheduling branch, with a mocked external archive-loader transport. The [jsdom test adapter](document-load-browser-preload.mjs) provided DOM globals to the existing React reprojection-status suite, which passed five tests and 184 assertions, including load progress and cleanup. The canonical compiler source-boundary preflight passed for WASI, Apple Silicon, Windows x64 and Linux x64, including the editor, import command and the four WGPU owners.
