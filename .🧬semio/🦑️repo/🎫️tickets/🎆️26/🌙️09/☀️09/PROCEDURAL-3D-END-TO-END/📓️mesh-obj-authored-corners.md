# Authored OBJ Corner Normals

The registered `brep.mesh.exportObj` path previously emitted the position stream, an optional texture stream and position/texture face references. It discarded authored normals and omitted a valid texture stream when every sample was zero. The synchronous mesh writer shared those omissions.

Both writers now use the same polygon channel resolver. It records the normal and texture attributes by rank in the immutable metadata index, one record at a time, with inline state. The normal stream retains separate indices and preserves corner, vertex, face and edge domains. Complete built-in vertex normals provide the fallback stream. Face records use the matching position/texture/normal or position//normal grammar and retain existing winding. An explicit zero-valued UV channel survives export. The original Flow writer funds each OBJ event, including attribute discovery, corner scans and normal emission, and its existing cancellation path retires the partial output without publication.

The neutral fixture uses two triangles with shared positions and different authored normals, plus an intentionally constant zero UV stream. The native witness rebuilt the mesh-document, reconstruction and 3D packages from source. It decoded the committed JSON with the original invoked polygon source cursor and wrote both channel combinations through the real mesh writer. Three.js OBJLoader parsed the hand-authored reference and both native outputs, preserving positions, normal discontinuity and authored UV values. The registered flow fixture checks Construct to OBJ output and cancellation during an emitted normal row. Linked Cargo remains below host storage admission. The OBJ importer remains a separate position-only mesh path. Persistence of the preexisting contiguous export string remains under its existing 16 MB cap.
