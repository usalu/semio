## Native Authority

Actual declarations, resets and consumers were read from existing semio-viz-coordinate/facet/label/theme/shape/scale.sty and semio-viz.sty. Coordinate axes accepts an integer or identifier list. Label series points use successive grouped pairs, and labels/values are per-point comma lists. Theme colors supplies explicit palette slots; the old font row was phantom and is removed because no native theme font key exists. Text font customization remains in its actual text owner. Shape forwards mark controls and now references api-path-mark explicitly.

The actual Figure window owns title/window/width/height. Frame height is automatic when omitted: only horizontal extent is initially pinned, and the native initial coordinate height equals width. Explicit height fixes the complete rectangle. The prior 80-by-40 implicit bounding-box prose was corrected in both languages. Stored scale unknown admits the existing numeric/string/bool/null result semantics and undefined sentinel; it is distinct from an empty or forwarding l3keys unknown handler.
