## Tracked Font Source Inspection

The existing font owner is `🔨️modules/🔤print-font-catalog`, with schema-backed descriptors and staging. It exposes no glyph measurement contract. The tracked Anta font has 2,048 units per em, 404 horizontal metrics, Unicode BMP cmap format 4, GPOS pair-positioning lookups and GSUB ligature/contextual substitutions. Share Tech Mono has 1,000 units per em, 194 metrics and GSUB ligatures; Noto Emoji includes Unicode format 12 and variable-font tables. Therefore summing approximate character widths would not reproduce actual Anta horizontal legend advance. Any portable read-side width interface must consume deterministic authored font metrics and preserve relevant shaping behavior; an actual native or canvas oracle remains necessary. Inspection output is retained in `🗑️generated/font-inspection.jsonl`. No font parser or external runtime dependency has been added.
