# Canonical Scientific Mode And Record Admission Proposal — 2026-10-05

The existing VizOptionSyntaxDescriptor gains optional recordFields and defaultsByMode. recordFields is an ordered array of owned field descriptors: syntax identifier/expression/text, nonempty boolean, enum string array, unique boolean, and reference {option:string,field:integer}. No external type enters the public interface. Records remain top-level comma-separated; fields are top-level slash-separated, honoring balanced groups and escaped delimiters. The existing generic record parser is extended with a delimiter parameter rather than creating a runtime module. Entirely empty records produce zero entries. Each row must have exactly recordFields.length fields, including its explicit empty final label. IDs/endpoints are nonempty; labels may be empty and retain authored grouping/escapes. Expression fields accept finite numeric literals and nonempty native numeric expressions. Literal NaN/infinity/overflow is rejected canonically; native guards reject any nonfinite evaluated expression before painting. Native expression evaluation remains authoritative, preserving authored grouped divisions, functions and macros.

Nodes use four fields: unique ID, x expression, y expression, label text. Edges use source ID reference nodes.field0, target ID reference nodes.field0, closed relation/style identifier, label text. Circuit elements use six fields: closed type identifier, x1/y1/x2/y2 expressions, label text. Pathway relation vocabulary is activate/inhibit/flux/plain. Abstract vocabulary is arrow/hook/double/dashed/wire/leg/order/dynkin-double. Circuit vocabulary is wire/node/ground/resistor/capacitor/inductor/source/diode/transistor/opamp/block/not/and/or/xor/nand/contact/coil/signal. Existing stock vectors and new Root-owned painters must agree with these declarations; unknown values cannot silently use a fallback glyph.

Mode descriptors carry exact enums: pathway [pathway,food-web,metabolic,interaction], circuit [schematic,logic,ladder,wiring,block,signal-flow], abstract [commutative,string,tensor,hasse,cayley,dynkin,proof,rewrite]. The four mixed owners add their complete supported enum: orbital [molecular-orbital,configuration,orbital], phase-diagram [binary,unary,ternary], electrochem [pourbaix,frost,latimer], pitch [shot-chart,pitch-map,pass-network,heatmap,positions,trajectory]. No unrelated mode family is narrowed without source adjudication.

For resolved cross-option validation, merge explicit stock entry options with authored preset.options only for validation, resolve mode from that merge or its declared default, then resolve each omitted records option from its descriptor defaultsByMode[mode]. Explicit empty overrides remain empty. Mode defaults are handcrafted schema assets matching the retained language-neutral18 vectors, and canonical tests require those arrays and the native actual default painter to agree. Formatters still emit authored overrides through the existing owner; they do not inject an alternate rendering system. Family-level cross-reference and uniqueness checks occur after this resolution, so nodes={} plus omitted nonempty edges rejects dangling defaults, while nodes={} and edges={} is valid. Partial custom nodes at changed positions preserve default edge IDs only when all endpoints exist. Multiedges are valid and preserve multiplicity; repeated node IDs are rejected.
