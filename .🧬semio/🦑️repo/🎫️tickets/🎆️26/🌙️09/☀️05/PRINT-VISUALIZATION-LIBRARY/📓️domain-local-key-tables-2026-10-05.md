## Native Authority

All families except text-viz use existing `semio-viz-domain.sty`; text-viz uses existing `semio-viz-text.sty`. Local boolean, integer, floating-point and token-list setters and actual defaults were read before authoring. Width and height inherit the frame with 80/40 mm fallbacks; domain padding defaults to 3 mm. The actual text-viz reset defaults to 2.5 mm padding. The optimization row/id keys share the actual agent binding; performance source/id share the actual id binding, rather than claiming separate defaults. Units are attached to geometry meanings and identifier bindings remain strings.
