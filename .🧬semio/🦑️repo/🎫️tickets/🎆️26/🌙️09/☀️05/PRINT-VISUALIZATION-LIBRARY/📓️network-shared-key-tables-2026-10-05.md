# Network Shared Key Tables

Handcrafted eight scoped tables from actual native keys, resets and consumers. Six helper tables supply 57 direct keys without duplicating inherited network keys; placement supplies 21 direct keys and force supplies 28 individually typed keys. Force collision iterations now have integer type, and grouped defaults are split into unambiguous individual rows. Base reset defaults and specialised-family overrides are qualified explicitly in English and German.

The source audit found three unresolved effective-control defects: placement seed is stored without reset or consumer; matrix split is stored without a drawing branch; network sizeBy=weight uses degree instead of weighted strength. These source facts are recorded explicitly rather than represented as working customisation. They remain execution work for the goal.

Only the existing force table and the new delimited NetworkSharedKeyTables region changed. Full before/after inputs, handcrafted bilingual rows, exact reversal data and seven source hashes are retained in 📥️authored-inputs/network-shared-key-tables. This is an authored source result, not a compiler or registered-test PASS.
