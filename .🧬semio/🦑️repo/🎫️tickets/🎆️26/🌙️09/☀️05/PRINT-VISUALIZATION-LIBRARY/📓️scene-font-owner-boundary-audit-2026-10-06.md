# Existing Scene Font Boundary Audit

Current read-only inspection 2026-10-06. Existing print render owner is `🧬️schema/💡️inferences/🖼️render/🟦️.ts`. Line 286 copies one item.font string into DrawingScene text node, converts TeX point size to mm, and retains the surrounding scene transform, anchor and baseline. renderVizScenePlan line 377 maps plan items through that owner. Native TikZ text line 433 resolves the selector through printFontTexSelector or explicit fontspec; native CJK transitions remain owned by semio-fonts.sty.

Shared framework DrawingScene text contract `🧰️framework/🔨️modules/◻️2d/🟦️.ts` line 42 carries one optional font string. Its Canvas painter line 248 sets `ctx.font = size + px + node.font`, then applies whole-text textAlign/baseline and draws full lines. It does not register or embed any tracked font itself. Host registration is therefore a prerequisite for deterministic Canvas font selection. The inspected generic drawingSceneToSvgMarkup line 313 handles only node paths: it returns an empty string for text nodes (nodePath returns no segments). It does not currently serialize text or embed print font assets. This source evidence does not establish another uninspected SVG backend's behavior.

No direct bridge from print DrawingScene font strings to the Rust UI TextSystem was found in the inspected print/2d owners. That separate UI owner exposes FontFamilyChoice SansSerif/Serif/Monospace/Custom(FontDependencyId), registers bundled fonts under fixed names, and uses host font dependencies. A CSS comma stack is not an appropriate replacement for this typed single-family registry interface; do not extend unrelated UI font systems merely to change the print scene contract.

Safest narrow existing print render extension: use current printSansRuns for Sans text only, preserve exact text and spaces, obtain each run's owned advance, and retain a single original text group's transform, rotation, baseline and whole-caption anchor. Compute total advance once; translate the group's start for middle/end anchors once, then place run nodes with start anchors and cumulative offsets. Do not independently centre/end-align every run or rotate around every run. Mono needs its own primary metrics/selector policy; replacing all non-CJK primary runs with Anta would alter an explicit SemioMono request. Every emitted run font must be an actual registered family, with exact tracked source bytes registered at the existing host boundary; font strings alone do not stage those assets.

For a browser SVG text owner, a single text element with tspans and a shared anchor/transform could preserve layout, but requires that an existing SVG text serializer first actually be identified or implemented in its existing owner and tracked font data URLs/resource references be emitted. The currently inspected generic SVG serializer cannot be fixed by changing item.font alone. Runtime assertions should cover mixed glyph ink and exact run advances, anchors, rotation and spaces in both browser Canvas and the registered native Canvas oracle.

This is a source-bound recommendation, not a runtime scene-font GREEN. Hash capsule retained as `📥️authored-inputs/scene-font-owner-source-capsule-2026-10-06.json`.
