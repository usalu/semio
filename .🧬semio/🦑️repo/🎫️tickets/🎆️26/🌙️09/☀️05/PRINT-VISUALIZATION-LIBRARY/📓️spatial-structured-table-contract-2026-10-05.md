# Spatial Structured Table Contract

The canonical table keeps its existing name, columns and rows. An optional owned structure discriminant declares how inference materializes those same rows for native spatial consumers: grouped geometry (polygon, line or point), indexed rectangular scalar grid, planar point set, or rectangular vector field. Column names are explicit; no name guessing or separate data service is introduced.

Geometry coordinates and optional per-part values must be finite numbers; every group has one consistent value and valid vertex count. Scalar grid row/column indices must be contiguous nonnegative integers with exactly one value per cell. Vector x/y coordinates must form a complete uniform rectangular lattice with at least two samples per axis; both components are finite. Invalid or incomplete structures fail inference atomically. All row walks use the existing inference cancellation checkpoints.

Native controls will apply one guarded mutation, replay the event and infer the emitted declarations in both explicit languages and both appearances. Existing D3 interpolation and projection libraries provide independent output checks. No runtime dependency or new module is planned.
