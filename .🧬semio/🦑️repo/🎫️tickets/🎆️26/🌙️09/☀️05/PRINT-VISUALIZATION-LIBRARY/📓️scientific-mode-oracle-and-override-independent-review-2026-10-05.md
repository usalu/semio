## Proven Scope And Important Limits

The helper explicitly sets pathway box and abstract none shapes plus unit in both halves; this intentionally tests mode list selection under fixed authored styling. It does not prove mode-conditioned omitted-shape selection. Preserve those authored shapes. Glyph equality checks compare string/origin/advance but not glyph font/size/bounds/fill; independent node check only horizontal center. For this bounded list-dispatch gate that may suffice, but do not claim full glyph geometry/style equality or vertical alignment until those are checked.

D3 grouping validates that authored edge incidence references existing node IDs. Its path construction ensures an independent line exists, and actual segments are matched to scaled node endpoints. Current matching is existence-only: it does not consume matches, assert edge multiplicity or prove the complete actual relation inventory; duplicate rows could reuse one segment. Arrow-style end tolerance1.8mm is reasonable for shortened shafts, but alone cannot distinguish activation, inhibition, plain, flux, hook, dashed or double semantics. Add endpoint-local head/bar and paint-state assertions with per-relation ownership or uniquely isolated head neighborhoods. The existing explicit painter used in both halves is not an independent style oracle. A reader that omits dash state cannot prove dashed-versus-solid behavior.

Current undirected Dynkin default test rejects every closed path in the body, so it depends on authored nodeShape=none and blank node labels; this is deliberate for this fixture, not a general Dynkin family invariant. Directed non-simply-laced Dynkin bonds and circular node decorations remain valid separate authored cases. Proof example supplies rooted premise/conclusion incidence but no rule bar; it tests the selected derivation graph convention, not a mandatory inference-rule layout.

Circuit component markers are strong. Output-terminal test currently checks AND/OR/XOR/NAND output projection; add their input-terminal reachability, and NOT input/output including the inversion bubble tip. A node with coincident terminals has no meaningful length division, so guard projection or branch by type before computing normalized axes. Contact checks two4mm vertical strokes/no closed body; additionally assert separate x positions and projected terminal leads. Coil checks two sampled arcs/no closed body; additionally assert opposite arc placement, terminals and no disconnected lead. Signal must have both shaft connectivity and a directed head located at its declared target, not any closed polygon somewhere inside the element. These strengthen semantics without relaxing the valid original gap RED.

The current Cayley stock vector and native default explicitly represent a directed C4 generator cycle e→r→r2→r3→e, all four relations labeled r. That is a meaningful finite cyclic-group example, unlike a generic four-node chain. Current proof/inference vectors use a rooted two-premise derivation graph; source promises graph glyph vocabulary, so a horizontal inference rule is not a mandatory missing feature. The phylogenetic-network stock vector currently is a rooted branching tree. Trees are an admissible special case of rooted networks, so this alone is not a runtime defect.
