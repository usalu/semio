\section{\ApiText{Authored spatial table views}{Verfasste r\u00E4umliche Tabellenansichten}}

\ApiText{%
  In the canonical chart snapshot, an optional \Key{structure} on \Key{VizTable} binds named column
  roles over the existing rows. Geometry uses \Key{kind=geometry}, \Key{shape=polygon|line|point},
  \Key{longitude}, \Key{latitude}, optional \Key{group}, and optional \Key{value}. Rows in each group
  form one ordered part with one consistent value; an omitted value is 1. Grids use \Key{kind=grid},
  \Key{column}, \Key{row}, and \Key{value}, with a complete rectangular set of nonnegative integer
  cell indices. Planar point sets use \Key{kind=points}, \Key{x}, and \Key{y}. Sampled vector fields
  use \Key{kind=vector-field}, \Key{x}, \Key{y}, \Key{u}, and \Key{v}, with a complete, uniformly spaced
  rectangular lattice containing at least two coordinates per axis. All coordinates and values
  are finite. Row changes use the same value mutation, diff replay and inference system as the
  rest of the chart. Inference emits the named native collection before the selected preset.%
}{%
  Im kanonischen Diagrammschnappschuss bindet ein optionales \Key{structure} an \Key{VizTable} benannte
  Spaltenrollen \u00FCber die vorhandenen Zeilen. Geometrie verwendet \Key{kind=geometry},
  \Key{shape=polygon|line|point}, \Key{longitude}, \Key{latitude}, optional \Key{group} und optional
  \Key{value}. Die Zeilen jeder Gruppe bilden einen geordneten Teil mit einem einheitlichen Wert;
  ohne Wertangabe gilt 1. Gitter verwenden \Key{kind=grid}, \Key{column}, \Key{row} und \Key{value}
  mit einer vollst\u00E4ndigen rechteckigen Menge nichtnegativer ganzzahliger Zellindizes.
  Ebene Punktmengen verwenden \Key{kind=points}, \Key{x} und \Key{y}. Abgetastete Vektorfelder
  verwenden \Key{kind=vector-field}, \Key{x}, \Key{y}, \Key{u} und \Key{v} mit einem vollst\u00E4ndigen,
  gleichm\u00E4\u00DFig verteilten rechteckigen Gitter mit mindestens zwei Koordinaten je Achse. Alle
  Koordinaten und Werte sind endlich. Zeilen\u00E4nderungen verwenden dasselbe System aus Wertmutation,
  Diff-Wiedergabe und Inferenz wie das \u00FCbrige Diagramm. Die Inferenz gibt die benannte native
  Sammlung vor der gew\u00E4hlten Voreinstellung aus.%
}

\ApiSig{\Cs{SemioVizPointSet}\{\meta{name}\}\{\meta{x,y; x,y; \ldots}\}}
\ApiSig{\Cs{SemioVizValueGrid}\{\meta{name}\}\{\meta{columns}\}\{\meta{rows}\}\{\meta{row-major values}\}}
\ApiSig{\Cs{SemioVizVectorField}\{\meta{name}\}\{\meta{columns}\}\{\meta{rows}\}\{\meta{xmin,xmax,ymin,ymax}\}\{\meta{row-major u}\}\{\meta{row-major v}\}}

\ApiText{%
  A vector collection stores its two components in row-major order over the declared rectangular
  domain. The vector family's \Key{field} option selects its name. Quiver arrows sample the domain
  lattice; streamlines sample both components with bilinear interpolation and integrate with RK4.
  Samples outside the domain clamp to its boundary.%
}{%
  Eine Vektorsammlung speichert ihre beiden Komponenten zeilenweise \u00FCber dem deklarierten
  rechteckigen Bereich. Die Option \Key{field} der Vektorfamilie w\u00E4hlt ihren Namen. Quiver-Pfeile
  tasten das Bereichsgitter ab; Stromlinien tasten beide Komponenten mit bilinearer Interpolation
  ab und integrieren mit RK4. Abtastpunkte au\u00DFerhalb des Bereichs werden an dessen Rand begrenzt.%
}
