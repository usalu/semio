# Native Work Collision Custody

Native replay preparation previously discarded a work-settlement refusal when its child had already failed. Root generalized the existing prepaid-node runner to scalar Copy results with a caller-supplied original receipt; owned child outputs must remain in funded persistent slots. Its existing RAII node guard remains intact.

NativeDecodeControl now exposes a generic with_retirement loan without changing its original ledger, observer or cleanup capacity. prepare_failure_storage admits a real collision node on a separate paid turn. run_prepared_work refuses to run a child without that node and the real work preflight, settles the child's actual work, retains both original failures and returns unused custody. An unwind returns the spare node before resuming the panic. Runtime is using this in native replay and migrating the paged preparation drivers.
