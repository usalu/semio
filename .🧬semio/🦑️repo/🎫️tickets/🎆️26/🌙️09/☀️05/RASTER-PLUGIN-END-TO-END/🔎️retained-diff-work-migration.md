## Selected-work cursor checkpoint

StringCursor retains an inaccessible byte vector and only converts its fully copied original UTF-8 bytes into a String; each copy turn selects no more bytes than the actual supplied work limit. The registered original-string-work law covers a single-byte budget and cancellation inside a multibyte scalar, but has not been compiled or run. The clone cursor, retained field, row patch and diff preflight interfaces now carry an explicit maximum work parameter. RowPatchApply and generic patch diff pass it to their actual selected children. Mutation decision and inverse interfaces and the set-field owner now carry the same parameter and gate on the selected work quote. Syntax parsing succeeded for the three latest changed Rust files; it is not a type check.

The migration is incomplete: other clone cursor implementations and generated and product callers still require the new parameter, and mounted callers must supply their actual remaining original work. Option cursor combines some child and parent actions, and alias admission has no defining work quote. Neither can be treated as a fixed one-unit action. Native integration and the complete Raster path remain unverified.

BoxCursor now separates child output transfer from the paid child close-start, and exposes selected child advance, take, and close work quotes. Its revised source parses; it has not been type-checked or exercised by a native law. The DSL retained mutation derive also forwards the selected work limit and gates each child turn on its work quote.

The BoxCursor child take and close-start quotes include the additional parent state action. Consequently a permanent one-work grant can still stall at these combined handoffs; a direct-to-slot owner contract is needed to split them safely. The neutral diff/diagnostic suite passed again (4 tests, 85 assertions); it does not validate Rust compilation or the mounted path.

A fresh read-only retained feature+unit census reports 256,476 bytes, 18 files and 1,827 lines, within the unchanged limits. The retained-clone derive record and enum paths and the clone field and owner wrappers now carry the selected limit; their downstream type migration is incomplete. The derive rustfmt invocation reported internal trailing-whitespace errors, so it does not establish a successful parse.

SharedOriginalStorage::duplicate uses AtomicUsize::try_update and reports one work unit despite contention-dependent retries. The SharedCloneCursor admission therefore lacks a sound bounded work quote; introducing a constant quote without a bounded retry contract would preserve that undercount.
