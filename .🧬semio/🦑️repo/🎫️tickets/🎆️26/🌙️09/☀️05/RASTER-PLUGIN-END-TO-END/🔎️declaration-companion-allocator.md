# Declaration App Companion Allocator Audit

The companion package 🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/📜️declaration/🧩️app/🧪️tests/🥣️companion/📦️packages/🦀️rust/Cargo.toml resolves its workspace to the repository root and all five local dev dependency paths to the named packages. Root Cargo.toml lists the companion as a workspace member. Its crate root mounts the moved fault and media-read test files with correct relative paths and imports their public APIs.

The companion crate root has no global allocator. The fault law invokes semio_framework_trace::observe_heap_allocations_on_this_thread, but that observer records only events emitted by the first-party HeapWitness global allocator. Without installing it, zero-event assertions are blind and a real retirement release can fail against an always-zero observation. Add #[global_allocator] static TEST_ALLOCATION_OBSERVER: semio_framework_trace::HeapWitness = semio_framework_trace::HeapWitness; at the test crate root. The trace crate is already a dev dependency. A positive-control allocation/free observed in the same test process should verify the witness is active. This source review does not establish compilation or runtime success; no build was started.
