# Host Event Command Birth Profiles

The four actual editor overrides now declare `host_event_demands` before their existing constructors. The domain quote is two command headers plus exact copied UTF8 string bodies; physical capacity is one boxed command header plus the constructed strings' capacities; depth is one and release is zero. The runtime source's own Option/ignored flag custody is outside this domain quote and remains the scheduler's separate responsibility. No handler or event behavior changed.

| Domain | Ignored events | Copied string bodies |
| --- | --- | --- |
| Raster | None | Abort phase plus event reason; BaseMoved uses refresh/baseMoved. No window-id copy. |
| Procedural | None | Abort phase, event reason and exact event window-id UTF8 bytes. Empty node array allocates no backing. |
| Layout | None | Abort phase and event reason. Empty ids array allocates no backing. |
| Remodel | All except Retiring | Retiring allocates retired only. |

All event variants are matched exhaustively. Saturating quote arithmetic refuses impossible overflow-sized combinations through the original finite grant instead of wrapping to a smaller demand. The quote does not invoke the command constructor or allocate a command.

## SDK Observation Fixtures

The two SDK fixtures previously cloned complete HostEvents into thread-local Vecs inside the domain constructor. Those unquoted observer allocations are removed. Shared testing/host-event-observation now uses64 inline Copy event records, each text field bounded to128 UTF8 bytes. Record capture allocates no String or Vec. Oversized text/event count marks overflow without growing storage; readback refuses an incomplete trace explicitly. The test-only take() reconstructs the original HostEvent vector outside the callback, preserving event kind, window id, utility from/to and order. Existing clear()/len() assertions remain meaningful.

TestApp declares a real two-header copy/one-header capacity profile for its blur Noop command. Its other events declare Some with zero domain command effects, so the original source invokes the fixed observer and receives None without allocating a promised box. ToyHistoryApp likewise declares Some with zero domain command effects for every observed event and still returns None. This uses the actual runtime_input contract confirmed by its owner: Some demand followed by None posts only its own ignored/header effects and one actual constructor work unit. None demand would skip delivery entirely and would invalidate these observation tests. Observer inline cells are external test instrumentation rather than retained command payload.
