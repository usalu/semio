# Reserved Domain Request Custody

The SDK reserved hook is moving to mutable source/output slots and the actual supplied StepContext. The generic request job owns the complete thirteen-lane request and funds its retirement after the domain work closes. Core hooks, lifts, runtime preparation, and Raster import remain assigned to react_selection.

Generation2d is the first converted non-Raster domain. Its work default allocates no heap storage. It borrows the exact original Media, snapshot, and completion from the retained request on each turn instead of cloning the whole Media or destructuring away unrelated request owners. The constructor no longer owns a partial request.

The domain's retained publication source bytes now have an explicit bounded close quote and terminal-empty condition. Retirement propagates actual delegated work on success and failure; a denied grant reports zero. Existing decoding and mutation publication behavior still need native execution; syntax checks alone do not establish it. Existing JSON parsing and mutation construction require a separate physical-work audit and are not claimed fully bounded by this request-custody refactor.

Eight other non-Raster overrides remain to be converted: Puzzle 2D/3D/5D, CAD, Drawing, Presentation, Layout, and Sequence. Each needs the same genuine request ownership and its own existing domain work preserved; no unsupported fallback or compatibility adapter is introduced.

Layout is now also converted in source. Its domain Work borrows Media, snapshot, history and completion from the original retained request. It closes the actual fault/checkpoint publications, refused completion, mutation rows and fault detail through exact existing retirement owners, forwarding their actual work even on refusal. Both modified files pass parse-only checks; domain/native import execution remains required.

Current parallel ownership: native_controls converts Puzzle 3D/5D, CAD and Drawing; root retains Puzzle 2D, Presentation and Sequence after its completed-source Generation2d/Layout changes. react_selection owns the generic SDK, runtime preparation and Raster import path.

Presentation is now converted to the same original mutable request interface. Its existing checkpoint/fault/complete flow remains, while media, snapshot, history and completion stay in the retained original request. Its private publication source bytes are now included in paid close and terminal emptiness, and actual child work is retained before propagating errors. Both changed files parse successfully; native behavior remains unverified. Root's remaining non-Raster conversions are Puzzle 2D and Sequence.

Puzzle 2D import/clipboard hooks and work are now converted in source, with actual immutable interaction reads, explicit presentation axes and funded private close staging. A seven-test Set/SQLite oracle validates the borrowed identity iterator; genuine native workflow tests are still required. Sequence remains root's unfinished non-Raster conversion.
