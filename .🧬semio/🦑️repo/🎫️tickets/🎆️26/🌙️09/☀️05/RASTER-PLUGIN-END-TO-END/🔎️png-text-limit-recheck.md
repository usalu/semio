# PNG Text Limit Recheck

The new measurement check subtracts transient inflater history from the already-owned total, then checks permanent rows/prior strings, normalized key length, accumulated value length and the next normalized byte against the configured maximum using checked arithmetic. Inflater history remains included in the simultaneous allocation demand. On rejection the decoder retains the actual inflater and reports the partial turn for paid retirement. The new compressed expansion law uses a 33,000-byte metadata maximum, one item per turn, requires refusal before 80,000 turns and drains the original decoder. No additional concrete defect was found in this source review; no native test ran.

History retained read admission and return move the same row between value and read owner while a directory pin may be active. The saved directory chunk pointer and slot ordering remain, and returned row references are tied to the current immutable ledger borrow, so safe Rust cannot simultaneously mutate that borrowed row. The row's address may change. Existing terminal page release checks read_count; the separately reported pinned-ledger retirement erasure remains unresolved.
