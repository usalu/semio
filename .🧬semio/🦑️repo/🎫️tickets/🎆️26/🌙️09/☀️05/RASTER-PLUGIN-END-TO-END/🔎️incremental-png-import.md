# Incremental Raster PNG Import Owners

The existing strict Base64DecodeCursor is at 🧰️framework/🔨️modules/🚪️io/🔤️base64/🎮️cursor/🦀️.rs. Base64Input accepts original OwnedText or OwnedBytes; new_range retains the complete owner, next_work_demand and next_capacity_byte_demand quote work and output allocation, step takes a work maximum and Base64Control, and take_output moves completed bytes once. cancel retains ownership; into_parts consumes the cursor and returns original input, range, partial output and outcome for caller-funded retirement. The cursor itself does not implement RetireOwned.

PngDecodeJob at 🧰️framework/🔨️modules/🔲️pixels/📷️png/📥️decode/🦀️.rs takes PngDecodeInput with owned Vec and explicit max_pixels, max_bytes, max_chunks; a refused constructor returns the input. Its limits cap pixels at 16,777,216 and encoded bytes at 67,108,864. It exposes copy/capacity/depth demand, advance(RetainedCloneGrant), last_turn_progress and last_turn_work including failed work, progress, cancel, decoded_properties and granted take_result. It derives RetireOwned for funded close. decoded_properties returns width, height, color_type and bit_depth; result is RGBA RasterImage and no text or ICC metadata API is exposed.

Raster currently uses semio_image_from_png_bytes in 🚪️io/🌉️semio-bridge/🦀️.rs:153, synchronously decoding a stdio PNG snapshot then dispatching the stdio Semio image deserializer. The actual converter at ✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/🧿️semio/🏅️standards/🔖️v1/🪆️subsets/🖼️image/🚪️io/📥️import/🧩️deserializers/🗿️artifacts/📷️png/🔖️1.2/✳️any/🦀️.rs preserves width, height, original color type mapped to SemioColorspace, bit depth and text chunks as metadata entries, builds one RGBA8 frame and explicitly sets icc to None. PNG native-decode retains text and ancillary data but is a synchronous controlled routine, not an incremental retained owner. Current semantic parity requires a new bounded metadata parser/projection alongside the incremental pixel decoder; true ICC preservation additionally extends current semantics. Do not silently discard text metadata or label an RGBA output as the original depth without recording the actual original metadata fields as this converter does.

No native tests were run. All cited source is subject to concurrent changes.
