# Retained Mask Intent Contract and Tests

The mask command schema now accepts only `layerId` and `expectedImageKey`. The action bridge checks that exact small member set before cloning or folding values, so incoming coverage payloads are rejected. Wire round-trip tests use the new small command, and mounted boot coverage first publishes the completed selection to config before requesting a mask. Its output oracle reads the raw local image frame rather than decoding a PNG.

The mask owner test suite was authored against the parent's planned `MaskSelectionWork` API before the production rewrite. The expected API is `begin_demands(command, document, config)`, `begin(command, document, config, grant)`, `demands(body)`, `advance(document, config, grant)`, `take_emit()`, `close_demands(body)`, `close_step(grant)`, and `terminal_is_empty()`. Begin returns an optional work/receipt pair; advance and close return retained clone steps. The parent owns the production module.

The authored tests preserve the neutral fixture and its Sharp oracle for white RGBA plus soft alpha coverage, while eliminating the PNG encode/decode round trip. Tests cover exact inverse history, scalar source/selection/protection guards, valid empty selection coverage, bounded invalid span rejection, zero-grant initialization and step starvation, receipt bounds, cancellation after multiple funded turns, funded close, and source/config changes before publication. Capacity tests cover replacement at 64 assets, shared prior child preservation, eventual refusal when a shared prior child cannot free capacity, and reuse of an existing destination at capacity. Every intermediate applied mutation must preserve the 64-child bound, and inverses must restore the exact original snapshot.

The neutral fixture additionally describes the small intent, scalar guard cases, cancellation cuts, and asset capacity. JSON parsing accepted the schema and fixture; their absolute paths are 151 and 161 characters respectively. Rust compilation and runtime tests have not run; the parent reported that the repository source admission pipe fails with EPERM. No alternative execution ingress was used.

Changed files are the mask command schema, mask command tests and neutral fixture, action bridge implementation, wire/action bridge laws, and mounted boot laws. The React overlay's small mask intent was already authored in the preceding React migration.
