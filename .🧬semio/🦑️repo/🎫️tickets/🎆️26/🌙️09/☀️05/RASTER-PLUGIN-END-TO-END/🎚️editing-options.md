# Shared Paint Editing Options

Native filter/resize/crop controls introduced local `filterKind`, `filterAmount` and `imageGrid` configuration, while React still staged its own filter, amount and dimensions. This split could show different values in the two implementations and silently replace shared staged dimensions whenever the selected layer changed.

Authored a required `Paint2dEditingOptions`/`Paint2dImageGrid` schema and neutral fixture before wiring the new carrier. The small options object stays in the scene spine. Native scene projection copies the actual configuration; Rust serde/value codecs and TypeScript types carry it through explicit public exports. There are no missing-field compatibility defaults. New codecs reject unknown/duplicate value fields, unsupported filter names and out-of-bounds grid coordinates/extents. The coordinate upper bound is 16384, matching the owning Raster configuration; an authored edge fixture prevents a narrower carrier from refusing valid configured state.

React now consumes these published options, sends `setFilterKind`, `setFilterAmount` and `setImageGrid` actions, and waits for scene feedback instead of privately changing displayed values. It exposes every admitted filter kind, grid coordinates, bilinear sampling and a grid crop action alongside the existing crop-to-selection action. Resize/crop consume the published grid and refuse unavailable extents; mask targets continue to hide destructive pixel operations. Selecting a new layer no longer overwrites staged dimensions locally.

Neutral tests cover serde/value/lane preservation, malformed carriers and the independent Ajv schema. A mounted test checks semantic setting commands, unchanged controlled values before feedback, an incoming gamma/grid scene, and exact filter/resize/crop command payloads. All four Rust scene fixture sites, wire golden, lane/typed fixtures and eight TypeScript scene literals were updated with explicit options. A light agent independently reviewed these sites while native selection work continued in the same fixture files.

Verification is limited to JSON parsing, path checks, static review and Bun syntax scans. Actual type checking, native tests and mounted tests have **not executed successfully** in this continuation because the repository's source-admission process channel fails before target execution. No zero-exit/no-output invocation is counted as a passing test. The overall raster acceptance remains open.
