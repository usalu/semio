## Compact Image Mutation Fields

The previous mutation image declaration encoded each RGBA8 channel as a numeric member. A 512×512 frame has 1,048,576 channels and the generic FieldValue vector exceeded Raster's 64 MiB mounted capacity during receive.

The AddLayerAsset mutation now declares frame pixels and the optional ICC profile as the framework's compact Bytes64 record fields. The record cursor retains the bytes in paged storage. Binding transfers each paged owner, then conversion reserves the destination pixel or profile buffer against the corresponding retention grant and copies one bounded page segment per turn. The final image Arc is allocated under the original effect. The existing Semio image snapshot and Raster diff formats retain their distinct schemas.

The language-neutral receiving fixture now pins the Base64 representation and the bytes of a 16 KiB paged frame. Sharp rasterized the frame through PNG and matched the fixture's SHA-256. The fixture oracle passed 3 tests with 13 assertions. The native law checks quoted text values, tagged binary size near the raw payload size, complete semantic recovery, and byte-identical re-encoding. Rust parsing and whitespace checks passed. Execution of the native law and the largest browser workflow remains to be verified in the shared build. The original record receiver reads individual octets per retained turn, so wall time for the larger browser case also needs measurement.
