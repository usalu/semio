# Raster Image Custody and Composite Effects

Raster image payloads retain their decoded pixel storage with a counted immutable Arc. Native receiving now uses the existing authenticated shared-constructor engine with an Arc lease output. The engine stages the output header, allocates one empty backing, and publishes the original decoded image into that backing. Cancellation clears the unpublished backing and the empty header before allowing the original input back. Raster maps the live lease into its image payload without another allocation and reuses the framework retained alias cursor for bounded clone and closure.

The payload exposes the framework's exact cold Arc birth grant and two work units. The payload's native retirement uses the actual Arc lease retirement cursor. The cold Raster retirement helpers now supply original effects to typed retirement or an already admitted factory ticket. The model's dedicated image-payload tests use the current original effects, native receiving scope and staged raw Arc operations.

The composite owners now receive the caller's retained effect. Preparation forwards the physical allocation marker to each allocator. The stack compositor batches work up to its turn grant and stops before reusing a marker occupied by an allocation. Preparation and composite closure run through the current original retirement poll. The blocking export edge opens its own bounded effects and closes the stack through the existing retirement driver.

The shared constructor fixture records the Arc output header, allocation and publication charges. Its SQLite/Ajv oracle passed 12 tests with 31 assertions. The existing native shared_owner Rust target passed both new Arc publication and cancellation laws in request 9082. Its outer repository wrapper was stopped during stalled automatic cache maintenance after Cargo reported both passing tests. The wrapper exited 130 and released the reservation.
