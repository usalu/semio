# Raster Owned Image Transfer

The importer previously supplied a SemioImageSnapshot where AddLayerAsset now requires RasterImagePayload. The worker now retains the decoded triple as its private candidate, admits the real shared image payload through the original construction recipient, then admits the two-row mutation vector and layer Box separately. A refusal returns or preserves the original image and source candidate; a post-construction receipt refusal leaves the born candidate in its persistent slot. No image pixel clone is introduced.

The image source, payload and mutation vector all participate in the same worker's funded retirement. The new native law checks denial of items, copy, capacity, depth and CPU at both payload birth and mutation assembly, the original RGBA pointer through both stages, and full paid cleanup. It is authored but not yet executed. Rust parsing succeeds; this is not a compiler or runtime verdict. True post-construction receipt refusal injection remains unproved.

The PNG, metadata and identifier work in the old pure converter remains synchronous and must still be decomposed. This repair makes the current mutation payload type and ownership transfer explicit; it does not establish bounded complete import or end-to-end acceptance.
