The published Draw editor passed the full English and German Chromium journeys. Each completed all 13 checkpoints, including clipboard, edits, undo, redo, a real folder save, reload and independent PDF rendering. The macOS memory incident, containment, package split and tool-runner regressions are recorded in [the memory incident report](memory-incident-26.md). The published Draw component also completed cold native precompilation. Runtime lifecycle validation is separate.
