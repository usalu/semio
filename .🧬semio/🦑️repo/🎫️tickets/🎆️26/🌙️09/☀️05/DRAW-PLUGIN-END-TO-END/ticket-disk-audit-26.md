# Ticket scratch disk audit

Read-only metadata survey on 26 November; no removal. Under this ticket’s `🗑️generated`, the strongest candidates for later cleanup are old direct Cargo scratch trees `e25/` and `e25t/`: respectively 15,712,370,688 and 11,771,473,920 bytes summed from file `st_blocks * 512`, with newest file mtimes 1795649071 and 1795649066. They contain mainly generated `.rlib`, `.rmeta` and test executables; all 37,495 regular files observed have link count one. They are not the named new `pacb6dd` lane. This is an inventory, not proof no open process or published artifact still refers to them: verify ownership and live file use before any deletion. Remove only those build trees if that check establishes they are retired; retain input scripts, logs and Markdown outside them.

Do not count the 27.48 GB sum as assured free space. macOS allocated-block accounting cannot establish uniquely owned APFS clone extents; the two trees contain same-sized repeated artifacts, and `nlink=1` does not rule out clone sharing. Actual released bytes can be substantially lower if clones or snapshots retain blocks. No destructive probe was used. `w25/` sums to 5,347,844,096 allocated bytes but the existing `native-clone-25.md` explicitly identifies it as an APFS clone of the original WASI lane and it includes prototype WASM outputs; exclude it from cleanup under the task constraint. No published/running assets or original guest caches were identified for removal.

A conservative smaller candidate is the historical generated test executable `focused-semio_s_artifact_draw_drawing_mutations` (169,029,632 allocated bytes, mtime 1795648876, link count one), subject to the same live-use and clone caveats. Metadata alone cannot give a defensible nonzero lower bound on bytes reclaimed. No source files, scripts, reports, caches, or processes were changed.

## Retired native test target

Only the retired generated e25t Cargo test target was removed. Its root held CACHEDIR.TAG, b and debug. A last-moment inspection of the user's open descriptors and the host command table found no reference to the target. The focused regression scripts still refer to e25, which was retained, as were the guest cache, all reports, inputs, and active compiler products. The volume reported 19,266,789,376 free bytes just before removal and 23,709,757,440 just afterward, an observed increase of 4,442,968,064 bytes during concurrent machine activity.
