# Descriptor Emitter Dependency Audit

The stored prototype emitter compilation receipt records 580 compiler-artifact units across 400 distinct package names, 441 marked fresh. Its selected binary is `semio-plugin-describe`; dev-only Wasmtime dependencies are not evidence of a release-tool dependency.

The emitter's own direct dependencies include two broad facades. Its `CanonicalDescriptorValue`, `PackageDescriptor` and `ASSEMBLY_FAILED_PLUGIN_ID` are reexports from `semio-framework-manifest-plugin`; its `Budget` and actor-turn types have existing `semio-framework-kernel` ownership. Its `store::pack_rt::{encode_wire_value,decode_wire_value}` comes from `semio-os-pack`. These direct references can be routed through those existing owners.

The exact reduction from that direct-only change is **zero removed umbrella packages and zero removed umbrella compiler units**: the required `semio-plugin-interpreter-runtime` directly depends on both `semio-framework` and `semio-os-kernel` with default features, as does the required `semio-plugin-guest-contract`. Both umbrellas and all their existing unit closure therefore remain required. The direct-edge change still improves ownership but adds no demonstrated dependency-build saving. Removing the facades from the runtime alone also leaves the guest-contract paths. Further work would require auditing all remaining transitive paths, API use, Cargo feature unification and actual unit graph; the stored provenance receipt is a list of artifacts, not a dependency-edge graph, and the available no-resolve metadata is stale. It cannot support a trustworthy exact deeper reduction or compile-time estimate.

For the actual fresh-component path, `fresh-component/🟦️.ts` calls `buildDescriptorEmitterV1` before `buildComponentClosureV1` and holds the emitter for component description. The emitter owner checks the published artifact's freshness and rebuilds it if missing or stale. Thus a real reduction of its transitive build closure could reduce cold or stale prerequisite latency; it would not reduce compilation of the WASI component itself, and a fresh emitter avoids that rebuild. The direct-only change above has no demonstrated speedup. No compiler was run during this audit: a unit-graph query requested through the tool registry was held by capacity admission and was cancelled.
