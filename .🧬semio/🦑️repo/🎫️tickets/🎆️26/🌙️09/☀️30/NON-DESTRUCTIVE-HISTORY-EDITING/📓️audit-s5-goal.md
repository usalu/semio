## Clause 1 — "In the history a mutation must be editable"

**Mechanism (VERIFIED)**
- Address of an edit: `MutationId` = `mutation_meta[i].mutation_id`, else `Mutation::mutation_id()`, else `<editId>#<opIndex>`
  (`FW/🔨️modules/📡️replication/🔗️causal/🦀️.rs:817` `mutation_ids_for_edit`, `:826` fallback chain). A composed member store is addressed by
  the extra verb arg `store = "<slot>/<childId>"` (`OS/🔌️plugin/⏪️time-travel/🦀️.rs:2707`, `TimeTravelMemberSubject::store` `:146`).
- The edit itself is a history transition `HistoryTransition::Supersede(TransitionSupersede{scope, inputs[SupersededInput{target, replacement}]})`
  with `InputReplacement::{Input{schema,payload}|Withdrawn}` (`FW/🔨️modules/📡️replication/🔗️causal/🔀️transition/🦀️.rs:53-75, 129, 135`).
  The op is never rewritten; the fold resolves an `EffectiveSupersession` per op (`effective_forwards`, `OS/🏪️store/🦀️.rs:23730`).
- Supersede law applied at author, ingest, load and fold: `admit_replacement` (`OS/🏪️store/🦀️.rs:23701`): original must not plan foreign steps;
  replacement must decode as the artifact schema, re-encode canonically and plan no foreign steps; otherwise the op folds as a `mutation.invariant` Fatal no-op.
- WHICH rows are editable (single predicate, row side): `history_mutation_view_of` -> `editable = !viewer && !shown.may_emit_foreign_steps() && shown.input_schema().is_some()`
  (`OS/🔌️plugin/⏪️time-travel/🦀️.rs:1615`; `shown` = the effective (already superseded) op). Session side repeats the test in `TimeTravelStoreState::open`
  (`:720-770`; refusal `NotEditable` at `:726` when `encode_op` fails and `:733` for foreign steps / no input schema; `UnknownMutation` when the id is not an applied op `:722`).
- What makes a row NOT editable (VERIFIED): (a) `Mutation::may_emit_foreign_steps()` is TRUE by default (`FW/🔨️modules/📡️replication/🎮️mutation/🦀️.rs:223`),
  derive answers per leaf (`OS/🗣️dsl/✨️derive/🦀️.rs:1103`) and every `CompositeMutation` hard-answers `true` (`:1307`) -> composite/foreign-step ops are never editable (design §9.7);
  (b) `input_schema()` is `None` by default (`…/🎮️mutation/🦀️.rs:250`); a leaf with `#[mutation_leaf(payload = Variant)]` is editable only in that variant (`OS/🗣️dsl/✨️derive/🦀️.rs:572` payload-variant arm, `:589` instance-schema arm), so internal inverse variants (`Restore`) are not;
  (c) viewer role (`A::ROLE == AppRole::Viewer`; also `viewer_rejects_action` refuses every history-edit verb, plugin `🦀️.rs:24547`);
  (d) hydrated head-only pure lane: history verbs answer `pure.history-unavailable` (`TimeTravelLedger::history_unavailable` `⏪️time-travel/🦀️.rs:322`);
  (e) session `Busy`: mutating tool run / agent transaction / open tool transaction / authoring of an undo-redo / local step pending (`time_travel_busy` `:2693`; `begin_time_travel` `:2702-2766`);
  (f) a session already open on another store (`:2708`).
- User-visible control: the Edit row action on each mutation child row, `historyEditBegin{mutationId, store?}`, also the row activation; disabled with a localized reason when `begin_refusal` (`OS/🔌️plugin/🦀️.rs:12859-12871`, `begin_refusal` `FW/🔨️modules/⏪️time-travel/🦀️.rs:663`).

**Reach**: store (supersede fold, `mutation_ops` `OS/🏪️store/🦀️.rs:19248`) -> plugin runtime (`open`/`begin_time_travel`) -> `HistoryMutationEntry.editable` on the wire (`history_mutation_entry` `⏪️time-travel/🦀️.rs:980-1011`) ->

## Clause 3 — "the user sees the current mutation and the downstream mutation are not yet applied"

**Mechanism (VERIFIED)**
- Preview = state BEFORE the target (with accepted upstream drafts) + the draft op folded once with keep-and-record semantics:
  `TimeTravelStoreState::preview` (`OS/🔌️plugin/⏪️time-travel/🦀️.rs:783-804`) -> `ArtifactStore::derived_snapshot_before` (`OS/🏪️store/🦀️.rs:18207`) -> `state_before` (`:19347`) -> `derive_history_snapshot` (`:18213`: `diff` + `apply`; an apply refusal becomes one `Fatal` message and the preview keeps the base).
- Render seam: `TimeTravelLedger::render_snapshot_or` (`⏪️time-travel/🦀️.rs:280`) returns the preview while `Editing|Replaying`, the replayed head while `Reviewing|Choosing|Finalizing`, else the committed snapshot (tool-run overlay for Inactive). A composed-member session leaves the parent document alone and swaps the member via `render_children_or` (`:290`). Comment on `:277`: polls/commands/context menus keep deciding over what landed, never over the preview.
- Downstream marking in the history: `pending = view.store == panel.store && panel.pending_after.is_some_and(|a| (position, op_index) > a)` (`history_mutation_entry :993`) -> dimmed row with clock icon (`history_panel_mutation_row`, plugin `🦀️.rs:12840-12865`).
- Cost model:
  - Editing preview is **not a replay**. `state_before` = `prefix_state_recorded` (`OS/🏪️store/🦀️.rs:20760`) picks the nearest prefix snapshot whose forwards-only digest matches, from a ring of about sqrt(n) retained prefix projections (`prefix_ring_capacity :20831`, `prefix_stride :20824`), then folds <= one stride plus the target edit (`:19347` doc). Each draft keystroke costs: O(n) cheap digest-chain steps over ALL applied edits (`forward_prefix_digests :23912` is computed for `applied[..from]` AND for the whole live order every call, `:20761-20762`) + O(sqrt n) heavy fold + one op diff/apply. Not O(change), not a full replay: "O(n) hashing + O(sqrt n) folding". When an accepted draft lies upstream of the edited target the digest no longer matches the ring beyond the first draft, so the fold restarts from the nearest ring entry at or before the earliest draft (`live_until`, `:19351-19365`), i.e. O(distance between first draft and target) heavy folds per keystroke (INFERRED from reading `prefix_state_recorded`).
  - After Accept: Report replay from the earliest accepted target (`begin_report_replay :19379`, `replay_window :20704`), live base = nearest live prefix, with **convergence early exit** (`EditReplay::converge :24340`: stops at an edit boundary when running state `Arc::ptr_eq`/`PartialEq` equals the live projection at the same prefix and splices the unchanged tail, `replay_report :19405` splices durable outcomes). Enabled for the document store at instance creation and store replacement (`OS/🔌️plugin/🦀️.rs:25235, 26253`). So the replay is O(change) only when the edit's effect converges (needs `P: PartialEq`, the order unchanged and the horizon past the last changed input, `report_replay :20717-20725`); otherwise it is O(suffix). Convergence is only probed at EDIT boundaries (after `close_edit`), so one very long edit (typing run, tool transaction) is replayed to its end first.
  - The replay is a stepped job: <= 4 ms wall per reactor turn (`step_time_travel_replay :2957`, `TIME_TRAVEL_TURN_WALL_US`), progress ticks throttled to 100 ms / 5 % (`:42-46`), cancellable (`historyEditCancelReplay`, `TimeTravelStoreCommand::CancelReplay :689`); every replayed op also computes `operation.inverse(base)` (`EditReplay::replay_operation :24246`, the `operation.inverse(base)` call is inside it) — extra per-op cost in Report mode.

**Reach**: store -> ledger preview -> render seam -> app `render` (VERIFIED: exactly four `render_snapshot_or` call sites, all inside `VcsArtifactApp::render`, `OS/🔌️plugin/🦀️.rs:35738, 35775, 35820, 35858`; the `snapshot_override_json` branch at `:35717` bypasses it by design) -> guest-built UI tree -> React + wgpu (both consume the same tree, so no per-renderer preview code). Not verified: readers other than `render` (hit-testing, selection resolution, `entity_label`, export, engagement/measure paths) — by design they "keep deciding over what landed" (`⏪️time-travel/🦀️.rs:277`), so a canvas pick during Editing resolves against the committed doc while the pixels show the preview (INFERRED consequence; not checked in a probe).

**Proof on disk (not run)**: store `state_before_answers_the_projection_before_an_operation_under_drafts` (`OS/🏪️store/🧪️tests/🧪️supersede-replay/🦀️.rs:417`), `convergence_early_exit_equals_the_full_replay :380`, `cancelling_a_report_replay_at_every_step_leaves_the_store_untouched :344`, `prefix_ring_evictions_retire_through_the_snapshot_factory :469`; hot-path census counters in test builds (`OS/🏪️store/🦀️.rs:15227 hot_path_census`, counted in `forward_prefix_step`). Corpus oracle: fast-json-patch (`supersede-replay` fixture). Plugin: `a_deferred_history_step_ends_its_turn_at_the_wall_deadline_not_an_operation_count :2059`. Live: clause 13.

**Verdict: COMPLETE** for the semantics; PARTIAL on the cost claim (see gaps).

**Gaps**
- G3.1 (M) Preview cost is O(n) digesting per draft keystroke (`prefix_state_recorded :20761-20762` rebuilds both digest chains each call). Cache the live digest chain on the store (it only changes with history) and compute the draft chain incrementally from `live_until`.
- G3.2 (M) Early-exit convergence only at edit boundaries (`EditReplay::converge :24340` is called after `close_edit`); long transactions are replayed whole.

## Clause 4 — "The user can either finalize the input change for the mutation or discard the input change" (Accept / Discard)
