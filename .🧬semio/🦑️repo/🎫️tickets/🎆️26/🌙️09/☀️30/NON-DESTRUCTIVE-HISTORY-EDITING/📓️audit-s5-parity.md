## 3. Descriptor → control mapping

### 3.1 The one function that maps a descriptor to a control for the history editor (guest-side, shared by both renderers)

There is exactly one: `time_travel_input_row` (TTG:4019-4330). It runs in the guest; React and wgpu never see a descriptor, only the nodes it emits.
Two-step derivation:

1. `ActionArgDef::control()` (MAN:861-910) turns schema + presentation into an `ActionArgControl` (MAN:466-663). Its number arm (MAN:877-889):
   ```
   Some(ArgPresentation::Slider)  => ActionArgControl::Slider  { min: travel_min, max: travel_max, … scale: *scale }
   Some(ArgPresentation::Dial)    => ActionArgControl::Dial    { min: travel_min, max: travel_max, … }
   Some(ArgPresentation::Stepper) => ActionArgControl::Stepper { min: *min, max: *max, … }
   _ if *integer                  => ActionArgControl::Stepper { … }
   _ if min.is_some() && max.is_some() => ActionArgControl::Slider { min: travel_min, max: travel_max, … }
   _                              => ActionArgControl::Number  { min: *min, max: *max, … }
   ```
   (`travel_min = soft_min.or(min)`, MAN:878). Other arms: string with options or `optionSource` → `Select` (or `Segmented` for presentation `segmented`, MAN:864-869); `format: IconId|ArtifactKind|SurfaceApp` → `IconSelect|ArtifactKind|SurfaceApp`; `Boolean` → `Toggle`; `Vector` + presentation `Color` → `Color{alpha: dims==4}`, else `Vector`; `Reference` → `Reference`; `Array|Object|Any` → `Text` (MAN:908).
2. `ActionArgDef::number_facets(locale)` (MAN:1129-1175) derives `ActionArgNumberFacets` (MAN:1082): min/max (a slider/dial's travel, a stepper/number/axis' hard bounds minus excluded ones), step, appearance (`Dial` for dial), scale (`Log`), unit and display unit as symbols (`deg`→`°`, `percent`→`%`, MAN:1104), display factor, precision, detents (sanitised: ascending, finite, inside the range, not crossing a limit, MAN:1164-1172) and `UiNumberLimits` whose localized refusal names the bound ("Must be at least 0 °" / "Darf höchstens 180 ° sein", MAN:1113-1124, 1157-1163).
