# JSON and XML Semantic Snapshot Relations

Read the owned Rust RFC8259 JSON snapshot model and XML1.0 document model before authoring either mapping. JSON persists schema and JsonValue: null, boolean, arbitrary precision number lexeme, string, ordered array and ordered object members. Duplicate keys are native RFC8259 model state; preserve their order and exact number spelling. XML persists schema and XmlDocument: optional root, declaration, doctype, ordered prolog/epilog; elements, ordered attributes/children, text, CDATA, comments, processing instructions; declaration version/encoding/standalone/quote; doctype prolog position/name/external SYSTEM or PUBLIC IDs; ordered general/parameter entity declarations. Geometry/domain interpretations of other artifacts are outside these codecs.

JSON uses four handwritten SQL tables: document, typed value, object member and array element. Number lexemes are individual scalar columns, not serialized documents. XML uses thirteen handwritten tables: document, discriminated node, five node payload components, ordered attribute and child relations, ordered document boundaries, declaration, doctype and entity. Each nullable field remains NULL, each native variant has explicit kind/payload validation, and every relationship has an explicit foreign key. Neither codec serializes native pack/DSL/XML/JSON into a container column.

Projection preflights row and semantic byte budgets using borrowed iterative traversals. Reconstruction preflights shared database resource guards and the declared SQL contract, then validates identifiers, field counts, scalar types, variant shape, dangling relationships, unique ownership and contiguous ordinals. Iterative postorder reconstruction rejects cycles and disconnected forests. Shared controls checkpoint counting and reconstruction work every256 entity units, before large field copies and before ordered group sorting. XML invokes the existing native boundary validator for declaration compatibility, doctype placement and legal prolog/epilog nodes.
