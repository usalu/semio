## Exact Owned Semantic Candidates

IFC2x3 Node directly holds coefficient: Option<String>, scale: Option<u32>, exponent: Option<i32> and negative: Option<bool>. Projection copies the actual coefficient through the controlled text producer and copies numeric words directly. Reconstruction only requires coefficient presence for decimal nodes; it does not impose decimal-digit/external-exchange validation. It constructs Part21Decimal from these four exact fields. This preserves arbitrary coefficient state and maximum scale/minimum exponent in the candidate source; current production provider coefficient restrictions remain the already documented independent issue.

STEP and IFC4 Node hold Option<f64>. Projection/reconstruction copy the actual f64 directly. Independent canonical DslField f64 binding uses FieldValue::Float and returns the word directly without a finite-value predicate. Controlled native DSL emission uses nan64 followed by the exact to_bits hexadecimal word for NaNs. These paths provide a concrete semantic mechanism for preserving raw IEEE payload words without Part21 printing/parsing or JSON conversion. Actual Binary/Text roundtrip remains unexecuted in this audit.

Reverse-preorder reconstruction checks children follow their parent; consuming Option slots detects missing or multiple ownership. STEP typed nodes require exactly one child, and their Box backing is charged before Box::new. IFC typed nodes retain ordered variable child lists. Borrowed input census precedes frame ownership; candidate projection measures typed node groups before allocating complete pending frontiers and admits complete node backing from the census. Cold guards protect completed frames, nodes, reconstructed collections and dependent names. These source properties do not prove unmounted candidates compile or all cancellation paths execute successfully.
