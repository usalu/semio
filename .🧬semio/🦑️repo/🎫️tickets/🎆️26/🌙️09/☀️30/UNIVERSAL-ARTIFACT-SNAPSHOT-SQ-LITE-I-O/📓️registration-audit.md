# Universal Snapshot Registration Audit

Read-only source audit of the shared working tree on 2026-10-01. No code changes or independent test execution. Root owns integration tests; this report does not claim runtime coverage from source inspection.

## Initial Findings and Repair Status

1. **Foreign app codecs omit SQLite native registration.** `ArtifactRegistrationPlan::from_declarations` in framework plugin source, around lines 4390–4392, adds foreign specs only to `document_codecs`. Owned and hosted specs add both codecs and `native_snapshots`. Production callers include `s.space` plugin line 241 (`SpaceApp`, `OS_SPACE_SCHEMA`) and procedural playbook extension line 1116 (`ModuleApp`, `MODULE_DOCUMENT_SCHEMA`). Exact native coordinates must be registered for these apps too. Schema aliases sharing one typed validator should not create false conflicts. Integration agent was notified and accepted this repair.

2. **Declaration-tree publication can partially mutate codecs/formats before snapshot failure.** `commit_artifact_declarations` around lines 38970–38972 performs three fallible mutations under one assembly barrier after an earlier preflight without that barrier. A concurrent registration between preflight and barrier acquisition can invalidate the earlier preflight. The integrated `commit_artifact_assembly_registry_plan` helper already acquires every affected lock, preflights all candidates, and only then mutates. Use it for declaration-tree codecs/formats/native snapshots. `PluginBuilder::try_build` calls this path at builder source line 743. Integration agent accepted this repair.

3. **Public direct app codec helper remains store-only.** `register_document_codec_for_app` around line 41817 registers `ArtifactCodec::of` without registering `A::DIALECT` in IO. No executable repository callers were found (only comments), so this is an exposed helper/API gap rather than an observed production boot path. Existing stdio direct `io::register()` helpers also publish store codecs only; production immutable declarations supply the SQLite registration. Clarify/remove unused direct helpers or make them publish both registries atomically if their supported invocation is intended to produce SQLite routes.

## Coverage Inspection

The inventory contains exactly 58 executable `document_codec_bare` registrations. Independently extracted all 58 triples and verified that each coordinate has another literal coordinate or matching dialect declaration under that exact artifact root. This includes both IFC standards (`4`, `2x3`), both PDF standards (`1.7`, `1.4`), and both GIF standards (`87a`, `89a`). No coordinate mismatch remained.

The app codec spec retains `ArtifactApp::DIALECT`; immutable owned and hosted declarations collect every document codec as a native snapshot registration. New declaration trees collect `subset.dialect` with `subset.io.native.codec` in both preflight and commit. Artifact-root source sweep found 96 top-level artifact root Rust files; roots lacking local `document_codec` expressions delegate through standards/declaration trees (remodeling, semio, sequence, writer, vcs, wfc variants, sourcing, note, forms, mathematical). This proves registration mechanisms cover the observed declaration forms; it does not substitute for booting every plugin and enumerating every runtime subset.

Ownership checks reject owned codec dialects whose kind differs from the declared root. Hosted declarations validate dependency ownership and then their channel ownership. New subset trees validate exact artifact-root ownership. Native registration rejects malformed coordinates, reserved SQLite endpoints, control characters, and missing validators. Duplicate same-coordinate codec conflicts compare schema and typed validator identities in the inspected source; foreign schema alias handling needs the repair above.

## Route and Atomicity Inspection

SQLite IO routes are supplemental exact single endpoint hops. `io_run_with_snapshot_control` rejects disconnected routes, multiple hops involving SQLite, nonexact fidelity, and mismatched supplemental descriptors. Import checks the embedded coordinate against the expected destination and validates the recovered typed payload. Export validates typed native payload before constructing the database. SQLite routes cannot serve as cross-artifact intermediate conversion paths. No route misuse was found in these guards.

The integrated assembly helper preflights native snapshots, composer entries, subset validators, formats, store codecs, and migrations before its first mutation while holding affected write locks. No new fallible operation follows its first mutation. Declaration-tree publication outside this helper is the concrete atomicity gap above. Other schema/language/IO declaration publication remains split across registries as documented by existing code; this audit does not claim whole-plugin rollback.
