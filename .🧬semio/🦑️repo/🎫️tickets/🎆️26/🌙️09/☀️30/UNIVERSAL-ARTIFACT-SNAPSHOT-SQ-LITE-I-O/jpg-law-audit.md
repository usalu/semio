# Genuine JPG Publication Law Design

Read-only original owner design audit. PNG's existing publication law first exercises literal owned logical fixtures and demo Pack/DSL assets, then reads its one actual factory, compares compiled protocol bytes with current disk bytes, independently hashes those bytes, checks live pack hash and kind/schema/extension, and emits the publication receipt. It does not itself assert TypeId; JPG should make that explicit through its concrete SQLite capability.

JPG actual factory is `stdio.native.jpg.v1`; kind is `s.stdio.jpg`; codec schema is `stdio.jpg`; extension is jpg. Its original bare factory in `📸️jpg/🦀️.rs:42` uses JpgSnapshot/JpgMutation. Logical Pack is the original Semio envelope + owned record, not raw JPEG. Its ArtifactPack implementation explicitly publishes a snapshot SQLite codec (`document/io/💾️binary/📸️snapshot/🦀️.rs:20–29`). Original DSL uses the same authored logical schema. Raw encode_jpg/decode_jpg is a separate lossy image carrier and must not be substituted for exact logical carrier identity.

Use the independent complete `document/io/🪶️sqlite/📸️snapshot/🧫️fixtures/🔣️.json` as a native snapshot witness: arbitrary schema, RGBA octets, exact JFIF version/density, optional thumbnail octets and ordered duplicate APP/COM metadata. Those fields are defined by JpgSnapshot.image and its original JpgImage schema. Exact Pack/DSL roundtrip compares the entire original snapshot, not just dimensions or reencoded JPEG pixels. Existing demo logical assets can be independently checked against demo_jpg_snapshot. Existing raw JPEG independent encode/reopen metadata law remains a separate rawcarrier proof.

Compare live factory against an independently constructed original `ArtifactCodec::bare::<JpgSnapshot,JpgMutation>(STDIO_JPG_DOCUMENT_SCHEMA)` for concrete schema and structural pack hash, and assert snapshot_sqlite concrete TypeId is JpgSnapshot. Compare kind/schema/extension to defining constants. Hash actual compiled protocol bytes independently and require current disk bytes unchanged before emitting schemaVersion1/artifactKind/artifactSchema/factoryId/extension/packSchemaHash/protocolSourceSha256. Do not derive expected identity or protocol hash from existing stale publication JSON.

Shortest original mount is appending the exact selector `owned_fixture_publication_reports_canonical_logical_carriers` to existing `document/io/🧪️tests/🔬️unit/🦀️.rs`, already mounted at io root1340; no new command or deep new test path is required. Existing `@semio-tech/stdio-plugin:native-codec-projection` target and generate launch entry dispatch the permanent guarded refresh command. Validate actual receipt test dispatch before publication: requested selectors have previously been dropped by generic test forwarding. A successful compile with no matching test cannot produce the required one receipt.

BIM scope correction: its mounted public laws call the original IO declaration provider's export/import functions directly. This qualifies that provider if executed, but does not by itself exercise Kernel `io_export_sqlite_snapshot` with the real registered typed/public envelope.
