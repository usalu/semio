# Existing Hosted Kind Codec Preflight Enumeration Join

Read-only exact current API audit. Old declaration hosted_kinds3679 returns one public HostedArtifactKind{id,schema,owner} per private document codec; no stand/subset/dialect field. Store async document_codec(schema)11854 retrieves a clone of the actual registered ArtifactCodec. This removes the need for a new old-declaration schema enumeration accessor.

NativeSnapshotRegistration::from_capability2177–2187 requires Some(snapshot_sqlite), otherwise None. preflight_native_snapshots2229 is read-only and proposes against the current registry. For an already existing exact dialect it compares codec extension, Pack schema hash and ArtifactSqliteSnapshotCodec::identical_to: exact SQL schema, optional concrete snapshot TypeId and export/import function identity. It does not compare ArtifactCodec.schema itself. It also succeeds for an absent valid dialect, because preflight tests admissibility/conflicts, not membership. Therefore combine it with native_snapshot_sqlite_schema(candidate) success and exact SQL equality, and exact bidirectional io_entries/route membership. Require snapshot_type Some rather than accepting two None values as concrete identity evidence.

Candidate coordinates inferred only from already published io_entries cannot prove a missing declared stand/subset: old hosted_kinds supplies schema/kind but not expected dialect roster. For a known old declaration owner, use its actual authored dialect/format/native factory binding, or its primary new declaration tree. Otherwise retain that specific dialect-membership limitation rather than calling the inferred list exhaustive.

Actual stdio contract ArtifactAssembly107 has Definition(ArtifactDefinition) and Runtime(Box<old ArtifactDeclaration>). definition() unifies only definition metadata. ArtifactContribution180 exposes identity/schema/constraint and callable definition/assembly/formats/native_codecs. Runtime supports hosted_kinds; Definition can declare kind/schema/codec capabilities without any hosted document row and must remain visible in the denominator rather than silently discarded. Native factory list can also be empty, as actual IFC illustrates, despite Runtime document codecs.

Primary new tree already supports exact enumeration without a registry API: each public artifact(...) producer (e.g Binary root96 and Playbook root371) returns declaration::ArtifactDeclaration with kind→standards.id→subsets.dialect/schema/io.native.codec. Its codec provides exact schema and snapshot_sqlite identity. Public old generation2d declaration151 is component-app-assembly gated and uses old builder; hosted_kinds is usable there. Execute primary composed builders with their actual required features, retain Definition-only entries as explicit capability membership, and traverse new trees for complete dialect expectations. No arbitrary initializer or count is proposed.
