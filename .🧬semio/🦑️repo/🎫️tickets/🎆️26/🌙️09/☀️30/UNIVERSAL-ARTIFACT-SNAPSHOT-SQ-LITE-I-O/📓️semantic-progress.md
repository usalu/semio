# Semantic SQLite Implementation Progress

The expanded objective is active and incomplete. The initial opaque snapshot container is being removed, not retained as a fallback. The planning inventory covers 149 dialect/subset schemas; none may silently use a serialized pack or JSON payload instead of its domain schema.

## Shared Infrastructure

The Rust and TypeScript file engines expose typed relational tables, signed integer row identifiers, INTEGER/REAL/TEXT/NULL/intrinsic binary cells, schema and table B-trees, overflow pages, explicit limits and cancellation. Independent SQLite tests query entity joins and recover data after SQL edits. Exact native I/O registrations remain atomic and SQLite remains an endpoint, so unrelated snapshots cannot convert through it as an intermediate.

The owned `ArtifactSqliteSnapshot` contract contains each snapshot's handwritten SQL and typed projection/reconstruction methods. Native document codecs explicitly publish their provider capability; missing owners still require implementation before the planned mandatory catalog preflight can be activated. Providers receive cancellation/progress control. No reflective value-tree fallback is allowed. Guest-loaded semantic providers remain a required coverage item.
