## Genuine receiving shape

Use the original encode owner's scoped_native and receive with an actual intermediate `Option<(Option<Vec<u8>>,Option<IoPayload>)>` or equivalent original typed body and candidate slots. Birth the body slot before its first allocation. Append source line bytes and actual LF/CRLF separators directly into that retained vector, checkpoint after accepted chunks, and record accepted body progress even on cancellation. Text can consume the Vec into String without another allocation; Binary needs a separately retained envelope candidate born before its allocation. Move the final candidate only into receive's output, which pays publication and preserves it if retirement or final checkpoint refuses.

Do not simply call wrap_binary_controlled under receive: the wrapper allocates a local Vec and returns early through `?` on cancellation, so its partial output is dropped before the receiving slot can retain it. A genuine into-slot declared-envelope encoder is required, or manually emit the identical declared prefix into the installed candidate slot. Source authority for prefix bytes is `🧰️framework/🛍️products/💻️os/🔨️modules/🧬️semio/🦀️.rs::wrap_binary_controlled` and `declared_envelope_prefix_len`. Magic is 8 bytes, little-endian token length is 4 bytes, token is `stdio.txt.pack v1`: 17 bytes; prefix P=29.

## Exact demands and API boundaries

Let B be native_length and F the actual receiving frame size. Frame birth costs one item and F capacity; parent/child depth admission requires at least two, then child depth is reduced. Existing NativeSnapshotBodyWallet `allocate_encode_vec_into` prepays one item, Vec header copy bytes and requested B capacity, then records actual capacity. It does not account later appended B copy bytes: the encoder must admit/record those actual accepted writes. `copy_encode_text_into` is unsuitable for multiple lines because it requires an entirely empty receiving String and copies one contiguous source. Neither helper should be reused as repeated reservation for each line.

Text payload physical backing is B. Binary preserves B body plus (B+29) envelope backing until intermediate retirement, so native cumulative backing allowance requires 2B+29 plus F and any accepted factory allocation. Capacity and copy ceilings must independently cover those original accepted demands, not only SQL file length. Source schema and Vec<String> input remain borrowed and are not cloned.

Publication implementation in `🧰️framework/🔨️modules/🚪️io/⏱️control/🛫️snapshot/🦀️.rs::publication_progress` demands one item, `size_of::<Option<IoPayload>>()` copy bytes, zero new capacity and F release bytes, plus positive original header depth. Intermediate body retirement has its own actual item/header/release demands and must precede publication; derive them from controlled_retirement demand methods rather than guessing constants. Native scoped maximum should preserve original cumulative owned bytes, and SQL admission should account the accepted delta, as the generic Record encode does. Capture an exact SQL observer error instead of converting every SQL refusal into a generic native cancellation.

## Neutral first laws

Use independently authored exact body bytes and Python/std UTF-8 equivalent or another existing third-party witness for source quoting: empty lines vector with trailing=false gives empty body; trailing=true emits one chosen separator even with no lines; `[""]` without trailing also gives empty body; `["", ""]` gives one separator; final trailing separator adds another. Include LF and CRLF, NUL within a line, multibyte UTF-8 crossing 65536, and embedded LF/CRLF within a line (the encoder presently copies them verbatim, so do not assume encode/decode preserves the original line segmentation for such sources).

Test denied frame/prebirth body allocation; original cumulative controller denial; mid-body cancellation retaining exact accepted prefix; Binary mid-envelope cancellation retaining exact magic/token/body prefix; cancellation after body completion but before publication; zero close authority and canceled funded close preserving the same recipient, followed by rearming the same caller observer and funded terminal close. Verify body/source/candidate pointers at the actual seams, exact cause and owner receipts, and original caller recipient terminal state. Cancellation at byte chunks can split a UTF-8 codepoint in the Vec: that is valid retained octet custody; convert to String only after complete valid body, or use character-boundary chunks if requiring a typed String partial.
