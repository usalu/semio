# Base Full and Empty Matched Demand Design

Actual Base Native subsets() is exactly the18 defaults already independently authored and validated. It contains no populated full fixture(). Actual Source authored union inputs live in base SQLite tests/🧫️branches/🟦️.ts; they differ materially from Native defaults: every child schema omits the s prefix, Image is rgba/8 with icc:null rather than Native rgb/0/absent, Audio is f32 rather than pcm16, and Text has one Unicode/NUL run rather than no runs. Consequently the older semio-base-eighteen-authored-branch-independent-extents.json is a Source authored corpus, not a matched Native-default oracle, and cannot be relabeled.

Base is a single selected union owner; a full union demand means all183 tables retained while one child is populated, not18 simultaneous child documents. A useful next authority is36 neutral cases, one full and one metadata-retaining empty per actual Native child fixture, explicitly wrapped as {schema:baseSchema,subset:{subset:tag,...child}}. Reuse each existing independent child Native-matched semantic-cell authority with exactly one manually authored semio_base_document row, preserving all18 unselected table families empty. Author Native constructors from their actual fixtures, because sibling test-private fixture functions are not reusable production APIs. Do not derive contracts by invoking owner projection.

For each selected branch, semantic rows = child rows+1; value bytes = child bytes + actual base header cells, measured from base schema rather than assumed tag lengths. Public metadata is separately one row with actual subset '*' and encoding text; all183 schema tables and max54 remain retained, public184. Independently author and verify base header root-kind and optional entity references against current actual Base projector/restore schema, especially Value/Object fields and Image/Text metadata distinctions. Original nativeAdmission.schema is 'semio.admission.雪\0'; largeSchemaUnit '雪\0' repeated40000 is an existing genuine header allocation/cancellation authority and can be kept separately from small full/empty semantic cases. The18 default specs currently delivered are complete defaults authorities and should remain distinct from these36 future cases.

No code or new fixtures were created by this design review; populated Source branch projection tests remain independent-engine comparisons of their own Source inputs, not a neutral Native-matched full corpus.
