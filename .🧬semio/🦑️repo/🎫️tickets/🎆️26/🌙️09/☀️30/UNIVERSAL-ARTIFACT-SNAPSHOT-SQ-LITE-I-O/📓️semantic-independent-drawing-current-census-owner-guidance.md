# Drawing Current Census and Native Owner Guidance

Read-only review of the current Drawing SQLite module and both Native codecs. The independent actual Native matched corpus remains full 32 rows/1992 bytes and metadata-retaining empty 1/159, schema 16 tables/5913 bytes/max34. This review supplies static guidance only.

The existing typed visitor already uses paid Projection frontiers for style name/id pairs, layer identity names, and per-root (SQL node id, borrowed node) traversal. Preserve authored style row ids while sorting lookup pairs; duplicates reject through compare_text. Preserve group traversal exactly: child node ids and child rows are allocated in authored order, then children are pushed in authored order and processed LIFO. Preorder rewriting would change ids for nested grandchildren. Each layer processes its complete root before its layer row. Keep indexed and reconstruction modules unchanged.

RowWriter adaptation must change every typed visitor receiver and FloatProjection implementation together. Current insert_ieee754/insert_key_ieee754 free functions take Projection specifically; a RowWriter visitor must use its native IEEE methods with float_columns as the third argument rather than pass RowWriter to those free functions. Compute style references before mutable row insertion. frontier element references borrow the original owner and must not outlive it; no typed clone or estimated maps are required.

Census fixed nonnumeric byte bases, including primary key cells: document 8+schema; style 24+name; layer 40+native_id+name; node 8+kind; path 8+optional style FK8; text 8+text+optional style FK8; group 8; child 32; image 8+mime+blob; segment 24+kind; move/line/cubic/quad/close 8; arc24. Add exactly the present IEEE triplets for each corresponding float_columns entry: Binary32 background/fill/stroke/opacity, Binary64 all positions/transforms/dimensions/stroke width. Missing optional numeric values add zero. Numeric class determines the actual REAL-cell presence; do not count every triplet as unconditional 24 bytes. Scene kinds path/text/group/image and segment kinds move/line/cubic/quad/arc/close are literal SQL text lengths, independent of compact Native tags.

Native binary node tags 0/1/2/3 correspond P/T/G/I in Text; path tags0..5 correspond M/L/C/Q/A/Z. Native Text floats are decimal IEEE words through native::float/float32, not generic floating point text. Options retain binary0/1 and Text[0]/[1,value]. Node decode keeps scoped_depth64; native entities increment2 per node and1 per segment, with list bookkeeping unchanged.

Current Native partial ownership gaps: schema precedes canvas/styles/layers; style name precedes optional colors and numeric fields; layer id precedes name/visibility/root; path segments precede optional style; Text node value precedes at/style; image mime precedes blob decoding. Establish actual Owned Snapshot/DrawStyle/DrawLayer/DrawNode or eligible field guards at those points, preserving original parse order and validation. Scalar-only point/color/transform helpers need no heap guard. Group children are the final allocating field, but completed nodes must remain in the admitted list owner. Current binary only guards layers immediately before trailing-byte validation, leaving schema/styles unguarded on earlier refusal. Text likewise builds naked completed lists across later fallible fields. Existing actual retire_struct implementations cover DrawStyle, DrawLayer, SemioDrawingSnapshot; inspect the DrawNode retirement implementation for variant guards. No new retirement eligibility or compiler pass is assumed.
