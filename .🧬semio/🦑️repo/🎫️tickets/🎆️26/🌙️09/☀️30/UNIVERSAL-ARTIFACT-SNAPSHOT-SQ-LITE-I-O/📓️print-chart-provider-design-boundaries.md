# Print Chart Provider Design Boundaries

Production owner: `🧰️framework/🛍️products/📓️print/🧬️schema/📸️snapshot/🦀️.rs`. Existing chart declaration has schema/inference services but no document/native codec or SQL capability. Coordinator owns the new closed schema-first corpus, tests, executable routes and launch entries; the physical agent owns handcrafted production providers, snapshot ordinary/controlled native codecs and actual declaration/mutation prerequisites. No provider has been mounted before the coordinator's genuine missing-provider demand.

The persistence owner preserves the actual default width80/height40/empty layers with absent language. This does not invent a UI language or change normal ChartSpecification's required language. Optional property absence stays distinct from empty collections/objects. Unknown/duplicate fields and domain-external values must receive typed refusal. The JSON chart norm supplies admission; its Source interface is narrower for coordinate options and must not truncate norm-permitted scalar/heterogeneous-array options.

Planned proper entities are chart document, margin, theme and ordered palette, tables/columns/rows/typed cells, scales/domain/range/options/ticks, coordinate/options, ordered layers/transforms/layout/channel encodings, guides/ticks/localized title, chart localized title, annotations/localized text and presets/options. Each scalar option belongs to its specific domain owner and key. No generic entire-chart JSON, compressed payload or generic recursive Value-node SQL carrier is permitted. Table row maps remain complete beyond declared columns; duplicate columns and array order remain normative. The norm permits unresolved or duplicate named references, so SQL must preserve authored names without inventing required uniqueness or resolution.

Ordinary Text/Pack should use the actual declared snapshot Record with its intrinsic chart field and canonical Core authority. Controlled native decode/encode and borrowed preflight must preserve the actual snapshot using that same declaration and expose real same-control progress, cancellation and paid ownership. Numeric native variants need careful scalar representation: DslValue admits UInt/Int/Float, whose widening comparison is lossy above 2^53; no SQL or native admission should silently round exact integer carrier identity. Independent third-party full-domain queries must match Source and Native reconstruction before claiming full ownership.
