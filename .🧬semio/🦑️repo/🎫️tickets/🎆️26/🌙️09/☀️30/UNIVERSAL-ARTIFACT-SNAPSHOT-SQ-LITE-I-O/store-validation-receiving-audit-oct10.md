Read-only audit of current Store source on October 10. No build or test run. Root products/AGENTS.md and os/AGENTS.md apply alongside root instructions. The generic retirement module is mounted from Store with its original path.

Current CodecFrame retains actual typed snapshot, database, payload and Option<IoResult<()>>. Validation directly invokes snapshot.validate_sqlite_snapshot_subset; it preserves current artifact overrides. No new receiving validation default exists in the inspected trait. The existing default validator permits wildcard but its normal dynamic trait override remains selected. Introducing a different receiving default that simply accepts wildcard would bypass existing custom wildcard/domain policy. Receiving defaults must explicitly refuse UnsupportedOwner until genuine typed implementations exist.

The returned original validation IoResult enters frame.validation before its variant or diagnostic severity is inspected. An original Err is moved into the outer logical result; error/fatal diagnostics move into the generated InvalidValue error. The outer callback returns Ok(logicalResult), so actual IoResult output enters receiving publication custody while CodecFrame retirement runs. Warning diagnostics stay retained in frame.validation until final output assembly. Error/fatal conversion uses a static cause message, differing from the previous coordinate-bearing validation helper; policy remains Error/Fatal refusal by source inspection.

The unresolved custody frontier is validator execution itself. Existing validate_sqlite_snapshot_subset accepts only SQL control and may construct allocating diagnostics/errors before it returns; the enclosing slot assignment cannot fund or own that callback's intermediate allocations. No Native receiving implementation or original validator retirement hook is presently provided. Direct existing dispatch preserves semantics but does not establish original physical validation custody.

Import checks input absence first, then invokes native.receive_nested; input.take executes inside the callback after native receiving checks item/depth/capacity, original retirement support, recipient/native charge and checkpoint and allocates the genuine frame. Admission denial therefore leaves the original input slot untouched by source inspection. P has RetireOwned bounds throughout codec construction and export/import; CodecFrame derives RetireOwned and its actual output type is IoResult. No duplicate semantic tree is introduced in this generic frame.

No runtime receipt is granted by these observations. A concrete receiving validation API must preserve exact existing domain subset semantics, have explicitly unsupported defaults, and be implemented by actual domains before universal codec qualification.
