Each artifact mounts its own receiving implementation under its own standard/subset SQLite snapshot tree. Both directions invoke the existing `owner.receive<T,O>` under the original wallet and allocation ceiling. The receiving frame stores its intermediate and output under controlled retirement; errors attach the frame to the same original native or parent pending recipient. On success it retires intermediate indexes/empty shells and releases the frame before returning the output. `Port.vector/text` records actual native allocation delta even when the producer returns an error. The outer `settle` accounts unreceipted native wrapper capacity under the same original maximum. No direct trait default forwarding or replacement grant was found in these two overrides. A hypothetical `settle` invariant failure after successful output return still requires an owned-output treatment; the inspected original maximum/delta accounting is intended to make that error unreachable, and this audit did not execute that proof.

TSV preserves independent `trailing_newline` and exact `LineEnding::{Lf,Crlf}` (`"lf"`/`"crlf"`) metadata; it has no header or quoted-field flag. CSV preserves `has_header` and `quoted`. Both preserve empty rows, empty strings, row ordering by authored ordinals, distinct arbitrary positive row identities, contiguous field ordinals, and reject duplicate IDs/orphan fields. TSV exact data matching rejects uppercase `LF`; shared declaration validation preserves exact single-quoted SQL literal bytes, so authored `CHECK(... IN ('lf','crlf'))` is not casefolded. SQL keywords/identifiers use ASCII case-insensitive token comparison, with token boundaries retained.

Concrete scanner accounting defect sent promptly to `/root/probe_receiving_execution`: shared `Tokens::next` line 49 checkpoints quoted scanning only when `end % 256 == 0`. Escaped doubled quotes increment `end` twice and continue. An opening quote followed by repeated doubled quotes keeps `end` odd and bypasses every 256-byte checkpoint, allowing a long quoted token to scan without further paid work/cancellation. Track a next-byte threshold or bytes since checkpoint so two-byte jumps cannot skip admission.
