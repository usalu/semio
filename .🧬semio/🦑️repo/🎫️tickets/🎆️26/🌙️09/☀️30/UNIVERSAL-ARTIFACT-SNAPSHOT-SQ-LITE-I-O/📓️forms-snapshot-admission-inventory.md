# Forms Snapshot Admission Research

Read-only inventory on 2026-10-02. Exact owner s.forms.forms@1/* is currently unowned in this lane and has not been modified.

Actual persisted FormsSnapshot fields are schema, id, version, optional title, complete typed FormsDefinition, ordered FormsResponse entries and independently persisted structure/results ArtifactChild handles. Form definition and response types live adjacent to the owning schema, with genuinely shared Playbook question/expression types reexported by the root.

The custom owning FromValue parser refuses unknown/duplicate top-level fields, requires all durable fields, then invokes validate(). validate requires schema forms.form, definition/each-response validation, distinct response ids and exact Semio child value/table identities. A future provider must inspect whether derived native DslRecord decode and both existing native codecs enforce the same admission, rather than inventing restrictions or assuming public struct types are unconstrained.

Structure/results children must remain their five persisted identity strings; inline Semio graphs/tables would duplicate independent artifacts. The native converter helpers currently reconstruct semio values from cached form state and degrade SemioRef to Null; those conversions are unrelated to snapshot SQL identity and cannot serve as a complete snapshot carrier.

No provider presence or runtime proof is claimed by this inventory. All definition fields, question options, expressions, response answers and actual numeric domains still require full inventory before handcrafted tables.


Follow-up owning codec inspection confirms actual admission rather than a prose-only restriction: binary encode invokes Snapshot::validate before constructing its record, binary decode validates after derived construction, and Text decode also validates after derived construction. Text print does not itself validate. Thus parser-accepted native snapshots enforce the marker, definition/response validators, duplicate response-id refusal and exact owned value/table child identities. Any future direct typed SQLite provider must keep full persisted fields and explicitly reconcile its admitted state with these actual native entrypoints. No Forms code changed and no runtime test claim follows from this inspection.
