# OS Six Provider Semantic SQL Audit

Read-only named-relation review, 2026-10-14. No tests/edits. Inspecting SQL and actual producer/model references separately from receiving authority; no opaque-record finding is inferred merely from native codecs or class names.

CollectionSnapshot `🪐️space/🗿️artifacts/🗂️collection/🦀️.rs:234–257` owns schema/name/folders/entries; entries have id/optional folder/name/kind and boxed ArtifactBody. Actual SQLite five tables name each property: collection_document, collection_folder, collection_entry, collection_document_body(schema,addressed_document_id), collection_blob_body(hash,size_high,size_low,media_type). Projection snapshot/🦀️.rs:20–22 explicitly writes each variant. Document body is a typed address, not an encoded document tree; Blob body is a typed blob reference, not a hidden semantic snapshot BLOB. No semantic storage redesign required. Existing fixture should independently query both body variants, literal/empty optional folder IDs, repeated intrinsic names and full u64size endpoints. Original paid P/R still missing separately.

SpaceSnapshot five tables expose document name/kind/visibility; users id/name/nullable avatar/role; collection references id/name/addressed document; programs plugin_id; extensions id/version/source_uri/package_hash/enabled. Extension package_hash/source_uri are reference metadata. No JSON/native whole-record column observed. Optional avatar empty versus absent requires independent fixture; no new schema entity inferred.

RunArtifact seven tables expose header lifecycle/reference fields, typed manual/automation trigger branches, named parameter values, node status/fingerprints/exact duration bits, directional port fingerprints, output artifact references and logs. run_parameter_value.value TEXT is native RunParameterValue.value:String (`🧬️schema/📸️snapshot/🦀️.rs:267–269`), not serialized arbitrary Value. Log message/level/at are literal domain strings. No whole native snapshot/semantic record hidden in them. Fixture should query both trigger variants and each option/full IEEE word.

WorkflowSnapshot schema exposes graph/node/port/edge/contract and parameter variant tables: numeric/categorical/options/toggle/text. Contract wire_kind/format_kind/wire_schema plus nullable conversion fields are explicit tagged metadata, not payload serialization. Node yields/artifact_ref/config_ref are authored lexical/reference fields. No opaque whole-graph column found. Numeric companions plus option rows require preservation; schema need not replace existing named entities.

InfiniteDag relation schema exposes named node/port/layout/edge/variant properties and recursive intrinsic tree tables. Only BLOB observed is dag_intrinsic_bytes.value; actual projection `🛫️projection/🦀️.rs:256–258` matches DslValue::Bytes and writes Cell::Blob(value), reconstruction `🪆️values/🦀️.rs:52` rebuilds that literal Bytes variant. It is genuine byte-domain content. Intrinsic objects/arrays are separate ordered member/element rows, with signed/unsigned/float/string variants named. No JSON wrapper needed or justified. Existing fixture includes DslValue::Bytes `[0,1,127,128,255]` and independent serde observation; strengthen query witnesses rather than relabel bytes as a semantic defect.

FlowHost schema names widget/chrome variants, synapses/layout/gui, recursive tree neuron/synapse and neural dictionary/value variants. Neural text is typed scalar payload, Decimal uses exact companions, Dictionary recurses through entry/order rows. Despite CameraJson/model type names and separate native encode/decode files, actual SQLite projection writes these named entities, not JSON strings. No BLOB/whole-snapshot encoded column found. Independent fixture must preserve variant tags, nested dictionaries/clusters, repeated map ordering policy and IEEE companions. Cold reconstruction352 has demand-derived cursor grant, but that is a separate receiving-ownership defect; it does not show opaque SQL semantics.

No concrete hidden whole-semantic-record schema gap found across these six inspected OS providers. This is bounded structural/model-trace evidence, not exhaustive field coverage or original Native qualification. Their cold receiving defaults and directional checkpoint wrappers remain actual work; schema-first migration should retain the already named entities instead of inventing new replacement storage.
