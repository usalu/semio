# Canonical Record List Boundaries

The ISO16757 erased Text law exposed two adjacent optional value-constraint records merging: the first minimum-only record acquired the next maximum and the second record disappeared. Empty list records had no token boundary at all. SQLite projection and Binary storage preserved their distinct presence states.

The canonical grammar now requires each direct `List<Record>` item to be `{ record fields }`, including empty `{ }` items. There is no bare-record fallback. Other scalar lists and nested scalar lists keep their existing grammar. Direct records outside lists are unchanged.
