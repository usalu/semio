## Authored Roles

Follow [actual projection](/Users/ueli/Documents/semio/✏️s/🔌️plugins/📕️norm/🗿️artifacts/📇️iso16757/🏅️standards/🔖️1/🪆️subsets/✳️any/🧬️schema/📸️snapshot/🪶️sqlite/🦀️.rs:31), not generic all-CST primitive counting. Native envelope/header bytes and DSL field IDs are file/backing costs and add zero semantic cells. Dictionary/catalogue reference IDs/versions are real document text cells. Names emit names identity row plus each alternative identity/owner/ordinal/locale/text. Every list/map membership relation authored by projection adds its own identity/foreign IDs/ordinal and key text even if CST only stores one item.

CatalogueValue emits tag/text/integer/query and nullable-unit roles plus recursively linked value_element rows. Geometry emits geometry_node and child links, primitive parameters, transforms/bounds and geometry-object membership. Extensions emit extension-field relation, extension-node variant cells and ordered element/member links including actual key text. Do not count intrinsic Object metadata key spellings as SQL payload unless actual projection writes them. Each optional presence distinguishes Null0 from FK8 or text byte count; custom list empty vs absent still follows the actual owning row/tag.

IEEE schema arrays: UNIT Binary64 column6; VALUE columns4,8,9; NODE5..10; BOUNDS5..10; PARAMETER4; CONSTRAINT3,4; EXTENSION6. Every present float contributes query8 except NaN query0, signed bit INTEGER8, exact class UTF-8 length (finite6,nan3,positiveInfinity16,negativeInfinity16). Absent optional IEEE contributes all NULL0. Original scalar INTEGER8, REAL8, Null0, Text UTF-8, Bytes length; every authored identity contributes8. No8192/24 approximation and no stack-size guesses.
