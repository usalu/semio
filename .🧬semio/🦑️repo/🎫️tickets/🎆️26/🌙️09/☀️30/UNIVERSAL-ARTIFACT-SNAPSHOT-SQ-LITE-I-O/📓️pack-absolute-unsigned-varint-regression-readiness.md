The changed helper is private `read_varint_u64_at` in shared Pack `📐️format/🦀️.rs`. It reads one byte at each absolute source offset into `[u8;10]`, refuses a continued tenth byte before an eleventh read, and forwards only the actual consumed prefix to canonical replication `codec::read_varint_u64`. That primitive refuses tenth-byte payload greater than one and continued tenth byte; it accepts nonminimal terminating representations, leaves trailing bytes unread, and advances its position over a terminating primitive. No minimality requirement should be invented by a regression fixture.

Existing replication Rust unit tests cover several boundary values and u64::MAX, and existing retained Pack cursor tests cover a sticky continued tenth-byte error. The broad Pack neutral fixture declares malformed-varint as a hostile category but does not contain a closed full u64 seven-bit-transition corpus with exact absolute byte reads, consumed-prefix/trailing-byte cases and tenth-byte overflow/truncation.
