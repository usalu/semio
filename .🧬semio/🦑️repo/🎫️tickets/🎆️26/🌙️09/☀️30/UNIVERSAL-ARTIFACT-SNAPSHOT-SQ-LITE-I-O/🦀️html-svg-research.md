# Native HTML and SVG Relational Schemas

Read the owned HTML5 any snapshot before authoring its mapping. It persists schema, optional doctype and HtmlNode root. Its node variants are element with ordered optional-valued attributes and children, text, comment and raw text with explicit script/style parent kind. Boolean attribute NULL must remain distinct from an explicitly empty attribute value. HTML has eight explicit tables; it does not borrow XML's AST or codec.

Read the owned SVG1.1 snapshot and subset validator implementations. Its persisted fields are schema and the same typed XmlDocument model used by XML. Geometry/viewBox/path/transform types are derived helper views over individual XmlAttr strings, not additional snapshot fields. Root approved sharing exactly the typed XmlDocument traversal with an explicit thirteen-field table vocabulary; SVG owns handwritten svg_* DDL, native provider and minimal SVG root validation. No database renaming adapter, reflection, serialization container or generic artifact fallback is used. XML's shared functions accept borrowed native fields, preserving all nodes, declaration, doctype/external identifiers and entities without a deep-copy intermediate. HTML remains independent.

Schema-first tests and neutral fixtures were created before mounting providers. HTML initial red gate rejected missing trait/methods. First implementation gate passed three tests and exposed a test oracle expectation error: Bun's independent HTMLRewriter exposes escaped wire attribute values, whereas the owned native model stores decoded text. Corrected the expected wire attribute to &amp; while native semantic reconstruction continues to assert decoded ampersand. Registered HTML/XML batch then passed after typed sharing. SVG initial red gate rejected missing provider and absent fixture-only serde_json dev dependency; this uses an already-existing workspace dependency and adds no runtime dependency or external public type.

HTML independent Bun SQLite checks integrity/FKs, boolean versus empty attributes and raw-text kinds, edits an ordered attribute and reconstructs the native model. Bun HTMLRewriter independently parses edited native HTML and checks ordered element/attribute witnesses. SVG tests independently query and edit its path field, inspect CDATA and doctype entities and restore native pack/DSL exact state. Tiny/basic I/O SubsetValidator tests validate both reconstructed binary and text payloads and recheck violations introduced through semantic relational rows. Basic and tiny have different vocabularies: linearGradient is a tiny negative; feTurbulence is a basic negative.

Completion and final registered validation are recorded in the corresponding report.
