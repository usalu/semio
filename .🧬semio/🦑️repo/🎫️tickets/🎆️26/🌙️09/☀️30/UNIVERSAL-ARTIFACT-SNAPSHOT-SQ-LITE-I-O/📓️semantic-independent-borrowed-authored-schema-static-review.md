Repeated const uses and recursive helper returns must not rely on optimizer deduplication of separate promotions for pointer equality. The same applies to VARIANTS and scalar Enum label arrays. The held pointer-equality law requires a concrete authored static backing prerequisite.

A coherent nongeneric derive emits uniquely type-named immutable module statics for the record field table, scalar label table, per-named/unit-variant field table, and variant function-pointer table. Associated constants reference those actual statics; borrowed_record returns the copied descriptor pointing to the same backing. Rust has no associated static item, so replacing const syntax with an associated static is invalid. Generic owner monomorphization and static type-parameter use require explicit design/compile demand, not an assumed method-local static solution.
