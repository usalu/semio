# Native TIFF Semantic SQLite Design

The actual TIFF6.0 document snapshot owns schema, byte order, ordered IFDs, and document RGBA pixels. Every IFD independently owns ordered tag entries and its own raw strip pixels. Every tag independently owns u16 tag id, TiffFieldType, and one of twelve TiffValues variants. Preserve the owned field type independently of the value variant, and retain duplicate ordered tag ids: SQLite projection must not silently normalize the owned model through TIFF wire encoding. Empty IFD/tag/value arrays and empty pixels remain exact. Full unsigned and signed scalar widths fit SQLite signed INTEGER; rational numerator/denominator remain separate fields. Float/double values use the physical engine's explicit IEEE binary32/binary64 companions, including signed zero and all NaN payloads.

The handwritten schema has seventeen tables: document, directory, tag, twelve distinct typed value tables, document pixels, and directory pixels. Numeric sequences use individually queryable ordered rows; ASCII owns one TEXT row. The two genuine raster payload byte buffers own BLOB fields. No TIFF wire file, generic packed field, JSON document or reflective tree is stored.

Reconstruction validates declared SQL, exact row shape/ranges, every typed component, directory/tag/value contiguous order, FK ownership, uniqueness of physical identities and component coverage. Projection and reconstruction use shared borrowed-cell/owned-copy controls before allocations and at256units. Baseline validation uses the actual native tag meanings and retains established warnings, with cancellable borrowed scans rather than cloning value vectors. The document wildcard and baseline are exact declared coordinates.

TDD starts with neutral fixture/schema/native laws before the provider. Independent Bun SQLite integrity/FK/query/edited-file witnesses validate real exported databases. Separate source-valid TIFF samples exercise native pack/DSL and actual declared capability; all owned scalar states exercise direct typed snapshot SQLite without lossy wire lowering.
