## IEEE Scope

The evaluated base factories preserve exact represented numeric values at every Binary64 field, including nested arrays/maps and mandatory systems. Full-cost constants above belong to those original numeric literals. They are not constants for every_word replacements: IEEE class/query payload bytes change for negative zero, infinities and NaN, with NULL0.

EN1993/1997/1999 carry eight word literals in the same neutral JSON; their Native fixture constructors begin from the same selected snapshot. EN1993 Source snapshot helper only replaces literal0.5 leaves using its supplied word; retain that exact scope. EN1997 Source everyWord and Native every_word traverse the full nested layer/footing-load/pile-test/wall/slope/uplift fields. EN1999 Source everyWord rewrites action lists from the first member/connection/coldFormed/shell; its original fixture has those branches, but an expanded fixture must not assume that first-only traversal equals Native every_word's every-owner traversal. The other nine use separate owning binary-word/control fixtures and setEveryWord helpers; those word cases require their own independent per-table cost authority. Base fixture parity is not runtime parity or all-word census credit.

No scalar or collection edits are needed for the twelve **full** Native neutral cases to match Source base factories. The three independently found existing-empty differences above must be handled by explicitly authored separate parity constructors, retaining all original factories, word setters, grants and assertions.
