## Actual Remaining Frontier

Neither source impl inspected declares receiving projection/reconstruction or both direction-specific subset validators. They currently rely on ordinary projection/reconstruction and cold field-owner cleanup. glTF native decode signature at snapshot line58 still takes bare NativeDecodeControl, inconsistent with current trait original NativeSnapshotDecodeOwner; encode takes original owner. DWG decode takes original owner but its callback ignores `_body`, constructs fully via construct_native_record, assigns only afterward, then runs additional native-row admission. This is the original-body-wallet/partial-destination custody frontier, not first relational SQL implementation.

Preserve these handcrafted families and repair original ownership in domain-neutral receiving ports and typed per-family destinations; do not rewrite schemas as carrier tables. A complete qualification requires authentic original control/callback, independent five-axis body/close authority, paid nested frame admission, receipt settlement on each refused prefix and actual derived retirement, plus exact installed declaration route assertions for each dialect.
