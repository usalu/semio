# Generation Per-Root Lease Contract

The proposed canonical lease is legitimate for the original GenerationPlayRoot contract when explicitly scoped to release of each root lease. The existing original alias law closes the first root while another root remains and expects that remaining root's data to survive. Thus full unique-custody false would change that per-root behavior and can deadlock if all retiring aliases wait for uniqueness. No actual caller contract requiring the DAG factory's full unique-custody policy was found for this root method.

Actual SharedControlledRetirement::lease retains its original Arc until a funded step. It blocks while weak leases remain and while grant release cannot cover actual Arc storage. It consumes one strong lease with Arc::into_inner: a nonfinal lease reports no backing release; the final lease moves exact original state inline into ControlledRetirement and reports actual Arc backing release. ControlledRetirement::new is explicitly allocation-free and retains the input inline with an empty PagedList; it does not allocate field scaffolds at Arc transfer. Subsequent capacity/work/depth admission funds the real deferred state/field cursors and eventual release.

Therefore inline GenerationRootRetirement holding SharedControlledRetirement::lease needs no invented heap birth allocation for the inline constructor. Deriving fieldwise RetireOwned for GenerationPlayState/FormGeneration must retain complete original fields; OrderedMap and recursively owned DslValue must already publish real controlled support and measured births. Shared step panics if that support is absent at final transfer, so validate it before transferring ownership rather than rely on that panic.

Weak backpressure differs from the old first-alias test: canonical lease blocks every source step while any weak observer exists, including nonfinal strong aliases. The updated physical law must assert that block and release the weak observer before expecting progress. Hold a separate strong observer when checking nonfinal per-root release, then return it or retire it as its own lease. Count final Arc release exactly once across all alias orders, plus actual nested backing and funded cleanup frames. Nonfinal Complete means that particular root lease closed; it must not be called full snapshot physical retirement.

The earlier generation-audit warning about alias relinquishment applies to claims of full custody. With this explicit per-root contract and physical conservation law, using the existing canonical lease API is preferable to inventing a different alias ABI. No production edits or runtime qualification performed.
