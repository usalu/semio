# 👴 Real Parts of Powers — Coefficients of `Re(z^{2m})`

Source notes: `👴️leutwiler/💤️realparts-of-powers-z-n/📯️notes/📐️.tex`
Paper: `👴️leutwiler/💤️realparts-of-powers-z-n/🏆️proof/📐️.tex`
Lean proof: `👴️leutwiler/💤️realparts-of-powers-z-n/🧘️lean/RealPartsOfPowers.lean`

## Setting

`z = x + i y + j t`, `r = y² + t²`, `u_m = Re(z^{2m}) = Σ_{k=0}^{m} a_k x^{2(m-k)} r^k`.

## Closed form

```
a_k = (-1)^k · C(2m, 2k)
```

## Explicit recursion

```
a_0 = 1
a_{k+1} = - a_k · (2m-2k)(2m-2k-1) / ((2k+2)(2k+1))
```

Division-free form proved in Lean (valid for every `k`, also beyond `m` where both sides vanish):

```
(2k+2)(2k+1) · a_{k+1} = -(2m-2k)(2m-2k-1) · a_k
```

Check `m = 5`: `1 → -45 → 210 → -210 → 45 → -1` matches the source.

## Why

Write `z = x + v`, `v = i y + j t`. Then `v² = -r` is real and `x` commutes with `v`, so the binomial theorem applies:
`z^n = Σ_i C(n,i) x^{n-i} v^i`. Even powers `v^{2k} = (-r)^k` are real, odd powers `v^{2k+1} = (-r)^k v` have real part `0`.
Hence `Re(z^n) = Σ_k (-1)^k C(n,2k) x^{n-2k} r^k`. The recursion is the quotient `C(2m,2k+2)/C(2m,2k)`.
No polar form and no case split on the real axis is needed.

## Conjectures of the source

- `a_m = (-1)^m`: true (`C(2m,2m) = 1`).
- `a_{m-(2k-1)} = (-1)^m a_{2k-1}`: true, and more generally `a_{m-k} = (-1)^m a_k` for **every** `0 ≤ k ≤ m` (odd or even, no bound `m ≥ 2k+1` needed), from `C(2m, 2m-2k) = C(2m, 2k)`.
- `t Δu_m = ∂u_m/∂t`: true for every `n`, equivalent to the recursion, formalised (`laplaceBeltrami_iff`, `laplaceBeltrami_re_pow`). Idea: `u = f(x, ρ)` with `ρ = √r` and `f = Re((x + iρ)^n)` harmonic in `(x, ρ)`, so `Δu = f_xx + f_ρρ + f_ρ/ρ = f_ρ/ρ` and `∂u/∂t = f_ρ · t/ρ`. Holds for every `n`, not only even.

### Components of `i` and `j` (2026-09-21)

`z^n = Re(z^n) + (i y + j t) S_n`, `S_n = Σ_{k<(n+1)/2} s_k x^(n-1-2k) r^k`, `s_k = (-1)^k C(n, 2k+1)`, `s_0 = n`,
`(2k+3)(2k+2) s_{k+1} = -(n-2k-1)(n-2k-2) s_k`, for `n = 2m`: `s_{m-1-k} = (-1)^(m-1) s_k`. The `ij` component is `0`.
`v_n = y S_n` solves `t Δv = ∂ₜv`; `w_n = t S_n` solves `t² Δw - t ∂ₜw + w = 0`; both equations are equivalent to the recursion.
Key identity: `Δ(y u) = y Δu + 2 ∂_y u`, so the bracket becomes `P_xx + 4 r P_rr + 6 P_r` (`2k(2k+1)` instead of `2k(2k-1)`).

### Clifford algebras (2026-09-21)

Only `w² = -r` was ever used. In any real algebra `(x + w)^n = R_n(x,r) + S_n(x,r) w` (`pow_eq_of_sq`), so for paravectors
`z = x + Σ x_i e_i` of `Cl_{0,μ}`: `z^n = R_n(x,|v|²) + Σ_i x_i S_n(x,|v|²) e_i`, same `c_k`, `s_k` for every `μ`.
In `ℝ^{μ+1}` with distinguished coordinate `x_l`: `Δ P(x,|v|²) = P_xx + 4 r P_rr + 2 μ P_r`, `Δ(x_i u) = x_i Δu + 2 ∂_i u`, hence
`x_l Δf = (μ-1) ∂_l f` for the scalar part and the `e_i` components (`i ≠ l`), and
`x_l² Δw - (μ-1) x_l ∂_l w + (μ-1) w = 0` for the `e_l` component; each is equivalent to the same recursions. `μ = 2` is the quaternion case.

| Theorem | Statement |
| --- | --- |
| `pow_eq_of_sq`, `z_pow_eq` | abstract algebra version, quaternions as instance |
| `clifford_pow`, `clifford_pow_components` | Mathlib `CliffordAlgebra (Q μ)`, `Q μ v = -Σ v_j²`, `e_j = ι (Pi.single j 1)` |
| `defectN_re`, `defectN_im`, `defectN_last` | the three defects for any finite monomial sum `P`; `pd`, `pd2`, `lapN` via `deriv` along `Function.update` |
| `hyperbolic_re_iff`, `hyperbolic_im_iff`, `hyperbolic_last_iff` | equation ↔ recursion |
| `hyperbolic_scalar_pow`, `hyperbolic_vector_pow`, `hyperbolic_last_pow` | the equations for the components of `z^n` |

Lean trick: the slice `r ↦ F x (update v i r)` equals the 3-variable `V x (qq v i) r` with `qq v i = √(|v|² - v_i²)`, so all one-variable derivative lemmas of the quaternion case are reused.
Not formalised: linear independence of `1, e_1, …, e_μ` in the Clifford algebra (uniqueness of components).

### Isolated roots outside the xy-plane (2026-09-21)

Question: is there a degree 2 polynomial with an isolated root outside the `xy`-plane `{t = 0} = ℂ_i`? Polynomials `p(q) = Σ q^n a_n`.
- Coefficients in `ℂ_i` (any degree): no. `p(z) = A + v B` with `A, B ∈ ℂ_i` depending on `(x, r)` only; the `j` and `ij` components of a root with `t ≠ 0` force `B = 0`, then `A = 0`, so the whole circle `y² + t² = const` consists of roots (`evalPoly_z`, `polyA_polyB_eq_zero`, `circle_of_roots`, `root_not_isolated` via a small rotation and `1 - cos θ ≤ θ²/2`).
- Real `b, c`: `z² + b z + c = 0 ↔ x² - r + b x + c = 0 ∧ (2x+b) y = 0 ∧ (2x+b) t = 0` (`real_quadratic_root_iff`).
- A coefficient outside the plane: yes. `q² - q (1 + j) + j` has in all of `ℍ` exactly the roots `1` and `j` (`jPoly_root_iff`, `jPoly_root_outside_plane`).
Paper section 6: Theorem 22, Corollary 23, Theorem 24, Remark 25. Not formalised: the remark that the statement holds for every plane `ℂ_I`, and the explicit description of the circle in Corollary 23 (immediate from the equivalence).

### Degree three and general degree (2026-09-21)

- Any degree, coefficients in the `xy`-plane: no isolated root outside it (Theorem 22 already covers every degree).
- Real coefficients, any degree: `p(z) = A + B v` with real `A = Σ R_n α_n`, `B = Σ S_n α_n`; `p(z) = 0 ↔ A = 0 ∧ B y = 0 ∧ B t = 0` (`real_poly_root_iff`). Degree 3: `real_cubic_root_iff`, and a non-real root has `r = 3x² + 2bx + c = p'(x)` and `8x³ + 8bx² + 2(b²+c)x + bc - d = 0` (`real_cubic_circle`, the identity is `(3x+b) B - A`).
- All of `ℍ`: `q = x + w`, `w² = -|w|²`, so `q^n = R_n + S_n w` (`quat_pow_eq`) and `p(q) = A + w B` (`evalPoly_quat`). Coefficients in `ℂ_j`: a root with `(b, d) ≠ 0` forces `A = B = 0` and a whole 2-sphere of roots (`polyA_polyB_eq_zero_J`, `sphere_of_roots_J`).
- Degree 3 example: `q³ - q²(1+3j) + q(-2+3j) + 2 = (q-1)(q-j)(q-2j)` on `ℂ_j` has in all of `ℍ` exactly the roots `1, j, 2j` (`jCubic_root_iff`): plane roots by factorisation and no zero divisors, no sphere because `x - jρ` would have to be a root too.
- Degree n: `q^n = j` has a root (`exists_pow_eq_j`, via `jEmb : ℂ → ℍ`, `a + ci ↦ a + cj`, and `exp(iπ/(2n))`), every root lies in `ℂ_j` with `imJ ≠ 0` (`pow_eq_j`, from `S_n b = S_n d = 0`, `S_n c = 1`), and the root set is finite (`pow_eq_j_finite`, image of the roots of `X^n - I` in `ℂ`).
Paper section 7: Theorem 26, Corollary 27, Theorem 28, Theorem 29, Theorem 30, Remark 31. Not formalised: the two classical counts in Remark 31 (three real roots or one real root and one circle; exactly `n` roots of `q^n = j`).
