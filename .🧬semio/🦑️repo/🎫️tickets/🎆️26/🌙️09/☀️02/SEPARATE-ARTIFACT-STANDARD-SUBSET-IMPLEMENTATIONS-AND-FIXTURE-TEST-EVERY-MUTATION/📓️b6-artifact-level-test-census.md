# Shard B6 — Artifact-Level Test Case Census

Exhaustive enumeration of every case directory found by:

```
find ✏️s/🔌️plugins -type d -path '*/🗿️artifacts/*/🧪️tests/*' -not -path '*/🪆️subsets/*' -not -path '*/target/*' -maxdepth 6
```

filtered to true case directories (immediate children of a `🧪️tests`, excluding nested `🧫️fixtures`). **176 cases** across **33 plugins**, captured at census time (one, `🎬️sequence/mutate-sequence-1`, was already relocated by shard B3 by the time execution ran — its row is kept for completeness and flagged stale).

## Method

For every case: its `🥒️.feature` (all `@capability-`/`@oracle-`/`@comparison-`/`@mutations-` tags and every `asset://`/`shared://`/`local://` URI), every adapter file (`🦀️.rs`/`🐍️.py`/`🟦️.ts`) for `standards::v<X>_<Y>::subsets::<name>` Rust paths, and the artifact's real subset list from `ls <artifact>/🏅️standards/*/🪆️subsets/`, extracted programmatically (script: `🔍️b6-extract-census.py`, raw dump: `🗑️generated/b6-census-raw.json`) and classified by:

- **SINGLE-SUBSET** — the case's `@mutations-`/`@capability-` tag (or, absent that, its Rust `standards::v_::subsets::` import, or its case-name suffix) names exactly one subset that actually exists under the artifact.
- **MULTI-SUBSET** — genuinely spans several subsets (none found outside stale B3 rows).
- **ARTIFACT-WIDE** — no `@mutations-` tag, no subset-scoped fixture: a pure container create/read/round-trip test of the artifact's grammar as a whole.
- **SINGLE-SUBSET (nominal)** — an anomaly: the tag names a subset that does **not** exist on disk for this case's own standard version (a catch-all `✳️any`/`✳️base` left behind when siblings were split out from under it, or a stray name that belongs to a *different* version of the same artifact).

Every SINGLE-SUBSET case that was **not** relocated this wave carries one of three reasons, stated per-row: **blocked** (its only real-world/handcrafted fixture is committed under a sibling subset or sibling standard version — `asset://`/`shared://` resolution is guarded against escaping the case owner's directory tree, so relocating would raise `missing-fixture`), **anomaly** (the subset it claims does not exist), or **out of scope** (shard B3's six artifacts).
