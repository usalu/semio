# 🪆️ Separate Artifact Standard Subset Implementations And Fixture-Test Every Mutation

## The two laws this ticket enforces

1. **Every artifact standard subset implementation is separate.** A subset owns its own
   `🚪️io`, `🧬️schema` (incl. `🧬️mutations`), `🧪️oracle`, `🧫️fixtures`, `🧪️tests`, `🏭️generator`
   under `🏅️standards/🔖️<version>/🪆️subsets/<subset>/`. Nothing is shared or collapsed at the
   artifact level, and a mutation is owned by the smallest semantic subset.
2. **Every artifact mutation is tested over fixtures.** Real-world example, handcrafted, or
   generated by a third-party oracle library — and the fixture reference must actually resolve.

## Ground truth used

The repository already owns the mechanical judge. `bun ./📜️script.ts test contract` writes the
complete breach set to `.🧬semio/🦑️repo/⚡️cache/breaches/testing.json`. Every claim in this
ticket is measured against that file, never asserted.

Discovery facts confirmed by reading the source, not assumed:

- `discoverTestCases` (`🧰️framework/🛍️products/🦑️repo/🔨️modules/🧪️test/📦️packages/🟦️typescript/🟦️.ts:522`)
  walks **arbitrary depth** for a directory named `🧪️tests`; the **owner is its parent**. A case
  moved from `<artifact>/🧪️tests/<case>` to `<subset>/🧪️tests/<case>` is therefore still
  discovered — and its `sharedFixtureDir` becomes `<subset>/🧫️fixtures`, which is precisely the
  placement law 1 asks for.
- `taxonomy.testOwnerKinds` already contains `🪆️subsets`, so a subset is a legal test owner.
- The Nx project id is `test-<owner-slug>-<digest6>-<case>` (`testProjectName`, same file:508), so a
  relocation renames the project — expected, not a break.
- `subsetPolicyIsSingle` (same file:2677) reads `subsetPolicy` from `🪆️subsets/🔣️.json`; that is the
  sanctioned way to record that a format genuinely has one scope rather than merely not having been
  split.

## Wave 2 — placement and implementation separation

- Relocate the 163 artifact-level test cases under `<artifact>/🧪️tests/` to the subset each targets.
  116 target exactly one subset, 18 span several (split them per subset), 29 need their target
  determined from the feature body.
- Give `📄️pdf` subsets `✳️a`/`✳️x`/`✳️e`/`✳️h`/`✳️ua`/`✳️vt` their own `🚪️io` and `🧬️schema`
  instead of importing `✳️base`'s `decode_pdf`/`encode_pdf`.
- Push artifact-level shared logic down into subsets: `📄️pdf`'s validator aggregation, `🏗️ifc`'s
  two-standard composer merge, `🧊️gltf`'s artifact-level inference services.

## Wave 3 — make the laws mechanical

Add the two missing policy rules so neither law can silently regress:

- `testing/taxonomy` `case-above-subset` — a case whose feature targets exactly one subset must live
  under that subset.
- `testing/fixture` `mutation-without-fixture` — every declared mutation kind must carry at least one
  fixture-backed vector.
