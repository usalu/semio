## Layout reference — the conforming exemplar

`✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📷️png/🏅️standards/🔖️1.2/🪆️subsets/✳️any/` is the shape every
subset should converge on:

```
🚪️io/{🟦️.ts,🦀️.rs}
🧪️oracle/{🔣️.json,🦀️.rs}          ← the owner contribution manifest + third-party reference
🧫️fixtures/<mutation>/{before,after}.<ext>
🧪️tests/<case>/…                   ← subset-level cases
🏭️generator/{📋️project.json,📜️script.ts,🦀️<engine>/}
🧬️schema/{🟦️.ts,🦀️.rs,🔣️.json,…}
🧬️schema/🧬️mutations/<mutation>/{🔣️.json,🔣️.schema.json,🦀️.rs,🟦️.ts,🔗️.graphql,🛰️.proto,
                                 📝️text/🦀️.rs,💾️binary/🦀️.rs,
                                 🧪️tests/<case>/{🦠️mutation,📸️snapshot/⬅️before,
                                                 📸️snapshot/➡️after,🔺️diff,🎯️outcome}/🔣️.json}
```

Fixture URIs inside a `🥒️.feature` resolve as: `asset://…` against the case OWNER (the directory
holding `🧪️tests`), `shared://…` against `<owner>/🧫️fixtures`, `local://…` against
`<case>/🧫️fixtures`. Entry filenames are kind-only: `🔣️.json`, `🦀️.rs`, `🟦️.ts` — never
`🔣️component.json`.
