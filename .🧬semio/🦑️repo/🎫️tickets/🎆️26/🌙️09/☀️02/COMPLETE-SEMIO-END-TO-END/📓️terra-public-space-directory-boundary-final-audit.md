# Public-Space Directory Boundary Final Current-Source Audit

**Scope:** Lane 1 public directory projection only, reread on 2026-09-04. Read-only audit; no Cargo/Nx gate was run. The small `bun -e` read-only count check reported 21 fixture forbidden keys and 21 hostile mutations versus each schema's `maxItems: 13`.

## Verdict: RED

The new discriminated directory DTO boundary is structurally sound in its own list/detail, raw-event, and credential-free *frame* paths. It is not an acceptable public-space boundary because its registered neutral oracle is currently invalid and adjacent legacy authorization still lets a public nonmember reach document currentness and blob storage, including blob writes. Directory WebSocket heartbeats also disclose the global directory sequence to an authenticated nonmember of a public space.

## Required repair before a final PASS

1. Keep the new directory DTO/public catalog path; do not redact a raw `DirectoryEvent` into a fake public event.
2. Split legacy generic authorization by route capability. Public visibility may authorize only the explicit directory list/detail public projection. `get_document_status`, `get_blob`, `head_blob`, and especially `put_blob` must require a member/session (or a separately scoped, read-only document capability where designed); public fallback must neither create/ensure a document nor touch blob storage.
3. Make directory stream visibility subject to the same access decision for **every** frame. For nonmembers, suppress heartbeat entirely; an unauthorised global `headSeq` cannot be converted into a public-space heartbeat without a separate scoped public stream contract.
4. Make the neutral schema cardinality match its deliberate 21-vector corpus (or deliberately reduce the corpus); retain exact cardinality so a missing hostile vector fails validation. Add exact process laws for anonymous and authenticated-public-nonmember denial of document-status/blob GET/HEAD/PUT and no storage mutation, plus a socket law that observes no heartbeat/event/connection/presence/rebootstrap output over a bounded interval.
5. Rerun the registered gate only after the above: `bun nx run os-hub:space-public-boundary-check --skip-nx-cache`. It must reach the AJV oracle, exactly select and run its Rust laws, run the focused TypeScript parser law, and complete the all-feature hub check. Current source supplies the project target (`hub/.../📋️project.json:143-149`) but cannot qualify because its first oracle rejects its own fixture.

## Nonclaims

This audit does not claim anonymous document opening, public document replication, public MCP authority, or a public WebSocket subscription. The verified safe surface is discovery metadata only; document bytes, currentness, storage, membership/invites, events, presence, and activity must remain outside it.
