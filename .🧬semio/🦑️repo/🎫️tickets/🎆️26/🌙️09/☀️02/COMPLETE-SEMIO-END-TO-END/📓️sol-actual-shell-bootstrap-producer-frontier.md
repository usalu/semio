### Space interruption evidence

The terminal line was exact:

```text
error: script "nx" was terminated by signal SIGTERM (Polite quit request)
```

No `[budget]` diagnostic preceded it. The producer passes `buildBudgetMs()` to its Cargo child, and the process environment set `SEMIO_BUILD_BUDGET_MS=86400000`; a nested Cargo budget expiry would therefore be a 24-hour `SIGKILL` with an explicit `[budget]` line. The observed `SIGTERM` instead reached the outer Nx/Bun owner while Cargo/rustc was CPU-active. After terminal, no process referenced `home-space-component-sol-target`; only Cargo's inert `.cargo-lock` files remained. This establishes orchestration interruption, not compiler slowness or a repository-code failure, without assigning an unproven external sender.

The superseded session `45110` had crossed the framework, graph, plugin and UI crates before its coordinated cancellation. Rust emitted explicit long-constant-evaluation warnings for Stdio's glTF mutation derive, first in core slice metadata and then in the replication mutation scanner, before progressing to TIFF and XML expansion. Those were compile-hotspot warnings with continuing CPU progress, not a compiler failure or budget event. The replacement producer `50835` is built from the narrow Home I/O dependency graph and is the only run whose terminal bytes can qualify the current Space closure.
