### Space interruption evidence

The terminal line was exact:

```text

```

No `[budget]` diagnostic preceded it. The producer passes `buildBudgetMs()` to its Cargo child, and the process environment set `SEMIO_BUILD_BUDGET_MS=86400000`; a nested Cargo budget expiry would therefore be a 24-hour `SIGKILL` with an explicit `[budget]` line. After terminal, no process referenced `home-space-component-sol-target`; only Cargo's inert `.cargo-lock` files remained.
