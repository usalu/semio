# Terra Space Collaboration End-to-End Audit

Read-only current-tree audit, 2026-09-04. This report did not run a build, test, launcher, or browser. “Source-provisional” means the named path exists in current bytes, not that it ran. “RED” is a source-confirmed missing/unsafe contract or an explicitly stale/non-runnable gate.

## Verdict

The hub has a substantial source path for durable space commands, membership checks, descriptors, authenticated document sockets, command durability, fanout, and reconnect. It is **not end-to-end accepted** for space collaboration yet. Three blockers are immediate:

1. **RED — unauthenticated public-space detail leaks every member's email and user id.** `get_directory_space` admits any public space and returns `space.members.clone()` at [bin.rs](../../../../../../../../../🌎️hub/📦️packages/🦀️rust/📦️bin.rs:3598)-[3610]. `MemberView` contains `user_id`, `email`, `display_name`, and role at [schema](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🦀️.rs:418). This contradicts the adjacent WebSocket privacy boundary's explicit rule that public visibility must not disclose account email/online identity ([bin.rs](../../../../../../../../../🌎️hub/📦️packages/🦀️rust/📦️bin.rs:3661)-[3665]). Split public `SpaceView`/document metadata from authenticated member detail, and prove anonymous/public-nonmember rejection of members, invitations, connection, and presence data.
2. **RED — the registered two-user browser gate is knowingly unable to open the created document.** The plugin emits `os.open-artifact` without `documentId`, `schema`, or `spaceId` ([plugin](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🦀️.rs:30393)-[30410]); `ShellHost` only calls `openDocument` when both `opening.documentId` and `opening.schema` exist ([ShellHost](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑️‍🎨️engine/🧱️elements/ShellHost/🟦️.tsx:3170)-[3181]); the resolver deliberately treats the document pair as optional ([os TS](../../../../../../../../../🧰️framework/🛍️products/💻️os/🟦️.ts:33)-[119]). The registered collaboration script calls this out as the direct cause of failures in steps 3 and 4 ([dev script](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/🧑️‍💻️dev/📦️packages/🟦️typescript/📜️script.ts:3006)-[3048]). Therefore mutations, presence, reconnect, and two-user visibility cannot be credited through the user action today.
3. **RED — presence has an outbound cadence but no server-side lease/expiry.** Browser and native actors emit `PresenceHeartbeat` (browser frame forwarding at [backbone-worker](../../../../../../../../../🧰️framework/🛍️products/💻️os/🟦️backbone-worker.ts:1639)-[1641], native cadence at [sync](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🔄️sync/🦀️.rs:957)-[1203]), and React schedules beats for open documents ([ShellHost](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑️‍🎨️engine/🧱️elements/ShellHost/🟦️.tsx:4291)-[4353]). Hub `PresenceSession`, however, contains only surface/user/color/peer—no last-seen/deadline—and removal happens only at socket handler exit ([bin.rs](../../../../../../../../../🌎️hub/📦️packages/🦀️rust/📦️bin.rs:413)-[422], [3168](../../../../../../../../../🌎️hub/📦️packages/🦀️rust/📦️bin.rs:3168), [3325](../../../../../../../../../🌎️hub/📦️packages/🦀️rust/📦️bin.rs:3325)-[3334]). A stalled connection can retain a stale roster indefinitely; heartbeat does not currently establish a bounded leave law.

Two additional source issues should be fixed before accepting the control plane:

- **RED — invite redemption escapes the DirectoryService writer lock before append.** `redeem_invite` creates its HLC-stamped event while holding `self.write`, then explicitly `drop(clock)` before `append_events` ([directory](../../../../../../../../../🌎️hub/📇️directory/🦀️.rs:1665)-[1694]), unlike command execution, which holds the lock through the append ([directory](../../../../../../../../../🌎️hub/📇️directory/🦀️.rs:1602)-[1610]). A concurrent command can append/publish a later HLC before the redeem append. The storage transaction preserves backend `seq`, but the service’s documented single serialized command-to-append/publish order is false for redemption. Keep the write guard through append and add a concurrent redeem/command ordering law.
- **RED — directory `Heartbeat` is a schema/client dependency but has no production publisher.** `DirectoryStreamMessage::Heartbeat` exists ([schema](../../../../../../../../../🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🦀️.rs:1003)-[1019]) and clients use it to advance stream state ([os TS](../../../../../../../../../🧰️framework/🛍️products/💻️os/🟦️.ts:4175)-[4216]), but the only current `DirectoryService.publish(Heartbeat)` site is a test at [bin.rs](../../../../../../../../../🌎️hub/📦️packages/🦀️rust/📦️bin.rs:7250)-[7255]. There is no server heartbeat/reconnect-progress proof. Either publish bounded head heartbeats or remove the false liveness promise and make reconnect readiness observable another way.

## Smallest independent schema-first partitions after document transport

1. **Public-space projection boundary.** Add separate public/detail DTOs to the directory schema; public detail must exclude members, emails, invites, active identities and presence. Enforce the same policy through REST and stream. Neutral oracle: anonymous public query succeeds for metadata/document-safe descriptors and rejects/omits each private identity field; member/author receives the authenticated detail.
2. **Opening identity propagation.** Extend the schema-first `OpenArtifact` relay payload with the immutable `(spaceId, documentId, schema)` descriptor identity. Make descriptor discovery the only producer; require all three before a hub attach. Add one language-neutral fixture and a two-user runtime assertion that creation, row open, direct URL open, and reconnect select the same scoped document.
3. **Presence lease contract.** Define `presenceLeaseMs`, last-seen update, expiry sweep and one final roster publication in the shared schema. Hub must expire an unresponsive client without relying on TCP close; reconnect gets a new actor/session and cannot resurrect the old lease. Add deterministic clock tests plus the real browser two-user disconnect/reconnect case.
4. **Directory writer and read projection.** Hold the writer guard through invite append/publish; give directory listing/detail a stored/read-through bounded projection or cursor protocol rather than complete-log replay. Neutral concurrent fixture: redeem vs rename/role command preserves append/HLC publication order; paged list produces no duplicate/gap and has hard byte/count limits.
5. **MCP collaboration control plane.** Only after the preceding contracts exist, add scope-bound MCP discovery/space commands and read-only collaborator summary as explicit capability schemas. Do not expose raw directory events, other-member PII, or live presence to an unscoped MCP process.

## Required acceptance proof

Use the existing registered collaboration launcher after partitions 1–4 are complete, but amend it to prove: two distinct authenticated identities; private/public membership negative paths; author vs spectator mutation denial; actual document identity propagated from descriptor to socket; one durable mutation observed by the other author; deliberate transport loss then deadline-bounded stale-presence removal/reconnect; no public member PII; restart/reopen; and explicit MCP scope refusal. Keep all server/browser/native/MCP failures distinct from unavailable external compile/toolchain failures.
