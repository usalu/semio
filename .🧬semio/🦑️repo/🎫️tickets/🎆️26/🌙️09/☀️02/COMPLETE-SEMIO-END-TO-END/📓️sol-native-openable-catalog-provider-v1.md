# Native Openable Catalog Provider V1

## Boundary

This packet implements the first hub-private statically linked `NativeOpenableCatalogProviderV1` for the zero-dependency `stdio` package. Authority originates in the owning artifact-definition `codecs` declarations. The checked-in 26-row registry JSON is a strict projection and independent-oracle input; it cannot authorize or mint a receipt.

The provider admits exactly one atomic closure:

- 26 schema-owned executable native codec declarations;
- 26 private factory identities and runtime capability claims;
- exact codec id, artifact kind, schema, extension and nonzero protocol-byte digest equality;
- exact plugin/package identity `semio:stdio`;
- one descriptor-owned JSON viewer target with exact app, window, role, renderer and surface ownership;
- no catalog or readiness publication if any row or target fails.

## Implementation

- `stdio` owner schemas each declare their executable codec row and private factory binding.
- `native_codec_factory_receipts()` joins owner declarations to private factories, instantiated codecs and exact protocol bytes. It consumes all 26 factories bijectively.
- `NativeOpenableCatalogProviderV1::linked()` consumes that private closure and exports only verified bindings to the hub trusted loader.
- The trusted loader validates every open target against the decoded package descriptor before publishing either codec or open-target indexes.
- Hub startup links only this `stdio` provider. Readiness remains false when the trusted pair is absent or incomplete and becomes true only after the complete provider and descriptor-owned bundle/profile are admitted.

## Independent contract

The neutral fixture has a strict JSON Schema, 26 exact projected receipts, the independently hashed component/descriptor vectors, one exact JSON viewer target and 13 hostile cases. The Bun oracle uses AJV and WebCrypto directly, recursively derives executable rows from owning artifact definitions, recomputes all 26 protocol hashes from checked-in bytes, and proves missing, extra, duplicate, digest, capability and surface substitutions publish nothing.
