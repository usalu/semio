# Trusted Catalog Browser-Actor Census

Read-only audit, 2026-09-06. This records the current producer and fixture frontier for the mandatory package-level `browserActor` record. It does not claim catalog loading, leasing, Worker containment, or activation.

## Required record and schema boundary

The authoritative public identity is already adjacent at [browser-actor schema](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🌐️browser-actor/🔣️.schema.json:3):

* `DocumentOpenBrowserActorV1` has only the immutable identity: `kind`, `schema`, `codegenPolicy`, `sha256`, `sourceComponentSha256`, `sourceDescriptorByteSha256`, `policySha256`, and sorted unique `importInterfaces` ([Rust](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🌐️browser-actor/🦀️.rs:73)).
* The lease variant adds only bounded `byteLength` ([Rust](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🌐️browser-actor/🦀️.rs:82)). Paths and raw bytes never enter plan or lease DTOs.
* A trusted bundle must additionally carry the private **relative** `path` and `byteLength` needed to load one body. The current bundle schema has the correct narrow composition: external identity `$ref` plus locally closed `path`/`byteLength`, and requires `browserActor` in every package ([bundle schema](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🧬️schema/🔣️bundle.schema.json:106)).

Keep this composition. Do not add a URL, component path alias, policy JSON, provider key, or bytes to the public actor type. The Rust loader needs a private tagged equivalent such as `BundleBrowserActor::{None, ClosedBrowserActor { path, byte_length, ...DocumentOpenBrowserActorV1 identity... }}`. It should:

1. validate its closed file record and path uniqueness together with component/descriptor;
2. load and hash the actor after descriptor decode/descriptor-source binding and before `NativeCodecProviderSourceV1::preview` ([loader ordering](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:446));
3. convert only the path-free portion to `DocumentOpenBrowserActorV1`, validate it against the already verified component/descriptor hashes and every relevant target renderer, then retain `Arc<[u8]>` privately;
4. include that plan identity in `VerifiedDocumentOpenSelectionV1`; retain body bytes only in `VerifiedExecutionTargetAssets`, never in an arbitrary package lookup.

The renderer rule matters: the shared validator permits `none` only for `react`/`wgpu` and a closed actor only for `wasm` ([validator](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🌐️browser-actor/🦀️.rs:112)). Therefore every current `wasm` catalog target needs a closed record and a verified body. A `none` placeholder is not a valid way to defer a WASM actor. Deferring **activation** until Worker containment is sound; deferring the record/body admission is not.

The new catalog corpus correctly registers both external schemas before compiling the bundle `$ref` ([script](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/📜️script.ts:4652)). Preserve this; compiling the bundle schema without first registering the directory actor `$id` is an unresolved-reference failure, not a valid independent schema check.

## File-ownership audit for actor body reads

This section audits the current loader, rather than the in-progress producer fence.

### What the current code guarantees

`contained_path` lexically rejects empty, absolute, parent/prefix, backslash, and overlong paths, canonicalizes the remainder and requires the **resolved** result to remain below the canonical bundle root ([1093-1107](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:1093)). `read_bounded` then follows that resolved path, checks a regular file and a caller-provided upper bound, allocates at most the metadata length, stops if read bytes exceed the same bound, checkpoints between 64 KiB chunks, and returns an empty/cancelled/error result before provider preview ([1109-1137](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:1109)). Actor-specific admission adds its declared length to a 128 MiB selected-closure counter before opening, then requires exact declared length and SHA-256 before retaining `Arc<[u8]>` ([502-511](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:502)).

Thus hostile bytes cannot become actor authority: a substituted body has to meet the record's exact length and SHA-256, actor source hashes have already been bound to verified component/descriptor bytes, and an error/cancellation drops the local `Vec` before `preview`/codec registration. Allocation is bounded by the declared actor limit (64 MiB) and selected actor closure maximum (128 MiB); a growing file is stopped before bytes beyond its declared maximum are appended. There is no unbounded read route.

### What it does **not** guarantee

It is not currently a regular-file/no-link ownership policy:

* `canonicalize(root.join(relative))` deliberately resolves an **in-root** symlink and returns only its target, so `starts_with(root)` accepts a link from `browser/actor.mjs` to another file under the same root. It hides both the linked leaf and any linked parent directory.
* `tokio::fs::metadata` follows a link, as does `tokio::fs::File::open`. A leaf/parent replacement after canonicalization can therefore change the object opened. The final digest prevents different bytes from acquiring authority, but it does not prove that a regular catalog-owned leaf, rather than a link/reparse point, supplied those bytes.
* The initial `bundle_path` itself is canonicalized before an `lstat`-style non-link check ([436-438](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:436)). A bundle symlink consequently defines its target directory as the root.
* `Vec::with_capacity(metadata.len())` has a numeric upper bound, but a host allocation failure aborts rather than becoming an `AuthorityError`. That is bounded resource use, not recoverable resource admission. Use `try_reserve_exact` in a future shared reader if the loader's cancellation/resource contract must include allocation refusal.

This is a source-ownership gap, not a digest/byte-authority bypass. A path race that supplies different bytes fails length/hash; one that supplies identical recorded bytes does not change actor authority. The strict producer generation fence already uses no-symlink directory/file identity checks; aligning the runtime loader to that policy is still the coherent choice.

### Bounded correction

Do not make an actor-only exception. Component, descriptor, bundle, and actor form one catalog authority closure, so replace the `contained_path` + path-reopening `read_bounded` pair with one private opaque opened-file input used by all four.

1. Validate the lexical relative path, `symlink_metadata` the supplied bundle leaf and catalog root **before** canonicalizing, and reject any link/reparse point. Walk each lexical path component from the regular root to the leaf; each parent must be a non-link directory and the leaf a non-link regular file.
2. Open the leaf without following it, then derive metadata from the handle and validate the opened object still corresponds to the checked leaf before streaming. The existing first-party reference is the CAS implementation: Unix `O_NOFOLLOW` plus opened-handle `dev/ino` comparison ([chunk CAS](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🧱️chunk-cas/🦀️.rs:679), [830-843](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🧱️chunk-cas/🦀️.rs:830)); Windows opens the leaf with `FILE_FLAG_OPEN_REPARSE_POINT` and rejects `FILE_ATTRIBUTE_REPARSE_POINT` ([707-720](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🧱️chunk-cas/🦀️.rs:707)). Do not copy only its leaf opener: Windows must also reject reparse points on every catalog path ancestor, not just `FileType::is_symlink()`.
3. Keep the opened handle through bounded async reading rather than reopening by pathname. Recheck lexical parent/leaf identities after the read where platform metadata makes that possible. A hostile concurrent rename cannot then switch the byte source after the no-follow open; any remaining post-open name change is detected/rejected rather than altering the already-opened bytes.
4. Perform `Vec::try_reserve_exact` using the checked handle length and map failure to the existing resource-limit category. Preserve the current 64 KiB checkpoint/yield loop and exact post-read length/digest verification.

The current CAS helpers are module-private and have CAS-specific errors, so this is a first-party shared filesystem primitive or a trusted-catalog-private equivalent—not an import of CAS storage or a new runtime dependency.

Use the existing `TestControl` ([1246](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:1246)) and `FixtureProviderSource.calls` counter ([1275-1308](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:1275)); make a one-package editor closure so no dependency preview obscures the actor result.
