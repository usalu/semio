# Member Dialect Authority

## Objective and Observed Defect

This packet is the first prerequisite for durable Norm EN 1990 action tables and DIN 18599 climate tables. The current generic app passes only `dialect.artifact_kind` to `MemberFactory::open`, while the only production generated member fleet dispatches its eighteen Semio variants by subset. An ordinary `s.stdio.semio` table therefore cannot traverse that generic restore boundary. The separate blanket `ArtifactStore` factory also treats caller-selected kind as schema on create and ignores it on open.

The correction is a complete, closed artifact-kind/standard/subset binding per factory arm, with exact requested-versus-persisted schema and dialect validation before constructing or publishing a store. Arbitrary kind/subset fallback and inferred aliases are not acceptable. The existing child handle remains separate from its child envelope; this packet will not serialize local caches into the parent.

Exercise generic app restore and coordinator creation where their existing fixtures permit. Source-only checks and metadata compilation will be reported separately from executed assertions.
