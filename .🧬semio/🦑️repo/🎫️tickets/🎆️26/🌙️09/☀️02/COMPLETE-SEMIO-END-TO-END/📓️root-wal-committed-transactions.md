## Retained Implementation

- The frame reader returns non-owning source spans and advances a raw replay offset only after complete record decode.
- The retained record decoder holds its byte writer, copy offset, index list and seal progress across fuel, cancellation and deadline interruptions. Cleanup is independent of cancellation grants.
- `WalTransactionGate` retains exactly 64 optional frame spans. An abort clears spans without decoding their payloads. Only a matching logical commit makes the bodies available.
- `WalCommittedCursor` verifies the complete segment's physical chain/header before grammar admission. A borrowed transaction prevents advancing or releasing the source segment. It exposes one borrowed record at a time, requires explicit record close and transaction finish, and poisons replay if a transaction borrow is dropped unfinished. Cursor cleanup retains and closes that unfinished decoder/record.
- Header-only segments remain visible through the immutable segment inventory, so compaction cannot mistake the last nonempty transaction for the active segment.
