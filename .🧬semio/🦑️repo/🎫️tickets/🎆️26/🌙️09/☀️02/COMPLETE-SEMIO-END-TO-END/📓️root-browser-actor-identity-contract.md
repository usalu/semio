# Browser Actor Identity Contract

## Scope

Implement the shared schema-first, path-free browser actor identity and bounded
lease projection in adjacent Rust and TypeScript implementations. A neutral JSON
corpus must agree with independent AJV shape validation plus binding/order checks.
This is the prerequisite for the mandatory catalog/plan/lease field census in
`📓️terra-closed-browser-derived-catalog-lease-current-frontier.md`.

The only states are explicit `none` and `closed-browser-actor`. Wasm requires the
closed state; React and Wgpu require none. Closed identity binds the exact source
component and descriptor SHA-256, generated bytes SHA-256, current fixed codegen
policy label and SHA-256, and canonical bounded import interfaces. Only the lease
projection has byte length. Neither projection permits paths, URLs, canonical
policy bytes, receipts, or module bytes.

## Sequencing

1. Define the schema and neutral adversarial corpus; run a registered source gate
   red before implementing the production parsers.
2. Implement strict owned immutable TypeScript projections and Rust first-party
   value codecs, validation, projection, and complete equality.
3. Qualify the shared corpus before making the existing catalog/public fields
   mandatory across all producers and consumers together. No optional-field
   fallback or dual-format reader will be introduced.

This contract does not authorize actor body delivery, Blob import, browser
activation, or durable GIS mutation. Those remain separately gated work.
