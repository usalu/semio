## First Missing Prerequisite

There is no `MemberOpenOperation` implementation in the current framework/Stdio tree, and `MemberFactory` has no associated retained operation or owned `begin_open`. The staged selected-factory declaration packet closes neither omission.

The actual `SemioFlowSnapshotDecode` consumes a whole `MemberOpenRequest` and returns `(SemioFlowSnapshot, MemberOpenRequest)`. The staged `SelectedVerifiedMemberHistory<M>` instead privately owns the original request, retained dictionary index and selected declaration. No current API can hand that witness to the Flow decoder while retaining its semantic proof, dictionary/input ownership and cancellation fence. Extracting the request, exposing raw history, re-reading through whole-value `decode_history`, or adding a second caller-provided schema would break the boundary being established.

The next implementation seam must therefore be the closed factory-owned typed operation, not a public loader wrapper around old `M::open`. It needs a kernel-owned selected witness with a scoped snapshot reader, an exact per-arm decoder from the same factory literals, retained history/replay/initialization stages, and ownership-preserving rejection. `MemberStoreOpenRetained` is only a partial-owner/retirement shell today; it does not implement those stages.

## Bounded Public Handoff Contract To Stage

The model stops at **private request handoff**, before invoking any typed decode/replay/store publication. A future public owned input contains only sealed pages, requested slot and full child reference. The app's fixed job registry mints operation/generation/expiry context; none is caller input. The loaded app supplies parent identity and declared child projection. Neither schema nor OwnerRef is caller input. The selected factory supplies the schema; `MemberFactory::create` is never an open-existing fallback, including for viewers.

Before consuming the public request, preflight operation-registry, abort-retirement, child-map and child-root capacity together. A refusal returns the same request without any partial reservation. After admission, the app retains the exact request/admission until the actual `M::begin_open` operation owns it. Begin rejection returns that same request to the app's abort owner. Cancellation or stale parent/operation authority cannot release an admission and leave an unowned request. The model must pin input and identity bytes separately and never claim typed allocation retirement.

This is not yet a proposal to change the public PluginApp method signature: the associated factory operation and selected-witness reader are absent. No dummy operation, `resolve_ready` bridge, borrowed-slice adapter, caller schema, alternate factory table, or public member publication is being installed.
