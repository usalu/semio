# Canonical Bootstrap Owner and Lease Binding

## Outcome

Canonical bootstrap installation now retains the exact document, socket, open attempt, client, private lease, installed target, schema and binding that admitted the transfer. A stale hash completion cannot install its pair, clear a successor assembler, or close a replacement socket. Socket-only retirement clears the old mounted owner only when both identities still match.

For an active execution-target lease, bootstrap admission now checks route scope and normalized Hub origin, the full artifact triple, descriptorDigestV1, a required checkpoint, aggregate SHA-256 and the complete checkpoint baseline frontier. The Welcome required-tail relation remains independent. This matches the Hub producer: lag-rebootstrap builds descriptor_hash from checkpoint.descriptor_digest_v1, not the raw component descriptor byte hash.

The assembler's returned shared-backing pack/SPR views are copied into the retained state and wiped in finally. Current state copies survive successful installation. No actor hydrate or render-ready status was added.

## Remaining Boundaries — Not Claimed Fixed

1. The generic folder mirror PUT still has no server-side owner generation or final publication fence. A post-PUT assertion prevents stale in-memory installation, but cannot undo a stale durable write. The read-only audit is locating the actual publisher and first-party staging contract. Mixed Hub/folder support has not been disabled to conceal this gap.
2. Snapshot/outbox notification reentrancy is a robustness frontier. The real Worker postMessage is non-reentrant, but the test sink can replace an owner between notifications. No browser exploit is claimed.
3. A verified retained pair needs a distinct private metadata-bound owner before it can drive the actor. currentPack/currentSpr alone are not a fresh authority.
4. Real actor lifecycle must integrate GuestLifecycleCell before cold pages: reject every occupied modulo slot, emit/retain Captured, consume only exact ACK, and retain the native close owner through terminal ACK. The existing native close path also needs review for double close admission.
5. Cold ingress must use acknowledged bounded pages under the existing 256KiB child message limit and end at the real plugin_load_document_pack. Typed patch publication through UiDocumentStore and real TiledMapHost remain mandatory.

All results above are JS production-path/fixture checks, not native Hub, real GIS child, durable folder race, renderer, Map editing or whole-product acceptance.
