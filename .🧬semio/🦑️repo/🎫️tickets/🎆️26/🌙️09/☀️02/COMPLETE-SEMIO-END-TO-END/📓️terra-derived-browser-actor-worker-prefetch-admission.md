# Derived Browser Actor Pre-Fetch Worker Admission Frontier

## Verdict

Actor delivery must remain off. The current authenticated browser path verifies only a component and descriptor, retains those two buffers in a private `DocumentExecutionTargetLease`, and intentionally publishes `renderer-unavailable`; it has no actor route, worker owner, aggregate ledger, invocation deadline, or termination path. The smallest safe next slice is therefore a **static, first-party child Worker controller in the backbone Worker**, constructed and made ready *after the verified target manifest is parsed but before a future actor body request is issued*. It is a containment/admission slice, not actor activation or a sandbox claim.

This covers application-owned byte retention and time. A web Worker has no portable hard heap quota: no implementation may describe the proposed ledger as a cap on arbitrary guest allocations. Forced `Worker.terminate()` is the only reliable answer to a non-cooperating guest and reclaims its realm; it does not make the guest a general security sandbox.

## Exact smallest owner

Add a private `DerivedActorWorkerOwner` and a module-private `DerivedActorByteLedger` beside the execution-target region in [`backbone-worker.ts`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🧵️backbone-worker.ts:522). The owner is created from a parsed, future `DocumentExecutionTargetBrowserActorV1` only when `kind === "closed-browser-actor"`, after the manifest-to-plan comparison and before the body request. Its factory does all of the following atomically from the caller's point of view:

1. Reserve a fixed global ledger credit for `actor.byteLength + 2 * ACTOR_MESSAGE_MAX_BYTES + ACTOR_HOST_OUTPUT_MAX_BYTES`. The actor body is at most `DOCUMENT_BROWSER_ACTOR_MAX_BYTES` (64 MiB); set `ACTOR_MESSAGE_MAX_BYTES` to 256 KiB and reuse the host's existing 1 MiB output ceiling. Retain this credit from preflight until termination; return it exactly once on every rejected creation, load fault, deadline, socket loss, and close. This is an aggregate **intentional-buffer** budget, not a heap cap. A conservative initial global cap is two full actor reservations (roughly 130 MiB including the two message reserves/output); choosing a larger product policy belongs to a later catalog policy record, not caller input.
2. Construct a fixed first-party module Worker, e.g. a new `🧵️derived-browser-actor-worker.ts` reached only by `new URL(..., import.meta.url)` in backbone code. The existing static worker pattern is [`browser-boot/🟦️.ts:7-9,164-168`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🎯️targets/🧊️wgpu/🚀️browser-boot/🟦️.ts:7); no catalog path, component URL, module URL, or caller-provided worker URL is admitted.

Wait for an exact `ready { ownerEpoch }` before fetching actor bytes. Failure, `error`, `messageerror`, or boot expiry terminates the Worker, closes both ports, removes listeners/timers, releases the credit, and yields no actor request.
4. Only then use a **dedicated private actor-fetch helper**. It may POST the existing canonical `DocumentOpenIntentV1` to a fixed `/execution-target/browser-actor` path, but must not be an additional value of public `browserExecutionTargetAssetRequest`. ## Deadline and terminal protocol

Use the existing frame transport only as a structural precedent: its small `Worker` interface has `onmessage`, `onerror`, `onmessageerror`, `postMessage`, and `terminate` ([`browser-frame-transport/🟦️.ts:110-115`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🎯️targets/🧊️wgpu/🚚️browser-frame-transport/🟦️.ts:110)), arms boot timeout and error handlers ([lines 184-204](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🎯️targets/🧊️wgpu/🚚️browser-frame-transport/🟦️.ts:184)), and treats a terminal state as fail-closed. Do not share its UI queues or make the actor a WGPU frame job.

`DerivedActorWorkerOwner` needs a monotonic `ownerEpoch`, phase `Booting | ReadyForBytes | Loading | Active | Terminal`, one timer per active phase, and one invocation slot. Arm the load/activation timer **before** transferring verified bytes; arm the invocation timer before posting an invoke. Every child message must carry the exact epoch and phase-specific operation id. A duplicate, stale, future, malformed, or terminal-after-terminal message is ignored after resources are terminal; a future/invalid message while live is terminal protocol failure. A completion only clears the matching timer/slot. `docAbort`, lease re-open, socket close, and `closeArtifactRuntime` must call the single idempotent `terminate(reason)` before `dropDocumentExecutionTargetLease`; it aborts the local bridge, clears timers/listeners, closes the port, calls `worker.terminate()` without waiting for guest cooperation, drops byte references, and releases the same ledger reservation once.

There is no portable way to prove that a noncooperative Worker has not allocated additional heap before it is terminated. The acceptance claim is bounded application buffers, one live child per document, and forced retirement, not process memory isolation.

1. `derived_actor_none_never_constructs_worker_or_requests_actor_body` — exact `none`, React, and WGPU vectors make zero Worker and actor-route calls.
2. `derived_actor_admission_precedes_actor_request` — a full ledger or constructor/ready failure makes zero actor-body calls, terminates any constructed child, and returns all reservation credit.
3. `derived_actor_verified_transfer_detaches_parent_once` — only matching byte length/SHA reaches the child via one transfer; post failure wipes parent bytes and does not retain a Blob/module URL in backbone.
4. `derived_actor_boot_timeout_forces_termination_and_releases_credit` — no ready message before the controlled deadline creates no actor request and releases the exact reservation once.
5. `derived_actor_load_timeout_kills_noncooperative_child` — a real child receives bytes then loops; parent deadline fires, `terminate()` occurs, and a second operation cannot reuse its epoch or credit.
6. `derived_actor_close_and_socket_revocation_terminate_before_lease_wipe` — close and reconnect invalidation each terminate/close bridge once, clear all timers, then clear actor/component/descriptor references; a late ready/result cannot publish.
7. `derived_actor_stale_or_cross_scope_message_cannot_settle_current_owner` — old epoch, different runtime key, duplicate result, and future operation-id are rejected/ignored without clearing the current timer or moving bytes/effects across spaces.
8. `derived_actor_message_and_host_output_limits_fail_closed` — oversized inbound/outbound framed bytes, two simultaneous invokes, or a denied host-effect request terminalizes or rejects before unbounded structured-clone retention; the neutral oracle proves exact credit restoration.

No law above should call Hub actor delivery, execute a GIS plugin, or claim persistence/rendering. The current verified lease test remains the prerequisite target-authentication law; this new packet begins only when the actor identity is carried through that same verified plan/manifest relation.
