# Native OS End-to-End Parity Audit

## Decision

Native WGPU is **not ready for an authenticated, collaborative GIS document journey**. The first deterministic stopper is a source-level compile integration break: the native shell exhaustively matches two protocol enums that have gained variants (`ArtifactEvent::BootstrapProgress` and `DirectoryStreamMessage::RebootstrapRequired`) without matching them. Even if those match arms are repaired, every native document-open path aborts at the deliberately unimplemented `ProgramBridge::attach_backbone`. The store actor below it does contain current P2-C-style descriptor-bound public `(pack,spr)` bootstrap, integrity checks, persistence, reconnection, and progress events; native never completes the bridge from that actor to a plugin document.

This is a read-only source audit on 2026-09-03. No build, package, socket, Docker, GPU, or launch command was run; claims marked *implemented* mean present in current source, not runtime-proven.

## First deterministic failures

1. **Critical — native target cannot type-check current protocol surface.** `ArtifactEvent` declares `BootstrapProgress` at `store/sync/🦀️.rs:494-496`; `pump_sync_events` matches every other current variant at `Shell/🦀️.rs:3098-3148`. Rust exhaustive matching makes that a compile error. Independently, `DirectoryStreamMessage` declares `RebootstrapRequired` at `directory/schema/🦀️.rs:541-562`, but `pump_directory_events` only matches four earlier variants at `Shell/🦀️.rs:4075-4080`. This is a current source integration defect, not a test expectation problem. It should be fixed before using native builds to diagnose any later runtime failure.

2. **Critical — after compilation, any real document open deterministically returns an error.** `open_document` invokes `ProgramBridge::attach_backbone` at `Shell/🦀️.rs:3561`; the only native WIT exchange implementation returns `Err` at `ProgramBridge/🦀️.rs:281-283`. The same stop exists in manual attach and space-index touch routes. This is a production defect, explicitly documented as a stub, not stale test fixture behavior.

3. **High — authenticated descriptor authority is bypassed at the opening relay.** `handle_open_artifact_relay` accepts plugin-supplied `documentId`, `schema`, and optional `spaceId` before binding/opening. It does not obtain a descriptor from a hub authority, verify document membership/revocation, descriptor digest, published plugin/package identity, or codec/manifest association. The actor validates a bootstrap once one arrives; it does not establish that the requested target was authorized to be opened.

4. **High — the launch/configuration is only developer-local.** The native launch lacks `S_HUB_URL`, `S_USER`, `S_DATA_DIR`; without them `resolve_identity_env` intentionally no-ops. The only collaboration compounds are React+hub and two React users. This is missing launch registration, not proof that native transport cannot work.

5. **High — expected production surfaces remain missing after the bridge.** Native does not surface bootstrap progress/outcomes/preview or session colour, has no controlled local broadcast-lag rebootstrap action, supports a single OS window/current document, and does not route GIS inference. The native non-empty renderer-asset-page path also hard-errors pending a retained-page handoff (`renderer/🦀️.rs:14927-14975`); do not represent it as general native asset parity.

## Authority and privacy invariants

- A native process may use `S_USER` only to enter the session bootstrap; it must never become the authority for a user id, actor id, space, document, schema, or role. The authenticated/revalidated server session determines all of those, and a revoked session must terminate both directory and document sockets before queued changes can be admitted.
- Bind a document open to one server-issued descriptor: `(spaceId, documentId, schema, descriptorDigestV1, codec/packSchemaHash, approved package/plugin identity, frontier)`. Verify it before an `ArtifactHost` is opened and revalidate it after reconnect/rebootstrap. A public pair is accepted only if it matches that frozen descriptor and codec; no database-private snapshot goes to clients.
- Use the hub-issued session actor/color. Native must not accept a plugin/action value as actor identity or peer presence scope. Presence isolation is structural document scope plus authenticated actor; `surface` is non-authoritative peer telemetry and must not filter the document-wide roster or leak cross-space/cross-user state.
- Keep user folder identity/cache roots separate in real two-process tests. Same data root is a deliberate shared local cache, not a multi-user isolation mechanism.
- A GIS inference result is observational until a currently authorized user explicitly approves a typed mutation at the same descriptor/frontier/revision. Cancel, restart, revoke, rebootstrap, or a changed frontier makes the old result stale and non-applicable.

## Dependency-ordered implementation packet

1. **Restore target integrity first — `Shell/🎯targets/🧊wgpu/🦀️.rs`.** Add explicit handling for `ArtifactEvent::BootstrapProgress` and `DirectoryStreamMessage::RebootstrapRequired`; never add a catch-all that masks future protocol growth. Give the user a bounded bootstrap progress/cancel status and route directory control to the same descriptor-bound rebootstrap coordinator. Treat broadcast `Lagged` as a state transition that closes/resubscribes/revalidates rather than `continue`.

2. **Replace the retired native backbone API — `ProgramBridge/🎯targets/🧊wgpu/🦀️.rs`, native Wasmtime exchange/host import boundary, and `Shell/🎯targets/🧊wgpu/🦀️.rs`.** Define one event-driven duplex channel keyed by a fresh mount generation: native creates `ArtifactHost` channel, registers the outbound route before the plugin can emit, supplies snapshot/mutations to the plugin and routes plugin outbound messages to actor commands. Closing, app switch, rebootstrap, plugin reload, and error must cancel the generation and drain/retire it exactly once. Do not resurrect a URI-only `EffectBackbone` compatibility shim.

3. **Introduce an authenticated descriptor open service before `handle_open_artifact_relay`.** Its sole output is a validated immutable open plan containing descriptor identity, public pair policy, `ArtifactActorConfig`, registered codec identity and authorized surface. The relay/action payload becomes an intent (`spaceId`, document locator, requested role); it cannot nominate schema or claim a space. Revalidate plan/session/membership on reconnect, checkpoint rebootstrap, share revoke, admin kick, and before an approved mutation.

4. **Complete actor-to-native UX semantics.** Preserve store actor’s bounded outbox/deadline and surface `BootstrapProgress`, `Status`, `Session`, `Presence`, `CommandOutcome`, conflict and rebootstrap in the native shell. Reconcile local store before live; show transformed/rejected command outcomes and do not falsely mark a document live before its required frontier. Keep the 10 MB/8 request directory transport limits and directory queue bounded; define a deadline for directory requests rather than leaving `deadline_ms: None`.

5. **Native window/process isolation and launch.** Either deliberately scope the first release to one OS window and register two isolated native processes, or add a host-level per-window shell/identity/document registry. In either case register `native + hub`, `native user 1 + native user 2 + hub`, and a headless smoke profile in `launch.json`, with distinct `S_USER` and `S_DATA_DIR` values and an explicit trusted local dev bootstrap. Do not expose a network dev bootstrap.

6. **GIS only after document authority works.** Mount the map against the descriptor-open document, use local tile/cache failures as cancellable resource states, then add native inference job submission/observation through the shared run-process router. Bind job inputs/results to descriptor/frontier, publish no inferred mutation automatically, and keep result visibility at least as restrictive as source document visibility.

## Stale/config versus production classification

- **Stale/config/test evidence:** absent native+hub/two-user launch compounds; default native launch omits identity environment; generated `frame-worker.js` catalog evidence may be stale until its owner’s generation/check target passes; `--smoke` boots identity/catalog but does not open an authenticated GIS document or prove GPU, map, edit, rebootstrap, or multi-user behavior.
- **Production source defects:** the two exhaustive-match compile breaks; retired `attach_backbone`; unverified opening relay; dropped local broadcast lag; missing event/progress/outcome presentation; single native OS window/current document; no native GIS inference run/approval route; hard failure for non-empty native renderer asset pages.
- **Implemented but not yet end-to-end proven:** native `ArtifactHost`, public artifact bootstrap validation/persistence/reconnect, native `DirectoryClient` setup, and `TiledMapSurface` allocation.

The sharp blocker is **the retired `ProgramBridge::attach_backbone` plus the immediate exhaustive-match compile break**: native cannot currently build against the refreshed P2-C event contracts, and, once it does, it still cannot connect an authenticated public artifact actor to a GIS plugin document.
