# Initial Composition Authority Seam Audit

## Verdict

**RED: the server already has an authenticated author-and-scope authority before snapshot construction, but no sealed authority reaches composition creation.** A surface instance id, `DocumentOpenGrantV1.write`, or a caller-provided role must not be treated as that authority.

## Existing Trusted Inputs

The protected open-plan route builds the exact `DocumentScope`, authenticates the bearer session, resolves the current directory role, acquires a per-subject gate, and revalidates before and after descriptor/catalog selection [open-plan route](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/🚀️bin.rs:1967). `writable` is computed only from the private `SocketSubjectV1::Session { role: Some(SpaceRole::Author) }` [role intersection](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/🚀️bin.rs:2010).

The private `DocumentOpenPlanAuthorityV1` already retains scope, descriptor digest, immutable catalog/package/artifact/surface choice, subject, server actor, client-instance digest, and revalidation generations [authority](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/🚀️bin.rs:994). Its validation enforces `grant.write` exactly when the private session role is `Author`; share grants are non-writing [validation](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/🚀️bin.rs:1010). The socket ledger retains that authority through the live socket and revalidates descriptor, catalog generation, membership revision, checkpoint, and binding on every protected turn [live-plan validation](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/🚀️bin.rs:2560).

The fully qualified parent dialect does exist in the verified plugin descriptor's `AppDefinition.dialect` [manifest](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🛂️manifest/🦀️.rs:3419), and the trusted catalog validates that the selected app's dialect kind agrees with the exact verified target [catalog validation](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:536).

## Current Missing Boundary

That dialect is discarded when `VerifiedDocumentOpenSelectionV1` is constructed: the public/retained selection keeps only kind, schema, and pack hash [selection](/Users/ueli/Documents/semio/🌎️hub/🗿️artifact-authority/🔏️trusted-catalog/🦀️.rs:455). The durable `DocumentDescriptor` likewise has only `artifact_kind` and `artifact_schema`, not an `ArtifactRef` or full dialect [descriptor](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🧬️schema/🦀️.rs:563). Therefore the hub's existing trusted open path cannot yet derive the full parent reference needed by initial-child identity without accepting it from the caller.

The desktop/plugin factory is explicitly unbound: `VcsArtifactApp::new` and `with_registry_on_bus` create a document envelope from `A::instance_id()` and `A::initial_snapshot()` [factory](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🦀️.rs:19189). That id is surface-local; it is neither `DocumentScope` nor an authenticated principal. The client-visible `DocumentOpenPlanV1`, `DocumentSocketAuthorityV1`, and `DocumentOpenGrantV1` are cloneable data projections, so their `write: true` cannot be accepted as a store capability [client authority projection](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📇️directory/🔌️client/🦀️.rs:244).

The live socket revalidates a real subject before each incoming frame, but drops that private authority and calls `handle_client_frame` with a role-derived database principal only [socket loop](/Users/ueli/Documents/semio/🌎️hub/📦️packages/🦀️rust/🚀️bin.rs:3207). There is no typed `CreateInitialComposition` frame, sealed receipt, or durable composition relation writer today.

## Smallest Sound P0

1. Retain `parent_dialect: ArtifactDialect` in `VerifiedDocumentOpenSelectionV1`, sourced only from the verified `AppDefinition.dialect`; include it in catalog sorting/generation bytes and all plan/socket equality checks. Construct the parent reference as `{ artifact_id: scope.document_id, dialect: parent_dialect }`, rejecting any disagreement. Do not derive it from an app instance id or client field.
2. Add a private, non-`Clone` `InitialCompositionAuthorityV1` in the hub. It may be minted only from the live document-plan authority after a fresh binding revalidation, and only when the subject is an authenticated `Author`, the selected grant is writing, and the selected surface is an editor. It carries the exact scope, parent reference, descriptor digest, catalog generation, session generation, server actor, and expiry. It has no `is_author` constructor or public boolean.
3. Issue a one-use opaque initial-composition receipt from that authority, bound to the live socket/subject. The browser/native client may carry the opaque receipt, but the hub consumes it under its ledger mutex plus a fresh `socket_live_authority`/catalog/descriptor recheck. A share, spectator, stale generation, changed descriptor/catalog, foreign actor, wrong scope, or second consume is terminally denied.
4. Thread the sealed server authority—not `Principal` strings or the public plan—into the new typed socket command handler. The handler derives the initial child coordinate from the server-selected parent reference and schema-declared child relation; it must not take parent dialect, slot, child id, or author role as arbitrary UI input. Persisting the actual parent/child relation and applying it through the composition transaction is a subsequent packet; until then receipt issuance/consumption must not claim composition creation.

The verified package/component and descriptor hashes already bind the selected app descriptor at open time, so P0 can retain the full dialect in the trusted selection rather than widening `DocumentDescriptor` immediately. The resulting durable relation must nevertheless persist its complete parent `ArtifactRef`; a later open must never re-infer standard/subset from a surface id.

## Required Neutral and Native Proof

- One author plan for one scope yields one receipt whose sealed parent id equals `scope.document_id` and whose dialect equals the verified app declaration.
- Spectator, share, forged `write`, forged role, surface-only `instance_id`, foreign scope, foreign session/actor, changed descriptor digest/catalog generation, cancellation, expiry, and double consume all fail before any initial snapshot/child factory call.
- A valid author receipt reaches the server composition command boundary exactly once; its subsequent persistence receipt is not yet a proof of client-side `VcsArtifactApp` creation.
- Re-run the existing open-plan issue/exchange law as the prerequisite, then add a separately registered hub exact-law target for this receipt. No browser/native factory or launch success should be credited until a server durable-relation command and authenticated two-user proof exist.
