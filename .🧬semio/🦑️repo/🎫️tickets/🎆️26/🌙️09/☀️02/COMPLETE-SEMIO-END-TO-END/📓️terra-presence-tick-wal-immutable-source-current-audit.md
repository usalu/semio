The smallest deterministic test-only replacement is a second helper, for example `evaluate_tick_and_ungate`:

1. wait with the existing five-second bound for `tick_admitted`;
2. store `gate_ticks = false` **before** releasing that admitted final tick;
3. add exactly one `tick_release` permit; then wait with the existing bound for `tick_evaluated`.

Use ordinary `evaluate_tick` for TTL-1 and the final helper for TTL. Delete the test's manual `gate_ticks.store(false)` and its stray release.
