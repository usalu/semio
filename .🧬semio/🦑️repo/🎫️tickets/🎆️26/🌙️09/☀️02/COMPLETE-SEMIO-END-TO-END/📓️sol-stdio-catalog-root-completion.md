## Implemented contract

- `PackageDescriptor.packageId` is required. `UtilityDefinition`, `WindowKindDefinition`, `AppDefinition`, `PluginManifest`, `ExtensionPointDeclaration`, and `PackageDescriptor` have first-party `ToValue`/`FromValue` derives with field-level rename/default parity and unknown-field denial. Plugin and extension descriptor exports encode directly through the structural DSL codec and fail explicitly on codec failure.
- The shared descriptor producer requires separate raw component and extracted core paths, bounds both at 64 MiB with 64 KiB reads, rejects equal raw/core hashes, computes the canonical blank-self-field descriptor SHA-256, and rollback-publishes the Pack/JSON owner pair. The stdio command extracts the core from the exact component it built once.
- The owned `catalog-root` operation requires an absolute, empty, caller-created root; refuses the repository, ambient `target`, and development cache; creates its own `CARGO_TARGET_DIR`; stages exact raw/core/descriptor files; publishes the row by rename; regenerates source projections only via registry `generate`/`check-generated`; and writes a canonical bounded completion marker last. Expensive subprocess/copy/hash work has a 20-minute aggregate deadline, cancellation checks, 64 MiB artifact limits, and 64 KiB chunks.
- Independent oracles cover the neutral fixture schema, WebCrypto SHA-256, framework Pack canonical round-trip, `WebAssembly.validate`, JCO WIT extraction, exact raw/core distinction, self-hash, rollback, cancellation/deadline, max+1, stale-root, and mutation-during-copy failure.
- `PluginRegistryEntry` carries the exact Cargo `[package.metadata.component].package` value. The bounded parser accepts exactly one component section and `package` key, enforces `semio:<lowercase-alnum-hyphen>`, and rejects duplicate section/key, malformed exact key, broad-key substitution, mismatch, and noncanonical identity. Generated TypeScript/JSON registry projections retain `packageId`.
- The canonical marker binds package/plugin/package-name/wasm-name and exact size/SHA-256 receipts for the staged raw/core/descriptor triplet. The strict reader verifies only the marker, carried Cargo entry, and staged triplet; owner JSON/Pack are producer-side derivatives and can be deleted before verification. It reads each admitted artifact through one file descriptor and returns the exact retained bytes it hashed. Consumer laws prove mutation after raw capture cannot substitute reopened bytes.
- The trusted hub descriptor projection directly decodes the first-party Pack value, recursively rejects duplicate fields, rejects unknown fields through the schema codec, validates canonical package grammar, and requires `descriptor.packageId == record.packageId`.
- `native_codec_factory_receipts()` is generated over explicit candidate factories but refuses admission at the descriptor/executable boundary. A runtime assembly without an executable native-codec declaration is negative evidence. The current glTF row proves a zero schema hash and extension/format mismatch and is not promoted. `linked_native_codec_bindings()` remains empty.
