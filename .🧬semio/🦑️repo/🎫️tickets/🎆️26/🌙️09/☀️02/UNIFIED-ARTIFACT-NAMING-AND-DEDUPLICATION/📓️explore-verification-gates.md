- `SEMIO_ORCHESTRATOR_BUDGET_MS` – Orchestrator timeout (4 hours)

### Budget Constants in Code
```typescript

export const CMD_BUDGET_MS = 600_000;      // 10 minutes

```

### Typical Cargo Lock Behavior
- Cargo operations serialize on shared `target/` directory lock
- First build is slow (full compilation)
- Incremental builds much faster
- Concurrent `cargo build` from different sessions causes contention (primary timeout cause)
