# 🖍️→🖍️ Rename `🖍️draw` plugin's artifact: verb `draw` → noun `drawing`

- `✏️s/🔌️plugins/🖍️draw/🗿️artifacts/🖍️draw` → `.../🗿️artifacts/🖍️drawing` (~420 files moved with it, all `#[path]`-wired, no symlinks). The plugin directory `✏️s/🔌️plugins/🖍️draw` itself was **not** renamed (per instructions — the plugin stays `draw`).

### Content rewrite
Wrote a token-aware Python rewriter (kept at `.🧬semio/…/UNIFIED-ARTIFACT-NAMING-AND-DEDUPLICATION/` is not where the script lives — it was run from the session scratchpad and not persisted; see "Verification" for the exact rules) that, for every file under the renamed artifact subtree (420 files: `.rs`, `.ts`, `.json`, `.md`, `.svg`, `.semio`, `.proto`, `.graphql`, `.feature`, `.toml`, `.lock`, `.spicy`, `.ksy`, `.g4`, `.ebnf`, `.abnf`):
- `Draw` → `Drawing` when followed by an uppercase letter or a word boundary (compound and standalone PascalCase).
- `DRAW` → `DRAWING` under the same rule (SCREAMING_SNAKE).
- lowercase `draw` → `drawing` whenever it is not directly adjacent to another letter (covers `draw_x`, `x_draw`, kebab/dot namespaces like `draw-store.x`/`draw.semantic`/`semio.draw.x`, and bare quoted `"draw"` values) while leaving `drawn`, `drawer`, `withdraw`, `redraw` untouched (those fail the letter-adjacency test).
- The literal path segment `🗿️artifacts/🖍️draw` → `🗿️artifacts/🖍️drawing`.
- Two identifiers were protected from the blanket rule and restored afterwards because they name the **plugin**, not the artifact: `DrawApps` (the plugin's app-registry type, `crate::DrawApps`, matches the `GisApps`/`RasterApps` convention where the Apps type is always plugin-scoped even when the artifact has a different name) and the `s.draw` identity prefix (`ArtifactIdentity::parse("s.draw")` and every `"s.draw.…"` capability-row name — plugin-scoped per the `s.<plugin>.<facet>` convention; only a *second*, doubled `draw` segment such as `"s.draw.draw"` → `"s.draw.drawing"` was renamed, since that second segment is the artifact descriptor).

Ran it over the 420 files under the artifact subtree, one whole-file pass. Corruption re-grep (`drawinging`, `Drawinging`, `DRAWINGING`, `drawingn`) came back empty; `withdraw` occurrences (zero in this plugin) are unaffected by construction. One miss the regex couldn't reach (bounded by non-letters on both sides, but here `draw` was glued directly to the next word with no separator): `#[dsl(extension = "drawcfg")]` → hand-fixed to `"drawingcfg"` (the artifact's config-facet extension; no other file referenced the old string).

Covered by the rewriter, spot-checked afterward:
