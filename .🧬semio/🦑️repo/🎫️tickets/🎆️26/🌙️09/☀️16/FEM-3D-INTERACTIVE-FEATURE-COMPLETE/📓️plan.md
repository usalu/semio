# 🏗️ Fem 3D interactive feature complete — plan (2026-09-16)

## Findings (coordinator reads)
- fem3d editor today: 18 commands (add*/set*/removeSelection/setActiveExample/setCamera/setResultDisplay), two `World3d` windows (model, results), NO interaction domain, NO panels, NO pointer/pick handling, NO transform, NO animation, NO patch commands. `world3d_selection_json("rectangle", &[], None)` on both scenes; instances are `node-{id}`/`el-{id}`/`solid-inst-{id}` (not entity ids); solids are baked meshes with identity instances.
- Results window solves synchronously per render (`fem3d_solve_all`, no cache); the mounted `live_visual` lane refuses the demo (memory) and is inert on the React lane.
- Mutations: 25 kinds; missing `replace-node`, `replace-load`, `change-load-case-name`, `replace-combination` (the four fem2d added for its inspector).
- `FemSolid` = footprint (outline+holes) extruded along +Z only → no gable roof (sloped), no window openings in vertical walls.
- `resolve_geometry`/`fem3d_mesh_preview` merge mesh points only against DOCUMENT nodes, never across solids → assemblies of solids are disconnected bodies.
- World3dHost: the gumball commits ONE start→end delta at drag end (`translateSelection`/`rotateSelection`/`scaleSelection`); mid-drag is a local imperative instance-root preview. Instance pick uses the literal `"object"` granularity (scene `domainGranularityId` is ignored for instance clicks, honoured for hover/marquee); records carry `interactionId` but no per-instance granularity.
- Mesher: constrained-edge subdivision `ceil(len / (max_edge/√2))`, lattice at `max_edge/√2` from the outline's bounding-box minimum; point dedupe is bit-exact (`to_bits`), edge points computed as `a + (b−a)·(i/n)`.

## Architecture
1. **Schema** (`🧬️schema` + every facet/fixture): `FemSolid.axis: FemAxis { X, Y, Z }` — the world axis the footprint is extruded along; outline coordinates are the two remaining axes in world order (X: `(y, z)`, Y: `(x, z)`, Z: `(x, y)`). Four new mutation kinds `replace-node`, `replace-load`, `change-load-case-name`, `replace-combination` (leaf modules, diff, inverse, JSON schema, fixtures, tests, oracle catalogs, kinds list, grammar/TS/GraphQL/proto facets).
2. **Engine** (`⚙️engine/🧊️3d/🕸️meshing`, `🗺️mesh-preview`, `🕸️mesh`): axis mapping of extruded points; cross-solid coincident-node merge (quantised spatial index, 1e-6 m); area loads as pressure on every upward-facing boundary triangle (projected area) so a sloped roof takes snow; mesher edge points as `a + (b−a)·i/n` and a tolerance on the segment count so grid-aligned interfaces conform bit-for-bit; near-duplicate point dedupe.
3. **Interaction** (`✏️editor/🕹️interaction`): framework-owned `fem3d` domain (node, element, solid, support, load, material, section, loadCase, combination), snapshot, entity kind lookup, model points, transform targets/pivot, selection JSON (`gumballActive`, `gumballTarget`, `gumballConfig`, `transformMode`, `gumballLiveDispatch`), scene instances keyed by RAW entity ids with `interactionGranularityId`; support/load glyph instances (`interactionId` → entity id).
4. **Framework** (`World3dHost`): `WorldInstanceRecord.interactionGranularityId` honoured on instance pick/hover; `WorldSelectionRecord.gumballLiveDispatch` — when set, the drag dispatches incremental pose deltas (latest pose wins, chained) and skips the local instance preview (the document IS the preview), drag end dispatches the remaining delta.
5. **Commands**: `translateSelection`/`rotateSelection`/`scaleSelection` (coalesced amends, refresh both window bodies), `setTransformGumballFlag` (model window config), `patchNode/Element/Material/Section/Support/Solid/Load/LoadCase/Combination`, `setResultAnimation`, `resultAnimationTick`, `focusEntity` (orbit target), `removeSelection` from the live selection.
6. **Panels**: artifact tree (paged, nine sections + analysis), inspector (form sections per kind, actions), results (display/playback/analysis; unfocused mode).
7. **Windows**: model scene with selection/hover/gumball; results scene with a per-revision results cache, playback amplitude, error caption over the undeformed scene instead of a blank window.
8. **House example** (`📚️examples/🏠️house` + committed DSL asset): raft foundation (Z), gable walls with door/window holes (Y-extruded), eaves walls with windows (X-extruded), ceiling slab (Z), gable triangles and a chevron roof (Y-extruded) — module 0.5 m, `mesh_size = √2/2` so every interface lands on the same lattice; concrete + masonry + timber materials; self weight, floor live load, snow on the roof; supports on the raft underside grid; a Rust generator whose print is asserted equal to the committed asset.
9. **Verification**: check + nextest (feature-enabled), wasm component build, describe + registry, React lane on 6087 with console probes (pick, tree, inspector patch, gumball live steps with re-solve count, playback), screenshots.
