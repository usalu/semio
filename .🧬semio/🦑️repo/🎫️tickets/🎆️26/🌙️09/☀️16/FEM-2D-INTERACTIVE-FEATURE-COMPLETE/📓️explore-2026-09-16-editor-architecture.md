# 🏗️ FEM 2D editor — architecture and implementation audit (2026-09-16)

Read-only exploration (Sonnet). Scope: `✏️s/🔌️plugins/🏗️fem/🗿️artifacts/◻️2d/🏅️standards/🔖️1/🪆️subsets/🌐️any/✏️editor/**`, the crate root `🗿️artifacts/◻️2d/🦀️.rs`, `🧬️schema/🧬️mutations/🦀️.rs`, `⚙️engine/🖥️app-surface/🦀️.rs`, and the `🗿️artifacts/🧊️3d` sibling.

## 1. Architecture

**Document model.** `Fem2dSnapshot` (alias `Fem2dArtifact`, re-exported at `◻️2d/🦀️.rs:299-300`) is a flat struct of 8 id-keyed collections plus one settings record (`fem2d_document_items`, `✏️editor/🦀️.rs:136-140`): `nodes`, `elements` (`FemElement::Bar|Beam`, `◻️2d/🦀️.rs:159-166`), `regions` (`FemRegion`, polygon-with-holes continuum, `:243-253`), `materials` (`FemMaterial`, `:177-187`), `sections` (`FemSection`, `:190-199`), `supports` (`FemSupport`, `:202-208`), `load_cases` (`FemLoadCase{ loads: Vec<FemLoad>, self_weight }`, `:230-239`), `combinations` (`FemCombination{ terms: Vec<FemCombinationTerm> }`, `:255-272`), and `analysis: FemAnalysisSettings{ modal_count, buckling_count, deformation_scale }` (`:283-295`, default 50×). Everything is referenced by string id.

**Mutation layer — event-sourced, semantic, guarded.** `Fem2dMutation` (`🧬️mutations/🦀️.rs:30-56`) is a closed 25-variant enum (create/delete/replace triads per noun, `add-load`/`remove-load`, `change-load-case-self-weight`, `update-analysis-settings`), generated by `#[derive(dsl::Mutations)]` delegating diff/inverse/apply to each variant's leaf module. Whole-document `SetSnapshot` is banned (`◻️2d/🦀️.rs:722-724`, `✏️editor/🦀️.rs:876-887`). Guards in `mod guards` (`🧬️mutations/🦀️.rs:124-373`): finite coordinates, Poisson bounds, section positivity, polygon validity, and `delete-*` reference-counting refusal (`referenced()`, `:155-163`).

**Commands vs mutations.** `Fem2dCommand` (`✏️editor/🦀️.rs:42-69`) is a thinner UI-facing set of 18 compound actions that resolve defaults/ids and emit mutations (e.g. `add_node::handle`, `🎮️commands/⚪️add-node/🦀️.rs:32-36` synthesises the next free id via `app_surface::next_id`). `setCamera`/`setResultDisplay` write window-config mutations only. `setActiveExample` builds an out-of-history `Effect::LoadDocument` (`reset_document_effect`, `✏️editor/🦀️.rs:883-887`).

**UI surface.** No panel/widget tree at all — only two `Canvas2dScene` bodies (`layers_json` arrays of `circle`/`line`/`polyline`/`text`/path ops built with `dsl::json!` inline in `🧱️model/🦀️.rs:1021-1072` and `📊️results/🦀️.rs:139-282`). `ArtifactEditor::render` (`✏️editor/🦀️.rs:858-871`) switches on body key between Model and Results. Windows are declared scalar (`.window_kind(...)`, `:908-909`). Dispatch is the hand-written `command_from_action` bridge (`:772-828`).

**View/window state.** `Fem2dModelWindowConfig{ camera }` and `Fem2dResultsWindowConfig{ camera, result_source_id, result_mode, result_mode_index }` (`📊️results/🎚️config/🧬️schema/🦀️.rs:1-11`). No selection, no visibility, no per-entity UI state.

**Selection — does not exist.** `removeSelection` (`🎮️commands/🗂️remove-selection/🦀️.rs:20-35`) takes bare ids and guesses the collection by precedence order (nodes → elements → materials → sections → supports → load cases → regions → combinations). Neither window config nor `Canvas2dScene` (`🧰️framework/🔨️modules/🖱️ui/🎬️scene/🎬️scenes/🦀️.rs:169-192`) carries selection.

**Results visualisation.** `results_window::render` (`📊️results/🦀️.rs:122-128`) dispatches on `ResultDisplay{ source_id, mode: Static|Modal(i)|Buckling(i) }` (`⚙️engine/🖥️app-surface/🦀️.rs:87-111`). `render_static` (`:139-237`) solves synchronously via `fem2d_engine::fem2d_solve_all`, draws faint undeformed structure, a pink deformed polyline scaled by `doc.analysis.deformation_scale` (`fem2d_deformed_shape_layers`, `🧱️model/🦀️.rs:1114-1135`), reaction text labels, beam moment diagrams (`MOMENT_SCALE_2D = 0.001`, `🧱️model/🦀️.rs:36`), and an 8-band von-Mises contour with legend (`clip_by_value`/`von_mises_legend_layers`, `📊️results/🦀️.rs:74-117`). `render_modal`/`render_buckling` normalise the mode shape to unit peak then scale by `MODE_SHAPE_AMPLITUDE_RATIO (0.1)` × `fem2d_model_extent` (doc comment `◻️2d/🦀️.rs:274-278`).

**Live/incremental solve session.** `✏️editor/🧵️session/🦀️.rs` (2550 lines): bounded resumable per-instance job pipeline (mesh → AnalysisModel → assembly → CSR → PCG → `Fem2dVisualJob` page publication), `SESSION_STEP_CEILING_MS = 8`, `SESSION_UNITS_PER_STEP = 65536`, thread-local arena `MOUNTED` (32 sessions). Public surface `prepare_snapshot_read`, `reconcile`, `with_live_visual`, `maintenance_step`/`close_step`/`terminal_is_empty` (`:2296-2543`) plugs into `ArtifactEditor::{mounted_job_*, pending_effects}` (`✏️editor/🦀️.rs:681-695, 846-848`). Publishes a `Fem2dMountedVisualLease` that `render_with_progress` (`🧱️model/🦀️.rs:1158-1161`) rides beside `layers_json`.

## 3. Ad hoc / incomplete

- No selection model; `removeSelection`'s collection-guessing is a workaround.
- No inspector / outliner / catalogue panel. `find` for `📌️panels` under `🏗️fem` returns nothing (neither 2d nor 3d). Properties can be created, never edited in place.
- `addMaterial` hard-codes steel `nu`/`rho`.
- `addCombination.terms` always empty (comment at `✏️editor/🦀️.rs:993-996`).
- `addSupport.fixed` is free text because `ActionArgDef` has no `Vec<enum>` control (`:947-948`).
- Copy-paste template debris: 13/18 command files carry empty `//#region` markers for every other command.
- Debug `eprintln!` in production paths: `🧵️session/🦀️.rs:1020` (`fail()`), `📚️set-active-example/🦀️.rs:35`.
- Uneven tests: only 7/18 command dirs have `🧪️tests/`; `⚪️add-node/🧪️tests` also covers bar/beam/material/section/support/region.
- No animation/timestep/playback concept anywhere.
- Two hand-maintained vocabularies (camelCase action id vs kebab wire keyword) in `app_commands!` (`:43-48`).
- `👥️presence`, `🫧️transient`, `🎬️actions`, `☑️options` folders are all `📌️.empty.md`; the app opts into `NoPresence`/`NoTransient` (`:518-521`).
- Session caps sized to the demo only: `SESSION_MAXIMUM_NODES = 48`, `_ELEMENTS = 24`, `_MESH_POINTS = 80`, `_MESH_TRIANGLES = 40` (`🧵️session/🦀️.rs:27-31`); overflow faults `fem2d.model-fixed-capacity`.

## 4. 3D sibling comparison

Same taxonomy shape; neither has panels. Differences: fem3d's model window calls `world3d_selection_json("rectangle", &[], None)` (`🧊️3d/…/🧱️model/🦀️.rs:28,41`) — `World3dScene` carries a selection field, `Canvas2dScene` does not. 3d has `add-frame` (roll) and `add-solid` (extrusion) instead of `add-beam`/`add-region`. 3d's model window is 50 lines because scene building lives in a shared `fem3d_scene_parts` helper — worth mirroring for fem2d (`fem2d_structure_layers`/`fem2d_deformed_shape_layers`). 3d carries `🧵️session/🧪️tests/📦️numerical-close/{🟦️.ts,🧫️fixtures,🧬️schema}` with no 2d twin. Neither has outliner, inspector, catalogue, animation, or persisted selection.

## 5. Test layout

- Per-node `🧪️tests/🔬️unit/🦀️.rs`, mounted with `#[cfg(test)] #[path = "🧪️tests/🔬️unit/🦀️.rs"] mod tests;` at the bottom of the owner.
- Shared harness `✏️editor/🧪️tests/🔬️unit/🦀️.rs`, `pub(crate) mod context` (`:1-42`): `fem2d_app()` (`VcsArtifactApp<EditorApp<Fem2dPlayApp>>` via `new_app_with_registry`), `dispatch(&mut app, command)` (picks the addressed window via a synthetic `ViewModel`, calls `app.dispatch_typed`, applies `Effect::LoadDocument`), `render(&mut app, body_key)`. Import as `use crate::editor::fem2d::unit_tests::context::{dispatch, fem2d_app, render}`.
- `every_command()` fixture + laws (`:51-72`): unique ids vs manifest (`:78-91`, hard-asserts `ids.len() == 19` — stale vs the 18-row enum), text/binary round trip (`:95-99`), frozen pre-migration bytes (`:108+`). Adding a command requires updating `every_command()` and the count.
- Command tests assert on the snapshot (`add_node_action_emits_op_2d`, `⚪️add-node/🧪️tests/🔬️unit/🦀️.rs:8-13`), `#[semio_framework_async_macros::async_test]`.
- Window render tests assert on the projected fixture tree string or pure helpers (`results_window_renders_contour_for_region`, `📊️results/🧪️tests/🔬️unit/🦀️.rs:32-43`; `live_visual_language_distinguishes_every_progress_state`, `🧱️model/🧪️tests/🔬️unit/🦀️.rs:53-81`).
- Cross-cutting laws as named sibling modules: `🧪️tests/🔬️fem2d-artifact-preparation-laws`, `🧪️tests/🪟️window-config-ownership`, `🧬️mutations/🧪️tests/🔬️kinds-conformance`, `🔬️semio-grammar-conformance`.
- Vector contracts: `🧱️model/🧪️tests/🔬️vector-json-contract/🦀️.rs` + `🧫️fixtures/🔣️vectors.json`.
- Feature-level bridges one level up: `🧬️mutations/🦀️.rs:437-465` (`fem2d_mutation_report_json`), `:578-621` (`fem2d_analysis_report_json`), driven by `🥒️.feature` + `.rs`/`.py` runners under `🪆️subsets/{load,material,mesh,boundary,analysis}/🧪️tests/*`.
