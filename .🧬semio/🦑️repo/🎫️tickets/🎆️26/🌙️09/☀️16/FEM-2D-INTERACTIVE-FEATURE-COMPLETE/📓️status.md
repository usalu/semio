## Definition of done
1. Artifact tree panel: every document entity kind (nodes, bars, beams, regions/mesh, supports, nodal loads, member loads, area loads, self weight, load cases, combinations, materials, sections, analysis settings, results) listed as a nested, paged tree; clicking a row selects it (shared selection with the viewport); rows show human labels.
2. Selection + inspector: the inspector renders the selected entity's editable fields (numbers/selects/toggles/sliders); editing dispatches a real mutation (new `update-*` mutations where missing) with inverse, diff, schema, fixture and unit tests, and the viewport re-renders.
3. Deformation animation: results window animates the deformed shape (phase 0→1 or sinusoidal) with a timestep slider, play/pause, speed, loop, and step buttons; works for static (scaled) and modal (mode shape) displays; driven by a config/view-state that survives refreshes.
4. Everything compiles natively and on wasm32-wasip2; `fem-2d-rs:test` and `fem-plugin:test` stay green; the React lane boots with the new panels rendering non-empty and dispatching, proven by console logs.
