- Implemented field type changes in both languages, retaining common properties while removing incompatible type-specific values. Invalid patches are rejected before emitting mutations; identical patches produce no mutation; bulk selection is deduplicated.

The later visibility run found that the test oracle itself mutated its source; corrected the oracle to clone its input. A final complete run remains due.
- Native testing with a ticket-local Cargo target passed the initial shared target lock but stopped in `semio-framework-os-infinite`: three new presentation types were missing from the existing WGPU public reexports. Added those reexports. The next native run advanced and failed in `semio-s-artifact-stdio-contract` with two type mismatches; an explicit Nx check with tests is gathering full diagnostics. Forms native tests have not yet run successfully.
- Persistence design decision: follow the existing Energy artifact's explicit persisted domain model plus derived stdio children. Forms currently serializes only two handles, has no member roster/genesis provider, and its only question tree is a serialization-skipped local owner. The definition and responses must become authoritative persisted fields; child content becomes deterministic projections. This avoids data loss on standalone snapshot/pack round trips, makes semantic event replay independent of an in-memory cache, and preserves the framework's composed value/table capabilities. Schema and restart fixtures will precede this change. No compatibility decoder or migration script will be retained.
