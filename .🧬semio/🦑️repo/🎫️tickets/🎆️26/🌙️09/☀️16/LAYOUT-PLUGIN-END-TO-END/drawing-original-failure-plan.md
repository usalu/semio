# Lossless Original Work Failure Before Paid Publication

The defining Job source already has OriginalTurnFailure, complete primary/receipt/context fields, OriginalDomainFailure/Projection and paid admit_original_domain_failure. Reuse those for final public erasure. They cannot hold an arbitrary Drawing cause inline before its paid domain frame exists: OriginalTurnPrimary has only Value/Fault/already-admitted Domain/Receiving, while OriginalClosureFailure holds two already-admitted OriginalTurnFailure owners. No new public source-input observation or compatibility failure formatter is needed.

The minimal pre-erasure type is OriginalWorkFailure<E>, an inline owner with private optional original E, actual effects, optional complete receipt ValueError and optional complete context OriginalTurnFailure. Its only constructors require at least one actual cause; there is no empty or dummy failure. Qualification before effects retains a full native context refusal. Folding receives only an optional error; successful owned output remains in the actual producer instead of being discarded when posting refuses. All fields move without allocating or cloning. Existing paid domain admission and borrowed projection remain the only final erasure boundary.

A single first-party Job fold records the actual ledger receipt exactly once and then consumes the actual CPU independently on success and error. It qualifies the real original source context after the body. A simultaneous domain cause, recording refusal and full context refusal all survive. Before-work source qualification also returns the actual complete native cause, rather than a new Drawing literal. Existing full OriginalDomainProjection/paid admission is the final publication boundary; no effect span is posted twice while admitting its frame.

DrawingSceneError will implement the domain projection over its exact literal/Arc payload and Root's typed PathRaster cause, not formatted message copies. Text/Vector/Raster/Paint advance_original and every reached test/caller will move the inline failure to an existing producer slot until paid domain publication is admitted. Existing diagnostic FaultMessageOwner remains for genuine owned application diagnostics, not a lossy replacement for the complete failure tree. Export and Geometry must retain primary and original refusal through blocked publication, actual receiver handoff and paid close.

## Test First

A language-neutral matrix will cover domain-only, receipt-only, context-only, simultaneous domain+receipt+context, success and zero-effect blocked turns. The defining native law uses an actual canonical OriginalJobFixtureCaller, real retained ledger allocation and its measured receipt/CPU. Hostile receiver policy or operation drift is applied only to that genuinely issued test context and restored before returning; it does not manufacture a new Original, issuer, progress receipt or authority. Exact before/after source identities and source payload pointer are checked. The actual failure projection is compared with an independent serde_json reference through a local test interface, including the full cause tree and effects rather than case/count whitelists. Every retained allocation/error/context owner is closed using the same original stock. Tests mount in the actual Job owner; its unfiltered --lib gate is mandatory in addition to Drawing/Flow and the complete original Layout scope.
