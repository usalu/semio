# Current Layout Launch

The previous ticket shell scripts used obsolete dev profiles and raw bun/nx. Current source routes are `repo run @semio-tech/framework-os-dev:activate-layout-react-prototype` and `repo run @semio-tech/framework-os-dev:serve-layout-react-prototype`. Dynamic playground targets are generated by the sealed build graph. Layout composition lives in `🌎️hub/🧩️compositions/📏️layout/📦️packages/🦀️rust`. React port is 6079. Use the exact declared routes after native checks.

Cross-platform ticket driver: `repo tools exec python -- <ticket>/launch-layout.py activate|serve|probe`. It resolves the workspace from its own location and pins the current specific catalog for all child repo operations.

Native CLI validation by the TypeScript worker refused a direct owner script path (`Unknown command`), so use declared `repo run` targets; source router signatures alone are not proof that a native public route is supported.

## Explicit Backend Selection

The driver accepts optional `--tool nx|bazel` and forwards it to each child repo command, including activate, serve and probe. Omitting it leaves backend selection to repository policy. Workspace resolution and the explicit specific catalog remain unchanged.

Cross-platform commands from the repository root:

```text
repo tools exec python -- .🧬semio/🦑️repo/🎫️tickets/🎆️26/🌙️09/☀️16/LAYOUT-PLUGIN-END-TO-END/launch-layout.py activate
repo tools exec python -- .🧬semio/🦑️repo/🎫️tickets/🎆️26/🌙️09/☀️16/LAYOUT-PLUGIN-END-TO-END/launch-layout.py activate --tool bazel
repo tools exec python -- .🧬semio/🦑️repo/🎫️tickets/🎆️26/🌙️09/☀️16/LAYOUT-PLUGIN-END-TO-END/launch-layout.py serve --tool bazel
repo tools exec python -- .🧬semio/🦑️repo/🎫️tickets/🎆️26/🌙️09/☀️16/LAYOUT-PLUGIN-END-TO-END/launch-layout.py probe --tool bazel
```

Use `--tool nx` to explicitly request the Nx backend. Current ticket activation uses Bazel because a foreign process holds the Nx mapping while waiting for a shared lease on that same mapping; see custody-blocker.md. The declared alternative retains normal source authority and admission. Do not stop the foreign owner or alter its leases, images, receipts or intents. Bazel can still wait on shared capacity, graph or compiler resources.
