# Native Shared Receiving Owning Laws

The existing shared receiving, callback refusal, wide-record32, declared defaults, flattened record and empty-record law families retain their inputs, cancellation cuts, loop limits, 4096-byte body, source identity, heap, denial and output assertions. Their obsolete synchronous source/header/result helpers are replaced with canonical pure receiver headers and staged Source admission from one explicit finite per-case wallet, including paid output and close. Actual normal and error CPU is captured from the defining outcome before interpreting its result. No demand creates or replenishes authority.

Before the driver migration, the original shared cases and law names were retained in the neutral data file, with a closed companion schema and explicit 100000-item/CPU, 32-MiB physical-axis, depth64 profile. Ownership transfer is copy0. Positive-axis denials remain; an axis whose actual quote is zero cannot be reduced. No production or original scalar/default behavior changes. Serde remains the independent output oracle. The earlier NativeDefault owning4/docs1 proof covers a separate owner; this affected NativeOwned suite is not yet compiled or passed.
