Current implementation scopes map structurally, but the suite does not directly protect those declared domain boundaries.

It does not exercise cancellation immediately after a successful support check, during async derivation, or after the last suspect before publication. Include pointer/facts absence assertions and exact signal propagation on those boundaries. No genuine issued-control/expired-control/copy refusal is covered by the model host.

Existing store cold-build laws cover persistence on ordinary sizes; a loader/full-bound test can be deferred if the focused helper bound and ordinary loader persistence remain explicitly separate claims.
