# Native Decode Work Loan

The defining neutral fixture and direct owning law were authored before the port implementation. One finite four-unit caller loan admits an actual Vec allocation, a nested retained payload store, a real standard-library UTF-8 refusal, and the known byte-buffer release. Admission reads the same loan and never debits it; the enclosing Original receiver remains the sole debit authority. Missing authority refuses, a zero loan performs no body action, nested replacement refuses, and actual work survives the returned error. Serde independently checks the resulting byte sequence.

The port does not establish that every existing Native/IO/Pack producer has been instrumented. Those defining call sites must preflight and commit their actual effects and forward the same outcome work. Physical grant items, byte receipts, semantic counters, and callback entry are not CPU authority. Standalone cold APIs are outside this work-loan proof until explicitly migrated.

This law is authored and unexecuted. The lower NativeDecode mount is held for the concurrent Job Payload diagnostic; no held lower body has changed.
