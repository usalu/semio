# Staged CloneSource implementation

The real empty SharedOriginalBirth allocation and Sealed publication permit are authored. Empty backing can be released only by its exact paid close. Materialization is no longer an infallible allocator; a current item/depth grant creates a unique publication permit and commit writes the already-paid payload, returning actual work one and copied bytes zero.

RetainedCloneSourceAdmission is mounted in the defining source owner. It retains the original, extra authority, shared owner, alias, typed payload Box, empty lease backing and completed output. Every real null branch returns AllocationFailed/work1 with unchanged partial state. Allocation denial returns zero progress/work and no heap. Cancellation returns each alias while the genuine parent witnesses it, then separately empties the typed headers/releases actual backing, unwraps A and transfers A/B into a caller-owned place. Completed output also moves to a caller-owned place in a separate paid turn. Live Drop refuses rather than silently destroying owned state.

The old synchronous Source admit_owned/admit_borrowed and BorrowAuthority.admit constructors are removed. Current public entries are admission_owned/admission_borrowed, RetainedCloneSourceAdmission::new/advance/next_demand/take_output/return_inputs, and BorrowAuthority.admission. Their direct runtime consumers and historical owning tests still require hand migration. Existing aggregate byte-size observers are retained as size observers, not a grant or completion adapter.

Eight source/schema/test inputs are sealed in drawing-clone-source-admission-working-files.json. No runtime has been launched. This is an authored production slice, not SourceReady, compiler success, test success or full caller closure.
