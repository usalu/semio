# Canonical Wire Actual CPU Source

Root released the canonical typed encoder CPU slice. Defining wire CPU schema/data and direct real-heap law were authored before production. The law discriminates each positive grant-axis denial, selected allocator/header/probe work, genuine immutable child fault, explicit close and cached terminal. Existing independent serde_json output law remains unchanged.

ArtifactCanonicalJsonTreeCursor and ArtifactCanonicalJsonTreeWireCursor now expose last_turn_work. Each call resets the count; denied and terminal calls remain zero. The native traversal commits work only after its actual selected event is admitted and before the bounded node/child/scalar/control operation, including a genuine selected error. Empty output blocking clears the count before any source operation. The wire delegates lower tree actual CPU before propagating errors; independent typed-source/alias/header/allocator/close steps report their real bounded work. No copied-item receipt is used as CPU.

FlowAction2599 encoding advance now consumes the actual defining getter and records that same CPU on encoding failure, preserving its other body and receipt ordering. Flow2605 will use the same contract.
