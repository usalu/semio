# Original Typing Fold Contract

The native policy explicitly selects Split, ReplaceIncoming (moves the actual incoming Vec), or an original producer. The default remains the real current Split behavior. Writer is the sole custom algebra and requires a bounded native producer for TextSplice composition and whole-text replacement. No cold callback may be called from the retained inlet.

The actual previous and incoming nets are immutable borrowed slices with source/decoder/parent and pair identity retained by the provider. Its result is a retained pure OriginalTypingFold, and its partial owners close before the pure writer may consume or mutate those inputs. The SDK pays the concrete producer shell separately from its internal physical retirement.

The defining declaration is authored but not mounted, forwarding and manifests are pending, and native validation is not claimed. This preserves the current IDML snapshot barrier.

For atomic delivery the canonical typing state will store an ordered Vec of net mutations. Existing keys are positional only. Final ledger exchange and actual Emit reception can then transfer the prior net and transaction as headers in one funded callback; no post-publication per-leaf conversion or reversible compatibility protocol is required. Source owns the defining representation and all original read/transfer users, Medium owns SDK consumers. All existing fixtures and implementations must be updated directly, without migration files.
