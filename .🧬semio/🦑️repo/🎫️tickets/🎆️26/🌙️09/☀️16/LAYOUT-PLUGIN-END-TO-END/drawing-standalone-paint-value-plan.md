# Standalone Paint Value Guard

Six closed language-neutral cases and one actual public-API law are authored before body: fill/stroke null and missing refuse with canonical typed position; valid solid/stroke retain the same nonnull object parser. Independent Ajv canonical FillStyle/StrokeStyle schemas reject null/missing. Nullable attributes remain explicit null and are checked separately.

The minimal defining correction after current156 release is a checked local return from ownedAttributes in each standalone helper: reject a null/undefined decoded result through the existing typed guard at the supplied position, otherwise return the narrowed value. This removes existing nonnull assertions without changing any nonnull parsing algorithm or attribute semantics. New law is disjoint from held156; no runtime/body edit yet. The existing present-API hole is a return of null/undefined from a nonnullable signature, not a new optional compatibility path.
