# Staged CloneSource admission

The Read owning null law aborted in the actual standard allocator before returning a refusal. Existing CloneSource admission performs two phantom Sealed birth qualifications, then infallible owner Arc, payload Box and lease Arc allocations. Its alias work assignment also replaces earlier work. This is a defining allocation/custody defect.

The canonical replacement is RetainedCloneSourceAdmission<T,A,B>. Its allocation-free constructor retains A, B and a higher-ranked projection function. advance(grant) returns RetainedWorkOutcome<RetainedCloneStep>; every call selects at most one actual owner birth, alias, payload Box birth, lease backing birth or final publication. Each stage retains its full output before returning the outcome. next_demand quotes that selected stage. Owned output remains in the admission until a separately funded take_output(caller_slot,grant). No synchronous runtime loop or old constructor alias remains.

Owner uses the existing fallible SealedShared::admit. Alias uses true try_duplicate. The typed SourcePayload Box is allocated with exact Layout and null handling before moving its alias/B into it. The lease is a real paid, uninitialized SharedOriginalBirth allocation, built by the existing first-party fallible shared allocator using Allocation<T> with MaybeUninit payload. It has explicit funded release while empty. Sealed birth publication checks item/depth before any typed input is erased, then initializes its unique already-paid backing without allocation. Source final publication moves the typed Box into its erased lease only after this admission, preserving every input on denial/null.

Cancellation is explicit retained return, not destruction: return the typed alias while the genuine owner witnesses it, move B back from the untouched Controlled owner, release the empty typed payload backing, release empty lease backing, unwrap the unique original owner into A, then transfer A/B into caller-owned output. Each control or backing release has its own actual work and receipt. An unsupported natural A retirement is therefore not fabricated; the caller recovers the actual read and closes it through its own real issuer. A live admission cannot implicitly drop its retained inputs/backing.
