## Natural Ownership Constraints

The tree contains intrinsic values/schema/diff/mutations and representation/admission domains. Splitting a genuine owner can reduce the normal root closure; deleting schema assets or raising limits would not correct ownership. Admission currently imports root IdmlSnapshot, PACKAGE_MIME and MAX_PACKAGE_BYTES; retained-part also imports schema::diff::IdmlPartPatch. Therefore extracting an admission crate that simply depends on the still-monolithic IDML root would create a cycle. A coherent split must place foundational model/part/diff identities below admission or otherwise preserve trait/type ownership without a back-edge. Root package also implements ToValue/FromValue for IdmlPackage and IO protocol traits for snapshot/mutations, so orphan-rule placement matters. Medium received these exact couplings before implementation. No production partition was performed by this reviewer.
