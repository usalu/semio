Validate loan liveness before any mutation. Forward that exact loan to the private Buffer admission operation. At the actual array-body birth or directory-reference publication, commitActualWork before any fallible post-effect receipt fold. Denied/cached/hold-only paths commit zero. The witness creates no byte stock, source binding or Original claim.

A byte hold stays bound to the same original ledger/grant, owner, logical length and storage epoch. It is not bound to a temporary accounting loan: a pending child can resume the same hold under a fresh genuine child loan within the same original ledger. Validate the current live loan at every actual mutator, including push/write/pop/vecPush, with mandatory explicit arguments. Revalidate current nesting and original unspent copy authority; an existing hold must not bypass a deeper resumed mutator demand. No old loan is relabeled and no stock is renewed. The actual page fixture already creates a real loan for every callback. Pass it into admission methods; explicitly commit row-store CPU at its actual defining operation and remove the physical-epoch fallback. Add closed schema/cases and actual laws before implementation for denied/cached zero, paid body birth/reference publication, expired loan before effects, genuine same-ledger hold resumption under a fresh live accounting loan, refused deeper resume without lost hold, and paid admission followed by a refusing receipt fold retaining the actual CPU.
