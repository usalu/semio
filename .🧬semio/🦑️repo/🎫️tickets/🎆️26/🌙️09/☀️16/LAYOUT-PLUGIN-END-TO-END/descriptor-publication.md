## Public Surface

Completed replay is idempotent. Copied or foreign tokens, unknown entries and drift refuse.

`attestFilePublication(name,actualEntry,maximumBytes)` observes the same private entry through held reads and post-close facts. Its immutable receipt contains actual parent/entry identity, SHA256 and Windows facts. It grants no deletion authority; a genuine fresh domain role must bind the identical actual entry and retain current authority through removal.

`appendFile(name,actualEntry,bytes,maximumBytes)` accepts exactly four arguments. It captures intrinsic bytes without calling user getters, verifies the same current private entry and rooted parent, consumes that entry proof, and writes at exactly the original size. Shared bounded backend writers serve stage creation and append. It checks total size, readback hash, file and parent flush, complete held facts and post-close named facts. It returns the current immutable attestation. No truncation, arbitrary offset or writable callback is exposed. A cancelled or refused partial write remains a real prefix for explicit domain current-metadata recovery; no rollback is claimed.

The closed prepared DATA codec preserves seven portable identity fields as canonical decimal strings, exact names/roster/hashes and complete Windows supplemental facts. Windows volume serial is canonical uint64 decimal, file ID is 32 lowercase hexadecimal digits, attributes are uint32, and full security/streams digests are 64 lowercase hexadecimal digits. Actual Windows facts require a single unnamed data stream and reject ADS. Historical parent qualification uses stable device/inode/mode plus Windows supplemental facts; the new private recovery token pins all exact current fields, including current link count and timestamps. Matching names or hashes alone never establish historical ownership.
