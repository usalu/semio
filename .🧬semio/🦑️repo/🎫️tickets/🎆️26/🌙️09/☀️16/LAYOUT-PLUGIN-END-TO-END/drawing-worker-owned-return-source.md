The actual preadmitted OriginalWorkerPageReservation now retains a returned OriginalJobOutcome or OriginalJobContinuation before any fallible receiver operation. Its source binding and existing pre-body return claim qualify those slots; no allocation, new Source, grant or late cause clone was introduced. Capture/receive work remains the existing one-shot held witness work, not a default callback charge.

NativeWorkerAuthorityState drives through that owning place. A later turn first retries receiving the same exact arm and does not invoke the producer again. Paid cancellation/close also settles an outstanding arm into the same origin before closing fault backing, continuation resources, original loan and local controls. Denied or foreign reception returns its full existing failure while the original arm remains in the place.

They use both actual return arms, a genuine pre-body claim, same-operation/generation foreign Source denial with zero CPU/heap, unchanged retained cause, same-Source receive and cancelled paid close.
