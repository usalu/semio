# Bounded Native Tree Source

Defining recursive bulk kind probes/measurement/read APIs and their consuming Result receiver have been replaced by mandatory pure tree_kind and actual NativeTreeReceiver/NativeTreeValue. No obsolete Bulk aliases remain. The receiver retains65 inline frame headers for unchanged depth64; each bounded turn performs one original accessor/probe, actual output-slot backing admission, <=64-byte text fragment, new row store, completed child transfer, final publication or real paid retirement. Existing scalar booleans/numbers are quoted as actual payload copies; fixed ownership and pointer/header moves are0copy. Real control outcomes are forwarded before Result, including allocation/null/refusal.

Graph PropertyValue uses the same defining cursor with bounded in-place heapsort and <=64-byte lexical comparisons, preserving sorted unique object semantics and exact duplicate/depth messages. PropertyBag validates actual original root shape and moves the typed object output; no recursive Graph read, unbounded native sort or newly minted grant remains in this path. Its existing NativeDefault provider still awaits the separate canonical staged-default migration.

All actual NativeValueSource implementations in the recorded bounded source roster now provide the pure mandatory predicate. Unsupported Dsl bytes and unsupported text-record cases remain unsupported; real accessors keep their own missing/ordinal diagnostics. New native three laws and concrete Graph law are schema/independent-Serde/BTreeMap/heap/finite-bank first-party tests, authored and unexecuted. Graph adds existing first-party allocator dev dependency only, no runtime library.

This is NOT SourceReady or compiler acceptance. NativeDefault, derive/enum, old owning APIs/test wallets and real controlled Ordered caller migration remain required. Root owns all actual Cargo gates. Exact current files/hashes are in drawing-native-tree-source-working-files.json; native original/cancel/default/Graph owning gates remain mandatory.
