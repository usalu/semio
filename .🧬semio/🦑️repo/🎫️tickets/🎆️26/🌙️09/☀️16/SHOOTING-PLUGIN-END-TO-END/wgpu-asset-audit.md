The production browser WGPU world GLB path stores a sticky surface miss after a transport rejection. In `🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🎯️targets/🧊️wgpu/🧊️renderer/📮️mailbox-impl/📥️renderer-asset-steps/🦀️.rs:83`, an uncancelled world rejection marks the URL missed. `♾️infinite/🌍️world/🧱️scene/📡️asset-io/🦀️.rs:566` inserts it into `asset_url_misses`, and `♾️infinite/🌍️world/🧱️scene/🥽️brush-lod-and-style/🦀️.rs:831` excludes it on subsequent frames. If the server recovers after a transient failure, the unchanged mesh remains absent for that surface. The same ledger also covers reference images.

The WGPU SVG icon preview has an independent sticky failure. In `📺️renderer/🧑‍🎨engine/🧱️elements/🎞️Scenes/🎯️targets/🧊️wgpu/🖼️icon-render/🖼️svg-pane/🦀️.rs:177`, a GLB request or loading error leads to `Work::Failed`; the unchanged host, JSON and URL are returned as `Paint::Failed` at line 89 without a new request. A recovered server therefore does not repair that preview until its request changes or the pane is reset. This also affects a temporary reservation failure.

Icon export GLB requests themselves are independently owned by token: `📺️renderer/🧑‍🎨engine/🧱️elements/🖼️IconRenderHost/🎯️targets/🧊️wgpu/📤️export/📥️asset/🦀️.rs:25` reserves a request per owner, and cancellation at line 53 identifies that exact token. The existing `🖼️IconRenderHost/🧪️tests/📤️asset-delivery/🦀️.rs:38` checks that dropping one request does not cancel a sibling. This source inspection found no cross-shot cancellation defect in that individual request path; no browser execution was performed.
