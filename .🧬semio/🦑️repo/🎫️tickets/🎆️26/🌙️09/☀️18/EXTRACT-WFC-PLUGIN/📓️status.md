## Brief (from the dev)
Extract wave function collapse (WFC) from the 🌀️procedural plugin (its `🧩️assembly` artifact carries the 10 kLOC engine under `🧬️schema/💡️inferences/🧩️wfc-engine`) into its own plugin with five artifacts:
1. **bitmap** — the classic overlapping model: an input bitmap and an output bitmap that looks locally similar.
2. **2d-grid** — regular rectangular grid, fixed left/right/top/bottom neighbours, tiles are vector graphics or bitmaps; two windows: grid canvas with cells + 2d preview.
3. **2d** — arbitrary neighbours, arbitrary non-rectangular shape, rectangular tiles (vector/bitmap); two windows: graph with slots + 2d preview.
4. **3d-grid** — regular non-uniform box grid, six fixed neighbours, mesh tiles; two windows: grid box with cells + 3d preview.
5. **3d** — arbitrary neighbours, arbitrary non-boxed shape, mesh tiles; two windows: the same graph-with-slots window as 2d + 3d preview.
