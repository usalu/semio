## 3. Document models (schema-first; the JSON Schema leaf is normative, GraphQL/Proto/TS/Rust mirror it)
Shared vocabulary (define locally per artifact, same names/shapes; no cross-artifact crate imports):
- `Color { r: Int, g: Int, b: Int, a: Int }` (0–255).
- `TileMedia2d` = one of `Bitmap { width: Int, height: Int, palette: [Color], pixels: String(base64 palette indices, row-major) }` | `Vector { paths: [VectorPath { segments: [PathSegment (M/L/Q/C/Z with Float coordinates in 0..1 tile space)], fill: Color?, stroke: Color?, strokeWidth: Float }] }` | `Image { child: ArtifactChildHandle }` (dialect `s.stdio.semio@v1/image`, raster precedent). Tile size is the cell size; media is drawn scaled into the cell.
- `TileMedia3d` = one of `Mesh { positions: [Float] (xyz triples), indices: [Int], color: Color? }` (inline, tile-space 0..1 box) | `MeshChild { child: ArtifactChildHandle }` (dialect `s.stdio.semio@v1/mesh`, remodel precedent).
- `Tile { id: String, label: String?, weight: Float, media: TileMedia2d|3d }`.
- Every artifact: `schema: String` (= dialect kind), `seed: Int (u64)`.

**bitmap** `BitmapSnapshot { schema, seed, input: Bitmap { width, height, palette, pixels }, output: OutputSpec { width, height, periodic: Boolean }, model: OverlappingModel { patternSize: Int (N, 2..5), symmetry: Int (1..8, D4 subgroup size), periodicInput: Boolean, ground: Int? (palette index forced on the bottom row) }, pinned: [PinnedPixel { x, y, color: Int }] }`. Mutations: `change-seed`, `resize-input`, `set-input-pixels { x, y, width, height, pixels(base64) }` (bulk region write, coalesced per stroke), `add-palette-color`, `change-palette-color`, `remove-palette-color` (fatal if used), `resize-output`, `change-model`, `pin-pixel`, `unpin-pixel`. Inference `s.wfc.bitmap.solve`: overlapping model via `extract_2d` (+ symmetry) over a `Grid2dTopology` (`Stencil2d` 4-neighbour, periodic per `output.periodic`), commit = output `pixels(base64)` + contradiction verdict + entropy map. Editor windows: `wfc-bitmap-input` (interactive: click/drag paints the active palette colour; palette + active colour in a panel/window config) and `wfc-bitmap-output` (read-only render of the inferred output). Layout `row` 50/50. Pixel payloads ride a paged lane, never inline in the 32 KiB spine (see patterns report §2.4).

**grid2d** `Grid2dSnapshot { schema, seed, width: Int, height: Int, cellWidth: Float, cellHeight: Float, periodicX: Boolean, periodicY: Boolean, tiles: [Tile(TileMedia2d)], rules: [AdjacencyRule2d { id, tileAId, tileBId, direction: LEFT|RIGHT|TOP|BOTTOM (B lies in `direction` of A), allowed: Boolean }], pinned: [PinnedCell2d { x, y, tileId }], masked: [Cell2d { x, y }] }`. Inference `s.wfc.grid2d.solve`: `TiledModelBuilder` + `declare_stencil_relations_tiled(Stencil2d four-neighbour)` + `Grid2dTopology` (mask = masked cells, boundaries from periodicity) + `Grid2dSolverBuilder` fixes for pins; commit = `assignments: [[x, y, tileId]]`. Layout `row` 50/50.

**wfc2d** `Wfc2dSnapshot { schema, seed, slots: [Slot2d { id, x: Float, y: Float, width: Float, height: Float, pinnedTileId: String? }], edges: [SlotEdge { id, fromSlotId, toSlotId, relation: String }], tiles: [Tile(TileMedia2d)], rules: [GraphRule { id, tileAId, tileBId, relation: String?
