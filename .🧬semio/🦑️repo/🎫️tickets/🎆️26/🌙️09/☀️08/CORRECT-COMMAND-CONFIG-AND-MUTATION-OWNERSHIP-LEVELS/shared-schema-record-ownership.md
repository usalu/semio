# Shared Schema Record Ownership

Generic allowed-field validation belongs to the framework schema module. Map feature/document/delta and Terrain document/delta will consume one first-party boundary. The neutral vectors compare object shape with Ajv; additional JavaScript cases reject getters, inherited fields, symbols and hidden fields without reading them. Test-first import is deliberately absent before implementation.

Both GIS consumers passed their registered Nx oracle and strict TypeScript checks after extraction. The Map route runs the shared record oracle: eleven Ajv vectors plus six direct JavaScript object-ownership cases. The first shared run exposed an incorrect test-relative import; that import was corrected before the successful run. No runtime dependency was added.
