## Findings

### P1 — Actual backing can cross the signed-addressable total after the preflight succeeds

`PagedList::reserve_page_using` checks only the requested allocation against the cumulative `isize::MAX` limit before allocating at [🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🦀️.rs:263)-[🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🦀️.rs:267). It then records the allocator's actual metadata or payload capacity at [🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🦀️.rs:273)-[🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🦀️.rs:291) with `checked_add(...).expect(...)`, which detects only `usize` overflow. It does not reapply the signed-addressable total limit to the actual allocation.

This is not hypothetical within the owner model: the owner’s test seam deliberately uses an allocator that reserves twice the requested slots at [🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🧪️tests/🔬️counter/🦀️.rs:17)-[🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🧪️tests/🔬️counter/🦀️.rs:21), and the law confirms that the actual capacity differs from the request at [🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🧪️tests/🔬️counter/🦀️.rs:25)-[🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🧪️tests/🔬️counter/🦀️.rs:45). Near the signed limit, a successful requested-byte preflight can therefore leave `allocated_bytes()` above `isize::MAX`. That invalidates the claimed cumulative physical-ownership bound for `PagedList<_, usize::MAX>`.

Preserve the required retained-backing error behavior, but make the post-allocation accounting path reject an actual total over `isize::MAX` explicitly and test both metadata and payload paths with the counter seeded just below that limit. The failure result must report the exact actual allocation and leave it releasable under its exact release grant.

### P2 — Merge refusal consumes the candidate and advances its cursor before placement succeeds

The new paged merge removes `merge_candidate` at [🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2228), advances the source cursor, then calls `push_reserved` at [🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2231)-[🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2237). If the destination reservation is refused, the exact `AssemblyTriplet` returned by `push_reserved` is discarded and the source cursor already points past it. The generic owner correctly returns the unplaced producer at [🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🦀️.rs:300)-[🦀️.rs](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/📋️list/🦀️.rs:307); this consumer defeats that guarantee on its new refusal path.

The pre-admitted construction normally makes refusal unreachable, so ordinary assembly does not currently expose it. It is still a fault/cancellation correctness hole: the interactive job turns that error into `StepOutcome::Fault` at [🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2580)-[🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2592) after mutating the checkpoint state. Move the cursor increment after a successful placement and restore the candidate on `Err(entry)`. Add a focused refusal law that exhausts the merged owner, checks both cursor and candidate are unchanged, then closes under a 4 KiB grant.

## Separate Existing Sparse Boundary

The final `Csr` representation still takes contiguous `indices`, `values`, and `indptr` vectors at [🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2414)-[🦀️.rs](/Users/ueli/Documents/semio/✏️s/🔨️modules/🏗️fem/⚙️engine/🧮️analyses/🦀️.rs:2456). The added unique-key pass avoids reserving duplicate-rich triplet counts for those outputs; it does not page the public CSR representation. This is the recorded, pre-existing downstream sparse-owner limitation, not a regression introduced by the paged triplet conversion.
