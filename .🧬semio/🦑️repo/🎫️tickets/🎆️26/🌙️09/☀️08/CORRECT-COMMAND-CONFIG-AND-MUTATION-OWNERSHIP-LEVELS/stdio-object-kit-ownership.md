# Stdio Object and Kit Ownership

Active source task after the shared inspector and Terrain identity milestones. Read-only inspection found canonical child dialects (`s.stdio.semio` plus v1/subset) conflicting with native Object/Kit slot metadata that appends the subset to artifact kind. Committed fixtures also contain unequal childId/target.artifactId. Object's TypeScript facet duplicates framework ArtifactRef/ArtifactChild shapes and returns unchecked object records for typed fields; Kit repeats those shared interfaces. Both families construct child handles in create mutations without validating identity/dialect.

Plan: schema-first exact parent/child boundaries, framework type/parser reuse, concise domain validation, canonical kind metadata and explicit constructor checks, corrected committed fixtures and native literals, independent Ajv and real nested typed-projection tests. Keep parent codecs handle-only and preserve payload ownership; complete archives/replacement remain the SDK agent's integration task. No Stdio source edits have been made at this point.

Existing private initial-child identity primitive discovered at framework Store composition/initial/identity hashes space+document+parent/child dialect+slot+ordinal with the framework hasher; it is separate concurrent work and has not been modified. New-document allocation should integrate that mechanism rather than content-hashing parent edits.
