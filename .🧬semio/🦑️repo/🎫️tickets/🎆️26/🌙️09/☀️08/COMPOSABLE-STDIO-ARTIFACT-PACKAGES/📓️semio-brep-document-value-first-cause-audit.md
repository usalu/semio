# Remaining Semio BREP, Document, and Value First-Cause Audit

## Scope and evidence

Read-only review of the completed representative Semio native receipt: [`stdio-representative-native-after-disk.txt`](🗑️generated/stdio-representative-native-after-disk.txt). It compiled the standalone Semio package and ran 2,503 tests: 2,306 passed, 196 failed, one ignored. The examined groups account for 43 failed test invocations: BREP 39, Document 2, Value 2.

The receipt contains no crate-resolution, missing-path, package-route, or process-launch diagnostic before these failures. These are executable test failures after the Semio artifact compiled, so an extraction cause is not supported. The first package-boundary defects are the BREP tolerance wire contract and Value diff composition below. Geometry failures are retained separately.
