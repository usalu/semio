# Navbar example picker audit (2026-09-17)

## Symptom

`ShellHost` only renders `NavbarExampleSelect` when `examplesForApp(manifest.examples, session.app)` is non-empty. That predicate matches examples by **dialect**, not legacy `appId`.

## Root cause

Many checked-in `🔣️.json` descriptors still list examples as `{ appId, … }` without `dialect`, so the picker resolves zero rows at runtime even though Rust registration (or `SubsetDeclaration.examples`) is correct.

Plugins on the old `.editor(def)` channel without `.editor_with_examples` also emit **zero** examples into the manifest until describe is re-run.

## Fix strategy

1. `normalizeManifestExamples` at descriptor load (`fetchDescriptorManifest`) — stamp `dialect` from legacy `appId`.
2. Re-describe / refresh `🔣️.json` for plugins whose WASM already registers examples.
3. `.editor_with_examples` for old-channel plugins that have `📚️examples/🎬️demo` facets but empty manifest examples.
