# Chrome motion and tutorial parity (opus55 fix, items 4 and 5)

Nothing was compiled or run (build freeze). All code was written against the surrounding sources; the integration agent runs the list at the end.

Path shorthand: `UI` = `🧰️framework/🔨️modules/🖱️ui/`, `E` = `🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/`, `S` = `E/🧱️elements/🐚️Shell/🎯️targets/🧊️wgpu/📥️staging/`, `W` = `E/🎯️targets/🧊️wgpu/`, `D` = `UI/🎯️targets/🧊️wgpu/🖍️draw/🏷️types/`.

## A. Chrome motion

Tokens (shared JSON `UI/🎨️styling/🔣️.json`, `metrics.chrome`, regenerated by hand into `🤖️generated/🔤️tokens/🟦️.ts` (both copies), `🔤️tokens/🐍️.py`, `🔤️tokens/🦀️.rs`): `loadingBorderDurationSeconds` 1.6, `waitingBorderDurationSeconds` 3.2, `introducedBorderDurationSeconds` 1.6 (celebrate 1.2 already existed), `transitionDurationMs` 150 and `transitionEasing` [0.4,0,0.2,1] (Tailwind `transition-[color,background-color]`), `dialogEnterDurationMs` 200, `dialogEnterEasing` [0.25,0.1,0.25,1], `dialogEnterScaleFrom` 0.95 (`animate-in fade-in-0 zoom-in-95 duration-200`). `Theme` gained `transition_duration_seconds`, `transition_easing`, `dialog_enter_seconds`, `dialog_enter_easing`, `dialog_enter_scale_from` (`UI/🎨️styling/🎭️theme/🧩️component/🦀️.rs`).

Engine (draw contract, `D`): new `🎞️chrome-motion/🦀️.rs` (CSS cubic-bezier solver, keyed `Transitions` registry, `chrome_transition`, `chrome_enter`, `introduced_pulse_opacity`), `DrawList::{set_reduced_motion, reduced_motion, note_motion_pending, motion_pending}`. Reduced motion: every animated border (`Loading`, `Waiting`, `Introduced`, direct `push_*_border`) paints the static `finished_border` kind, which is React's `animation: none; opacity: 1` and also lets the prepared packet stop requesting continuous frames. `Celebrated` no longer maps to the introduced pulse (React has none) but to the static ring whose colour cycles with the clock. `UI/🎯️targets/🧊️wgpu/🎟️prepared/🏁️job-completion-and-interactive-job/🦀️.rs` ORs `motion_pending` into `has_animated_primitives`, so CPU-clock fades keep frames coming.

Wiring:
- Host `prefers_reduced_motion` is stamped onto `draw` and `overlay` at the start of `render_chrome_step` (`S/🪀️view-panels/🖼️chrome-frame-and-main-window`) and copied into the retained candidate in `UI/🎯️targets/🧊️wgpu/⚙️engine/🖥️frame-into-step-and-frame`. Celebrate paints its first colour when reduced.
- Hover fade: `chrome_hover_amount`, `chrome_item_bg_at`, `chrome_item_text_at`, `mix_rgba` (`UI/🎯️targets/🧊️wgpu/🖥️chrome/🦀️.rs`) used by both chrome group item painters (`S/🍱️view-chrome/🧱️chrome-paint-and-navbar`). Premultiplied blend, first sight snaps, an interrupted fade restarts from the reached value. Clock: `chrome_motion_seconds()` (shell-async, one second after first read so 0 stays the unstamped sentinel).
- Dialog overlay enter: scrim and modal glass alpha and blur, fills and text alpha scale by the eased 200 ms progress; forgotten when the stack empties (`S/🗨️view-overlays/💬️chrome-dialog-and-tooltips`).
- Border pulse: the shader (WGSL contract, WGSL draw copy, HLSL, MSL) pulsed kind 9 from 0 to 1; React's `introduced-border-pulse` is opacity 1 -> 0.7 -> 1, now `0.85 + 0.15 * cos`. Loading (0.55..1) and waiting (0.7..1) already matched. The cfg(test) `introduced_pulse_thickness` and `INTRODUCED_PULSE_PERIOD_MS` were deleted (the shader paints the pulse in production); tests now use `introduced_pulse_opacity`.

Known limits (deliberate): dialog close fade and zoom 95 -> 100 are not painted (close needs a retained ghost of the last dialog frame; zoom needs glyph rescaling). React has no panel open/close transition, nothing to match. Scrollbar thumb fade, svg fill 120 ms and the intro ripple are not chrome controls in wgpu. Border dashes under reduced motion are solid (React keeps the dash array). Hover fade interpolates linear-light premultiplied RGBA, CSS uses sRGB. The shader durations stay literals; a law ties them to the fixture. Assumes the continuous redraw the prepared packet already requests for animated primitives; verify visually.

Laws and fixtures:
- `UI/🎨️styling/🧪️tests/🧫️fixtures/🎞️chrome-motion/🔣️.json` (curves sampled by an independent Python bisection solver, transition scenarios, enter vectors, pulse vectors, token values).
- `D/🎞️chrome-motion-tests/🦀️.rs`: bezier, transitions, enter, pulse, tokens equal fixture, reduced motion border kinds, celebrate is static.
- `UI/🖌️render/🧪️tests/🔬️shader-contract-unit/🦀️.rs`: phase clocks 1.6/3.2/1.6 and the pulse formula equal the fixture.
- `UI/🧪️tests/🎞️hover-motion/🦀️.rs` (mounted in `🖥️chrome`): hover fade, reduced snap, blend ends exact.
- `UI/🧪️tests/🔬️targets-wgpu-paint-unit/🦴️skeleton-celebrate-and-chrome-paint-laws`: updated (celebrate is the static kind).
- `S/../🧪️tests/🔬️wgpu-chrome-overlays-tour`: pulse tests replaced, motion clock law.

## B. Tutorial

Implemented in wgpu (`S/🖍️view-paint/🎓️tutorial-runtime`, `S/🍱️view-chrome/🧭️navbar-footer-and-overlays`, `S/🗨️view-overlays/💬️chrome-dialog-and-tooltips`, `S/🪀️view-panels/...`):
- Runtime state `muted` (default false) and `captions_on` (default true), as React's store.
- Bar: mute (`shell.tutorial.mute`) and captions (`shell.tutorial.captions`) toggles with icon and label, pressed state exposed, EN/DE strings `tutorial.mute` ("Mute"/"Ton aus"), `tutorial.captions` ("Captions"/"Untertitel") in `W/📖️shell-vocab`. Chapter ticks on the scrub track (`size-1` dots at `atMs/durationMs`, 50% ink, full on hover, 12 px hit target, named by the chapter title, click seeks and wins over the scrub drag).
- Captions: new phase `TutorialCaptions`, bottom-centre dialog glass box, `bottom-double`, `p-double`, width min(672, viewport/2), text-sm, covering narration cue resolved in the active terminology and locale, hidden when off or uncovered. Limit: multi-line text is left aligned (React centres).
- Ghost pointer: replaced the 18 px ring with the Semio cursor glyph (`UI/../🖼️assets/👆️cursor`), contain-fitted into a `size-double` square, opacity 0.9, light/dark asset per theme, default glyph per gesture kind, drag linear, orbit along React's arc, click-family and scroll static. Glyph geometry: `🖼️assets/👆️cursor/👻️ghost-glyphs/🔣️.json` (source of truth, extracted from the SVGs by `🧰️opus55-chrome-motion-tutorial/ghost_glyphs.py`) -> `S/🖍️view-paint/👻️tutorial-ghost-glyphs/🦀️.rs` (generated by `ghost_glyphs_rs.py`). The old `render_tutorial_gesture_overlay_node` moved from window-actions to view-paint; the view-panels import was updated.
- Video: pure resolver `tutorial_video_overlay` (viewport-pixel rect, URL/data source, mute = global or cue, transport, rate, local time, 300 ms resync rule) and the browser host `E/🎬️media/🌐️browser/🎞️tutorial-video/🟦️.ts` (`createBrowserTutorialVideoOverlay`, same overlay root conventions as the media-slot host: absolute, `pointer-events:none`, muted playsInline, object-fit cover, rounded). NOT transported: the existing media-slot path only carries plugin-document `ExternalSlot` nodes with resource authority and is step/retirement governed; injecting a synthetic slot, or a new frame output field, through `AppPresentStep::Complete` -> `BrowserMediaOutput` -> `PresentedMediaSlot` could not be done safely without compiling. Wiring point: append the resolver's plan to the frame result next to `media_slots` (`W/🧊️renderer/🖥️frame-presentation/🎬️present-step-inner` line ~473, `W/🚚️browser-frame-transport/📋️contract`) and call `accept(plan)` from `W/🌐️browser-host/🟦️.ts` beside `createBrowserMediaOverlay`.
- Native limit, precisely: there is no video decoder in the native wgpu host, so a tutorial video cue paints nothing natively (React also paints nothing when `src` is missing); blob sources need the studio blob store, which the shell chrome cannot reach, so the resolver returns none for them; narration audio and TTS are not played by either host path here.
- Not done: record button, add-chapter button and recording indicator of the React bar (recording itself exists, bar shows `REC mm:ss`).

Tests: `S/../🧪️tests/🔬️wgpu-tutorial-presentation/🦀️.rs` (mounted in `W/🌴️shell-tests-chrome-4`) over `S/../🧪️tests/🧫️fixtures/🎬️tutorial-presentation/🔣️.json` and the glyph fixture; `E/🧪️tests/🎞️wgpu-tutorial-video/🟦️.ts` (vitest, same fixture). Existing `🔬️wgpu-tutorial` test literals gained the two fields.
