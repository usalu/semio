# Overlay, Extension, scrollbar, splitter, placeholder parity fixes

Status: code written; see Verification status below.

## Audit verification
- Extension: audit was wrong. `Component::Extension` reconciles to `UiNode::ExternalSlot`, which already has a painter. The real gap was look: panel fill plus raw body key instead of React's muted `Extension unavailable: <id>` line.
- Overlay shadow: React's `--shadow-lg` is `0 0 transparent`, so no shadow is correct; the fake offset shadow quad was removed. Popover/Dialog have no `rounded` class, so square corners stay.
- Splitter and placement: placement math was already field-for-field identical; the gap was shared vectors.

## Changes
1. Surfaces (`🖌️paint/🖼️ui-image-sources-skeleton-and-overlays`, engine frame files `🎞️frame-step`, `🖥️frame-into-step-and-frame`, `🪟️surfaces`): scrim is `theme.veil_glass(Level::Dialog)` (veilAlpha, veilBlur, no 0.55); surface is `theme.glass(level)` with Dialog level for modals and Menu for popovers/tooltips; content paints as the glass region's foreground (`paint_glass`/`overlay_glass` on the frame). Laws added in `🎭️scene-host-overlay-body-and-frame-laws`.
2. Events (`⚡️events`): `OpenOverlay.return_focus` + `OverlayVeto {escape, outside_press, focus_return}` (React preventDefault semantics); focus returns to the focusable trigger anchor, else the prior focus, on Dialog/Popover/ContextMenu/CommandPalette close; prevented outside press is not swallowed. `Ui::set_overlay_veto`. Focus trap was already Tab-scoped. Laws in `🪟️overlay-drag-drop-and-scroll-laws`. Select keeps its own focus rule.
3. Placement: shared vectors `🧪️tests/🧫️fixtures/📍️overlay-placement/🔣️.json` (generated by running React's `resolvePopoverPlacement`), replayed by Rust (`🪟️overlay` unit test) and by TS (`Popover/🧪️tests/🧩️component/placement.tsx`).
4. Extension: `paint_external_slot_node_step` draws React's unavailable line with no fill for non-media extensions; layout uses a control-height line. Law in the engine overlay laws file.
5. Scrollbars: `vertical_scrollbar`/`VerticalScrollbar` geometry in `🧮️layout` (React `--scrollbar-size`, thumb = border colour while host hovered, muted foreground under pointer/drag, square, transparent track); router derives the bar (`scrollbar_for`, `press_scrollbar`), proportional thumb drag and track paging; the thumb-node registry `register_scroll_thumb` was removed; new `Scrollbars` paint phase. Only vertical, only retained `SCROLLABLE` nodes; the shell panel scroll regions (`ScrollRegion` hits) are not covered. Splitter: `split_hit_extent` 20 fine / 28 coarse (`SPLIT_HIT_MIN_*`), `DockState.coarse_pointer`, set by the shell from the mobile/tablet breakpoint because the shell event path carries no pointer kind. Law uses React's `dock-cases.json`.
6. Placeholder: `render_placeholder` now draws two muted skeleton blocks (no text, so no English); callers drop the kind argument.

## Round 2 (coordinator follow-up)
- Dialog/CommandPalette/Popover open now moves focus to the first tab stop (`EventRouter::open_overlay` returns the resulting commands; `FocusState::first_tab_stop`). A modal also isolates the page: `EventRouter::hit_test` returns only nodes inside the modal or overlays above it, so nothing behind is hit, hovered, scrolled or focused by pointer. Laws: tab-trap test updated for autofocus, `a_modal_dialog_makes_everything_outside_it_inert_to_the_pointer`. Assistive-tech isolation: `hide_outside_modal` (hosting `accessibility`) sets the existing `hidden` projection flag on every node outside the modal subtree and its ancestors; `Ui::modal_overlay_document_id` names the modal and the accessibility dump applies it. The TS mirror already renders `hidden` as `aria-hidden` (`♿️accessibility-mirror`), so no TS change was needed.
- Scrollbars generalised to both axes (`layout::scrollbar`, `Scrollbar`, `scrollbar_for(tree, node, vertical, rtl)`, horizontal thumb capture/drag/paging, painter loops both). Shell: new `HitKind::ScrollThumb`, `paint_scroll_thumb` (chrome-frame file), shell press/move/release handling with `ShellInputState.scroll_thumb_drag`; applied to the panel tab rows, the only shell region with a plain `scroll_offsets` viewport (horizontal). The other shell scroll offsets (`tree:` ids, window bodies) belong to retained trees/nodes, which the retained scrollbars cover; the Tree agent owns tree scroll windows.
- Pointer kind: the splitter hit class now comes from the real pointer kind (`PointerInfo.kind` from winit mouse/touch and the browser `pointerType`), recorded on press and move through `shell_hooks.note_touch`, read by `last_input_was_touch()` into `DockState.coarse_pointer`; the breakpoint heuristic is gone. Pen counts as fine.
- Extension unavailable is localized: new `ui.common.extensionUnavailable` (en "Extension unavailable", de "Erweiterung nicht verfuegbar" with umlaut in the files) in the React i18n config and type, used by React's `ExtensionView` (React hardcoded English before), and `UiCommonLabels::extension_unavailable` for the wgpu painter, which formats `<label>: <id>` in the host locale (empty label, no guessed language, when the host names none).
