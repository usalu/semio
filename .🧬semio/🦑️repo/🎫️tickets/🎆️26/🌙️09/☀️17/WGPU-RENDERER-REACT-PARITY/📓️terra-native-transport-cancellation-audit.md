# Native Transport Cancellation Audit

## Scope and confidence

This is a source-only audit of native renderer asset streaming. It establishes a reachable stalled-body cancellation defect with high confidence. It does not claim that an already-blocked TCP connect or DNS lookup is interruptible: neither current native transport exposes a handle before a response body exists.

No source evidence shows an abortable underlying TLS stream.

## Minimal coherent repair

Add an object-safe, synchronous `HttpBody::abort_in_flight(&self)` hook, with a no-op default only for bodies that complete synchronously. Expose it through `HttpPoolBody::abort_in_flight(&self)`. It is intentionally `&self`: `next_chunk` returns a static future and the close owner must signal that future without taking or dropping its `HttpPoolBody`.

For `SocketHttpTransport`, return a shared `SocketHttpAbort` beside the reader state. `socket_http_connect` should `try_clone` its connected `TcpStream`; the reader remains in `SocketHttpBodyState`, while the abort control owns the clone. `abort_in_flight` calls `shutdown(Shutdown::Both)` on that clone and never takes the mutex-held reader. This wakes the actual blocking read, after which its closure releases the compute permit normally. It must translate the resulting I/O error to cancellation only when the exact request token is cancelled; a live request must retain its real transport fault.

Register a bounded `NativeAssetTransportLease` before `stream_native_renderer_http_asset` awaits a body chunk. The lease contains only a copied identity `{ surface_token: Option<AdmittedSurfaceToken>, request_token: WorldAssetRequestToken }`, the request child `CancelToken`, and the cloneable `HttpPoolBody` abort operation. It does not own the fetch response, body, payload, or worker. `close_component_asset_step` first marks the World authority as today, then, if the lease’s surface token matches its target and the exact request has been cancelled, cancels that child token and invokes `abort_in_flight`. It returns pending until the stream task maps cancellation to `fetch.begin_close`, installs `NativeAssetHandoff`, and the existing bounded handoff returns the owner. The worker clears the lease only after its stream future is terminal; the close side never clears `native_asset_fetching` or takes the response owner.

The stream must check `renderer_asset_cancelled(fetch)` before starting each chunk and on every error boundary. A cancellation after a page arrives but before `push_page`, seal, or handoff must close A without publishing it. The existing post-read check at [renderer `🦀️.rs:15241-15249](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🎯️targets/🧊️wgpu/🧊️renderer/🦀️.rs:15241) is necessary but insufficient for the wait itself.

Do not use the mailbox root token for component close: it is an application-wide parent and is currently cancelled only by whole renderer-asset closure [renderer `🦀️.rs:11927-11943](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🎯️targets/🧊️wgpu/🧊️renderer/🦀️.rs:11927). A stale A close must not cancel a current B or poison future children of that root.

The protocol needs an explicit terminal policy for HTTPS before it can claim native-wide cancellation. The retained renderer should not silently use a no-op abort for `UreqStreamingHttpBody`. Either its transport must expose a comparable abortable stream, or it must publish a bounded timeout result as a transport fault and retain its owner until that terminal result. That issue is confirmed but not resolved by the socket-body repair.

## Fail-first laws

1. Extend the real local TCP socket harness in [services component tests `🦀️.rs:1110-1152](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🛎️services/🧪️tests/🔬️component-unit/🦀️.rs:1110): server A writes a valid head then keeps its body open; start a real `next_chunk`; call `HttpPoolBody::abort_in_flight` and the child token’s cancellation. Assert the read reaches the cancellation boundary and the same actor can acquire its `outstanding_cap: 1` slot for B. This is the direct regression for the in-flight, not merely dropped, body.
2. Extend [renderer native handoff cancellation law `🦀️.rs:259-285](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/📺️renderer/🧑‍🎨engine/🧪️tests/🧊️wgpu-os-host-standalone/🦀️.rs:259) with an actual socket A running under the stream task and a queued World B. Close A while its body is stalled. Require A has no page/seal/publication, B is current and publishes after A’s terminal handoff, `native_asset_fetching` does not clear early, and no frame fault occurs.
3. Add a stale-identity variant: close old A after its same host has a new surface token/request token B. The old lease must not abort B. A close is keyed by both the admitted surface token and request token, never URL or document surface text.
4. Add ready-then-close: deliver A’s bytes, suspend immediately before page acceptance/seal, close A, then resume. Require no `WorldAssetResponsePage` or decoded mesh/reference publication for A, while B’s independently queued response remains live.
