## Accepted-epoch conclusion

Only the Ink failure intersects accepted-frame ownership. The current UI contract intentionally holds candidate reconciliation while a scene retirement is outstanding, then lets the frame-owned interpreter transfer and acknowledge one exact head before returning to reconciliation. A test that steps the UI engine alone does not exercise that handoff. The correction should preserve the accepted-pixel boundary and consume exactly one retirement opportunity per fixture turn. It must not alter `acknowledge_presented_input`, loosen `candidate_ready`, or make an accepted candidate visible before its frame is acknowledged.

The chat label discrepancy is independent of accepted epochs: both hosts project the same component, and only its localized explicit accessibility string differs.
