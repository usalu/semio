## 1. Group alpha (true offscreen group, round 2 replaced the CPU multiply; the CPU path is deleted)
- Contract (`D/🫥️group-alpha`): `DrawList::begin_group_alpha(bounds, alpha) -> GroupAlphaMark` / `end_group_alpha(mark)`. Every `DrawLayer` from the begin layer to the first layer outside carries `group: Option<GroupAlpha { alpha, bounds (logical clip), begin }>`; all layer constructors (scissor, clip, glass, scene pass, shared-border insertion, retained append into an open group) propagate it. Groups do not nest; alpha >= 1 is no group. Shared-border seed/mark merging refuses to cross a group difference. Glass regions and shared borders live in group layers, so they are inside the group.
- Prepared stepping (`semio-ui-prepared`): new cursors `GroupBegin(layer)` (emitted at the begin layer's header) and `GroupEnd(layer)` (emitted when leaving the group's last layer, `layer_exit`), each one draw item.
- Encoding (`GpuContext`, execution crate): `GroupBegin` ensures a pooled surface-sized `PreparedGroupTarget` (same texture and view formats as the composite), clears it to transparent and sets `group_open`; every UI/vector/raster scalar and every glass scalar then targets the group view; `GroupEnd` composites it onto the composite view inside `group.bounds` at the group alpha and clears `group_open` (also reset at `InitializeComposite`). Deviation: the pool is surface-sized (all scalar encoders draw in surface coordinates), touched only inside the clip, not sized to the bounds.
- Shader: `GROUP_COMPOSITE_SHADER` (WGSL, `🖍️draw/🎨️shaders/✨️world3d-effect-shaders`, exported): samples the premultiplied group, scales by `group_globals.alpha.x`, pipeline blend `PREMULTIPLIED_ALPHA_BLENDING` (`PreparedGroupTarget`, factory crate; `UiPipelines::encode_prepared_group_clear/composite`). UI pipelines already alpha-blend, so a transparent target holds premultiplied colour and coverage; the result equals CSS opacity over a group. Naga parse and validation plus a structure assertion added to `🧪️tests/🔬️shader-contract-unit`. No HLSL/MSL/webgpu twin: no other backend has prepared groups (the shader-contract registry is not extended).
- Limits: 3D scene passes inside a group still draw to the composite (not faded); glass inside a group blurs the main composite snapshot, not earlier group content; two adjacent groups with identical alpha and bounds can merge shared borders.
- BlockList: the dragged row group (its bounds the union of its targets) is a group at `BLOCK_LIST_DRAG_ALPHA = 0.5`.
- Canvas/vello: `SceneCommand::PushLayer` already carries `alpha` into vello; nothing needed.
- Tests: `D/🫥️group-alpha-tests` (layer marking across scissors and glass, no-op cases), `🔬️targets-wgpu-prepared-unit` `a_group_alpha_group_is_bracketed_by_begin_and_end_cursors`, shader naga entry. No GPU pixel test (needs an adapter): verify visually.

## 5. Dialog close fade and zoom
- `dialog_zoom(visible, from)` in `D/🎞️chrome-motion` (exported), law test in `🎞️chrome-motion-tests`.
