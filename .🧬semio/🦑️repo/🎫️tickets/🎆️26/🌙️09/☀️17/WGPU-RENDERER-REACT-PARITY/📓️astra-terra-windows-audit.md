## Test slices

1. Add a dock/shell law: close the only window, invoke Display's `openDisplayWindow`, then assert a
   one-instance root stack, active instance, persisted layout, and optional World3d template. Cover an
   invalid kind and unavailable session as no-op controls.
2. Add a two-World3d-surface retirement law: plan/sync `a` and `b`, close `a`, plan/sync again, then
   assert `a` is absent from `world3d_states`, status/settle/preview/projection maps and cannot claim a
   pointer or wheel inside its old rect; assert `b` remains interactive. Reopen the now-available
   instance id and assert it starts with fresh camera/selection state. A browser parity companion should
   close React's matching window and prove its descriptor/component is absent before comparing the event
   census.
3. Add pointer interaction coverage for a Display row dragged to a tab, each split edge, and an empty
   dock. Assert the new window's layout path and seeded template follow the targeted drop zone; compare
   it with React's `onTemplateDrop(payload, zone)` path, rather than with a fixed-right action.
