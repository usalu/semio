## Design (the one derivation everything else reuses)

**Coedge orientation** (`📓️w2c-sweeps.md` §orientation, referenced from every submodule's docstrings): for a "bottom → top" prism segment where `bottom` is REUSED (not rebuilt) and `top = transform_face(bottom, map)` (so `top`'s coedges have the *same* `forward` bit as `bottom`'s, per `copy_loop`'s own `members.push((edge, c.forward))`), a ring-closure derivation (hand-traced, not pattern-matched off `make_box`'s differently-constructed loops — see the module doc in `🧮️core/🦀️.rs`) shows the ONLY closeable lateral loop is `[bottom_edge(!f_i), left_rail(true), top_edge(f_i), right_rail(false)]` with rails running bottom→top. This is used, unchanged, by extrude (`Placement::Translate`), the general sweep/pipe/helix chain (`Placement::General`), and — in mirror form (profile edge plays the rail role, new rotation arcs play the cap-boundary role, since `Surface::Cylinder`/`Cone`/`Torus`/`Sphere` are angle-linear in `u` = the *sweep* direction, not the edge's own parameter) — revolve's partial and full-2π cases.

**pcurve exactness** (`📓️w2c-sweeps.md` §pcurve): a lateral surface's u/v-axis is built so the relevant boundary is *affine* in the edge's own curve parameter `t` — always true for `Curve3::Line` and `Curve3::Nurbs` (their `to_nurbs()`/native form doesn't reparametrize `t`), true for `Curve3::Circle` only when the surface stays angle-linear (`Cylinder`/`Cone`/`Torus`/`Sphere`, i.e. the axis-parallel/torus-plane-contains-axis cases). Everywhere else — a circle/ellipse profile edge that doesn't qualify for an analytic fast path — `to_nurbs()`'s own rational-quadratic reparametrization is *not* angle-linear except at span breakpoints, so a straight `Curve2::Line` pcurve there would silently reproduce the wrong physical curve. Per the kernel's own stated invariant ("never wrong, fail loud" — `snapshot/🚨️error/🦀️.rs`'s own docstring), these cases return `KernelError::Operation` with a clear message instead. **Known gap, explicitly scoped out, not attempted**: extrude/revolve/sweep of a `Curve3::Ellipse` profile edge, and revolve of a genuinely free-form (`Curve3::Nurbs`) profile edge (needs the 9-point-rational-per-quarter-turn surface-of-revolution construction, not implemented this pass). None of the required test cases hit these.

## Per-operation summary

- **`extrude_face`**: profile face reused as one cap (flip decided by `n0·offset` sign, recorded modified); `transform_face` translate as the other (recorded generated). Every profile edge (every loop — holes get their own tube faces): `Line`→`Plane`, `Circle` with `frame.z ∥ direction`→`Cylinder`, `Nurbs`→degree-1-in-v NURBS extrusion surface built directly from `to_nurbs()`'s control net (not sampled). `Ellipse`/non-axis circle → refused.
- **`extrude_wire`**: closed wires only this pass (builds the planar face via the existing `make_planar_face_from_wire`, then `extrude_face`); open-wire shell-only extrusion is a documented, refused gap (`KernelError::Operation`).
- **`revolve_face`**: `|angle| ≥ 2π−ε` → full closed revolve (no caps — one rotation-orbit circle, or a degenerate on-axis edge, per profile vertex, shared by its two adjacent lateral faces; each profile edge reused twice as its own seam — the direct N-edge generalization of `🧱️primitives::make_cylinder`'s single-seam pattern). Otherwise → two caps (same reuse-bottom/transform-top trick as extrude) + one lateral face per edge bounded by two new rotation-arc rails. Per-edge classification: line ∥ axis → `Cylinder`; line ⟂ axis → planar annulus (`Surface::Plane`, whose Cartesian (u,v) forces the rotation-arc rail to be a genuine `Curve2::Circle` pcurve instead of a straight line — the one place the "u = sweep angle" convention doesn't apply); line crossing the axis → `Cone`; circle in a plane containing the axis → `Torus`, or `Sphere` when the circle's centre is on the axis. On-axis profile edges (both endpoints on the axis) and apex-touching cone edges are refused rather than mis-built (documented gap — W1-E's sphere/cone degenerate-edge convention was not extended here for time reasons).
- **`loft_profiles`**: requires the same loop count and same edge count per corresponding loop across all N profiles (checked, clear error otherwise). Per edge position: `to_nurbs()` every profile's corresponding edge, elevate to the max degree present (`elevate_degree`, parameter-preserving — unlike `to_nurbs`'s circle reparametrization, degree elevation does NOT change the `t → point` function, so this stays exact); if control counts still don't match after elevation (a genuine knot-vector mismatch, e.g. very differently-shaped profiles), refuse rather than guess (full knot-vector-union insertion via `insert_knot_multi` is a documented, scoped-out gap — not needed by congruent-profile inputs like matching rectangles/circles). Skins by fitting one NURBS curve per control-column (`interpolate_curve` with `ParamMethod::Uniform`, so every column's fit shares the identical knot vector — the tensor-product-consistency the whole skin needs); `smooth` picks degree 1 (ruled, exact piecewise-linear) vs `min(3, sections−1)` (C² on ≥4 sections). First/last profile's own edges are mutated in place to their harmonized NURBS form (parameter-preserving ⇒ their existing pcurves stay valid) and reused directly as the two caps; interior profiles are fully consumed (deleted).
- **`sweep_along_path`/`pipe`**: a single straight-line path (no guide) delegates entirely to `extrude_face` (exact `Cylinder`/`Plane` fast path); a single circular-arc path (no guide) delegates entirely to `revolve_face` (a circular profile along a circular arc is an exact torus segment). Otherwise: rotation-minimizing frames (double-reflection method, Wang et al. 2008) along adaptively-sampled path stations (denser where `curvature(t) > 0.5`), with the guide (when present) re-pointing each station's own axis at the guide's closest point (Gram-Schmidt-orthogonalized against the tangent) instead of the RMF-propagated axis. The profile is aligned to the first station, then chained through `🧮️core::build_prism` under `Placement::General` one station-to-station segment at a time (intermediate cross-section faces are built via `transform_face` for topology, then marked deleted — not part of the final shell — only the first/last are real caps). Certified only for `Line`/`Nurbs` profile edges on this general path (see §pcurve above) — a circular profile on a genuinely curved (non-line/arc) path is refused, not mis-parametrized.
- **`helical_sweep`**: an analytic helix parametrized directly (closed-form point/tangent, `≥16` stations/turn, actually `24`/turn), fed through the same RMF station chain as `pipe`'s general path (`Station`/`stations_to_frames` are exposed from `🐍️frame` specifically for this).
