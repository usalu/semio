Date: 2026-09-12  
Scope: the mandatory-script expansion packet, coverage report, non-package enforcement probe, and `🗑️generated/coordinator/script-owner-scope-native-ast.json`. This is a read-only Terra audit. It intentionally does not review the in-flight recursive command-router grammar.

## Finding

The earlier package-only census is insufficient: the native AST scope contains **455 mandatory scripts** (105,891 lines), including **318 paths outside the earlier review subset** (65,007 lines). The native parser reported zero TypeScript syntax diagnostics for the full scope. That establishes parseability, not thin-command compliance.

The meaningful next work is a set of bounded extractions into domain owners. A single root replacement, a generic utilities module, and a blanket script exemption would all preserve the current implementation-named source authority and are not acceptable.

## Root Mandatory-Script Enforcement Gap

The probe's root `📜️script.ts` record is classified as `not-package` before fixed-contract source disposition is evaluated. Its implementation-leaf filename finding is `null`, and the fixed-contract filename therefore avoids a source-body diagnostic. Five opaque reference-target comments were recorded separately; they do not remedy or explain the bypass.

After the active router grammar work settles, add a **separate mandatory-script source-disposition path before the `not-package` return**. It must inspect root and other non-package fixed-contract scripts, while retaining the fixed filename contract.

The acceptance fixture pair should be language-agnostic and portable:

1. A positive fixed-name script has only named owner imports and a routing/registration invocation; it produces no mandatory-source-body diagnostic.
2. A hostile fixed-name script keeps the same router shape but introduces local semantic I/O, artifact production, or a domain function; it produces the dedicated mandatory-source-body diagnostic.

This audit did not inspect or modify the in-flight recursive parser, so it does not judge the nine hostile router cases. The gate must not use an exception for root scripts or any other filename that the taxonomy reserves.
