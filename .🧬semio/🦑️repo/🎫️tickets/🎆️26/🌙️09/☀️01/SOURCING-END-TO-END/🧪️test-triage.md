## Remaining 11 failures, by class

### A. Unmigrated document commands (4 tests)
`curateAdd`, `curateSetCount`, `curateRemove`, `dropOnCurated` fault with
`interactive-job.missing-factory`. They are declared `InteractiveJobClassification::BatchOnlyPendingRewrite`
(`SOURCING_CURATE_BATCH_ONLY_TOOL_IDS`, 8 ids), so they own no tool proof and typed dispatch refuses them.

Migrating them is not a one-line registry flip: they publish on the `Artifact` lane, and
`unsupported_publication_contracts` rejects that lane unless the app implements
`build_artifact_store_one_item_preparation_factory` — which sourcing does not (it has only the
config-lane one, `SourcingCurateConfigPreparationFactory`). The document-lane equivalent has to be
written; `🗒️note`, `📐️cad`, `🌊️flow` and `🌍️gis` already have theirs.

### B. World3d scene payload over its fixed cap (1 test)
`grid::renders_via_the_app` → `ui.fixed-capacity: fixed UI admission failed at mesh-window.scene`.
`semio_framework_ui_scene::encode` packs the whole `World3dScene` into `UiFixedBytes`, capped at
`UI_FIXED_BYTES = 32 KiB`. The grid window inlines every filtered kind's full mesh (positions,
normals, indices) as JSON, so the unfiltered demo stock overflows it. **This is a runtime defect, not
just a test one** — the same render runs in the browser. `World3dScene` already carries an optional
`World3dSnapshotLease` for exactly this case, but no plugin has adopted the page-based path yet.

### C. Scene assertions written against the pre-pack encoding (2 tests)
`grid::grid_instance_count_matches_filtered_stock_and_normalizes_scale` and
`preview::preview_renders_selected_mesh_id` assert `serde_json::to_string(&node).contains(&id)`.
Since `encode` packs the scene to opaque bytes, ids no longer appear in the node JSON. The current
idiom is to destructure `Component::Surface(props)` and `semio_framework_ui_scene::decode` the scene
back (see `🎪️demonstrator`'s `🪟️main` window test).

### D. Stale generated descriptor (1 test)
`descriptor_is_fresh` — `🛂️descriptor.semio` / `🔣️descriptor.json` need regeneration after the
mutation-taxonomy rename. Regenerated by the plugin build.

### E. Registry kind discipline (1 test)
`view_kind_config_only_commands_pass_kind_discipline` — was blocked behind the live-instance fault;
re-triage after the instance binding lands.
