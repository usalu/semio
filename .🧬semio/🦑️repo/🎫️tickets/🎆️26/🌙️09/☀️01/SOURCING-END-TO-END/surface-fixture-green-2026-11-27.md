## Priority 1: the two hangs (same root cause)
`registered_editor_consumes_intrinsic_natural_bytes_through_the_real_media_route` and `registered_editor_natural_bytes_stay_untaken_while_unfunded_and_settle_once_funded`.
- Root cause: the law helpers `consume_media` and `consume_media_refused_then_funded` (`🧪️testing/🧪️artifact-app-laws/🏗️registered-app-construction-and-typed-operation-settlement`) re-polled with `while !cancelled && !should_yield`. A turn is never renewed (fuel about 6.5e10) and the cancellation issuer was never born (`import_media` and `dispatch_fixture_*` birth it via `ensure_fixture_cancellation_issuer`). `ToolCancellationIssuer::begin_original` answers `Ok(None)` when `!ready()`, so the mount phase "lease admission" retried forever at zero cost. Measured: 73 polls, then fuel constant, 17000+ identical polls, CPU 94%.
- Fix: both helpers now follow the `import_media` shape: per-turn `fixture_renew_turn`, bounded by `OriginalFixtureCaller::maximum_turns()`, `history_snapshot` plus `ensure_fixture_cancellation_issuer` after turn 0, `maintenance_step` each turn, and a typed `WorkLimit` error carrying `typed_operation_diagnostic()` on exhaustion.
- Product verdict: no product code changed. The production host births the issuer with the instance (`advance_instance_birth`) before any media import, and the sourcing hub Open File probe passed on the hub wasm of 17:29, so the hub wasm is unaffected (nothing to rebuild). Residual risk worth a peer decision: `begin_original` returns `None` silently while the issuer is unborn; a typed `interactive-job.cancellation-issuer-unborn` refusal would turn a future harness or host omission into a loud failure instead of a spin.
- After the stall was gone the same two tests failed at the document load with `closure-rejected (InvalidReference)`. Cause: the fixture dialect `testkit.surface` is not a canonical artifact kind (`is_canonical_artifact_kind` demands `plugin.owner.artifact`, three kebab segments, as in `s.sourcing.curation`). Fixed in the fixture: `s.testkit.surface` (dialect constant, controller id literal in the factory file and the `bounded_first_step_tool_proofs!` controller).

## Still failing (6), with diagnosis
1. `natural_file_cancel_after_decode_retires_the_unpublished_snapshot` and `natural_file_reserved_job_accounts_cancels_refuses_and_retires_boundedly` (exit 133, drop assertion abort after the failed assertion): after `cancel_now()` the test expects `FixtureStepOutcome::Cancelled` from `fixture_step`. `OriginalJobReturnReceiver::prepare` returns `false` for a cancelled context, so `drive_step` answers `Preparing` and the job body never runs; the `Cancelled` outcome cannot be delivered through this helper under the current return protocol. The first assertion of the `accounts` test (first checkpoint) was already moved to the decode stage change (`progress == octets.len()`, coalesced). Needs a peer decision: either the cancelled step must be allowed to enter the body (product) or the law should assert cancellation through `close_step` (test).
2. `reserved_request_keeps_all_lanes_on_denied_birth_and_continues_after_input_donation`: `surface_prepare_origin` cannot admit the return origin within the turn bound once the Source is cancelled (case `cancel == 1`), same class as (1).
3. `child_emission_private_typed_lanes_stage_three_...` and `child_emission_private_group_row_frames_...`: lane `close_step` needs "its existing decoder receipt". The first now runs under `with_original_decoder` and still fails; the second panics in `OriginalJobFixtureCaller::admit` (`JobPayloadAuthority::admit(...).unwrap()` is `None` for its grant). The group-row test builds its own one-item `RetainedCloneGrant` for `MemberStoreOwnedBatch`; both need the decoder-owning caller pattern of `retained_command_work_borrows_...` and were not converted.
4. `work_fixture_close_reconciles_the_actual_original_job_and_allocator_once`: `released_bytes` receipt delta is 12152 against 24 observed by the allocator. The receipt now includes a terminal frame release that the fixture probe (`CloseProbe`) does not model (`terminal_frame_release_bytes` default); needs the retained-command owner to say which side is intended.
