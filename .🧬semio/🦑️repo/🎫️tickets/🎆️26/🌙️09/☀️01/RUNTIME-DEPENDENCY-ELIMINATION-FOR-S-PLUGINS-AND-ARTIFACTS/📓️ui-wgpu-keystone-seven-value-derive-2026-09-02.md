# 🌱️ The UI-wgpu keystone seven now have `ToValue`/`FromValue`

## What landed

All seven types named in this packet — `LocalizedLabel`, `IconName`, `ActionDescriptor`,
`NamedLayout`, `WindowLayout`, `WindowOptions`, `SurfaceKind` — plus every nested type they require
now implement `ToValue`/`FromValue` (`🌱️value/🔁️codec`), additively, alongside their existing
`Serialize`/`Deserialize`. No serde was removed. No wire shape changed (see "Divergences" below for
the one deliberate exception).

## Why two are hand-written instead of derived

- **`LocalizedLabel`**: its own `Serialize`/`Deserialize` are hand-written (a `[[Cow<'static, str>;
  Locale::COUNT]; Terminology::COUNT]` matrix has no struct field for a derive to annotate). The
  `ToValue`/`FromValue` impls mirror the same `{terminology: {locale: text}}` object shape.
- **`IconName`**: home file is generated and marked do-not-edit (~2300 lines, one `#[serde(rename =
  "...")]` per variant). Hand-written impls bridge through the EXISTING `serde_json`
  `Serialize`/`Deserialize` plus `DslValue`'s own `From<&serde_json::Value>` /
  `From<&DslValue> for serde_json::Value` bridge (`🌱️value/🦀️.rs`), so the wire string is
  byte-identical to what the generated impl already produces — no ~2000-arm match needed.
- **`WindowLayoutChild`/`WindowLayoutRoot`**: `#[serde(untagged)]`, which the derive does not
  support (`🌱️value/✨️derive/🦀️.rs`'s module docstring lists `rename_all`/`tag`/`content`/`default`/
  `deny_unknown_fields`/`transparent`/`bound` as the only container attributes — no `untagged`).
  Hand-written `ToValue`/`FromValue` replicate serde's own untagged algorithm: try `Axis` first,
  then `Stack`, matching declaration order.

## Divergence from serde (deliberate, documented in-line)

`WindowLayoutStackNode.active_window_kind_id` carries `#[serde(skip_serializing_if =
"Option::is_none", alias = "activeId")]`. The derive has no `alias` attribute (unrecognized `#[value(...)]`
keys are a hard compile error) — the `#[value(...)]` twin drops `alias` and keeps only
`skip_serializing_if`. Round-trip (`FromValue(ToValue(x)) == x`) is unaffected; only the legacy
`activeId` INPUT alias is not accepted on the `ToValue`/`FromValue` path (the serde path is
untouched and still accepts it).
