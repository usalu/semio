# 🌱️ The five residual blockers (kernel + ui_wgpu) now have `ToValue`/`FromValue`

## What landed

All five types named in this packet now implement `ToValue`/`FromValue` (`🌱️value/🔁️codec`),
additively, alongside their existing `Serialize`/`Deserialize`. No serde was removed. No wire shape
changed.

- `kernel::ActivationEvent` — `🧰️framework/🔨️modules/🎠️kernel/🦀️.rs:1092`. Externally-tagged mixed
  enum (unit + named-field variants), no prior `tag`. Derived via
  `#[derive(ToValue, FromValue)]` + `#[value(rename_all = "camelCase", rename_all_fields =
  "camelCase")]`, an exact twin of its existing `#[serde(rename_all = "camelCase",
  rename_all_fields = "camelCase")]`.
- `kernel::CapabilityRequirement` — `🧰️framework/🔨️modules/🎠️kernel/🦀️.rs:150` (line numbers
  shifted after edits; originally ~150). Plain struct (`artifact: ArtifactKind, rights: Rights,
  scope: Scope`). Derived via `#[value(rename_all = "camelCase")]`. Its three nested field types —
  `Rights`, `ArtifactKind`, `Scope` (all plain all-unit-variant enums, `#[serde(rename_all =
  "camelCase")]`) — did NOT already have `ToValue`/`FromValue` and were blocking, so they were
  derived too, same `#[value(rename_all = "camelCase")]` twin each.
- `ui_wgpu::UtilityCategory` — `🧰️framework/🔨️modules/🖱️ui/📦️packages/🦀️rust/🎯️targets/🧊️wgpu/🦀️component.rs`,
  inside `pub mod utilities`. Plain all-unit-variant enum, `#[serde(rename_all = "camelCase")]`.
  Derived via `#[value(rename_all = "camelCase")]`.
- `ui_wgpu::Locale`, `ui_wgpu::Terminology` — defined in
  `🧰️framework/🔨️modules/🖱️ui/📦️packages/🦀️rust/🎯️targets/🧊️wgpu/🤖️generated.rs`, marked
  `// @generated by ui/script.ts from 🔣️ui-axes.json — do not edit.` at its own top line — NOT
  touched. Hand-written `ToValue`/`FromValue` impls added instead in a NEW sibling file
  `🦀️locale_terminology_value.rs`, mounted via `#[path]` in the wgpu target root `🦀️.rs` right
  after the existing `pub use ui_axes_gen::{Locale, Terminology};` line — exact same pattern as
  `IconName`'s existing `🦀️icon_name_value.rs` sibling-file impl from the prior "keystone seven"
  pass. Both types are still LOCAL to `semio-framework-ui` (path-mounted, not foreign-crate), so
  the orphan rule allows this. Bridges through the types' existing `serde::Serialize`/`Deserialize`
  (`#[serde(rename_all = "lowercase")]`) via `serde_json`/`DslValue`'s JSON bridge, same technique
  `IconName` uses — wire shape stays byte-identical (`"en"`/`"de"`, `"native"`/`"reuse"`).

## Why nothing else needed hand-writing

All five (plus the three newly-derived nested types `Rights`/`ArtifactKind`/`Scope`) are either
plain structs or enums the derive macro already supports natively: `rename_all`,
`rename_all_fields`, and tag-less externally-tagged enums with mixed unit/named-field variants are
all documented as supported in `🌱️value/✨️derive/🦀️.rs`'s own module docstring, and this exact
externally-tagged + `rename_all_fields` combination is already used elsewhere in the same kernel
file (e.g. the existing `TutorialUiKeyframe`-adjacent block at `#[value(rename_all = "camelCase",
rename_all_fields = "camelCase", tag = "kind")]`, minus the `tag` here). No `#[serde(untagged)]`,
no `u128`/exotic scalar, no generated "do not edit" struct-shaped file among the five kernel/ui
types — only `Locale`/`Terminology` needed the sibling-file treatment, and that was because of the
do-not-edit marker, not the shape.
