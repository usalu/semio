# Native Receiver Work and Recovery Phase Matrix

This is the intended interface contract, not execution evidence. The receiver changes are incomplete and have not compiled. No source admission or formatter result proves a test pass.

| Owner or phase | Actual current child API | Required next-turn contract |
|---|---|---|
| NativeReceiver | demands(original, body, maximum_work_units); advance_work_demand(original, body, maximum_work_units); advance(original, control, body, maximum_work_units, grant); take_work_demand(); close_work_demand(body) | Quote and effect select the same immutable original and phase. Zero or insufficient work must leave owner and output unchanged. The outer original work loan must be passed or reused, never reserved a second time by a nested owner. |
| NativeReceiveSlot birth | NativeOwnedStorage reserve/put_from each reports its own work | Quote the exact selected reserve or handoff action; use the actual allocation marker on allocating birth. Constructor and subset selection must also be bounded and charged. |
| NativeReceiveSlot active | Child NativeReceiver advance_work_demand / advance, or take_work_demand / take | Forward the original, body, actual remaining work and grant; transfer actual child work once. Do not infer cost from copied byte counts alone. |
| NativeReceiveSlot close | Child close_work_demand / close_step; RetainedCloneClose::next_owner_work and step_granted | Quote the selected original child or owned retirement; preserve OriginalRetirementFailure. An allocating retirement must expose its real attempted-allocation marker. |
| RetainedFieldCursor | RetainedCloneCursor::advance_demands(source, body, maximum_work_units), advance_work_demand(source, body, maximum_work_units), advance(source, body, maximum_work_units, grant), take_work_demand, close_work_demand | NativeStringReceiver must forward these signatures and preserve OriginalRetirementFailure; current calls are older and uncompiled. Field birth and retained clone effects require the original frame and actual marker. |
| NativeScalarValue and NativeValueSource | read(original), read_copy_bytes(original); source boolean, number, is_null, text, tree_kind, indexed record and sequence accessors | Primitive conversion and the actual source accessor each need a declared, validated work quote; arbitrary trait implementations cannot be assumed constant. DslValue uses direct vector get for entries; first-party providers and any nested source projections must be audited individually. |
| Record matcher | Current advance loops up to grant.maximum_items; advance_one compares up to 64 bytes while reporting one work unit | Redesign to one bounded event or byte-counted turn, with its pre-effect quote and an actual receipt. Preserve cursor identity and paid page/binding close. Selector delegates the actual selected matcher quote. |
| Default cursor, shared field, record and enum | Current child work queries are not consistently exposed | Each owner must expose its actual phase-specific next-work demand and recovery loan; generated code delegates selected owner rather than a synthetic constant. |
| Recovery | NativeRecoveryLoan::Value / Retirement loans the actual typed NativeReceivingEffect; receive_allocation / receive_retirement and finish variants use the same construction and work issuers | Resolve the actual callback with its original typed result and marker, settle work and receipt once, preserve OriginalReceivingPrimary including retirement_failure, and refuse close while unresolved. A test must debit finite allocation/work stock and pay closure. |

The interface requires a source-neutral phase fixture, refusal/zero-work tests with unchanged ownership, and an independent reference accounting oracle before claiming coverage. Callback interruptions, foreign issuers, cancellation, child retirement failure and completion must retain their actual owners. Current tests and source caps are unresolved; no native pass is claimed.

Concrete storage observation: NativeOwnedStorage::reserve currently calls alloc directly and reports work one, but accepts no actual-allocation marker. An original effect wrapper cannot reconstruct that marker from a quoted layout. The defining storage operation must record the real attempt before alloc, with None for zero-sized backing that performs no allocation and Some(0) for a genuine failed nonzero allocation attempt.

Current default owner: NativeDefaultCursor::demands(body), advance(control, body, grant), take(grant), begin_close(), close_demands(body), close_step(grant). It has no work quote, maximum-work argument, or recovery loan today; NativeDefaultValue::admit_default similarly exposes no original allocation marker. A generated default field must not pretend those child costs are known until their defining APIs are extended.

Take and close do not currently receive maximum_work_units. Their quoted action must therefore be pre-admitted through the genuine original outer work authority; the query alone does not gate their effects.

Constructor follow-up: NativeReceive::receiver and record_subset_receiver are arbitrary current producers; NativeReceiveSlot and sealed-shared child birth both use them. A selected full/subset constructor needs an explicit demand, work quote, allocation flag, actual marker and caller-owned pending receiver output with a real RetainedWorkOutcome. Generated record constructors initialize positions arrays whose work scales with authored field count. The slot must retain that output before handoff or interruption, and close it on cancellation. This interface remains proposed, not landed.

Composite output gap: NativeArrayDefaultCursor reads an entire MaybeUninit<[T; N]> into output in one reported unit; NativePairDefaultCursor similarly combines arbitrary A and B and then takes the whole tuple in one unit. NativeOwnedStorage::put_from also moves an arbitrary cursor inline while reporting one unit and zero copy bytes. A bounded in-place owner/handoff or genuinely accounted resumable alternative is required before these can claim interaction-friendly work bounds. Merely increasing the quoted work does not make a very large move cancellable.
