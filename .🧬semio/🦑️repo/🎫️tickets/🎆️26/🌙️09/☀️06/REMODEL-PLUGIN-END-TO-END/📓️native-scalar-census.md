The search completed normally and found eight files in the searched framework and application trees; its same-line implementation pattern may omit multiline or generated implementations. Generic native scalar values therefore cannot be sealed to primitives or assigned a universal one-unit cost. Each implementation must quote its actual source accessor and conversion, and generic owned-output transfer remains unresolved. No source or native test has been executed by this census.

Their original accessor calls, comparisons and actual work need accounting; NativeScalarValue::read currently returns only Result<T, ValueError>, so a quote alone cannot report actual computation or an allocation attempt.
