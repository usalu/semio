# Native Window Initialization

The Energy editor and viewer retain independent camera state in each Window configuration Store. Actual mounted commands must admit that Store under their original `StepContext`; rendering borrows existing partitions and can show the authored default before any command creates a Store.

## Empty Window Genesis

`WindowConfigPartitionBirth<O>` retains the original address, schema, artifact ID, opened actor lease, admitted domain default, borrowed native Pack cursor, canonical Pack destination, initializer and candidate Store. Its cursor measures and emits the actual declared record incrementally. Its BLAKE3 digest covers the emitted Semio envelope and native Pack bytes. Genesis facts and the authoritative Pack then move into the existing native Window replay initializer.

Owner defaults are explicit admission ports. The framework refuses owners that do not declare their initial source instead of calling arbitrary allocating `Default` implementations. Both real Energy Window owners declare the fixed camera source and actual native record projection.

Cancellation closes the original outcome, source-dependent cursor, replay initializer, retained candidate and every source before the original frame can be released. The mounted registry separately admits its immutable address and registry pages.

## Saved Window Sources

`WindowConfigPackSource` retains either split Pack/SPR owners or the mounted command's original framed buffer. Pair admission borrows the actual source slices and preserves source pointer and original decoder identity. It does not duplicate the full input into a second parsing buffer.

The native saved loader uses the existing `OriginalArtifactPairReceiving`, `OriginalHistorySource`, original `HistoryFoldJob`, dynamic original operation receiver and `WindowConfigInitialization`. It receives one typed genesis, folds Config history, transfers the original cursor and transition owners, receives original canonical operations, preserves operation metadata and messages, and asks the native initializer to replay the typed ledger.

The dynamic JSON receiver now supports a unique owned result handoff after closing its canonical/output aliases. The same typed mutation moves into the Window edit ledger; no clone or second decode is used.

Split input transfers its canonical Pack owner directly into genesis. Framed input admits an exact Pack-only destination and copies bounded chunks after all source-dependent receivers close. The SPR portion remains in the original framed owner until retirement.

The private candidate remains outside the live registry until initialization is complete. Registry installation and cancellation retain the original registry slot custody.

## Verification Status

The actual mounted command tests pass: exact original framed Vec pointer, registered native Pair receive, two original operation replay, private candidate, funded installation with final zoom 2.75, complete registered Store retirement, cancellation through the original caller token at seven cutoffs, and independent item/copy/capacity/release/depth grants. The tests reconcile every observed allocation and release against the original caller receipt. A separate test now targets an actual positive release demand rather than assuming every event requires all five currencies.

The cancellation regression initially stalled because closing header events reused open construction, which correctly refuses cancelled callers. Closing now uses the same original caller's retirement scope; cancellation and original decoder identity remain intact.

Nonempty Store retirement exposed a real history-ledger owner bug: retained factory authority had no demand or stepping branch, so closure reported Complete while retaining that authority. The defining retirement now closes each original factory before further ledger returns and removes its empty header under a funded event. Returned-read scalar queries also borrow the retained registry after its live handle frame retires. These fixes make complete installed-command retirement pass without relaxing receipt or terminal checks.

The native saved Pair/Framed replay test and uninstalled cancellation test use the same fixture and production sources. The independent portable oracle passes one test with 22 assertions through Ajv, SQLite and JSON. Empty genesis and preview closure are validated separately by the lifecycle agent. Full SDK/browser completion remains part of the overall Energy task, not implied by these focused tests.
