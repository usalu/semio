# Generation Payload Contract Design

## Scope and evidence

Production was read only. No cache/store row was opened, no producer was launched, and no publication, lease or budget was changed. High owns Source29512 and the idle Native cold-first lane. This report establishes source contracts, not the identity or contents of the failed row.

Canonical owners are library/🏗️build/🕸️graph/🕰️generations (MJS, declaration and schema) and library/⚡️caching/💾️storage/🔒️enforcement/📦️budget/🕸️graph/📏️headroom/🧾️closures (worker and schema). Generated source-observation metadata retains file hashes only; it contains no source snapshot or cache content. Each file was individually stable across its read; this is not a sealed cross-file set or proof of bytes loaded by29512.

The generation policy declares index/frontier512MiB, fragments64MiB and raw manifests128MiB. The generic store compresses canonical JSON and checks only compressed length before writing. Its own index/frontier reader limits decompressed output to512MiB; fragment/global readers use64MiB. Consequently a highly compressible document can pass the writer yet exceed its own reader. Manifest publication separately checks its raw canonical UTF8 bytes and does not have this dimension mismatch. FactIndex arrays and Row.fact are not given a canonical-byte bound by their schema/interfaces.

Low’s earlier worker snapshot applied a shared expanded128MiB ceiling to index/frontier. Fresh physical source has since changed: the first observed worker SHA b436d28c… and later individually stable135c7b379eca… contain a separate generation branch using the generation512MiB ceiling; the current schema SHA e22765bbc302… has general expanded256MiB. No actor or29512 loaded-byte attribution is made. That branch still inflates the complete Buffer before feeding slices to a token scanner. Chunked token retention therefore does not make decompression memory chunk-bounded: the complete capped Buffer remains retained. The writer/own-reader mismatch remains regardless of the older128MiB consumer discrepancy.

## Recommended canonical design: bounded generation pages

Use one paged format for small and large generations; no dual-format or compatibility reader. Keep the existing logical aggregate index/frontier ceiling512MiB and all existing global proof, reference, path and depth ceilings. Give each independently compressed page a canonical and packed ceiling no larger than the existing64MiB fragment ceiling. A tiny authenticated root catalog names every page, its semantic role/range, packed digest, packed bytes, canonical bytes and counts. Root and page headers count toward actual budgets. Exact numeric page policy must be schema-first and shared by writer, own reader and closure reader; no implicit fallback to a larger allocation.

Page owners, rows and class associations explicitly, including high-fanout class memberships; merely putting an arbitrarily large class into a classes page is not bounded. Enforce complete nonoverlapping ordinal coverage and valid global row/owner references. Give an indivisible row/fact an explicit supported extent, or design a genuine framed streaming value port; never silently split an opaque fact into a different value or truncate it. Canonical UTF8 bytes, not JavaScript UTF16 string length, are the accounting unit.

The public GenerationStore currently exposes readIndex():FactIndex and readFrontier():Frontier, while GenerationFilePort.read returns one whole byte array. Change the actual ports to bounded page/selected-class cursors with real signal/progress and byte grants. Plan, patch/refine and holds must consume those ports; loading every page and rebuilding the entire object behind the same old API would leave the memory problem intact. Preserve interned row identity, exact consumer classes, stale-consumer selection and frontier diff semantics. All callers/declarations/schema must change together.

Selection is valid for a task’s authenticated owner/dependency closure. It cannot shorten the maintenance reachability proof: every page named by every retained generation root must be authenticated and scanned for Source/Cargo closure references. Root-to-page links must enter the actual closure inventory/retirement graph, including pages without matching references. Account each physical read and each expanded chunk under the existing Original loan before retaining it; keep bounded token carry, reference cardinality, nesting, UTF8 validation and result framing. Do not replace complete proof with a sample.

Publish immutable pages, then their root catalog, then the manifest, and finally the existing expected-generation CAS pointer. All required shape, totals, links and budgets must pass before the pointer changes. Cancellation/refusal keeps the prior generation current. Unreferenced partial writes remain owned retirement work; no inline private cleanup or forced lease. Digest/content validation remains complete.

## Smaller alternative: truthful whole-document agreement

If a bounded whole-document contract is intentionally retained, declare separate packed/canonical limits for every role and use the same closed budget descriptor at every producer and required reader. A writer must refuse canonical overflow before an unbounded serialization/compression allocation, not after publishing it. A bounded canonical encoder/decompressor counts actual emitted UTF8 bytes and preserves error identity/cancellation. A smaller authorized read loan may still refuse normally; sufficient authorized budget must make every admitted publication readable.

Under the earlier shared128MiB consumer contract, the unchanged common index/frontier document ceiling is the intersection128MiB; fragment64MiB is already lower. Raising that consumer to512MiB or raising the current general256MiB limit is not this alternative. Any role-specific512MiB interpretation now present in concurrent source must be reviewed as an explicit authority/memory contract, not assumed safe because an existing producer constant has that number. Early refusal makes the contract honest but does not prove it can represent this repository’s actual graph. The failed role and actual canonical size remain unknown, so this alternative alone is not an established unblock. Paging is the cleaner long-term choice.

## Schema-first tests before implementation

Authored inputs are e2e-generation-payload-contract.schema.json and e2e-generation-payload-contract-vectors.json. Nine policy cases cover exact/over shared128MiB and own512MiB boundaries plus the currently observed generation branch. Seven page cases use explicitly abstract counter units, not claims about encoded wire bytes. A Unicode case distinguishes the8-byte canonical UTF8 string from5 UTF16 units. These are design inputs, not executed production evidence.

1. Validate the closed fixture with Ajv; compare byte-admission predicates and page totals against independent SQLite CASE/SUM queries. Test role selection explicitly, never inferred from packed compression ratio.
2. Through the actual supported producer budget port, create small valid compressed documents using the existing system Brotli implementation. Exercise equality and one-byte overflow in packed, canonical and granted remaining bytes; verify current pointer/write count on refusal. Include a highly compressible expansion case without allocating512MiB test strings. This requires a real smaller Original grant, not a test-only policy escape hatch.
3. Compare complete decoded shape/reference results with JSON.parse plus the declared schema on bounded concrete fixtures. Split UTF8 code points, escapes, numbers and closure markers at every chunk boundary; test depth64/65, duplicate/unknown keys, unsafe indices, missing members, malformed/truncated JSON and bad UTF8. Frontier capturedAt is declared number, so the parser must match that contract instead of silently restricting it to integer.
4. Test cross-page high-fanout classes, shared rows, owner selection and stale propagation against existing factConsumers/frontier oracle behavior. Reject missing pages, wrong digests, inconsistent canonical counts and out-of-range global IDs without publishing.
5. Run real cancellation at each page/manifest/CAS boundary, progress callbacks, concurrency/CAS conflict and exact byte/physical-custody tests. Closure proof must find a required reference on the last page even when no task selects that owner.
6. After source/schema acceptance and the current whole boundary, use the existing owned generation/closure Source controls, then one materially changed formatter/recovery request with fresh source observations. No unchanged retry, cap increase, truncation or cache inspection is authorized by this design.


Input-only consistency check: all9 numerical policy vectors and7 abstract-page vectors match their declared arithmetic, and the Unicode canonical string has8 UTF8 bytes/5 UTF16 units. This pure check did not run Ajv, SQLite, the producer, the worker or any Source control.
