# Canonical IDML TypeScript Event Algebra

Added an actual TypeScript counterpart for the canonical native package mutation and sparse diff algebra. The runtime exports typed package admission, semantic member/package decisions, immutable central sparse application, exact snapshot differences, reverse diff and semantic operations, and sequential composition that preserves intermediate refusal checks. XML/package semantic validation comes from an owned IdmlAdmission port; no third-party runtime types or libraries enter the API. This is the cold reference algebra, not a claim of bounded asynchronous UI execution.

Tests were authored before implementation and reuse the language-neutral native package corpus. The nine witnesses now carry explicit accepted booleans; native and independent test routes consume them instead of deriving refusal intent from case names. Four extra hostile event streams cover invalid intermediate XML followed by a repair, missing removal, duplicate order and duplicate member patch.

Actual executed result: 9 semantic cases and 8 refusal decisions pass through production TypeScript with independent fast-xml-parser XML admission and fast-json-patch expected documents. The independent ZIP/XML corpus oracle also passes9cases,9archives,10XMLparts. Strict TypeScript compiler API checking of the actual179-file closure returns zero diagnostics. Independent GraphQL builds the combined four-facet schema, and protobufjs parses all four Protobuf facets. Type names IdmlPartPatch match the native owner.

Native declaration factory was corrected to bare_artifact_codec to request its actual optional-SQLite capability. The declaration and updated native regression source both pass the independent Rust grammar. Native compilation, native test execution, retained batch preparation and full Store replay remain unverified; see native-runner.md and idml-registration-review.md.
