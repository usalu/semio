# Genuine Drawing Consumer Audit Fixes

## Result

The four confirmed consumer audit findings are fixed in the shared Drawing planner and composition implementations. Native resumed label identity compares the Utf8Text trait-object data pointer using supported casts. Its phase-two copy quote now sums the original graph/text loan and up to four UTF-8 bytes. The loan receives a grant with copy bytes and source items reserved for that scalar; the composition preflight also covers the planner route item count plus the actual child item and scalar bytes. No exact quoted turn can borrow the original text and then discover that its copy has no remaining budget.

Native paid child failures in planner advance, text, and close now include the planner movement in both last_receipt and ValueError.retained_progress. Composition records that receipt before converting its error to String. Portable composition now records original planner receipts in a finally block, including actual paid vector failures. Portable text loans repeat the original parent snapshot/member check after funded preflight. Denied text grants do not observe member accessors.

The planner requires explicit resolution descriptors and composition verifies explicit resolution refusal; it never asserts fabricated encoded MIME bytes. Three member-reference qualifications and two authored artboards cover the current member-only contract; removed parent-side child-content mutator APIs are no longer imported or tested as live behavior.
