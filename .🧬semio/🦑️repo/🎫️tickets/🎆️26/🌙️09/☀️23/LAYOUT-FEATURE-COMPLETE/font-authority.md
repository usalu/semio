# Original Font Work Authority

The direct font owners now receive one original work ledger. Their actual paged reservations, contiguous body admissions, retained row writes and portable backing releases consume that ledger. Child advance calls use one source step and forward the same remaining authority; no production caller manufactures a grant from a child quote. The obsolete native reserve_slot API was removed after its consumers moved onto the funded owner.

## Contract and Ownership

The schema and neutral corpus are under framework text/font/🎟️work. Native FontWorkLedger accepts RetainedCloneGrant and exposes remaining(), receipt(), next_demand(), enter/exit, slot/push, contiguous/vec_slot/vec_push and retained copy preflight. Portable FontWorkLedger and FontBuffer mirror those logical operations. The original portable grant is captured by value. Held payload-copy claims share one original budget and produce a copied-byte receipt only when the row actually moves. Partial earlier effects remain in the receipt when a later operation refuses.

Base SFNT admission, cmap, kerning, catalogue, outlines, runs, paragraphs and the Unicode/OpenType child owners now append the ledger to their advance/step APIs. The Graph agent's font-unicode-shape-work.md records its child-specific work. Native fixed metadata remains inline. Known contiguous font/style bodies are admitted once under the original caller grant, then populated one row at a time. Native Layout begin_story_box retains scalar base style descriptors and empty owned buffers; it does not allocate by source style count. ready_one admits the stable font Vec and original job archive with caller authority. Native contour frame/point rewrites, paragraph sort/metric/line rewrites and bidi seen-row writes are priced before mutation.

Portable FontRetirementCursor.advance(grant, work) forwards the same original ledger through original children. FontBuffer retirement moves one retained row, then releases its admitted backing. FontRetirementCursor also exposes nextDemand() and terminalIsEmpty(). Active children enter fixed scalar close slots; cancellation does not append them to an unquoted archive. Successful outputs remain with their parent or caller until explicitly retired. Caller-provided ordinary arrays are borrowed and are not drained; owned FontBuffer bodies retain their original close authority. General non-font 2D retirement was not redirected through font code.

Native Layout uses advance_one_funded, advance_external_funded and advance_flow_funded. Each stores last_receipt and next demand on success and failure. The live phase 4 and export/Drawing consumers debit those actual receipts before propagating errors. A wholly blocked turn does not invent an item receipt. Flow projection preparation stores its receipt before returning errors.

Portable LayoutStoryFlowJob.advance(grant, work), LayoutAddressedFlowJob.advanceOne(work) and LayoutLinkLabelJob.advance(snapshot, grant, work) now forward original authority. Story regions and addressed plans use funded original buffers. Addressed head/range lookups use prepared ordinal rows instead of unquoted Maps; preparation fills a known admitted row extent one row per turn. Their retirement uses the direct font cursor. Every story turn and each addressed request has zero-item and zero-depth refusal checks in the neutral flow suite.

## Original Font Source Identity

The neutral same-length replacement law initially failed with a missing expected refusal. Admission now binds metadata to the exact original byte owner: native FontFace stores source_pointer and byte_length and exposes validate_source(bytes); portable FontFace retains readonly sourceBytes/sourceLength and validateFontSource(face). Base cmap, metrics, outline and kerning use those guards. Admission also binds its original source across progressive records. Equal byte content from a different owner does not inherit metadata authority. Graph is adding the same guard at its native and portable shape entry points. These guards establish source identity, not content hashing of an externally mutated owner; the byte source contract remains immutable.

## Native Evidence and Limits

Native paired ledger tests compare actual requested/released heap bytes with receipts, and native source replacement and lazy 4,097-style admission laws are authored. Owned font and shared Layout native fixtures now pass explicit original grants. Rust grammar parsing is available; native compilation and test execution are not. The authorized repo frontend remains stale/unavailable as recorded by the parent. No raw Cargo workaround was used. Nothing in this report is a native runtime pass.

Portable FontBuffer accounts retained scalar body capacity, moves and releases; it does not measure JavaScript VM object headers or garbage collection. Native controlled retirement and HeapWitness laws are the physical-allocation proof and remain unexecuted until the repo frontend works.

The explicit async loadBuiltinFontSources host I/O helper still uses its provider's whole-response bytes. Layout's headless/shared admission uses compiled first-party bytes and does not call that helper. This work does not establish a funded streaming host-I/O protocol. Authored style-id lookup in the shared native paragraph admission still compares source IDs during its existing incremental scan; it is not a proof of bounded scalar identifier comparisons. Those are separate concrete boundaries, not hidden by this authority work.

Final owned native grammar sweep: 21 Rust files, 0 grammar failures. This checks parsing only.

The source-identity addendum is complete: all ten native shape entry owners and ten portable shape entry owners now validate the admitted original font source before processing it. The fresh shape work driver passes 261-source strict checking, 74,594 original pipeline turns with 74,594 denied retries, 20 independent real-font feature plans (931 turns/denials), and the 9-turn/27-denial workspace close proof.
