# Layout Core

## Changes

The artifact now declares ten additional semantic mutations: paragraph style, parent page and spread insertion/removal; atomic page-spread assignment with retained position; layer reordering; parent-page content replacement; and whole-document import replacement. Complete row payloads retain all owned fields for undo. The central LayoutDiff applier remains the only state writer. Page-spread changes patch the page and both spread memberships atomically. Parent content replacement derives layer memberships, removes stale inherited overrides and restores them with its inverse. Referenced stories and image links reject deletion, including references in parent frames.

Sparse native diffs now distinguish absent optional patch members from explicit null clears through omission attributes and a present-null decoder. The independent serde testkit uses the same rule. Snapshot/full-row canonical JSON tree coverage supports retained semantic payloads without foreign runtime types.

Native page resolution now stably sorts inherited frames by parent layer order, then local frames by page layer order. Existing frame order stays stable within a layer, unknown layers trail, and inherited overrides remain applied. Therefore central ReorderLayer diffs affect scene paint and hit-test ordering.

## Validation

- 22 portable structural RFC 6902 witnesses verified with installed fast-json-patch 3.1.1. Native tests consume their before/mutation/after documents and assert application, immutable inputs, diff inverse, semantic inverse and text/binary round trips.
- 18 structural payload schema checks and 18 unknown-field refusals passed through installed Ajv. Mutation declarations and both persistent TypeScript test sources passed TypeScript compiler API syntax checks.
- All ten mutation metadata records match enum kind vocabulary and binary tags 49–58. The external oracle and mutation manifest validate against the repository registry schema.
- Three portable layer-order witnesses verified with installed lodash.sortBy 4.18.1, including reordered layers, stable within-layer ordering, inherited overrides and unknown-layer trailing behavior. Native tests assert the same projections.
- The shared 11-case diff-algebra corpus has an equivalent mounted Rust application/inverse/sparse-wire law test.
- Native Rust compilation and execution remain unverified: the available repo CLI test route returns silently without test evidence, and no working native executor was exposed. No native test success is claimed.
