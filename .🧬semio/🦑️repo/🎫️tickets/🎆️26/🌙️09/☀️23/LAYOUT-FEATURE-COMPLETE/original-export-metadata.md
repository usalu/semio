# Original Export Metadata

The Layout export metadata helper is mounted under the actual export tool job. It copies document/page authority one UTF8 byte per funded Native turn, emits the canonical revision as 64 lowercase hex bytes, and sanitizes at most 128 Unicode scalars into the filename before adding the real format extension. Six format MIME and binary encoding cases are explicit. Package filenames use the document name. Page and document IDs are bounded to 256 UTF8 bytes. Actual source pointer/length coordinates and revision bind the Native continuation.

Six owned Native byte buffers transfer their allocations into the prepared strings after UTF8 validation under the take quote. Cancellation closes one actual allocation per turn. The portable twin uses an explicit source port and logical ownership; it does not claim an actual Native issuer or registry. Its prepared owner retains and returns all logical capacity after output inspection.
