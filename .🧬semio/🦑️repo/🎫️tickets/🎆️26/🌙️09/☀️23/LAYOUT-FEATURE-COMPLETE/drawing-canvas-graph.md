# Layout Genuine Graph Consumer

## Result

The old inline Semio-event DrawingPlanCursor implementation was replaced in portable and native source. The portable cursor routes the original parent member through drawingReadAt and a mandatory supplied provider/address, then drives OriginalChildVectorPreparation using the remaining original grant. Actual registered Draw admission closes fully before any typed descriptor becomes available. The consumer borrows the complete authored graph, preserving seven node kinds, original paint sources, exact binary64 affine shear/reflection, authored text family/size, boolean references, trace intent, asset keys and original RGBA samples. Each descriptor, gradient stop, dash, reference, path segment, shape command, asset and sample consumes an original funded turn. Portable fixed backing uses explicit logical accounting; it does not claim JavaScript GC is physical native retirement.

Path and primitive-shape segments are consumed incrementally. Two-pass fitting obtains actual caller-supplied text extents. Canvas placement maps the complete authored viewport. Content fitting explicitly refuses unresolved boolean/tracing extents. Raster, boolean and trace descriptors produce explicit resolve primitives. Flattening composition rejects unsupported full paints or group compositing and raises a resolution-required error for raster/boolean/trace; it never silently drops those nodes or supplies fake MIME bytes. Scalar canvas publication now preserves binary64 colors/width, fill rule and cap/join. No Draw DocumentVectorJob or scalar-work-to-physical-grant adapter is used.

## Bound Host Contract

Portable DrawingPlanCursor constructor argument4 is DrawingSourceBinding {provider,address}; DrawingParagraphResources.bindingForSource must supply the actual original qualified member provider/address for each selected source. There is no global provider or source issuer fallback. Portable plans retain their original issued read until aliases and child custody close. Cancellation is beginClose/closeDemand/closeStep with the entire original VectorSceneGrant; release-only closeOne was removed.

Native DrawingPlanCursor stores only an original-funded PagedList of numeric graph routes and fixed traversal scalars. It stores no borrowed graph trait object or raw source pointer. Its next_demand(read,body), advance(read,grant), and text(read,index,grant) take a fresh borrowed ChildAdmissionRead obtained by its caller from the already-funded original qualified drawing_read_at. The caller must keep that provider loan alive while returned descriptors are in use. Every resumed graph/text loan goes through the real preparation owner and verifies the original source and paired registration. Native DrawingCompositionState.next_demand(snapshot,read,body) and advance(snapshot,read,grant) now thread that exact issued read. Native original text is dyn Utf8Text; composition copies one original chunk slice per funded turn. Retirement uses close_demand/close_step with full original grants and exact PagedList release operations.

Root owns the remaining live export host injection and operation-issued child read/custody. That path is incomplete; this slice does not claim the UI, exporters or entire Layout artifact are integrated or fully rendered. No native build/test was run because repo runner remains unavailable. Historical planner/page-canvas/composition tests and the planner runner now use actual authored Draw providers, member-only parents and current retirement contracts.
