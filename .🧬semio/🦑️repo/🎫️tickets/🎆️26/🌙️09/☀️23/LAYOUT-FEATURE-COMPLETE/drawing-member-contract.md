# Genuine Layout Drawing Member Contract

The editable child owner is the genuine s.draw.drawing@1/* dialect and DrawingSnapshot/DrawingMutation, not s.stdio.semio@v1/drawing. Its complete paths, gradient fills, locks, assets and rich property commands stay Drawing-owned.

## One Authority

Current Layout document/Page backgroundDrawing fields persist an opaque current-content Value. Registering a separate live child store while retaining this as the renderer/export/JSON/SQLite source would create two authorities. The coherent target is a child reference plus explicit original genesis/envelope source, with actual live/replayed content borrowed from the framework ChildContentView/member read. Parent page/document source addresses select that same member edge. An immutable genesis source must never be presented as the edited head. Natural/composed exports must read the same source-qualified group that commits typed child mutations.

Document, page, escaped nested ownership and Unicode IDs are positive cases. Parent id/revision, owner, slot, child id, independent artifact id, full dialect, registered editor and command must all match. Substituting the STDIO neutral dialect for the richer Draw editor must refuse before a typed command is constructed. Exact original parent read, child read and command custody bind the continuation; changed source ownership refuses even if values look equal.

Qualification is a fixed-state bounded scalar cursor with real incoming retained grants. No source trees, paths or strings are cloned. A ready source stamp alone does not publish: the eventual generic child command route must carry it through original ChildEmitPreparation and revalidate against the actual store head immediately before aggregate admission.

## Concrete Existing Seams

- ArtifactEditor::Members defaults to NoMembers; Layout does not override it.
- ChildContentView already offers typed_read_at and borrowed reference_fields_at. It retains exact member snapshot reads and revisions across undo/redo and group publication.
- Existing command owner addresses have Os/Plugin/App/Mode only. dispatch_command constructs A::Command and cannot construct a registered child's editor command.
- ChildEmitPreparation::of_owned preserves an actual typed mutation vector. ChildEmit metadata currently carries ownership edge and operations, but no expected original child revision/read stamp. A qualified command route must add/retain that authority explicitly; it cannot silently fill a newer child revision.
- SemioMembers::Drawing stores SemioDrawingMutation. It cannot host Draw editor mutations. A proper registered editor/member producer for DrawingSnapshot/DrawingMutation is required.
- EmbeddedChildCodecV1 currently has only cold validate and vector lower_step. Canonical incremental Drawing admission is still missing and the retained validator must consume a real owner facet, never a loop around cold validation.

## Original Member Source Custody Foundation

The framework child editor module now mounts a native borrowed `ChildEditorRead<S>`, metadata/admission `ChildEditorRegistration<S>`, and `ChildEditorSourceCustody<S>`. The parent ArtifactView requires a real bound operation/render context; the read derives ownership, dialect, revision and typed payload from the same ChildContentEntry. Custody first duplicates the actual erased snapshot read lease, then issues the retained clone source from that same typed SnapshotRead under the original incoming grant. It does not construct authority from a bare payload borrow. Alias and issuer birth demands are preflighted; refusal restores the same pending read. `opaque_source()` exposes the issued original to the new domain-neutral child admission port. The owner and registry aliases use controlled retirement. Native laws mount pointer-custody, source substitution, all-axis undergrants and exact HeapWitness birth/close checks; native execution is unavailable, so these laws are authored and grammar checked only.

## Genuine Draw Registration Milestone

Draw-owned `editor/🪆️child` now registers editPath, editFill and patchLayer with the exact genuine `DrawingSnapshot` type and `DRAWING_ADMITTER`. Native registration derives its editor identity using the same `surface_app_id(DRAWING_DIALECT, AppRole::Editor)` owner used by Editor::builder; portable registration uses the canonical surfaceAppId twin. Registrations preserve the actual admission producer identity. Native parity laws bind the real retained Draw command rosters. Registration declares metadata/admission/read custody; it does not yet execute commands or publish child mutations.

`drawing-member-check.mjs` reproduces the actual portable checks: 62 non-declaration source files strict checked with zero diagnostics; 17 source qualification cases, 4 accepted, 13 refused, 1,985 bounded turns, 5,994 denied currency probes, 51 cancellation cuts, 4 changed-original refusals; 3 genuine Draw registrations and 3 original-admitter identity observations. Ajv2020 validates the neutral fixtures and Lodash exact equality independently observes metadata. The registration test first failed on the missing implementation module before its implementation was mounted. Twelve owned/field-local native source files parse without grammar errors; all native runtime and compilation claims remain unverified.

The next coherent schema boundary should persist only `ArtifactChild<GenuineDrawing>` references in Layout Document/Page fields. Authored creation inputs carry a separate original typed Drawing genesis/envelope owner into aggregate child admission. Current head reads always come from the live/replayed member read; immutable genesis is never rendered as the current head. ReplaceDocument must either carry an original composed child bundle or refer only to already-issued members; a bare replacement snapshot with new child references cannot manufacture a source. Natural composed JSON/SQLite/pack reconstruction must gather the same original child group. Scene/export retain DrawingSourceAddress but borrow each typed source from that group. This requires coordinated schema, import, member-factory, group publication and UI changes before deleting current raw content across all consumers.

A member producer is also more than metadata registration: the actual MemberStoreProducer contract requires an original-funded SnapshotOpen operation and owner catalog. Existing SemioMembers only accepts SemioDrawingSnapshot/SemioDrawingMutation and is unusable for genuine Draw. The Draw host already owns specialized initialization/mutation arena infrastructure; it must be reused by a genuine Draw member producer rather than selecting the STDIO producer or cold-decoding a full child on a retained turn.
