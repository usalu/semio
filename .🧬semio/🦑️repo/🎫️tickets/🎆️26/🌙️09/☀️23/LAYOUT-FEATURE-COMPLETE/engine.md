# Layout Hover and Preview

## Runtime changes

- Pointer hit testing reads borrowed bounds and visibility. It visits local frames before inherited frames and resolves the topmost hit by layer rank and reverse frame order. It no longer clones or sorts the complete frame list. Inherited overrides supply the effective bounds and visibility.
- Scene visibility uses the actual owning layer. A hidden page layer stays independent of an inherited frame whose parent layer uses the same ID.
- Viewport culling uses the extents of the rotated frame. The rotated frame stays in preview when its unrotated rectangle starts outside the view.
- Deferred rendering starts document story-flow preparation only when the visible display list includes a deferred paragraph. Low zoom and an empty detailed viewport can publish immediately through the existing budgeted frame and output steps.
