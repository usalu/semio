# Borrowed IDML Package Admission

Canonical IDML now owns native and TypeScript admission cursors over ordered borrowed members. A replacement-byte view can reference a resolved original member without copying the package. Numeric open-address name metadata grows one explicitly funded 1 KiB page at a time, with a conservative 2 KiB initialization-copy quote. Maximum metadata is 128 pages at the 16,384-member envelope. Each page closes separately under its exact 1 KiB release quote. XML validation reuses fixed numeric metadata without allocating a DOM per member.

Paths, duplicate members, first mimetype bytes, directories, aggregate payload limits, every XML member, designmap root and DOMVersion are admitted. DOMVersion remains an original member span with a decoded length; a separate bounded decoder emits at most one decoded ASCII version byte per turn. It supports decimal/hexadecimal character references and source identity checks. The source remains immutable until closure. No external runtime libraries enter either implementation.

Canonical native IdmlPackage admission now runs the same cursor synchronously, then copies only its admitted version. It no longer constructs a DOM for every XML package member. Empty XML members and repeated trailing separators are refused consistently. The XML DOM reader remains available for callers explicitly requesting xml_part. TypeScript exports production IDML_ADMISSION; existing event algebra uses it by default, preserving explicit owned admission injection for independent tests. These synchronous facades are cold paths; retained callers must use the cursors and their own genuine source/copy/closure authority.

The schema and 12 portable package witnesses preceded implementation. Actual idml-admission-check.mjs execution passes strict target diagnostics 0 against 201 real source files, 12 package cases against independent fflate ZIP roundtrip and Saxes XML parsing, 2,051 total members, four work grants, four cancellation cuts, replacement designmap version, underfunded copy/allocation/release, and exact metadata closure. Valid package cases additionally run the real default typed mutation, application and inverse with no caller XML engine; resulting packages agree with the independent oracle. The admitted version decoder runs at all four grants. Compiler outputs self-clean inside the ticket.

Native source and two admission laws are grammar-clean. Native laws cover portable/cold agreement, paged closure, underfunding, cancellation and replacement views, but native build/runtime remain unverified through the authorized repo frontend.

RetainedMutation, RetainedDiff and the semantic issuer factory remain unfinished. A synchronous wrapper repeatedly calling an incremental cursor is not funded retained publication. The original source aliases, central preflight, inverse custody, staged sparse fields and exact issuer retirement still require explicit protocol integration.
