## Exact Controlled Hook Repair Contract

The new nullable helper's ordinary and serde semantics are already correct: a supplied null becomes Some(None), absence defaults to None. Preserve those helpers. Add a controlled helper with the signature fn deserialize_double_option_controlled<T: FromValue>(value: &DslValue, control: &mut NativeDecodeControl<'_>) -> Result<Option<Option<T>>, ValueError>, delegating to <Option<T> as FromValue>::from_value_controlled(value, control).map(Some). Supply a controlled missing-field hook returning the admitted <Option<Option<T>> as FromValue>::default_value_controlled(control), so absence stays None rather than Some(None). Supply an explicit retire_with function which delegates to <Option<Option<T>> as FromValue>::retire_decoded. Name all three on each custom field, alongside the existing ordinary deserialize_with. Field retirement is required even when a custom controlled constructor exists because the derive checks retire_with first.

Primary repository patterns: [CustomControlledDefault](C:/git/semio/🧰️framework/🔨️modules/🌱️value/🔁️codec/🧪️tests/🛬️controlled/🦀️.rs:88) names deserialize_with, deserialize_controlled_with, default_controlled and retire_with together; its helper definitions immediately above demonstrate controlled allocation/default admission. [Converted](C:/git/semio/🧰️framework/🔨️modules/🌱️value/🔁️codec/🧪️tests/🛬️controlled/🦀️.rs:268) demonstrates matching ordinary/controlled conversion and explicit retirement. These are hook-contract examples, not nullable-specific helpers. The existing [deserialize_double_option_serde](C:/git/semio/✏️s/🔌️plugins/📏️layout/🗿️artifacts/📏️layout/🏅️standards/🔖️1/🪆️subsets/✳️any/🧬️schema/🔺️diff/🦀️.rs:117) is the repository's correct nullable serde pattern: <Option<T> as Deserialize>::deserialize(deserializer).map(Some), paired with serde(default, skip_serializing_if = Option::is_none) at the call sites.
