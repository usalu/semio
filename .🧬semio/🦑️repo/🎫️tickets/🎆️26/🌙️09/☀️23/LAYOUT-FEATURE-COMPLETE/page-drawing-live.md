# Live Page Drawing Rendering Seam

The canonical Page child, Canvas placement and export schedule exist, but live assembly still only reads the document child. This is a source audit, not a native execution result.

`✏️editor/⚙️engine/🎬️scene/🧩️assemble-display-list/🦀️.rs::assemble_display_list_items` calls `background_scene(doc)` unconditionally before frame iteration. It eagerly builds raw strokes, labels and raster vectors, even when include_background=false. There is no selected Page source at this boundary. The local source_page_index currently supports deferred paragraph addresses only. Document strokes and labels are fitted to ink; placing a Page Canvas child through this helper would distort preserved viewport margins.

`scene/✍️drawing-labels-and-rasters::background_scene` calls model::background_drawing_scene(doc), cold-lowering one complete VectorScene and swallowing the error into None. Its text collector copies trimmed labels, caps them at32 and accumulates only group translation. Its raster collector constructs PNG data URLs with an8192-byte admission cap. `scene/🖌️drawing-strokes-and-paths` copies paths into f32 sampled points, caps paths/points at128, samples curves at fixed four steps, accumulates group translation, and clamps stroke widths. None of these helpers can represent the full new affine/Page Canvas contract.

The production retained caller is `✏️editor/🖼️canvas/🧵️paragraph-work/🦀️.rs::LayoutRenderWork`. prepare() captures immutable snapshot identity and optional transform-preview snapshot, calls build_deferred_display_list(), and retains DisplayList under Owners. advance() receives original StepContext, checks cancellation/yield and source identity, funds paged key/chunk reservations with cx.retained_grant(), consumes exact progress receipts and advances one phase. Owners already derives RetireOwned; adding the shared Drawing owner there must preserve controlled retirement, original preview source identity, and cancellation publication discipline. Existing prepare() is synchronous, so adding a new cold Page lower there is unsuitable.

The reusable composition owner currently lives at `✏️editor/⚙️engine/📤️export/🧵️drawing/🦀️.rs::ExportDrawingState` and its TypeScript twin. The type/path/turn visibility is pub(super), and it imports super::* plus OUTPUT_CHUNK_BYTES; moving it to the shared engine scene composition package requires explicit neutral imports/constants rather than an engine-to-export dependency cycle. It retains DrawingPlanCursor, normalized local paths, once-shaped labels through shared LayoutParagraphState, and bounded image payloads under original VectorSceneGrant/Receipt. It has controlled RetireOwned. Public methods are new(), has_active(), begin(source,placement,target), advance(snapshot,grant), last_receipt(), path(index), segment(label,glyph,at), glyph(), glyph_cluster(), glyph_style(). Turns are Progress, Path(index), Glyph(label,glyph,paint,affine), Image(local rectangle,affine,owned proxy), Done. Each image payload moves once; label text is copied in funded bounded fragments, not per glyph.

Recommended retained live sequence: white page background, Document/Content, Page(index)/Canvas, then ordered frames and chrome. Retain the one shared composition owner in LayoutRenderWork, advance it using original grants, debit last_receipt on every return including failure, and publish each local path/glyph/image with its full affine. Keep Page Canvas measurement traversal because label shaping happens on MeasureText before emission, even though the viewport determines fit. Add the active-page ordinal as retained scalar input, and preserve placed Drawing frame Document/Content semantics. Existing StackPiece display structures have no general affine path shape, so a retained primitive publication branch is needed rather than lossy conversion to DisplayStroke. Hit testing can continue to treat page ink as page background; explicit editable-child interaction remains a separate command/selection concern.

Root owns live integration after this audit; Core owns the retained live caller and font/shared paragraph changes. No source was edited for this audit.
