# Export Physical Retirement

Manual export close stages now quote retained capacity rather than initialized length. Strings and scalar vectors free the quoted allocation in one admitted turn. Empty strings/vectors with spare capacity remain owned until their full capacity is released. PDF item payloads release raster, proxy, mark or point backing before their outer row disappears; outer item/page/offset and ZIP backing allocations are quoted separately. Chunk close quotes the chunk's capacity and then its deque backing. terminal_is_empty() requires zero retained collection capacity.

JSON validation owns its private stack behind retirement_bytes/close_one; private JsonContainer types no longer cross the export interface. Typed JSON payload quotes use actual vector/String capacity and include the cursor stack backing. The currently used source-qualified ChildJsonCursor reports its own task/path capacities.

ChunkRope construction no longer preallocates the maximum output deque before the initiating turn. Output append, PDF planning vectors, offsets and encoder scratch allocations still need original-funded admission; this change does not claim complete production output allocation accounting. Old manually constructed TypedJson Drawing cache routes also remain for removal/convergence; normal document/Page JSON serialization uses the original Child cursor without a lowered scene cache.
