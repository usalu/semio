# Resumable Paragraph And Export Ownership

Added the framework font-run paragraph schema and six portable fixtures before the paragraph implementation. Native and TypeScript owners now resolve original style ranges one per turn, preserve whole-source Unicode/OpenType grouping, measure with metrics only, order logical metrics with bounded merge passes, plan legal wrap candidates, reshape each actual line with its captured paragraph direction, align/justify/tracking, and publish one glyph or outline segment per bounded turn. TypeScript line shaping borrows original strings through source ranges; it does not slice or encode complete line strings. Completed and partial children remain in controlled owners for retirement.

Executed proof: paragraph-check.mjs loads the actual TypeScript test module via the existing TypeScript compiler API and invokes its checks with real font and pinned Unicode bytes. Six cases across grants 1, 7 and 4096 pass: 18 runs, 18 independent OpenType/Sharp outline pixel comparisons, and 30 partial cancellation/one-unit close checks. Strict diagnostics report zero errors in the three owned runtime TS sources; the dependency-only diagnostic is the existing ImportMeta.dir platform declaration. The actual embedded Layout Sans font was also admitted and shaped (11 glyphs, 167 segments for Hello world). Native source parses have zero Rust grammar errors; native compilation and Rust tests remain unverified because the repo frontend is stale.

Layout export now plans immutable stories and unshaped drawing labels through ExportTextState. It consumes one display primitive or paragraph glyph per plan turn, preserves layer/parent order, feeds actual mapped outlines to SVG/PNG, and emits PDF glyph paths one segment per turn. Export jobs no longer create or drop a synchronous UI TextSystem/font atlas. The Paragraphs close stage admits and drains original quoted owned retirement, before the snapshot closes. Borrowed glyph_cluster metadata exposes exact original Unicode text, UTF-8 range and first-cluster glyph for the semantic PDF layer.

Source owners: framework font run/paragraph and its tests/schema; the existing Unicode normalizer source-range seam; UI FontHandle controlled leaf and its first-party value dependency; Layout scene source projection/font-byte seam/display ownership; Layout export paragraph-planning, planner/painter/PDF path integration and original close dispatch; new Layout paragraph integration regression. No new external runtime library, compatibility adapter or build-system refactor was introduced.

Remaining precision work is active, not claimed complete: temporary whitespace/hyphen/CJK legal-break tailoring must be replaced by proper Unicode16 UAX14 (see uax14-research.md); PDF image streaming/alpha and semantic text are assigned to the main agent; bounded embedded drawing projection is assigned separately. Synchronous interactive/native preview builders still exist for callers outside the export job. Native integration/runtime behavior remains unverified.

Unicode line breaking follow-up: the temporary paragraph opportunity policy is removed in both native and TypeScript. Proper admitted Unicode16 UAX14 owner is integrated into export paragraph planning. See [uax14.md](uax14.md): 16,672 official/independent cases; paragraph proof now eight cases,24 runs/pixels,40 partial cancellations. Native remains unverified.
