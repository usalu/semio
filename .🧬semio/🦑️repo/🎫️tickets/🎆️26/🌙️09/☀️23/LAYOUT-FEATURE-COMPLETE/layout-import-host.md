The selected cold Layout ArtifactComposition lives in rootIO/derived_composition. It directly called import_document(pdf,step,idml) with an always-true callback and returned only LayoutSnapshot. Old SVG/DXF/DWG leaves used the removed raw Drawing codec, then serialized an inline Semio child. No existing Layout InteractiveJob importer was found outside interchange. The clean cold result is LayoutImportSourcePlan: Document{document,drawing_sources} for already mapped parent drafts plus retained pending scenes, or External{format,source,name} for original SVG/DXF/DWG bytes before genuine target identity and mapping. External preserves actual bytes without a fabricated DrawingID or empty placeholder parent. It is analysis input, not successful persistent publication.

Root reserves rootIO cold helpers/composer/leaves, root public package facade, and the future selected import job/tool/UI routing. A true live import still needs original byte/parser/mapping grants, progress/cancellation, actual target identity, member preparation and atomic parent/birth publication. No cold plan or fabricated-grant loop will be called that job.

Validation owns the borrowed virtual-final graph abstraction. This is unresolved and no whole-snapshot clone is allowed.

Root cold inline constructors have now been removed. The three external format leaves expose analyze_source(bytes,name,actualControl), returning explicit External plans. The helper preserves all encoded bytes and cancellation checkpoints at4096-byte extents, without pretending to decode or create a child. The old snapshot-only composer refuses these six document import dialects with retained-preparation-required while the true live importer is being implemented; it cannot discard pending scenes or fabricate authority.
