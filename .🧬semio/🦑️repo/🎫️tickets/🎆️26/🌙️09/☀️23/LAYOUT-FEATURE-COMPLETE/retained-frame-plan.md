# Retained Frame Membership Plan

CreateFrame and DeleteFrame will use a dedicated decision owner with original RetainedCloneRef mutation/base bindings. Numeric cursors address original pages, frames, parents, layers, stories and links. Every key comparison yields after at most 256 UTF8 bytes. No cloned candidate Snapshot, concatenated frame array, cold graph validator or external runtime dependency is permitted.

Creation checks local duplicate identity and insertion index first, then bounded nonempty identity, global local-frame uniqueness, assigned-parent collision, fixed geometry/color/inset envelopes, effective local layer (including explicit override), story/link existence and outgoing thread compatibility. An outgoing target may have no existing predecessor. Since the admitted base graph has no dangling edges and the proposed source ID is globally new, the new edge cannot close a cycle through that source; self/missing targets are rejected by original global target lookup. Deletion scans local incoming edges, excluding the removed source itself. Parent content remains a separate graph.

Forward output will move the original prepared frame into a typed insertion. Layer override exchanges the authored original layer String into the retained command instead of dropping it. A vacant allocation-free Frame replaces the moved payload slot; remaining command fields stay under its factory retirement owner. Removal moves identifiers into typed removal headers.

Creation inverse prepares only original authored page/frame IDs. Deletion inverse prepares only the original affected Frame plus page ID, then moves the row into CreateFrame at its original ordinal. All aliases, partially prepared fields and inverse vectors require original grants to close.

Portable fixtures and an independent RFC6902 oracle will cover Rect/Text/Image insertion, effective layer override, global and parent collisions, referenced deletion, thread story/incoming constraints, ignored original layer storage and cancellation. Native compilation remains unavailable; authored native execution must be reported separately from actual portable evidence.
