# STEP Export Verification

Snapshot-only STEP export refuses a document or selected page that references an embedded Drawing before it emits a header. The editor requests each original member through its existing qualified child custody while the STEP encoder consumes it. It projects the document Drawing followed by the selected page Drawing, using typed geometry, bounded path batches, positioned text, and image asset names. The STEP session retires its traversal stack and generated entities on closure.

The Three.js oracle passed nine frame cases and ten Drawing transform and curve cases through the repository Bun tool. Updated Rust cases cover cold refusal, member order, independent AP214 readback, long path and text batches, and closure after cancellation or rejected filled paths. The first native IO check stopped at the dependency gate because `objc2 0.5.2` was absent from the offline cache.
