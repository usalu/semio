# Bounded Borrowed XML Validation

Canonical XML text snapshot now exposes native XmlValidationCursor and an owned TypeScript counterpart. The schema and first20portablewitnesses preceded implementation; the durable corpus now has32cases. The cursor retains fixed numeric source spans for256ancestors and1024attributes, with no DOM, member String, or input byte clone. Element and attribute events expose original byte spans; callers keep the source immutable until closure. One work unit consumes one source byte with at most16fixed-token byte lookups, or compares a pair of original name bytes. Long closing names and duplicate attribute comparisons pause between bytes. UTF8, XML1.0 names/scalars/references/comments/CDATA/PI/declarations/root uniqueness are checked; DTD is expressly refused by this owner policy. Input envelope8MiB, depth256, attributes1024. Birth initializes fixed metadata (no heap backing); a retained owner must still quote its own containing allocation.

Source: [W3C XML1.0 FifthEdition](https://www.w3.org/TR/xml/), well-formed documents, NameStartChar/NameChar, attributes/references/comments/PI. This is an IDML-compatible no-DTD syntax validator, not full XML/namespace/DTD validation or a DOM parser. Root attribute spans retain raw lexical references for the semantic consumer to decode.
