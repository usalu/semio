# Genuine Drawing Parent Edit Authority

Removed the Layout-owned `SetDrawingText` mutation and `drawingTexts`/`drawing_texts` diff lane. A reference-only Layout parent cannot construct a child text edit, replace child content behind a handle, or edit the actual Draw head by importing an unqualified parent snapshot. Actual editing remains assigned to the registered Draw command/member route; it is not yet end-to-end mounted.

The aggregate schema, native and portable declarations, exact nativeJSON parser, cold diff algebra, binary/text grammar, Proto and GraphQL descriptors, mutation fixtures and golden diffs now carry 58 Layout variants. Deleted the obsolete leaf and its wire witness; surviving explicit binary tags retain their actual owner-assigned numbers, and there is no reserved/accepted deleted command. Removed the duplicate inspector fields and patch-frame handler; the native patch-frame refusal law checks that the old parent field cannot publish a mutation.

Actual verification: `semantic-ts-check.mjs` reports 370 source files with zero strict diagnostics, 122 portable semantic cases, 51 golden cases, 58 variants, 40 exact IEEE word cases, and two child-authority refusals (unknown parent edit command and inline child-head input). Native grammar checked 9 touched sources with 0 errors. Native compilation and runtime remain unrun because the required repo frontend is unavailable. Root owns the remaining old PDF Drawing test callsite; Interchange removed retained-lane references independently.
