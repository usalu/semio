# Native Clipboard Retirement Drafts

## Mounted Clipboard Migration

The [native clipboard draft](🗑️generated/native-clipboard-retirement.patch) changes the production native hold and its existing language-neutral law. The mounted slot owns the original read or write job and passes its job, parameters and session slots into the same worker admission tested by `clipboard-ingress`. The original text backing is moved into the job. Cancellation can retire the admission, untransferred job, parameter alias, published session or checked-out outcome in its existing owner. The session and parameter alias returns post their reported Work and physical progress once. Checked-out outcomes use the caller-context acknowledgement and keep the outcome until it succeeds.

The cancellation alias output is stored in the mounted parameters before its admission result is propagated. An admission that declines before depositing an alias leaves the original job owned by the mounted slot. The production change is limited to the existing native configuration that excludes tests and testkit.

## Clipboard Fixture Schema

The existing native clipboard fixture supplies a `close` grant consumed by both Rust clipboard-ingress cases. Its strict schema previously rejected that field before the neutral law reached its ownership assertions. The [schema draft](🗑️generated/native-clipboard-close-schema.patch) requires the five exact fixture grant fields and continues to reject unknown keys both at the top level and inside the close policy.

## Born Session Regression

The [worker regression draft](🗑️generated/unpublished-worker-cancel-alias-law.patch) covers cancellation before the caller receives the born session. The test drives the existing private admission slot to its cancellation witness. It checks a denied turn consumes no Work or retained progress, then proves that a funded turn returns the alias without releasing heap backing while the cancelled root lives. The admission is fully retired and its caller output stays empty.

The live framework already handles the original alias in `OriginalWorkerJobAuthority::close_step`. The unpublished-session close delegates through that wrapper. The draft adds the regression to the existing Rust admission suite.
