# Host descriptor tool profile in the Play release

Play already uses a distinct release optimization policy for `semio-plugin-describe`. The repository calls it `release-descriptor` in its policy table and renders it into Cargo's canonical `--profile release` selection. There is no supported command-line selection for a faster descriptor profile within the same release. | Policy row | Target opt-level | Codegen units | LTO setting | Incremental |
| --- | ---: | ---: | --- | --- |
| `release-descriptor` | 3 | 16 | `false` | off |
| `release-native` | 3 | 1 | `thin` | off |
| `release-wasm` | `s` | 16 | `thin` | off |
| `prototype-descriptor` | 0 | 256 | `off` | on |

All four rows use debug level zero. There is also a `release-host` row with opt-level zero, 256 codegen units and incremental off. It becomes Cargo's `profile.release.build-override` for build-time dependency units such as build scripts and proc macros, separate from the emitter binary's target settings. The descriptor row's LTO value is boolean `false`, distinct from explicit `"off"`. ## Existing release path

- Play's `describe-tool` job is a host command. The pipeline resolves the job's profile to the Original release mode. The descriptor script accepts exactly one `--host-platform=<actual platform>` argument and chooses the producer `descriptor-emitter`. The driver also chooses that producer when giving the emitter's manifest its compiler input custody. The infrastructure derives the optimization selectors from the Original mode, actual compiler target and producer. Component passes independently select `wasm32-wasip2` and use the release WASM row. ## Effect on retries

The current producer already selects a retained per-product compiler lane keyed by the manifest, release mode, producer, arguments, and toolchain. Every attempt still plans and produces a completed observation under current source custody. Old release job tails show real edits of Rust input files; a faster profile would reduce time spent between checks without making a changed-source result acceptable. A separate authored experiment could compare changes confined to `release-descriptor`, keeping its producer, target, and verified output path. That would need to measure both compile time and the elapsed time for the emitter's owned interpreter to describe real release components. A cheaper compiler setting can make that interpreter slower. The source snapshot audit covers sharing one stable source revision across retries.
