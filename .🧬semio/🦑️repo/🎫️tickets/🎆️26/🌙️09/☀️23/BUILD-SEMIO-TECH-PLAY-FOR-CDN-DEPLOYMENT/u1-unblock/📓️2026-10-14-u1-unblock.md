# 🔓️ U1 Unblock (2026-10-14)

Lane U1. Goal: get the three fleet checks green so the blocked split lanes can compile again.

## Method

- Runner: `u1-unblock/chk.sh <sdk|kernel|hub|ktest>`. It goes through `🚦️cargo-slot.sh u1-<check>` with private `CARGO_TARGET_DIR` and `CARGO_BUILD_BUILD_DIR` under `.🧬semio/🦑️repo/⚡️cache/u1/{native,wasm}`, and passes `--keep-going --message-format=short`. Logs go to `🗑️generated/u1/`.
  - `sdk`: `cargo check --lib`, plugin SDK manifest, native.
  - `kernel`: `cargo check --lib`, os-kernel manifest, native.
  - `hub`: `cargo check --manifest-path 🌎️hub/Cargo.toml --workspace --exclude semio-hub --exclude semio-hub-auth-client --target wasm32-wasip2 --profile wasm-release`.
- Mtime gate: a Python edit helper refuses to touch any file modified less than 20 minutes ago (`time.time()-mtime>1200`). Files in an active edit were left alone and re-checked after a 10-minute wait.
- Fix rule: declare the dependency on the owning crate under its package name, use paths that name the owning crate, and put each impl next to the type or trait that owns it. No re-export shims and no compat aliases.
