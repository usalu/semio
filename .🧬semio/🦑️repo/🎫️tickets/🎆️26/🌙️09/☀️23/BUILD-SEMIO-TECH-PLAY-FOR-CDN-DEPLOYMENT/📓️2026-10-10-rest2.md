## Decisions

- Did not restructure named-variant enums (bim) and did not change the architect struct layout: the canonical derive gained flatten and named-variant support instead (main's decision, wire stays byte-identical).
- For the diff entry records without a sensible default row I removed `Default` rather than adding `Default` to deep row types (vdi3805, iso16757); for en1994 I added `Default` to the plain-data row types.
- Stopped at the lib release path per #45; no tests were run.
