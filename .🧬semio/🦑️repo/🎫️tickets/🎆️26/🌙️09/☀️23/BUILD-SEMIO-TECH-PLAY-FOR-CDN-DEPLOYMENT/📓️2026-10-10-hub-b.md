## Mechanics (differs from the brief)
- The hub crates are members of the HUB workspace, not the root workspace: `--manifest-path 🌎️hub/Cargo.toml -p semio-hub-<name>`. They have no `component-app-assembly` feature; the artifact dependencies already enable it in each hub `Cargo.toml` (`features = ["component-app-assembly"]`), and the hub crates enable `semio-framework-plugin/component-guest`. Default features (`plugin-entry`) are the release features.
- The hub crate root is either the composition `🦀️.rs` (puzzle, wfc, fem, gis, …) or `📦️packages/🦀️rust/🦀️.rs` which `#[path]`-includes the composition root (sourcing, layout, …).
- Gated + batched: one cargo with several `-p` and `--keep-going` (shared dependency compile, ~8 min cold, ~4-5 min warm). Logs: `.🧬semio/🦑️repo/⚡️cache/play-fleet/hub-b/*.log` (50 MB+ of warnings; always filter `: error`).
