## 4. Decisions

1. **Layers follow trait-impl ownership.** Codecs (`🚪️io/{📝️text,💾️binary}/<facet>`, `🪶️sqlite`) implement framework traits for the facet types, so they sit in the crate that owns the type: snapshot/diff codecs in `-model`, mutation codecs in `-mutations`, inference codecs in `-inferences`. The first table cut put all io in one crate (orphan rule); it was folded back with `🔙️merge-family.py` and re-cut.
2. **Schema descriptors get their own crate.** The facet descriptor embeds about 20 schema files, which alone breaks the 32-file limit of a model. `📇️descriptor-extract.py` moves it into `🧬️schema/📇️descriptor/` (crate `-descriptor`).
3. **The subset io root (composer, builders, conversions) lives in the subset/aggregator crate** with editor, viewer and examples.
4. **`semio_member_owner!` is split** into `semio_snapshot_retirement!` (model crate) and `semio_member_owner!` (mutations crate); all 18 subset roots updated.
5. **Upward edges were inverted in the domain:** ifc 2x3 SQLite subset validation now resolves `cv20`/`sav`/`cobie` through `validate_registered_snapshot_subset` (each subset implements `SnapshotSubsetValidator`), and extending subsets' composers moved from the owning subset's `io_registry` to the format root (`io_registry::subset_entries()`, `🎹️subset-composers.py`) for ifc, docx, xlsx and pptx.
6. **Barrels and shims removed** (`🧭️barrels.py` + `🧭️canonical-paths.py`): root `pub use`, `schema`/`engine` alias modules and standard-level `engine` facades of ifc, docx, xlsx and pptx. Root schema-id constants moved into the owning snapshot (`🪨️root-items.py`).
7. **pptx `xml-address` split in the domain:** revision-bound addresses and projections → model module `schema::xml_address`; plans that build `PptxMutation` stay in `mutations::xml_address`.
8. **Tests:** unit tests stay with their owner where the unit fits; fixture laws, mutation/model/SQLite laws that need several crates or exceed 32 files moved to `[[test]]` integration targets of the owning package or aggregator (35 targets, each measured).
9. **Crate roots** follow the E3b `✂️crate-cut.py` model: root at `<owner>/📦️packages/🦀️rust/🦀️.rs`, `[lib] path = "🦀️.rs"`, files mounted at unchanged module paths. This deviates from the brief's `path = "../../🦀️.rs"` and costs one file per unit.
10. **New taxonomy folders**: `🌀️entropy-internals/{🤝️dependence,📈️series,🗂️applied}/…` (27 extracted modules), `🧬️schema/📇️descriptor`, pptx `🧬️schema/🧭️xml-address`. The full taxonomy gate was not run (it does not finish under fleet load).

## 6. Incidents

- **Out-of-scope manifest write.** `🩺️fix-deps.py` added a dependency row to peer A's `semio-framework-os-pack` manifest. The row was reverted at once, and the peer's own concurrent `serde_json` move was left in place. The tool now refuses manifests outside `🗄️stdio/`.
- **Offset corruption in integration-test rewrites.** `🧪️integration-tests.py` used the census strip, which shortens raw strings by 2 bytes, and it applied nested-mount removals to already rewritten text. This corrupted 11 test files (ifc, docx, xlsx, pptx). All 11 were rebuilt from their step pre-images with `🩹️repair-integration.py`, and the reader check and corruption scan are now clean. The tool now uses the offset-preserving strip and one combined edit pass.
- **Dangling `#[cfg(test)]`.** A dangling `#[cfg(test)]` was left before region comments in two docx inference files and was repaired. The mount regex now tolerates comment lines.
- **Pre-existing break.** The semio text `🫴️receiving/🧪️tests` calls `crate::declaration`, which does not exist in the text crate. This was already broken before P8.
