## What was fixed (about 27 files in this session; the crate was uncompiled before)

1. `pack_json::Value`/`Object` API drift (no `is_object`/`is_array`/`keys`/`entry`/`IndexMut`, `Object::insert` takes `impl Into<String>`):
   - `is_object`/`is_array` -> `as_object().is_some()` / `as_array().is_some()` (import snapshot, kind catalogs).
   - `entry().or_insert_with` -> `contains_key` + `insert` / `get_mut` (import snapshot defaults, `puzzle2d_push_entity`).
   - `keys()` -> `iter()` (kit:in root key check).
   - Index assignment `v["k"] = x` (13 sites in editor root + recorder) -> new `pub fn set_member(&mut Value, &str, Value)` in the editor root (`✏️editor/🦀️.rs`, imported by the recorder).
   - Ambiguous `insert("k".into(), ..)` (E0283) -> `insert("k", ..)` (catalogue drag payload, recorder, `puzzle2d_placed_handles` patcher).
   - `DslValue <-> Value` bridges: `From<&Value> for DslValue` and `From<&DslValue> for Value` do not exist -> `pack_json::to_dsl_value` / `from_dsl_value` (brush candidates, force layout board snapshot, `command_from_action`, select tool scratch view).
2. `PagedUtf8` has no `as_str`: recorder selection tests now go through a private `named(&HashSet<&str>, &Text)` that reads the single page in place and copies only for a multi-page id (no per-entity allocation in the common case).
3. Recorder: calls to the nonexistent `Self::modified::<T>` (already wrong at HEAD) now call `Self::patched::<T>`; `place_nodes` converts the board `String` id to `Text`; select tool `ActorId` takes `SharedUtf8` (`.into()`).
4. Grant arguments on the new retained-clone APIs (copied from the migrated draw lookup, `🖍️draw/.../📸️snapshot/🔎️lookup`):
   - `RetainedCloneRef::bind(&mut slot, grant) -> Result<Option<RetainedCloneProgress>>`: every `x.bind(&mut self.f)?;` (36 sites in the lookup cursor and the flag/text/create/delete/move/connect `prepare`, `candidate`, `inverse`, `edge`, `literal-id-inverse` cursors) became `if let Some(progress) = x.bind(&mut self.f, grant)? { return Ok(<Step>::Pending(progress)) }` (`RetainedCloneStep::Progress` for the candidate/inverse cursors), so the authority-binding turn is charged.
   - `BoundedOrdCursor::compare(.., ord_grant, retirement_grant)` (4 sites) passes the turn grant and handles the new `BoundedOrdStep::Authority(progress)` arm as a pending turn.
5. `BoardFillSnapshotIngress` close demands: it only exposes the inherent `next_close_release_byte_demand() -> usize` (it has no copy/capacity/depth quotes; its `close_step` charges one item and release bytes). `FillCapture::close_demands` now quotes `RetirementDemand { release_bytes, depth: 1, ..Default }`, the same shape the fill placement already used a few lines below.
6. `Puzzle2dRedrawShape` (plain `Copy` record held in `Vec<Option<_>>` of the redraw work owners) is a retire leaf: `semio_framework_value::artifact_retire_leaf!(Puzzle2dRedrawShape)`.

## Decisions

- The `Value` mutation helper lives in the editor root and is public, not in pack-json: adding `IndexMut` to the framework `Value` would be a logic change in another scope (and `Index<&str>` deliberately returns `Null` for a missing key, so a mutable index has no sound analogue).
- No wire change anywhere; every `Value` rewrite preserves the object member order (`Object::insert` overwrites in place, appends otherwise, same as before).
