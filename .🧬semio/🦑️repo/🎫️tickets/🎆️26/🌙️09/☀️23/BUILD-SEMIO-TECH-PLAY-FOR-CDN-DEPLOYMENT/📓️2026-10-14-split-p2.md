## 2. Cut plan

### 2.1 Decisions

1. **Fixture vectors are data read at test runtime.** The 131 template-generated quintet tests (`applied`, `no-op`,
   `refused` variants, chosen by `🎯️outcome` `status`) become one data-driven law runner in the mutation dispatch
   crate that walks `🧪️tests/🧫️fixtures/🧬️mutations/<leaf>/<case>/` through `CARGO_MANIFEST_DIR` (the raster
   precedent). Same assertions, same messages per vector; the 681 fixtures leave every compilation unit.
2. **Mutation leaves are generic over the dispatch enum.** A leaf implements
   `MutationKind<RemodelingSnapshot, Op>` for every `Op: Mutation<RemodelingSnapshot, Diff = RemodelingDiff> + From<…>`
   naming exactly the leaves its inverse emits, and its builder returns `Op`. That removes the leaf ↔ enum cycle so
   the leaves can sit in group crates below the dispatch crate. Groups follow the snapshot sections, and every
   create/delete, add/remove pair stays inside one group.
3. **Domain records move into the snapshot facet** (`🧬️schema/📸️snapshot/🦀️.rs`), with `ordered_index`, the dialect and
   the document schema constant. The crate root keeps identity/definition/declaration glue only.
4. **Facet leaves are owned by their facet crate** (`ARTIFACT_LEAVES`/`SNAPSHOT_LEAVES` in the model, `DIFF_LEAVES` in the
   diff crate, `MUTATION_LEAVES` in the dispatch crate); the subset root assembles the descriptor.
5. **Engine topics split along their own regions** into sub-topic files registered in
   `members-of-members-of-engine`: mesh → `🔺️surface`, `🩹️repair`, `🗺️atlas` + pipeline; sfm → `📐️geometry` +
   incremental; video → `🎞️h264` + container/extract.
6. **Editor plumbing** (ui value/action helpers, payload decoding, reset effect, io ports) moves from the editor root into
   `✏️editor/🧰️kit/🦀️.rs` (registered editor member), so commands, modes and panels sit below the editor app.
7. **Synthetic-orbit frames** cannot share one unit (760 KB). They are split into four orbit-quarter data crates of nine
   views each; the example module assembles them in capture order. A runtime render was rejected: rendering 36 views
   costs seconds per activation, far beyond the 8 ms interactive step.
8. **Package-only group directories** host the group crates of flat leaf collections (`🧬️mutations/<group>`,
   `🎮️commands/<group>`), so no leaf directory moves and no fixture path changes.
9. Every crate keeps the monolith's module paths (`standards::v1::subsets::any::…`, `editor::remodeling::…`), so the cut is
   a crate-prefix rewrite (E3b `✂️crate-cut.py`). Re-export barrels (`crate::RemodelingSnapshot`, `crate::mutations::*`,
   `crate::algebra`, …) are canonicalised to owning modules first; no facade survives.
