# Bounded pending tables: audit for the parallel component phase

Context: the borrower table (`📓️2026-11-18-native-borrower-admission.md`) and the reservation `operate` table refused work under load after 2h. This audits every other bounded-pending refusal under `🧰️framework/🔨️modules/🏃️process`. Rule used: a refusal is converted when its table is shared by all ~73 components (or by every stage under a shared owner) and the limit is pure capacity; per-component or per-image tables with a small fixed fan-out, lifetime counters and failure-retention bounds stay refusals.
