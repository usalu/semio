# Unit Cache Storage Evidence

`native-play.sh` defaults `SEMIO_UNIT_CACHE` to `off`; an enabled run must override it. The latest existing `.cache/b/r/m/u/fill.jsonl` observation reports 33,943,281,664 bytes (31.61 GiB) for the wasm release profile of lane `pb370e7`, and 633,876,480 bytes (0.59 GiB) for that lane's host release profile. These are recorded lane profile sizes, not the unit-cache object total, a complete final attempt, or a prediction of unique objects. A current `df` snapshot reports 30 GiB free on the 70 GiB compiler image and 26 GiB free on its host volume. The live workload and shared fleet can change both.

The unit publisher reads each successful output into memory and places its bytes into the host-wide SHA-256 CAS. Existing objects deduplicate by content; a new object is written to a temporary file and renamed into the CAS, so this path does not hardlink or reflink the compiler's output into the store. Restore attempts a reflink and falls back to copying; it never shares an inode. The CAS defaults to a 32 GiB cap with high/low collection watermarks, while low-space admission and recovery can collect or refuse new writes. The compiler image separately has admission and reclamation and the unit-cache emergency threshold is 4 GiB. These are policies, not guaranteed available capacity or hit retention.

Enabling a cold cache can create host CAS bytes alongside existing image lane outputs. A unique object temporarily exists as a CAS temporary during publication; concurrent writers and fallback restores can raise transient disk and memory demand. Output deduplication and possible reflinks reduce the incremental physical total, while eviction reduces retained hits. Existing lane sizes cannot be added directly to project a physical peak because the image and host CAS have different filesystems and the ledger does not report unique CAS contents or sharing. No bounded existing ledger established current unit-attributable CAS occupancy or next-run peak, so neither is estimated. No build or Cargo process was run.
