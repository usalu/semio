# Preflight Generated Token Observer

The native boundary preflight calls `readRustSourceClosureV1` without an owner, so it refuses quoted generated include tokens. Real Cargo unit admission calls the same reader with the unit manifest directory and `generated: () => undefined`. The reader's tests explicitly show an emitted `quote!`/`include_str!` accepted with that owner and refused without it. The no-op callback identifies token output as belonging to the expanding consumer rather than counting it as an authored input of the generator; it is not itself a content observation. The source contract states compiler dep-info must qualify those generated inputs, and actual `OUT_DIR` and local macro expansion references still require compiler ownership.

This verifies the real path passes that particular scanner condition, not that the full release succeeds.
