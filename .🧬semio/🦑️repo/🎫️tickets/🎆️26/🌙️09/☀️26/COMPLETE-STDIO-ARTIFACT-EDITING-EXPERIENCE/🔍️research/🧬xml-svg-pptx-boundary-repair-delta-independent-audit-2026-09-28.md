### P1 — Boundary validation does not validate declarations or the UTF-8 encoding contract

The new decoder/builder gate calls only validate_xml_document_boundaries: [XML text decoder](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/🔨️modules/🧬️mutation-support/🦀️.rs:35), [XML binary decoder](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/🔨️modules/🧬️mutation-support/🦀️.rs:68), [XML builder](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/🦀️.rs:117). The validator checks only boundary node kinds and doctype position: [validator](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/📸️snapshot/🦀️.rs:373).

Declaration values are raw strings. Both state decoders reconstruct version and encoding without lexical validation: [text declaration decode](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/🔺️diff/🦀️.rs:966), [binary declaration decode](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/🔺️diff/🦀️.rs:1143). The checked writer then interpolates the encoding inside the chosen quote without escaping or validation: [writer](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/📸️snapshot/🦀️.rs:325). Moreover, import_utf8 rejects non-UTF-8 bytes and export_utf8 always emits String UTF-8 bytes: [import/export](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📰️xml/🏅️standards/🔖️1.0/🪆️subsets/🧱️base/🧬️schema/📸️snapshot/🦀️.rs:208). A declared non-UTF-8 encoding can therefore be retained while UTF-8 bytes are exported, and a matching quote in raw encoding text can forge or corrupt the declaration.

Use one complete XML-document validator at every snapshot/artifact/diff ingress and before every writer. It must validate declaration lexical values and quote compatibility. Because this artifact's import/export transport is UTF-8, it must reject a conflicting declared encoding or perform actual declared-byte encoding before publication. Apply it to XML and SVG. Cover structured text, pack, builder, raw artifact conversion, and diff application with a quote-bearing encoding plus a non-UTF-8 label and non-ASCII content.

Each schema therefore accepts a JSON-valid attribute with that property, while the shared typed parser only reconstructs name and value: [parser](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📽️pptx/🏅️standards/🔖️ecma-376/🪆️subsets/🧱️base/🧬️schema/📸️snapshot/🟦️.ts:71).
