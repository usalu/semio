## P1 — The public cursor contract does not enforce immutable source contents

`RetainedCloneCursor::advance` receives an ordinary `&T`, although its trait documentation promises an immutable owner ([`retained-clone/🦀️.rs:52-64`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:52)). Callers can safely mutate the owner between calls after each borrow ends. The guards only preserve wrapper address and shape:

- `StringCursor` records `&String` address and length, then accepts any same-length contents whose next offset remains a UTF-8 boundary ([`retained-clone/🦀️.rs:198-224`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:198)).
- `VecCursor`, `OptionCursor`, and `BoxCursor` use the same address/length-or-variant strategy ([`retained-clone/🦀️.rs:303-315`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:303), [`:448-462`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:448), [`:563-566`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:563)).
- Generated struct and enum cursors retain only the outer address ([`derive/retained-clone/🦀️.rs:209-218`](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/✨️derive/🧬️retained-clone/🦀️.rs:209), [`:379-388`](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/✨️derive/🧬️retained-clone/🦀️.rs:379)).
- Ordered-map clone and lookup have only map address/shape checks; the long-string comparator stores backing pointer and length but no immutable read witness ([`ordered-map/🦀️.rs:148-152`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:148), [`:436-446`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:436), [`:510-521`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:510)).

For example, after a two-byte page of `"abcd"` has copied `"ab"`, a safe equal-length replacement of both an already copied byte and an uncopied byte changes the source to `"zbyd"`. The next copy accepts the UTF-8 boundary and produces `"abyd"`, which is neither one retained input value nor a rejected mutation. The present regression only changes length or deliberately moves the next UTF-8 boundary ([`retained-clone tests:244-259`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🧪️tests/🔬️unit/🦀️.rs:244)).

Use the retained `SnapshotRead`/lease as the required `advance` input, or make this foundation owner-accepting so it retains a single immutable source before the first step. A pointer/length fingerprint cannot establish immutability. Add a language-neutral fixture and native laws for same-address, same-length edits to copied and uncopied regions, plus a lookup target changed between binary-search turns.

## P1 — Cancellation itself can traverse the whole active recursive chain without a grant

The depth limit applies to `advance`, but `BoxCursor::begin_close` immediately invokes `begin_close` on its child ([`retained-clone/🦀️.rs:625-636`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:625)). An active `Option<Box<RecursiveRecord>>` chain therefore recursively walks every live level before the first bounded `close_step`. Derived structs and enums expand this pattern over all field cursors ([`derive/retained-clone/🦀️.rs:238-247`](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/✨️derive/🧬️retained-clone/🦀️.rs:238), [`:404-413`](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/✨️derive/🧬️retained-clone/🦀️.rs:404)).

`begin_close` also synchronously boxes each retained field and grows `RetainedCloneClose::retirements` without a close grant ([`retained-clone/🦀️.rs:68-75`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:68)). The derived expansion calls those pushes as one unbounded sequence ([`derive/retained-clone/🦀️.rs:241-243`](/Users/ueli/Documents/semio/🧰️framework/🔨️modules/🌱️value/✨️derive/🧬️retained-clone/🦀️.rs:241)). The later `close_step` implementation is bounded ([`retirement/🦀️.rs:263-283`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/♻️retirement/🦀️.rs:263)); it cannot retroactively bound work already performed by `begin_close`.

The recursive cancellation law calls `begin_close` before it begins measuring one-item/two-byte close turns ([`retained-clone tests:339-357`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🧪️tests/🔬️unit/🦀️.rs:339)), so it misses this cost.

Make `begin_close` a constant-time state transition. Store an explicit, incrementally retired close frontier that admits and visits at most one child/field per `close_step`; give its own capacity rule rather than allowing a growing `Vec<Box<...>>` to allocate during cancellation. Add a deep-prefix cancellation law that counts the cancellation call itself and a wide derived-owner law.

## P1 — A cloned map can grow by one page only, then every later full-page insertion fails

The map clone allocates exactly one spare page-directory slot: `source.pages.len() + 1` ([`ordered-map/🦀️.rs:155-169`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:155)). On insertion into a full map, phase 1 consumes that spare by pushing the new page ([`ordered-map/🦀️.rs:614-633`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:614)). It never admits a replacement directory slot. After that new last page fills, the next page split reaches `pages.len() == pages.capacity()` and returns the error at [`ordered-map/🦀️.rs:616-618`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:616).

The current fixture starts with 70 entries and exercises only a single insertion, ending at 71 ([`ordered-map tests:95-154`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🧪️tests/🔬️unit/🦀️.rs:95)); it never consumes a newly added page and attempts another split. The public API does not encode a one-insertion lifetime, so ordinary repeated mutation gets a surprising hard failure.

Either make the owner/cursor explicitly one-edit-and-discard, or retain an explicitly budgeted directory-growth strategy. Growing `Vec<Vec<_>>` in place is insufficient because reallocation moves every directory entry; use a segmented directory or represent the directory relocation as resumable admitted work. Add the boundary law: begin at exactly `n * 16` entries, complete one page growth, fill the page, then insert once more and compare the final owner with `BTreeMap`.

## P2 — Insertion reports comparison scans as copied bytes

`RetainedCloneProgress` names its byte dimension `copied_bytes` ([`retained-clone/🦀️.rs:17-35`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:17)). Yet insert phase 0 converts `BoundedOrdProgress` directly into that copy progress ([`ordered-map/🦀️.rs:599-610`](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🗺️ordered-map/🦀️.rs:599)). A 64 KiB long-key comparison thus reports 64 KiB copied even though it only read compared bytes. This prevents callers from distinguishing comparison work from tuple moves/capacity admission and contradicts the design's independent clone, lookup, and insertion progress.

Give insertion an explicit progress type containing comparison, move/copy, and capacity fields; validate each against its corresponding grant. Keep the existing lookup cursor as the comparator oracle, but do not reinterpret its byte count as copy work.

## Root Follow-up on the Lease Repair

The new retained source owns a SnapshotRead witness, and binding retains its lease. However, the public `RetainedCloneRef::project_ref(discriminator, value: &U)` accepts a reference unrelated to that immutable owner. A caller can pass a local String, advance, mutate equal-length contents after the temporary borrow ends, then call project_ref again with the same lease, discriminator and address. This recreates the original torn-copy case despite the lease. Root requested that public projections use the source-derived closure API; arbitrary-reference construction must remain inaccessible outside the exclusive owner implementation. A regression must exercise this boundary rather than only two fields of a stable owner.
