# PNG Source Authority Frontier

Source inspection on October 3, 2026. The focused seven native region/runtime laws and shared plan laws establish bounded command publication, cancellation and stale-root protection only. They do not establish PNG fidelity or a complete primary editing experience.

The current `1.2/any` snapshot stores editable `bit_depth`, `color_type`, `interlace`, palette, transparency, background, typed ancillary data and chunk markers beside only RGBA8 pixels. The decoder admits packed grayscale/indexed and16bit input and maps samples through `scale_to_8`. The writer explicitly writes IHDR `[8,6,0,0,0]`, omits every tRNS marker, combines IDAT into one generated stream and chooses new filters. Thus save cannot preserve16bit sample words, duplicate palette index identity, original interlacing, filter choices or compressed IDAT boundaries. Header Details edits can disagree with emitted values. A grayscale or indexed bKGD representation is also emitted unchanged next to the forced RGBA IHDR; this needs an independent-file witness rather than relying on the current normalization comment.

The editor image window calls `encode_png(snapshot).ok().unwrap_or_default()` and base64-encodes the entire result during render. Encoding errors become empty images, and repeated renders repeat whole-raster work. These source facts prevent claiming the complete end-user goal even though command lifecycle tests pass.

The next PNG cut must choose one lossless persisted authority before adding further paint controls. A chunk/byte authority with checked semantic projections can retain exact source fields and compression choices; typed sample storage must preserve indexed identity, packed precision and16bit words rather than retaining a competing RGBA8 plane. Region actions must map through the selected storage profile. Format conversion must be an explicit reversible operation. Preview generation belongs to a cancellable retained producer and immutable cached result, with errors visible to the user.

Before enabling the replacement, add neutral external fixtures for duplicate palette entries, packed1/2/4bit samples, RGB/RGBA/gray16bit low-byte differences, tRNS/bKGD combinations, Adam7 and multiple IDAT chunks. Require exact no-op output where bytes remain authoritative, changed-range or declared conversion witnesses, independent PNG rendered/sample values, undo/save/reopen and registered cancel/stale laws. Preserve the current real16KiB retirement and128patch admission coverage. No production source changed and no new PNG fidelity native test was run during this inspection.
