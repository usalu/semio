# Frozen DOCX Canonical Route and XML Boundary Audit

Audited the current frozen sources only. No production or test files changed, and no Cargo command was run. This is a source audit, not a completeness or runtime claim.

## Actionable Finding

### P2 — Strict and transitional `set-page` admit the compact-owner limits too late

The base editor rejects a non-admitted snapshot, address, or text before it constructs and resolves `SetRunText`, and supplies its retained `DocxSetPageWork` to the native command lane ([base editor](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/🧱️base/✏️editor/🦀️.rs:41), [base work mount](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/🧱️base/✏️editor/🦀️.rs:262)). Strict and transitional construct and resolve the mutation without those admission predicates and omit the custom work mount ([strict helper](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/📏️strict/✏️editor/🦀️.rs:37), [strict mount](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/📏️strict/✏️editor/🦀️.rs:176), [transitional helper](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/🔄️transitional/✏️editor/🦀️.rs:37), [transitional mount](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/🔄️transitional/✏️editor/🦀️.rs:176)).

Both subsets do mount the base preparation route, so this is **not** a final history-admission bypass ([strict route](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/📏️strict/✏️editor/🦀️.rs:187), [transitional route](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/🔄️transitional/✏️editor/🦀️.rs:187)). The shared factory measures the snapshot and mutation before accepting the preparation owner ([factory begin](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/🗿️artifacts/📜️docx/🏅️standards/🔖️ecma-376/🪆️subsets/🧱️base/✏️editor/📬️preparation/🦀️.rs:169)). The observable source-level asymmetry remains: strict/transitional run address resolution and mutation preparation before the known compact envelope is checked, then use the generic bounded work default whose contract says artifact-sized reduction should override it ([default work](/Users/ueli/Documents/semio/✏️s/🔌️plugins/🗄️stdio/📇️registry/🧬️contract/✏️editing/🦀️.rs:787)).

Extract the base admission gate and `DocxSetPageWork` into the shared DOCX editor support used by base, strict, and transitional. Keep the current 2 KiB / 128-item / depth-32 limits; this finding is about consistent early rejection and retained native work, not the separately planned paged XML/OPC migration.
