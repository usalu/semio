## Blockers Found in the First Foundation Checkpoint

1. **Completion cannot bypass the byte budget.** [StringCursor completion](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:184) validates the entire accumulated owner using `String::from_utf8` and returns zero work. A multi-megabyte string therefore adds an unbounded final scan after paged copying. Copy valid UTF-8 boundary chunks into a String incrementally, retaining bounded progress and avoiding a final whole-buffer validation pass.
2. **Child completion is not parent completion.** [Option close](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:405), [ordered-map close](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:605), and generated struct/enum close methods forward a child's `Complete` while sibling cursors or the parent's retirement queue still hold owners. Parents must report `Pending` until their own terminal-empty witness holds. Existing [cancellation tests](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🧪️tests/🔬️unit/🦀️.rs:131) loop only on terminal state and do not assert the invariant `Complete => terminal_is_empty`; add that assertion.
3. **Zero-cost native values escape the item grant.** Generated unit/empty struct construction reports zero work. The [vector loop](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:273) then copies arbitrarily many such elements in one call because no grant is consumed. Charge element/field/assembly transitions independently of a child's payload work and cover a large vector of a derived unit record with a one-item grant.
4. **A source shape change can bypass admission or panic.** [String growth](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:182) can grow beyond its initial admitted buffer; [vector copy](/Users/ueli/Documents/semio/🧰️framework/🛍️products/💻️os/🔨️modules/🏪️store/🧬️retained-clone/🦀️.rs:275) compares its retained index with the new length and can index past a shortened source or grow the destination without capacity credits. The public cursor contract must bind to an immutable source owner or reject shape/identity changes before copying. Stable SnapshotRead is the intended preparation source, but the foundation API did not enforce that invariant.
5. **Recursive retirement must be lazy.** The initial RetireOwned derive eagerly called every child field's `retirement()` during creation. With derived recursive Box/Option records, that recursively traverses and allocates retirement state without a grant. Build deferred owner wrappers per field so traversal occurs in later bounded close steps; test a deep recursive value. Sol began correcting this during the review.
6. **Completed wrappers must not overwrite live output.** OptionCursor had no completed-output guard; repeated advance before take could drive the child again and replace an existing large owner. Define and test repeated advance, take, begin_close, and post-take semantics for every base/generated cursor. Generated records currently retain their terminal phase after take, so reuse must either be explicitly forbidden everywhere or reset safely everywhere.
