# Returned Read Witness Physical Custody

The mounted SnapshotReadReturn originally exposed completion of its registry generation but had no physical retirement facet. Clearing that witness drops its registry Arc; a strong-count observation cannot establish that another owner remains until the decrement. A final witness may therefore own both the original Arc allocation and the registry slot backing.

The new native facet moves the original witness into a fixed admitted cursor. The cursor declares the full original Arc frame release before any decrement, uses atomic Arc::into_inner, and retains a final original registry body inline. A non-final decrement reports zero heap release. A final decrement reports the actual original Arc frame release, then separately requests the original slot backing release. Zero items, insufficient release and depth refusal preserve original custody. Weak registry aliases and unresolved returned roots cannot be credited as closed; the cursor retains custody and refuses unresolved store-owned typed work.

The existing public terminal_is_empty still observes generation retirement. It is not a physical empty witness. Mounted children must use ControlledRetirement<SnapshotReadReturn> and its actual terminal state. UI and PNG agents have been instructed to adopt that boundary.

Neutral fixtures cover a live shared registry, sole final registry and alias-to-final transition. Native laws construct the actual SnapshotRead and return_to_registry_witness source, preserve the original slot pointer, and observe actual allocation/release on every granted and refused step. These tests are authored but not executed: the shared Kernel compilation gate still blocks this owner. This report does not claim that the host registry alias helper or every mounted source-return path has migrated.

## Concurrency Review and Strong Capability Repair

The UI execution review correctly identified that a weak_count pre-read cannot certify physical Arc backing release: another strong owner could create a Weak before returning its strong share. The original cursor is not an accepted concurrency gate. The Store registry now uses SnapshotReadRegistryHandle with its raw Arc confined to a separate child module. All actual registry carriers, issue/read witnesses, presence/history/ephemeral callers and authored fixtures have been updated to that firstparty handle. The public capability provides strong clone, original identity/equality, and atomic into_inner/try_unwrap, without exposing a Weak creator, raw Arc reference or raw ownership pointer. Original source state Arcs and their test Weak observers were preserved. The witness cursor uses the sealed strong handle and no longer relies on weak_count observations.

This source repair still needs compiler and concurrency-law replay. The prior actual native attempt stopped during test compilation on concurrent trait migrations (ArtifactEnvelopeFieldDecoder next_close_byte_demand and MemberFactory open_birth_bytes); no returned-witness native pass is claimed. The existing generic registry alias close helper still contains a pre-read strong-count return path. It must be migrated to original caller-funded custody before the whole host can be accepted; the new strong handle alone does not prove that helper safe.
