# Localized Label Physical Retirement

Draw retained commands retain history labels. Their existing fixed locale × terminology matrix owns Cow strings and needs a concrete physical retirement facet before the host can compose command-root retirement. This lane preserves borrowed text, moves each existing owned String without cloning, refuses unfunded release, and reports actual allocation capacity. Shared language-neutral fixtures describe borrowed, owned, Unicode, and spare-capacity empty cells. Native Serde decoding independently verifies the exact original label before retirement, and a test allocator measures actual births/releases under caller grants.
