## Host Integration Points

React shellActionPaneReducer's SET_ACTIVE_UTILITY equality currently treats an absent property as null and returns the original state when asked to establish an explicit clear (Shell:887). Even though writeUtilityRegister temporarily adds null to its live ref, the following render replaces that ref from the store. The future nullable contract must therefore check entry presence as well as value when deciding whether a store write is redundant. The current utility-assignment reducer law compares resolved values only and does not accept absence/null persistence; the initial-window corpus must use actual own-property assertions and the next rendered/guest-projected state.

React refreshUi computes sessionWindowInstances from the new layout before constructing the first ViewModel at ShellHost:6049–6088. Initial register admission must precede that ViewModel, including added window instances and scoped spawned programs; toolbar rendering at 12699/12735/12779 must read the same admitted register. A utilityGenerationFor read currently mints a register lazily, so admission cannot rely on the cell being uncreated: the authoritative absent-state check must use the scoped stored entry and session/window lifetime. Session switches also need to retire old register identities, not reuse a previous app's arm under a reused window key.

Native refresh_ui_rendered calls sync_dock and constructs live_view_state before guest window rendering, then derives utility nodes and refreshes palette bodies. Initial admission must precede that live_view_state as well. Native ShellState currently stores HashMap<String,String> and clears by removing the entry; unlike React's null-preserving local store, it does not distinguish deliberate clear from uninitialized state at all. Its close path removes per-window state at retire_closed_world3d_windows, which must continue to retire the actual window lifetime after explicit initialization is added. Both typed local host state and guest wire state therefore need the nullable resolved-map contract; changing only the helper that builds ViewModel is insufficient.
