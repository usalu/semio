# Returned Read Custody Review

Reviewed the coordinator-authored native store/read/return cursor before adopting it at GeometryOwner. The cursor preserves the exact registry Arc, waits for the exact generation witness, admits cursor creation and capacity/release demands, and retains a last registry body inline for its actual backing close. Geometry now retains the original witness through ControlledRetirement and treats its physical terminal state separately from generation completion. Native runtime is not claimed; the isolated store test is running in the coordinator lane.

A concurrent weak-alias release proof remains open. The cursor tests Arc::weak_count before Arc::into_inner, then credits the complete Arc frame whenever the original body moves out. An existing second strong alias can create a Weak after that observation and release its own strong alias before the cursor wins into_inner. The cursor then receives the body while the new Weak still retains the Arc allocation. Its release receipt would credit bytes that did not release. A sequential allocator witness does not cover this race. The coordinator was notified to use actual shared atomic authority or retain header custody across body extraction and account its final physical release separately.
