# End-User Vector Editing Acceptance

This goal requires usable visible editing controls and observed gestures, in addition to geometry/operation laws. The current creation palette and catalogue expose primitive shapes, paths, text, images, groups, Boolean layers and tracing. Registered selection arrangement covers group/ungroup, duplicate/delete, z-order, alignment and distribution in one undoable event. Registered path editing covers anchors/control handles, segment split/delete/line-cubic conversion, open/close/join and reverse. Fill edits cover solid/linear/radial paints, colours, opacity and stops. Their generic palette JSON argument contracts are agent-facing evidence; end-user accessibility must come from the inspector, canvas and dedicated controls, without requiring JSON entry.

Current geometric acceptance is in [canonical paint evidence](🎨️paint-topology-selection.md). Actual Draw registered-app tests exercise layer creation, marquee/lasso selection, transforms and history with real geometry completion. The full native production gate passed 582 laws; the added ellipse law separately passed its four rows under three grants. TypeScript full acceptance passed 627 laws and strict checks, including all existing PDF reference appearance checks. These are not proof of browser interaction, download, screen-reader or native pixel parity.

Required concrete journeys remain: create and rename/reorder/lock/hide/group artwork; select via click/marquee/lasso without selecting invisible cancelled paint; edit anchors and curve handles without exposing wire JSON; transform and arrange artwork; change paint/stroke/gradients; run Boolean and trace algorithms with progress/cancellation; immediate Undo/Redo; import supported artwork and download/reopen faithful SVG/PDF/PNG; explicit English/German controls and announcements; usable pane hit targets at desktop/mobile sizes; native canvas and input parity.

Current export action exposes PDF and SVG only. The PNG conversion serializer remains lossy and synchronously reduces authored Draw paints; faithful cooperative raster export is a concrete missing user capability. Shaped text/fonts and image-alpha selection also require their actual owned paint representation, rather than fallback bounds. Native floating palette footprint integration and complete first-click browser history remain pending as recorded in the existing reports.

Their controls dispatch structured editPath/editFill payloads internally; wire JSON is not the input required by those inspector rows. Their actual browser keyboard, focus, cancellation and gesture behaviour still needs verification after the rebuilt module is admitted.
