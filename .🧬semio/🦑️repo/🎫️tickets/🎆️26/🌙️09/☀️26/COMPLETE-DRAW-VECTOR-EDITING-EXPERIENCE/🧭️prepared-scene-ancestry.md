## Implemented Contract

Prepared nodes now capture `sourcePath`, a root-to-leaf authored index address of at most 32 unsigned 16-bit indices, and `lockedAncestors`, an unsigned 32-bit mask including each authored ancestor and the node itself. Ordinary groups participate regardless of compositing isolation. The address is meaningful only for the exact scene identity; it is not a persistent cross-revision reference.

Rust and TypeScript preparation carry these fields through the real Boolean and encoded-image trace pipeline. TypeScript owns an independent bounded address copy in each resolver output. Native address vectors retire as one bounded shallow owner; exact neutral retirement totals include one extra owner/work unit per node. The independent JSON ownership census includes that field. These bounded structural measures do not certify byte admission, allocator capacity or scalable UI publication.

Seven language-neutral ancestry cases cover ordinary groups, each lock level, both locks, hidden ancestors, resolved differences and traced Boolean operands under grants 1/7/4096. Thirteen address cases cover depth 32, unsigned bit 31/all bits and invalid indices, depth and lock masks. Three's actual scene hierarchy supplies an independent metadata oracle; Ajv validates completed plans. Native tests print actual source/address diagnostics and the measured node header separately from bounded dynamic path payloads.
