The current CombineBoolean command creates a separate root Boolean layer with selected layer IDs and an identity transform. It leaves those operands in their existing forest. The Boolean result transform is independently editable. Legacy document resolution applies child-local transforms, then the result layer transform during scene publication; it misses operand ancestors but does make result movement effective.

The bounded resolver should index nodes one at a time, traverse references iteratively with visiting/resolved states, and cache complete world-space fill geometry per dependency. A path uses the real PathBooleanJob with its full world matrix and authored fill rule; a group unions all resolved child world regions; a Boolean applies its operation to every resolved operand world region. Its raw result becomes local geometry through inverse(referenceTransform), and its cached world result becomes transform * inverse(referenceTransform) * rawWorld. This preserves result movement for further nested operands while retaining result-local paint in the published plan. Geometry/operand copying and both remapped output points must advance under grants; bound aggregate retained cache/output segments and total work, not only each child job. Empty groups and Boolean operand lists need explicit empty geometry semantics with operation validation. Never filter an empty child from intersection/difference. Stable immutable source ownership, sticky failures and cancellation must precede raster publication.

The prepared Boolean content will retain `referenceTransform`: the world matrix of the result layer's **parent** at preparation time. Path operands resolve to world geometry through all ancestors. Region operations consume complete world-space fills. Their raw world result is converted to the reference parent's coordinates, then published using the result layer's existing world matrix. Thus identity result transforms align with world operands, and edited result-local transforms remain effective rather than being cancelled by inversion of the result world matrix.

Nested Boolean operands cache geometry after that result transform; group operands union complete child world regions. Paint remains authored in the result's local coordinates. Singular reference space is an explicit geometry refusal unless the regularized region is empty; never silently omit nonempty operands. No authored document field or legacy fallback is required: the parent space is derived during the existing iterative forest traversal.

The prepared schema and Rust/TypeScript content now require this reference matrix. The original Boolean fixture carries identity reference space, and a seventeenth neutral document hand-authors a reflected/sheared parent and independently moved/sheared result. Both plan jobs copy the frame parent's matrix into the record. Reflected matrices normalize signed zeros in both implementations so language-neutral JSON fixtures remain canonical. Existing native fixture serialization includes the required reference field.
