# Command Admission Custody

## Implemented

The generic retained command payload now returns its original captured owners even when raw allocation is refused. `ArtifactRetainedCommandPayload::new` yields a payload with an explicit copy-only refusal discriminator; the job starts in its fault phase and retains command, snapshot, config, history, interaction state, hover, context, operation, completion and work. It does not manufacture a fault allocation or destructure into an error path that destroys those inputs.

All 134 constructor calls across 125 source files were updated in their existing call regions. Each replacement used a fresh source identity check; unrelated concurrent changes were preserved. There is no obsolete constructor alias. The language-neutral schema has ready, zero raw, zero work, and impossible allocation cases. A native allocator/Serde witness is authored, but has not executed.

## Verification Limits

Removed `SnapshotRetirementStep` imports in presence, interaction and extension retirement are among the current diagnostics. No native raw or new admission law executed. The previous raw source fixture passed one test with 12 assertions; that does not verify this new constructor.

The payload change does not repair pre-payload route or authority rejection, original command Box custody, or generic nonempty captured-owner retirement. Those original owners remain an explicit integration gap. Full native Draw and mounted end-user journeys remain unverified.
