# Draw PNG Execution

## Source and Publication

Owned and reserved command requests now receive a required genuine store SnapshotRead acquired at their four production dispatch constructors. Native PNG export checks its generation/revision at construction and each work turn. Its authoritative DocumentVectorJob and DocumentRasterJob retain that exact immutable read through preparation, trace, Boolean resolution, scene composition and output encoding; an Arc clone cannot substitute for the source authority.

The registered exportDocument factory admits PNG dimensions and transparency, renders authored paint through RasterSceneJob, composites a white background when requested, encodes first-party PNG bytes, segments base64 through ArtifactOutputChunks, seals output and returns CompleteDownload. PNG publishes no authored mutation. The direct synchronous command handler refuses invocation outside this owned route.

The existing host lifecycle commits its sealed download before Work.begin_close. Therefore completed typed children remain privately retained throughout normal work and close afterwards using the caller's actual item/copy/capacity/release/depth grants. Cancellation before committed completion withholds the download; cancellation after committed host publication cannot retract it. There is no claim that private physical close precedes host publication.

Normal native raster/vector/PNG stages do not self-fund deep retirement.
