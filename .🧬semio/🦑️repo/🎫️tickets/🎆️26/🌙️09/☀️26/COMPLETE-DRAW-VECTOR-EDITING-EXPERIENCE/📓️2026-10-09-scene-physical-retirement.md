# Physical Scene Plan Retirement

The coordinator replaced the shallow owner counter with ControlledRetirement<DocumentScenePlan>. The real public plan, node, content and group fields now derive RetireOwned; RasterSceneAsset manually retires its ID and genuine RasterLease. close_step exposes exact copy, capacity, release and depth demands. The temporary advance adapter funds each exact physical turn; its count now reflects actual cursor work, not shallow estimates, and must be removed after composed callers migrate.

A language-neutral schema and fixture contract covers empty, painted and externally borrowed raster plans. Native tests observe independent System allocator allocations and deallocations on the test thread, compare every step with its physical receipt and grant, refuse zero item grants without consuming owners, preserve external raster aliases, and check zero backing release when the terminal shell is destroyed.

These native scene tests are authored, not executed. Draw compilation currently stops in the shared OS kernel. No source-only physical correctness or native integration pass is claimed. The earlier TypeScript scene-retirement tests use a structural JS owner model and do not establish native physical allocation equivalence.
