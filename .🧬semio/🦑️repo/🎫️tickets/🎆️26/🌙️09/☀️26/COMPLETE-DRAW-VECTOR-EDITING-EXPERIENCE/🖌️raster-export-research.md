# Raster Export Investigation

Draw PNG export currently projects to the reduced `s.stdio.semio/v1/drawing` schema, losing gradients, fill rules, full affine shear and isolated group effects before rasterization. Its first-party PNG rasterizer provides solid nonzero fills, butt/miter strokes, PNG image sampling and a 4096-edge cap; text is unpainted. The recently repaired SVG export already bypasses this bridge, so the PNG leaf's claim that it uses the same projection as SVG is stale.

The framework's `pixels/compositing` module already has first-party Rust/TypeScript isolated RGBA blending, masks, sixteen blend modes and cancellable tiled jobs. The `framework/raster` module instead wraps Vello/wgpu and cannot execute in WASI Preview 2 components. A complete PNG fix must preserve Draw scene paint/geometry through a shared first-party vector raster contract and use the existing compositor, rather than continue dropping appearance in the semio bridge. Path coverage, full stroke outlines, gradient sampling, text shaping and image sampling all need that contract; no PNG production change has been made in this turn.

While tracing the formats, found a directly actionable PDF contract bug: authored blend names are camelCase (`colorDodge`, `colorBurn`, `hardLight`, `softLight`), while PDF accepted kebab-case names. The new strict PDF validation would reject those valid drawings, and older PDF code silently emitted Normal for them. Added all sixteen modes to the shared raster corpus for both group isolation and layer fill/stroke isolation, plus native PDF vocabulary assertions, before correcting the writer.

The preceding goal turn was progress: native PDF implementation and tests changed authoritative source. Handles 5483 (native) and 93519 (component) were polled and remain live this turn; no duplicate jobs were started.

## Stroke Region Plan — 2026-10-02

Previous continuation was progress: canonical shared 2D path-preparation implementations, neutral fixtures, strict TypeScript/native green suites and launch registrations changed authoritative source. Preview 75879 was polled and remains live. Draw's PNG projection remains unchanged. Complete stroke regions are the next prerequisite.

Represent a stroke as positively oriented polygons whose nonzero fill gives the union of segment bodies, outer joins and endpoint caps. This avoids winding cancellation for crossing/reversing centerlines and retains short-segment correctness by using round sectors rather than whole join circles. Miter joins respect an explicit limit. Dash preparation is resumable, restarts per contour, repeats odd arrays, preserves zero-length dots and offsets, and reconnects painted closed-contour seams without endpoint caps. Normalize consecutive duplicate source points incrementally but retain whether an authored zero-length segment exists. Round sectors adaptively subdivide with transformed chord-error bounds. Source normalization, dash pieces, primitives and round endpoints advance under work grants. Point and contour budgets prevent unbounded expansion; coverage contour limits must accommodate the generated primitive union. Neutral masks and an independent high-resolution SVG stroke oracle precede Rust/TypeScript implementations. Full Draw paint/scene/export lifecycle remains required.

Independent stroke comparisons found zero-gap cap overpainting, an almost-straight round join incorrectly wrapping to a full circle, and square dots missing their local tangent; the implementations were corrected and neutral regressions added. Extending the oracle to degenerate closed subpaths also proved they need the zero-length cap shape. The standards distinguish these from an isolated moveto: [SVG 1.1 stroke rules](https://www.w3.org/TR/SVG11/painting.html#StrokeProperty) exclude a moveto alone, but require round/square zero-length drawing/closed subpaths to paint. [SVG 2 cap rules](https://www.w3.org/TR/SVG2/painting.html#StrokeLinecapProperty) confirm both open and closed degenerates and tangent-oriented square caps. Sharp/librsvg paints an isolated moveto with square cap contrary to that rule; the SVG test oracle now removes only those nonpainting subpaths, and an independent native-canvas test validates their empty coverage. Degenerate closed paths remain in the oracle. This normalization is confined to tests, not a runtime compatibility layer.

The stroke-region job is now implemented and verified in Rust/TypeScript; see [stroke-region verification](🖊️stroke-regions.md). Independent comparisons cover 432 cases plus thirty-two shared masks. Coverage contour limits now accommodate bounded primitive unions, demonstrated by 9000 crossing segments. Paint, images/text, group compositing and responsive production Draw export remain the next required work. The production PNG bridge is still unchanged, so these green kernel suites do not establish end-user export completion.
