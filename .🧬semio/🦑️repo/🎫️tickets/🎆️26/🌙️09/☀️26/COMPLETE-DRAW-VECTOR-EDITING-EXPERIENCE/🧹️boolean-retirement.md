## Current Contract

This stage introduces consuming retirement of private Boolean arrangements with the shared first-party retirement controller. Genuine source operands move back to the caller, including nested source contours, and only successful completed path output is returned. The parent must retain or retire returned operands; this API does not pretend source ownership or allocator byte admission is solved. Work describes actual structural cleanup, not released bytes.

Inspection found native preparation synchronously discarding the entire nested input at its transition to indexing. Source inputs will instead remain owned until an explicit transfer. TypeScript ring heaps and the emitting cursor will use indices like Rust, removing deep ring aliases from flat heap storage. TypeScript parameter extraction will remove each parameter incrementally, matching native extraction rather than clearing a full set at once.

The neutral fixture covers fresh state, every public phase, successful hole geometry, separate regions, failure with retained intermediates, and previous eager cancellation. Tests are authored before the production API. JSON parser inventories independently count the fixed slots, two steps per edge owner, remaining edge parameters and nested collection entries. Existing independent polygon-clipping and Sharp coverage oracles validate algorithm output through the same full 2D test command.
