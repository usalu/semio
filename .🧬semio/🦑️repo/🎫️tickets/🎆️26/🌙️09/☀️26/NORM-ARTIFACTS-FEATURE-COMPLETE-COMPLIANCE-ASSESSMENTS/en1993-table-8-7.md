# EN 1993-1-9 Table 8.7 welded lattice nodes

C93-25 assesses a selected chord or brace. The four Table 8.7 details use 45 to 90 MPa for circular gap joints and 36 to 71 MPa for rectangular gap joints over t₀/tᵢ from 1 to 2. K overlap joints use 56 to 71 MPa and N overlap joints use 50 to 71 MPa over t₀/tᵢ from 1 to 1.4. The evaluator interpolates within each interval and uses the higher category at and above the upper threshold. Each row uses m = 5. The input damage-equivalent stress is referenced to two million cycles. [DIN EN 1993-1-9:2010-12 Table 8.7](https://www.niedersachsen.de/download/80810/nds._mbl._nr._37_2012_vom_30.10.2012_anlagenband_37i.pdf#page=284)

The check applies the table's wall, shape, width, angle, eccentricity, gap and overlap limits. For the pinned model it uses the shared Table 4.1 or 4.2 factor for the selected member and confirmed joint geometry. The frequent-load check uses the separately supplied direct stress range. Document the detail drawing and weld construction and assess the chord and every brace in separate cases. The implementation accepts the calculated stress ranges, β and γ as project inputs and does not solve the joint model or produce a load spectrum. [Tables 4.1–4.2 and §6.4](https://www.niedersachsen.de/download/80810/nds._mbl._nr._37_2012_vom_30.10.2012_anlagenband_37i.pdf#page=264)
