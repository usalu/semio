# EN 1993-1-9 Table 8.3 transverse butt welds

The C93-29 case covers the tabulated transverse butt welds. It applies the thickness factor to the rows requiring it and the additional eccentricity reduction for detail 17. Below 25 mm that reduction starts from a thickness factor of one. It checks the 10% or 20% weld convexity limit and applicable taper limits. Backing strips at exactly 10 mm are assessed under detail 16 because that row explicitly includes the boundary. The case requires confirmation of the selected row's other fabrication and inspection conditions. [DIN EN 1993-1-9 Table 8.3](https://www.niedersachsen.de/download/80810/nds._mbl._nr._37_2012_vom_30.10.2012_anlagenband_37i.pdf#page=278)

The intersecting-flange details have separate verified stress ranges along the weld and in the perpendicular continuous flange. For detail 19 the English table's category column refers to Table 8.4 detail 4. The published DIN table's category column refers to Table 8.5 detail 4 while the geometry description refers to Table 8.4 detail 4. The case requires an approved category reference for the weld direction before returning a numerical result. The perpendicular flange uses the applicable detail 4 or 5 of Table 8.4.
