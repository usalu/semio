# EN 1990 characteristic action values

E90.08 follows EN 1990:2002+A1:2005 §4.1.2. The operator declares the basis for permanent actions. A mean applies where the variation is small and the structure is insensitive to it. The selected two-value route determines the 5% and 95% fractiles from the confirmed Gaussian distribution or accepts the documented characteristic bounds. A variable action may use a prescribed value or a fractile of the confirmed Gumbel annual maxima distribution. The climatic default is 98%, with an explicit probability available for a different design basis. [§4.1.2](https://www.phd.eng.br/wp-content/uploads/2015/12/en.1990.2002.pdf)

The updated catalogue example declares both statistical bases. The reported values are forces. The production case and SciPy agreed on 21 scenarios, including small variations with different structure sensitivities, a signed mean, reversed supplied bounds, the climatic default, another reference probability, zero variation and incomplete inputs. The characteristic values are reported on the catalogue case. Using them in the project combination model still requires applying those values to the action definitions. Geotechnical and prestress characteristic values require their corresponding parts. The latest native app and browser staging are pending.
