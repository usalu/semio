## Blocking fix list

1. **`🗿️artifacts/🧱️din4108/…/✏️editor/🦀️.rs`** — `command_from_action` does not route `setField`, `insertItem`, `removeItem`, or `applyRemedy` (lines 136–160). **Fix:** replace the hand-written match with `semio_s_artifact_norm_contract::norm_command_from_action!(Din4108Command, crate::standards::v1::subsets::any::schema::snapshot::decode_din4108_snapshot_json)` (same pattern as the other fourteen families).

2. **`🗿️artifacts/🧱️din4108/…/✏️editor/🦀️.rs`** — `render` calls `inspection_panel::render` with only two arguments (line 183) but the panel requires `(host, selected_check_index, locale, controller_id)`. **Fix:** pass `view_state.locale` and `Some(CONTROLLER_ID)` like every other family's editor `render` dispatch.

3. **`🖥️app-surface/🦀️.rs`** — `evaluate` has no progress or cancellation for an expensive synchronous re-evaluation on every paint (`NormHost::from_artifact`, `⚖️compliance/🦀️.rs:871–873`; evaluate handler emits nothing, `…/🧮️evaluate/🦀️.rs:24–25`). **Fix:** implement a cancellable retained `evaluate` job (incremental/checkpoint-capable `ToolExecutionContract`, progress events, cooperative cancellation) that runs `NormFamily::evaluate` off the paint path; stop rejecting `checkpoint` in `create_job_from_wire_pages_with_payload` (`:1370–1371`) once checkpoints are supported.

4. **`🖥️app-surface/🦀️.rs`** — Results check rows omit subject label (`check_row_label` `:504–516`; subject only in viewer/inspection). **Fix:** include `check.subject.label.resolve(&protocol_locale)` (and optionally path) in the collapsed row label per spec checklist.

5. **`🖥️app-surface/🦀️.rs`** — `NormFieldMetaFn` documented as longest-prefix match (`:360`) but `field_label` only does exact `lookup(path)` (`:363–367`); no family wires the hook. **Fix:** implement longest-prefix / `[]`-wildcard lookup in `field_label` (supporting paths like `buildings[].storeys[].massKg` from en1998 metadata); add a shared adapter from family metadata tables; update each `📥️inputs/🦀️.rs` to pass `Some(family_meta_lookup)` (Wave C can fill tables — B2 must wire the call site and lookup semantics).
