# DIN V 18599-10 Potsdam climate

The default climate uses the twelve outdoor temperatures and horizontal irradiances from Potsdam, Region 4. The directional lookup covers eight compass sectors at 30°, 45°, 60° and 90°, plus the common horizontal series. The 2024 DIN interpretation takes the nearest sector, averages the adjacent values at a 22.5° boundary and interpolates linearly for intermediate tilts. The zone balance uses the resulting correction for transparent elements. With custom horizontal weather, it scales the recorded series using the Potsdam directional ratio. [DIN interpretation, Annex E](https://www.din.de/resource/blob/68624/9b6ade5098332800c2a14378d476985a/auslegungen-zu-din-v-18599-10-data.pdf)

The tabulated values are reproduced in the IBH research report. DIN Media's change notes for the 2016 and 2018 revisions list usage, table and editorial changes. The separately published 2018-method project assessment validates the horizontal and West 30° series by reproducing all twelve displayed PV yields to 0.01 kWh for its west-facing 10° array. [IBH report, Table 5-1, page 69](https://www.irbnet.de/daten/rswb/14049014899.pdf) · [DIN Media 2016 change notes](https://www.dinmedia.de/de/vornorm/din-v-18599-10/259376282) · [DIN Media 2018 change notes](https://www.dinmedia.de/de/vornorm/din-v-18599-10/293576742) · [Rheinhessen project, pages 59–60](https://landesverwaltung.vergabe.rlp.de/VMPSatellite/public/company/project/CXPDYDVYNFJ/de/documents/misc/P22%2B014_MAI%2B-%2BHWK%2BRheinhessen_Bericht%2Bzur%2BBauphysik_LP%2B4_Kubatur%2Bneu_240828.pdf%3Bjsessionid%3DOZEQfQvIoADJX9equT88a-4q4buF737dr49EHpUR.ev-web-ldi1)

The production Rust lookup passed 32 cases. The twelve worked PV yields also matched the independent SQLite interpolation and rounding. Five DSL examples contain the updated climate and its canonical child identifier, verified by reproducing the previous identifier and reapplying the same SHA-256 canonical JSON algorithm to the new data. The tool has yet to run the browser's native child transfer on these assets. The other climate regions and complete usage profile sets remain in DE-10.
