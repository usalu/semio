# EN 1993-1-9 Table 8.5 load-carrying welds

The C93-27 catalogue case classifies the load-carrying welded-joint details using the published weld geometry and stress locations. It distinguishes direct toe stress, transverse weld-root stress and longitudinal weld shear. For a partial-penetration joint it checks the toe in the plate and the weld throat. The separate throat checks include the combined utilization from Eq. (8.3). Lap joints include the separate weld shear assessment. The cover-plate and ring-flange details enforce their documented dimensional conditions and require confirmation of the applicable execution and inspection requirements. [DIN EN 1993-1-9 Table 8.5](https://www.niedersachsen.de/download/80810/nds._mbl._nr._37_2012_vom_30.10.2012_anlagenband_37i.pdf#page=281) · [EN 1993-1-9 §8](https://www.phd.eng.br/wp-content/uploads/2015/12/en.1993.1.9.2005-1.pdf)

The published lengths for the first two detail 1 categories both exclude exactly 50 mm. A case at this dimension requests a documented category. The starred details use the tabulated base categories. The higher-category alternative in §7.1 uses a different S–N curve and needs a separate assessment. Detail 10 directs users to the EN 1994-2 headed-stud check, which uses the nominal stud section and the 90 MPa reference category with slope 8. The input stress ranges come from the project analysis.
