## Digests

- GLB digests: unchanged. FBX: `🧫️fixtures/🧍️rigged-arm` changed in exactly three `sha256` values (rest, wave, wave-thermal; byte lengths, outlines, counts, notices identical). Cause: the one-implementation rule replaced the FBX Gauss-Jordan inverse by the kernel's adjugate `invert4` in `TransformLink` (last-bit differences of doubles). Verified by swapping the old inverse back (digests matched again). Keeping the FBX one instead would have changed the kernel's normals and inverse binds, which must stay byte-identical. Regenerated with `T/fbx-fixture-source.ts`; three `FBXLoader`, assimp and the owned second reader still pass. Staffage tests holding FBX digests of skinned assets (if any) need the same regeneration.
- Geometry: unchanged (positions, normals, indices of `tessellateSolid` identical; the only numeric path touched, `worldMatrices`, performs the same multiplications).
