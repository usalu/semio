### 1.1 `🌐️browser.🧪️tests.🧹️staging` (`/var` versus `/private/var`)
- Cause: `W/🐍️.py::_membership` resolves every base with `Path.resolve()` and returns real paths (correct on every platform, it is what makes a symlinked temp root or a Windows 8.3 name compare equal); the test compared those against the unresolved `tempfile` directory (`/var/folders/...` is a symlink to `/private/var/folders/...` on macOS), so `relative_to` raised. A test bug, not a code bug.
- Fix: the test resolves its root (`Path(directory).resolve()`) and starts the oracle through the same locator as the product (`BROWSER._repo()`, not a bare `repo`). `W/🧪️tests/🧹️staging/🐍️.py`. Result: `Ran 1 test ... OK`.

### 1.5 Cancellation test of the staffage consumer (flaky "under load")
- Cause: not load. `_thread.interrupt_main()` is a no-op when SIGINT is set to `SIG_IGN`, which is what every background job of a non-interactive shell (`cmd &`, `nohup`, many CI runners) starts with; verified with a three-line repro (`trap '' INT; python -c "..."` prints `no KeyboardInterrupt`). Interactive runs pass, my background suite runner failed. The 0.5 s timer additionally raced the exporter start (the `[pid ..]` lines that the test needs).
- Fix: the test installs `signal.default_int_handler` for the duration of the call (restored in `finally`) and interrupts when the exporter reports `cancelAfterFrames` frames (`🧍️staffage/🧫️fixtures/🎭️cast-cancellation/🔣️.json`, the same value the Bun test of the exporter cancels at) instead of after a timer: deterministic mid-export. `🎨️visuals/🧍️staffage/🧪️tests/🐍️.py`.
