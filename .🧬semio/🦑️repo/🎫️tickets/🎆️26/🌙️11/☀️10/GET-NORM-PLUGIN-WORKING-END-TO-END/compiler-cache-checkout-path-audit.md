# Compiler Cache Checkout Path Audit

The shared local Rust compiler cache restored an archive that contained an earlier checkout's manifest directory. The regression exercised `wrapRustcV1` through `repo test-file` with a small compiler fixture. The second checkout received bytes naming the first checkout even though it provided its own `CARGO_MANIFEST_DIR`. The path-independent control reused the same key across both checkouts.

The wrapper now scans compiled artifacts from remapped invocations before it publishes locally or assigns producer, dynamic extern, metadata interface or build-script executable identities. The bounded scanner checks 64 KiB chunks with overlap, recognizes resolved path spellings and Windows separators, and treats unreadable output as ineligible for publication. Artifacts containing a known root use a scoped local key. The wrapper checks the current scope on lookup and can still reuse path-independent output across checkouts. The existing fleet root hint protocol carries the recognized shared root kinds, and adoption stores the artifact under the consumer's scoped local key. A warm local hit can seed the matching rooted fleet key.

The compiler key adds one version component for invocations whose working directory is remapped. Old local entries lacked proof of any output scan and could also have been offered to the fleet from a warm hit. The new component excludes those entries on both tiers. Unremapped compiler units and build-script execution retain their key formats. Remapped units may incur a one-time miss, and the scanner adds bounded reads on new remapped outputs. Scoped local hits rescan their artifacts to recover the paths used by downstream identities.

The regression fixture records the observed cache outcomes across two simulated checkouts and verifies the producer key against the published key. An independent Python model consumes the same fixture and inspects the emitted archives. The focused `repo test-file` run passed 42 tests across the leak, interface, and local-key suites, including real rustc interface checks. The tests cover rooted fleet publication and restoration, same-checkout warm hits, clean cross-checkout hits, symlinks, split UTF-8 roots, Windows path spellings, unreadable outputs, and rekeying a memoized interface identity. The scanner covers recognizable path bytes in output. It cannot prove that a proc macro or compiler input did not use its path in a branch or transform it into bytes without a recognizable root.
