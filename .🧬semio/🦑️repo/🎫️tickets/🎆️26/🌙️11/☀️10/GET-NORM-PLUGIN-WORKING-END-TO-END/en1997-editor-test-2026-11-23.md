# EN 1997 editor integration test (2026-11-23)

## Cause
The `integration` target of `semio-s-artifact-norm-en1997-editor` mounts the unit tests as an external crate (`pub use semio_s_artifact_norm_en1997_editor::*`). Five errors:
1. `store::` / `protocol::` (3 errors): the lib declares `extern crate semio_os_kernel as store/protocol`, which is not visible in the separate test crate. The sibling families (en1990/92/95) run the same test file in-crate, where the aliases resolve.
2. `En1997PlayApp::examples()`: `examples` is a `semio_plugin::ArtifactEditor` trait method and the trait was not in scope.
3. `queries overflow the depth limit` (depth +130, layout of the async test blocks): every `context::dispatch/render` test awaits the whole generic async chain `dispatch_original_fixture_command` -> `dispatch_fixture_action` -> `PluginApp::handle_action/handle_command/render` (blanket `impl<D: PluginAppDelegate> PluginApp for D` over `VcsArtifactApp<EditorApp<..>>`). Layout of an async block requires the layout of every awaited future, so query depth grows with the chain length. The same chain overflows `semio-hub-norm` (`<impl PluginApp>::handle_command`).

Why the tests stay a separate target: moving them into the lib (as en1992 does) was tried and fails source admission (33 of 32 files, the closed per-crate boundary), so the separate `integration` target is the intended layout.

## Fix
- Unit test file: `store::os_store::test_support` -> `semio_os_kernel::os_store::test_support`, `protocol::OpText/OpBinary` -> `semio_os_kernel::OpText/OpBinary` (already a dev-dependency with the needed features), `En1997PlayApp::examples()` -> `<En1997PlayApp as semio_plugin::ArtifactEditor>::examples()`; `semio_s_artifact_norm_en1997_editor::` -> `crate::` in this and the assets and inspection test files.
- Depth limit, root fix instead of `recursion_limit`: every forwarded future is boxed so the layout query stops at a pointer:
  - `dyn_enum(delegate)` blanket forwarding in `🧰️framework/🔨️modules/🔀️dispatch/🦀️.rs` (`Box::pin` around the target call, docstring explains why).
  - fixture drivers in `artifact-app-laws` (`handle_action`, `handle_command`, both `render` awaits).
  Test-only drivers pay no production cost; the delegate box is one allocation per async plugin call.
- Lib root: the mojibake region markers of the unit-test region were replaced by the proper region heading; the case-edit mount stays in the lib.
