# Host configuration and framework job test migration

## 1. semio-plugin-host-configuration (green: 2 passed)
- Root cause of the unreceipted release: `built` can return `Ok(false)` after the constructor ran (the settle step may finish on a later turn). The host owner kept each constructed candidate (text, parser, selected, writer, mutation) in a per-call local, so the pending turn dropped it unreceipted (first seen as a 2-byte `String` for the empty projection, later a 32-byte `Vec`). Candidates now live resident in `Owners` (`born` helper, `selected` is `Option<Vec<usize>>`, `writer_born` flag) and the phase advances only once the birth settles.
- Floors removed: `testkit::grant(declaration, input_bytes)` quotes the grant from the settled construction turn quote over the owner's own demands (fixed state, one slice, one parsed node per declared item plus text); `testkit::closing(grant, demand)` quotes each closing turn from the refresh quote plus `close_demands()`. The `.max(64)`, `.max(32768)`, `retirement_demands(32768)`, `0..64` loops and 16 MiB grants are gone.
- The stray `semio_framework_trace` use at host `🦀️.rs:77` was my own temporary `[DEBUG]` line; it is removed (no `[DEBUG]` remains).
