# EN 1996 examples fix (2026-11-22)

## Root causes
1. compliant example: `CheckReport::complies()` is false whenever any check is `UnverifiedBasis` (unverified NDP basis), so the assertion `complies()` can never hold. Fixed the test to the sibling-family semantics (EN 1992): no `Fail`, at least one `Pass`.
2. multi-fail example: engine defect. For wall-weak the compression check at `uls-bad` had no remedy because every single-field solver failed. Thickening alone raises the slab eccentricity e_slab = (t - a)/2 for a fixed slab bearing depth a, so Phi_i stays 0 (e > t/2) up to t = 3 m; the bearing depth is already clamped at t, f_b/span/density/phi_inf cannot lift Phi_i from 0. Fix: the thickness remedy now falls back to a coupled solve (bearing depth follows thickness) and emits two remedies, thickness >= x and slab bearing depth >= x.
