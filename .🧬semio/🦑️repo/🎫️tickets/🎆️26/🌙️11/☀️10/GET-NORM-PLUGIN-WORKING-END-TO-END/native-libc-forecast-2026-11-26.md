# Native libc Compiler Forecast

The native EN 1990 replay build held `libc@libc|host|prototype|lib` at an estimated 5,711 MiB. The log reports that no comparable peak existed and shows the actual 2,458 MiB host admission margin. The forecast came from the cold source-size model. The libc 0.2.186 source directory contains 127,423 Rust lines across all supported operating systems and architectures. The unchanged formula, 614.4 MiB plus 40 MiB per thousand lines, predicts 5,711.32 MiB for that directory.

The same owned compilation later completed. The unit cache event for PID 18927 in lane `pebbc24`, key beginning `9cce56f0`, measured **149,176,320 resident bytes (142.27 MiB)**. The cold estimate was about 40 times that observation. Other local libc cache events record roughly 139–215 MiB, but the native launcher did not write its completed units to admission history. The latest exact compiler event is under `.cache/b/r/m/u/x/pebbc24.jsonl`; the held estimate begins at line 60115 of `coord-en1990-replay-geometry-retry.log`. The same invocation later held Tokio at approximately 4,762 MiB under the same policy.

The native launcher now records only verified local compiler successes, using the existing leased atomic history writer. Its separate history file is scoped to the compiler host OS and architecture within the local storage root. A forecast needs the original package, crate, target and profile identity plus the same compiler input digest. The digest includes the exact unit-cache key, which covers the toolchain, normalized Rust flags including cfg and features, source, externally named artifacts and build environment. It additionally includes the package name and version and the byte digests of externally named artifacts, even when cache lookup can use an interface digest. Incremental or unkeyed contexts do not supply local evidence. The cache wrapper confirms that the source and output checks completed and the key stayed unchanged before the broker records the sample. Cached, remote, failed, cancelled, unmeasured and unverified rows do not teach the forecast. Existing component history takes precedence and the cold model, memory floor, host margin and warden are unchanged.

Five targeted controlled tests passed with 62 assertions, including independent Ajv validation of the existing wire schema. The fixtures verify host, target, profile, crate, version, feature, optimization, toolchain and dependency-byte isolation, the incremental and unknown-input fallbacks, the prior history precedence, and the socket protocol's refusal to learn from an absent or mismatched verification. A separate wire check rendered keyed and unkeyed scheduler packets from the Rust format string and parsed both as JSON. Under the same accepted context, the observed libc peak would use the existing 256 MiB prediction floor. The queued EN 1990 run uses its previously loaded launcher and cannot write or consume this new history. The Rust scheduler itself was not rebuilt during this investigation.

No target-specific source pruning was used. Libc declares its platform module mounts inside a local `cfg_if!` expansion. The current graph-free source reader does not certify closure completeness through that macro, so pruning its filesystem tree would undercount unknown cases.

## Ordinary native launcher reachability

The subsequent fixture relocation run rebuilt the scheduler and executed through the real broker without producing a history file. The previous EN 1990 invocation also left no file. The shared Cargo launcher enables managed build-script caching while leaving cache-to-broker replay disabled. The initial learning hookup incorrectly used the replay-only broker selector to obtain the compiler facts. It therefore omitted the input key and never attempted the keyed verification, even for an otherwise eligible non-incremental unit.

The unit cache now obtains its live compiler broker independently from cache replay. Only a keyed verification or keyed advisory probe can use the ordinary compiler broker when replay is disabled. Cached outputs still require explicit replay opt-in. The focused broker test passed with 12 assertions and uses the real unit-cache client. It proves that keyed recall publishes the successful measurement, a keyed headroom probe reaches the broker, and cache replay still needs explicit opt-in.

The normal native prototype configuration inherits dev and deliberately enables incremental compilation for focused workspace units. Such units remain excluded. Cargo can still emit non-incremental registry dependency commands in prototype mode, and the wrapper also removes the incremental session for shared non-focused units when it uses the shared route. Eligibility follows the effective rustc command. Native release is non-incremental. The smallest real verification uses the ticket's dependency-free `semio-local-history-proof` release library, with a single compiler unit and the standard shared launcher. The expected receipt is a fresh `semio-local-history-proof@semio_local_history_proof|host|release|lib|<64-hex-input-digest>` row in the compiler host history. Isolated runs without the unit cache, cached or remote outputs, missing output or dep-info evidence, or an input key changed by final dependency verification leave no row.

## One-unit native proof

Run from the repository root:

```sh
repo cargo --store=shared --configuration=release --parallelism=1 -- build --offline --locked --manifest-path '.🧬semio/🦑️repo/🎫️tickets/🎆️26/🌙️11/☀️10/GET-NORM-PLUGIN-WORKING-END-TO-END/local-history-proof/Cargo.toml' --lib -p semio-local-history-proof
```

The shared launcher admitted one core and one fixture source unit. Cargo compiled the library and finished release in 11.43 seconds. The cache event in lane `p5bc55a` records a local miss and a peak resident size of 68,091,904 bytes. The matching durable row in `.cache/b/r/m/components/build-telemetry/units-darwin-arm64.jsonl` records the same **64.94 MiB** peak, 212 ms compiler wall time, 8,163 output bytes, and four source lines under `semio-local-history-proof@semio_local_history_proof|host|release|lib|2d0b5e3dbe0491d8236c37a2d4f472958b5726d5dd3814cd86535f466f69246f`. The capacity grant retired and the repo command exited 0 after its automatic disk recovery collector drained. The run used the default shared launcher with replay disabled.
