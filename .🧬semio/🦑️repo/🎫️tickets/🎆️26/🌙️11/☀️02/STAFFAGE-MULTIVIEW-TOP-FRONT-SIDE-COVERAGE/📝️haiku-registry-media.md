Generator and key, read from code:

- `🧍️staffage/🐍️.py` `cast_key()` (line 144): SHA-256 over (1) the whole manifest row as sorted JSON, (2) the catalog file bytes of the asset (LF-normalised), (3) the environment presets the cast names (only if it has `environment` or `timeline`), (4) `_source_digest()`: every file under `🔨️modules` and `🧬️schema` plus bundled print profiles. Truncated to 32 hex.
- **Viewpoint is in the key.** The row is hashed whole, so `viewpoint` is part of the digest. `cast_key` raises `ValueError` (line 147) if `viewpoint` is missing or not in `elevation|front|plan`.
- Exporter `🔨️modules/📤️export/🎭️cast/🟦️.ts` writes `viewpoint` into every index (line 188) and the schema requires it (`🧬️schema/🟦️.ts` line 81).
- The reader `_index` (line 471) rejects any index without a known `viewpoint`. So the 1,427 pre-migration indexes are unreadable by the current code.
- Consequences for regeneration:
  - Every key changes after the migration. The exporter source digest covers all `🔨️modules` and `🧬️schema` files, so any exporter edit invalidates all 1,576 keys.
  - The 88 manifest casts without `viewpoint` cannot be keyed at all. `_prune` (line 463) calls `cast_key` on every manifest cast, so it raises until those rows get a viewpoint.
  - The 87 stale cast ids are pruned after a successful render of the current manifest (`_prune` removes key folders no manifest cast maps to).
