# DSL field receiving

The block fixture stalled because the field test driver supplied one construction item per turn. The native record schema matcher may need three items in a nested turn to perform its metadata action, acknowledge it to the Source, and release the completion. An isolated build against the native dependencies reproduced the block test passing when only the nested item allowance increased.

The test driver now lends three construction items to nested advances. Local, take, and close turns still receive one item. Copy, allocation capacity, release, and depth still use the receiver’s quote. The existing refusal and cancellation assertions exercise the funded and denied paths.

The native field-receiving test suite passed all six tests, including block receiving, the canonical value type, and nested statement blocks. The test binary was rebuilt from the checked-in target source with the existing native Cargo dependency artifacts.
