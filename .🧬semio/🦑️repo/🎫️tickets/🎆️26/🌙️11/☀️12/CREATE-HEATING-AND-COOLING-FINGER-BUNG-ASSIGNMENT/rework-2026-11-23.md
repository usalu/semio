## CSV Format

The handed-out template (`energiebilanz.csv` in the assignment folder) is the unquoted file from the submission folder's `ki/input`: 60 rows `label;`, UTF-8 with BOM, CRLF. The reference output puts every field in double quotes and uses a decimal comma; the assignment asks for exactly that.

Open point: the template is unquoted while the reference output is quoted. The sheet follows the reference output. If submissions from plain Grasshopper panels without quotes should also count, item 1 of the submission list needs one more sentence.

## Framework Changes

- `semio-assignment.sty`: new key `cover-image-fit` (contain, cover, fill, none; default cover), used here with `contain`.
- `semio-window.sty`: `\semio_image_typeset:n` used `\str_case:VnTF` with a single trailing branch, so the fallback ran after every match and drew each image a second time. Changed to `\str_case:VnF`. This affects every `\SemioImage` in every Print document.
