# Agent Lane Retained-Fields Close

The V1-23 preview law passed the previous metadata-drop site and then timed out in mounted app close with a zero-byte, depth-two demand. The focused retained ELF reproduced that failure. Breakpoints at the address of the canonical tool catalog confirmed that the RetainedFields rung was repeatedly asking the canonical catalog to retire.

The first two shell fixture catalogs acquired and returned their mounted, boot and typed proof aliases. Their canonical allocations became physically unique and each completed about 3,100 bounded close calls. The later, failing agent fixture acquired three aliases and returned two. Its canonical catalog retained two strong references and issued only the depth-one waiting quote, which the retained-field rung nested to depth two. The ELF probes distinguished the failing allocation from the earlier completed catalog allocations.

The instance close selector previously exposed its pending original typed source only on the TypedOperations rung selected by other owners or as a fallback after RetainedFields. The original typed source can hold the admitted registration on a preview refusal or aborted handoff. The instance now selects its existing TypedOperations rung whenever RetainedFields would run while that source is pending. Its existing demand and retirement paths return the registration under the caller's actual grant, after which the original canonical catalog remains responsible for its physical close. The fixture's exact terminal-empty check remains intact.

The preview had successfully installed its request before this close. GDB captured the earlier typed refusal after 32,713 finish calls. The fixture exhausted its call count with `interactive-job.owner-refused`, whose underlying WorkLimit reported that the preview did not settle. A separate 128-call probe observed 127 original typed-source close calls, one residual retirement admission and zero mounted preview job advances. The last source quote repeated 40 copy bytes with depth three, which is the issued-alias election nested in the proof retirement. The caller still held 1,379,171 fuel, 16,727,766 retained items, 125,999,720 copy bytes, 250,300,629 capacity bytes, 533,865,798 release bytes and depth 4,096. Those counters remained fixed while the quote repeated.

The catalog alias cursor quoted one unit of Work at every frontier. Its shared alias election needs four, and controlled retirement clamps its child effect to the cursor quote. The cursor now forwards the selected ticket's exact Work and uses one unit for ticket admission and terminal box release. The initial physical quote uses the shared-ticket producer’s full constructor demand, and the close path posts the producer's actual receipt. The fixture’s work stock and call limit are unchanged.

The existing Bun AJV oracle passed 9 preview cases and 15 carriage cases with its new source-ordering check. Rust syntax parsing and `git diff --check` passed. The focused native failure was reproduced with the previous ELF. A rebuilt native result is pending.
