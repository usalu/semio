# Example switch Store publication

The native editor law switched to empty and Concrete Forest, then exhausted its 1,048,576-turn fixture bound during the Nakagin command. The same native binary also exercised the Capsule Dream asset path and exposed a separate missing page-grant renewal in the traced fixture. The observations below come from the Nakagin law, which runs through the plain fixture and renews its worker page grant every turn.

`editor-stack-sample.gdb` measures the mounted operation and the Store batch in the existing editor executable. The first census recorded 39,261 Store units and 38,880 calls to `ArtifactStore::advance_apply_batch_with_turn_ceiling` by unit 40,000. The return-site probe confirmed that the preceding Concrete Forest publication reached `AwaitingAck` at Store call 13,772. The next batch began with 395 mutation rows and reached Store call 30,000 in `Preparing`. It returned `PreparationProgress`, charged two Work units, and advanced the folded-item cursor from 23 at call 20,000 to 63 at call 30,000. The donated body still had 30,134 copy bytes, 16,777,216 capacity bytes, 1,048,576 release bytes, and depth 4,096 at both checkpoints.

`Puzzle5dStorePreparation` creates a separate immutable post root for each row. The play snapshot apply path copies the typed snapshot through `Arc::make_mut`, then the typed diff copies the root into a transactional candidate. The changed table is also copied by the list delta. The Store folds the new root into `ArtifactStoreBatchStage.post` and retires the preceding staged root before moving on to the next row. With flat `Vec` tables, intermediate cloning and retirement grow with the size of the scene during a switch. The 395-row Nakagin batch is already spending hundreds of calls per folded row at the measured checkpoint. The larger Capsule Dream asset contains 2,880 parts and 2,864 fasteners.

The receipt samples establish forward progress during the sampled portion of Nakagin. A later sample will determine whether the operation exhausts the fixture budget while still folding or reaches a separate refusal. The example switch currently keeps the schema and target volumes and uses one reversible edit for the changed scene fields. The history-free import follows a different path and does not meet the existing switch undo law.

The old operation reached 143 folded rows at 50,000 Store calls and exhausted the fixture while the overall operation was still active. The example producer now emits bounded positional scene-row splices for parts, fasteners and compatibility rows. It keeps scalar updates in the same gesture and can undo the splices in reverse order. The new native law passed forward and inverse application and the text and binary round trips. AJV validated the JSON payload and rejected overlong or mismatched inserts. SQLite and the independent Python implementation agreed with the committed ordered fixture.
