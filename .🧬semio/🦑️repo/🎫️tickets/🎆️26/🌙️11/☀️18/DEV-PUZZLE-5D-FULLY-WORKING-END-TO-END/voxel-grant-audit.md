# Voxel publication grant audit

The mounted typed operation passes its original turn ceiling separately from the current remaining grant. WindowConfig publication delegates both through `WindowConfigOwnerRegistry::advance`, the erased owner and concrete owner into `advance_apply_batch_with_turn_ceiling`. The store forwards the ceiling to the preparation; snapshot clone re-quotes at full copy budget when the current quote cannot fit, blocks when the full quote fits, and refuses an intrinsically oversized quote. Artifact, Config and Draft use the same store entry point. The tool-run path also passes a ceiling; the old store and preparation entry points deliberately use their supplied grant as ceiling. Other preparation implementations retain the default delegation.

The synthetic `snapshot_clone_does_not_refuse_a_spent_turn_remainder` law tests admitted, blocked, and refused decisions with a fixture. Its full-quote closure returns the same fixed demand, so it does not test the actual cursor changing its quote with body size, capacity or depth differences, native receipt preservation, registry delegation, or a subsequent funded turn. The World WindowConfig birth test checks the initial factory quote against policy, not the clone turn or publication. Verify that `original_turn_ceiling` is bounded by every applicable mounted policy limit; if the full original ceiling exceeds the policy that can actually reach the owner, a permanently impossible demand may otherwise repeatedly block. This is a verification concern, not a demonstrated failure.

If the live voxel test still stalls, run its single native test with symbols and the retained `voxel-advance.gdb`, `voxel-grant-probe.gdb`, and `voxel-quote.gdb` probes, updating addresses for the current binary. Break at the mounted publication call, registry and concrete delegation, and `snapshot_clone_turn_admitted`; inspect actual `grant`, `turn_ceiling`, `body`, current and re-quoted demands, phase, progress and ownership receipt over consecutive turns. Compare ceiling with mounted policy, and distinguish zero remaining budget from a full-turn impossibility. Continue through completion and original owner teardown; do not infer success from preparation birth alone.

This was a source audit; no tests or debugger runs were performed.
