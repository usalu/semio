## Fresh browser failure

The fresh diagnostic component exposed the semantic cause at epoch 7115. The instance's live cleanup pump exhausted its zero-progress credit. The callback reported 0 microseconds elapsed and an 8,000 microsecond ceiling. There was no separate receipt or context refusal.

The live maintenance classifier faults after 256 zero-progress or blocked callbacks. FEM 3D's mounted maintenance can retain a healthy app and referenced results while lacking a child to retire. The framework selects that callback based on session close emptiness. The FEM 3D retirement callback reports zero progress when its current shell has no retirement. A live owner waiting for another input therefore has the same status as an actual stall.

The ticket probe can record native cleanup observations when `SEMIO_ACTOR_REPLAY_CLEANUP=1`. It reads the checked-out worker's progress, the stall count and the generic maintenance ladder's last stage marker before reporting an actor refusal. A generic stage marker identifies a ladder visit. No marker can also mean the turn is settling an earlier worker outcome, so the surrounding epochs remain part of the evidence.

The 22:52 native replay reproduced the zero-progress fault from the complete browser input tape. Sequence 7 reached command ingress completion at epoch 5415. The actor refused epoch 6989 before the first recorded typed result ACK at epoch 7091. This establishes two distinct observations: the older browser capture refused during the terminal ACK poll, and the native baseline can exhaust the same credit before any result ACK. Native ingress completion confirms command admission and driving. It gives no evidence that the terminal page had settled.

A separate browser capture with response logging recorded the same page sequence. In this capture the terminal ACK was issued and refused at epoch 7207. [Browser ACK verifier](./native-actor/verify-renderer-acks.ts)
