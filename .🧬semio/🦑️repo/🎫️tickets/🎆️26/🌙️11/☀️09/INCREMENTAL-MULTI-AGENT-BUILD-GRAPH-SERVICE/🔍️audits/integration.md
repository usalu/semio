## Cut-over analysis (third request: steps a to d)

Nothing landed; finding that blocks (b) as specified:

- The "derived" facts that `settleSuspectsV1`, the generation row model and `invocation/memo` settle are answers of `deriveClosureFactV1` (`inference/🧭️script-inputs/🟨️.mjs:506`): (1) `walk` questions (bounded script-input module walks over roots, resources, selectors, views), (2) `program` questions (TypeScript programs of a project list), (3) `derive` recipes (derived walks). Their value is a walk answer plus the set of rows read.
- The published `🧮️derived-nodes` kinds (`manifest`, `project`, `named-input`, `target-inputs`, `action-key`, `closure`) compute glob rosters and file digests. `closure` there is a digest over named-input members, not a module-graph walk or a TypeScript program. Replacing the three question kinds by it would silently narrow what a closure depends on (imports, tsconfig resolution, generated imports), so a build could be wrongly considered up to date. It is not a drop-in.
- Needed from derived-dag before (b): node kinds `script-walk`, `ts-program` and `derived-walk` whose rules call the existing walkers through the world port, record every read as a raw read (file digest, glob roster, directory listing, resolution of bare specifiers through `node_modules`), and whose values equal `walkAnswerV1`/`programAnswerV1`/`derivedWalkAnswerV1`; plus an oracle test that the Python naive model equals them on the existing `✂️cutoff` and `🧠️memo` fixtures.
- Step (a) is cheap and independent: all inference reads go through `observedFs` (`👁️observation/🟨️.mjs`: 9 `readFileSync`, 2 `readdirSync` call sites in `🕸️graph`), a synchronous port. `WorldPortV1` of derived-dag and `openPinnedWorldV1` are asynchronous, so the seam must be a sync view over staged CAS files (`materializeRevisionV1` or `cas.link` paths) or the walkers must become async; that choice belongs to whoever owns the walkers' API. It is not done because without (b) the seam has no consumer (dead code).
- Consequence for (c) and (d): `derived` stays in `trustedKinds`' complement and the owner-discovery retry stays, since both are only removable after (b) and the pinned world.

Request filed for derived-dag in `📌️requests.md`.
