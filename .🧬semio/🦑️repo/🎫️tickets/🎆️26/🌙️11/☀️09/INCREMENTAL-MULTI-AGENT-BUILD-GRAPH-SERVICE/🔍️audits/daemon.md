# Lane `daemon`: per-host graph service

`R` = `BUILD/🏡️resident`. Status: protocol, endpoint, service, client, command and composition implemented and green; door and `repo run` cut-over left to `integration` (needs files outside this lane), see "Open".

## Delivered
- Schema (`R/🧬️schema/🔣️.json`, extended in place, closed documents): client frames `plan` (`PlanRequestV1`), `host-status`; service frames `plan-reply` (`PlanReplyV1`), `service-status` (`ServiceStatusV1`); `Hello.implementation`, `Welcome.features` (capability negotiation: a client must not send a frame the welcome does not list); `HostDescriptor`; `HostPolicy` (all bounds); progress phases `start`, `load`; EN+DE texts `host-*`. `Plan`/`PlanTask` are the inline `ScopedPlanV1` placeholder, `RevisionId`/`CasRef` placeholders for revision-cas.
- Endpoint `R/📨️protocol/📍️endpoint/🏠️host`: `hostEndpointsV1(implementationDigest)`; one socket (`$XDG_RUNTIME_DIR/semio-repo/<uid>/h-<tag>.sock`, named pipe on Windows) per user and implementation digest, descriptor, key, start lock, log.
- Service `R/🏛️service/🌐️host`: multiplexes `WorkspaceId`s (lazy open, validates root hashes to id, LRU bound `maximumWorkspaces`, idle close), capability check (`query` scope, worktree and agent caveats), fair admission through the existing governor (lane `agent/priority`), per-request cancellation (client `cancel` or disconnect aborts queued/running work), deadline, plan memo (bounded), large plans spill to a content-addressed, size-verified file (`CasRef`), stale-socket recovery, atomic descriptor, graceful drain, idle exit, memory bound (drop indexes, then exit with reason `memory` = code 75), retirement when a newer-digest sibling exists (after grace, no clients).
- Index pool `R/🏛️service/🌐️host/🧊️pool`: refcounted, byte and entry bounded, LRU, single-flight per content key, a load nobody waits for is aborted. Equal-content workspaces share one index; `ServiceStatusV1.indexBytes` counts it once.
- Planner port `R/🔌️ports/🧭️plan` (`identify?`, `load`, `plan`, injected `stale` hook for journal/memo): closure of requested targets in dependency order from the neutral graph.
- Client `R/🚪️client/🛰️plan`: `requestPlanV1` (auto start under an exclusive lock with stale-lock recovery, progress, cancellation via AbortSignal, retries lost connections, resolves spilled plans), `requestHostStatusV1`, `connectHostV1`.
- Command `repo service host start|status|stop|run` (`R/⌨️command/🌐️host`, dispatched from `runResidentCommandV1` when `options.host` is supplied), composition `R/🏗️composition/🌐️host` (`runHostForegroundV1`, detached `spawnHostServiceV1`), types `.d.mts`, exports in `R/🟨️.mjs`.
