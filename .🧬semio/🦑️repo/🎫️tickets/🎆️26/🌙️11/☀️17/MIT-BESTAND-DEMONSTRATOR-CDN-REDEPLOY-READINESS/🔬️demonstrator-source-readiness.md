# Demonstrator Source Readiness

The `opt-preview-demonstrator.log` records `original-turn.source-not-ready` for the localized pane UI, including `setContributions` errors for koordinator and aussuchen. Aggregator and verfolgen expose the same text in their English page snapshots. The English bearbeiten result is separate: its guest traps after a concrete `interactive-job.catalog-authority` rejection for `importModelFile`, with generated `Process3dModelImportJobFactory` versus registered `Process3dBoundedCommandJobFactory<true>` and `typed_join=false`. The generic source message does not establish that this separate fault caused other panes.

The 8781 overlay process serves a private copy of wmJDEkF's optimized core and copied component JS, but its probe directory contains no `🌉️bridge.js` or `🟨️.js`; the route falls back to the staged November 18 bridge and shim. That bridge is part of the actual actor path and is not current: its `exclusive` merely runs `sourceTail.then(run)`, whereas current `🌉️component-bridge-source/🟦️.ts` checks `nativeRefusalError(originalSource.nativeRefusal)` before each queued operation. Thus this probe combines a newer guest with an older actor bridge, and its result cannot establish behavior of a fully current browser release.

In the actual staged bridge, `OriginalOperationSource.issue()` emits this error when the source is closed, has an outstanding turn, has a refused receipt, or holds a producer or native refusal. It attaches the last three as `cause` (not closed/outstanding). The bridge's poll catches guest failures, retains a native failure, returns the original to its host shim, and can retain an unreturned producer report; `receiveOriginal` also holds native data if receipt conversion or validation fails. Host contribution refresh logs only `error.message`, and the available pane snapshots provide no original cause or earlier actor failure. It is therefore a subsequent readiness symptom, not a diagnosis of which branch or native function failed.

The next diagnostic should use a stable, identity-checked copy of this guest with the matching current, normally materialized bridge and host shim, and verify each served response rather than silently falling back. Capture the first failure at the actor boundary, including source state (`outstanding`, receipt, producer and native refusals), its original structured payload/cause and operation/epoch, before `setContributions` retries; correlate by actor activation and turn. Do not clear an outstanding turn or refusal to make the message disappear. The process catalog failure has its own precise typed-factory mismatch to investigate against the matching source and artifact.
