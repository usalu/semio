# Compact Release Build Headroom

The Demonstrator release driver captured 992 source units in run `wWRav8W`. Its second, physical disk admission forecast 10.28 GiB of writes plus a 2 GiB reserve. It had 7.95 GiB free and refused to compile, a shortfall of 4.32 GiB. The host later reported 13.64 GiB available after recorded owner and host cache collection, while the second Demonstrator attempt was building its host emitter.

## Demonstrator Retry

A supported shared `repo cargo` preliminary compile ran while the canonical host emitter rebuilt. It was cancelled when the emitter published at 21:59:06 UTC, and the canonical driver reported zero measured cache reuse. The canonical retry `w22Imi5` passed physical admission and built 1,045 Cargo units. It then stopped at the `semio-hub-demonstrator` library. Native unit admission classified it above the machine's memory and the fleet path reported `no-endpoint`. No guest linked, no browser artifact staged and no authored descriptor changed.

After both diagnostic consumers confirmed they had finished, the generated compact probe directory was retired. Available host space went from 4.84 to 5.57 GiB. The original static archive, historical Vite tree, strict diagnostic report and test logs were retained. Rust owner reclaim-wait then completed. It reduced the backing allocation from 46,506,426,368 to 27,647,729,664 bytes, returning about 17.56 GiB and bringing host availability to 23.10 GiB. The reclaim exited with `settled: false` because backing allocation had not reached its stable polling count. The retained Demonstrator compiler lane remained present. The mounted statfs value still read 6.01 GiB, while the host and backing allocation reported the recovered blocks.
