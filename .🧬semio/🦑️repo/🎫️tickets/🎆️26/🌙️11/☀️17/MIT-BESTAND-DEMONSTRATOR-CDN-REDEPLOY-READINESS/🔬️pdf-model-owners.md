# PDF model compile ownership

The Procedural browser release's `w1X9Raa` Cargo pass stopped in the PDF model with SIGTERM after the unit was measured at 7.47 GiB. The model compiled all typed PDF document families and their generated value conversion, native receiving and retirement implementations into one unit.

Four packages now compile the existing model sources at their authored paths. COS owns the object model, navigation and metadata cycle, including the handwritten octet and canonical JSON implementations. Graphics owns content, colour and XObjects. Fonts and pages are separate consumers, with annotations and forms in the page owner. The model facade re-exports the same declared surface, and the PDF workspace and 31 lock records carry all four owners. The existing COS fixture's manifest-relative path follows its new owner.

The managed Cargo metadata graph resolved all four owner edges and 24 direct facade dependents, including the PDF artifact, schema, snapshot, inference, diff, font, lexer and lift/lower packages. All 31 lock records were checked against Cargo's new owner adjacency. The focused native replay with pinned nightly and one retained dependency lane typechecked all four owners. Its consumer exercised the facade's existing module exports and proved canonical tree methods still resolve on the object, stream filter, and embedded file. The independently compiled public type-surface SHA-256 was `41f9a28e97618ec3ca3cb288d46f6e80459af76be67eb116c68af59688689f73`. The replay script is `pdf-model-verify.py`.

The native COS fixture passed through the managed Cargo entry point with `--locked --offline`. It checked 10 wire tags in both directions, 10 independent Serde JSON parity results and 20 preallocation refusals. The fresh Procedural `wruWBuc` unit graph resolved the four owners and facade as five distinct `wasm32-wasip2` units and passed source admission. Cargo emitted both the release `.rlib` and `.rmeta` for all four owners. Compilation stopped in Flow Host Read Authoring before the PDF facade published and before release staging.
