# Procedural Retry Source Witness

Read-only snapshot of `wONtSjE` held retry while its final compiler was running. From its actual retry Cargo artifact stream, 104 Flow graph, BREP, Job Context and UI rlib depfiles were present. Their 729 checksum rows normalized to 604 paths with no conflicting checksum/length pairs in this bounded selection. This is not a full receipt audit; depfiles and source files were observed live.

A first current-body SHA lookup found 11 paths without the current body in `cs`. A fresh scan found 13, including Job Context root and owned as well as the 11 BREP paths, reflecting concurrent changes between observations. Enumerating this generation's `cs` by exact claimed length selected 17 candidate blobs; hashing only these with BLAKE3 found a matching retained body for every one of the 13 compiler claims. For example, solid-transaction's 41,412-byte claim `44d287ab99d5739ac05a2e0ac027ccb2bf8ed27c55a55acb303af41cd25a073a` matched `cs/c43db831dfca45e58e0d77190b56bc59c1f936e21a274e357965b3c256ee2e82`. This proves matching bytes exist in the generation store, not that the path-to-body issuance has been established or that final provenance will pass.

A subsequent bounded live extension read internal `.d` files derived from all announced workspace artifacts in this retry: 1,113 depfiles, 10,243 workspace checksum rows and 8,887 normalized paths. No path had conflicting checksum/length claims. Workspace is a superset of admitted paths; the final root depfile and later announcements were not included. No source body was rehashed for this extension.
