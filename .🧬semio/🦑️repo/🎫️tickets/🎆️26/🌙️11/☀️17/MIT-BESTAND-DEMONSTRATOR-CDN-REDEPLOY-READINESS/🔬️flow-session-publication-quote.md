# Flow Session Text Publication

The release session publisher reserved the size of a plain shared string pointer in phase three. Its actual admission moves a string into shared allocation storage and needs both copy and capacity allowance. The production WASI session stalled when granted its own exact quote. The ticket witness failed at its ready assertion before the fix.

The session now quotes the same shared storage operation it calls. The linked WASI witness passes for an empty string, multibyte text and a decomposed accent with an embedded NUL, copied three bytes at a time. It checks the returned bytes against the neutral UTF-8 fixtures using serde_json. Denying one capacity byte leaves publication pending. Exact funding publishes, an elected owner returns the identical text, and both ownership handles reach terminal state. This verifies the session primitive independently of the mounted Generator and its full browser test.

The ticket's WASI witness runner also now preserves the requested output filename across dependency iteration, preventing witnesses with the same final dependency from overwriting each other.
