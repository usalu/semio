## Completed command learning

The previous Cargo launcher took an endpoint change in free space as a whole-image write and checked other owners only at those endpoints. Host changes could therefore enter APFS volume learning and fully nested compiler admissions could vanish from both checks. Whole-image learning now uses occupied bytes, with a token written for every successful admission under the existing claimed ledger. An owner uses the volume delta only when no other ledger owner is present at its admission or sampling, and its token remains the latest through the physical measurement. Where ownership or occupancy cannot be proved, learning keeps the directly observed lane delta. Out-of-band writes inside the same volume remain indistinguishable from this owner and can add to the observed delta. Samples remain net endpoint observations under the existing policy. The change preserves the existing failed/cancelled completion rules and does not infer peak usage, seed history, or change reservations of processes already admitted or waiting.

An APFS ownership fixture reproduced the old planner making zero recovery calls where one was required. Neutral fixtures tested valid APFS, crossed mount, wrong filesystem, out-of-range/missing fields and non-Darwin fallback against SQLite. The real pressure executor was exercised with controlled physical ports, and the operator waiting fixture with real fair leases and mocked effects passed 145 assertions after its private directory was shortened within ticket-generated storage. The writer fixture reproduced the old 6 GiB sample where genuine occupied growth was 2 GiB, then verified that a fully nested completed write cannot inflate the outer lane. All 16 headroom tests and two focused launcher tests passed. No module build or actual reclaim ran.

## Idle interval and watcher

Query `repo leases status --all --json` for the exact `native-fixed-image:<workspace>/.cache/b/r` resource and use macOS `lsof -nP -t +f -- <workspace>/.cache/b/r/m` through an owned read-only diagnostic to enumerate the filesystem itself. A raw Cargo can hold active files without the repo lease, and a headroom waiter may release or retain its read lease as it parks. Neither list can substitute for the other.

The detached collector has no image lease and holds only the inherited write descriptors on `u/gc.log` while idle. Its current daemon entry catches SIGTERM/SIGINT, aborts its work and releases its single watcher claim; a future pressured compile starts collection again. It is a real unmount blocker even with no registered reader. A safe coordinated interval lets every genuine compiler and other agent scope finish, leaves the supervisors between batches, verifies no Rust lease holders/waiters or raw mount users, and lets the watcher exit or uses its supported graceful cancellation with the coordinating owner. Recheck before any effect and use the repository non-waiting image reclaim route so a racing new reader is refused. The bounded operator waiting route also rechecks exact backing, mapping and pressure, but has the unchanged routine bloat threshold and queues ahead of future readers. The automatic host pressure route revalidates a measured required-free target and device and uses the lower shared pressure slack rule. No queue, daemon, compiler, mount or image state was modified by this audit.
