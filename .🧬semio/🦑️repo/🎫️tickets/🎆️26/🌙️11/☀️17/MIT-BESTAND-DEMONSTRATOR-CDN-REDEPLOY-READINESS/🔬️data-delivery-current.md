# Data and Delivery Audit

The current build receipt records `.cache/b/p/m/vite/release/5dc1b077e86de2aa/out`, 2,496,793,374 bytes and 1,815 files. The directory currently exists and measures 2.3 GiB; its `vt` and `osm` subtrees measure 69 MiB and 8.0 MiB. These agree with the earlier site-size audit's map-tile measurements; the receipt alone does not establish that the artifact corresponds to the latest concurrent source changes.

The static build prefetches raster and vector tiles for Switzerland (west 5.95, south 45.82, east 10.52, north 47.81) through z10, plus vector world coverage through z3. It reuses existing cache files, fails on reported fetch errors, and checks two canaries. Upstream providers are OpenStreetMap raster and OpenFreeMap TileJSON/vector; inputs are network-fetched and unpinned. The build must have a complete reachable cache or network and a subsequent deployment must preserve all files, including dotfiles. Tile availability outside those bounds and zooms is not guaranteed by this static package.

The demonstrator README specifies host-root deployment, correct `application/wasm` and `application/x-protobuf` MIME types, dotfile delivery, and genuine 404s for missing files. The prior size audit measured 2.33 GB of plugin wasm and estimated gzip ratios of 18–22%; compression is a delivery optimization to verify against the actual public CDN, not an assumption about its configuration. The previous audit's counts and compression results refer to its measured artifact, not a fresh public deployment test. Full browser acceptance and network checks against the exact final artifact remain necessary to establish release readiness.
