# Native component transpile

- Reference: jco 1.39.0, jco-transpile 0.20.0, whose vendored bindgen is js-component-bindgen 2.16.0 (wit-component 0.259, wasmtime-environ 49). The crate is pinned `=2.16.0`; the output matched jco byte for byte on the first try.
- Options jco gets in `transpilePluginComponentModulesAsync`: `--name <base>`, `--map semio:framework/pure=./🟨️.js`, `--map semio:framework/host-async=./🟨️.js`. Everything else is a jco default: wasi preview2/preview3 shim map, deny-by-default node capability map, base64 cutoff 5000, typescript declarations on.
- Tool: `🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🌐️browser-bundle/🏗️materialization/🦀️native-transpile/` (standalone cargo crate `semio-native-transpile`, own `[workspace]`, `cargo-features = ["trim-paths"]` required by the repo cargo gate). CLI: `transpile <component.wasm> -o <dir> [--name] [--map a=b]... [--instantiation [async|sync]] [--base64-cutoff N] [--no-typescript] [--tla-compat] [--valid-lifting-optimization] [--no-wasi-shim] [--no-nodejs-compat] [--no-namespaced-exports] [--multi-memory]`. It runs on a 512 MiB stack thread.
- Build and stage: `repo ./📜️stage.ts` in the crate folder (runs `repo cargo --store=shared --configuration=release -- build --manifest-path ...`, copies to `.cache/b/p/m/browser/release/tools/native-transpile/<platform>/`). `SEMIO_NATIVE_TRANSPILE_BIN` overrides the path.
- Wiring: `🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🌐️browser-bundle/🏗️materialization/🟦️.ts` `transpilePluginComponentModulesAsync` and `transpilePluginComponent` always use the native tool (no size threshold, no jco fallback); a missing binary is a named error.
- Evidence: 137 MB component `runs/wAxBlgM`: `diff -r` of jco and native output trees identical (jco 6.2 s / 0.97 GB, native 2.3 s / 0.49 GB). Test `🧰️framework/🛍️products/💻️os/🔨️modules/🔌️plugin/🌐️browser-bundle/🏗️materialization/🧪️tests/🦀️native-transpile/🟦️.ts` with language-agnostic cases `🧫️cases.json` compares both trees with jco as oracle (2 pass).
- Energy 379 MB (`runs/w6FIa88`): native transpile succeeds in 5.4 s at 1.28 GB peak, writing a 379 MB core wasm, 788 KB JS and 29 interface typings.
- Known jco quirk not copied: jco's CLI ignores `--no-typescript` (it reads another option name); the native tool honours it. The repo does not pass it.
