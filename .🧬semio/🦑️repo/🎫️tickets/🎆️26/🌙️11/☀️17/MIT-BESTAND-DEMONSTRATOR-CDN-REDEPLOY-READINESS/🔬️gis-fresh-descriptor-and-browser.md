# GIS release descriptor and browser diagnostic

The lean paired build linked a 144,126,651-byte GIS WASI component at SHA-256 `e68bca31b4889512fdfdc015e9f8d4c3e18bb332ffc6fbef01f2bfed13360a6c`. The pair's FEM build had already failed and the aggregate could not produce a sealed shipping receipt. I preserved the exact linked bytes and the actual canonical native-transpiler factory and three unoptimized cores before the retired run cleaned its compiler directories.

The factory's actual `describe()` under Node JSPI returned `13a0a7f8c7c15befc5fd9e8367af45a0e940a950ef9accbb98f3ee0a7d5f122f`. The checked descriptor pair was `fb68e4315d73e40a01de82d6b1963b5e56dec6ae38c9777ef7b9c2eedb863a54`, so the first private overlay stopped before launching Chromium. The canonical Rust descriptor tool ran the same raw guest through the owned interpreter, using 4,158,863,542 fuel in the descriptor turn, and returned the identical 756,769 packed bytes. A small independent Python decoder checked the same semantic JSON against both the Rust mirror and JSPI codec projection, including numeric and nested values.

Both the shared app builder and domain owners account for the descriptor changes:

- All four GIS surfaces now put the shared interaction, cancellation, host-event, and document-transfer actions at app scope.
- Terrain editing advertises the move-position utility, up to 65 samples per side, millimetre precision, Fill Missing Samples, and 64 KiB ASCII grid imports. Terrain notices and the existing terrain demo now use the corresponding precision and format.
- The GIS embedded Stdio catalogue keeps all 35 codec entries and the original definition order. Its updated PDF, Semio and XLSX capabilities match the current authored Stdio definitions. Its document HTTP payload and map demo were unchanged.

With these changes reviewed, I passed the Rust emitter's native JSON and its identical verified pack through the existing `settleComponentDescriptorV1` writer at the GIS owner's checked pair. Re-reading that pair through the release codec verifies the intended new semantic digest. The canonical release path still independently checks its future sealed product, transpile, optimization and browser receipts.

`probe-raw-owner.ts` supports an exact live raw component, optional existing native transpile output and an audit-only mode for other release owners. It retains the actual guest's canonical pack/JSON on mismatch, refuses descriptor drift before materialization, and does not stage release receipts. `inspect-guest-descriptor.ts` requires known before/after hashes and matching Rust and JSPI semantic packs before calling the existing pair writer for reviewed changes.

The second private overlay passed real Chromium `verfolgen boot` and `verfolgen undo-redo` in 8.8 seconds. The latter exercises Add Feature and real artifact undo/redo, where the older site previously stalled. The capture recorded 267 static requests, including two HTTP 200 fetches of the compressed GIS main core and 16 requests in the GIS mount. The strict request parser found zero failed assets and zero agent-bridge traffic. This diagnostic used the fresh unoptimized cores with an earlier compact Vite shell and does not mint the final release acceptance marker.
