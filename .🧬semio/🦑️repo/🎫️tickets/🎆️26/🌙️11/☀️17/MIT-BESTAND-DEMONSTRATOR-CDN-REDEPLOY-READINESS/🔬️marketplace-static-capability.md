# Marketplace on the static Demonstrator

The Demonstrator mounts the normal React shell for all eight panes. Its default bottom-right dock includes the Marketplace tab, and the authored pane locks keep that tab available. On the historical shell the tab could start extension installation from a URL or file, or remove an extension. These actions use POST/DELETE at the same-origin extension installation path. That transport is a Vite serve middleware and the published static site serves files.

The shell's composition root now advertises the extension mutation route only in the Vite development server. The Marketplace receives install/remove controls as an optional grouped capability. A static host shows the shipped extension catalogue and lets the user enable or disable contributions. Local plugin loading/reload controls stay available. The guarded callbacks return before touching the ledger or network when the composition root provides no mutation route.

The real Marketplace tree failed the new neutral capability test on the prior code by exposing all four transport-dependent controls for a static host. The focused replay passed both static and local-store cases, including direct execution of the same local enable callback. React's element interpreter supplied the independent exact control inventory. The full renderer suite requested a large graph admission behind active native release work, so I withdrew that optional run. The current code-level evidence uses no new compiled Wasm. The final Vite shell and live receipt acceptance remain separate delivery steps.

The final acceptance runner executes a separate real Chromium Marketplace smoke check inside the same static origin, request log and before/after manifest window. It opens Koordinator's Marketplace, requires absence of transport-only controls, waits for the published AEC Building toggle, changes it and verifies its visible label changes. The script rejects any same-origin install/remove request. Its exit affects the acceptance marker independently of the unchanged 96 official Playwright executions. The manifest fixture used real local HTTP, exercised the exact two suite and additional probe invocations, and confirmed a deliberately refused Marketplace process leaves no accepted marker. The actual full-site browser run awaits the fresh candidate.
