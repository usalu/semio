The first full WASI release attempt reached the Demonstrator hub library after compiling 1,047 units. Its single compiler invocation owned six full mounted surface dispatch implementations. The compiler scheduler refused that library unit because the host could not carry its memory estimate and no larger compiler endpoint accepted it. It never linked the component.

Its typed `From` implementations move the appropriate concrete surface through its owner into that enum. The router target is named `semio_hub_demonstrator_router`. That target carries different compiler work from the historical aggregate library, whose crate-name telemetry records 11,893 MiB and remains in the store. Direct WASI metadata compilation passed for all six surfaces and the hub against the original attempt's exact retained dependency lane.
