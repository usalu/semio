# LLVM backend admission for small final components

The native scheduler supplies one front-end thread and serial codegen/ThinLTO to an admitted final cdylib. It applies these scheduling arguments after parsing the identity of the unit and leaves its output flags and codegen-unit count intact. The wrapper selects them before the admission verdict. The broker verdict currently carries a single admitted boolean.

The retained measured unit journal has 24 non-host cdylib identities. Process robotic, metal, concrete and wood finals have one observation each. They used 0.56–0.66 GiB and took 294–331 seconds. CAD building and spatial shape have one observation each at 0.77–0.88 GiB and 256–257 seconds. Sourcing finals have one or two observations at 1.11–1.41 GiB. Those are process RSS and wall measurements for recorded builds. The keys omit the exact dependency graph, feature set, backend schedule and concurrent worker count.

The native pass holds a fixed set of admitted CPU tokens, then gives the wrapper Cargo's jobserver for that set. A wrapper keeps its own token until its process exits. Enabling parallel Rustc backend execution permits it to borrow tokens still available to that jobserver. No per-final grant accounts for extra backend workers' memory or bounds how many currently available tokens the final can borrow. The memory broker predicts one unit from historical unit peak RSS, admits a single unit even when its estimate exceeds the predicted budget to preserve progress, and freezes future starts after reporting an overshoot. It does not cap a running process or revoke its already-started backend work.

The retained observations cannot authorize a safe small-final exception. An enforceable exception would require a broker-issued worker count bounded by a leased CPU subgrant, a corresponding mode- and graph-specific peak memory bound reserved before starting rustc, and a verified way to keep rustc within the worker count through LLVM and ThinLTO. This investigation changed no compiler flags or admission rules and ran no compiler replay.
