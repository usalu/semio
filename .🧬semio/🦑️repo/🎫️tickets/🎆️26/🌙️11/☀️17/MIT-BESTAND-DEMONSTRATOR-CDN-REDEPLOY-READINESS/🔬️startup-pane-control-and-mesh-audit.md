# Startup Pane Control and Mesh Audit

The retained UI name rule requires input, select, slider, number stepper, icon select, ring, and a toggle with blank text to have either an explicit accessible label or a direct labelled Field parent. Tree item labels and input placeholders do not supply the control name. At the World3D boundary an optional color lane may be empty, and when populated it must contain four numbers per vertex.

The branded application and example choices come from `♻️mit-bestand/🧺️demonstrator/🪧️brand.ts` and the component Cargo manifest. The audit follows the selected files and their Rust initial render paths. It does not establish behavior following selection, editing, or switching examples.

Shared terrain flattens the `hypsometric_color` return value, which is `[f32; 4]`. There was no proven boot-time RGB producer among these seven choices. FEM's separate selected-entity inspector contains editable controls under tree items, and its non-startup solid stress branch emits triples. Those paths fall outside the selected startup scenarios. The shared FEM control row now copies its already-localized label onto the interactive child, including the toggle. The solid triangulation publishes four scalars per vertex with opaque alpha for both neutral and stress-colored passes. CAD and Process each ship a demo-session that dispatches the same demo. The alternate Process demo also explicitly owns a BREP stock child and uses the same indexed evaluator. No alternate CAD or Process RGB lane was found.

## Regression

The Sourcing Rust unit witness calls the actual `filter_bar` and checks the emitted accessibility label by each stable key in English and German. The neutral JSON fixture and the ticket Bun test also compare the live Rust producer's builder and terminology declarations with the production retained-UI name check. SQLite independently evaluates the same six control/locale rows. The baseline removes explicit label assignments from the projection and reports all six rows as unnamed; the current source passed. FEM's source fixtures exercise number input, select, slider, and toggle projections in both locales and check one opaque alpha per vertex for both bundled-demo solid modes. The host-facing regression invokes the production World3D geometry binder to reproduce the RGB cardinality rejection and validates the fixed opaque RGBA, with SQLite computing the independent cardinality result. Three Bun tests passed with 38 assertions, and all three failed when their fixes were omitted. The focused Bun tests ran through `repo tools exec bun -- test`. The Rust units and full browser components were not executed in this preflight.
