# Mounted Page Integration Work

The backing, finite borrowed wire views, resumable fixed-sink cursor and PendingPublicationPage are implemented and separately queued for native proof. Production FullOp and typed publication still use cold result pages; they have not been switched. The genuine direct-emission native regression is authored and gated behind corrected core compilation.

Integration must retain accepted intent before any retry: frozen token after Store generation update; scalar accepted count immediately when an outbox item moves; Ui/Download/raw source borrowed from unchanged retained producer only during a cursor step. A later document generation must not reject an already accepted receipt. ACK producer cleanup remains first.

Prefer a separate mounted result-page owner/field rather than conflating PendingPublicationOutcome's existing fault-capture phases. New custody needs pending page, both primary/forwarding refusals and funded retirement. ValueError already implements RetireOwned; no owned refusal may be discarded. FullOp lease readiness, terminal emptiness and both ordinary/granted close routes must account for every new owner before retiring its publication source.

Store commit and new pending-frame capture cannot assume two retained items are available in the original one-item grant. Existing Store publication retains the accepted receipt in AwaitingAck; use that original retained outcome on a later funded capture step before freshness/new-action checks, rather than replaying commit or losing a local receipt on denied capture. Inspect the exact Store accessor/advance API before implementing.

Ui Full/None are plain values. Partial owns two Vec<String> and five flags. Existing UI outbox and terminal-witness clones also need genuine bounded custody; borrowed serialization only avoids an extra serialization clone. No atomic whole-source String/ToValue fallback, invented budget, clamp, hidden shared-root cache or unchecked after-commit retry is acceptable.

No production page integration edit has yet been made. Native proof of the helper owners and direct publication remains required; this document is a work map, not a completed implementation claim.
