Every edit locator is scoped to the opened document's own window bodies. English and German both actively select their language through the same real Settings control (native select or exact localized combobox option). A boot label or missing-control result is rejected. The actual HTML locale must equal en or de after boot and reload; requesting a locale or seatLocale returning success is insufficient. Authored entry additionally checks Note/Notiz.

All nine reported steps must pass:

1. Open the exact owner and obtain a nonempty kept document UUID.
2. Render its own body with no new runtime fault.
3. Change the exact native field to Matrix; export edit, undo and redo. Undo must reproduce baseline bytes, redo edited bytes, and edit must differ from baseline.
4. Savefile must produce a download plus file-saved acknowledgement, with the same focused kept UUID and data-semio-local-persisted=true.
5. Close the owned tabs and wait for actual disappearance.
6. Wait for that exact LocalFiles UUID catalog button to be visible and click it even when no live actor yet reports persisted. Require file-opened, new owned windows and exact plugin/app ownership, then wait for persisted=true and verify edited bytes. Authored entry also requires the exact Matrix field.
7. Reload the browser, witness the same requested locale, reopen the same UUID and repeat owner/bytes/field checks.
8. Export must retain the reversible edit, judged through the declared format oracle.
9. Invalid input deadbeef must produce refusal without file-opened, window changes, page errors or any change to the current exported content.

Window ownership uses the same first-party spawnedIdOfWindowInstanceV1 mapping as the host, including longest-prefix resolution. A compatible foreign owner cannot pass reopen merely by exporting matching bytes.
