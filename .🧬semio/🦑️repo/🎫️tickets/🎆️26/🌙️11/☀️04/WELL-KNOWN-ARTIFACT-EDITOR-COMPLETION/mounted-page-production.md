## Behavior

Accepted effects, events, UI, completion witnesses, interactions and owned child results retain their exact intent/token before framing. Deferred custody gates pump shortcuts. Interaction outputs retain their owning vector for paid retirement. UiDirtyScope copies use a paged owner for both vectors, UTF-8 string prefixes and five flags; both host outbox transfers are funded and the immutable emit source remains retained.

Raw fault reports borrow the existing canonical bounded bytes. Terminal, child-empty and cancellation payloads use fixed reason selectors. Latest-wins cancellation mounts a deferred scalar fault intent rather than allocating a cold Vec page. No source String/ToValue tree or cold result-page constructor is used in these production paths.

Accepted JSON custody uses the central resumable cursor through the original NativeRetirementDecodeControl encoding receiver. This borrows the same actual ledger, observer, allocation port and remaining hop authority after cancellation. It creates no new ceiling. Actual written prefixes, work and physical effects remain accounted on refusal. The retained failure preserves primary, forwarding and context ValueErrors. A framing refusal enters paid Retiring and returns a static refusal; it does not loop indefinitely or replay acceptance.
