# Empty Child Root Close Audit

The close ladder currently treats only root.len != 0 as ownership requiring retirement. A representable Some(Arc<ChildContentRoot { len: 0, ... }>) therefore reaches drop(previous) with a generic handoff receipt and no actual Arc release quote. ChildContentRetirement already handles an empty owned root correctly through view.take_one: no pages means actual root allocation is released and returned as ChildContentTake::Complete(released_bytes).

However, the proposed ordinary last-child removal trigger is not established: ChildContentView::without_member (declaration/child lines425–443) explicitly returns root None when next.len becomes zero. Prepared cancellation extraction (take_prepared_entry, lines270–282) does retain Some root while decrementing len to zero, but its concrete production caller operates on group.future, not the installed current child_content_root. Cancellation then closes that future's structure. No path publishing this already-cancelled empty future into the current root was found in this bounded review.

The normal group publication swaps next into child_content_root and retires previous only when !previous.is_empty (typed-operations/staging/child-group lines138–150), so it shares the representation-sensitive concern if an empty owned current root can enter. This is a potential ownership-law gap for a valid public representation, not a demonstrated additional runtime failure from normal removal.

A focused actual native fixture can install ChildContentView { root: Some(Arc::new(ChildContentRoot::default())) } in the real ladder, record actual allocation, deny release before handoff/retirement, then drive the public close lane and compare physical release to its receipt. Existing ChildContentRetirement::new(view,true), retirement_demands(children,retiring,body), and close_step are the reusable owner. An inline final-root cursor, analogous to peer close, avoids requiring a newly allocated registry during cancelled partial initialization. No production source changed and no native job launched.
