# Paged Absent Initialization Review

Read-only review of value/🏗️initialization source, two native tests, neutral corpus/schema, and Bun test. No concrete Rust soundness defect found. Immutable promoted None templates contain no constructed T owner; selected-range copies use MaybeUninit<u8>, preserving uninitialized payload/padding without typed reads. Destination pointers are raw, so no reference is formed to a partially initialized Option or array. Bounds use count > extent-offset after checking offset <= extent, avoiding addition overflow. Exclusive destination storage excludes source overlap. After full coverage, typed None borrow/drop is valid.

The returned bool means selected range end equals total extent; it does not prove prior ranges were copied. In particular offset=extent,count=0 returns true. The unsafe caller must retain a monotonic cursor and ensure full coverage before any typed borrow/drop. This is a caller proof obligation, not a demonstrated defect in the current sequential tests.

Existing pinned opt0 IR confirms the physical distinction: old addr.write(None) allocates [56001 x i8] stack storage and copies all 56001 bytes. New initialize_absent_page and initialize_absent_drop_array call immutable template functions and emit memcpy with dynamic count and offset; no full aggregate temporary appears in those functions. This proves the inspected monomorphizations, not all compiler targets or end-to-end native construction.

Tests cover large byte-array Option extents and a 64-element array of absent boxed owners with 7-byte pages. Additional boundary cases not currently covered: Option of a niche-bearing value, non-Sync owner, zero-sized payload and zero-length array, plus end-of-extent empty range semantics. The neutral payloadBytes+1 expectation is a chosen concrete Option<[u8;N]> layout observation, not a general Option<T> sizing law. Source APIs correctly use size_of for actual layout. Bun Ajv/lodash proof covers chunk arithmetic only; native tests and actual app construction remain pending. No source edits or build executed by this audit.
