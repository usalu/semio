Exact nested shapes must follow authored FemSnapshotValue DSL schema and variant producers, including their Lists, Records, Statements, booleans/enums/numeric/text fields; do not infer that only node/material shapes occur.

A reusable text cursor should retain an immutable source identity, static borrowed RecordSpec and a depth-bounded explicit traversal stack of path indices plus record layout/order scan, child index, separator/glue/indent and token byte/UTF-8 offset. Each advance reborrows the original source by path, quotes the next actual stack growth/output fragment before mutation, checks original cancellation and fuel, emits into caller supplied output, and returns actual work and retained receipt on success and refusal. Use fixed inline bounded stack where its cost fits policy or existing PagedList with paid birth/close for unbounded declared depth; pending token and numeric formatter use fixed byte buffers, no cloned RecordValue, reconstructed control or fake receipt. Preserve all current borrowed grammar ordering and exact canonical escaping. Denied grant must leave cursor/output unchanged, while post-effect cancellation retains the written prefix and exact receipt. Close cursor/source/output through original owner.
