## Why The Current Fixture Shape Is Different

`🧰️framework/🔨️modules/🧵️job/⏱️context/🧪️testing/🎟️caller/🦀️.rs:8` accepts its source argument as total original stock. It pays cancellation, payload and source-parent birth from that stock. turn_original uses StepBudget(...self.stock) with the cumulative self.spent recipient and narrows each callback through with_retained_loan(grant). remaining_grant subtracts every accumulated receipt, and retirement also consumes the same finite stock. Reusing INTERACTIVE_COMPONENT.preparation for this source argument therefore provides only32768 total copy bytes and32 total items, including root work; repeated32KiB callback grants cannot replenish it. A1024-node carrier cannot be assumed to fit that total, independently of the valid16MiB per-turn capacity ceiling.

A genuine actor acceptance fixture must name its total original Source independently from its per-turn mounted/host policy, and take both from the intended embedding authority. The audit does not authorize substituting an arbitrary larger stock, multiplying a turn grant by an iteration bound, resetting OriginalJobFixtureCaller between chunks or bypassing receipts. If no actual Run policy file is supplied, there is no current production default numeric total to reuse honestly.
