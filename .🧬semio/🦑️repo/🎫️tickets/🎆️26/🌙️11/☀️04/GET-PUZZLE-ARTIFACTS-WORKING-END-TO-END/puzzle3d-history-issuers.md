The existing Discard store frame is a grounded reusable mechanism: `prepare_discard_effects` creates its paid effect owner, acquires five retirement frames from the same Store issuer, and checks preview, replay and snapshot authority. ## Late Report Replacement Cancellation Ordering

A live replacement may outlast admission of its decoded operation into raw `EditReplay`: Report phase 3 moves the native input into `operation_preparation`, leaving `replacement_operation` set while `original_preparation_ready()` is false. The Store retirement selector consequently closes the raw replay first. This looks dangerous until the raw close ordering is included: `🔁️replay/🛑️cancel/🦀️.rs` retires `replay_retirement`, `prefix_message_retirement`, `operation_preparation`, `operation_retirement`, `operation_message_settlement`, and `prepared_operation` before it reaches supersessions or drafts, and every selected close unit returns before selecting the next field. Those are precisely the six fields in `original_preparation_ready()`. After the final blocker leaves, the outer Store selector runs again, sees ready, and `close_original_report_replacement` returns the payload through the original history row before raw cancellation can retire that row. A live draft/supersession makes raw's original-empty witness false, so clearing the last preparation blocker cannot simultaneously make the raw owner terminal. The replacement selector and its demand quote both use the same guard.

This ordering supports safe late cancellation; removing the guard without further analysis is not necessary. Existing `original_report_original_token_cancellation_returns_all_partial_sources` tests numeric cuts 0, 1, 8, 32, 64, 96, 128 and 192, but does not assert any cut actually reaches the live replacement plus non-ready raw preparation state. Add a phase-witnessed regression that pauses precisely there, cancels, observes every resumed retirement turn, and asserts the same payload allocation returns to its draft or supersession row before raw row retirement, including a denied original grant and the terminal-empty witnesses. This is a source-order analysis, not a new native run.
