# Puzzle Owned JSON And TXT Export Readiness

This is a source-based design report before production edits or native execution. Root owns the shared projection design, Integration the registered IO publication/native traits. Existing queued portable handles 33543 and 19193 remain unchanged. No compiler or producer was requested here.

## Existing Genuine Contract

The existing OS IO serialization/owned owner defines OwnedSerializerRequest with the actual ErasedSnapshotRead, exact route, generation/revision, options and optional captured child authority. IoEntry.begin_owned_serialization checks the registered export coordinates and live source/child authority, quotes factory demand and admits before invoking the factory. Refusal returns the complete same request and incurred progress. OwnedSerializerJob already is an InteractiveJob, with real outcome borrowing, source authority, paid output/fault handoffs, close demands and terminal frame release.

Draw export/owned is a genuine ownership reference, not a conversion target. Its factory rechecks the real DrawingSnapshot type and generation/revision, preserves request on refusal, converts the same read through try_into_typed, admits exact frame allocation and retains metadata under ControlledRetirement. Its producer owns that original typed read through resumable writer work and paid close. Puzzle must accept its own exact captured snapshot type; constructing a DrawingSnapshotRead from a Puzzle root would invent authority.

The generic SnapshotRead source_admission already transfers the real typed read into RetainedCloneSource::admission_borrowed using read.get(), without cloning payloads. Real source projections then retain exact root-backed aliases. This is the existing first-party carrier seam; no additional fake capture registry or carrier protocol is needed. Root/Integration already identified the real native snapshot helper and should continue using that owner rather than another carrier.

## Existing Writer Programs

The pack JSON native tree owner exports ArtifactCanonicalJsonTree, ArtifactCanonicalJsonTreeCursor and ArtifactCanonicalJsonTreeWireCursor. The cursor retains root-backed projections in paged frontier storage, quotes the next real allocation/copy/release demand, reports actual last_turn_work and written prefix, and closes every retained alias and frontier page. The wire cursor performs paid source admission, measurement, exact destination allocation and bounded initialization, second encoding traversal, source close and output transfer. Its whole-output constructor consumes a real owned root; it does not require a DslValue mirror.

The alternative JsonWriteSource/JsonBorrowedWriteCursor already reads scalar/container views through ordinal paths and emits incrementally under NativeEncodeControl plus grant receipts. It retains a contiguous String and fixed-depth Vec frontiers. write_json_source_into is a borrowed synchronous sink adapter with cancellation/work controls, not a resumable InteractiveJob by itself. Neither API should be presented as a complete captured serializer factory without its real job/controller lifecycle.

The DSL owner already exposes BorrowedRecordSpecProducer and FieldProjectionSource with native ordinal field views. measure_print_borrowed uses the real canonical emitter directly on those views, including tables, nested records and intrinsic data. RetainedRecordWriter is resumable but requires an already owned RecordValue and RecordSpec. RetainedFieldProjection can construct a field incrementally under the actual encoder control; the plain ArtifactDsl::print_dsl currently eagerly builds the entire record/spec and String. No complete publicly exported resumable borrowed record text writer was found in the actual DSL owners inspected. A new borrowed writer should belong beside that canonical emitter and retain its traversal state, rather than replaying the prefix or wrapping synchronous print_dsl in one nominal job event.

## Canonical Puzzle2d JSON Roles

The new declared IO schema and typed converter remain the normative external shape; native snapshot JSON/DSL state remains separate. Its forty-three exercised float fields cover camera; node and node handles; edge; target region; metadata kind-catalog node handle records. The nine authored IEEE-754 words include zero signs and non-finite payloads. An owned export must read these exact native field roles directly and emit the sole bits member with sixteen lowercase hex digits. It must preserve optional/null/default/empty rules and every unrelated semantic field. It must not run ToValue over the entire root, recursively recognize arbitrary bits-like user objects, or globally alter native f64 serialization.

The existing native canonical tree f64 node emits decimal JSON; F32HexWord is an explicit typed scalar role that emits a string. Therefore using the current derived semantic tree directly would lose the declared Puzzle2d bits-object wire. The clean reusable extension is an explicit binary64 hex-string scalar role beside the existing binary32 role, with a domain-owned typed bits-object view selecting it only at the declared roles. The current root, row, option and collection views must retain the real root authority; no owned tree needs to be allocated. This is a proposed interface change requiring schema/neutral scalar cases and independent bit-exact oracle review before implementation.

A job using the generic whole-wire cursor must account for its source-close-before-output phase: OwnedSerializerJob output authority still must be checked against the actual live generation/revision at publication. Retain a genuinely admitted read alias until handoff, or use the lower tree cursor with the job retaining the original read and explicitly coordinating the two passes. Do not reduce source_authority_matches to stored generation numbers after disposing the actual lease. Cancellation/refusal at any phase must retain the live read, partial output and diagnostic until paid close.

## TXT Contract And Required Gates

TXT is the native ArtifactDsl carrier, including its semio preamble and canonical record/table order. Preserve exact existing print_dsl output for the authored case. Implementing a borrowed resumable DSL emitter alongside its existing measurement/emitter owner avoids an eager DslValue/RecordValue tree, permits real one-event yields and lets the same snapshot read remain the source. The existing emitter grammar and source/spec identifiers should be reused rather than copied into Puzzle.

Before exposing a Puzzle factory, add neutral request cases for exact/wrong snapshot type, route, generation/revision and children, zero/underfunded grant, cancellation at each writer/output/close boundary, stale authority before publication and preservation of original refusal custody. Reuse the authored JSON schema/43-pointer/nine-word oracle, the ten malformed words, forty-five presence cases and unrelated-semantic specimens. Third-party serde parsing must independently compare complete wire shape and exact word strings; native schema acceptance and exact TXT roundtrip must run under actual owned IO tests. The existing real four-format laws and browser twenty-case scope remain required.

The current actual inferences cfg(test) Source is 208608 bytes/31 inputs and text-inverse is 211047/23, under unchanged 262144 bytes/32 inputs. A controller and additional laws should not be casually mounted into the already 31-input inferences owner. Keep the natural IO serializer job responsibility in its actual export owner, depend on the real snapshot/record owners and remeasure production and test closures before registering it. No cap raise or input exclusion is justified.

## Concrete Paged Text Readiness Gap

The actual DSL binding implements DslField for PagedUtf8 but does not override projection_view, so it currently inherits the explicit UnsupportedOwner refusal. Puzzle2dSnapshot.schema is PagedUtf8. In addition, the borrowed canonical emitter has no TextSource or IntrinsicTextSource arm despite those real FieldProjectionView variants existing. Thus direct borrowed TXT measurement is not currently ready for the actual Puzzle snapshot even before adding resumable output. Fix these genuine native paged-text view/emission responsibilities in the DSL owner, with paged multibyte/escape/boundary fixtures, rather than flattening or cloning them in Puzzle. This source finding is not a native execution verdict.
