## Registered Mutation Latency Audit

The 20:08 native `editor-gestures` law failed its eight-turn bound: the one-object translate reported 934 fixture loops, 20 worker census units, 1,673 Store and 95 Page units; delete reported 993 loops, 14 worker units, 1,879 Store and 142 Page units. These are real observations, but the test's interpretation needs updating before it can be used as a browser round-trip measurement. `settled.turns` increments in the raw fixture's local `host_turn`, which runs maintenance, renews a separate caller turn, advances publication once and locally drains and acknowledges results; it does not cross the reactor transport. Subtracting a worker *unit count* from a host *loop count* assumes exactly one worker unit per loop, which the census interface does not establish. The test's `SETTLE_HOST_TURN_ITEMS = 256` currently changes the maintenance item allowance, not the publication grant. The mounted preparation policy is 64 items, and publication is restricted by the actual original caller and remaining custody. The eight-turn description assumed a much shorter publication ladder and 256-item host batching before the current original ownership and receipt phases; the log alone does not show actual browser polls or prove that work is size independent.

There is a concrete place to investigate a real batching loss. The mounted publication pump records each Store or Page unit, computes the actual retained `unit` even when there is no explicit ownership receipt, then returns if `receipt.is_none()` and its coarse tuple of publication progress/presence/stage is unchanged. A nested paid custody step can potentially advance and spend a nonzero `unit` without changing that tuple; if so, this condition ends an otherwise funded turn early. Record the selected phase, actual `unit`, receipt, work and stop reason before changing it. If demonstrated, continue on actual paid progress while preserving the real receipt, page, time, cancellation and grant boundaries; do not simply increase the eight-turn constant. Separately replace the claimed host-round-trip count with measured reactor polls and real host grants, retain a size-scaling assertion for comparable documents, and record worker polling separately in matching units. No build or production edit was made during this audit.
