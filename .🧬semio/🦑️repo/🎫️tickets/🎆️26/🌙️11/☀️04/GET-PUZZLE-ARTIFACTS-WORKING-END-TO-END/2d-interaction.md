# Puzzle 2D Interaction

The Play shell and Puzzle development variant register Puzzle 2D's WASM board session with the React board host. The native/WGPU renderer uses the same board engine. Its retained node-drag planner already resolves the release sample and uses the shared relative drag geometry.

The direct board lane now previews and releases from the original grab positions. Releasing between move samples commits the release sample, with the same translation applied to each selected member. A stationary click keeps an off-grid node in place with grid snapping enabled. Repeated drag and rotation samples leave geometry and preview queues alone. Large selections pack preview positions into fewer events so the preview queue's item limit cannot prevent the local drag. Rotate and area-region gestures use the final sample, and cancellation restores the original transform preview in sibling panes.

The browser board handles pointer moves from its own canvas and tracks releases and cancellations for the pointers it captured. A captured drag can cross the canvas boundary and still release on its originating board. Catalogue ghosts use the board camera's inverse transform, share world coordinates across panes, and use the frame scheduler for repainting. The drop uses the same transform and commits only when the camera is available.

The browser mirrors live node and selection previews to sibling panes immediately. The document event buffer excludes those previews and retains one consecutive camera sample. A completed drag sends one relative gesture record with the staged selection. Wheel samples use the camera settle lane, and an intervening document snapshot keeps that lane's live camera.

Clipboard paste now allocates a distinct handle for every cloned port and uses that mapping for internal edges. Ports with different source identities and the same final path segment keep their connections. The node and edge allocators keep a free candidate and check every replacement against the destination, including serials reused after wrap. Cut checks the selected nodes, their handles, and their incident edges for locks before deleting anything.
