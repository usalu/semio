The canonical authoring test registry includes `🎓️teaching.🏛️architecture.🦗️grasshopper.🎬️clip.🧪️tests.🎭️presentation.🐍️`. The capsule folder is not excluded from discovery.

Thus a successful, fresh, unfiltered canonical suite covers the same two actual capsule lifecycle calls and the same assertions: real animation compilation/begin/interpolation at 0, 0.5 and 1/cleanup, finite member points at each narrated step, exact ordered narration keys, required animation kinds, nonempty family, and final Cairo capture at 480×270 with visible nonuniform pixels. Both run with spectator audience, Cairo dry-run and the same method; the output location differs only by caller (set `SEMIO_TEACHING_OUTPUT_ROOT` to the ticket for the canonical suite). The canonical suite additionally includes the Grasshopper and Excel presentation modules and the permanent capsule geometry, ghost and UI modules and scene interop frame tests, registered in authoring `📜️script.ts`.

A successful canonical suite can therefore serve as the mandatory full bilingual capsule lifecycle gate without a duplicate standalone invocation, provided it executes the complete unfiltered current registry, uses the frozen current sources and exits successfully.
