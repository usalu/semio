# Excel anatomy capsule recalculation: read-only dependency trace

The s125 recalculation width is a real geometry input, not just a label or an ignored field. In `🎓️teaching/🏛️architecture/📊️excel/🎬️clip/🦴️anatomy/🐍️.py`, `_key` includes the rounded live `s.iw` and all presentation flags; `_live_capsule` rebuilds the whole keyed image on a changed key. `_drawing` passes nominal outer dimensions plus explicit `interior_width=iw` and `interior_length=il` to `capsule_axon`, with default `interior="reference"`, `glass_opacity=.25`, and `cutaway=False`. It also separately builds the floor/hatch, interior dimensions, area badge and fitting overlays from iw/il.

The Nakagin visual `_cap` includes both overrides in `_CAP_NAMES/_CAP_KEYS`; `_cap_parameters` forwards them, and `_cap_parts` includes them in the `_capsule_parts` LRU key for exterior and full assemblies. A changed width therefore cannot hit an identical full-assembly key. The model's `capsule_interior` makes explicit overrides the actual usable bounds, with width `[-iw/2,+iw/2]` and length centred within the nominal length. The full `capsule_assembly` uses those bounds in the `floor-finish` geometry, lining geometry, and reference interior. `_reference_interior` scales actual furniture and fixtures by `usable.width/2.3`, `usable.length/3.8` and `usable.height/2.1`, then fits them to the usable cavity. The reference wall luminaire also scales its width/depth from those bounds. The floor build-up's upper vertices and lining side/rounded-profile positions therefore change too. The outer casing, opening and fixed exterior structural dimensions are derived from the outer parameters, but the full detailed body is not invariant.

`capsule_axon` requests both exterior and full parts, makes the full drawing and performs section ordering and painting. Its exterior-only filter for interior parts applies only when `not cutaway and glass_opacity >= 1`; the actual default is .25, so reference interior remains in the assembled scene. The scene then changes body opacity for floor/error states. Thus excluding iw from the existing whole-body key would be incorrect, and treating the existing detailed body as a fixed image while the stated reference interior changes would not preserve current geometry/visibility semantics. The full rebuild is a consequence of the current whole-drawing keyed factory, not evidence that every subcomponent necessarily changes: a future decomposition could independently cache proven invariant exterior geometry while updating exact width-dependent lining, floor, furnishings and compositing/order, but would require native actual-frame equivalence tests and a review of projection, glass, occlusion and opacity. No implementation change or runtime benchmark was made in this read-only investigation.
