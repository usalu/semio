# Linux/amd64 release rehearsal

The build produced a deployable archive containing the Rust binary, catalog and ten quizzes, offline Docker images for the Proctor and Caddy, Compose configuration, SHA-256 checksums, operator instructions and the vendored Rust source. The build used pinned Rust nightly and Zig against glibc 2.36 and selected the exact amd64 variants of the authored image digests. The canonical native runner was unavailable. The source checkout and the previous deployment remained separate.

The teaching workspace passed 133 Rust tests. A Linux x86-64 guest executed the extracted Proctor on glibc 2.36 and inside the packaged distroless filesystem as UID 65532. The catalog had ten valid quizzes and thirteen badges. Chromium served the extracted static archive through its production origins on loopback. A first learner's progress resumed on a fresh second device and the phone navigation and quiz worked. The wider browser runs also covered both languages, every quiz at a perfect score, a live leaderboard update and offline use. A live rehearsal backup restored 413 events and passed SQLite integrity checks.

The exact outer archive (SHA-256 42eaadf3614460942a7b8608b7d449e5b679b5c48a8c458602851179108ab405) was extracted on fresh Alpine Linux x86-64. The contained file checksums matched. Docker Engine 28.3.3 loaded both bundled images and returned their expected configuration IDs. Compose 2.36.2 brought both services up healthy with the supplied rehearsal certificate. The external HTTPS endpoint returned HTTP/2 200 and the configured site origin. Chromium confirmed a live leaderboard update and a saved quiz on a second device through Caddy.
All three final browser journeys passed through Compose. A Proctor container replacement preserved all 75 event records. A separate restore into a clean volume recovered all 75 unchanged records, and SQLite integrity checks passed.
