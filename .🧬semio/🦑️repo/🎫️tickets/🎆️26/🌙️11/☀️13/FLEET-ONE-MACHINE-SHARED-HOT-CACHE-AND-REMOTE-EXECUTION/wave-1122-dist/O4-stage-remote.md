## Changed
- Offload (`LIB/🏗️build/🌐️remote-execution/🚀️offload/🟦️.ts`): `OffloadCommandInputV1.directories` (`out/<name>` -> real destination directory). Declared with the output paths, read per directory from the action result, staged in a sibling `.tmp` directory and moved entry by entry into place; a directory the tool left empty or absent is `incomplete-inputs` (run here); failures remove what landed. Output count is bounded by `maximumOutputFiles`. The worker and validator already supported directory outputs; only the client lacked them.
- Allow-list (`🚀️offload/🧰️command/🧬️schema/🔣️.json`): shipped tool `descriptor-emitter` (2048 MB peak).
- CMD `🟦️.ts`: shared `stageOffloadV1` (honours `SEMIO_OFFLOAD=never`) and `remoteStageV1` (never fails a stage; any fault or non-done answer empties the stage directory and answers false). `optimizeStageRemoteV1` moved onto them (same action).
  - `transpileStageRemoteV1(work, binary, native)`: `native-transpile` shipped (`file` = the binary, digest = the key's `native-transpile` digest, checked by the worker), input `in/<base>.nodebug.wasm` (the stripped component), args `transpile @root/in/.. -o @root/out/transpiled --name <base> --map ..`, output directory `out/transpiled` -> stage directory, then the two jco rewrites a local run applies. Wired as the `remote` argument of the transpile `cache.run` (slot `base`).
  - `probeStageRemoteV1(work, module, vendor, source?)`: `node` resolved (worker offers its own node by digest; requester digest = `commandToolDigestV1` of the PATH node, symlinks followed, memoised), inputs: module files at `in/m/`, vendor files at the path that keeps the module's relative import (`relative(module, vendor)` below `in/m`, refused when it escapes `in/`), the unchanged probe source as `in/probe.mjs` and a fixed 5-line entry `in/run.mjs` that points `process.argv[1]` at the module and writes the probe's stdout to `out/semantic.b64` (a command must declare an output file). Decoded into `semantic.bin`. Wired as the `remote` argument of the probe `cache.run` (slot componentBase). The optional `source` parameter mirrors `probeStageRequestV1`.
- `PL/🖨️describe/🧩️component-stage/🟦️.ts`: `describeStageRemoteV1(cache, deliverable, control, emitter, digest)`: `descriptor-emitter` shipped (emitter path + sha from `withDescriptorEmitterTaskV1`), input `in/component.wasm`, `describe @root/in/component.wasm --out @root/out/d [--prepare-actor]`, output directory landed in a scratch dir, pair strict-verified (`verifySemanticDescriptorPairBytesV1`) before pack, json and actor image are copied into the stage directory. Wired as the `remote` argument of the describe `cache.run`.
- Keys unchanged from D2 (no key function touched). Stale fixture fixed: `🧪️tests/🦀️native-transpile/🧫️cases.json` + test now expect D2's schemaVersion 3 and `maps` tool (the test was failing before; 6/0 now).
