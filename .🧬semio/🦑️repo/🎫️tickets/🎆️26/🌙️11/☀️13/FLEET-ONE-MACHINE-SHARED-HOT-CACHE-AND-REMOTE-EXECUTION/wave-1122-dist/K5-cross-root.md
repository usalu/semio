It never enters the local or fleet key; it differs by construction between two roots (40 cases = every unit with a remap/path argument).
2. The fleet key IS root-independent between `/Users/ueli/Documents/semio` and `/Users/ueli/.sinc/play`. Real run (script `wave-1122-dist/K5-cross-root-real/keys.ts`: real wrapper + real rustc, `unicode-ident-1.0.27` from each root's own Cargo home inside the checkout): local key `6e02aa93...` and fleet key `b121f39c...` equal in both roots, only `roots` differs (`bb516d06...` vs `b333e7fd...`, the same values as in the two lookup logs). The unicode_ident v3 key is NOT on the server (main never compiled it under v3: cargo kept its old artifacts), so even with fleet on, registry crates miss until one machine has built and uploaded them.
3. Why all 92 missed: the fleet tier was OFF in the clone, not a key problem. Evidence: no lookup row has a `remote` field (main rows do); the clone has no `.cache/f/cache-facts.json`, `.cache/f/machine.json`, `.cache/f/identity/`, no `fl/reachable|down|cost`, no remote counters. `readFleetSettingsV1` returns undefined without `SEMIO_REMOTE_CACHE_ENDPOINT`; the launcher (`UC/🚪️launch/🟦️.ts:91-99`) takes it from the environment or from the local facts copy `<root>/.cache/f/cache-facts.json`, and `repo incremental prepare` clones only tracked files and `incrementalChildEnvironmentV1` strips `SEMIO_*`. The signer (`loadFleetSignerV1`) also reads `<root>/.cache/f/identity`. Other causes checked: clone wrapper is generation `df792f99f969bb95`, namespace v3 (K1+K4 landed); toolchain identity and platform digests equal (`toolchain fd044cb9`, `platform 5a0fc5cf` same in both); no `no-compiler-identity`.
4. Real key gap found and fixed: `env:OUT_DIR` (3 cases). Values read by `env!` (not selected names) entered the key raw (`📜️script.ts` callback `...?? text`): OUT_DIR holds Cargo's unit hash (`build/<crate>-<hash>/out`) and the lane root, both root/lane specific.

- `UC/🔏️key/🟦️.ts`: `outDirectoryIdentityV1(path, laneRoot)` (`.../build/<crate>-<16hex>/out` -> `⟨out⟩<crate>`, else lane-neutral path) and `sourceValueV1` (selected names via `keyEnvironmentV1`, OUT_DIR as above, others lane-neutral). `UC/📜️script.ts`: the `sourceEnvironmentV1` callback uses `sourceValueV1`. Generated files stay keyed by bytes (`⟨out⟩/...` rows), so soundness is unchanged.
