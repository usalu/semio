# K2: portable roots, build-script run sharing, key gaps (2026-11-22)

UC = `🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/⚡️caching/🦀️cargo/🗃️unit-cache`

## Changes
1. Portable roots. `toolRootsV1` (`UC/🛰️fleet/🪪️identity/🟦️.ts`) reads CARGO_HOME, RUSTUP_HOME (defaults `~/.cargo`, `~/.rustup`) and the sysroot (only when outside the rustup home). `portableRootsV1` takes them and gives tokens `@@semio-cargo-home@@`, `@@semio-rustup-home@@`, `@@semio-sysroot@@` (fleet schema tokens). Deepest root wins, so a Cargo home inside the checkout is the same token as one in `~/.cargo`. Wired in `script.ts` (roots, `prepareFleetV1` x2), `prepareFleetV1`, spool jobs (`tools`), uploader and adopt. The checkout token already applied to any checkout root (also `Users/Shared/semio`); now tested. Leak detection (`leakedRootKindsV1`) already named cargo-home and rustup-home; a `sysroot` root kind was not added (sysroot inside the rustup home is covered by it; outside it stays untokenised only in leak detection). Open.
2. Build scripts. Run key = `localKeyV1/remoteKeyV1` over `buildRunKeyInputV1` (`UC/🏗️buildscript/🔑️run-key`): env via `buildKeyEnvironmentV1` now neutralises rustflags (role-reduced remaps) and reduces RUSTC/RUSTDOC/RUSTC_LINKER/RUSTC_WRAPPER/RUSTC_WORKSPACE_WRAPPER to the program name; the executable is keyed by the unit key that compiled it (`<real>.semio-run` identity file written by the wrapper's `shim()`), else by bytes. RUN outputs go through the same fleet tier (`prepareRunFleetV1` -> `obtainFleetUnitV1` lookup/claim/wait/fetch, `shareFleetUnitV1`, offer on local hit, uploader/adopt with `run:true`). Wire form (`UC/🏗️buildscript/📦️run-wire`): manifest outputs `run.json` (facts, env) plus `f:<path with / as %2F>`; roots tokenised; leak check (roots, HOME/USERPROFILE, lane) on text after tokenising and on binaries: leaked, too many files (>63), name too long (>200) or too large stay local with event `remote-skip` reason and skip counter `run-<reason>`. Package-tree facts are re-verified by the existing local lookup after install.
3. key-incomplete. `recordGapsV1/readGapsV1` (`UC/🔏️key/🕳️gaps`): dep-info files missed by the scan are stored per slot (`fl/gaps/<xx>/<slot>`, portable names) and added as `⟨gap⟩/<name>` source rows by `unitSourcesV1` on the next compile, so the next key is complete. The per-run observation file (`semio-compiler-resources/<ms>-<pid>-<n>/observation.json`) is written by `with_compiler_resources_v1` (native-build/📥️resources/🧮️compiler/🦀️.rs) and registered in dep-info on purpose (the build receipt reads it); it does not affect compiled output, so it is declared non-input (`key.compilerWrittenFiles`), excluded from the gap and from stored unit dependencies (otherwise a fleet install could never validate it).
4. Legacy `unit-counters/skipped`: no code reads or writes it (the sum of reason files is the count); removed the test fixture that planted it and deleted `.cache/f/unit-counters/skipped` here (no open handle).
