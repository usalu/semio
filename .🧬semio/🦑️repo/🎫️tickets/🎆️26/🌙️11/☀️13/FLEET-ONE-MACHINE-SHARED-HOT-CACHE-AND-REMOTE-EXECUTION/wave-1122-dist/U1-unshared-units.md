## 3. Changes
1. Client (`F/📡️client`): `storeBlob`/`storeResult` return a verdict `stored | capacity (507) | busy (5xx/429/401/403) | refused (400/413) | down | diverged | stale`; `putBlob`/`putResult` keep their boolean API on top. `readFleetSettingsV1`: empty access = not named; then the fleet facts' access (same answer as the one resolver); read-only only without facts.
2. Uploader (`F/📤️uploader`): spool bound = 1 % of the disk's free room / 8 KiB per entry, clamped 4,096..262,144 (`spoolBoundV1`, schema `spool`); a job that must wait is REWRITTEN IN PLACE (never needs a slot, so back-pressure cannot lose it); no try count: a job ends when uploaded, settled by the fleet, refused for good (new reason `upload-refused`), its local entry is gone (`upload-entry-gone`), stale/diverged, or older than 6 h (`upload-expired`); backoff doubles to 5 min; capacity (507) and busy are retried, not failed; the drainer lives while any job waits (idle exit 15 min, was 15 s), keeps an in-memory queue refilled from one directory listing per second (no per-iteration stat of the whole spool), and a drainer of another cache identity (endpoint|generation|token) is replaced (`uploader.identity`, `--takeover`). `shareFleetUnitAwaitingV1` (`F/🟦️.ts`): at a full spool the compile waits up to 30 s while the cache answers (back-pressure) instead of dropping.
3. key-incomplete (`UC/🔏️key`): files below an unpacked registry crate directory are covered by the key (name+version fixed by the lock file), `key.environmentIgnored` (`SEMIO_COMPILER_RESOURCE_ROOT`), and gap records are scoped per slot AND per proc-macro library (`gapScopesV1`): the first unit of a machine that finds the derive's data file makes every later user of that derive complete from its first compile (was one skipped unit per slot per machine). Design gap left: the first unit per machine and derive is still skipped; making the record fleet-wide needs a shared gap index (AC entry per derive, read before the key is computed).
4. Not changed: `no-compiler-identity` (471 on m06 only, no live growth); `path-dependent` (genuinely unshareable); server admission (507 only from the blob bound, 4,454 in 4.7 h, retried now).
