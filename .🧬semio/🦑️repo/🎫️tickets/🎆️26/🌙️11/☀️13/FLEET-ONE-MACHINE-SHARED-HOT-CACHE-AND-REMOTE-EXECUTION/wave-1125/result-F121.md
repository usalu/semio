## 2. Law `⚖️laws/👓️image-lease-readers`, per call site on the TypeScript syntax tree
Uses `typescriptCompilerV1()` (the repo's loader, as `test-store-isolation`). Rule: a call whose callee matches `openers` (fs openers plus the two collector functions that take a mount path) and whose arguments name a mount pattern or a name declared from such an expression must sit inside the arguments of a `leaseCallees` call (`withNativeImageSharedReadV1`, `readUnderImageLeaseV1`, repository store scopes, `reader.run`, `held`, the sample constructor), or inside a function with a `leasedParameters` parameter (reader type, `leased`, `RepositoryToolingStoreV1`/`RepositoryCacheStoreV1`), or be a documented site. Names follow declarations to a fixed point; a name declared inside a top-level statement counts only in that statement (a global name taint produced false hits: unrelated `path` variables).
- Schema: `openers`, `leaseCallees`, `leasedParameters` replace `leaseMarkers`; entries need `site` (a whitespace-free fragment of the call). Classes `custody`, `metadata-probe`, `test-support`.
- Allowlist: the 13 file-level entries are gone (a file that only names or passes a path is no longer a violation); 3 call-site entries remain, all `metadata-probe` `existsSync(mount)`/`existsSync(store)` (doctor graph and dependencies probes, gc dependencies).
- Oracle `🐍️.py`: independent Python tokenizer implementation (strings, templates, regex literals, generics, bracket matching, declaration extents, function heads and bodies, top-level units). Verdicts (named files, unrouted files, `path:line:opener` sites, stale entries) equal the TypeScript law on 22 corpus cases and on the whole repository (25 named files, 0 sites, 0 stale).
- Proof: corpus case "a file with one leased and one unleased read" yields exactly the unleased line; the scratch repository test has `mixed.ts` (one leased `readdirSync`, one plain `statSync` at line 5) failing with `mixed.ts:5 statSync` and the fixed file and a test file passing; the oracle agrees on the scratch repository. Before the gc was routed the repository test failed on exactly the two gc calls (census line 195, `collectUnpinnedDependencyGenerationsV1` line 225), after routing it is green. Law 5/0.
- Limits: a path handed to a function in another file (a parameter) is invisible; that is why two helper names (`censusNxToolingStoreV1`, `collectUnpinnedDependencyGenerationsV1`) are listed as openers. A settler or store that is only constructed with a mount path (`sharedClosureSettlerV1({cacheRoot})`) is not an opener call; its reads are covered by the leased section, not by the law. Name matching is by text (a callee named `held` counts).
