## 1. Dedupe through the shared-read helper
- Decision on writing: dedupe writes only copy-on-write clones that replace a file of identical bytes (temp clone, `chmod`, `utimes`, rename), so it charges no bytes and needs no storage reservation. The lease an image's content writers hold (the stores keep the image `shared`, `withRepositoryCacheStoreV1`) is the shared mode; the exclusive mode stays with retirement, regrow and detach. So dedupe uses the same shared lease as the readers, not the store custody (which needs an invocation, a phase control and a charge that `runCacheLedgerCommandV1` neither has nor needs). The probe file of the clone check is written inside the same hold.
- `G/👯️dedupe/🟦️.ts`: `DedupeRequestV1` has a required `reader` (`DedupeReaderV1 = Pick<NativeImageSharedReaderV1,"run">`). Every touch of the tree is a short step inside `reader.run`: one `readdir`, one batch of at most `dedupeEntriesPerHold` (256) `lstat`s, one hold of at most `dedupeReadChunksPerHold` (8 MiB) of a hash read (the file is opened and closed per hold, positional reads, so no descriptor is open while the lease is given back and a large file does not pin the image), the clone probe, and the whole check-clone-rename of one replacement including its cleanup. Both limits are schema entries with English and German descriptions (`G/🧬️schema/🔣️.json`). The reader's own hold limit (2 s) and idle release (250 ms) apply, so a waiting exclusive writer waits at most one hold plus one step.
- `G/⌨️command/🟦️.ts`: `CacheCommandContextV1.leaseDirectory` (set to the repository lease directory by `runCacheLedgerV1`); per target one reader (`imageDirectory` = the partition directory, same resource as the stores, wait bound `imageReadLeaseWaitMilliseconds` 30 s), the presence `stat` of the base inside it, closed in a `finally`. Without a lease directory the command refuses with a texts entry in both languages (`dedupe.leaseRequired`). A target whose run throws (a refused lease, a bug) is reported as `dedupe.failedTarget` (both languages, JSON row with `failed`), counts as failed (exit 1) and the other targets still run; cancellation is rethrown and ends the command. Progress: `dedupe:lease <id>` before the first lease wait, the existing per-file ticks, cancellation also ends a wait for the lease.
- Texts added to `L/⚡️caching/💾️storage/🧾️ledger/📖️texts/🔣️.json`.

## 2. The law sees dedupe's path construction, whatever the expression shape
`W/🟦️.ts` judges a call that opens a path (or hands it to `dedupeTreeV1`, now an opener helper) when its arguments carry a path below an image. New schema-first policy keys: `rootPatterns` (helper calls `cacheAreaDirectoryV1|cacheAreaHomeV1`, `budgetPolicy.partitions`, `repositoryCacheBudgetV1(..).partitions`), `rootTypes` (`CachePartitionBudgetsV1`, `RepositoryCachePartitionV1`, `DedupeRequestV1`), `leasedArguments` (an opener call that hands a `reader` to its callee), `carrierMethods` (`push unshift add set`), plus the class `unrouted`.
Data flow over the TypeScript AST, to a fixed point: values from the seeds go through variable declarations (type annotations against the root types), parameters (typed and defaulted), assignments, for-of/in bindings, member/element access, templates, ternaries, spreads, and the arguments of calls to functions declared in the same file (argument to parameter; not when the call itself is leased); `candidates.push(path)` / `map.set(k, path)` carry into the receiver. A name that is only a property name or object key is no reference (the old text rule flagged `other.directory`). Top-level declarations count file-wide, others only in their top-level statement. Dedupe's old base was `join(workspace, partition.directory, "m", ...)` with `partition = budgets[...]` and `budgets: CachePartitionBudgetsV1`: invisible to the old law, now `stat(base)` and `dedupeTreeV1({base})` fail it.
Oracle `W/🧪️tests/🐍️oracle/🐍️.py` reimplements it on tokens (declarations with generics and type annotations, loops, function heads and parameters, assignments, call-argument flow, carriers, template substitutions); its tokenizer no longer glues `>` to `>=`/`>>=` (a TypeScript generic before `=>`). Verdicts equal the TypeScript law on 42 corpus cases and on the whole repository (TS and oracle both 11 sites before the entries, 0 after, 0 stale).
Proof of the fix: corpus case "the old dedupe pattern" yields exactly `stat` and `dedupeTreeV1`, "the fixed dedupe pattern" (reader.run around the stat, reader handed to the walker) yields none; the new scratch-repository test writes the old walker (readdir/lstat/unlink without lease, base from `DedupeRequestV1`, results stored in a list and read back) and the old command as files: both fail with the exact call list, the fixed pair passes, the oracle agrees. Other new cases: area helper through assignment and loop, template/ternary/spread, parameter fed by a same-file caller (and the same inside the reader), key names, typed parameters without initializer, loop binding over the partition table, list and map carriers (and a clean list).
Real dedupe files: 0 sites with the lease; the law would fail them without `reader.run` (the scratch pair is the same shape).
