# Result E31 (offload-tests)

## 1. Offload tests: green, root cause was test drift against the live fleet (no product regression)
`🌐️remote-execution/🚀️offload/🧪️tests`: cluster 9/9 (was 1/9), main 31/31 (new law test), timeouts 6/6 (was 5/6), determinism 6, signed-fleet 1, fleet-store 1, failure 2, toolchain 4; dependants of the helper: graph compiled-closure 5, mounted-sources 29, host-capacity cargo-scaling 10.
Root cause: `repo test-file` and the suite runner set `SEMIO_WORKSPACE_ROOT` to the live checkout. The offload tests built their environment from `process.env`, so the requester resolved the fleet facts of the live checkout; the test's cache endpoint `127.0.0.1:<port>` is "a leftover pointer that the facts supersede" (`pointerSupersededV1`, no `SEMIO_REMOTE_CACHE_ENDPOINT_OVERRIDE`), so the wrapper uploaded the action blobs to the LIVE fleet cache while the test cluster's worker read its own cache: worker answer `Missing blob <digest>/344`, mapped to `no-idle-machine` (the 8 of 9 failures, "probe counter 0" in the cache-endpoint test, gRPC transport error in the upload-hang test). Side effect before the fix: those tests wrote blobs and offload counters into the live fleet store of the checkout.
Fix (test side, `🚀️offload/🧪️tests/🧰️workspace/🟦️.ts`): `testRustEnvironmentV1` never names the running checkout (`SEMIO_WORKSPACE_ROOT`, `SEMIO_UNIT_CACHE_WORKSPACE_ROOT` removed unless a test passes them in `extra`); law test in `🚀️offload/🧪️tests/🟦️.ts`. None of tonight's landings (door, idle endpoint, fd budget, breakers, env scrubbing, `sources-v2`, no-incremental) broke offload; the cluster test also proves unit-cache, remote execution, cache and signed paths end to end (remote compile, door verdict, twin checkouts, diagnostics byte-identical, proc-macro, path-dependent fallback, worker kill, SIGTERM cancel).
General rule (same family as E30 finding 1): a test that builds a requester environment must not inherit `SEMIO_WORKSPACE_ROOT` from the suite envelope.

## What other lanes must know
- Offload is healthy: do not chase `no-idle-machine` in offload tests; if a requester environment in any test resolves the live fleet facts, the test talks to the live cache (check for `SEMIO_WORKSPACE_ROOT`).
- Any test that sets a cache endpoint pointer must either not name a workspace root or set `SEMIO_REMOTE_CACHE_ENDPOINT_OVERRIDE`.
- Path-length laws (view roots 120, test sandbox root) and cargo/workspace-root laws need different bases: short laws `/tmp` (tmpdir on Windows), cargo laws the artifact dir.
