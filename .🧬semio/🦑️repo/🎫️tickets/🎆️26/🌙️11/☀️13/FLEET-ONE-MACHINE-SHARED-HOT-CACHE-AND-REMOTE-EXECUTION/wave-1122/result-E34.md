## 2. Running Nx daemon and a newer authorizer bundle
Design: the daemon already has a quiet-time timer (`yieldTimer`, 5 s) that drains a finite daemon with no open request and no attached client when an eviction asks for its namespace. The same timer now also asks whether a bundle beside its generation was used or created after the one it was born with (`SEMIO_NX_AUTHORIZER_ROOT`, pinned in its environment). If so it calls the existing `drain("Superseded by a newer authorizer bundle")`; the existing path settles requests, releases the bundle lease and ends. The next client run finds the namespace not live and starts a daemon with its own (current) bundle. A request in flight always finishes (the check needs `activity.open===0` and `attachedClients()===0`).
- `🏃️…/🔏️authorizers/📦️bundle/🟦️.ts`: `supersedingNxAuthorizerBundleV1(toolsRoot, dependencies, current)`. "Used" time is `max(birthtime, mtime)` as `newestNxAuthorizerBundleV1` and `touchNxAuthorizerBundleV1` (every client provision touches the bundle it runs, so a landing is visible as soon as one client used the new bundle; reverting to an older source makes the older bundle the most recently used again, so no flapping). Only candidates newer than the current one are verified with `nxAuthorizerBundleHoldsV1`, so an unchanged tools image costs one listing plus one stat per bundle per tick; bundles of another generation, or that do not hold, never supersede.
- `🕸️graph/🏁️startup/🚏️admission/🟦️.ts`: pure `nxDaemonSupersededV1({kind,openRequests,superseded})` (finite only, no open request). Watch daemons are excluded on purpose: a developer's watch daemon has no automatic restarter; the developer restarts it (as before).
- `🕸️graph/🏁️startup/🚦️service/🟦️.ts`: imports and the timer wiring (one added statement before the eviction probe).
Tests: bundle 8/0 (new: supersession by use and by creation, revert case, other generation, non-holding candidate, missing root or current); admission 55/0 (4 new rows `superseded` evaluated by TS and by the independent Python model `🐍️.py` with identical results, plus a source test pinning the wiring and that the drain stays inside the quiet guard). Other members' tests listed in `T/landings.md` (section E34).
