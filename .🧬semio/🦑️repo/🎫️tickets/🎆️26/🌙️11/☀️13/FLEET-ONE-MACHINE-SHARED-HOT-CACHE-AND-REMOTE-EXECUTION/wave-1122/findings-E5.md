For E3 (path remaps / divergence): the largest offload decline is `unmapped-path` (2350 of 4665 logged attempts on the coordinator, 50 %): "no --remap-path-prefix covers the module directory X / the working directory". Those are units compiled with cwd = package directory whose module directory above the manifest is not covered by Cargo's trim-paths remap (stdio/gltf, framework modules, plugin crates). I tried to lift the decline in the planner and measured it: with an uncovered cwd the worker's rlib differs from the local one by the 16-byte crate hash (SVH; rmeta differs too), so the decline is correct. The fix belongs in the remaps the launcher gives rustc: if every unit has a remap covering its module directory and its cwd, these units become offloadable and also machine-independent (same cause as AC divergences). Not changed by E5.

## Round 2 plan and coordination (E3 had written no result or findings and touched no launcher remap file when I checked at 00:55; I did it)
- Root cause of the unmapped-path declines: Cargo's `trim-paths = "object"` remaps only the working directory (workspace root, or the package directory for a standalone package). A package compiled in its own directory whose one-line shim includes the module directory above the manifest has that directory uncovered. The two things that made worker and local bytes differ were (1) no remap for the module directory and relative source names (the worker's cwd is the virtual root, not the manifest) and (2) the planner dropping the requester's remaps that lie inside the shipped directory (the manifest remap `=.` was lost, so names under the manifest were recorded as module names remotely).
- Change (E3 please keep in mind when touching unit keys): `moduleRemapArgumentsV1` (`🚀️offload/🗺️paths`) is called by the rustc wrapper before the key is computed. For such a unit it inserts `--remap-path-prefix=<module dir>=<path below SEMIO_UNIT_CACHE_WORKSPACE_ROOT>` before Cargo's remaps (the last matching remap wins, so the package directory keeps Cargo's `.`) and makes a relative source absolute. This changes the argv, so the unit key of exactly these units changes once; the names recorded are checkout-independent (relative to the checkout) and identical on every machine, which is also the AC-divergence cause for them. The planner now carries every requester remap that lies inside the shipped directory, in order, to the worker.
- Cache restarts: the cache sidecar is the group server's process; ops note: 124 `serving the cache` lines in its log, each preceded by an outage of 2 to 20 minutes (see result-E5.md).
