# Native Shared Border Resolver

The Rust counterpart lives beside the TypeScript presentation resolver and consumes the same neutral cases. Stable numeric source and owner IDs decide ties; fixture adapters map the existing ASCII textual identifiers to these IDs. State order matches the browser resolver.

The incremental cursor ingests one source, resolves one event or contributor, and retires one retained item per call. Its owned AVL nodes and exact-length boxed contributor storage expose exact backing capacity, push/step allocation preflight and retirement release demand. It preserves state priority, partial collinear overlap, disjoint spans, deterministic ordering and perpendicular crossing independence.

Tests compare the shared cases, reversed input, incremental and batch output; assert preflight bytes against actual backing changes; cancel at every sampled stage; and compare owned ordering, rotation and node reuse against the standard ordered map. Existing TypeScript vectors independently compare with lodash and Ajv. Native compilation is pending repository memory admission; no native pass claim is made yet.

## Fixed-Grant Runtime Output

The production worker grants 64 KiB of copying/capacity per step. A full contributor list can exceed that with more than 8192 coincident sources. Runtime rendering therefore uses an ownership-only cursor that emits the winner and final contributor ID without allocating a contributor array. The full-list cursor remains the cross-language batch contract. A 9000-source stress regression checks every runtime step against the actual fixed worker grant and incrementally retires all backing.
