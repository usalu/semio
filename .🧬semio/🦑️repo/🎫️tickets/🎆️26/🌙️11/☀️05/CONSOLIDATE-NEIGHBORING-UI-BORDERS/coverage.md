# Border Surface Coverage

- Input and Textarea use a shared frame on their non-void wrapper, including collapsed and disabled states. Stepper uses one frame and three cells. Button delegates to ButtonGroup; Action, ActionGroup, ButtonGroup, Toggle, ToggleGroup and Select already register frames. Checkbox is a native unstyled input and does not draw a custom rectangular frame.
- Ribbon zones, groups and toolbar and the Navbar control row now remove gaps between control frames. Footer and Navbar register their outer edge. Tabs list already groups adjacent triggers; its root gap separates the tab list from its content, and the trigger gap separates icon from text.
- Dialog content registers its frame; DialogFooter and UIDialog choice rows remove gaps between neighboring controls. Dialog header spacing separates title and description; dialog content padding and row gaps separate content, not adjacent frames. Choice descriptions retain their vertical spacing.
- Form itself draws no border. Tree rows do not independently frame neighboring controls; its content spacing, ghost outline and empty-state card are distinct surfaces. OverviewCard delegates its frame to WindowChrome; chip gaps are internal icon and text spacing. Table uses collapsed borders with one bottom edge per row; HistoryTable draws row separators and overlaps avatars intentionally. Avatar and PresenceBar circles are identity decorations, not adjacent rectangular chrome.
- Panel delegates its window outline to WindowChrome and its dashed empty drop target is an independent drop affordance. WindowPane delegates its outline to the hosted chrome. IconSelector frames its distinct preview and content surface with deliberate internal padding. Select's menu viewport padding and item icon gaps separate unbordered menu content; its trigger and popup already have frames.
- Native wgpu remains a separate implementation gap: `push_control_border` and `push_chrome_border` emit four immediate solids without owner or interaction priority; Stepper emits divider solids separately. DrawList splits output into scissor, clip and overlay layers and enforces retained-output admission, so shared segment records must survive those boundaries and be resolved before publication with appropriate accounting. Inferring border identity from arbitrary solids would conflate backgrounds and content.
