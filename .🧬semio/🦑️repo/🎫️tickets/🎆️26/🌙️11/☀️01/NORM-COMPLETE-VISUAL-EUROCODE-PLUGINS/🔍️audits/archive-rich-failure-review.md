# Archive rich failure review

The current maintenance ladder archive merger moves each reachable original cause into an owned lifecycle slot. Primary-only and primary plus work retain their producer errors. Work-only becomes the lifecycle primary without an outer refusal and remains the independent work refusal with one. An outer receiving refusal is paired as the receiving quote when a producer primary exists, while its receipt and context refusals remain separate. The lifecycle effects use the caller-supplied physical progress.

The terminal close caller obtains progress from the returned step or original retirement failure. The history caller uses its taken physical receipt when available and otherwise the failure progress. The current receiving implementation constructs only a Value primary with no independent outer work refusal, so the merger assertions hold for this actual call path. This is a source review, not runtime verification.

The caller law should exercise producer primary plus work alongside outer quote, receipt and context refusals, and the work-only cases, verifying each owned error and the physical receipt.
