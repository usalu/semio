## 2. Statics, deflection, stations (review findings 32, 34)
New module `⚖️checks/🧮️catalogue/📉️continuous` (`Layout`, `Stiffness`, `solve`, `Solution`, `Profile`, `span_deflection_m`, `cracking_ratios`): flexibility method with piecewise EI (EI1 / EI2 over a fraction of each span at internal supports, cl. 5.4.2.3), spans from `Layout::of`: simple `[L]`, end `[L, L2]`, interior `[L2, L, L2]`, cantilever `[L2, L]` (cantilever moment determinate, loaded neighbour lifts the tip).
- Oracles: `🧰️scripts/en1994-continuous-oracle.py` (numpy flexibility method and PyNite, split members with EI2) agree to 1e-4 on 11 cases (two equal, end unequal 8/6, interior 6/8/6, cantilever 8/3, load patterns, cracked and uncracked). Closed forms: M_B = qL²/8, 9qL²/128, M_B = q(L1³+L2³)/(8(L1+L2)), 5qL⁴/384EI. Same values in the Rust tests and the stdlib oracle (rows E1-14 of `🧪️tests/🧮️catalogue-en1994/🥒️.feature`).
- Checks: `deflection` uses the solver per span position (permanent on all spans with n_L stiffness, variable on the designed span with n_0, EI2 over `crackedLengthFraction`, cantilever limit with 2L); the old `m_to_q` 1/16 inversion (wrong for the three-moment moments) is gone from beams (still used by slabs). Stations use `Profile` (all-spans-loaded shapes of the span position, normalised to the governing values) instead of the two-equal-span shape.
- New check `en1994.5.4.2.3.cracked.<id>` (C-04/C-49 cracked global analysis option): support moment ×r_hog and span moment ×r_sag from the cracked/uncracked ratios, against M_pl,Rd; remedy: uncracked analysis (`crackedLengthFraction = 0`) or less load.
- New check `en1994.6.2.2.4.vm-sagging.<id>`: M_Ed(x) against M_V,Rd(V(x)) along the span with the web strength reduced by (1−ρ) about the real plastic neutral axis (`shear_reduced_sagging_moment`; equals the symmetric formula for a web-centred axis).
- Scene: supports, hogging bars and cracked zones from `facts.layout`/`stiffness` (EI2 intervals, or contraflexure zones when the fraction is 0), multi-zone ids `:rebar-hogging[-n]`, `:cracked[-n]`, `support-m[-n]`; deflection line from the solver (`statics::uniform_load_line(&Layout, Stiffness)`), the deflection marker moves with the span position; deformation overlay of beams with hogging is `Motion::Ramp` (animated load ramp).
