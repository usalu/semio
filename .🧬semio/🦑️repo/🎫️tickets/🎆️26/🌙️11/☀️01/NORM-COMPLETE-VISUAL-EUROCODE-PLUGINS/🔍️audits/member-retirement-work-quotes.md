# Member Fault And Partial Retirement Quotes

Member close selects active erased box first, then outer fault, inner fault, and, once decoder is absent, partial. artifact_retirement_admit_owned on a present pending value with empty active slot performs its native retirement birth and reports actual work; the paid successful or failed allocation attempt is one work. artifact_retirement_box_close_step returns zero for an absent box, releases the terminal box shell for one work, or calls the actual nonterminal owner once and returns its work and original error. A Member preflight must quote that same priority: one for a present pending birth or terminal shell; active nonterminal owner.next_computational_work(body) for its selected action, using the same body span. Preserve actual result/error progress and commit work even on refusal.

RetainedHistoryOpMetaFault and RetainedHistorySourcePartial both derive RetireOwned. The normal derived retirement sequence uses Sequence and Deferred, each with explicit one-action work quote; ControlledRetirement selects real frontier and delegates its quote. ValueError retires borrowed messages through leaf and owned messages through String; JsonError chooses leaf or String; OriginalReceivingPrimary uses derived-style Sequence/Deferred of optional errors. Those paths have quote-capable primitive sequence/leaf/string/option owners in current source. This is static analysis, not proof of every populated nested payload.

A populated partial can contain HistoryEdits, an alias of PagedList<HistoryEdit, usize::MAX>, and nested SharedUtf8 in history edit/conflict metadata. PagedListRetirement and SharedControlledRetirement implement RetirementCursor but currently do not override next_computational_work; the default returns UnsupportedOwner. Therefore a genuine cancellation drain containing either owner can eventually refuse its selected work quotation. The quote must follow each cursor’s actual next action and retained ownership, not derive CPU from receipt bytes/items. Other nested retirement cursor types should be checked as each concrete populated branch is exercised; static presence of a derive alone does not prove complete quotation.

Recommended native regression: build real history source that reaches a partial with a nonempty edits page and shared actor, cancel using the original caller, preflight each selected work quote with zero-fuel denial followed by a funded turn, compare independently observed physical spans and actual reported work, retain all refusal envelopes, and drain to terminal. This is not yet a runtime result.
