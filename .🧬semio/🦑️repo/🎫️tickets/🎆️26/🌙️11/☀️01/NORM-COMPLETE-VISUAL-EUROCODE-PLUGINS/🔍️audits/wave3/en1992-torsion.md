# W3-EN1992-TORSION report

## 1. t_ef lower bound (EN 1992-1-1 6.3.2(1)): real defect, fixed test-first
- Clause: t_ef = A/u, not less than twice the distance between the edge and the centre of the longitudinal bar. The nominal cover c_nom is measured to the outermost reinforcement, the links (4.4.1); the repo's own 3D reinforcement (`scene/foundation/reinforcement`, inset = cover + link + phi/2) confirms this. The Rust (`torsion_case`, the torsion check, the scene diagram) and the oracle used 2 c + phi_l, so the link diameter was missing.
- Direction: too small a t_ef, hence conservative (T_Rd,max too low, about 15 % for 300 x 550 with 8 mm links: 105 mm instead of 121 mm). Fixtures `torsion-strut-*` (400 x 800, A/u = 133 mm governs) are unaffected; 17 other fixture members would change if torsion were checked on them, but no committed feature row covers them.
- Fix without a schema change: the catalogue input `c` is documented as "Concrete cover c to the bars", so the member builders now pass c = cover + link diameter. New pub fns in `checks` (`📋️members/🏗️resistance-and-serviceability-checks`, re-exported in `📋️members`): `torsion_cover_mm(member)` and `torsion_t_min_mm(member)` = 2 c + phi_l; `torsion_case` and the torsion check use them.
- Tests (hand value): catalogue test `e24_the_wall_limit_reaches_the_bar_centre_through_the_link` (300 x 550, c = 35 + 10, phi_l 25: t_ef = 115 mm, A_k = 185 x 435 mm2, u_k = 1240 mm; old reading 95 mm lost to A/u = 97.06) and Gherkin row `t-01-tef-link-de` (0.115 m). Oracle `🧭️families` follows the clause (`T_MIN_WALL(cover, link, phi_l)`), self-check updated; the third-party `⚖️compliance` shapely twin takes the catalogue `c` and is unchanged.
- OPEN, other lane: scene `diagrams/🦀️.rs` ~263 still calls `torsion_section(2 * m.cover * 1000 + phi_l)` (crate being split by W3-EN1992-SPLIT); request posted in requests.md to use `checks::torsion_t_min_mm(m)`. Until then the picture's t_ef label can differ from the check on slender sections.

## 2. cot theta (6.3.2(2)): consistent, no change
- Clause: for combined shear and torsion the same strut angle theta applies to both (6.3.2(2) / eq. 6.29 context). Implementation: one `cot` from `shear_capacity_n` of the shear-governing combination is used for the links (A_sw/s = T/(2 A_k f_ywd cot) after the shear share V/(z f_ywd cot)), the longitudinal steel (T u_k cot/(2 A_k f_yd)), V_Rd,max and T_Rd,max in the interaction (eq. 6.29). So one theta per member in the combined design.
- T_Ed (torsion-governing) and V_Ed (shear-governing) are taken independently: an envelope, equal or above any single combination, so safe. The standalone family `6.3.torsion` uses cot = 1 (maximum of T_Rd,max = 2 nu f_cd A_k t_ef sin cos), the pure-torsion capacity; combined torsion is governed by `interaction`, which uses the shared cot. Nothing to fix; the oracle reproduces both.
