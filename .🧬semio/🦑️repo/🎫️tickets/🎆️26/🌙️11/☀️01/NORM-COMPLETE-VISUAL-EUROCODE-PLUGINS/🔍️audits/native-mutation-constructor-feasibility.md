## Existing Typed Aggregate Handoff Port

The current neutral owned decoder already exposes object-safe NativeReceiver<I,T> and NativeMappedReceiver<I,Leaf,Aggregate>. The mapped receiver owns the real child receiver, partial native leaf and aggregate output through separately granted handoff/close stages; its NativeReceiveMap<Leaf> author contract permits only an infallible allocation-free ownership move. Source: framework value owned/🔄️map/🦀️.rs. This can wrap a genuinely received norm leaf in its already-authored aggregate variant without requiring a giant aggregate NativeReceive implementation or a cold FromValue callback. A direct per-variant NativeReceiveMap implementation belongs to the aggregate owner, which already depends on its leaf cohort; putting it in the leaf cohort would create a dependency cycle. Its birth and source admission still need the actual original grant/control, followed by the existing ArtifactMutationSource and genuine private semantic producer. This is an available concrete next port, not an implemented/mounted norm constructor claim.
