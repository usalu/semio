# Native Oracle Catalogue Ownership and Coverage

The actual EN1999 mutation gate stopped before compilation because its kinds-catalog test embedded the entire 407,413-byte oracle registration file into a compilation unit with only 180,165 bytes remaining. The same pattern embeds larger registrations in other cohorts.

The existing shared mutation-vector runner explicitly treats committed fixtures as runtime test data. All fifteen mutation crates already declare both this runner and the canonical fixture-reader. The native build graph's inputs.mjs constructs nativeTestSources from the declared nativeSources; every cohort explicitly includes its JSON assets, and project-assembly replaces ordinary test input groups with those native test groups. Thus the unchanged registration files remain declared, hashed runtime inputs.

Thirteen native kinds tests are being strengthened in their original locations to parse actual mutationCatalogs[].vectors[].mutationId registrations through that shared runner; EN1996 and DIN4108's existing local tests also receive that membership check. No test is relocated, no input is copied, no fixture scenario is removed, and source admission/budgets are unchanged. The original enum/descriptor parity and uniqueness assertions remain. Seven new neutral cases plus independent serde_json/Ajv checks distinguish a real registration from merely mentioning a kind in prose.

The new independent Bun gate observed one real gap: EN1997's insert-characteristic-basis and insert-ground-investigation are declared native kinds and have existing apply/duplicate fixtures but no actual vector registration. Their names occur in catalog kinds arrays, so the old substring assertion falsely accepted them.

A separate read-only census found repeated identical catalogue IDs across six cohorts. Their non-vector metadata and per-kind source/fixture paths are compatible, and no same-scenario identity has conflicting metadata. There are 5,701 catalogue scenario references but only 2,827 unique references. Those facts do not authorize dropping any unique coverage. There are also twelve registered scenario paths that do not exist; the exact list is in generated/catalogue-scenario-audit.json. These require source-backed reconciliation rather than silent filtering.

The repair now uses the explicit reference-diff contract and retires owned cold diffs. All vector replay, inverse, wire, binary, message and outcome checks remain.
