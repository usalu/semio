## 1. EN 1993 base plate c-strip (fixed)

Defect: `F_c,Rd = f_jd b_eff l_eff` used `l_eff = plate width` (unconservative for a plate wider than the T-stub footprint).
Fix (EN 1993-1-8 6.2.5(3), Fig. 6.4): flange T-stub footprint `b_eff = min(t_fc + 2c, L_p)`, `l_eff = min(b_fc + 2c, B_p)`; `b_fc` is read from the section of the joint's member (`column_flange_width`, no value invented: a joint without member section gets no base-plate verdict, like any other invalid input). The fixed point (`c`, `f_jd` with `A_c0 = b_eff l_eff` and the block spreading `A_c1`) moved into one kernel `joint_components::base_plate_c_strip` (+ `CStrip`), used by the foundation block checks (bearing, c-bend, M_j,Rd, scene c-strip box) and by the joint base plate (`special-parts-checks::base_plate`, also `k13` now with `b_eff`, `l_eff`). The required `c` of the c-bend row solves `(t_fc + 2c) min(b_fc + 2c, B_p) = C_Ed/f_jd` (`base_plate_c_required`, closed quadratic, plate-limited branch) instead of dividing by the plate width.
Also: with the whole section in compression (`T <= 0`) the bearing and c-bend rows use the larger of the two flange compressions (`base_flange_compression`, moment equilibrium about the opposite flange line) instead of the full `C` on one stub, so the new narrower stub does not turn pure compression into a spurious failure. The web T-stub is not added: neglecting it is conservative (documented in the explanation as the flange T-stub). Incremental-evaluation edges `foundationBlocks -> members/sections` and `basePlate joints -> sections` added (units file) so the read audit stays complete.

Hand values (kernel with constant `f_jd = 40 N/mm2`, `t_fc 17`, `b_fc 240`, `t_p 30`, `f_y 355`, `gamma_M0 1`): `c = 30 sqrt(355/120) = 51.5994 mm`, `b_eff = 120.1988 mm`; plate 450 mm: `l_eff = 240 + 2c = 343.1988 mm`, `F_c,Rd = 1 650 084.05 N` (old code: 450 mm, 2 163 k N); plate 300 mm: `l_eff = 300`, `F_c,Rd = 1 442 386.05 N`. Required `c`: `(17 + 2c)(240 + 2c) = 8750 -> c = 8.5206 mm`; plate 250 mm: `(8750/250 - 17)/2 = 9.0 mm`.
Showcase block-bp (plate 300 mm, c = 51.6 mm so `240 + 103.2 > 300`): bearing 0.24265, M_j,Rd 0.35929 unchanged; the c-bend utilisation moves 0.117895 -> 0.165130 (required c 8.52 mm instead of 6.08 mm). Wide plate 450 mm: bearing 0.218655 (f_jd 37.19 MPa, l_eff 347.0 mm), c-bend 0.180276. Fully compressed (N -300 kN, M 20 kNm, levers 150 mm): `C_l 83.3 kN`, `C_r 216.7 kN`, bearing 0.150214.

Tests and mirrors: `special-parts` clause test (hand values + oracle), oracle rows `jc_cs_leff_{free,plate}`, `jc_cs_fc_{free,plate}` (scipy), `jc_cr_{free,plate}` (brentq) with 6 feature rows and adapter arms; `plate-wiring` tests (new wide-plate / fully-compressed test, c-bend value updated); oracles `plate-and-foundation` (strip fixed point, bisection `required_c`, numpy statics for the all-compression split, wide-plate and all-compression keys) and `check-outcome` (flange width from the section, same rules, bisection) with the feature row `pass-v2-47` (0.117895385 -> 0.165130071); `plate-and-foundation` feature gets 3 scenarios. Unchanged by design: `fail-v2-58` (plates-fail c-bend 1.5714, plate-limited).

## 2. EN 1997 characteristic values from CPT/SPT (fixed, unverified basis)

Defect: every reading depth of every sounding was one sample (n = 50..500), so `k_n -> ~0.1` and `X_k -> mean`.
Fix: the statistics run over independent samples, one per investigation point and layer (the mean of the readings of that sounding inside the layer, i.e. spatial averaging), t-distribution of `n - 1` degrees of freedom over the soundings (`derive_layer`, `independent_samples`). Fewer than 3 samples: cautious estimate = lowest reading inside the layer (as before for few data). The rule is the new registry row `ndp.en1997.2.characteristic-samples-per-sounding` (value 1; `k > 1` splits a sounding into `k` depth segments, the scale-of-fluctuation reading if a printed text supplies one), status **unverified**: the repo spec (`en1997-en1998-target.md` G-02/GI-13) states the sample set `x_1..x_n` without independence rule or scale of fluctuation. The derivation check records the row, so a passing verdict is `unverifiedBasis`; the explanation says so (EN + DE) and reports sounding and reading counts; the remedy asks for more investigation points.
Hand values (worked example, now three CPT soundings): clay samples 42.4 / 40.3333 / 43.5 kPa, `X_m = 42.0778`, `s = 1.6077`, `V_x = 0.03821`, `k_n = 2.920/sqrt 3 = 1.6859`, `X_k = 39.367 kPa`; counting the 10 readings as samples would give 40.55 kPa (`k_n` 0.58), asserted larger. Silt: two soundings, lowest reading 28 kPa. Sand phi' from three SPT soundings: 40.189 deg. A single dense CPT (200 readings) stays one sample and falls back to the lowest reading.
Tests and mirrors: Rust tests rewritten (`ground-derivation`, new `an_investigation_point_contributes_one_independent_sample...`), fixture extended to cpt-A/B/C and spt-A/B/C and blessed from the scipy oracle (oracle samples per sounding with the registry row, `readings` field added), feature rows replaced (n, readings, mean, k_n, X_k for clay, silt, sand, single sounding). Registry script: `🧰️scripts/w3-correctness-fix-ndp.py` (row + codegen), fixture script `🧰️scripts/w3-en1997-soundings-fixture.py`.
Side effect to know: the showcase derived values move (sand phi' 40.52 -> 40.62, clay c_u 69.25 -> 66.32 kPa, now two soundings, cautious); the committed check-outcome rows of the showcase come from the compliance oracle, which reads the declared layer values, not the typed basis, so those rows are not tied to these numbers; please watch them in the next build anyway.

## 4. EN 1991 footbridge comfort trigger (fixed)

`footbridge_comfort_required(f_v)` = `f_v < ndp.en1991.2.footbridge-band-vertical-max` (5.0 Hz, EN 1990 A2.4.3.2(1), registry row already present, unverified). The walking row now states whether the comfort verification is required; only inside that trigger it adds the walking-range verdict (1.7..2.1 Hz, registry) with "inside"/"outside"; at `f_v >= 5 Hz` it says no comfort verification is triggered and gives no walking verdict. Lateral/torsional frequencies below 2.5 Hz (row `-band-horizontal-max`) are not in the snapshot and not modelled (said in the text). The 10 kN floor of Q_flk remains flagged unverified (no source in the repo; 10 % of the vertical load is the clause rule).
