## 2. Irregular fastener positions (decision 2): done
- `fasteners[].positions[] {id, xM, yM}` (all layers as above). Non-empty: replaces the regular pattern. `pattern_mm` returns the positions (at most 72 drawn); `pattern_facts` gives count, longest row, a1 (neighbours of one row, rows grouped within 0.5 mm), a2 (neighbouring rows), a3,t (first fastener) and a4,c (nearer edge) from the actual points; a missing neighbour never governs (member span or depth stands in). T-74/T-75 and the pattern-count check use these facts (message names the explicit positions); remedies on spacing fields are not offered for an explicit pattern (`FASTENER_EXPLICIT` bindings).
- Scene: case number `explicit`; `regular(g)` is false so the col/row/a1/a2/a3/a4/count grips disappear; instead two grips per fastener (`px<k>`, `py<k>`, at most 24 fasteners) write `positions[id=..].xM|yM`. Live spacing colouring of an explicit pattern uses the actual pairwise distances (`pairwise_demand`: a pair is admissible when `|dx| >= a1` or `|dy| >= a2`; demand `min(a1/|dx|, a2/|dy|)`, maximum over pairs, combined with the end and edge ratios); function lives in the schema crate (scene crate budget).
- Kinds: `insert-/remove-fastener-position`, `change-fastener-position-x|y`.
