## 2. Solver (loads as an argument)
- `🕸️frame-eigen`: `FrameLoads { nodal [(node, [fx, fz, my])], line [LineLoad{bar, fx, fz, from..to segments}] }` with `design(document)` (explicit `loadX/loadZ`, already factored), `of_case(document, case)` (from `frameActions`, faults name unknown targets / off-grid / reversed ranges), `scaled`, `add`, `vertical_at_nodes`, `horizontal`. `model_with`, `frame_eigen_with`, `second_order`, `second_order_with`, `solve_with_imperfections` take `&FrameLoads`; line loads are added to the refined model as global-frame distributed loads on the segment members; first order is the `first*` half of the same call. Tests: line load M = q L²/2, partial load, superposition, nodal moment, `of_case` faults.
- New `⚖️checks/🕸️frame-envelope` (mounted in `checks-core`, which now depends on `frame-eigen` and `mechanics`; `Cargo.toml` + `Cargo.lock` edited; `joint-row-model` mount moved from special-frames to core so the semi-rigid secant is reachable): `load_sets` builds the ULS combinations by calling the shared `combine_scalar_forces` (EN 1990 6.10a/b, no rule repeated) on unit forces per case, so a combination = factored sum of case load vectors + the explicit node loads; every combination is solved on its own (second order is not additive); `case_results`, `combination_results`, `envelope` (max/min per station and governing combination by largest second-order |M|), `governing_loads`, memoised `combination_results_cached`.
- `joint_frame`: `solve`, `alpha_cr`, `solve_second_order` now use the governing combination; `solve_with_imperfections(document, loads, imperfections)`. Frame checks (`en1993.1-1.5.2.second-order.*`, `.member.*`) evaluate every combination with its imperfection variants and report the governing one by name; sway forces derive from the load vector (incl. line loads).
- Member checks: `combine_member_actions` returns, for members with basis `FrameDerived`, one ULS row per combination from the bar of the member with the largest second-order |M| (N compression positive, V, M) plus the unchanged SLS rows; frame faults give no ULS rows (the frame row reports the fault). Limitation: the frame results of the member basis carry no imperfections (derived in frame-checks), stated here.
