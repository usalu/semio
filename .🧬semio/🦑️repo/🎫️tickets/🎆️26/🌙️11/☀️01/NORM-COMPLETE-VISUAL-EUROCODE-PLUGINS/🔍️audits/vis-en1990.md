# EN 1990 visual vertical (WP-13): Phase 1 and Phase 2 report

Status: written, see "Verification" for the build state. Artifact `⚖️en1990`, `SUBSET = ⚖️en1990/🏅️standards/🔖️1/🪆️subsets/✳️any`. Spec: `📐️specs/en1990-en1991-target.md` section 4.1, 5.1. Code tag `en1990`.

## Built (crate `semio-s-artifact-norm-en1990-scene`, `SUBSET/🎬️scene`)
- Registered in `⚖️en1990/Cargo.toml` (member, `semio-s-artifact-norm-en1990-scene`, `semio-s-plugin-norm-structural-scene`) and in `📦️packages/🦀️rust/📜️script.ts`. Dependencies: `-checks`, `-inferences`, `-model`, `norm-compliance`, `norm-structural-scene`.
- `🧰️kit`: layers (members, decks, actions, supports, annotations), legends, `ENTITY_KINDS` (member, permanent, variable, accidental, seismic, bridgeSls, combination selector), `entity_kind_of`, `entity_dependencies`, utilisation binding by `CheckResult.subject.entity_id`, `check_tone`, `Spec` with ghost style.
- `📍️layout`: members left to right along +X with a 1.5 m gap, persisted `Placement` wins.
- `🧮️combinations`: the generated EN 1990 combinations of the whole structure as matrix columns `family:equation:leading` (STR/GEO 6.10 or 6.10a/b, EQU, accidental 6.11b, seismic 6.12b, SLS 6.14b/6.15b/6.16b) from the same generator and the same action extraction as the report (`inferences::actions_with`, `context_for`); `active` (requested id, else the governing STR column), `column_for_check` / `id_for_check` (a selected check selects its combination).
- `🏗️members`: simply supported members with supports, span dimension bound to `members[].span`, label, clause badge, failure glyphs (STR yielding, EQU overturning, GEO sliding, FAT fatigue), SLS deflected shape `w_net,fin = w1 + w2 + w3 - w_c` as `DeformationOverlay` with automatic exaggeration (L/25 peak, x1 to x200), stacked Fig. A1.1 dimension lines w1, w2, w3, w_c bound to their leaves, L/n limit label, first-mode ghost below f_min; bridge deck plate over each `bridgeSls` with deformation (bridge deflection), vibration ghost (Mode overlay with frequency, participation = acceleration/limit) and acceleration, twist, deflection labels coloured by their checks.
- `⚓️actions`: the load-glyph model. Permanent, prestress, variable (kind by category: variable, snow, wind, thermal), accidental (impact) and seismic actions as Line, Point or Impact glyphs on every member they affect. Glyph magnitude is gamma x psi x E of the active combination; an action outside the combination stays a ghost at its characteristic value; psi rows travel in `LoadCaseRef.psi` (only ordered rows). Badges: consequence class, reliability class with K_FI and DSL/IL, beta against the Table B2 target (tone from `en1990.annex-c.beta`), annex, provisional psi rows, active combination. Combination selector group entity.
- `📈️diagrams` (each with table twin): `matrix` (cells = gamma x psi with opacity, hatched leading action, framed active column, column markers bound to the worst check of the column), `psi` (psi0, psi1, psi2 per used category, dotted when unverified), `reliability` (P_f over beta on a log axis, RC1 to RC3 targets, draggable beta marker bound to `betaComputed`), `form` (reliability circle, linearised limit state, failure domain, design point from the Annex C alphas), `annex-d` (k_n for V known and unknown), `fatigue:<member>` (normalised S-N line m = 3 / 5 with cut-off, range ratio marker bound to `en1990.fat.<member>`, Palmgren-Miner damage for 2*10^6 cycles).
- `🕹️handles`: member span, pre-camber (grip height divided by the exaggeration), magnitude of every action (grip height over N per metre, writes `gk`, `qk`, `ad`, `aEk`), combination selector (CountStepper, `view.activeCombination`).
- Tests `🧪️tests/🔬️unit/🦀️.rs` (33 tests: validity of nine fixtures, unique ids, determinism, member geometry and deflected shape, bound dimensions, mode ghost, bridge deck, utilisation, failure glyphs, glyph kinds, glyph sizes follow the active combination, ghosts, governing default, check-to-combination link, badges, selector, handles for every fixture, span/pre-camber/magnitude/selector writes, placement, dependencies, diagram validity and twins, matrix equals generator, reliability marker, FORM design point, Annex D values, focus, golden scene, Python oracle, 1000-member timing), `🧪️tests/🥒️.feature`, oracle `🔮️oracles/🐍️.py` (gamma and psi factors from the printed tables, glyph magnitudes, Phi(-beta) via scipy.stats when installed, FORM design point on the circle along alpha_E = -0.7 / alpha_R = 0.8, Annex D Table D1, psi rows, S-N slopes, member axis length and bounds).
- Edited outside the scene (owner-adjacent, minimal): `🧬️schema/💡️inferences/🧰️report-helpers` now has `pub fn actions_with` (the old private body of `member_actions`), `member_actions` and `context_for` are `pub` and re-exported from the inferences root.

## Not done (details in `📌️important/requests.md`)
1. Placement fields and `update-placement` (step 9): scene accepts placements, snapshot does not store them.
2. Groups of exclusive actions, Annex D test series, fatigue spectrum and reliability distribution inputs are not in the snapshot, so the Annex D marker, the real Miner damage and the converged FORM run are not shown; the FORM diagram draws the Annex C.7 design point.
3. `view.activeCombination` handle commits need view-state routing in the viewport interaction; today the active combination follows the selected check and the matrix markers.
4. No transient drag preview lane and no `IncrementalNormFamily` / CheckUnit split (same blockers as WP-12), so the 12 ms and 400 ms gates are unmeasured.
5. Mode shapes are half-sine indications, not eigenmodes; bridge twist arrows per 3 m and acceleration contours are labels only.
6. Glyph form per category is fixed (line, point, impact); the EN 1991 geometric load fields are not modelled here (EN 1990 owns only magnitudes).
