## Oracle

`SUB/🔮️oracles/⚖️compliance/🐍️.py` (run with `-I`, stdin / stdout only, no temp files):

- document mode: required values of imposed loads, self weight, snow and wind faces for a snapshot read from stdin; the Rust test compares `CheckResult.computed` within 0.5 %.
- `--catalogue` mode: ~45 entries evaluated by independent means. Third-party: `scipy.stats.gumbel_r` quantiles for c_prob (EN 1991-1-4 / -1-6) and the Annex D snow factor, `scipy.integrate.dblquad` for the configuration factor, `scipy.integrate.quad` for the Annex B admittance functions R_h and R_b, `scipy.integrate.solve_ivp` for the Janssen force balance (pressure and wall friction force by ODE), `scipy.constants.Stefan_Boltzmann`, `numpy.interp` for the c_pe tables. Independent formulation: Rankine coefficient as `tan²(45° − φ/2)`, parametric θ_max by dense sampling of the heating curve. No library implements EN 1991 (`structuralcodes` and `eurocode` do not cover the actions), recorded in the Rust test and the module docstring. The mutation oracle manifest `SUB/🔮️oracles/🔣️.json` is unchanged (its schema is framework-owned).

Findings of the cross-check: the spec example E14-12 (R² = 1.5737, c_s c_d = 1.34354) multiplies η_h and η_b by S_L a second time; the standard defines η = 4.6 (h/L) f_L, which gives R² = 0.03856, ν = 0.2939 Hz, k_p = 3.403, c_s c_d = 0.8444. The code and the tests follow the standard. The spec value for E13-10 (1.10768) uses the rounded coefficients 0.45 / 0.78 / 2.59; the Gumbel quantile gives 1.10691 (0.07 % apart, tolerance 2e-3 in the oracle test, the formula of the standard is implemented). E12-06 uses 273 instead of 273.15 and σ = 5.67e-8 (62407 W/m²; 62437 with σ from scipy, tolerance 1e-3).
