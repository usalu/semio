## 0. The gap audit was wrong for A-61, A-70, A-72
`norm-gaps.md` listed A-70, A-61, A-72 as "missing" ("check fragments absent"). They were implemented since wave 2 (shell: `en1999.1-5.buckle/ring/shear/int/regime`, ρ_o,haz on f_o of a welded shell; sheeting: `en1999.1-4.axial/bend/shear/nm/defl/local`, web crippling rows `…web-crippling.<load>` with null coefficient rows). The audit script only matches string literals and the ids were composed with `format!("en1999.1-5.{suffix}.{}")`. Fix: the check helpers of `CHK/🥫️thin-wall-checks` now receive the full literal id (`mk("en1999.1-5.buckle", …)`), so a literal scan finds all nine. The real remaining gaps were: A-12 net section at holes, A-61 for a real (trapezoidal) sheeting section (the flat strip `b·t²/6` is not a profile), A-51 protected members, and the hard-coded, unregistered shell constants. Those are what this pass delivers. A-62 (deflection with the effective inertia) comes with A-61. A-81 stays "not modelled" (the spec excludes it). A-19 and A-28 stay blocked on the printed coefficients (no value invented).

## 1. A-12 net section at holes (`en1999.8.5.net`)
- Schema first: `evolve.py add-leaf en1999 connections` with `🧰️scripts/schema-evolve/specs/en1999-connection-hole-stagger.json` (leaf `holeStagger`, m, 0 = aligned hole lines, kind `change-conn-hole-stagger`); dry run: 502 files, 0 unsupported; applied by `🧰️scripts/en1999-norm-apply.sh` (status below).
- Pure clause functions (`CHK/📏️parts/🧩️joints`): `net_width` (minimum over all paths across the plate through any subset of the hole lines: Σ d0 deducted, s²/(4·p) added per diagonal; the holes of every second line are offset by s), `net_path` (the governing hole lines, for the plan), `plate_width` (= gauge·(n−1) + 2·edge, as drawn), `plate_tension_resistances` (N_o,Rd = b·t·f_o/γ_M1 and N_u,Rd = 0.9·A_net·f_u/γ_M2, EN 1999-1-1 6.2.3).
- Check (`CHK/🔗️connection-checks`): V_Ed (the force along the bolt rows) against min(N_o,Rd, N_u,Rd) of the connected plate; remedies: thicken the plate, increase the edge distance (wider plate); explanation language-neutral (symbols). Not modelled: angles connected through one leg, an unequal plate width wider than the bolt pattern (the plate is tight to the edge distances, conservative).
- Hand values (test `e2_12b`): M16 plate 140 × 8 mm, d0 = 18, f_o 260, f_u 310: A_net = 832 mm², N_u,Rd = 185.702 kN, N_o,Rd = 264.727 kN; net width 3 lines gauge 40: aligned 86 mm, s = 30 mm 97.25 mm (path [0,1,2]), s = 100 mm 104 mm (path [0,2]).
- Oracle: `net_width_paths` in `SUB/🔮️oracles/⚖️compliance/🐍️.py` enumerates every subset (independent of the Rust DP; matches the hand values); rows `pass-119/120`, `fail-121` of the check-outcome feature (oracle values 0.00868770358, 0.135142056, 12.162785).

## 2. A-61 / A-62 trapezoidal sheeting (EN 1999-1-4)
- Schema first: new collection `sheetProfiles` (spec `en1999-sheet-profiles.json`: `sheetId`, `pitch`, `topFlange`, `bottomFlange`, `webHeight`; the web angle follows from the geometry; the sheet thickness is the profile thickness); dry run 774 files, 0 unsupported. A sheet without profile stays the flat strip (no default, no invented section).
- Clause functions (`CHK/📏️parts/🫙️thin-wall`): `Rib` (valid when b_t + b_b ≤ p, h > 0), `rib_props` (thin-walled A, z_c, I with exact plate inertia incl. t³·e²/(12·s_w) of the inclined webs, W_top/W_bottom), `rib_effective` (fixed point: compressed flange b_t/t, web β = η·s_w/t with η = 0.70 + 0.30ψ of its mid-line ends, ρ_c of 6.1.5 as effective thickness, tension flange gross), `rib_bending_resistance` (sagging and hogging via the mirrored rib), `rib_axial_resistance`, `rib_sheet_flexure` / `rib_sheet_shear` (per sheet width b·/p; ρ_o,haz for a welded sheet), `sheet_web_rho_v`, `rib_shear_resistance` (V_Rd = 2·h·t·ρ_v·f_o/(√3·γ_M1), the vertical component of the web shear flow).
- Checks (`CHK/🥫️thin-wall-checks`): with a valid profile `axial`, `bend` (min of sag/hog), `shear`, `nm`, `defl` (I_eff of the effective rib at f_o, conservative against the SLS stress) and `local` (widest plate element) use the rib; new `en1999.1-4.profile.<id>` (b_t + b_b ≤ p, h > 0, remedies on the failing leaf) and `…profile-ref.<id>` (sheet exists) in `CHK/🎯️entity-checks`; incremental units and integrity wired (`🧮️units`, `🧾️structure-evaluation`).
- Honest limit: the web shear rule (λ̄_w = 0.35·(s_w/t)·√(f_o/E), ρ_v = 1 or 0.83/λ̄_w) is the plate-girder rule of the spec (A-25) applied to sheeting webs by analogy; the EN 1999-1-4 6.1.5 rule is not in the repo. It lives in two unverified registry rows (`ndp.en1999.sheet-web-shear-factor`, `-limit`), the `shear` check reads them lazily, so only that check becomes `unverifiedBasis`. The recalled printed formula (h_w/sinφ · t · f_bv) would be larger by 1/sinφ; the vertical-component form used here is the conservative one. Web crippling coefficients stay null rows (nothing invented).
- Hand values (test `e2_13`, `e2_13b`, rib p 200 / b_t 60 / b_b 60 / h 40, t = 1 mm, f_o 250 MPa, γ_M1 1.1): s_w = 56.569 mm, φ = 45°, gross I = 6.30997e-8 m⁴ per rib, effective factors (0.47222, 0.87181, 1), z_c,eff = 16.6126 mm, M_Rd = 440.969 Nm per rib, A_eff = 112.889 mm², N_Rd = 25.6565 kN, ρ_v = 0.70148, V_Rd = 7363.6 N.
- Third party: `sectionproperties` on the shapely mid-line outline with thickness agrees to 1.2e-4 (I) and 1.4e-5 (z_c), A exact (`--self-check` of the check-outcome oracle and `🧰️scripts/en1999-norm-crosscheck.py`).
