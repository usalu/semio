## ISO 16757-2 solid volume
- New `🧬️schema/💡️inferences/⚖️checks/🧰️check-builders/🧊️solid-volume/🦀️.rs` (mounted in the check-builders `🦀️.rs`): CSG tree -> world solid with rigid frames (`rotationDeg` intrinsic about the local origin, `R = Rz*Ry*Rx`, then `translation`). Primitive set is the schema set (box, cylinder, sphere); volumes are closed forms. Exact world bounds (rotated box via |R| half extents, cylinder via axis tilt, sphere); union = hull, intersection = overlap, difference = minuend.
- Booleans: disjoint (AABB-separated) union = exact sum, disjoint intersection = 0, difference with separated subtrahends = minuend (all `exact`). Overlapping operands: adaptive Simpson over (y, x) of the exact per-line interval-set length along z (each primitive is convex, lines meet it in one interval; interval union/intersection/difference); knots at primitive AABB edges; tolerance `SIMPSON_RELATIVE_TOLERANCE` = 1e-8 of the bounding volume, estimate returned as `error_m3` (observed 1e-12 .. 8e-8 m3).
- `part_libraries::part_2::evaluate_bounding_box` now delegates (rotation applied); new `evaluate_solid_volume`; check `2.7.1.volume` and `solid_volume_m3` use it (EN/DE text says solid volume). Error mapping unchanged (`width` first, `cone` out of scope, empty boolean, unresolved reference); reference cycles now `Cycle` instead of overflow.
- Observed (Rust standalone vs oracle): cylinder r1 h2 6.283185 (was 8), sphere r1.5 14.137167 (27), two unit boxes 5 m apart 2 (216), offset-box intersection 0.125 (3.375), difference 0.5 (1), two unit spheres 1 m apart 7.0685835 (oracle 7.0685812), cylinder with square hole 4.2831853 (4.2831828), rotated overlapping boxes 3.75 (3.75), rotated cylinder inside sphere 0.4313031 (0.4313028); rotated box 2x1x1 at 45 deg has extents 2.1213 x 2.1213 x 1.
- Oracle `🔮️oracles/🌐️cross-checks/🐍️.py` rewritten: independent method (shapely polygon booleans on z sections of convex hulls / analytic sphere circles, scipy quad over z, ConvexHull, closed forms); asserts closed forms to 5e-6 (inscribed polygons limit it to ~4e-7); `--write` also emits the derived Rust table `🧪️tests/🧫️fixtures/🔮️cross-checks/🦀️.rs`. 12 vectors; `python -I` verifies `ok: true`. Feature rows 1..11 flipped `@known-divergence` -> `@agree` (tolerance 2e-5).
- Rust tests added in `🧬️schema/🧪️tests/⚖️compliance/🦀️.rs` (oracle table, rotation bounds). trimesh/manifold3d are not installed.
