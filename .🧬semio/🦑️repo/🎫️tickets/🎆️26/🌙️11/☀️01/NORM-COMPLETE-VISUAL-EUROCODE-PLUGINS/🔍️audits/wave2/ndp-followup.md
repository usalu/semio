## 4. Codegen reproducibility
- Cause of the en1995 rewrite: not a hand edit and not non-determinism. Running the new check on the freshly edited registry reports drift in exactly `en1995` (my value, status and edition edits) and `en1997` (my symbol edit); every other crate matched, so no other owner left stale or hand-edited generated files. The earlier rewrite was the data change of the previous verify run (newly verified rows add `.ver()` and `.ed(..)`) plus rows added to the JSON by wave scripts without regenerating.
- Hardening: `codegen.py` now renders all files in memory, writes bytes as UTF-8 with LF (no platform newline translation), removes stale files only after rendering, and has `--check` (`codegen.py REGISTRY.json …/🔖️ndp/🗃️table.rs --check`, exit 1 listing DRIFT and STALE files, writes nothing). Two consecutive runs are byte-identical (`diff -r` clean), `--check` is ok for 2920 entries. Rule: edit the JSON only, run codegen after every JSON change, run `--check` before handing over. The language-agnostic registry test also catches drift (ids, flags, values).
