# Native Cursor Seed Contract Debt

The bounded map and defining standard checkpoints are accepted separately from this contract debt. The new NativeSeedTemplate evidence is unsafe, optional and defaults to absent; known Scalar/String/tuple templates use no user constructor. Field still retains its original fixed-inline fallback when evidence is absent. That branch records one allocation primitive, then calls the safe RetainedClone::retained_clone_cursor constructor. Its documentation requires no allocation/callout/unwind, but no unsafe native capability authenticates an unknown implementation. The full18-law native corpus passing does not prove arbitrary external callbacks pure.

The next complete defining cut must supply explicit native descriptors for the remaining supported first-party cursor owners and their actual custom test fixtures, then remove Field fallback invocation for absent evidence. Unknown implementations must remain resident and refuse before mutation. No alternative Authority, replay wrapper, stock increase or generic callback adapter is justified. Parent route metadata install/clear billing and child Work-window accounting remain independent debts.
