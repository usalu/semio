# NDP wave 2: the shared registry is the single source of every annex value (EN 1990 to EN 1999)

Nothing was compiled or run (builds are the infra agent's); every Rust edit was checked by reading, delimiter balance of all touched files was scanned, and the two Python oracles pass (`python3 -I ⚖️compliance/🧪️tests/🔖️ndp-adoption/🐍️.py`, `…/🔖️ndp-registry/🐍️.py`). Rebuild requested in `build-en1990 … build-en1999/latest.md`.

## Registry and tooling
- `⚖️compliance/📜️annex-and-tables/🔖️ndp/🔣️.json`: 583 -> 1259 entries (en1990 196, en1991 181, en1992 182, en1993 93, en1994 66, en1995 89, en1996 93, en1997 116, en1998 131, en1999 112), all `unverified`, ids sorted and unique. The three en1991 rail rows that were hand-added to `🗃️table.rs` are now in the JSON too.
- `🗃️table.rs` regenerated by `🧰️ndp/codegen.py`: 158,829 bytes (guard 200,000; crate limit 262,144). To stay compact the runtime `NdpEntry` no longer carries `specRef`, `asWritten`, `evidence` (audit text stays in the JSON; nothing read them at runtime); `row(..)` lost the three arguments, the unit test dropped the two comparisons.
- Pipeline change: the JSON is now the source. `🧰️ndp/ndplib.py` (`put`, `load`, `save`) plus one script per artifact (`wave2_en19xx.py`, `wave2_en1990_psi.py`), rewrite helpers `rewrite_lib.py`, `rewrite_en1992.py`, `check_cited.py`. Do not rerun `curate.py` from `ndp.json` any more, it would drop the wave 2 entries.
- Kernel API (`⚖️compliance/📜️annex-and-tables/🦀️.rs`, `✅️check-results/🦀️.rs`): `ndp_number(id, annex)`, `ndp_number_opt`, `ndp_common(id)` (EN == DE, asserts), `drain_ndp_reads()`, `record_ndp_reads(run)`, `annex_parameter_rows(prefix, annex)` (properties window data), `CheckBuilder::ndps(&[ids])`, `CheckBuilder::ndp_reads()`. Every `ndp_number*` read is logged per thread, so a check cites exactly the ids it read (member level) in addition to explicit spec ids.

## Value changes (everything else is faithful to the code before)
- `ndp.en1992.m-01.alpha-cc-accidental` DE 1.0 (spec) -> 0.85 and `m-01.gamma-c-accidental` DE 1.2 -> 1.3 (what the code used; public verification agrees).
- EN 1999: the private `confirmed: true` flags no longer exist; all entries are `unverified`, so EN 1999 verdicts now end as `UnverifiedBasis` (intended gate).
- Kept as in code, flagged in `evidence`: EN 1998 NA.4 B-T/C-T S = 1.25/1.50 (spec 1.00/1.25), EN 1994 gamma_Mf DE 1.35 vs EN 1993 DE 1.15, EN 1998 psi2 for snow 0.2 (EN 1990 `snow_high`; the <= 1000 m value is 0.0), EN 1994 deflection divisor 250/300 without NA source.
- Behavioural side effect everywhere: every check that reads a registry value is `UnverifiedBasis` until a human sets `verified`; EN 1992 `M-02` no longer "passes without basis".
