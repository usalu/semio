## Actual Changes

The read owner retains its original factory authority, native projection action and child reply, frozen original Source/Work binding, pending invocation route and return fence. The slot invokes genuine projection Drive through the resident frame. Reader admission uses RetainedOwnedProjectionAdmission<T> and a borrowed reply; no owned RetainedOwnedProjection return, removed SourceTake enum or raw-grant Source birth/take callback was reintroduced. First allocation consumes real Work and publishes Some(0) before the allocator; null retains the original input. Handback returns into actual payload and issuer slots through the new native factory field-transfer leaf, then separately pays empty authority and Box-frame release.

The original-slot retirement cursor now has real close_into/recover/original-loan borrowed ports. It retains the child Step/OriginalRetirementFailure slot across pending callbacks, freezes the actual grant and invocation, reserves its reply-mapping copy/Work and delegates selected Birth/control. It uses the genuine FactoryTicketClose and FactoryAuthority borrowed ports. Factory implementation and native cleanup are being completed concurrently by allocation_terra; Root did not create an erased owned-Poll close adapter.

The actual projection frame now explicitly implements Sync for immutable metadata/answer queries under its sealed Sync authority. All frame mutation and producer invocation remain behind exclusive frame loans. This supports the existing read-owner Send+Sync contract without requiring arbitrary retirement cursors to be Sync.

FactoryOwnedSourceAuthority<T>::transfer_original_into moves only the original T and captured Arc into caller-owned slots after checking the actual Source effect, all physical currencies and actual remaining Work. The native schema test verifies original value and issuer identity and all four denied axes, then completes actual borrowed factory retirement and paid native Box release (82663). The removed take_original owned-pair API was not retained as compatibility.
