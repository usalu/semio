## Method

- **Id extraction**: unchanged (`extract.py`, `ids.json`). Same 655 spec ids.
- **File kinds**: unchanged (`scan.py`). `doc` = non-catalogue file under `⚖️checks/`, `📋️member-evaluation` or `📸️snapshot` (the snapshot schema the checks read). `cat` = registration file (`ENTRIES`, `Entry {`, `registry()`). `fn` = other non-test code.
- **Classes (v2)**:
  - `implemented-in-document` = id literal in a `doc` file (snapshot or check path), or an EN 1999 `catalogue::ENTRIES` row with a `Check(prefix)` realisation whose prefix is present in check code.
  - `catalogue-only` = id literal only in a `cat` file (incl. the EN 1999 `Data(...)` realisation for A-01).
  - `function-only` = id literal only in other non-test code.
  - `clause-cited` = no literal, but the spec clause is cited in non-test code or in a clause key (weak evidence).
  - `missing` = none of the above; test-only mentions also land here.
- **Change against the earlier rule (v1)**: v1 required a catalogue literal and a check-path literal together for `implemented-in-document`, so a check-path literal in a file without `Entry {`/`registry()` was counted as `function-only`. v2 counts it as implemented. Affected: EN 1994 (42 ids in `⚖️checks/🧮️catalogue`, which the v1 catalogue-file test misses) and EN 1999 (16 traceability rows). Treating `📸️snapshot` files as the document path adds EN 1997 (+1, EQU-01) and EN 1995 (+1, T-83). The per-code deltas below mix artifact progress and this rule change; the last section separates them.
- **Snapshot `cases` design-case path**: The `cases` modules (`🗂️cases`, under `⚖️checks/📇️catalogue` for EN 1990, 1991 and 1997, `⚖️checks/🗄️registry` for EN 1992, `⚖️kernel/📇️catalogue` for EN 1995 and `⚖️masonry/📇️catalogue` for EN 1996) implement `CaseCatalogue` over `registry()`. `evaluate_case` dispatches on `entry_id`, so an entry is document-reachable only when a case names it. These modules name no ids as literals, so the cases path adds no literal evidence; their entries stay in `catalogue-only` until a snapshot case or check names them.
- **Limits**: literal matches are reliable. Clause citations are noisy. `missing` is a lower bound in EN 1993 because its code is keyed by clause, not by V-id.
