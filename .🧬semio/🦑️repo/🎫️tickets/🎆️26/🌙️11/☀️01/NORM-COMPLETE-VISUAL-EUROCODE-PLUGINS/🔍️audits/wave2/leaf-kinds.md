## index-selector template (wave 2, leaf-kinds A) - `🧰️scripts/leaf-kinds/index_selector.py`
Additive module (no existing module changed). It generates the per-kind files (payload `🦀️.rs`, `🔺️diff`, `↩️inverse`, schema `🔣️.json`, ts twin) for keyed `list_delta` diffs:
- `Link(coll, row, sel, single, en, de, key="id")`: one step of an addressing chain. A selector named `index` or `*_index` is positional (`rows.get(payload.sel)` -> `usize`, diff key read from the row, `Link.key`), any other (`member_id`) is a row key (`find(|row| row.id == payload.sel)` -> `String`). Mixed chains work (`building_index`, then `member_id`).
- `Style(P, model_crate, diff_crate, snapshot_type, snapshot_ts, mode, opt_index, item_field)`: names the diff lanes. `mode="lanes"` (en1992/en1999): rows/patch = `En1992` + pascal(collections of the chain) + `Rows`/`Patch`, top lane `Some(..)`. `mode="single"` (en1990/en1998): `En1990<Single>Delta`/`Patch`, top lane bare. `opt_index=True` makes insert take `Option<usize>` and clamp (en1990 convention), otherwise `usize` and `target-missing` past the end.
- `Ent(name, emoji, links, en, de, slug, group)`, `Leaf(ent, path, ty, ui, opt, kind)` (`ty` = f64/u32/u8/bool/String/`enum:Name`; `opt=True` when the first path segment is an `Option<struct>`, patch field = joined path), `SetKind(leaf)`, `InsertKind`/`RemoveKind` via `pair(ent, insert_kind, remove_kind, style, by_index)`. Every kind offers `leaf_rs/diff_rs/inverse_rs/schema_json/schema_ts` and the data `module/record/dirname/group/wire_fields`.
- The wiring (group crates, registration, root enum/KINDS/twins, edit rules, text/binary codecs, harness, oracle, taxonomy, fixtures) of a keyed artifact is `keyed.py`; per-artifact profiles `en1992_run.py`, `en1990_run.py` show how an artifact declares entities and anchors. The diff Patch fields still have to exist: en1992 uses `scalar_patch!`/`nested_patch!` (see `en1992_diff.py`), en1990 `protocol::row_patch!`.
