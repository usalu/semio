# Required Source-Owned Staged Values

2026-11-05. Design work; this transport is not implemented or mounted.

## Observed Boundary

The actual SDK StagedPayloadCursor keeps STAGED_PAYLOAD_MAP_MEMBERS=32. Control pagination at16+2 does not reduce the size of a nested Create/Add seed or status.commitArgs. The paid page worker's35-field neutral case proves a real representability gap. Raising limits, truncating a seed, hiding a valid Add control, or putting a large object inside a JSON string does not satisfy the existing source contract.

The host must continue to execute actual native-admitted arguments. No raw draft fallback or fabricated ready state is permitted.

## Required Ownership

- A seed/draft or executable argument reference must originate from its actual paid native value source and issuer.
- Scope must bind actor instance, controller, action, source window/surface, document revision and generation; stale/foreign scope must refuse before a command begins.
- Original value/source ownership must survive render closure and, for a replacement request, transfer/alias under the same real control before the old surface retires.
- Commit must consume one native argument owner through the existing action invocation/command path, retaining the existing atomic document-revision check. It must not add a second mutation command or reinterpret reference metadata as domain arguments.
- Cancel, stale revision, retirement and failed receiving must close the original referenced owner with its exact factory and funding; no global immortal cache or guessed authority.
- Text editing may keep small local overlays, but references must not require the browser to deserialize or reconstruct the large native object. Structural seed/variant operations and exact integers must preserve their genuine native representation.
- Every transfer, lookup, receiver birth and close must quote actual native work/capacity; wrapping a synchronous clone/FromValue callback with a header quote is not a producer.

## Concrete Existing Ports

NativeReceiver and NativeMappedReceiver already construct actual native leaves and aggregate ownership moves. ArtifactMutationSource already admits an existing typed mutation. NativeSemanticPreparation supplies metadata-free private replay; its real ColdMutation admission/messages/index were repaired and tested, but its atomic cold nested allocations remain unresolved.

Compiled descriptor/seed sources now have real paid admission, provenance and shared ownership. The page producer can lend projections from the same original rather than clone or serialize whole values. The host already captures the authentic acknowledged surface, source revision and action scope, and passes expectedDocumentRevision through existing dispatch.

A new schema-owned reference representation and its native registry/transfer issuer are still needed across binding, request/session, ready status and action invocation. The ordinary Value lane remains useful for inputs that already fit. It cannot stand in for this missing wide-value lane.

## Acceptance Needed

Neutral cross-language cases must cover the actual35-field Create/Add and ready payload, exact u64 values, replacement-parent and choice sources, cross-window/instance/action/generation substitution, source revision change, consume-once, cancellation at each transfer prefix and failed close retry. Actual native receiver/physical closure and browser edit→commit→history/undo/reopen evidence remain required; no completion is claimed from this design.

## Available Original Lending Accessors

The page worker now exports NormInspectorOriginalSource and norm_inspector_seed_source, norm_inspector_commit_source, norm_inspector_variant_source from paid/original.rs. They project genuine RetainedCloneRef<DslValue> from the original page lease without allocating or minting authority. An escaping alias must quote RetainedOwnedProjection<DslValue>::constructor_demand and call retain_owned with the real grant before render closure. The source and its original decoder ownership must both remain alive until the projections return. These accessors establish a real lending port; they do not implement the reference wire schema, actor-scoped lookup/consumption or mounted commit route.
