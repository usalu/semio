## 3. Free outlines: shear, torsion, LTB
- New crate `semio-s-artifact-norm-en1999-section-solver` (`⚖️checks/🌀️section-solver`, no dependencies, registered in Cargo.toml, script.ts, build-owners, checks Cargo.toml): Saint-Venant I_t (Prandtl stress function, one constant per hole, Lagrange-free via the energy functional) and I_w + shear centre (Neumann warping function, Q4 weak form) on a square raster aligned to the bounding box with the cell width `t_est/8` (`t_est = 2A/P`), 3 000..40 000 cells, matrix-free Jacobi-PCG. Unit tests: series rectangle, Bredt-Batho box, circle, orientation/origin invariance, degenerate polygons.
- Algorithm prototyped and measured in Python (`🧰️scripts/en1999-wave3/grid_torsion.py`, `run_proto.py`, `sp_ref.py`) against `sectionproperties`: solid 70x140 I_t 1.0978e-5 vs 1.0981e-5, I_w 2.391e-9 vs 2.391e-9; box 100x60x4 I_t 1.559e-6 vs 1.562e-6, I_w 5.72e-11 vs 5.73e-11; I 100x120x8x6 I_t 4.10e-8 vs 4.12e-8 (-0.5 %), I_w 4.19e-9 vs 4.17e-9; hexagon tube -3 % / +6 % (non-aligned edges). Stair-step error grows when the walls are not multiples of the cell width, hence the stated accuracy of about 5 % (`wall_cells`, reported in the check).
- `⚖️checks/🪢️free-outline-torsion` (new module): `free_constants` (solver + shear areas A_v,z = sum t|dz| and A_v,y = sum t|dy| over ring edges that name a plate element, gross area if none, t_max = thickest named element or the shorter box side), `torsion_info` (check `en1999.6.1.outline.torsion.<section>`, Warning for a coarse raster or a shear-centre offset above 1 % of sqrt(A)), `free_shear_torsion_ltb` (checks `en1999.6.2.6.v`, `.6.2.6.vy`, `.6.2.7.t`, `.6.2.7.vt`, `.6.3.2.ltb` with M_cr from I_z, I_w, I_t of the polygon, chi_LT by the class, omega_x for a transverse weld). `outline_checks::check_free_member` solves once per member and passes the constants into every combination; the scope check now lists only patch loading, torsional buckling and the combined interaction as not evaluated.
- Independent oracle: three cases `en1999.section.free-outline-{solid,box,i}-torsion` in `third-party-extended.json` (adapter `sectionproperties`, check `en1999.section.polygon-holes`, I_t and I_w, profile `method-spread-v1`); the harness prints `ok` for all 11 cases. Rust tests reproduce the same values (I_t 4 %, I_w 8 %) and compare the free I outline with the parametric I section (shear 3 %, torsion 12 %, LTB within a factor 0.6..1.6, class effects differ).
