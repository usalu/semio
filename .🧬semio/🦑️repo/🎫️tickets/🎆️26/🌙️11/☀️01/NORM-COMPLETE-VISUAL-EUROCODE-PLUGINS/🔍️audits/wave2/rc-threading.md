## Why only en1996
Every artifact stores the root differently: positional record indexes in `🛂️admission/🦀️.rs`, positional cells in the SQLite codecs (rs and ts), per-artifact SQLite contracts (`🎛️semantic.json`, schemaBytes, table widths, valueBytes), en1997 additionally carries a bun "independent" oracle over 210 SQL cells and a native-extent fixture, en1998 stores `annex` as `String`, en1994 splits its checks (CRATE-BUDGET F). The field has to be exact in all layers or the artifact's round-trip tests break, so one artifact was finished instead of eight half-done.

## Design decisions
- `reliabilityClass` is the LAST field of snapshot, artifact and diff (Rust, and SQLite document column), so no positional index of admission, SQLite or DSL record moves. Twins (json/ts/graphql/proto) clone the `annex` entry next to it (proto: next free number).
- Type is the shared `semio_s_plugin_norm_compliance::ReliabilityClass` (DSL key `rc1..rc3`, JSON `RC1..RC3`). Fixtures carry `RC2` (the SQLite fixture `RC3` to exercise a non-default value); `En1996Snapshot::compliant_clay_wall()` is the example constructor. The shared `impl Default for ReliabilityClass` (= RC2) is still there: remove it when all eight artifacts pass the class explicitly (shared owner).
- Leaf `change-reliability-class` is a module of the group crate that already hosts `change-annex` (no new crate, no Cargo/project.json change); `binaryTag` = max tag + 1.
