## 3. Pier demand
No code change of the model: the `3EI/H^3` in the pier-capacity diagram is not a separate pier-only model. It is `bridge::Support::pier_*_n_per_m`, the same pier stiffness the modal analysis uses (cantilever 3EI/H^3 in series with the bearing). The support force passes through the pier, so pier displacement = F/k_pier equals `pier_top_displacement_m` (deck displacement times (1 - bearing share)). Diagram description (EN/DE) now says that. A cracked/section-based pier stiffness needs a pier section, which the pier rows do not carry (only M_Rd); another agent is adding `change-bridge-pier-cracked-inertia-ratio` concurrently, so that route belongs there.
