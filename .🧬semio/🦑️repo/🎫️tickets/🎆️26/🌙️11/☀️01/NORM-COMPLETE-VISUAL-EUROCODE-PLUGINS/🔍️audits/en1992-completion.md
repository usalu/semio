# EN 1992 Norm Completion

Artifact `✏️s/🔌️plugins/📕️norm/🗿️artifacts/🏛️en1992`. Checks root `ANY/🧬️schema/💡️inferences/⚖️checks/` (`ANY` = `🏅️standards/🔖️1/🪆️subsets/✳️any`). Build state and test results: section 5 (updated after each run, logs in `🗑️generated/build-en1992/`).

## 1. Architecture of the completion

- Pure clause library plus verification catalogue, schema-free (no snapshot change, so no twin, fixture or migration churn; same pattern as EN 1995/1996): `📇️catalogue` (`Case`, `Outcome`, `Entry`, `registry()`, `evaluate_case(id, &Case)`, `evaluate_outcomes`), inputs in N, mm, N/mm², outcomes in SI.
- 156 catalogue entries in 11 domain folders under `⚖️checks/`: `🧱️materials-and-time` (M-01…M-14, D-01…D-07, A-01, A-02), `📐️section-resistance` (S-01…S-10, strain-compatibility integrator over polygons with holes, N–M curve, constant-N slice of the biaxial surface), `✂️shear-torsion` (V-01…V-08, T-01…T-04), `🕳️punching-and-struts` (P-01…P-07, ST-01…ST-04 with truss solver, PA-01), `🔗️detailing` (B-01…B-09, DT-01…DT-14), `🪟️serviceability` (SL-01…SL-09), `🧵️prestress-and-fatigue` (PR-01…PR-10, F-01…F-07), `🔥️fire-design` (R-01…R-08 incl. ISO 834 finite-difference field, 500 °C isotherm, zone method), `🌉️bridges-and-liquid` (BR-01…BR-08, LQ-01…LQ-07), `🪝️fastenings` (FA-01…FA-14, union-area group cones), `🏛️analysis-models` (A-03…A-15 incl. nominal curvature/stiffness and the general method).
- NDP registry `📜️ndp-tables` (97 symbols with EC and DE value and a verified flag, no value hard-coded in logic). Every outcome whose entry lists an unverified basis is downgraded to `Warning` and carries the unverified symbol in its explanation, so it can never produce a silent `Pass`. `unverified_ndps()` is the list the kernel registry can adopt (request below).
- The member engine (`evaluate_member`, `evaluate_anchor`) now calls the same functions.
