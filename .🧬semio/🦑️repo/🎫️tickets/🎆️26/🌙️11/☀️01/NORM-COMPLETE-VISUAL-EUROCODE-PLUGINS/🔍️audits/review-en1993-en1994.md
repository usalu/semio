- Severity: **S1** wrong or unsafe result on a default path, **S2** wrong for a variant, a convention/unit hazard, dead-but-exported wrong formula or an unverified normative value that drives a verdict, **S3** robustness, simplification, style. `[V]` = my reading from memory of the printed text (confidence given when below high); not a verified quote.

## 1. EN 1993 findings (ranked)

### S1

1. **T-stub prying condition is inverted.** `CL93/🔗️joint-components/🦀️.rs:86` `let prying = lb > l_b_star;`. EN 1993-1-8 Table 6.2: prying forces develop for **L_b ≤ L_b\*** (L_b\* = 8.8 m³ A_s n_b/(Σl_eff,1 t_f³)); L_b > L_b\* means no prying. Evidence: spec E10 (L_b = 60, L_b\* = 389.4) expects Mode 2, F_T,Rd = 245.96 kN; the code returns no prying, F_T,Rd = 2 M_pl,1/m = 209.67 kN (script). Worse, for a thick plate with short bolts (t_f = 40, L_b\* = 20.5, L_b = 100) the code flags prying and returns Mode 1 F_T,1 = 4 M_pl,1/m = 2982 kN instead of 2 M_pl,1/m = 1491 kN: unconservative by a factor 2 on the governing mode. All callers are affected: `C93/🔗️special-element-checks/🔭️special-parts-checks/🦀️.rs:810,825,854` (column flange, end plate, base plate), hence M_j,Rd and S_j,ini. The tests and the Python oracle encode the inversion (`CL93/🧪️tests/🔭️special-parts/🦀️.rs:105-108` asserts `t.prying && t.mode == 3` at L_b = 300 > L_b\* = 292; `:180-187`, oracle `🔮️oracles/🧮️special-parts/🐍️.py`). Fix: `prying = lb <= l_b_star`; correct tests and the oracle (the oracle is therefore not independent on this point); add E10 (L_b = 60 ⇒ 245.96 kN) as a test.
2. **Bending–shear reduction uses the signed shear and the wrong formula.** `C93/🧱️member-checks/🧮️action-resistance-checks/🦀️.rs:44` calls `part_1_1::shear_reduced_m_rd(m_y_rd, a.vz, v_z_rd)` with the **signed** `a.vz` (`C93/📏️parts/🦀️.rs:235`: `if v_ed > 0.5 * v_rd`), whereas the shear check uses `a.vz.abs()`. A negative shear (every second sign convention) gets no reduction at all: IPE300 S235, V_Ed = −0.9 V_pl,Rd: code 147.67 kNm, EN 126.95 kNm (+16 % unconservative). For positive V the code multiplies the whole M_c,Rd by (1 − ρ): 53.2 kNm at 0.9 V_pl,Rd (EN 126.95), and a negative capacity for V_Ed > V_pl,Rd (see 5). EN 1993-1-1 6.2.8(3): M_y,V,Rd = [W_pl,y − ρ A_w²/(4 t_w)] f_y/γ_M0 ≤ M_y,c,Rd (E15: 146.96 kNm), already implemented as `CL93/🧮️resistance:65 m_y_v_rd_i` but not used. Fix: `v_ed.abs()`, call `m_y_v_rd_i` (class 1/2 I), use W_el/W_eff with the reduced f_y for class 3/4, V_pl,T,Rd when torsion acts; test with a negative V.
3. **Welded and hollow sections get the buckling curves and class of a rolled I.** `C93/📏️parts/🦀️.rs:44` `section_class_rolled_i` and `:130` `buckling_curve_rolled_i` are called for every member (`C93/🧱️member-checks/🦀️.rs:76,95-96`); the Table 6.2 selector `CL93/🧱️stability:43 curve_table_6_2` (welded I b/c, tf ≤ 40; welded box b/c; hot hollow a/a0; cold hollow c; channel/T/solid c; angle b) and `classify_*` for CHS/angle/RHS are never wired. A welded I (tf ≤ 40) must use b (y) and c (z), the code gives a (y) and b (z) for h/b > 1.2: at λ̄ = 1.0 χ is 0.666 vs 0.597 (y) and 0.597 vs 0.540 (z), i.e. 10-12 % unconservative; RHS/CHS are classified with I-section web/flange limits and their M+N interaction uses the I-section `a`, α = 2, β = 5n (`parts:248 mn_interaction_eta`, EN 6.2.9.1(6): α = β = 1.66/(1 − 1.13 n²) ≤ 6 for RHS, 2 for CHS). Fix: add `kind` to the snapshot section and dispatch to `curve_table_6_2`, `chi_general`, `chs_class`, `biaxial_exponents`, `m_n_rd_rhs`; until then return Err/`n.a.` for non-rolled-I members instead of a wrong verdict. Also `fy >= 460` (`:116`, `stability:44`) must be the **grade** (S460), not the thickness-reduced f_y (430 for t > 40 mm).
4. **Class 4 effective section: wrong lever for b_e2, no iteration, no e_N.** `CL93/🧮️clauses/🪟️effective-width/🦀️.rs:118` places the part b_e2 directly below b_e1 (`z_wc = bc − web_eff_top − web_eff_bot_comp/2`). EN 1993-1-5 Table 4.1 (ψ < 0): b_e1 = 0.4 b_eff at the compressed edge, b_e2 = 0.6 b_eff **adjacent to the zero-stress point**, the strip between them is ineffective. For the girder 1000×8 web, 300×20 flanges S355 (script): W_eff = 7256 cm³ (code) vs 7007 cm³ (correct), +3.6 % unconservative; the centroid shift e_N is −1.8 mm vs −11.2 mm. The stress ratio ψ is taken once from the gross section (doc says "iterating"), and the member check feeds ΔM = N e_N = 0 (`C93/🧱️member-checks/🧮️action-resistance-checks/🦀️.rs:602` `delta_my: 0.0`; completion report §6) so the class-4 interaction (EN 6.2.9.3 / Annex B ΔM_Ed) is unconservative by design. Fix: put b_e2 at `z = b_e2/2` from the neutral axis, iterate ψ until W_eff converges, return e_N with its sign convention and pass ΔM_y,Ed = N_Ed e_N to Annex A/B and `class4_utilisation`.
5. **Negative capacity passes (shared crate).** `⚖️compliance/✅️check-results/🦀️.rs:20-28` `ratio()`: only |capacity| < ε is handled; a negative capacity with positive demand gives a negative utilisation, and `utilization()` (`:266`) then reports `Pass` (`<= 1.0`). Reachable: `m_y_rd_red` of finding 2 for V_Ed > V_pl,Rd (ρ > 1), `shear_reduced_moment` EN 1994 (`K94:239`, `Q94/🏗️beams` hogging M_V), any `1 − x` resistance. Fix: `capacity <= EPS` with demand > ε ⇒ cap; add unit tests R = 0 and R < 0.

### S2

6. **Joint rows: group effects ignored, column T-stub reused for every row.** `special-parts-checks:833` `distribute_rows(&iso, &|_, _| f64::INFINITY, cap)` removes the group limits of 6.2.7.2(7); `:810` computes the column flange T-stub once with the outer-row individual l_eff and uses it for all rows (`:824`, `iso.push(col.ft_rd.min(...))`). Inner rows need the group/"inner" l_eff (2p / p, `l_eff_column_flange_inner_group`) and the pairwise group resistances. Unconservative for closely pitched rows.
7. **k10 and k5 are inconsistent with the spec.** `CL93/🔗️joint-components:191` k10 = 1.6 A_s **n_b**/L_b gives 13.07 mm for E10 (2 bolts), the spec has 6.533 (1.6 A_s/L_b per row). Table 6.11 literally gives 1.6 A_s/L_b "bolts in tension (single bolt-row)"; many references use ×2 for two bolts [V, 60 %]; decide against the printed table and fix spec or code. Spec E10 uses k5 = 0.85 (9.413 mm) but Table 6.11 has **k5 = 0.9** (code 0.9, 9.967 mm); only the base-plate k15 is 0.85. The spec example is wrong, S_j,ini changes by 1.6 %.
8. **Bolt shear/slip not complete.** `C93/🔗️special-element-checks/🔩️joint-checks/🦀️.rs:25` the shear check never applies β_Lf (long joints, `clauses::joints::beta_lf`) or the packing factor β_p; slip (`:177 slip_resistance_n`, `C93/📏️parts/🦀️.rs:501`) ignores the combined tension relief 0.8 F_t,Ed that `joints::fs_rd` already implements and clamps ks and μ with `.max(0.1)`, hiding missing input; `joints::bolt_fub/fyb` default unknown classes to 8.8 (`🧮️clauses/🔩️joints:14,25`). Category B must use γ_M3,ser and SLS forces (`:177` uses the ULS combination and γ_M3 = 1.25). Weld `weld_length` is used gross (no l_eff = l − 2a, no 6a/40 mm minimum). Spacing docstring says "not exposed" but the values are the exposed ones (`joints:146-160`), `p1,max` for inner rows min(28t, 400) is missing.
9. **Dead duplicate with wrong formulas.** `CL93/🧮️clauses/🔩️joints:222-283` (`t_stub` always Mode 1 = 4 M_pl/m without prying test, `omega_transverse` with ω1/ω2 swapped for β ≥ 1 / β < 1, `fc_wc_rd` with ρ = 1, `m_j_rd`) duplicates the correct `joint-components`. Remove (rule: duplicated logic must be close, wrong dead code must not exist).
10. **Annex A/B wiring.** (a) `C93/🧱️member-checks/🧮️action-resistance-checks/🦀️.rs:641` uses `c1_end_moments(ψ)` for the Annex A limit also for parabolic diagrams (UDL C1 = 1.127) and `:631` `ncr_tf = ncr_t` (valid only for doubly symmetric); (b) one C_m (`cm`) is used for C_my, C_mz and C_mLT, the z-axis diagram is not modelled; (c) `:600` `rhs: false` always, so hollow sections use the I-section k_zz (for λ̄_z < 0.4 this is unconservative: 2λ̄ − 0.6 < λ̄ − 0.2); (d) both methods are run as separate checks and **both** must pass, while 6.3.3(5)/NDP lets the user choose one (NA-DE allows both): report both, gate on the NDP-selected one; (e) `CL93/🧱️stability:360` `eps_y = (My/N)(A/W_el)` yields ∞ and NaN (`inf/inf` in `s/(1+s)`) for N = 0 when called directly (the engine guards `n_ed > 1e-6 N_Rk`, the public function does not); use W_eff/A_eff for class 4.
11. **Annex B/A numeric check.** Spec E06 NA-DE values 0.4552/0.6442 are wrong, the code/oracle values 0.4565/0.6418 are right (γ_M1 also inside n and in the M term, script). Update the spec. EN values 0.4138/0.5857 reproduce.
12. **Fatigue γ_Mf and category.** `C93/📏️parts/🦀️.rs:561-575`: EN 1993-1-9 Table 3.1 is a 2×2 matrix (damage tolerant low/high consequence 1.00/1.15; safe life 1.15/1.35). The code has three "methods" DamageTolerant 1.0, SafeLife 1.15, **LowConsequence 1.35** (inverted label, no way to select damage tolerant/high or safe life/low-consequence 1.15 distinctly). `:528 detail_category_pa` maps any unknown Δσ_C (e.g. 32, 150) to 71 MPa, which is unconservative below 71. `fatigue-fire…:` `max_by(partial_cmp).unwrap()` panics on NaN. The NA-DE value γ_Mf is "NA-DE 1.35" in `AnnexParams::de` (EN 1994) but 1.15 in EN 1993 `GAMMA_MF_DE`: pick one source.
13. **Legacy simplified engine checks without an EN basis.** `parts:608 tower_buckling_n` divides N_b,Rd by `max(c_f·dyn, 1)` (EN 1993-3-1 has no such rule: wind enters the load side), `parts:639 pile_soil_reduction` (0.85 + 0.02√(L·perimeter) and a linear 0.75..1.0 driving factor, not EN 1993-5), `parts:616 janssen_pressure = k γ z` (linear hydrostatic, not Janssen; `CL93/🏺️containment` has the real one), `part_2::bridge_interaction_eta` linear |N|/N + |M|/M. They are the ones wired in `🏛️shell-and-structure-checks:8,227,268,333` while the correct clause functions exist. Wire the clause functions or drop these.
14. **Fire engine.** (a) class 4 and tension members need k_0.2p,θ and θ_a,cr = 350 °C (4.2.4); the engine uses k_y,θ and the μ0 formula for every class. (b) `parts:329 critical_temperature_c` clamps μ0 to [0.02, 1] so μ0 > 1 yields θ_cr ≈ 349 °C instead of failing at 20 °C; `CL93/⏳️fatigue-fire:135 theta_critical` returns NaN for μ0 ≥ 1.03. (c) `parts:310 parse_rating` maps any unknown string to R60 and only R30..R120 exist (no R15/R180/R240). (d) `kappa_1(false,false)` returns 0.85 also for protected beams exposed on four sides (should be 1.0). (e) unprotected members use k_sh = 1 (conservative); the 0.9·[A_m/V]_b/[A_m/V] rule exists as `k_sh_i_section` but is not wired. (f) N_b,fi,t,Rd, M_fi, κ factors are functions only; no engine check.
15. **Shear buckling interaction function.** `CL93/🧮️resistance:228 bending_shear_buckling_utilisation` lacks the M_Ed < M_f,Rd branch and η̄3 ≤ 1 (EN 1993-1-5 7.1: for η̄1 < M_f,Rd/M_pl,Rd only η̄3 ≤ 1): η̄1 = 0, η̄3 = 1.2 passes when M_f/M_pl ≥ 0.49. 16. **Combination layer** (`C93/🧰️structure-helpers/🦀️.rs:146-205`): permanent and variable effects are summed **signed** with fixed γ_G = 1.35, so a relieving permanent action is never taken with γ_G = 1.0 and a relieving variable action is still added; only the leading variable is switched (no pattern/sign envelope); labels "6.10a"/"6.10b" are Eq. 6.10 (no ψ0 on the leading action) and 6.10b; the permanent-only branch tests `n + my + vz` and omits m_z, v_y, T. Same finding as EN 1992 #2; fix once in `en1990`.

## 2. EN 1994 findings (ranked)

### S1

23. **Continuous two-span statics wrong.** `P94:131` (UDL) `m_span = q L²/16`: the maximum sagging moment of a two-span beam is 9 q L²/128 = q L²/14.2 (the station profile in `Q94/🏗️beams` `relative()` normalises with 9/128, so profile and amplitude disagree): sagging moment −11 % (unconservative; script). Point load at mid-span of both spans (`:139`): M_span = 5PL/32 (code PL/8 = 4PL/32, −20 %), M_support = 3PL/32 (code 4PL/32, +33 %), V_inner = 11P/16 (code 0.625P, −9 %). Fix the coefficients (or take an influence-line solver); add the pattern load (live load on one span only, γ_Q on one span) for maximum sagging, ULS and SLS.
24. **Crack control: Δσ_s from tension stiffening is ten times too small.** `Q94/🏗️beams` `crack_eval` (`:573`) calls `delta_sigma_ts(fct, el0.area, el0.i, sec.area(), sec.i_y, ρ_s)` with the **uncracked transformed** section including the concrete. EN 1994-1-1 7.4.3(3): α_st = A I/(A_a I_a) with A, I of the section **neglecting concrete in tension** (steel + reinforcement). For IPE300 + 2000×100 C30, A_s = 2000 mm² (script): α_st = 24.0 (code) vs 2.43 (EN), Δσ_s = 4.8 MPa vs 47.8 MPa. σ_s, `max_bar_spacing_m` (Table 7.3N) and the 0.8 f_sk limit all use the too-small σ_s. Fix: `A = A_a + A_s·E_s/E_a`, `I = cracked().i` (the function exists, `K94:268`).

### S2

25. **C-04 global analysis is a hard-coded pass.** `Q94/🏗️beams:159` `.utilization(dim(0.6), dim(1.0))` with fixed text "adjacent span ratio 1.0 ≥ 0.6, cracked EI₂ over 15 %", no span ratio is read and the internal forces (finding 23) are for constant EI, so the claim is untrue for the moments used. Compute the ratio, apply 5.4.2.3 (15 % of each span cracked, EI₂, redistribution Table 5.1 with class and cracked/uncracked) or return `incomplete`.
26. **χ_LT curve.** `K94:414` `α_LT = 0.34 (h/b ≤ 2) else 0.49` with the 6.3.2.2 shape. EN 1994-1-1 6.4.2(4) refers to 6.3.2.2 of EN 1993-1-1; Table 6.4 gives a/b (0.21/0.34) for rolled and c/d for welded sections; my reading of 6.4.2 is "curve a rolled, c welded" [V, 70 %]. The code is conservative for rolled sections (IPE300 λ̄_LT = 1: χ 0.597 vs 0.666) but unconservative for welded ones (welded needs 0.49/0.76). Take α from `stability::ltb_alpha_table_6_4` with the section kind. Also `ltb_hogging`/`ltb_moment_resistance_nm` (`P94:464-487`) always use W_pl,y: for class 3/4 hogging webs use W_el/W_eff. k_cC4 = π is conservative; the 6.4.3 Table C4 values should replace it for the moment diagram.
27. **Stud detailing rule inverted and masked.** `K94:379` `(if solid { 4.0 } else { 2.5 }) * d / s_trans`; EN 1994-1-1 6.6.5.7(4): transverse spacing ≥ 2.5 d in solid slabs and ≥ 4 d otherwise [V, 80 %]. 29. **Slab shear and punching.** `K94:514` uses the ENV formula V_v,Rd = b_0 d τ_Rd k_v (1.2 + 40ρ) with τ_Rd = 0.25 f_ctk,0.05/γ_C; EN 1994-1-1 9.7.5 refers to EN 1992-1-1 6.2.2 (V_Rd,c = [C_Rd,c k (100ρ f_ck)^(1/3)] b_0 d, ≥ v_min) [V, 75 %]; the spec example E1-09 (49.17 kN/m) follows the old formula. `K94:523` critical perimeter at 2 d_p; I recall Fig. 9.8 with 1.5 d_p [V, 60 %]; spec flags it as not transcribed. `K94:535` formwork `A_p h_p f_yp/4` carries an undocumented extra ½ (W = A_p h_p/2 gives A_p h_p f_yp/2), inconsistent with `m_pa` (0.45 A_p h_p f_yp).
30. **Fire.** (a) `P94:568 insulation_thickness_m` Table "4.2" values (12/22/33/48 mm, ...) have no counterpart in EN 1994-1-2 that I know; EN 1994-1-2 has no board-thickness table for protected I-beams (Table 4.1/4.2 are dimension tables for partially encased/composite members) [V, 70 %]: mark as unverified project data and exclude from compliance claims. (b) `Q94/🔥️fire…:50` η_fi = M_fi,Ed/M_Ed is used as μ0 (should be E_fi/R_fi,0; conservative because M_Ed ≤ M_Rd) and `critical_temperature_c` (`K94:595`) clamps to [0.013, 0.99] (μ0 > 1 does not fail). (e) composite-column fire C-32 is absent.
31. **Columns.** (a) `Q94/🏛️columns:21` creep threshold λ̄ > 0.8 / 0.5 must be divided by (1 − δ) (6.7.3.4(2)/6.7.3.3(3)); conservative as is.
