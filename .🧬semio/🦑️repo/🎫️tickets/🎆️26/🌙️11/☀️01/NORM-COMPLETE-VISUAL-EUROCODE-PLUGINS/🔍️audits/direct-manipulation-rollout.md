## Design (event-sourced, CQRS)

- Document truth only changes through one `setFields` emission (one batched edit = one undo step). Everything provisional lives in the ephemeral local transient lane; the shared presence lane carries only the open drag of the user. Selection and hover of peers already travel on the framework's typed `PresencePeer.interaction` and are read from `InteractionView.peers`.
- The editors now implement the framework `Transient`/`Presence` facets. `norm_lane_stores!` (SURFACE `🫧️live-lanes/🧱️lane-stores`) stamps `NormLanePresence` / `NormLaneTransient` (+ `Set` mutations, bim-presence template) into each editor (`lanes` mount); each is one opaque `state` line holding the canonical JSON of `NormPresence` / `NormTransient` (`LanePresence` / `LaneTransient` traits decode and replace it). `NormTransient::apply` stays the pure fold; `LaneRuntime` types (`LaneEvent`, `overlay_document`) are the reducer's vocabulary. `norm_exact_store_ownership!(live)` installs the bounded presence/transient disposers, retirement and preparation factories.
- Commands: the five live rows are appended to every `app_commands!` (`setFields`, `previewRemedy`, `clearPreview`, `cancelEvaluation`, `evaluateUnits`), the retained-disposition declaration is `NORM_EDITOR_TOOL_IDS` / `NORM_EDITOR_PUBLICATION_CONTRACTS` (retained six first, live five appended; `NormRetainedEditor::{TOOL_IDS, PUBLICATION_CONTRACTS}` default to the six so the five non-Eurocode apps are untouched), the fixture gained a `live` section checked by `assert_live_fixture`. Handlers: `setFields` is the only document writer (`live_set_fields`); `ArtifactEditor::ephemeral` = `live_ephemeral::<App>` folds the lane events of any live command into the transient (and the drag into the presence) without touching the document.
- Gesture adapter (`🫧️live-lanes/🎛️editor-wiring`): `setFields` carries an optional `gesture` (`{entity:{kind,id}, handle, s, origin?, modifiers?, entry?, phase(+reason) | key}`). `gesture_step` drives the existing `HandleDragTool` statechart from the transient (the open drag stores `origin`, `s`, `entry` now) so pointer phases and keys share one machine: `stream` previews, `commit` / Enter commits only the writes the statechart releases (stateless replay `commit_writes`; a release at the origin writes nothing), `abort` / Esc / lost capture clear with zero trace. Typed entry overrides exactly, clamped to limits.
- Frame-rate preview: `LiveView::with_lanes` overlays the transient writes (drag first, then ghost) on the committed document; every window (viewport, diagrams, properties, checks, outliner) paints `host.document()` and `host.report()` of that preview document. The retained live session re-evaluates only the affected units (EN 1993 has per-entity units; the other nine settle through the fold source until their `Units` land).
- Remedy chips: checks window and properties of the ten live editors get a `👻 Preview` row per applicable remedy / per option of a choice remedy (`previewRemedy`) and a `Clear preview` row (`clearPreview`); gated by `controller_is_live`, so the other five apps are unchanged. EN + DE.
- Viewport (SURFACE `🪟️visual-windows/🧊️viewport3d/🫧️lane-overlays`, carried by `ViewportView.lanes` through the dynamics toolbar panel, so it composes with fields and playback): grips of the selection as markers `handle:<id>` (open drag toned primary, accessible EN/DE names), peers' selection and hover as markers at the entity anchors, and the two missing overlays:
  - **insert-tool cursor ghost**: `previewRemedy` with `insert: {kind, at:[x,y,z]}` becomes `LiveCommand::PreviewInsert` -> `GhostSource::Insert`; a cross at the cursor labelled "Insert member" / "Bauteil einfügen" (all entity kinds named EN/DE).
  - **inline dimension-line numeric entry**: while a drag is open a dimension annotation runs from the grip along its axis to the dragged value; its text is the previewed value in the handle unit (`5,5 m` in DE) or the typed entry with a caret (`7,▏ m`).
- Per-editor viewport shim: `scene_of`, `handles_of`, `render(…, frame, locale)`, `render_with` (resolves the grips from the projected scene); EN 1990 keeps its `combination`, EN 1992 filters `handles(&SceneInput)`.

## Follow-up: host gesture dispatch, insert tool, lane clock, peer drags

- **Surface bindings** (`🧰️toolbar`, only for `s.norm.enXXXX@1/*#editor` controllers): the world-3d node carries `ActionBinding`s `delta` -> `setFields{phase: stream}`, `commit` -> `setFields{phase: commit}`, `abort` -> `setFields{phase: abort}`; an armed insert tool adds `hoverPreview` -> `previewRemedy{insertSpec}` and `drop` -> `setFields{placeSpec}`. Contract with the host: it merges under the static arguments the pick id of the grip as `handle` (`handle:<id>` is accepted, the entity is looked up among the handles of every entity when absent), the drag parameter `s` and press `origin`, the `modifiers`, and for the cursor `at`; key presses arrive as `key` (+ `s`, `origin`, `entry`). `command_from_action` turns these arguments into the `gesture` / `insert` JSON of the payloads (`gesture_json_arg`, `insert_json_arg`). Escape is a manifest keybinding to `clearPreview`, which now clears the drag as well as the ghost.
- **Insert tool** (`🕹️direct-manipulation/➕insert-tool`, palette from each scene's `ENTITY_KINDS` via `viewport::insert_specs`): toolbar section "Insert" / "Einfügen" lists one tool per entity kind plus "Select"; picking a tool arms `GhostSource::Insert{spec, kind, at}`; hover moves the ghost to the cursor snapped to the 50 mm grid (Ctrl frees it); the drop places one item as ONE `setFields` emission resolved through the artifact's `insertItem` edit rule (`NormEdit::InsertItem` at the end of the collection: a copy of the collection's last item with a fresh `<tool>-<n>` id and the snapped `x/y/z` where the item has them; an empty collection inserts the default item). Escape disarms with no trace.
- **30 Hz presence gate and T1/T2 debounce** (`🫧️live-lanes/⏱️lane-clock`): `live_ephemeral` publishes the open drag through `PresencePublisher` (34 ms, changes only, a cleared drag at once), ticks the `EvalScheduler` on every drag change and commits it on release; `LiveView::with_lanes` re-evaluates the preview document only when T1 is due (60 ms after the last tick, or a commit) and otherwise paints the cached preview report (geometry still follows every frame). The cache is dropped on commit.
- **Peers' in-progress drags**: `NormTransient.peers` mirrors the drags in `presence.peers` (`LaneEvent::PeersSeen`), the viewport draws each as a dimension line labelled `<user>: <value> <unit>` at the grip they hold (`peer_drags`, grips resolved by `peer_handles_of`). Limit: the framework hands the typed peer presence only to `ephemeral`, never to `render`, so the mirror refreshes whenever the local user runs a live command (pointer hover emits `previewRemedy` ticks while a tool is armed); a push on every peer change needs a presence-change hook in the framework (request to schema-owner).
- **Tests**: SURFACE `➕insert-tool` (snapping, copy-with-fresh-id, empty collection, unknown collection), `⏱️lane-clock` (30 Hz gate, T1 debounce, commit, cache), `🫧️lane-overlays` (peer drags), viewport `render_viewport_panel` (bindings and palette only for live editors, armed tool adds hover and drop), command parse (`insert` with optional spec and position); per artifact via `norm_live_acceptance!` three more tests: a grip pick id without entity commits the same bundle, the insert tool arms a snapped ghost / follows the cursor / places one item as one emission / Escape leaves no trace, peers' drags mirror into the transient. All artifacts: `ready for rebuild: direct manipulation (host gesture bindings, insert tool, lane clock, peer drags)`.

## Not done / open

1. Nothing compiled or run. Unverified API guesses are listed in `requests.md` (plugin crate-root re-exports, `DslValue` accessors including `Bool`, lane `Set` mutation descriptor schema file, derive output naming `pack`, `BuiltNode.bindings.try_push`, `ui::Trigger::{Delta, Commit, Abort, Drop, HoverPreview}` spellings, `keybinding("escape", …)` key spelling).
2. The host side of the contract above (merging `handle`, `s`, `origin`, `modifiers`, `at`, `key` into the binding arguments, key events as `key`) is specified here but not verifiable from the plugin side.
3. Insert placement copies the last item of the collection; domain-specific defaults (a new pile with its own depth, an opening in a wall with `offsetXM`) need per-artifact templates; the position fields set are `x`, `y`, `z` only where the item has them.
4. Peers' drags refresh with the local lane activity (see above); the framework lacks a presence-change render hook.
5. `previewRemedy` ghosts one write of the first option; multi-write remedies need `preview_remedy` to return several.
6. Viewers do not mirror the lanes; EN 1999 has no retained-disposition unit test to extend.
7. Acceptance tests panic by design when an editor's default document has no handle with a free range, or no palette tool places an item into the default document.
