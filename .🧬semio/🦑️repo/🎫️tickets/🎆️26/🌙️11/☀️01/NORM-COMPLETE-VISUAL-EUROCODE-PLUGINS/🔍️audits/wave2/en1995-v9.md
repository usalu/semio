- Input key is `n_braced` (the key `n` is already "Number of fasteners" and keys are global): `📚️inputs` rs + json (EN + DE labels, example 1), demo rs + json, catalogue fixture (5 cases) and demo-document fixture (2 cases) now carry `n_braced` 4 and `n_d` 5000 (same product 20000 as before, so the verdicts stay). - Oracles: compliance `_bracing` and third-party `bracing_spring` take `n_braced` (q_d = k_l n N_d/...); the third-party case is 4 x 5000 N. Rust tests updated: `the_stabilising_load_and_force_of_t_95_...` (n = 4 and n = 1 equivalence, F_d per member, missing `n_braced` is an error), the PyNite test sets `stabilised_count` from the case.
