# Path budget (wave 2, 2026-11-03)

## Measurement
- Limit rule: AGENTS.md "no path above 256 chars", native Windows included. Rule-guard measures UTF-8 bytes of the path relative to the repo root; the framework fixture-placement tests measure UTF-16 length and code points of the absolute path (≤256). UTF-8 bytes bound both from above, and the relative path drops the machine-specific checkout prefix, so bytes-relative is the one number that holds on Windows (MAX_PATH 260 UTF-16 units), macOS and Linux. Budget set to 240 bytes (16 bytes headroom for the checkout prefix and the next kind).
- The longest fixture path was 255 B (UTF-16: 189 units), en1994 `change-column-reinforcement-product` was 256 B.
- Segment costs (en1998 example, 255 B): fixed prefix `✏️s/🔌️plugins/📕️norm/🗿️artifacts/<art>/🏅️standards/🔖️1/🪆️subsets/✳️any/🧪️tests/🧫️fixtures/🧬️mutations` 151 B (+11 slashes), kind folder 41 B, tail `/✅apply/📸️snapshot/⬅️before/🔣️.json` 51 B. Emoji with variation selector cost 7 B (`🧬️`), without 4 B, BMP symbols 3 to 6 B. Only the kind folder and the tail are movable; the prefix is fixed by the repo taxonomy and the fixture-placement law.
- Where the layout lives: the shared Rust harness `✏️s/🧪️tests/🧪️mutation-vectors/🦀️.rs` (`semio_s_mutation_vectors`, used by the 15 norm artifacts and the 3 block artifacts), the shared norm Python engine `🔮️oracles/🏃️execution/🐍️.py`, the per-artifact `mutate-*` adapters, features and oracle manifests, and the framework document oracle `🧰️framework/🔨️modules/🧬️schema/🔮️oracles/🪪️document/🟦️.ts`. Norm and block use it; about 25 other plugins have their own nested trees (see open items).

## Fix (structural, not per kind)
- Layout: the nested role tree is flattened into role files of the case folder.
  `<kind>/<case>/📸️snapshot/⬅️before/🔣️.json` -> `<kind>/<case>/🔣️.before.json`; likewise `🔣️.after.json`, `🔣️.mutation.json`, `🔣️.outcome.json`, `🔣️.diff.json`. A missing diff file means no diff; the 79 `🔺️diff/🚫️.absent` markers are gone. Tail 51 B -> 29 B (22 B saved on every file), file count unchanged, `🔣️.<name>.json` follows the existing `🔣️.cases.json` naming. Kind folder budget for the longest artifact folder: 48 B (emoji + about 42 characters).
- Why not one JSON per case or short ids: reading a part of one JSON needs a changed reading path in all 15 hand-written adapters (`include_str!` of four files per kind, the `shared://` step URIs of the Gherkin runner), unverifiable without a build; short ids would be the per-kind abbreviation again. The flat layout is a pure path change that a script and a reference checker can prove complete.
- Harness (`semio_s_mutation_vectors`): role constants, a new layout law (`layout_breaches`: a bundle holds only the five role files, so any nested legacy folder fails), unit tests in the crate. Not compiled (no cargo allowed).
- Framework: `DocumentContractOracle.fixtureRole` plus exported `nestedFixtureRole` / `flatFixtureRole` (`🧬️schema/🔮️oracles/🪪️document`, re-exported explicitly by `@semio-tech/schema-ts/oracles/document` and `@semio-tech/framework/schema/oracles/document`). The norm document-contract test passes `flatFixtureRole`; other plugins keep the default nested role. New bun test `🧰️framework/🔨️modules/🧬️schema/🧪️tests/🪪️fixture-roles/🟦️.ts` checks both against independent minimatch and the 22 B saving.
- Also shortened (13 source folders over 240 B, `#[path]`/`include_str!`/Cargo paths updated in the same step): en1998 `🧱️structural-system-checks` -> `🧱️system-checks` (crate folder, Cargo.toml); en1992 `📋️member-evaluation` -> `📋️members`; en1993 `🧪️material-fatigue-fire-vids` -> `🧪️fatigue-fire-vids`, `🔗️special-element-checks` -> `🔗️special-checks`; din18599 `💡️lighting-hot-water-and-cooling-checks` -> `💡️lighting-water-cooling-checks`; vdi3805 `🗃️catalog-integrity` -> `🗃️catalog`, `🗃️product-and-index-checks` -> `🗃️product-index`, `🗓️correction-date-and-strict-mode-checks` -> `🗓️correction-strict-checks`.
- Also aligned: 9 en1998 fixture folders still carried `sourceMutationDirectoryName` while the manifest, features, adapter and engine already used the shortened `mutationDirectoryName` (the earlier cleanup renamed references only); folders renamed to match.
