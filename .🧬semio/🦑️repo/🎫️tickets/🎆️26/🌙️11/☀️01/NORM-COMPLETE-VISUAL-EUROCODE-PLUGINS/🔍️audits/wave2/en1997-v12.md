## 2. Investigation-driven GI-03 and typed basis
- Schema (tool, no hand edits): leaf `layers[].cptNkt` (0 = not given, then the registry row) and collection `characteristicBases[]` {layerId, parameter: undrainedStrength | frictionAngle (`CharacteristicParameter`), basis: declared | derived (`ParameterBasis`)}. 701 + 471 files by `evolve.py add-collection/add-leaf` (spec `specs/en1997-characteristic-bases.json`): model, 5 twins, diff, SQLite, io text, mutations (insert/remove + 3 set-field kinds, `change-layer-cpt-nkt`), edit rules, field-meta EN+DE, 1100 fixtures.
- Kernel `⚖️checks/🎯️ground-derivation` (new module `ground_derivation`): sigma_v0 and sigma'_v0 from the layer gamma/gamma' and the water table (+ gamma_w by annex), `cu_profile` = (q_t - sigma_v0)/N_kt per CPT reading, `phi_profile` (CPT Kulhawy-Mayne, SPT Hatanaka-Uchida), `derive_layer` (readings inside [top, bottom)), `characteristic`: n >= 3 (spec: n per layer >= 3) statistical X_m(1 - k_n V_x) with the existing t-quantile table, n < 3 the lowest value (cautious estimate), no reading none.
- Basis semantics (no silent override): no row or `declared` leaves the layer value untouched; `derived` makes `check_project_scoped` run on `resolved_document` (layers with the derived c_u / phi'), which feeds GEO (undrained bearing/sliding) and SLOPE/walls/piles unchanged. When nothing is derivable the value is 0 (never the declared one) and the check `en1997.2.characteristic.{cu|phi}.<layer>` fails with a remedy; the same check (n against 3) lists method, X_m, V_x, k_n, rejected readings and the declared value for the comparison. Integrity check `en1997.integrity.basis.<id>` for unknown layer or second row per (layer, parameter). Units: the layer/footing/embedded-wall/lab/water groups now also depend on `investigations` and `characteristicBases`, piles/walls/uplift/slopes via `GROUND`.
- GI-01: depth = deepest investigation point when points exist (declared `investigationDepth` only without points); remedy deepens the deepest point (`investigations[id=..].depth`). Spec-trace row GI-03 also traces `en1997.2.characteristic.`.
