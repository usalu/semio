## DIN V 18599 (`⚡️din18599`)
Clauses: DIN V 18599-2 with EN ISO 13790:2008 12.2.1.1 (heating gain utilisation), 12.2.2 (cooling loss utilisation), 12.2.1.1 a = a0 + tau/tau0.
- `🧬️schema/💡️inferences/⚖️checks/🧮️balance-model/🦀️.rs`: removed `utilization_factor` (cooling-loss form applied to heating gains; equalled gamma x standard eta). Added `heating_utilization(gamma, a)` = (1 - g^a)/(1 - g^(a+1)), a/(a+1) at g = 1, 1 at g = 0 (overflow-stable for g > 1: (1/g - g^-(a+1))/(1 - g^-(a+1))), and `cooling_utilization(gamma, a)` = (1 - g^-a)/(1 - g^-(a+1)) (stable for g < 1). `utilization_parameter(zone, H)`: a = a0 + tau/tau0, tau = C_wirk,zone / H with C_wirk = 90 Wh/(m2K) x zone area, H = H_T + H_V of the zone. Heating Q_H uses the heating form, cooling Q_C keeps the cooling form, both with the zone a. Monthly hours = 24 x calendar days (was constant 730 h) in `heating_months` and `solar_gains_month_kwh`.
- `📜️norm-tables/🦀️.rs`: `DIN_V_18599_2_UTILIZATION_A` (0.95) replaced by `..._A0` = 1, `..._TAU0_H` = 16, `DIN_V_18599_2_C_WIRK_WH_M2K` = 90; `DIN_V_18599_1_HOURS_PER_MONTH` replaced by `DIN_V_18599_1_DAYS_PER_MONTH` (non-leap).
- Assumption (gap): the snapshot has no thermal-mass class, so the medium construction C_wirk = 90 Wh/(m2K) (the value the reference vectors use) applies to every zone. A per-zone class needs a schema field plus mutation; not done.
- Tests: `🧬️schema/🧪️tests/⚖️compliance/🦀️.rs` constants test updated, new `the_utilisation_factors_reproduce_the_independent_mpmath_vectors` (35 gamma/a rows, both forms, plus extreme-gamma stability).
- Oracles made independent of the old defect: `🎬️scene/🔮️oracles/🐍️.py` (heating form via mpmath, cooling form, a from tau, calendar hours, no copied `safe ** (-A)`); `🔮️oracles/⚖️compliance/🐍️.py` (same, it also copied the 0.95 and 730 h); `🔮️oracles/🌐️cross-checks/🐍️.py` simplified to the standard model only, divergences now empty, vectors regenerated by it (`--write`, never Rust). Reference values reproduced: a = 5.401, Q_H 7933.3 kWh, Q_C 1709.2 kWh, Q_T 10046 kWh (8760 h).
- `🧪️tests/🔮️cross-checks/🥒️.feature`: `id-eta-heating` and `id-month-standard` flipped `@known-divergence` -> `@agree`. Step bindings in Rust still pending (filed earlier under `## fleet-1108 → din18599`); the Rust unit test above covers the eta rows directly.
