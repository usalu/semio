## 1. Placement semantics (gap 13)
- **One selector name.** The three outliers (en1992, en1995, en1999) used `placementId`. All `change-placement-x|y|z|yaw` leaves now use `id` (was: struct field `placement_id`, wire `placementId`, text key `placement-id`). Renamed by hand in every layer: leaf struct, diff, inverse, schema json/ts/proto/graphql, mutations root proto/graphql, text codec (`id=`), edit rules (`SelectorKey::Id("id")`), unit tests and the 12 `✅apply` vectors. The other seven artifacts already used `id`. Insert item and value payload names (`item`/`placement`, `newX`/`newValue`) are payload fields, not selectors, and stay as they are.
- **Derived yaw.** `placement-drag::standing_pose(handles, id, derived_yaw)` starts from the yaw of the derived projection and only a yaw grip overrides it. New `derived_yaw(scene, id)` reads the heading of the entity's frame `x` axis (members, plates) from the scene; vertical axes and bodies without a frame give none (0). The editor supplies the scene through the new `NormLiveEditor::live_scene` (macro arg `scene =`, projected lazily once per call via `standing_of`, memoised by the live scene). `resolve_placed_fields`, `handle_placed_fields`, `complete_preview` and `dispatch_live_command` now take a `standing: &dyn Fn(&str) -> Option<Placement>` instead of raw handles.
- **dispatch_live_command.** `SetFields` goes through `handle_placed_fields`: placement leaves of a row-less entity become ONE `insertItem` (standing pose plus dragged leaves). `lane_events` passes the standing pose, so the dry-run no longer errors.
- **Law tests.** Unit (placement-drag): `the_first_drag_of_an_entity_without_a_row_keeps_the_yaw_its_derived_projection_stands_in`, `a_yaw_grip_overrides_the_derived_yaw_and_a_row_overrides_both`. Per artifact (stamped by `norm_live_acceptance!`): `the_first_drag_of_a_row_less_entity_keeps_its_derived_yaw_inserts_through_dispatch_and_selects_by_id` (drops all placement rows, checks the standing yaw equals the scene-derived yaw, one insert, dispatch raises exactly one mutation, the row reloads with the derived yaw, and the four placement edit rules resolve to a mutation whose Debug text carries `id: "<entity>"` and no `placement_id`).

Assertions only when `debug_assertions` is off; debug runs still write the report. An unwritable directory is reported with `[DEBUG]`, never fatal.
