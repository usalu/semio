# Prepared Semantic Capability

The native semantic producer now passes only NativePreparedDecodeControl into a prepared work callback. Its internal selected turn can checkpoint and admit capacity without exposing a replaceable NativeDecodeControl. The full semantic edit remains in the original receiving branch; a prepared post return exits before that branch. Reaching semantic receiving through a prepared action returns a retained invariant failure before invoking it. No new authority or work credit is constructed. Concurrent work-count additions are preserved.

This is a source change. Native compilation and the original caller laws remain pending the shared allocation migration.
