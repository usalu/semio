# Native Shared Constructor Owner

The next Root implementation replaces the obsolete decoder NativeSharedAdmission and by-value receive_shared/receive_arc wrappers with the existing NativeSharedSlots owner in native-shared-engine. This is an actual owner migration, not a second constructor implementation or a compatibility layer.

NativeSharedSlots must retain the entire input, birth, resulting output and close frontier in its actual common OriginalEffectAuthority producer. Its private operation contexts select capture, birth, publication, take/reclaim, ordinary close or original close. The existing resident action/request freezes the operation before callback entry and retains the actual reply across Pending or unwind. The producer exposes no mutable body getter. Immutable quotes inspect the actual body. Capture/take are separately paid transitions into empty resident slots.

Use a sealed first-party result mode for SealedShared<T> and Arc<T>, with T's actual owned-retirement contract. This keeps the two implementations adjacent and prevents arbitrary third-party mode callbacks. Sealed mode uses existing SealedShared::prepare_birth and SealedSharedBirth::publish. Arc mode uses the now-accepted allocation-return try_uninitialized_arc_into, publish_uninitialized_arc_from and release_uninitialized_arc_from leaves. An empty completed birth wrapper requires a separately priced header clear.

The advance method drives NativeDecodeControl::receive_original_effect with the same retained NativeReceivingEffect and actual authority. Inputs and outputs remain in that actual producer while original Work, allocator quote/Post and construction acceptance settle. No public advance accepts replacement caller input/output slots. A real take occurs only after those same actions settle.

The new defining lower close ports are RetainedCloneClose::step_into/recover_step_into and step_original_into/recover_step_original_into. They take the actual borrowed OriginalEffectReply<RetainedCloneStep,OriginalRetirementFailure>; no arbitrary callback may return an owned failure before its resident deposit. Birth remains a separate selected before-effect driver. Preserve genuine invocation identity and selected child across close recovery, and pay any child-to-parent result/header mapping separately.

The constructor's source-free native data operations may run under Source-bound genuine Work, as the accepted common authority pairing laws require. Any Source-backed operation must validate the same Source context and Work before callback entry. A caller-supplied scalar or function address is never an original binding.

Remove the old NativeSharedAdmission/NativeOwnedDecodeControl exports and old NativeDecodeControl shared wrappers when their actual functionality is represented in this owner, and migrate NativeIntrinsicSharedField, DSL persistent receiving and direct Actor/Job consumers to the real owner. Keep existing laws and migrate them; do not delete them to make a gate pass. The legacy arbitrary Job construction callback must separately become an actual retained producer owning its candidate and using StepContext::original_source_turn().

Current native decoder original-effect integration remains blocked by the remaining obsolete shared/Arc constructor calls. Root's selected-Birth driver and Work forwarding were production-compiled in the earlier 12-error capture, but the new native priority witness has not executed. The current record/enum generated receivers also retain obsolete APIs and require full Nested/Local, borrowed-reply, real pending and paid metadata migration.

The accepted low-level prerequisites are Core 43 native tests, record storage 15 native tests, and resident Arc 3 native integration tests plus their portable schema/oracle laws. These do not certify the unfinished constructor owner or norms plugin end to end.
