## 1. EN 1998 findings (ranked)

### S1

1. **Rayleigh period is independent of stiffness.** `BR98:24-34` builds the "Rayleigh" displacements as `z_i/H` (a normalised linear shape in metres 0..1) and passes them to `S98:413-425` `t1_rayleigh`, `T = 2π √(Σ m d² / (g Σ m d))`. That expression needs the real deflections of the building under lateral loads m_i g. With a normalised shape it returns 1.74 s (4 storeys), 1.68 s (10 storeys), 1.83 s (2 storeys) for any building, stiff or soft (script B2). A stiff 4-storey building (true T ≈ 0.4 to 0.5 s) is evaluated at 1.7 s: Sd drops by 3x or more, λ flips to 1.0 and the LFM-applicability check changes. Fix: compute d_i from the storey stiffnesses `stiffness_x/y` (shear-building deflection under F_i = m_i g: `d_i = Σ_{j≤i} V_j/k_j` with `V_j = Σ_{k≥j} m_k g`) per direction, or reject method `rayleigh` when no stiffnesses are given (Fail, never a default shape). Add the golden: 4 storeys, m = 400 t, k = 1.2e9 N/m each gives T = 2π √(Σ m d²/(g Σ m d)) from real d (not 1.74 s).
2. **Table 4.2 φ ignores the occupancy category.** `S98:207-220` returns φ = 0.8/0.5 for every non-roof storey. EN 1998-1 Table 4.2: categories A to C roof 1.0, correlated storeys 0.8, independent storeys 0.5; **categories D to F and archives 1.0**; the spec SEI-11 says so (storage E 1.0, D–F 1.0). Result: ψ_E for retail (D) = 0.48 instead of 0.60, storage (E) = 0.64 instead of 0.80 (−20 %), so mass, base shear, P_tot and θ are understated for every non-A–C storey (script B3). Fix: `phi_table_4_2(category, is_roof, correlated)` with `match category { A|B|C => …, D|E|F => 1.0 }` (also for "archives"); unknown category fails instead of 0.3 (`S98:202`).
3. **DE annex is based on withdrawn data.** `S98:87-166` (a_gR zones 0 to 3, Table NA.4) follows DIN EN 1998-1/NA:2011-01. `ndp-public-verification.md` (§3, §4) documents that DIN EN 1998-1/NA:2023-11 uses the spectral response acceleration **S_aP,R** (plateau, subsoil A-R, T_NCR = 475 y, digital `SaPR.csv`) and no zone table. Every DE verdict is therefore on a superseded basis. Fix: model the 2023-11 hazard input (`S_aP,R` at the site, subsoil class combination, `S`, `T_B,T_C,T_D` per NA:2023-11), keep the 2011 zones only as an explicitly named legacy edition selected by the user (the repo has no legacy rule, so remove the zone enum once the 2023 table is loaded as data); until `SaPR.csv` is available show a Fail "edition not supported" instead of a numeric Pass. Update the spec §3 header, SEI-01, SEI-02 and EX98-01..09 (all of which are built on `a_gR = 0.6`).
4. **Foundation "bearing" check divides the horizontal base shear by the footing area.** `PE98:304-305` + `S98:723-725`: `p_Ed = V_b/A`, compared with the bearing pressure `p_Rd` (a vertical resistance). A shear stress is not a bearing pressure; the check ignores N_Ed (G + ψ_E Q), M_Ed = V·h, eccentricity and the Annex F interaction, and the supported-building base shear already contains the q reduction, whereas the foundation of a dissipative structure is designed for the capacity-design action (EN 1998-1 §4.4.2.6, 5.8: `E_F,G + γ_Rd Ω E_F,E`, γ_Rd = 1.2 DCH/1.0 DCM). Example (script B8): V_b = 486.8 kN over 25 m² gives 19.5 kPa, which is independent of the vertical load and moment. Fix: `p_Ed = N_Ed/(B L')` with `L' = L − 2 e`, `e = M_Ed/N_Ed`, `M_Ed = V_Ed h + …`, check `N_Ed ≤ N_Rd(V, M)` by GE-06, and take V from the capacity design action, not Fb.

### S2

5. **Design spectrum used for the base shear is not Eq. 3.13 to 3.16.** `S98:403-406` `design_spectrum_sd = max(Se·γI/q, β·a_g)` is called at `DB98:146`, `PE98:109,205,257,369`. (a) For `T < T_B` Se/q gives `a_g S (1 + T/T_B(2.5−1))/q`, the EN function gives `a_g S (2/3 + T/T_B(2.5/q − 2/3))`; at T = 0.02 s, q = 3.9 the code gives 0.369 and EN 0.591 m/s² (−38 %, unconservative; script B1). (b) The floor is `0.2·a_gR` while EN uses `β·a_g` with a_g = γI·a_gR: for γI = 1.4 at T = 3 s the code gives 0.120, EN 0.168 m/s² (−29 %). The correct function `design_spectrum_horizontal` (`S98:487-500`) exists and is tested but unused by the checks. Fix: delete `design_spectrum_sd`, call `design_spectrum_horizontal(γI·a_gR, S, TB, TC, TD, q, T)` everywhere; also the explicit `Sd(T1)` shown in explanations then equals the oracle.
6. **P-Δ is checked but never applied, and the 0.2 < θ ≤ 0.3 tier passes.** `SF98:137-169`, `S98:472-474`: (a) `p_delta_amplification` returns 1/(1−θ) for 0.1 < θ ≤ 0.2 only in the explanation text; no storey shear, drift or member utilisation is multiplied by it, so θ = 0.2 leaves 25 % of the effect out. (b) For 0.2 < θ ≤ 0.3 EN 1998-1 §4.4.2.2(3)/(4) allows no approximation: a second-order analysis is required and θ ≤ 0.3 is the upper limit. The check uses `utilization(θ, 0.3)`, so θ = 0.25 is a Pass and the function returns 1/(1−θ) for it. Fix: amplify V_i and the storey utilisations by `1/(1−θ)` for 0.1 < θ ≤ 0.2; for 0.2 < θ ≤ 0.3 give status Warning/Fail "second-order analysis required" unless a snapshot flag `secondOrderAnalysis` is true; `drift_sensitivity` (`S98:629-632`) must return infinity (not 0) for `V_tot ≈ 0` with `P·d > 0`.
7. **Storey shear used for θ subtracts δ-amplified forces.** `SF98:57-58,171-172`: `forces` is `F_raw·δ` and `shear_above = (shear_above − F_i).max(0)` starts at `f_b` (not amplified). For EX98-06 with δ = 1.3 the code shear above the top storey is 107 kN against 194.7 kN true (θ × 1.8 too large); with δ = 1.6, 19.5 kN (θ × 10); with δ ≥ 1.8 the shear becomes 0 and `theta = 0` (line 137) so the sensitivity check **passes** (script B5). Also `remaining_v = f_b·δ` makes V_0 > F_b. Fix: keep `forces_raw`, compute V_i = Σ_{j≥i} F_raw,j; apply δ only to element forces of elements at distance x, not to the system storey shear.
8. **Plan regularity: r ≥ ℓ_s does not decide, and stiffness-free inputs pass.** `BR98:114-152`: utilisation is `e0/(0.30 r_min)` only; `ls > r_min` only adds a remedy (line 143), so a torsionally flexible plan with small e0 is a Pass with a remedy attached. `S98:252-271` models K_θ as `k_x(L_y/2)² + k_y(L_x/2)²` (all stiffness on the perimeter, measured from the geometric centre, not from the centre of stiffness), which overstates r for core-stabilised plans (an interior core has r ≈ 0). With `stiffness_x = stiffness_y = 0` the radius is 0, `limit_e = max(0, 1e-6)` and e0 = 0 gives utilisation 0 (Pass). Fix: add `ls/r_min` as the second utilisation and take the max; require stiffness > 0 (Fail otherwise); take K_θ from element positions (`Σ k_i d_i²` about the centre of stiffness) once elements carry coordinates; EN 1998-1 Table 4.1 then selects model and q, not a Fail (see 19).
9. **Mononobe–Okabe thrust.** `S98:730-735`: the denominator is `cos θ · bracket²`; Eq. E.4 has `cos θ cos²ψ cos(δ+ψ+θ)`, i.e. `cos²θ` for δ = ψ = 0. The code is 0.5 %/1.9 %/4.2 % too low at kh = 0.1/0.2/0.3 (script B4: 0.39459 vs 0.39655 for kh = 0.1; the spec EX98-13 value is 0.39655). Only kv = 0, no δ, ψ, β, no (1 ± kv); for θ > φ the square root argument is negative and K_AE becomes NaN (kh = 0.7 at φ = 30° in B4b), and a NaN utilisation must never be a Pass. In addition `PE98:345` passes `a_g` = a_gR, but α = γI·a_gR/g (EN 1998-5 §7.3.2.2(2)); class III/IV walls are 20 to 40 % under-loaded. Fix: implement Eq. E.4/E.5 with all angles, `(1±kv)`, θ from `atan(kh/(1±kv))`, the θ > φ − β branch `K = cos²(φ−ψ)/(cos²ψ cos(δ+ψ))`, kh from `γI·a_gR`, and give the seismic increment `ΔE_d = E_d − E_static` acting at 0.6 H (spec RW cross reference).
10. **Zero or invalid divisors that turn into a huge capacity.** `S98:689-691` `design_capacity_n = r_k/(cf·max(γ_el, 1e-9))`: γ_el = 0 gives 7.4e14 N for R_k = 1 MN (script B9), so a missing γ_el passes any demand. EN 1998-3 requires γ_el ≥ 1.0 (secondary 1.0, primary 1.5). Fix: `γ_el ≤ 0` → capacity 0 (Fail with remedy "γ_el ≥ 1"), same for `cf ≤ 0`. Also note the formula divides the characteristic R_k, whereas EN 1998-3 §4.3 / 7.2 uses mean values divided by CF for ductile and by `CF γ_m` for brittle mechanisms (AS-03); the model has no mean/brittle distinction.
11. **Storey resistance silently replaced.** `SF98:63`: `v_rd = if storey.shear_resistance_n > 0 { … } else { system.base_shear_resistance_n }`. A storey with zero (missing) resistance inherits the base-shear resistance, so upper storeys can never fail. The snapshot examples set 400 kN per storey. Fix: zero storey resistance is a Fail "no resistance given" (or an explicit `inheritFromSystem` flag), never an implicit fallback.
12. **Behaviour-factor table is partly wrong.** `S98:295-336` (used only as an upper bound, `DB98:150-178`): RC dual DCH 5.2 (EN: 4.5·αu/α1 with αu/α1 = 1.2 wall-equivalent = 5.4, frame-equivalent 1.3 = 5.85), dual DCM 3.6 (3.0·1.3 = 3.9 for frame-equivalent); steel "wall|dual" DCH 5.0/DCM 4.0 has no counterpart in Table 6.2 and exceeds the DCH q of concentric diagonals (4) and V braces (DCM 2, DCH 2.5 `[V]`; the spec says 2.5/2.5, which I believe is wrong for DCM); composite DCH 6.0 (5αu/α1 up to 6.5); masonry 2.5 for confined and reinforced (Table 9.1: 3.0 `[V]`); timber 5.0/2.5 `[V]`. The system type enum (`frame|wall|dual`) cannot represent concentric/eccentric/V bracing, inverted pendulum or torsionally flexible systems (SEI-30), so braced frames are admitted with q up to 5. Fix: key the table by (material, structural type, ductility) with αu/α1 limits, derive q0 from the type, and make `q` an output (SEI-30 "q reasons"), not an input bounded by a table maximum.
13. **Importance and ν are not applied consistently.** (a) Tank impulsive and convective shears (`PE98:229-235`) use Se without γI; bridge displacement (`PE98:108-112`) `d = Se(T)(T/2π)²` without γI while the shear uses it. (b) Tank mass uses `ψ_E × content` (`S98:246-249`) where ψ2 = 0.8 for storage reduces a liquid to 80 % `[V]`; EN 1998-4 takes the full contents mass for fluids. (c) `ν` is a free snapshot field (`SF98:111`); it is never tied to the importance class (0.5 I/II, 0.4 III/IV), and `ν = 0` makes drift utilisation 0. Fix: multiply a_g by γI in every Part 2/4/5/6 evaluation, derive the default ν from the importance class and reject ν ≤ 0, use the full liquid mass in Housner.
14. **Silo and tower placeholders.** `S98:715-717` silo axial demand `m(g + 0.9 a_g)` uses a_vg without the vertical spectrum amplification (S_ve plateau = 3 a_vg = 2.7 a_g for type 1) and without γI or S; `PE98:204-208` evaluates the silo at the plateau `T = T_C` regardless of its period; `S98:747-748` accepts q ≤ 3.5 for non-chimney towers (EN 1998-6: RC chimneys ≤ 1.5, steel 1.5 to 2 `[V]`); `tower_base_shear_n` has no λ, no T1, and `(2/3)H` assumes a uniform mass with a linear mode (spec TW-03 wants Rayleigh T1 and three-mode SRSS). Fix as TW-01..05.
15. **Capacity design and detailing rules are missing or constant.** `S98:624-626` `strong_column_ratio`, `S98:612-621` Fa, `S98:619` seismic gap exist only as functions (no snapshot input, no check). In `DM98`: column minimum dimension 0.25 m (`S98:339-345`) and beam width 0.20 m (`DM98:69`) are not EN 1998-1 values `[V]` (EN 5.4.1.2: b_c ≥ 1/10 of the inflection distance; NA values unverified); ρ_min 0.0025/0.0035 constants instead of `0.5 f_ctm/f_yk` (5.4.3.2.2); no ρ_max = ρ' + 0.0018 f_cd/(μ_φ ε_sy,d f_yd); `ω_wd` is compared with a constant 0.08/0.12 (`DM98:151-173`) instead of `α ω_wd ≥ 30 μ_φ ν_d ε_sy,d b_c/b_o − 0.035` (5.4.3.2.2 Eq. 5.15, 5.5.3.2.2 Eq. 5.18); no ν_d ≤ 0.65/0.55 check; no beam/column shear capacity design (γ_Rd 1.0/1.2, 1.1/1.3), no joint shear; `omegaWdBeam ≤ 0.30` (`DM98:206`) is an invented bound that can Fail a design; `qDetail` (`DM98:247-269`) is a self-declared flag. Fix: SEI-50/51 with snapshot fields `M_Rb`, `M_Rc`, `l_cl`, `ν_d`, `μ_φ`, `ε_sy,d`.
16. **Cancellation returns a partial report that looks compliant.** `I98/🌍️full-seismic-check/🦀️.rs:190-192` `if !step(0.0) { return report; }` and the `En1998Units` slow rows return whatever was collected. A cancelled building row yields fewer checks and no Fail. The runner must discard or mark the result (`CheckReport::cancelled`), otherwise cancellation reads as Pass. (EN 1999 has no cancellation hook for its loops at all.)
17. **Masonry simple-rule limits are invented and not registered.** `S98:639-645` (`0.02/0.03/0.04` by zone, ×1.25 III/IV) matches neither the doc comment (2 % for zone 2) nor DIN EN 1998-1/NA Table NA.12 (depends on number of storeys, a_g S and wall length) `[V]`; it drives a Fail (`DM98:301-310`) without an `ndp::REGISTRY` entry and uses `document.site.seismic_zone` even in the EN annex.
18. **NA-DE Table NA.4 B-T and C-T.** `S98:161-162` S = 1.25/1.50 against the spec (and, to my recollection, DIN 4149:2005 Table 4 / NA:2011) 1.00/1.25, T_B/T_C/T_D equal; the registry marks it unverified and a Warning is emitted, but the numeric value still drives Pass/Fail and is conservative by 25/20 %. Fix by item 3 (moot once NA:2023-11 data are loaded); until then use the spec values or mark the verdict `UnverifiedBasis`.
19. **Elevation regularity criteria are invented.** `BR98:156-193`: 0.70 stiffness ratio and 1.50 mass ratio are ASCE-style thresholds, not EN 1998-1 §4.2.3.3 (which requires continuous load paths, gradual changes, set-back limits 20/50/30/10 %, storey-resistance ratio R_i/R_avg, spec SEI-20). They issue a verdict without being registered as unverified. The regularity "claim" check (`BR98:80-112`) fails any irregular building although Table 4.1 only changes model, method and q (the q reduction by 0.8 is already applied at `DB98:146`), and `planRegular`/`elevationRegular` are free flags not derived from geometry (re-entrant corner ≤ 25 %, slenderness ≤ 4, diaphragm stiffness).

### S3

20. **Accidental torsion.** The fidelity audit's L_e swap is **not reproducible in the current check**: `SF98:18,21-22` take the perpendicular plan dimension and perpendicular offsets, identical to `S98:252-271` (lx = plan width = x extent) and to the scene (`🎬️scene/🧮️response:95`); EX98-08 reproduces (script A). Remaining deviations: `L_e` is the whole plan dimension, EN uses the distance between the outermost lateral load resisting elements (`δ = 1.3 + 0.6 e0/Le` is underestimated when Le < L); `e_ai` is only printed, no torsional moment `M_ai = e_ai F_i` for spatial models; the simplified procedure bound 1.6 (`S98:456-458`) is an own bound (registered unverified); `plan_regular = false` Fails the torsion check even though a spatial model with M_ai is the EN route; δ multiplies the system storey shear (see 7).
21. **Component combination.** `I98/…/🧱️structural-system-checks/🦀️.rs:48-75` adds the base shear of the y-system to the x-system capacity (`E_x + 0.3 E_y ≤ V_Rd,x`). The 0.3 rule combines action effects in an element that resists both directions (columns); a wall system that resists only x does not carry E_y. Replace by an element-level check (columns of both systems) or label it "bounding".
22. **Defaults for unknown strings.** `gamma_i` unknown → 1.0 (`S98:275-282`), `drift_theta` unknown → 0.0075 and the class named "isolated" gives 0.010 (`S98:373-379`; the 0.010 limit is for non-interfering fixings), `en_ground_params` unknown letter → B (`S98:788-806`), `confidence_factor` unknown → KL1 and `limit_state_return_period_yr` unknown → 475 (`S98:663-677`; the separate `limitState` check does Fail, the capacity check does not), `psi2_de` unknown → 0.3 and snow 0.2 (EN 1990 NA-DE: ψ2 = 0 up to 1000 m, 0.2 above, `S98:200,202`). EN 1998-1 requires importance class I..IV, so an unknown class must Fail.
23. **Inconsistent T1 between building and dependent demands.** `PE98:249-259` `building_base_shear_n` ignores method `rayleigh` and the first-system-only q (`system.first()`), so foundation, wall and assessment demands use a different T1 and q than the building check. Reuse one function.
24. **Not implemented in the checks: modal analysis, vertical component, time history.** `S98:518-609` (CQC, SRSS, Jacobi, M_eff) and `S98:503-515` (vertical spectrum) are only used by the oracle and the scene. SRSS is applied without the `T_j ≤ 0.9 T_i` test. The drift input `drift_x_m` is a user value (d_r or d_e is not distinguished; the check never multiplies by q_d), the storey stiffnesses are not used to derive it.
25. **Numerical edge cases.** `damping_correction` (`S98:482-484`) with ξ ≤ −5 divides by zero; the elastic spectrum is not held/limited beyond 4 s (`S98:381-400`, spec SEI-03); `t1Given` limit `1.5·T1(Ct)` (`BR98:41,62`) is invented; `soft_storey_utilization` doc comment says "stiffer" for "softer".

## 2. EN 1999 findings (ranked)

### S1

1. **Internal flanges are classified with the web's stress-gradient η.** `MC99:226-229` computes one η from the section stress state (`ψ = s_min/s_max`, My only) and `AS99:118-121` `element_beta_over_eps` applies it to **every** non-outstand element; `AS99:276` uses the same η for ρ_c. For an RHS/box in bending the compression flange is an internal element in (nearly) uniform compression (η = 1) but is classified with η = 0.40: RHS 150×150×5 (flange β = 28) is Class 2 instead of Class 4 (script B1: 0.40 · 28 = 11.2 ≤ 16); ρ_c and A_eff/W_eff for Class 4 are likewise unreduced. Clause: Table 6.2 η and ψ refer to the element itself (A-04). Fix: compute ψ per element from the stress at its two edges (web: ψ from My; flange of a box: ψ from the flange stresses, ≈ 1 for My, and from Mz for the webs treated as flanges); pass the element's own η. Add the golden: RHS 150×150×5, My = M_el → class 4, ρ_c = 0.8622.
2. **Heat-affected zone check of the connected plate has the wrong geometry.** `CC99:181` `N_haz,Rd = t (L − 2 b_haz (1 − ρ_o,haz)) f_o/γ_M1` reduces the width by the HAZ strip only. A weld transverse to the force has its HAZ over the full width, so the resistance is `ρ_o,haz · t L f_o/γ_M1` (spec E2-03: Ahaz = full area, No,Rd,haz = 113.45 kN = 0.48 × 236.36 kN). Example (script B3): t = 8 mm, L = 200 mm, b_haz = 30 mm: code 319 kN, EN/spec 182 kN (+76 %). Also the ultimate check `ρ_u,haz f_u/γ_M2` is absent and `f_haz = |N| + |V|` adds shear as axial force. Fix: for a transverse weld use `A_haz = t·L`, `N_o,Rd = ρ_o f_o A/γM1` and `N_u,Rd = ρ_u f_u A/γM2`; for a longitudinal weld use the strip form with `b_haz` on both sides; decide from a `weldDirection` field.
3. **Alloy data contradict the spec seeds and can overestimate strength by 10 %.** `AS99:24-32`: 6061-T6 f_u = 290 MPa (spec A-01/E2: 240/260), 6063-T6 f_o/f_u = 170/215 (spec 160/195), 6060-T6 160/215 (EN 1999-1-1 Table 3.2b gives lower values for T6, `[V]`), with ρ factors that are unverified (0.53/0.62, 0.49/0.56, 0.48/0.56 vs spec 0.48/0.67 [T] for 6061 and 0.41/0.56 for 6063). A section in 6061-T6 gets f_u +12 %, 6063-T6 f_o +6 %, f_u +10 %. The 6082-T6 rows match the spec. ### S2

4. **Class 1/2 axial-bending exponents are not on the safe side.** `AS99:504-511` uses (ψ, η, ξ) = (2, 1, 1) for I/H/channel and (1.5,1,1) for tubes with the comment "rounded to the safe side". For the strong axis of an I section the plastic interaction is `M_N,y/M_pl = (1−n)/(1−a/2)` for n > a (a = A_web/A), well below the rectangle curve `1 − n²`: for the spec section 80×120×10/6 (a = 0.273) the code allows M/M_Rd ≤ 0.91/0.75/0.51 at n = 0.3/0.5/0.7 while the plastic section allows 0.81/0.58/0.35 (script B2). Either ψ = 1 (linear, safe) or the verified Table values `[V]` are needed; `PT99:53-76` registers ψ as unconfirmed but no verdict qualifier results. Fix: ψ = η = ξ = 1 until transcribed.
5. **Thickness band taken from the thickest element.** `MC99:536`, `FF99:61`, `TC99` use `max_thickness(section)` (`AS99:71-74`). For 6082-T6 f_o is **higher** for the thicker band (250 → 260 MPa), so a section with a 10 mm flange and a 4 mm web gives the 4 mm web f_o = 260, f_u = 310 instead of 250/290. Fix: derive f_o, f_u, ρ_haz per element thickness (or use the minimum over elements for the resistance).
6. **Connections use the thickest band regardless of plate thickness.** `CC99:229` `resolve_alloy(&material.designation)` (`AS99:59-62`, the catalogue row = thickest band) drives bolt bearing, block tearing and the HAZ plate check (`CC99:37,154,181`), while `welded_checks` correctly resolves by thickness (`CC99:164-165`). A 4 mm 6082-T6 plate gets f_u = 310 instead of 290 MPa: bearing and block tearing +7 % (script B10). Fix: `resolve_alloy_for_thickness(designation, b.plate_thickness)`.
7. **Deflection is verified under the quasi-permanent combination only.** `MC99:497-513`: EN 1990 A1.4/EN 1999-1-1 §7.2 compare the characteristic (or frequent) combination with L/200..L/360; the QP combination excludes ψ2 < 1 of the variable load. For g = 2, q = 3 kN/m (office) the QP deflection is 42 % below the characteristic one (script B5). The "stress" check at 0.8 f_o (`PT99:64`, "project limit, not in EN 1999-1-1 §7.2") is an invented limit that produces Fail. Fix: evaluate the characteristic combination for w, keep QP only for creep-sensitive limits, and drop or label the stress limit "informative".
8. **Welds along the member: only full-length longitudinal HAZ; transverse welds and ω_x are not supported.** `MC99:395-402` κ0 = A_eff,haz/A_eff and `AS99:490-495` κ (interpolation "unverified") are applied, but `AS99:497-502` `omega_x` is never called; `MC99:463` prints "ω_x = 1 (no localized transverse weld)". `PlateElement.weld_position` is a position across the element width, so a transverse weld at distance x_s from midspan (spec A-21: ω_x = 1/(χ + (1−χ) sin(π x_s/l_c)^c)) cannot be expressed. Members with transverse welds (end plates, splices) are checked as unwelded in 6.3.1/6.3.2/6.3.3 (and also in fire, see 12). Fix: add `transverseWelds: [{xs, tFactor}]` to the member and apply ω_x, ω_x,LT; keep the unverified c as a registered NDP.
9. **Torsional and torsional-flexural buckling, LTB and Mcr assume doubly symmetric sections about geometric axes.** `AS99:476-481` `n_cr_torsional` uses `i0² = (Iy+Iz)/A` (no shear-centre offset y0, z0), `AS99:483-488` Mcr has no `z_g`, `z_j` or load-height terms and C1 is an input; channels and angles (`section_geometry` kinds `channel`, `angle`) have Iy, Iz about geometric axes, not principal axes. For these kinds torsional-flexural buckling is unconservative (λ̄_T too small), and flexural buckling about the weak principal axis is missing. Additionally `AS99:447-448` takes the torsional curve (α of the BC, λ̄0 = 0.20): to my recollection EN 1999-1-1 Table 6.6 gives α = 0.35, λ̄0 = 0.40 for torsional and torsional-flexural buckling of both classes `[V]` (script B7; at λ̄_T = 1.0 the code χ = 0.672 versus 0.635). Fix: restrict 6.3.1.4/6.3.2 to doubly symmetric kinds and Fail "not supported" for channel/angle until Annex I/principal axes are implemented; correct the curve after verification.
10. **Fatigue inputs.** `FF99:153-156`, `FT99:207-210`: `m1 = fat.m1` is used as given; `m1 = 0` is accepted (powers use `m1.max(1e-6)`), which collapses Δσ_D to 0 and gives N = 2e6 for any stress range (script B6; 60 MPa gives D = 0.5 instead of 0.282). A single block (Δσ, n) per detail: the spec example E2-09 (two blocks, D = 0.359) cannot be expressed, and the Miner sum is per detail, not over a spectrum; γ_Mf is a single value (1.0 EN, 1.35 DE `PT99:36`, unconfirmed) with no damage-tolerant/safe-life and consequence class (A-41). Fix: validate 1 ≤ m1 ≤ 8 (Fail otherwise) and derive m1 from the category (71-3.4, 80-4.3, …) in the data table; add `blocks: [{Δσ, n}]` with `D = Σ n_i/N_i` and γ_Mf by class.
11. **Weld metal strengths exceed the spec range.** `JT99:76-83`: f_w 190/240/270 MPa for 4043/5356/5183; spec A-32 gives 110 to 210 MPa `[T]` (EN 1999-1-1 Table 8.8). Up to +29 % on the weld-metal resistance, which governs unless the HAZ boundary is lower (`JT99:85-90`). Fix: load Table 8.8 as data; unknown filler falls back to `min(f_u, 190 MPa)` (silent) → Fail.
12. **Fire: one 6xxx reduction table for every alloy, buckling in fire ignores κ, protected members and thermal data missing.** `FR99:99-111` k_0.2,θ, k_E,θ are "transcribed from the spec seed" and applied to 5083 and others (non-heat-treatable alloys retain more strength); `FF99:45` `n_b = χ k loc_p.a fo/γ_M,fi` uses the unreduced effective area and no κ/ω_x although the room-temperature check does; `FF99:66-67` supports unprotected members only (A-51 protected formula, ksh, ε_m, α_c in the NDP registry unconfirmed); `PT99:189-198` takes `G + Σψ2 Q` only (the leading ψ1,1 of EN 1991-1-2 is not an option, indirect actions are ignored); `FF99:74` sums the utilisations linearly (safe).
13. **Missing resistance checks that let a design pass.** No torsion (6.2.7: grep finds no `6.2.7`), no combined shear + torsion, no patch loading/web crippling (6.7.5, 6.2.11), no transverse/longitudinal stiffener checks (6.7.6/6.7.7), no net-section reduction at holes in tension (`MC99:287` `0.9·gross.a`; the "A_net" never contains holes), no bolt-group in-plane torsion or p2 ≥ 2.4 d0 spacing (`CC99:123-128`), no multiple shear planes/inner-bolt k1 (conservative). A torsionally loaded RHS or a web under a point load is therefore reported compliant.

15. **Unconfirmed NDPs give unqualified verdicts.** `PT99:53-76`: 14 of 24 registry entries have `confirmed: false` (γ_M,fi, γ_Mf, γ_Ff, deflection ratio, α_max, η0/γ0/ξ0, ψ, κ end, shell Q, fire constants), but no check carries an `UnverifiedBasis`/warning (EN 1992 has the mechanism). γ_M,fi = 1.0 is the recommended value; DIN EN 1999-1-2/NA is `[V]`.

## 3. Cross-cutting points

- **Zero capacity must fail** — good: `utilization_check` (`MC99:81`) returns infinity for limit 0 with demand > 0, `ratio()` returns 1e6, `floor_limit` (`MC99:130`, `I98/🧰️seismic-helpers:18`) keeps a positive demand failing, drift with zero limit is infinity. Exceptions found: γ_el = 0 (EN 1998 item 10), storey resistance fallback (11), zero stiffness plan (8), `drift_sensitivity` with V = 0 (6, 7), NaN K_AE (9), `lambda_bar`/`m_cr_ltb` degenerate (EN 1999 S3-2), `CC99:72` computes `u = 0` for a zero limit (only used for remedies, the result itself is infinite).
- **Cancellation must not pass** — see EN 1998 item 16; EN 1999 `evaluate_scoped` has no hook.
- **Units** — consistent SI in both artifacts (N, m, Pa, m/s², kg). Hazards: shell actions carry stresses in Pa in force-named leaves (documented at `📸️snapshot:268-272`, but the leaves are named `nK/vZK/mYK` and the remedy text says "force"); `g = 9.81` literal in 6 places; fastener table in m² (`JT99:24-27`) is correct; EN 1998 `stiffness_x` N/m and `drift_*_m` m are consistent with θ and Rayleigh.
- **Unverified values drive verdicts without qualification** in both artifacts (same pattern as the EN 1997 report, item 12): add an `UnverifiedBasis` flag to `ndp::REGISTRY` (EN 1998) and `NDP_REGISTRY` (EN 1999) uses.
- **Defaults and silent fallbacks** — see EN 1998 item 22 and EN 1999 items 3, 5, 6, 11.
- **Test strategy** — the oracle comparisons cover the catalogue functions; add member/building-level goldens for: D–F occupancy mass, Rayleigh with real stiffness, T < T_B base shear, γI = 1.4 long-period floor, θ with δ = 1.6, θ = 0.25, foundation V/M/N, MO kh = 0.3 and θ > φ, γ_el = 0, RHS bending class 4, transverse-weld plate, 6082 thin web in a thick section, I-section N-M at n = 0.5, fatigue m1 = 0, class C shell.
