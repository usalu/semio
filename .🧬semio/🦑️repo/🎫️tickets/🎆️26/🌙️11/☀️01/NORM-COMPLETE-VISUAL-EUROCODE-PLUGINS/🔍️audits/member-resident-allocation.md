# Resident Member Allocation Authority

The original Member receiving owner now keeps a NativeDecodeAllocationIssuer and pending quoted request in its resident state. Short callback loans use that issuer when creating or rebinding the same detached native receipt. The borrowed original StepContext is validated through its actual source parent and OriginalSourceBinding before a new loan.

The forwarding callback distinguishes Quote, Post and Cancel. It holds the exact request and grant until settlement, preserves pending custody on mismatched/foreign settlements, records actual physical bytes separately, accepts a performed zero-byte Post, and refuses physical overrun after retaining the observed extent. Post/Cancel settlement is allowed after cancellation/yield because effects may already exist. The Member terminal witness includes no pending quote.

Schema/corpus and an independent SQLite/Ajv test were authored first; a Rust port-state law is mounted in the existing owner tests. Original Member native work/retirement laws now carry the resident allocation state. Neither native law has run against these changes, and the new neutral test is not yet executed.

Remaining work includes paid original source lifetime custody across interrupted callbacks (the binding alone is a scalar witness), a lossless forwarded-control continuation/unwind result, recovery while old grants remain pending, and migration of the separate public SPR receiving adapter. This source is not end-to-end acceptance and does not introduce extra physical or CPU credit.
