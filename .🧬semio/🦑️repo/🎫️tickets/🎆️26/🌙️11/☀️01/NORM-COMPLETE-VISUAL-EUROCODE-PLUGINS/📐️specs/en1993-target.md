## 0. Conventions

### 0.1 Units and symbols
Internal SI-derived: length mm, force N, moment Nmm, stress MPa, temperature degC, angle rad, time s. Editor/report units kN, kNm, cm, cm2, cm4, cm6 are presentation only (field-meta unit conversion). E = 210000 MPa, G = 81000 MPa (E/(2(1+nu)), nu = 0.3), epsilon = sqrt(235/fy), fy per thickness (Table 3.1 / 1-10 Table 2.1 NA).
Partial factors are carried as a `PartialFactorSet {gM0,gM1,gM2,gM3,gM3ser,gM4,gM5,gM6ser,gM7,gMfi,gMf,gFf}` resolved from `annex: AnnexChoice` (EN recommended | NA-DE | user override with audit flag).

### 0.2 Result contract (every verification)
`VerificationResult { id (V-nnn), clause, status (pass|fail|n/a|incomplete), utilisation = Ed/Rd (or max of partial terms), terms[] (named sub-ratios), inputs_used[], ndp_used[{id,value,source}], intermediates[{symbol,value,unit,clause}], notes[], remedies[] }`.
Governing utilisation per member = max over load combinations x segments x checks; checks are independent pure functions of (section, material, member, action, NDP set). Progress and cancellation: every member-level batch and every Mcr/eigen/FE solve reports progress (0..1) and honours a cancel token.

### 0.3 Alignment with the current model (gap list)
Current snapshot (`🧬️schema/📸️snapshot`) has `SteelMaterial{fy,fu,E,G,subgrade,kind}`, `SteelSection{kind,h,b,tw,tf,r,A,Avy,Avz,Iy,Iz,It,Iw,Wel,Wpl,Anet}` with free-string `kind`, `SteelMember{buckling_length_y/z, ltb_length, ltb_restraint_spacing, load_application, end_moment_ratio_psi, moment_diagram, analysis}`, `LoadCase`, `MemberAction{DesignAction n,vy,vz,my,mz,t}`, `SteelJoint` (bolt grid scalars, plate, weld, category), `FatigueDetail`, `FireExposure`, `ColdFormedMember`, `PlatedPanel`, `SiloShell`, `TensionComponent`, `BridgeFatigue`, `TowerLeg`, `SteelPile`, `CraneRunway`.
Gaps this spec closes:
1. `kind: String` fields become closed enums (schema-first); sections become parametric with derived properties computed, not stored.
2. Single `DesignAction` per member -> station-resolved action diagrams (N,Vy,Vz,T,My,Mz at stations along x, plus load-case combination records and psi factors).
3. Members have no supports/restraints/imperfection model -> `Support`, `LateralRestraint`, `TorsionalRestraint`, `Brace` entities, from which Lcr, Mcr, C1.. are derived instead of typed.
4. No frame/node topology -> `Frame { nodes, members, supports }` and global analysis (alpha_cr, second order).
5. Joints are scalar bolt grid -> geometric joint entities (plates, bolt grid with arbitrary positions, welds, stiffeners) and component method.
6. No classification, no 6.2.9 interaction, no 6.3.3 method choice, no 6.3.4, no 6.4, no 1-5 reduced stress method etc. (all below).

### 1.C Global analysis (1-1 section 5)

**V-020 5.2.1 — alpha_cr elastic critical load factor / Verzweigungslastfaktor.**
In: HEd (kN, horizontal reaction of storey), VEd (kN, total vertical load at storey bottom), h (mm storey height), dH,Ed (mm, storey drift under HEd incl. equivalent horizontal forces from imperfection). F: `alpha_cr = (HEd/VEd) * (h/dH,Ed)` (portal/storeys approximation, eq. 5.2); general: lowest eigenvalue of `(K_E + lambda K_G) phi = 0` (linear buckling by FE of the frame). NDP 5.2.1(3): limit 10 elastic analysis, 15 plastic analysis (rec); **[NA]** same. Out: alpha_cr per storey and global (min eigenvalue), eigenmode. Crit: alpha_cr >= 10 (>= 15) -> first order permitted (sway effects negligible); else second order required. Edge: pitched portal/low-slope roofs and shallow frames: use eq. 5.2 only if slope < 26 deg and axial force in beams/rafters << 0.09 NEd-ratio (5.2.1(4)B: lambda_bar >= 0.3 sqrt(A fy/NEd) check for beams); storeys with VEd=0 -> n/a.

**V-021 5.2.2(3) — Second-order amplification (approximate) / Verstaerkungsfaktor.** F: `1/(1 - 1/alpha_cr)`, valid alpha_cr >= 3.0. Applies to horizontal loads and sway imperfections: `M_II = M_I / (1 - 1/alpha_cr)`; for alpha_cr < 3 full second-order (P-delta + P-little-delta) required. NDP: alpha_cr min = 3 / **[NA]** 3. Out: amplified sway moments, factor.

**V-022 5.2.2(5) + (6) — Which effects / Welche Einfluesse.** Decision matrix: global second-order effects (P-Delta) and local member effects (P-delta); if global second order included with member imperfections eq. 5.x, member buckling checks 6.3 are reduced to cross-section checks (5.2.2(7)b) ; otherwise buckling length from the sway or non-sway mode. Out: `AnalysisMode {first-order, amplified-first-order, second-order-global+local-eq., second-order-full}` and which checks (6.2 or 6.3) apply to each member.

**V-023 5.3.2 — Frame sway imperfections / Globale Anfangsschiefstellung phi.**
In: h (m, structure height), m (number of columns in row carrying NEd >= 50 % of average column load). F: `phi = phi0 * alpha_h * alpha_m`, phi0 = 1/200, `alpha_h = 2/sqrt(h)`, `2/3 <= alpha_h <= 1.0`, `alpha_m = sqrt(0.5 (1 + 1/m))`. Equivalent horizontal force: `H_equiv = phi * N_Ed,i` at each column top (or per storey `phi * sum VEd`). Storey relative: phi_i uses h = storey height for storey-wise application (5.3.2(3) Fig. 5.2: relative rotation of storeys). NDP phi0 = 1/200 / **[NA]** 1/200. Out: phi (rad), H_equiv per node, applied as geometry (inclined) or force set. Edge: may be neglected for HEd >= 0.15 VEd (5.3.2(4) with first-order); in multi-storey floors apply alpha_m per floor diaphragm; sway in two directions: apply separately in each direction, combined only with the unfavourable one.

## 2. Schema-first entity model

All entities are events-sourced aggregates (CQRS): commands emit events, the snapshot is a projection; derived values (properties, Mcr, utilisation) are inferences (`💡️inferences`), never stored. Identifiers are stable strings; every entity has `LocalizedLabel::native(en, de)`; enums are closed with EN/DE labels. Every geometric field carries a unit tag in `field-meta`.

### 2.1 Section catalogue (parametric)
`SectionDef = oneof { Catalogue(designation, series), Parametric(kind, params), Polygon(outline, voids) }`. Catalogue series (data files, schema-first, one row per designation, versioned with standard edition): IPE, IPN, HEA/HEB/HEM (+HD, HL, UB/UC), UPE, UPN (channels), L equal/unequal, T (cut IPE/HE), RHS/SHS (EN 10210 hot, EN 10219 cold), CHS, flats, rounds, rails, sheet piles (AZ, AU, PU, GU), Z/C/Sigma/Omega cold-formed (EN 1993-1-3, manufacturer-neutral parametric), stainless tubes.
Parametric kinds and params:
- `I_rolled {h,b,tw,tf,r}`, `I_welded {hw,bf1,tf1,bf2,tf2,tw,a_weld}` (mono-symmetric), `I_tapered {start, end, length}`, `I_castellated {...}`.
- `Box_welded {h,b,tw,tf,a}`, `RHS_hot {h,b,t,ro,ri}`, `RHS_cold {h,b,t,ri}`, `CHS {d,t}`.
- `Channel {h,b,tw,tf,r,slope}`, `Angle {h,b,t,r1,r2}`, `T {...}`, `Z/C {h,b,c,t,r}` with lips, stiffener groups (edge/intermediate: `Stiffener{pos,shape,A,I}`), `Hat/Omega/Trapezoidal sheet`.
- `Built_up {chords: SectionRef[], lacing|battens, h0, a, n}`, `Plate_girder {panels, stiffeners[]}`.
- `Composite_poly {polygons[], material_per_polygon}` for arbitrary thin-walled sections (computed by generic polygon mechanics).
Derived (inference): all of V-050, section modulus, plastic neutral axis, shear centre, warping function, effective section per action (V-040). Material: `SteelMaterial {grade, product_standard, t_ranges[], fy(t), fu(t), toughness_class (JR, J0, J2, K2), reference E,G,nu, density, alpha_T, stainless: {n, f02p}}`. Corrosion allowance and coating per member.

### 2.2 Members, supports, restraints
`Member {id, label, kind (beam|column|brace|chord|diagonal|purlin|rail|pile|tower_leg|cable|panel_stiffener), section_ref, material_ref, start_node, end_node, orientation (roll angle β), local axes, segments[], taper?}`.
`Segment {x0, x1, section_ref}` (section variation, tapered).
`Support {node|station, dofs: {ux,uy,uz,rx,ry,rz,warp} each fixed|free|spring(k)}`; `LateralRestraint {member, station, side (top flange|bottom flange|centroid|shear centre), kind (rigid|spring k_y), applies_to (lateral|twist|both|warping)}`; `TorsionalRestraint {member, range, k_theta (kNm/rad/m), source (sheeting|purlin|manual)}`; `Brace {kind (diagonal|K|X), stiffness}`; `EffectiveLengthOverride {axis, value, reason}` flagged `non-derived`. Imperfection record: `ImperfectionSet {phi (global), e0_y, e0_z, shape, method (equivalent forces|geometry|none)}` produced by V-023..V-025.
`LoadApplication {zg offset from shear centre, destabilising, direction}` replaces the free string `load_application`.

### 2.3 Frames and analysis
`Frame {nodes (x,y,z), members[], supports[], releases (hinges, semi-rigid spring from joint), storeys[], bracing_systems[]}`; `AnalysisSetup {mode (first|second|buckling), imperfections, mesh (n elements per member), warping DOF}`; results as inferences: nodal displacements, station forces N,Vy,Vz,T,B,My,Mz (n >= 21 stations per member), alpha_cr and eigenmodes (first k), second-order forces. `LoadCase {id, name, kind (permanent|variable|accidental|seismic|fire), category}`, `Combination {factors, uls_kind (6.10, 6.10a/b), sls_kind}` supplied by en1990 interop; member actions come from the frame solution, with manual override allowed (`MemberAction` retained as "imported action envelope").

### 2.4 Joints
`Joint {id, kind (beam_column_end_plate|flush_end_plate|beam_splice|column_splice|fin_plate|double_cleat|web_cleat|base_plate|moment_base|truss_node_CHS|truss_node_RHS|gusset|pin|lug), node, members: [{member_ref, role, face}], parts[], fasteners[], welds[], stiffeners[], forces/actions[], classification}`.
- `Plate {id, outline (polygon in plate coords), thickness, material, position (3D frame), holes[{x,y,d0,shape (round|oversize|short-slot|long-slot)}]}`.
- `BoltGroup {class, d, grade, preload?, rows: [{y, bolts[{x,...}]}] | grid {n_rows, n_cols, pitch_x[], pitch_y[]}, free positions allowed, shear_planes, thread_in_plane, washer, countersunk}`; derived: e1, e2, p1, p2 (V-406), bolt rows effective (V-430).
- `Weld {kind (fillet|butt_full|butt_partial|plug|slot), a (throat), length, path (polyline on plates), sides (both|single), quality_level, beta_w}`.
- `Stiffener {kind (transverse web|diagonal|supplementary web plate|backing plate), t, position}`; `Concrete {fck, block (a1,b1), grout t, anchors[]}` for base plates.
- Joint action `JointAction {Nj, Vy, Vz, Mj,y, Mj,z, T}` per load case; `Rotational spring {Sj,ini, Mj,Rd, phi_cd}` published to the frame.

### 2.5 Domain objects of other parts (all schema leaves, each with its own derived checks)
`FatigueDetail {detail_ref (category from catalogue), location (member/station/weld), stress_history (nominal ranges | spectrum | time series), thickness, correction, safety format}`; `FireExposure {curve (iso834|external|hydrocarbon|parametric|natural), protection {type, dp, lambda_p, rho_p, c_p, perimeter model}, exposed sides, t_req, eta_fi}`; `PlatedPanel {a, b, t, edges, longitudinal/transverse stiffeners[], stress field (sigma_x1,2, sigma_z1,2, tau) or FE}`; `ColdFormedMember {section_ref, thickness tcor, bends (n, r), fyb, lips, sheeting restraint}`; `ShellStructure {geometry (cylinder|cone|sphere|silo|tank), courses[{h,t}], stiffener rings, quality_class, loads}`; `Cable {kind (spiral|locked|rod), d, Fuk, length, pretension, sag}`; `TowerStructure {legs, bracing, ice/wind inputs}`; `Pile {kind (U|Z|tube), section, interlock behaviour, corrosion}`; `Bridge {girders, decks, fatigue load model, lambda inputs}`; `CraneRunway {girder, rail, crane class S, wheel loads, spans, support}`.

### 2.6 Commands (mutations; no CRUD)
Domain-level events only: `SectionAssigned`, `SectionParametersAdjusted`, `MaterialAssigned`, `SupportMoved`, `RestraintPlaced/Removed/Moved`, `BoltGridEdited`, `PlateOutlineChanged`, `WeldPlaced`, `LoadApplied/Moved`, `ActionEnvelopeImported`, `NdpOverridden`, `AnnexSelected`, `InteractionMethodSelected`, `FireScenarioSet`, `FatigueSpectrumSet`, `AnalysisModeSet`. High-frequency drags use ephemeral-local state (preview events) and emit one committed event on release.

## 7. Test strategy

1. Language-agnostic test vectors: one JSON file per verification `🧪️tests/<V-id>.vectors.json` with `{inputs, ndp_set, expected{intermediates, outputs}, tolerance, source}`; the same files run in Rust, TypeScript (and any future language).
2. Third-party oracles (`🔮️oracles`, Python): independent re-implementations using stdlib/numpy/scipy only in test code (flexural/LTB curves, Mcr via `scipy.linalg.eig` on an independently assembled 7-DOF beam matrix, rainflow via `rainflow`/`fatpack`, 2D plate buckling via a plate FE, sections via `sectionproperties` if available, steel temperature integrator, T-stub formulas, bolt/weld tables). Output must equal the Rust output within tolerance for random-sampled inputs (property-based sweeps with fixed seeds) plus E01..E15.
3. Published benchmark examples as extra vectors: SCI/ECCS/Steel Construction "Design of Steel Structures" worked examples, Eurocode worked-example datasets (JRC "Eurocodes: Background and Applications", Annex-A/B comparison), the ECCS TC8 LTB benchmark for C1/C2/C3 (cite in vectors `source`).
4. Metamorphic tests: monotonicity (longer member -> lower resistance), invariance (rotate section axes), limiting cases (lambda -> 0: chi=1; Mcr -> inf), Annex A/B agreement within a documented spread, Mcr general eigen = closed-form C1 within 1 %.
5. Visual regression: deterministic 3D/2D snapshots for E01..E15 states; accessible-text alternatives compared textually.
6. Performance tests against the targets of 4.2.
