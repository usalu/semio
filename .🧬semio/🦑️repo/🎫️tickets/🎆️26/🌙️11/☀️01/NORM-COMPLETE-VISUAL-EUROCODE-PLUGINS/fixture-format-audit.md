# 🧾️ Independent Fixture Formatting

Every write independently parses before and after and asserts equal values, keys, IDs and signed zero. Nonfinite JSON is refused. Python standard-library JSON serialization uses schema-owned field order and number kinds.

```json
{
  "requested": 5131,
  "written": 5131,
  "counts": {
    "🗿️artifacts": 5131
  },
  "failures": []
}
```
