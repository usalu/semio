# Sheet rename / removal reference rewrite (status: implemented, NOT yet compiled or tested)

BASE = xlsx/ecma-376/subsets/base

## Design
- `rewrite_sheet_references(expr, from, to)` (in `schema/mutations/recalculation/🦀️.rs`, moved out of `schema/calculation` because the model crate is at its 32-file source boundary): rename swaps the prefix and adds or drops quotes (doubled apostrophes, cell-like, `TRUE`/`FALSE` and R1C1-like names are quoted); removal turns the reference into `#REF!`. String literals and prefix-sharing sheet names are untouched.
- `xlsx_rename_sheet_mutations` and `xlsx_remove_sheet_mutations` build one command of `RenameSheet`/`RemoveSheet` plus one `SetCell` per rewritten formula, so the inverse restores formula text.
- `edit_rules::special` now wraps `resolved_special` with `xlsx_with_recalculated_caches`. Rename and remove arms use the new builders.
- Base editor no longer wraps `snapshot_edit_special` itself. Strict and transitional editors call `edit_rules::special` directly, so they now get recalculation through the shared path. The `xlsx_set_cell_emit_fields` path is already shared by both.
