# Captured Snapshot Retirement

The XLSX history capture transfers the exact issued Store read and keeps a typed issuer. The regression runs the real captured source in a narrow Cargo integration target over the existing neutral fixture rows. It checks that the source projects the original root, returns the read before closing custody, and chooses the exact ArcRoot copy, capacity, release, and depth demand when it owns the last registry alias. Each one-short grant must preserve the demand and perform zero work. An exact grant must allocate the quoted ArcRoot frame. A funded Complete reply requires terminal source custody. When a Store registry alias survives, the exact generation must remain returned in that registry until the external owner drains it.

The fixture schema and independent SQLite law cover both registry conditions with empty and nonempty payloads. The SQLite oracle derives the selected root admission and terminal condition from the registry alias count and the live custody slots.
