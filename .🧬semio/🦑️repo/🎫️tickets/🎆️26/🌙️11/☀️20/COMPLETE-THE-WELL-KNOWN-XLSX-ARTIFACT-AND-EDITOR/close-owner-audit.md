# Close owner audit

The native close-scope log records Strict and Transitional conflict fixtures stuck on StoreReplacement with a one-byte copy quote and a one-item grant; regular history reports a boxed child completing with 2,576 copied bytes and 2,528 retained capacity bytes. Those are separate witnesses.

A failed initializer callback can strand its owner: `WorkerJobSession::try_step_on_original_caller` returns the original authority to `SESSION_CLOSE` on callback failure. `MountedWorkerJobSession::pump_one_for_interactive_turn` maps an unsuccessful idle-phase acquisition to Idle, while `drive_initializer` handles Idle with an empty progress step and drives session close only after setting `terminal_target`. Therefore a failed callback with no terminal target can remain in the initializing rung after cancellation. The one-byte quote by itself does not prove that phase: it also matches the `resume_pending` boolean quote. A phase and flags witness is needed to distinguish them.

For regular history, `ArtifactHistoryReadRetirement` admits an `ArcRootRetirement` for the derived snapshot, displaced preview operation, and preview state. Arc-root admission returns Complete after placing a live child in an active slot; its demand is the root frame capacity plus the copied root, issuer and output slots, matching the observed 48-byte difference. Current `close_inner` converts these helper completions to Progress before returning. The active-box branch uses helpers that themselves report Progress while an owner is present, including after a terminal header is removed. The observed old log cannot alone select among the constructor branches or prove that it exercised the current code. The derived and preview state demand paths should additionally quote full arc-root admission copy bytes for tight-grant tests.

## Snapshot registry alias

The first zero-capacity receipt matches the closed-slot removal in `snapshot_registry_alias_close_step`: it quotes and copies `size_of::<SnapshotReadRegistryAliasRetirement>()` before returning Complete. Its precise 2,416-byte size was not measured. The current `SnapshotAliasRetirement` checks its own terminal witness and translates intermediate completions into Progress. `CapturedSnapshotRetirement` instead forwards the registry completion while its captured factory is still retained; its cursor converts that child outcome directly. Native replay preparation captures this source from the original Store read, making this path relevant to history replay. The narrow correction is to retain the child receipt and work while reporting Progress until the parent is empty. The existing captured-source one-item fixture is in `🌱️value/📸️snapshot/👁️read/🔗️source/🧪️tests/🦀️.rs`; its API calls appear stale against current effect signatures and must be validated before use.
