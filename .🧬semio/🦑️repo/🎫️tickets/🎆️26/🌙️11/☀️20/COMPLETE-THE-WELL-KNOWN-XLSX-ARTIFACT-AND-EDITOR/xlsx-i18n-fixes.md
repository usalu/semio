# XLSX editor localization, accessibility and metadata fixes

Scope: the three ECMA-376 subsets (`base`, `strict`, `transitional`) of the XLSX artifact and the shared natural-file action declaration. Follows `browser-editor-path-audit.md` gaps G3, G5, G6, G7, G8, G11.

## Changes

1. G5 layout titles. The edit and view mode layouts (all three subsets) no longer carry the English-only titles "Worksheets" and "Cells". `title` is `None`, so the dock falls back to the localized window-kind label (`Workbook` / `Arbeitsmappe`). Tests assert `None`.
2. G6 unknown-body fallback. Editor and viewer (all three subsets) resolve `unknown_body` from a catalog label set (`XlsxEditorLabels`, `XlsxViewerLabels`, declared with `app_labels!`): "Unknown body: {body}" / "Unbekannter Bereich: {body}".
3. G8 locale-aware numbers. `base/editor` gained `xlsx_decimal_separator`, `format_xlsx_number`, `parse_xlsx_number`. `render_xlsx_cell_value` and `parse_xlsx_cell_value` take `Option<Locale>`; `None` is the canonical invariant OOXML spelling. German `1,5` stores `Number(1.5)`. Only the locale's own separator is a decimal mark, so English `1,5` and German `1.5` stay text instead of silently regrouping digits; a repeated separator stays text; non-finite values stay text. The unchanged-draft check compares in the same locale. The UI command path (`handle`) passes the session locale from `ViewModel`; the agent/tool reducer path passes `None` (invariant). Stored values are unchanged canonical numbers. The viewer (separate surface by design) has its own display twin.
4. G7 grid labels. Row and Column axis names come from the catalog labels (`row`, `column`) instead of a `match locale`, in editor and viewer grids.
5. G11 natural-file hidden argument labels. `natural_file_action_arg` now takes explicit en/de labels: Format kind/Formatart, File extension/Dateiendung, Media type/Medientyp, Binary/Binaer (umlaut in source).
6. G3 `artifact-definition.json`. Profile `any`, source dialect `source` and the external-reference resource are `implemented` (external relationships are preserved as inert data and only created through the explicit `set-relationship` mutation, never fetched). 27 mutation leaves (13 base, 8 strict, 6 transitional; `strict-`/`transitional-` prefixed for the subset-specific ones) and the `outline` inference are declared `implemented` with `executable_registration: false` (same convention as the json artifact; they are not registered as stdio executables). The empty `public-corpus` suite is replaced by `calamine-oracle` listing the five real fixture groups. The support ledger is `opaque` for read, write, lossless and canonical, and its mutation, inference and fixture lists mirror the definition. The standard stays `unverified` and the ledger cannot claim `implemented`: the validator (`stdio-ledger` and `assembly`) requires a normative source, publication date, checksum, known redistribution status, clauses and validators, and no checksum of the ECMA-376 text is available offline.

## Tests added or updated

- base editor: number-notation fixture (`🧫️fixtures/🔢️number-notation/🔣️.json`, language-agnostic) checked against `serde_json` as the third-party float oracle; German decimal comma edit; unchanged localized draft emits nothing; label catalog en and de; edit layout titles.
- base viewer: localized number display, label catalog, view layout titles.
- strict and transitional editor tests: adapted to the new `locale` argument.
- plugin natural-file lifecycle: hidden argument labels carry both languages.
- hub catalog: capability counts updated for the new xlsx definition entries (declared mutations 30, declared inferences 68, implemented mutations 27, implemented inferences 1).

## Not changed (residual)

- The shared `snapshot_details_split_layout` still receives English titles "Workbook", "Strict workbook" and the fixed "Details" in the shared contract; this is a cross-artifact contract and out of this ticket's scope.
- The generated Office/stdio component descriptors (`🌎️hub/🧩️compositions/🗄️stdio/🧩️component/🔣️.json` and siblings) embed the xlsx definition identities and descriptor hashes and must be regenerated by the repo's describe step.
