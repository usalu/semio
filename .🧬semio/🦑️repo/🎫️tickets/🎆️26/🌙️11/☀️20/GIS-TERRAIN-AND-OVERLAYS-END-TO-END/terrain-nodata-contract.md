# Esri ASCII Terrain NoData Contract

## Canonical elevation source

Keep the 2–65 sample bounds, south-to-north rows, west-to-east columns, WGS84 sample-centre extent, and exact signed i32 millimetres. Add optional `missingSamples` to the authored elevation source and inline terrain descriptor. Its JSON value is the lower-case hexadecimal encoding of a packed byte array. Bit 1 means missing. The south-first ordinal is `row * width + column`; within each byte its least significant bit addresses the first ordinal. Use exactly `ceil(width * height / 8)` bytes with zero high padding bits. Omit the member when all samples are present. Refuse null, empty or all-zero masks, mismatched lengths, uppercase and non-hex digits, set padding bits, and nonzero stored millimetres at missing ordinals. A missing sample has one canonical numeric payload of zero, distinguishable from a valid zero by the bit. Every i32 value is available for valid data. An all-missing source and a source with valid isolated samples are both authored sources and both may have zero faces.

Use one first-party validity type with checked construction, lookup and row iteration across GIS and the shared surface. Keep the JSON schema, Rust/TypeScript parse and native receive, GraphQL and Protobuf, DSL and Pack, canonical trees, text snapshot, normalized SQLite, mutation codecs and shared scene descriptor consistent. A validated optional bounded string can serve the existing JSON, DSL and native receive boundaries; the shared validity type decodes it once for geometry and queries. The staged storage chooses nullable TEXT for the same lowercase encoding on the existing SQLite source owner. Both projections and reconstructions retain it, with validation at the owner boundary and unchanged row counts and ordinal admission. A masked maximum-width grid adds 529 raw bytes or 1,058 hexadecimal bytes before headers and ownership. Charge copies, replays, validation and preparation against the actual owning lanes, and retain existing read, prepare, publish and cancellation checkpoints.

Import through the registered `elevation:in` and the Terrain file picker. Read the marker as an exact base-ten decimal. For bounded signed decimal/scientific tokens, strip leading and trailing zero digits and compare sign, significant digit sequence and adjusted power of ten. Use checked exponent arithmetic without expanding powers and normalize all signed zero spellings together. Decide marker equality before millimetre parsing so that markers can lie outside i32 metre limits or below one millimetre, and reject an unrepresentable sample only if the decimal differs from the marker. Keep the omitted header default of −9999. Reverse sample rows and mask ordinals together on import/export. Continue to reject malformed header or samples and non-square angular cells; a deliberately missing value is a valid inspected sample. Export an explicit `NODATA_VALUE -9999999` and emit that integer for missing ordinals. The value is outside the valid metre interval and exactly representable as Float32. The current output sentinel `-2147483.649` and valid minimum `-2147483.648` collapse to the same Float32 value. Exact millimetre interchange uses the written text and Float64 readers; mask classification should agree in Float32 readers as well. The change needs no file format extensions. [Esri ASCII to Raster format](https://pro.arcgis.com/en/pro-app/3.0/tool-reference/conversion/ascii-to-raster.htm)

Use one accepted `ReplaceElevationSource` artifact mutation for a complete import. The retained candidate, forward diff, inverse mutation, history and saved source include the mask. A mask-only replacement with otherwise equal bounds and rows is a real change. Undo and redo restore exact topology including the distinction between authored empty and no source. Cancellation before publication leaves the old source, map, and History Head intact. Preserve the current WGS84 extent policy and localized validation and status messages. Report total, present and missing sample counts in Terrain Data and omit elevation extrema when no present samples exist. Indicate when an authored grid has no surface. Supply English and German through the existing locale catalog.

## Shared surface topology

Preserve the existing north-first projection and the northeast–southwest diagonal in every cell. Emit each of its two existing triangles exactly when all three vertices are present. Check each triangle independently. There is no diagonal flip, height filler or vertical wall around a hole. Valid vertices with no incident face exist in the raster but carry no surface area. A closed face owns its edges and vertices, even if a neighbor is missing. On a grid line or diagonal, resolve support from either incident face with a deterministic tie. An all-missing or zero-face source suppresses fallback terrain within the authored mode. Its bounds still drive a horizontal camera frame; use a valid incident sample for the camera altitude if the centre has no face and the ordinary default camera altitude if there are no faces.

- **Renderer and picker.** Share a face iterator with contours and scene export and keep row mapping explicit: renderer row `r` refers to canonical row `height - 1 - r`. Keep the renderer's dense vertex layout if useful for indexed UV/topology and drape. Never index a missing vertex in a face, use valid neighbor differences or accumulated incident-face normals, and exclude missing samples from height ranges. Renderer fallbacks for unused buffers are internal only. In `pick/🦀️.rs`, intersect emitted faces and retain the winning vertex IDs so a returned nearest sample is valid, with a stable tie. Preserve the geographic hit and skip a foreground gap when looking for a later intersection. Vertical rays over unsupported interior points return no hit. Disable fallback local picking/rendering that would fill an authored hole.
- **Overlay drape.** `overlay/🦀️.rs` currently evaluates every triangle even if a future mesh emits fewer indices. Reuse the face-availability predicate and make surface interpolation optional. Hide draped markers in gaps, including markers whose provided elevation acts as a floor on top of a valid surface. Keep overlay data in the artifact. Split route and region-boundary lines at existing x, y, and x+y crossings, classify each open interval by midpoint face support, then interpolate both endpoints on that face. At cell or diagonal edges, consider either incident face so the result is independent of path direction. Emit no degenerate intervals or bridging segments across gaps.
- **Edits.** Numeric sample editing refuses a missing target clearly. Grade, raise, lower, flatten and smooth operate on valid targets and preserve all validity bits. No change means no terrain diff or history entry. Smooth uses valid neighbors within the current stencil without crossing a missing edge and leaves a sample unchanged when no neighbor qualifies. Dabs need an eligible surface hit; the individual brush kernel excludes missing samples and a continuous pointer gesture emits no synthetic hit across a gap. The direct grade/brush mutation produces the same after-state when applied or replayed. Filling gaps, if added, requires explicit intent and immutable before/after topology through the usual mutation and inverse.
- **Contours.** Derive unexaggerated levels, crossings and routes from emitted faces only, using existing tie deduplication and density/cancellation handling. Estimate levels from face-referenced samples so an isolated extreme cannot cause a valid surface to fail its contour density bound. Stop at the missing boundary and produce zero lines for zero faces. Generating contours again replaces the prior generated contour set even when the new set is empty. Preserve manually authored map features.
- **Scene interchange.** `TerrainSceneView` currently obtains a dense index count and random-access indices through its resumable borrowed source. Prepare a bounded owned face-ordinal list (or compact index map) with a per-row checkpoint; index scalar lookup must remain direct without scanning cells per scalar. Export only referenced vertices for a holed scene, remap indices deterministically, and project the same normals/ranges as the renderer so missing positions never leak into external mesh bounds. Emit the existing localized empty-scene outcome or a validated empty mesh if the receiving schema supports it. The ASCII export stays available independent of face count.

## Verification and integration

[Language-neutral fixture](terrain-nodata.json) checks rectangular orientation, explicit and implicit markers, decimal-equivalent markers, a Float64 alias, i32 extrema, valid negative and zero heights, all-missing and dense rasters, exact face membership, edge point interpolation and draped gaps. [Executable prototype](verify-terrain-nodata.py) reproduced all five sources and faces with first-party code and re-imported each ASCII export. It also checks the maximum 65 × 65 mask and refuses nonzero padding and masked nonzero payload. Rasterio 1.5.2 with GDAL AAIGrid independently matched the applicable source shape, bounds, NoData mask and valid millimetres using Float64. GDAL matched all five exported masks in both Float64 and Float32. The near-equal marker input is a first-party precision test because a Float64 reader cannot distinguish the marker spelling from its rounded valid neighbor. The prototype runs with `repo tools exec --light python -- <ticket>/verify-terrain-nodata.py`; pass `--gdal` with Rasterio and NumPy available in the test interpreter.

Before publishing source changes, run this fixture across Rust and TypeScript parsing and across JSON, DSL, Pack, SQL, text and mutation round trips. Cover the maximum 65 × 65 mask, invalid mask padding and payload, controlled cancellation, and an old/new import with equal dense rows and different missing bits. Use the registered Terrain app to import, save, reopen, undo and redo; assert unchanged elevations and missing topology. Exercise both browser and native shared surface hosts with interior and boundary hits, draped routes through holes, no-face grids, no-op grade/brush and smooth boundary cases, a contour terminating at a hole, and parsed scene indices and bounds. The prototype and contract are ticket files, and production integration has not been applied.
