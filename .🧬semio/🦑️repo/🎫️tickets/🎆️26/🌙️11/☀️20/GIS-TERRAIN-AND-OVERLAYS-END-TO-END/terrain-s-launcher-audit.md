The genuine broker lane is `repo run os-hub:local-hub-owner` on 8787. It consumes the published Hub executable and verified native packages `stdio,gis,note,writer,draw,puzzle,space`, and issues a local developer session. The browser scope does not change those Hub prerequisites. Let the ordinary s contribution discover the broker for automatic signing. `S_HUB_URL` connects an external Hub origin without automatic developer credential relay, and `S_LOCAL_ONLY` bypasses the Hub. The separate command `repo run os-hub:trusted-catalog-bootstrap -- --packages <list>` validates and publishes an immutable selected generation, then exits. It is not a replacement for the running tenant service.
