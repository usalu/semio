# Continuous Terrain Brush Strokes

`terrain-brush-stroke.patch` prepares the registered GIS Terrain editor and React interaction. It reuses the existing `editElevation` verb and the same reversible `ReplaceElevationSource` artifact mutation used by clicks. A stroke follows actual authored-grid ray picks, spaces its ordered samples by brush radius, and emits one command when the primary pointer releases on the surface. Work remains in the transient gesture and private reducer grids until one Store publication. Ordinary clicks send the existing five fields. Wheel, right-button and middle-button navigation keep the existing Orbit bindings. The declared brush mode reserves one-finger input and leaves two-finger pinch navigation in its existing recognizer.

The optional hidden action argument is `stroke: [[column, row], ...]`, with one through 64 anchors and integer coordinates in the authored 0–32 grid. A path must begin at the action’s column and row. Raise, Lower and Smooth use the stroke path. The action parser checks each two-component tuple by reference before collecting the narrow owned pairs. Integral runtime float tags are accepted at ingress, and the derived typed command writes unsigned integer tags for those coordinates. The reducer grants no more than 64 interpolated stamps. Its grid passes read one source and write one destination per stamp, allowing Smooth to read a consistent previous stamp without in-place neighbor bias. Both grids remain private on overflow or cancellation.

The registered retained ceiling reserves 696,961 work units. The stroke quotes the exact number of admitted stamps times 33² cells times ten units for the current cell and at most nine smoothing neighbors, then leaves one bookkeeping unit at the maximum. The worker checks its issued turn and source before spending, waits when a valid local turn has insufficient remaining fuel, and checks cancellation and deadline between stamps and before emitting. The largest neutral case reaches exactly 64 stamps and 696,960 charged work units.

Browser gesture cancellation covers losing the picked surface, lost or cancelled pointer capture, a competing touch, Escape, blur, a grid/frame or tool replacement, and the 64-stamp bound. The R3F event adapter handles native cancellation at the DOM boundary because its own cancel/lost handlers do not dispatch those events to a mesh. The fixture checks gesture ownership, cancellation, and deferred capture loss. Ajv validates the nested action shape. The independent TypeScript arithmetic reference and Rust fixture cover identical Raise, Lower and Smooth outcomes. The Rust mounted law additionally checks one Artifact receipt and ordinary whole-stroke undo/redo. The patch keeps the current grid replacement representation. The in-progress path is transient and does not render a displaced-mesh preview.

The native pointer approach is in the separate native-brush ticket patch. It must use the same release payload, ray-hit validity, operation modes, interpolation and cap. TypeScript verification only covers React gestures and the independent oracle. Native and live browser execution require the patch to be applied and built after the current Dev capture.
