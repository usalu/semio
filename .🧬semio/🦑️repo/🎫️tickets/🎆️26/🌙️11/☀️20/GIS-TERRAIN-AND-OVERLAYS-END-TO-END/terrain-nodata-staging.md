# Staged Terrain NoData Storage and Exchange

[Production patch](terrain-nodata-canonical-exchange.patch) changes 32 paths. [Stage generator](stage-terrain-nodata.py) reconstructs the patch from the live source without editing that source. It can also recreate the isolated Rust and TypeScript test inputs under the ticket's generated folder.

The storage uses optional canonical lowercase hex in the elevation source, mask-aware equality and replacement, and the matching native record, JSON canonical tree, text and Pack paths. SQLite stores the same wire value as nullable TEXT on the existing elevation source row and retains dense millimetre ordinals. Native row admission verifies the optional field's size against the dimensions, and reconstruction observes the original byte and row limits. SQL row counts are unchanged. The structured elevation reader accepts compact JSON for the full authored 65 × 65 range within its 64 KiB limit. The GraphQL and Protobuf contracts carry the optional text value. The shared inline scene grid transports and validates the same mask.

The retained ASCII reader builds topology in a fixed 529-byte south-first bit buffer while reading one row at a time. It publishes one replacement after charging the retained hex value. The mask participates in the no-op comparison, so changing a zero-height sample to missing triggers a real mutation. Exact decimal matching retains distinct near-equal samples and both signed extremes. Both direct and segmented download emit the collision-free marker at the original missing ordinals.

The staged patch passed read-only applicability checking. A standalone native binary compiled the exact staged Rust mask and ASCII modules with the repository's configured Rust toolchain. It passed the five language-neutral fixtures, full 65 × 65 mask, round trips and invalid mask cases. Rasterio/GDAL passed independent comparisons against all five ASCII files emitted by that binary in Float32 and Float64. Bun, Ajv and Bun SQLite ran the staged TypeScript schema and SQLite projection/reconstruction with 21 passing assertions for shape, native ordinates, the stored mask and malformed padding.

The repository-native Rust integration builds and tool-level browser/native acceptance were outside the staged test surface. The patch transports the mask to the shared terrain grid, and it must land together with the [surface and editor consumers](terrain-nodata-contract.md). Existing dense terrain geometry, drape, contour, grade, brush and scene-export code would otherwise treat the canonical zero payload as a valid height. The source patch has only been staged in the ticket.
