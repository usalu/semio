# Terrain Viewport Move Position

The Terrain editor exposes **Move Position** in English and **Position verschieben** in German. The tool is active on an embedded elevation grid. A primary drag claims the rendered pin’s overlay ID. On release over a valid terrain triangle, World3d sends the exact WGS84 longitude and latitude through the registered `moveOverlayPosition` action. The editor applies the overlay mutation and owns its history. The existing numeric action form remains the keyboard entry point for the same action.

The browser holds one pointer capture and resolves competing pins by intersection distance. The native host checks its rendered marker geometry against the pick ray, with terrain occlusion and deterministic overlap ordering. The native action reservation checks the terrain and utility revisions again before publication. Pointer cancellation, capture loss, window blur, utility or terrain replacement, a missing sample, an off-grid release and a release within three pixels of the press produce no move. The typed action also discards exact coordinate repeats.

The shared fixture records drop coordinates and cancellation cases. The browser contract and gesture tests use Ajv to validate the action descriptor and Three.js Raycaster to verify release coordinates and terrain gaps independently. The native journal test consumes the same fixture and exercises marker overlap and the bounded dispatcher. The mounted editor test sends the fixture’s viewport arguments through the registered action, checks the exported GeoJSON position and the retained label and elevation, then exercises Undo and Redo.

The two focused Move Position tests passed all 43 assertions. React and Rust source syntax checks and the scoped whitespace check passed. A combined browser run also passed the two existing brush gesture tests. Its brush arithmetic test reported an empty fixture grid during a concurrent edit to the shared elevation fixture. The standalone native journal run was cancelled after waiting for the repo’s Cargo capacity admission. The repository reported insufficient free memory and a swap ceiling during that wait. The native journal test and mounted editor test require the compiled Rust host or editor package.
