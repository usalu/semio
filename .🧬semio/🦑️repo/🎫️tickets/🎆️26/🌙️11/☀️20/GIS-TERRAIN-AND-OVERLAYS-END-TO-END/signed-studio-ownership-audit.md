# Signed Studio Ownership and Reload Audit

The signed route resolves the Space's indexed `s.space.studio` document with schema `os.workflow`, attaches its exact Space/document scope, and runs `openSpace` against that document. A stored Workflow node carries a separate Terrain artifact reference. SQLite checks the Studio singleton inside the immediate genesis transaction. PostgreSQL and Neo4j check it under the Space and directory writer locks. The losing create request re-reads the Index so it can mount the winner. 1. **Forward signed Studio effects through the admitted browser actor.** The actor publication codec accepts service operations and external URLs. It throws `unsupported host effect` for `replay-shell-command`, which starts persisted Terrain creation, and `open-plugin-instance`, which opens the existing Terrain when its node is activated or its URL is reloaded. The browser result dispatcher likewise handles only those first two effect types. Add exact typed projections for the required Studio effects and pass them through the existing guarded host-effect dispatcher with the actor action's document owner. Extend the same rule to the Terrain file-picker and download effects where required. Test canonical wire round-trip and retirement before effect publication. 2. **Use the same live Terrain actor for display, edits, history and role preparation.** Actor acquisition and the send guard compare the document entry's app and instance directly with the primary Studio session. A mounted Terrain child therefore fails both checks even while its retained actor paints the focused window. Edit and Undo can fall through to the local guest. Match the exact live spawned panel row plus the already verified attachment, mailbox and activation generation. Count direct browser actor calls in the session work drained by role switching. Role preparation and shell archive export currently read the local handle, so verify those bytes against the mounted actor revision after an edit and before checkpoint. Use the authoritative document pair if they differ. 3. **Acknowledge deep-link recovery only after the child mounts.** After `openInstance` is reported applied, the route writes `openInstanceIdRef` even if the effect found no registered program or the attachment returned null. The same route then short-circuits by node ID. Make the exact mounted panel entry and document attachment the success condition, preserving retry after a reconnect or a refused attachment. Also isolate the lookup lease from the existing Space Index subscription. The lookup opens and closes a worker directory lane keyed only by Space ID, so another subscriber to that Space can lose its feed.
