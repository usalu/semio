# Staged NoData Surface Integration

[Surface patch](terrain-nodata-surface.patch) changes 12 paths and applies after the [canonical storage and exchange patch](terrain-nodata-canonical-exchange.patch). [Stage generator](stage-terrain-nodata-surface.py) reconstructs the incremental changes and writes a 41-path combined storage and surface patch under the ticket's generated folder. Both patches were prepared without editing live source.

The shared Rust topology preserves dense north-first vertex numbering and the renderer's original winding and diagonal. It emits a face only when its three samples are present. Native and browser renderers consume the same shared mesh. The picker returns a valid vertex on the hit face for a holed raster. Overlay markers require a supported face, even when they carry an elevation override. Routes and region boundaries use midpoint face ownership for each clipped interval, including either closed side of a grid line or diagonal. A grid with no faces yields empty buffers and no picks, origin sample or drape. The authored grid remains the active terrain source.

Unreferenced vertices do not affect rendered altitude bounds, UV normalization or normal differences. Direct scene export compacts to referenced vertices by dense ordinal. The retained scene output uses per-row counts and bit sets with bounded rank and selection to generate the same positions, normals, UVs and remapped indices without materializing a mesh. Empty scene output uses the existing mesh document carrier with empty triangle buffers. The camera keeps the authored horizontal frame and finds the center face or nearest supported sample. With no faces, it uses the ordinary overlay-based altitude.

The isolated native harness compiled the staged topology, projection, mesh, picker, overlay and scene modules with the configured Rust toolchain. It passed four fixture cases for signed extrema, surviving single halves, closed diagonal and gridline queries, reversible route clipping, region clipping, all-missing sources, and a valid isolated extreme with no influence on rendered bounds. It compared every retained scene scalar to the direct compact mesh, including the empty representation. A rank-select unit test passed with faces at both ends of the 128-bit range and an empty interior row. The [Three oracle](verify-nodata-surface-oracle.mjs) independently agreed with rendered indices, rays and draped route and region segment midpoints. The drape comparison uses a Float32-scale height tolerance for the fixture's kilometre-scale elevation extrema. The combined patch passed read-only application checking.

Canonical storage and surface integration overlap in the shared terrain core, shared terrain unit tests and GIS text snapshot camera source. The combined patch and the separately staged editing patch overlap in contour and grade-region source. Workspace-native component builds, the added browser fixture and registered scene delivery still need to run after coordinated application. Grade, brush and contours are in the separate editing slice.
