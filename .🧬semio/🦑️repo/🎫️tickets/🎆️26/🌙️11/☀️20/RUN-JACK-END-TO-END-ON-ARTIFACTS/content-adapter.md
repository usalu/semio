## Bounded graph planning follow-up

A localized first improvement can preserve the publication interface. The production qualifier can park one composition-specific planner alongside the qualified child source and replace its one `child_mutations` call with planner turns. The planner can use SemioGraphSnapshot's existing RetainedClone cursor and the framework ClonedProjection sequence for scratch admission, incremental clone, output transfer, and cursor close. It can carry an effect index, one pending leaf, and an incident-edge scan offset. A node deletion scans a fixed page at a time, emitting one incident edge deletion before continuing the scan and a final node deletion once the scan completes. Successful leaves occupy the same original typed output vector. A separate paid retirement stage closes the scratch before handing that vector to the existing qualified batch API. On refusal or cancellation, the same close ladder retires the partial clone, scratch, and all planned leaves.

A one-leaf turn still has Semio's cold vector lookups, recursive property conversions, and row movement. Fully bounded latency requires indexed or paged typed mutation semantics for lookup and deletion, plus incremental proof of exact property ordinals and value conversion. Keep the live write path unchanged until the planner can meter those active steps and preserve the current apply and inverse outcomes. Existing full-scene entity limits and query input admission bound the current work size, while the cold scratch phase still has no cancellation yield within that phase.
