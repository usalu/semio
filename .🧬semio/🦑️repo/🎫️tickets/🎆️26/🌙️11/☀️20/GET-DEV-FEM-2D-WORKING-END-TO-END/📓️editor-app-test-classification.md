# FEM2D editor integration test audit

The 20 November `editor-native-boot-fixed.txt` log reports 163 errors for the `editor_app` integration target. It has 162 source-located Rust diagnostics and one compiler query-depth overflow when laying out the async body of `context::history_verb`. The 169 warnings are separate. The counts below are diagnostic counts, including multiple reports at the same expression. They are neither failed assertions nor a count of independent source fixes. Current source was inspected after the captured run. No build was started for this audit.

## Bounded modernization order

1. Replace the common fixture plumbing first using the registered boxed setup in `editor_boot`, the current reference/empty snapshot admissions, `Arc<ViewModel>`, and the original fixture scope for close. Replace the ad hoc history drain with `settle_registered_typed_operation` and assert the returned `history_patches`, retaining page/lane completion checks where the law needs them. Box or separate the history future boundary if the compiler still reports layout depth. No runtime recursion-limit change is implied by this log.
2. Separate the pure command/manifest suite from the app-heavy binary. Resolve payloads from their defining crates and use current enum and factory contracts. Keep the language-neutral command fixture, exact command/order/codec checks, action defaults and all-lane assertions. Include the active manifest declarations without exposing owner-private helpers.
3. Restore owner-local tests for add/patch intent, outliner viewport/selection marks, and retained visual packet lifecycle. Build or decode accepted snapshots, address entities with current scoped identities, and retire owned snapshots through their controlled fixtures. Register model packet tests in the model-window owner so its private lease checks do not require an exported snapshot field. Keep short semantic checks through the public facade in the application target.
4. Re-enable a compact mounted integration set using current public app APIs. Keep undo/redo, gumball transaction semantics, reconnect/idempotence, peer departure and editor media ports as separate law groups. Verify both integration targets with the shared harness after the owner-local suites work. The already focused `editor_boot` remains an independent gate.

## Shared fixture modernization

The shared context uses the boxed registered app constructor, the canonical `exampleId` shell argument when loading an empty document, and the host's admitted load effect. Both retained dispatch helpers now send an owned action view. History rows come from the public funded settlement receipt, which already closes and acknowledges result pages and rejects fault lanes. The row filter and 30-second settlement check are retained. A boxed history future limits the layout crossing into the law, and explicit or automatic close still requires a terminally empty app. The concrete app field and all law call sites remain compatible.

This step addresses the four source-located context diagnostics and changes the layout boundary implicated in the unnumbered compiler overflow. The other 158 historical source-located diagnostics belong to untouched test families. That arithmetic is a triage inventory, not an updated compiler result. Cargo verification of either integration binary remains pending because the native and guest build lanes were occupied.

## Command and media progress

The command and manifest laws now bind to the editor and command crates that define the payloads. Wire tests call the current staged action resolver, the route table comes from the public factory identity, and command publication reserves a real authoring identity in its test fixture. The editor media laws now run in the editor boot target as well as the broader target. They construct an accepted material snapshot, supply an authoring identity for geometry import, and read results through canonical source IDs.

Artifact media import previously released the decoded snapshot through Rust drop after encoding the load effect. It now explicitly retires that owned snapshot after the effect takes its Pack bytes. The port laws are queued for native verification.

The first results-window rerun advanced past the session gate and stopped while compiling the shared job-return crate. Its header guard still called two helpers on its former parent after the original return source moved into the job context crate. The guard now uses a source-owned row reservation that preserves the existing pending-claim reason. The isolated results rerun is compiling past that crate.

No shared workspace lock or source copy was needed.
