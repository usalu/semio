# Mounted FEM analysis modes

Before the retained implementation, FEM 2D's window config and request registry already tracked the analysis family and index, with Modal independent of the load source. `💼️job-bridge-and-live-mount` refused Modal and Buckling before admitting a snapshot. The state machine connected only the mesh, static assembly, recovered displacements and visual publication. The published `NodeLiveField.mode_shape` was zero and the results window had no eigenvalue to display.

FEM 3D has a bounded modal implementation in `🎼️modal-and-publication-stages`. It maps lumped mass into compact free equations, transfers the stiffness matrix, constructs the symmetric pencil, runs the retained LDLT and subspace jobs, and publishes an eigenvalue with each mode shape. Its corresponding static recovery stage still explicitly refuses Buckling with `fem3d.numerical-buckling-owner-missing`.

FEM 2D's synchronous modal engine assembles the consistent element mass matrix, including off-diagonal entries. Matching its frequencies needs an incremental mass assembly with that matrix and cannot use FEM 3D's diagonal lumped mass as a drop-in. FEM 2D's synchronous buckling engine solves a reference load, computes each element's geometric stiffness from the displacement, assembles the signed geometric matrix, and filters the eigenvalues. The 2D element implementations currently expose the batch geometric matrix only.

A mounted completion needs control of mass and prestress owners, assembly, LDLT and subspace job stages, typed publication and retirement, and mode/index/authority freshness through cancellation and reconfiguration. It also needs independent frequency and load-factor fixtures to validate the browser-visible values. This spans the FEM element engine, retained session stages, Visual/Results projection and job verification laws. Calling either batch solver inside render would block editing and forfeit the retained job's ownership, progress and cancellation controls.

## Retained implementation

The shared `SymmetricPencilConstruction::new_pair` can now transfer a full CSR as its second matrix. FEM 2D stages assemble consistent mass or signed geometric stiffness in the exact compact equation order of the stiffness assembly. The retained route advances element positions, free equations, individual coefficients, sparse conversion, LDLT and positive-spectrum subspace work under the worker’s turn grant. Buckling uses the selected load’s converged PCG displacement. The results window addresses the exact family, source and mode index before painting a deflected shape and frequency or load factor.

The NumPy four-point Gauss oracle matched every entry of the cantilever free-tip mass block, including its off-diagonal translation–rotation coupling. The same oracle independently gives the first cantilever frequency as 6.462388647654482 Hz and first positive buckling factor as 464.04618383572256. Separate native element-cell tests and NumPy quadrature compared 320 coefficients across five fixtures, including signed prestress, reversed orientation and zero density. The mounted session suite passed 19 of 19 tests. Its cantilever law completed both modes, matched the independent frequency and buckling factor above, confirmed a nonzero result field, and retired the original owned job. The browser gate is still in progress.
