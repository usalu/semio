# FEM 2D Demo Eigenmode Browser Checks

The optional `--eigen-modes` browser gate follows the static edit and Live Load check. It uses the Results panel's Mode control, waits for the first modal frequency in hertz and first buckling factor, and verifies the canvas paints both a converged status and the corresponding deformation path. The default browser run still stops after the static round trip.

The live static reaction gives an independent witness that the bundled demo has a physical positive buckling mode. The detached frame's roller at `p8` carries 12,000 N vertically and connects only to the vertical timber post `p8–p8_l1`. With no applied load between these nodes, equilibrium puts the post in compression. The roller leaves its rotation free. A trial displacement with only that rotation nonzero is a valid mode-space vector, and its elastic bending energy and negative geometric energy are both positive. The NumPy oracle `🧪️demo-buckling-witness.py` computes the energy ratio with Gauss quadrature from the DSL values. Its trial factor is 112.24489795918366, so the lowest positive physical factor is at most that value. The browser check uses the sign and converged shape without assuming the first factor equals the trial factor.
