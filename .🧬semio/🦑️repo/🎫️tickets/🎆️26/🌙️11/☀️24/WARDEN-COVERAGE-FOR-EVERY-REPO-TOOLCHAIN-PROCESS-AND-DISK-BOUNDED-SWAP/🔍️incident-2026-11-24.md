# 🔍️ Incident: Worker Halted by macOS for Application Memory (2026-11-24)

## Facts on this worker (16 GB Mac)

- Host warden (`🧰️framework/🔨️modules/🏃️process/🏗️build/🌡️host-capacity/🛡️warden/`) ran the whole time (pid 58345, started ~10:53, mode `enforce`, state fresh at 17:19).
- Its last action was at 13:54; between then and the halt it logged nothing. At 17:19 its subjects were only `stage` and `slice-worker` (135 MB), while six `rustc` processes of a native `cargo build` (1.17 GB, 0.73 GB, 0.64 GB, …) ran unseen.
- Swap: total 3072 MB, used 1856 MB. The data volume had been at 95–100 % earlier today (ticket build dirs of 70+ GB under `SOURCING-END-TO-END/🗑️generated/`), which leaves macOS no room to grow swap files.

## Causes

1. **Ancestry gap.** `Roots` in the warden schema only admits descendants of the repo bun runtimes and `semio-build-scheduler`. Processes started from a shell (agents' Bash tool, ticket scripts) are never subjects, even when they are the repo's pinned `rustc`/`cargo` (`.cache/b/t/m/r/*/toolchains/*/bin/`), cargo test executables under repo target directories, or Playwright browsers from the repo browser path.
2. **Admission bypass.** The ticket's native fallback scripts (`native-wasm-build.sh`, `minav-cargo.sh`, `verify-cargo.sh`, `gesture-cargo.sh`) pass `build.rustc-wrapper=""`, i.e. they skip the unit-cache wrapper where local units are admitted, and ran with `-j 8` while agents ran `cargo test` in parallel.
3. **Disk-bounded swap.** The warden ladder measures available memory and swap-out rate, but not how much swap can still grow; with a near-full disk the OS runs out of application memory while "available" still looks above the guard line.

## Fix plan

- Warden: subjects by toolchain/target/browser identity regardless of ancestry; new kinds for cargo test executables and repo browsers; swap headroom bounded by free disk enters the level; tests against the Python oracle.
- Admission: native cargo invocations go through the host-capacity gate (job count from the grant) and keep the rustc wrapper; ticket scripts rewritten accordingly.
- Carving: measure peak memory per compile unit of the sourcing closure under the warden; carve units above `Policy.unitCeiling`.
