# 📝️ PW-10 — windmill-palm, banana-plant, tree-fern

Worker PW-10 of the Staffage Plant Collection Wave. Three new `semio.staffage/v2` vegetation assets, generated end to end by scripts in `🧰️scripts/PW-10/` that reuse the round-3 date-palm generator of the 3D-models ticket (`☀️14/PERFECT-HANDCRAFTED-…/r3-date-palm-kit.ts` for frames, lofts, outlines, unions; `r3-date-palm-parts.ts` `FrondGeom` for the arched two-bone leaf; `r3-project2d.ts` `forward` for the product's placement of 2D shapes; `volumes-lib.ts`), imported from their place, never copied.

## Scripts (inputs, kept)

| file | what |
|---|---|
| `pw10-plant.ts` | shared builder: golden-angle crown tables, leaf bones, exact pose offsets per leaf (`solveOffsets`), wind/snow/wilt crown responses, standard clips (`wind-sway`, `gust`, `diurnal-transpiration`), closed polyhedron sheets (`thicken`, `gridSheet`, `weldSheet`), torn/lobed laminae along an arched midrib (`lamina`), per-scale volumes (body, thermal by reference + transpiration patches, structure members/joints/support/masses), 2D drawings as true views (flat outlines through `forward`, leaf bones as `solid` extruded plates per band with v-spans fitted to the 3D), the plan symbol, document assembly |
| `pw10-windmill-palm.ts`, `pw10-banana-plant.ts`, `pw10-tree-fern.ts` | the species: every measure, LOD table, form, text (en, de), physics |
| `pw10-run.sh` | build + `r3-validate.ts --file … --volumes` for each asset (`SHIP=1` writes the catalog file) |
| `pw10-diag.ts`, `pw10-solids.ts` | silhouette diagnosis per view, fast kernel `polyhedronFault` check |
| `pw10-manifest.py` | writes `📥️manifest-rows/<id>.json` from the shipped document |

Regenerate: `cd 🧰️scripts/PW-10 && SHIP=1 ./pw10-run.sh && python3 pw10-manifest.py`.
