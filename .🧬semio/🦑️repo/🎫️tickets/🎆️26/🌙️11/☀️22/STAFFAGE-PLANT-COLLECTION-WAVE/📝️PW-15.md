# 📝️ PW-15: Grasses and Perennials (pampas-grass, common-reed, sunflower)

Worker PW-15 of the staffage plant collection wave (brief: [📋️brief.md](📋️brief.md)). Three new `semio.staffage/v2` vegetation assets, each generated end to end by a script in `🧰️scripts/PW-15/` (kept as inputs) and written to `S/🗂️catalog/🌳️vegetation/<id>/🔣️.json`; manifest rows in `📥️manifest-rows/<id>.json`.

## Generators (inputs, kept)

| file | role |
|---|---|
| `🧰️scripts/PW-15/pw15-lib.py` | Shared assembly. Imports the round-3 miscanthus kit (`r3-miscanthus-grass-kit.py`: vectors, rig frames, lofts, arches) and model (`r3-miscanthus-grass-model.py`: `Plant`, `fine`, `coarse500`, `plume`, `solid_of`, `strip_of`, `outline`, `drawings`, `extent`) **from their place** in the PERFECT-HANDCRAFTED-3D ticket, and adds: a `Plant` subclass with `leaf` (no 1:22 width cap, declared `sheet` laminae), `drawings` wrapper (a sheet seen edge-on becomes a stroke of its projected width instead of an unprintable sliver), the planar rig from a shoot table, a species-parametrised structure list, poses/clips helpers (wind sway, gust, diurnal), the true-extent symbol in three views, outer-area estimates, the manifest row and the writer. |
| `🧰️scripts/PW-15/pw15-pampas-grass.py` | Cortaderia selloana: tables per scale in the miscanthus row format; built with `M.fine` (1:50, 1:100, 1:200) and `M.coarse500` (1:500). |
| `🧰️scripts/PW-15/pw15-common-reed.py` | Phragmites australis: own stand builder (culms apart on the rhizome, distichous leaf sheets, panicle branches / masses) from the round-3 parts. |
| `🧰️scripts/PW-15/pw15-sunflower.py` | Helianthus annuus: own builder (stems, spiral petiolate leaf sheets, necks, receptacles, ray-floret sheets) from the round-3 parts; dimensions are measured from the 1:50 body. |
| `🧰️scripts/PW-15/pw15-preview.sh` | Three-view sheets 1:50/100/200/500 + axonometric 1:50 as SVG, rasterised with the system Quick Look thumbnailer (`rsvg-convert` is not installed on this machine, so the preview CLI's own PNG step fails). |
| `🧰️scripts/PW-15/pw15-validate.sh` | Round-3 validator (`r3-validate.ts --volumes`: schema, `validateAsset`, print ranges, `checkVolumes`) from its place. |

Run: `repo tools exec python -- 🧰️scripts/PW-15/pw15-<id>.py`, then `sh pw15-validate.sh <id>` and `repo tools exec bun -- 🔨️modules/🗂️catalog/🩺️check/🟦️.ts --asset <id>`.
