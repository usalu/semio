All power 0 W (passive), all four scales 1:50, 1:100, 1:200, 1:500 authored with drawings (elevation, front, plan) and authored volumes (body, thermal, structure).

## Method

The archive generators of the existing plants (`ARCHITECTURAL-STAFFAGE-ARCHIVE/🧰️scripts/NW-V1`, `vegetation`) produce the pre-volume v1/v2 documents; the shipped
assets were afterwards reworked by many later tickets (multiview, per-scale volumes, flow obstacles, feature rules). Importing those generators would
reproduce an outdated state, so the new plants are derived from the **shipped** catalog document of the closest plant, which carries all of that work,
by exact geometric morphs, and then re-authored as a species (texts, materials, thermal, loads, poses). Generators (inputs, kept) in
`🧰️scripts/PW-09/`:

| File | Role |
|---|---|
| `morph.py` | morph library: `Morph` (per-bone local scale `S_b = diag(su, sv, sw)` about the bone origin, children keep their attachment point; bone-local geometry × `S_b`, world-space front/plan shapes by `o_b' + R_b S_b R_bᵀ (p − o_b)`; optional crown map: one world-diagonal affine for all crown geometry whichever bone a scale binds it to), `WorldAffine` (world-diagonal map of a subtree about its root: rest angles and lengths re-derived, bone-local geometry by `L_b(q) = R_b'ᵀ(map(o_b + R_b q) − o_b')`, exact for planar shapes and polyhedra; `keep` bones are carried without being deformed), `inflate` (vertical thickening of leaf masses about their bone's mean height), `shrink` (fruit about the point facing its bone), `fit_symbols` (true-extent symbols to the measured drawing box), `apply_floors` / `floors_from` (feature floors from the `volumes-feature` findings: thickening along the thinnest principal axis) |
| `species.py` | renaming, tones, texts by path, loads, section titles, number words, manifest row |
| `olive_geometry.py`, `fig_geometry.py`, `stone_pine_geometry.py` | the morph parameters of each species (design inputs) |
| `olive.py`, `fig.py`, `stone_pine.py` | species re-authoring: ids, materials, tones, thermal, poses and loads, provenance, all texts `{en, de}` |
| `*-floors.json` | recorded feature floors (design input written by `floors.py` from the validator) |
| `build.py`, `measure.ts`, `floors.py`, `ship.sh` | build → measure (default-pose extents per scale and view, validation) → floors → build with measured dimensions and fitted symbols → check (9 samples) → ship asset and manifest row → evidence sheets |
| `raster.ts` | PNG from the preview SVGs through sharp (librsvg), because `rsvg-convert` is not installed on this machine |
| `draft.py`, `geometry-loop.sh` | geometry-only iteration (draft, measure, check, 1:100 preview) |

Every shipped JSON comes only from these generators; nothing was hand-edited.
