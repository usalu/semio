# Audit 2: Python UI chrome against the frame and glass-chip design

Read-only audit. No source file, git state or build was touched. Scope: Python that draws UI chrome, above all the Manim teaching clips. Reference: `design.md` in this ticket folder (one axis-aligned rectangle, content edge to edge, chips inside on top of the content with translucent glass, a chip draws only its inner edges, no gap shapes, no outside tabs, no reserved strips beside content, no rounded corners).

Verdict legend: OK, OUTSIDE (chip or tab sticks out of the body edge), OPAQUE (chip opaque or not glass), SAME-SURFACE (chip uses the body tint), STRIP (title or chip in a reserved band that separates it from content), OTHER (anything else, e.g. rounded corners, full 4-side border, free-floating labels).

- `🎓️teaching` holds 621 `.py` files, 101 of them non-test Manim modules under `🏛️architecture`, plus `🧰️interop/🕐️clock` and `🎬️scene`. All Manim chrome is here.
- `🧰️framework` (671 files), `✏️s` (433 files; mostly `📕️norm` oracles, no drawing), `♻️mit-bestand` (1 file), `🏢️semio-tech` (0 files): no Manim, and no chip or footer drawing code found. `🧰️framework/🔨️modules/🖱️ui/🎨️styling/🔤️tokens/🐍️.py` only mentions `footerHeightUiSpacing` as a token value.

## Ranked fixes

1. **Make the energy `window_frame` family full bleed (STRIP to OK).** `watt_anchor` L324, `window_card` L1213-1230 and therefore `stat_card` and `card_grid`: body/reading centred in the whole frame, heading chip overlaid on the top row. Edgeless content (formulas, numbers, icons) must not carry `+ depth` in the frame height. Also fix `window_geometry` L110 (padded body) and its tests `📐️geometry/🧪️tests/🐍️.py:135-165`.
2. **One chip primitive for all shared chrome (OUTSIDE/OPAQUE/ROUNDED to OK).** Make a single `chip_glass` helper in `🎨️visuals` on top of `window_frame`: square, translucent, inner edges only. Consumers to migrate: Grasshopper `gh_ribbon` L434 (outside tabs), `gh_group` L27, `gh_viewport` L89, `gh_param_viewer` L476, capsule `_card` L1253 and `_table` L698, trees `_chips`/`_plate` L320-331, casting `_chips` L486, nakagin `_chip` L1688, BIM drafting `badge` L404, roadmap `_chip` and card badge L205-224, morph `_pill` L27.
3. **Single owner for glass paint.** Visuals hard-code `CHROME_CHIP_FILL = color("dark-6-7")` and `CHROME_CHIP_OPACITY = 0.76` (`🎨️visuals/🐍️.py:39-40`), and `surface_paint` (`…/🎨️surface/🐍️.py:73`) has no production consumer. Route chip fill through `surface_paint(level, parent=body fill)` and keep the same colour family in both places. Roadmap `shades` (L219) also uses `CHROME_FILL` directly, which is the body token (SAME-SURFACE risk).
4. **Strips beside content.** `class_box` L36-… (rule under header), `gh_group` L31 (head 0.36), `gh_viewport` `LABEL_ROW` (L102), `gh_ribbon` group titles L67, excel `_title_bar` L630, `window_geometry` L110. Replace each reserved band with a chip overlaid on the frame's top or bottom edge.
5. **Rounded corners and 4-side borders on chrome.** `frame_box` L27-30 (BIM), `badge` L404-411, `gh_group` L32, `gh_param_viewer` L482, capsule `_card` L1253, `_table` L698. Set the corner radius to 0 for chrome and draw only the inner edges for chips.
