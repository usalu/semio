The frozen editor suite had five create/delete/engagement-edge cases and two engagement command cases blocked by `retained command input requires its original app-owned retirement authority`. The fill failures also included a shared job fixture continuation with no diagnostic before the current fixture change.

`ui-history-frozen.py --refresh-editor` rebuilds only the live 2D retained crate, the live editor crates that directly depend on it, the current Puzzle job fixture, and the 2D history/edit test executable. It uses the cached test's direct dependency fingerprints to isolate the test from the rest of the live build. The current Puzzle job fixture has a separate Rust crate identity, so the test drives existing fill jobs through their shared `InteractiveJob` interface without substituting the job library used by frozen transitive crates.

The first invocation failed before compilation because the pinned compiler requires `-Z unstable-options` for `-C link-self-contained=+linker`. The retry compiled the current retained work, v1 editor, unit-test dependency, and Puzzle jobs fixture, then linked a 236 MiB native test executable. The two changed sources inspected for this run were the retained work component (`2a5df691889340ac30f992be1d607b56eea83f05af44e52a9f07d068280b70b0`) and Puzzle job fixture (`a6ec48e14aca6b319e9b8c66e27d512842cbc701890d4de4ec6aec979d097003`). The first execution aborted on the default test thread stack. The direct rerun reuses the linked executable with the frozen builder's `RUST_MIN_STACK=134217728` and one test thread.

The direct run passed all five `create_edge::tests` cases covering the duplicate preparation and both `engagement_submit::tests` cases. The previous native binary failed each of these seven cases before the retained work finished. The same run timed out with exit 124 while running the first alphabetically selected fill case, which requests 100 placements.

That helper resets the completed attempt and keeps the original source binding. Both callers consequently called construction again with an occupied output and no remaining candidate receipt. The fill run now tracks completed search and ingress admission separately and retires the constructor binding under the original close control before capture or search proceeds. `--refresh-fill-only --reuse-compiled` rebuilds the production fill crate and relinks the focused tests while retaining the current diagnostic job fixture.

With construction repaired, the canonical case fixture, Geo collision oracle, region constraint, and revalidation ran to completion. The canonical summaries use `serde_json` to read the fixture bytes independently and compare the complete objects. Object key order is irrelevant and every array retains exact order. Those paths now yield so the next funded turn can retire the placement first.

The tool declares its unit as `placements`. The earlier single-step test already measured successful placements and compared all candidate decisions with a free run. The final `--refresh-fill-only` run passed the canonical fixture, Geo oracle, target regions, replay raise and lower, conflict revalidation, and single-placement checkpoint law. The six native tests completed in 20.47 seconds, with 38 tests filtered out.
