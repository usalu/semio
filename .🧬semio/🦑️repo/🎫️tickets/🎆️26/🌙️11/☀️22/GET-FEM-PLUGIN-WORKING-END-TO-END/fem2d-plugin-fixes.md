# FEM 2D editor plugin fixes

Plugin root: `✏️s/🔌️plugins/🏗️fem/🗿️artifacts/◻️2d/🏅️standards/🔖️1/🪆️subsets/🌐️any/✏️editor/`. Laws run with `fem2d-fixes-law.sh` (own target dir `C:\t\p2`, logs in `🗑️generated/p2/`).

| # | Root cause | Fix | Law |
|---|---|---|---|
| 1 | The retained reducer (`🧾️retained-command-contracts-and-work`) ignored the live selection for `removeSelection` with no ids, so Delete/Backspace fell through to the no-op; `remove_ids` also left members, supports and loads naming a removed node, and the cascade-free `delete-node` made the whole transaction refuse. | `with_selection` resolves the keybinding payload in both routes; `remove_ids` cascades node to members, supports, nodal loads, member loads and area loads (dependency ordered). | `remove_selection_without_ids_speaks_for_the_live_selection`, `remove_selection_of_a_node_cascades_its_dependents_and_restores_exact_snapshot`, mounted atomicity law (cascade case, material stays protected). |
| 2 | The Results panel is bound by the host to the FOCUSED pane; with the Model pane focused it reads defaults (Static, hint row) and its commands rewrote the whole results config from defaults. Deformation Scale itself is wired (doc setting read by both result renderers); with results stuck on `Pending 0/0` there is no deformed shape to scale (other agent's re-solve stall). | `results::config::remember/remembered` shadow of the last window state feeds the panel when it is not bound to a results pane; `setResultDisplay` from an unbound panel starts from the shadow and publishes only the field it named (`addressed_fields`). | `set_result_display_from_an_unfocused_panel_is_remembered_and_sparse` |
| 3 | Focus: a panel button has no `window_id`, so `focusEntity` faulted `window-required`. Add Term: the select was omitted once every case was superposed. | Focus addresses `focused_window_id` and writes through new `set_camera::camera_in_window`; Add Term select always rendered (EN "Add Term", DE "Term hinzufügen"). | `focus_entity_from_a_panel_recentres_the_focused_pane`, combination Add Term laws (EN and DE). |
| 4 | The Analysis tree row had no pick target. | New `analysis` granularity (`analysis/settings`), tree row is a pick target, Inspection shows the analysis settings. | `the_analysis_row_selection_shows_the_analysis_settings_2d` |
| 5 | Session lifecycle (`reconcile` and close of the mounted state after `LoadDocument`) owns the re-solve and the `runtime close cleanup faulted` fault; that is the job-settlement code reserved for the other agent. | not changed here | n/a |
| 6 | 2D tree rows use `circle-dot`, `minus`, `square`, `triangle`, `list`, `link`, `layers`, `beam`, `settings-2`, all present in the generated icon registry. The 2D action manifest used two unregistered ids (`mouse-pointer-click`, `timer`). | replaced by `mouse-pointer` and `clock`. | registry check by grep (no runtime law). |
