Root cause: the 2D flags lived in a `thread_local` map keyed by window id outside every versioned store, so a toggle changed the options rail (read from the same map) but nothing the body render depends on. 3D keeps them in the model window config (`Fem3dModelWindowConfig.gumball`), which re-renders the pane, survives refresh and is per pane.
Port (2D twin of 3D):
- `🕹️interaction/🧭️gumball`: `Fem2dGumballConfig` is a record value (DslRecord, ToValue, CanonicalJsonTree, NativeReceive ...) with `set_flag` (unknown flag refused); the `thread_local` store, `set_gumball_flag` and `gumball_config_for_window` are gone; `fem2d_gumball_meta_layer(doc, ids, utility, &config)`. Cargo deps added (dsl-record, dsl-record-derive, value-derive).
- Model window config (`🎭️modes/✏️edit/🪟️windows/🧱️model/🎚️config`): `gumball` in struct, patch, apply, inverse, exchange, default, `captured()`; neutral schema `🔣️.json`, `🟦️.ts` (`parseFem2dGumballConfig`), fixture `document-contract` (valid gumball, three invalid kinds, one patch op), Rust and TS contract laws extended.
- `🎮️commands/🧭️gumball` `set_transform_gumball_flag::handle_window(payload, cfg, view)`: addressed MODEL window only (results window refused, `fem.gumball-flag.window-kind`), publishes a window-config mutation; route contract lane `HostOnly` -> `WindowConfig`; retained and play-app call sites pass `cfg`.
- Options rail `🛠️options/🔄️transform` and `🛠️window-measures` read the captured config; `window_measures` offers it for the model window only; icon `expand` -> `maximize-2` (the unregistered-icon fallback fixed in 3D).
- The model body renders its own config; the results window no longer draws a gumball (3D parity: results has none).
Laws, all PASS: interaction `gumball_meta_config_follows_the_window_flags`; options `gumball_flag_toggle_follows_the_config_it_is_read_from`, `every_transform_toggle_icon_is_registered_2d`, group tag; model body `the_model_body_draws_the_gumball_its_window_config_describes`; commands `gumball_flags_are_model_window_config` (model ok; results, unknown flag and no window refused; wire dispatch).
