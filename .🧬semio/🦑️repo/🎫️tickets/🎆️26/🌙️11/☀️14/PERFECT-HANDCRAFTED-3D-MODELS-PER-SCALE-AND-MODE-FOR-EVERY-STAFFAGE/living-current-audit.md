## GLB storage measurements

All three passed product geometry, scene complexity and independent glTF validation. Each exceeded the serialized file-size limit.

Apple has 1,275,752 JSON bytes and 14,692,932 BIN bytes. All 2,001 accessors have their own tightly packed buffer view. Its 784 distinct POSITION views take 6,126,936 bytes for 510,578 rows, of which 430,050 are bit-distinct. Its 414 NORMAL views take 5,188,068 bytes for 432,339 rows, of which 337,907 are bit-distinct. Triangle indices take 3,218,004 bytes across 350 views; line indices take 159,924 bytes across 453. Neither interleaved vertex padding nor serialized colors, skin weights or joints account for the excess. Independently deflating each view at the fast setting would occupy 4,934,123 bytes for positions and 4,026,099 for normals, with no savings on the already compact 16-bit indices. Date-palm has 2,497,868 JSON bytes, 9,489,396 position bytes, 5,736,864 normal bytes, 1,735,212 triangle-index bytes and 516,376 edge-index bytes. The byte measurements and exact row comparisons come from [living-payload.ts](living-payload.ts).
