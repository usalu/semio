# Schema API for the authoring tool (stable; written by the schema agent)

`S` = `🎓️teaching/🏛️architecture/🧍️staffage`. Module: `S/🔨️modules/🗂️catalog/🧊️volumes/🟦️.ts` (also re-exported from `S/📦️packages/🟦️typescript/🟦️.ts`).

```ts
import { checkVolumes, measureVolumes, VOLUME_RULES, VOLUME_LIMITS } from "S/🔨️modules/🗂️catalog/🧊️volumes/🟦️.ts";

type VolumeRule =
  | "volumes-availability" | "volumes-silhouette" | "volumes-bounds" | "volumes-feature" | "volumes-monotonic"
  | "volumes-cross-scale" | "volumes-thermal-coverage" | "volumes-structure-coverage" | "volumes-bones" | "volumes-solids"
  | "volumes-copied";

type VolumeOptions = {
  readonly scale?: 50 | 100 | 200 | 500;          // only this scale (monotonic/cross-scale: the pair ending at it); default all authored scales
  readonly rules?: readonly VolumeRule[];          // default: all of VOLUME_RULES
  readonly profile?: PrintProfile;                  // smallest feature = profile.minFeatureMm * denominator / 1000 (default office-laser, 0.15 mm)
  readonly pose?: Slug;                             // default asset.presentation.defaultPose
};

type VolumeMeasurement = {
  readonly rule: VolumeRule;
  readonly scale?: ScaleDenominator;                // absent for rules over the whole asset
  readonly list?: "body" | "thermal" | "structure";
  readonly name: string;                            // e.g. "iou:elevation", "hausdorffM:plan", "bbox:widthM", "areaRatio:<region>", "triangles"
  readonly value: number;
  readonly limit: number;                           // threshold of the design; value must be >= limit for "min" kinds, <= limit for "max" kinds
  readonly bound: "min" | "max";
  readonly ok: boolean;
};

type VolumeFinding = Issue & {                      // Issue = { path, code, message: {en,de}, data? }
  readonly rule: VolumeRule;
  readonly scale?: ScaleDenominator;
  readonly list?: "body" | "thermal" | "structure";
  readonly measurements: readonly VolumeMeasurement[];   // the failing measurement(s) of the finding; code === rule or `volume-*` for per-solid rules
};

// Findings only (empty = valid). Expensive rules honour operation.signal and call operation.progress(done, total, {en,de}).
checkVolumes(asset: Asset, options?: VolumeOptions, operation?: JobControl): readonly VolumeFinding[];
// Every measurement, passing or not, so authors see the distance to each limit.
measureVolumes(asset: Asset, options?: VolumeOptions, operation?: JobControl): readonly VolumeMeasurement[];
```

Notes

- `Asset.volumes` is `{ "50"|"100"|"200"|"500": ScaleVolume }`; `ScaleVolume = AuthoredVolume | UnavailableVolume` (types in `S/🧬️schema/🟦️.ts`: `Volumes`, `ScaleVolume`, `AuthoredVolume`, `UnavailableVolume`, `VolumeSolid`, `ThermalSolid`, `StructuralSolid`, `VolumeSolidList`). Source of authoring `{ "volumes": Volumes }` validates against `#/$defs/Volumes`.
- `validateAsset` already reports the cheap rules (availability, bones/ids/`of`, per-list solid rules, thermal region and layer names, member bones) as `Issue`s; `checkVolumes` is the superset including geometry.
- `volumes-silhouette` uses the support raster `S/🧪️tests/🧰️support/🌓️silhouette/🟦️.ts` (now a re-export of `S/🔨️modules/🗂️catalog/🧊️volumes/🌓️silhouette/🟦️.ts`): `measureAsset(asset, scale, pose?)` gains `hausdorffM` per view and takes the body of `volumes[scale]`.
- Solid helpers: `solidsOf(volume: AuthoredVolume, list)` resolves `{ of }` references into full solids; `expandedCount(solids)`.

`volumes-copied` (3D twin of `representation-copied`, analytic, also run by `validateAsset`)

- For every authored scale and each list (`body`, `structure`, `thermal`) the real solids (`{ of }` references excluded) are compared with the same list of every finer authored scale by `compareSolidLists(coarse, fine, coarseDenominator, fineDenominator) -> { kind: "identical" | "subset" | "scaled" | "distinct", sharedSolids, coarseSolids, fineSolids, factor? }` (exported from the module). Signature of a solid = kind, bone, material, role, tone, weights, transform, repeat and geometry with lengths rounded to 0.1 mm; `id`, `region`, `layer`, `member`, `part`, `tags` are ignored. `identical` = same multiset; `subset` = every coarse solid occurs in the finer list; `scaled` = equal after multiplying every length by one factor (denominator ratio either way, or the ratio of the drawn reaches).
- A finding has `rule`/`code` `volumes-copied`, `scale` (the coarser), `list`, `path` `volumes.<scale>.<list>`, bilingual message and `data: { finer, kind, factor? }`; its measurement is `sharedFraction:<finer>` (0 when distinct, 1 otherwise; max 0). A list with no real solids is not judged.
- `analyticRules` and `validateAsset` report it; mirror it in the authoring tool by calling `checkVolumes(asset, { rules: ["volumes-copied"] })`.
