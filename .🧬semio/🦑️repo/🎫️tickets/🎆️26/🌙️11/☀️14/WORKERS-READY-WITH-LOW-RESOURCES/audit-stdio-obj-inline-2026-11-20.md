## Shared layer verdict contention

The shared verdict file holds a one-byte result or an empty in-progress claim. The previous wait treated every exclusive-create error as contention, including access failures, and kept polling when a cancelled holder released its claim. A timed-out reader could also write the verdict without owning that file.

The reader now waits only on an existing empty regular file. If its claimant releases the path, the reader attempts exclusive acquisition again. Malformed records and unavailable storage go straight to a private check. The bounded wait observes the Original signal, and a timeout finishes privately. Publication uses the descriptor owned by the claimant. On rejection, it removes the path only when the same identity still names an empty file. A waiter with a cancelled phase cannot return or seed the completed in-memory verdict.
