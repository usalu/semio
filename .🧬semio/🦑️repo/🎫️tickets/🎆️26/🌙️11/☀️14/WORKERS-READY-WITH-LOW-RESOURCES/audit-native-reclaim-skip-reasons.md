# Native Reclaim Skip Reasons

The 19:41 nonwaiting Rust reclaim completed with an older reasonless `skipped` receipt. It recorded zero measurements and did not identify which eligibility or operation check stopped it. Active image holders overlapped the operation, which did not establish the precise cause. This implementation makes future skip receipts carry the branch the native owner observed.

The closed `ImageReclaimReceipt` schema now requires a declared reason on a skipped outcome, with zero measured bytes and `settled:false`. A completed reclaim has measurements and carries no skip reason. The owner distinguishes a pending retirement, routine ineligibility, automatic backing and mount checks, unmeasurable occupancy, request device mismatch, unconfirmed live pressure, insufficient slack, a typed nonwaiting lease timeout, an unclassified lease failure, a failed native cycle, and a failed lease release. An exclusive lease timeout reports the timeout only. It does not identify a holder. Inspection errors and unavailable platform support have their own evidence.

The automatic reader verifies the exact partition and the closed receipt before carrying a reason into the existing bilingual report. An anonymous skip, unknown reason, or reason attached to a completed cycle is unconfirmed and supplies no safe fallback evidence. A valid typed skip and a settled zero-gain cycle follow their existing fallback behavior. The collector still rereads physical volume space and does not credit a skipped operation.

The nonwaiting owner still asks for a single exclusive image lease with zero timeout and keeps the same validation and pressure predicates. Normal reclaim uses the partition bloat rule. The routine tests exercise success with 50 GiB free when slack covers the full floor, refusal with less than that floor above the same threshold, and success with the reduced floor below it. The separately authored waiting Rust route and its pressure threshold are unchanged.

The native fixture injects a typed lease timeout, generic lease failure, cancellation, changed volume, pressure or slack, missing occupancy, pending retirement, native cycle failure, and lease release failure. An independent SQLite expression reproduces eligibility, and an independent Python reader reproduces receipt acceptance and skip-reason propagation. The fixture verifies exact nonwaiting timeout, release counts, automatic fallback boundaries and both report languages. The native maintenance routing, wait-Rust, receipt, disk recovery and image collector batch passed 49 tests with 940 assertions. A separate native test passed with 23 assertions and reclaimed only a private synthetic APFS image while preserving its identity and cache content. The 19:41 receipt has no newly attributable reason, and this work started no live image reclaim.
