# Array-backed graph claim work

The isolated claim-law fixture reproduced 1,441,560 Set insertions for 120 owner arrays, each with 12,000 shared rows and six owner rows. Its bound is 50,880 insertions. The independent Python shape oracle passed the baseline. The failing production lines matched the checkout's committed baseline, `3d62b2ef22c`.

Each array held the same shared row objects in a distinct list. The original array claim pass traversed each base to subtract rows already held by the owner, then traversed it again to mark claimed keys. Row keys were already memoized by object identity. The repeated calls were number-of-owners copies of the base traversal and Set registration, even when each shared key was already marked.

The array path now seeds unclaimed keys from the authoritative capture while sorting its path index. A path match claims its captured key because the owner either holds it or receives it in the appended ordered rows. The base traversal handles environment membership and candidate deduplication together. It returns the original base object when no additions are needed. Existing base order and duplicates, first captured occurrence for new keys, environment row order, and streamed processing retain their existing rules.

The actual shaping fixture counted 4,322,160 owner-row visits before the change, including the final array copy. The updated code passes the 2,881,440-visit bound and the existing insertion bound. A direct comparison of the exact isolated array claim functions from the baseline and current source measured 1,441,440 versus 13,440 Set insertions and 2,881,440 versus 1,440,720 base-row visits. Both returned the unchanged base arrays by identity. Two sets of seven measured trials in alternating order after a warmup gave median claim wall times of 168 and 153 ms before, then 107 and 75 ms after on this host. The private synthetic fixture measures the array route. The retained benchmark takes the repository-relative generation load module and claim fixture paths in that order.

The normal repository entry passed all 104 shape-law and loader tests with 364 assertions. The streamed-shape and row-log suites passed 10 tests and 579 assertions, including direct array-versus-streamed output equality. The permanent shape-law test checks 60 independent Python corpora, the bounded insertion count, and visits over the owner arrays.
