# Read-only stage certification

The deployed diagnostic recorded repeated native index-signature movement across the reporting workers, including 43 events on m02 and 82 on m08 in the initial 12:44 sample. The diagnostic identifies an unavailable observation and may record an exact tree after recovery. It does not identify the process that moved the index.

The old observer invoked Git tree construction against the live index. The preceding native fixture showed that this rewrote the cache-tree extension even while the logical staged tree stayed the same. The new fixture also reproduced that an otherwise idle follower could replace the live index inode when it verified an already matching stage. Both are avoidable sources of index signature movement.

The observer now constructs its native tree from a private copy on a cache miss. It still compares the original index signature and ref stamp, and no longer reports a tree if either moves. The unchanged cached path remains available. An unborn repository can certify the empty stage from a private index. An unresolved committed tip or missing committed index cannot imply an exact empty index. A settled follower also uses private certification and defers repair if the observed index signature changed while it read.

The scoped regression failed for full, split and sparse index layouts before the change. The settled follower previously changed the original inode and both timestamps. After the change the native fixture compares live index bytes, inode, timestamps, and tree with independent Git commands for each layout. It also verifies missing objects under a writer lock and a real staged edit that interrupts certification. Eight focused native tests passed with 47 assertions. Native Git still manages the tree objects in the repository's existing object database. These changes avoid live index writes during observation and do not change the archiving or stage application authority.

The full physical fleet rollout is separate from the private regressions. No live process was restarted or current index changed by the verification.
