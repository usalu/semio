## Changes to the normal propagation path

The author now polls the Git index signature on its existing hot interval independently of the ordinary hot-set scan. For a representable incremental stage, the author publishes the exact staged worktree paths and any required loose Git objects before the index registers. A real private regression showed the old targeted pass publish unrelated worktree bytes before the register and miss the new object altogether. The fast pass uses the existing publication port, reports that work in the ordinary counters, and preserves normal full-stage fallback for a new base, explicit rebase, and unresolved object custody.

Followers fold consecutive bounded journal spans against one head snapshot before materialising the queue. A queued ignore-file update ends that intake pass so the next pass can observe the updated rules. The test feeds 1,025 valid linked events across two real journal spans, with the same path mutating between spans. The old follower applied two filesystem states and the new follower materialises only the final one. Object and staged worktree prerequisites apply before the stage. Unrelated worktree payload and safe object retirements follow. The normal Git object, index-lock and local-stage backup gates still apply.

Stage register operations now use IDs already interned for this realm. The controlled native case visited seven IDs in place of 1,552 ordinary and stage paths and produced the same output. Incremental receive also avoids refreshing stat metadata for the entire index. Real Git status and diff continue to test the changed paths. The stat-cache-sensitive `git diff-files` plumbing can emit a transient dirty result until a refresh, and the checked repository has no caller of that plumbing. Detached or whole-base recovery retains its established path. The pack rescue turn skips index table reads when no local pack needs rescue.

The normal full worktree scan already records a refused directory. The observer now records the refusal without traversing that directory or changing its shared-path policy. The test waits for both independently produced refusals.
