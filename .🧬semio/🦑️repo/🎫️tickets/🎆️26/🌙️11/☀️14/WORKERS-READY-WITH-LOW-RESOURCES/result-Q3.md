## What was built

1. **Rule (schema first, `U/✅️complete/🧬️schema/🔣️.json`)**: the names a command line promises: `<crate><extra>.d` for dep-info, `lib<crate><extra>.rmeta` for metadata, `lib<crate><extra>.rlib` for lib/rlib, the proc-macro dynamic library per platform, the executable of a host binary (test harness included); nothing for a single `-o` output. Everything else the compiler writes is covered by its own announcements (`announcedPathsV1`, the former `artifactsOf`).
2. **A hit is complete or it is a miss**: `lookupUnitV1` skips variants lacking a promised name (an older complete variant behind a newer incomplete one is served); after `restoreUnitV1` the wrapper checks promised names plus every announced path in the replayed messages exist, otherwise event `incomplete` and the unit is compiled; `installFleetUnitV1` answers `miss` for a manifest lacking a promised name; `publishUnitV1` refuses to store an incomplete unit (event `publish-skip` reason `incomplete: <names>`), so the fleet is never fed one; an offload `done` with status 0 is checked the same way and, if incomplete, falls back to a local compile (event `incomplete`, "offload <origin> returned a unit without …").
3. **Restore is atomic**: every output is written aside and renamed over (`placeV1`), no moment with an absent name (before: `rmSync` then copy). A reader polling during repeated restores of a 48 MiB `.rmeta`: **849 606 absent observations in 2 s with the old code, 0 with the new**.
4. **Other artifact kinds**: proc-macro dynamic libraries are in the promised set (entry without the dylib is a miss, tested); build-script RUN output (`OUT_DIR`): restore is atomic and throws, so the script runs, when a recorded file is not in place afterwards; `-L dependency=<dir>`: rustc accepts a missing directory (checked, exit 0), Cargo creates the directories, nothing to restore; the `.semio-unit` identity beside a dynamic library only changes dependants' keys, never presence.
5. **Diagnosis**: a unit whose dependency file is unreadable now logs `bypass unreadable-input: extern <name>` (before: no name); event kind `incomplete` added to the unit-cache event schema.
