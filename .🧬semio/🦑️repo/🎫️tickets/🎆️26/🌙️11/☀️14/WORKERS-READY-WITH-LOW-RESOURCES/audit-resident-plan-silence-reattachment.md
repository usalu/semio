## Reproduction and change

A private resident service starts a plan and records its slice progress, then stays quiet until the client retries. With the original client, the silence callback destroys its connection before starting another. The resident service immediately cancels a job with no subscriber. The second connection starts the same planner again. The fixture reproduced two starts and one abort for one successful user request. The independent SQLite oracle counts planner lifecycle events from the neutral fixture.

A retry now uses the original request snapshot. After matching job progress on a connection to the same endpoint, silence retains that transport for up to one existing silence interval while the new request connects. Entry into the service job follows its existing scope, inputs and index key. Matching job progress from the replacement, caller cancellation, endpoint change, first transport closure, the overlap deadline or retry termination releases the old connection. The old exchange ignores late frames as soon as its silence deadline expires. Each new exchange uses the same silence policy and retry budget. Process exit still closes both sockets and the host applies its existing last-subscriber cancellation rule.

The private resident fixture verified one planner start, zero aborts, one completion and one coalesced retry even when a progress observer mutated the original target array. Private socket fixtures verified caller cancellation, cleanup on unsuccessful retry, and rejection of a late reply sent to the retained transport. The deployment and live workspace outcomes remain unverified. No live process, worker, storage, or readiness configuration was changed by this audit.

The final native Bun run passed 69 tests and 852 assertions across silence, keepalive, cancellation and protocol. The first broad run placed the existing cancellation harness under an absolute ticket path and hit the 96-byte local socket limit. Running from the ticket scratch directory with relative runtime paths passed all of those checks. The cross-platform fixture uses the repository endpoint interface. This run executed on macOS.
