# Protected m04 dependency capture cost

The live g1-m04 second capsule capture reported 66,256 rows at 05:43 UTC with 357,779 weighted operations after 2,668 seconds. Its printed native syscall timings cover the selected descriptor helpers during the sampled interval. They exclude the substantial physical custody callback nested around those helpers. The m04 capture was still running when sampled.

The selected capsule reader invokes its original guard from the capture loop and throughout the descriptor operations. The funded producer's read frame supplies the actual Native physical guard for this capsule path. On a directory partition each physical guard repeats live lease/refinement and ancestry checks, reads the current `image.json` through an exact descriptor, checks the publication namespace, verifies the backing and named root identity, rereads and canonically decodes `fixed.dir`, checks both directory mapping identities, and validates current geometry. The control publication writer is synchronous and the continuation explicitly yields via immediate scheduling. Those waits do not explain the controlled experiment.
