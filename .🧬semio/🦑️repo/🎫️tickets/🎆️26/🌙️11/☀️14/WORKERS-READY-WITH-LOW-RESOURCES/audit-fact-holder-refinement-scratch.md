# Fact Index Holder Scratch During Refinement

Packed fact-index refinement grouped rows by their incoming run IDs, then built each typed owner union by concatenating every holder occurrence into a new Uint32Array. A group with overlapping runs could allocate for all occurrences even when its actual owner set was small. Cold upserts add each owner-row pair once. They can still encounter many groups with multiple runs and previously allocated a fresh temporary union for each. Overlapping holder incidences are chiefly a delta concern.

Refinement now uses the existing dense live owner numbering with one reusable Uint8Array for membership and one Uint32Array for the unique holders. The pair costs five bytes per live owner and is allocated only when a group needs a union. It clears the marks of the owners visited, sorts the occupied span numerically, and preserves the existing collision checks and independent copies when retaining a class. Single-run classes still use their incoming holders. Class ordering, packed encoding, and the existing cancellation boundaries are unchanged. This only bounds the typed owner-union scratch. The reverse row-to-run incidence and output class lists retain their existing costs.

The red native fixture reached 2,135,552 Uint32 slots (8,542,208 bytes) in one union across only 4,096 live owners. It already matched the Python set-union partition. The final fixture uses distinct overlapping runs, duplicate holders, a separate run with an equal owner set, and a row without holders. It still matches Python, and the largest measured Uint32 allocation is at most 4,096 slots. The two reused owner scratch arrays account for 20,480 bytes at that fixture's owner count. The allocation measurement records constructor arguments during the synchronous phase. It is not a process footprint measurement.

The native Bun cohort passed 52 of 53 tests across six files, including cold and warm fact-patch comparison, row logs, chunked encoding, generation publication, and cancellation. The shared-file timing assertion exceeded its threshold in the cohort (5,518 ms versus 5,229.2 ms). It passed on an isolated rerun with all 314 assertions. The strengthened overlap fixture passed its focused rerun. Temporary test artifacts were removed.

The real graph reader and its existing capacity grant were left alone. This work establishes neither a measured lower whole-graph peak nor a reduced reservation. The row-key interner and observation memo lifetime during cold encoding remain a separate candidate for measurement.
