A safe next validation is an isolated deterministic gate test using controlled host samples and an independently advancing or blocked holder: verify a published compatible generation ends the capacity wait without custody and that cancellation removes the request while preserving other holders. Test a bounded low-memory admission scenario with actual production graph reading and measured progress; no live lease, process, or host state should be changed to force the observation. A structural remedy needs a verified smaller bounded rebuild or progressive published-generation reuse; merely weakening the memory gate could exceed the host floor, and lending a planning grant without proving the waiting tree is idle and reclaimable is unsafe.
