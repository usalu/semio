# Verified Closure Repair Evidence

The new generation repair module stages a closed immutable sidecar before the normal invalidation swap. The path binds the next pointer generation to the original manifest digest. Existing readers still see the ordinary null-manifest quarantine. A builder reads the sidecar only for the exact current closure quarantine and requalifies the archived manifest, scan and owner list before receiving its receipt digest. Missing, malformed, global, superseded and incompatible evidence refuses the targeted patch. Equal digests in the source and lock namespaces remain separate references.

The optional verified-closure callback first requires the originally observed typed leaves to occur in the archived owner fragments. Then it probes every exact named reference and records all and only the genuinely absent leaves. A true answer means verified bytes, false means absent, and an unknown answer refuses the repair. The ephemeral recovery for older null pointers uses the same full census with no receipt write. It requires the exact old parent and an unchanged pointer, and refuses an existing runtime receipt. Candidate verification checks every reference, including global ones, before the engine can publish.

The scanner hashes every packed fragment, validates its role and owner identity, and inflates one document at a time. The limits include 8,192 fragments, 16 MiB per expanded fragment, 64 MiB total packed and 256 MiB total expanded fragment bytes, 20,000 distinct typed references and 65,536 links. The final receipt limits missing references to 64 and affected owners to 128. The existing generation file port supplies complete packed blobs before digest and size checks. The scanner does not open paths outside that port.

A private 5,101-fragment fixture completed with RSS sampled at 212,418,560 bytes before the operation and a 300,138,496-byte peak during it. The 87,719,936-byte increase measures the test process, including allocator retention and the in-memory test fixtures, without any native inference or fact-index patch. The SQLite fixture reproduces owner counts and quarantine outcomes independently. The earlier targeted suite passed 5 tests and 44 assertions. The existing closure parser suite passed alongside the initial receipt suite. No live graph data was changed.
