## Verdicts

1. **What was wrong in P5's landing 2.** (a) Its five sibling tests did not hang because of the new design: `declined`, `release`, `farm-close`, `retirement`, `authority` and `captured` were already red on the LIVE tree before P5 (baseline run 20:20: 1, 2, 2, 1 and 3 red). P5 moved the handshake but not the environment, so it saw the same hang and read it as a defect of its pool. (b) Real defects of P5's hub, found by those tests: a pool that is disabled or whose workers cannot start was still counted as "starting", so a project was held 190 s for a pool that would never come (`release`); a pool whose spawn failed left a dead pool that never became ready and never disabled (`hub` test "no worker can start"); `disable` fired synchronously inside `createFarmV1` before `pool.farm` existed; the chain of host requests went on asking after every worker was refused for its identity, so 9 pools were started and refused instead of 1; a request that was released was released a second time when its grant arrived; `retireHub` waited for ever on a request whose `release` does not settle.
