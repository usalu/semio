## Where the schema changes behavior

The graph host combines exact captured source rows with the inference library's rows. The inference protocol replaces declared sources with scoped stamps, retains unclassified data by content, and puts retained data rows into every generated owner and the shared environment. Separately, selected graphs validate an exact module-authority digest that covers the complete loaded source roster. The current direct selected route uses its own source inventory, observation memo, scope authority and publication. Its selected-subgraph oracle only compares the selected projects, edges and external nodes. A selected read's success cannot establish the whole roster, the shared environment or the whole generation's fact index.

The added memo bound and diagnostic text affect bookkeeping or refusal presentation. Some other fields have observable effects. The selected loader's retry bound can terminate the loop and lead to a distinct seal verdict. Its stale-path collection limit participates in repeat detection and the persisted seal evidence. The registry-failure table changes how a farm fault moves through retries and how a worker can leave a project unavailable. The current classifier can propagate a fault and have the registry follower reconcile source before the next complete attempt. Removing the whole policy row from the derivation projection would also remove these behaviors from its authority.

A future schema split can move only fields tested to affect scheduling, memory, progress or diagnostic presentation into their owned runtime schemas. That still preserves the exact loaded-process authority. Result-bearing classification and seal admission should use closed scoped stamps tied to the owning inferrer and observed by its products, especially for native owners, withheld nodes and environment facts. Runtime-only edits would then avoid whole-graph invalidation when the equivalence rules already exist in both producers. The current archive predates that evidence. A new projected digest would give a different implementation identity and must not be compared equal to the old raw digest.

## Evidence still needed for reuse

An archive could serve as an immutable input to a producer with a separate schema for verified owner contributions. A contribution needs authorization from the exact old manifest and document digest, plus a current proof of its source observation closure, scoped derivation semantics, and validity under the current roster and environment. Output-affecting changes require current inference of their affected owners and dependents unless exact equivalence is proved. Unknown coverage, ambiguous refusals and incomplete results need conservative reconstruction. All membership, shared environment, withholding, edge, global and closure facts then need to pass the normal current qualification. The original pointer remains quarantined until a writer publishes a fully verified replacement with the current implementation digest. An authenticated complete-head consumer continues to require exact identity and implementation equality.

A useful neutral regression must independently compare the complete owner and unavailable roster, fragment and edge content, shared facts and complete closure index with ordinary current inference over the same frozen source. Cases must cover an exact positive reuse proof, altered source observations, registry faults that become withheld in one producer, incomplete roster evidence, incorrect old or current digest, missing closures, cancellation and a changed pointer. A private replay can establish semantics. A physical acceptance run must also measure the complete native process-tree peak of discovery, qualification, fact verification, patching and publication under the issued grant and show a compatible peer adopting the resulting head.

The existing targeted route requests the same 14,336 MiB pre-custody reservation as the whole rebuild. Even a valid compatibility proof alone could not advance the current physical wait. A separately admitted producer with a lower measured native envelope would require the same end-to-end proof.
