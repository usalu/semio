# Source Closure Collection Custody

## Reproduced

- An aged source inventory survived neither host age eviction nor partition pressure once the graph process pin was absent. In a private workspace fixture the old CAS collector selected three files. Two were legitimate victims, a host CAS object and an unrelated graph memo. The third was a loose source inventory. Preview and apply now select two. The source inventory contributes 2 MiB to both total and protected bytes even with a custom CAS age and area cap. The follow-up scan has no candidates, preserves its overage, and gives the graph reclaim command in English and German.
- A graph inventory sweep could take the canonical writer lease after the first generation directory appeared and still use its earlier group list. A private fixture reproduced the deletion of an aged inventory that a fragment in that new generation directory named. The sweep now takes the canonical writer lease even before a directory exists, compares the census group list under the cut, and declines that batch when the list differs. A second stable sweep takes the unrelated inventory and leaves the source inventory the fragment names.

## Ownership and dispatch

- The host-wide age, area and partition cuts account for every source inventory in the registered workspace source area. Graph custody owns deletion. Protection is independent of PID, lease files, pointers and manifests. Host collection still evicts eligible exact host objects and loose memo files. The host collector reports a shortfall even when its plan has zero candidates.
- Default `repo cache gc` delegates the graph-inference area to its issued-resource owner before host CAS. The explicit `repo cache gc --area=graph-inference` route and pressure-triggered background launch reach the same graph reclaim. The explicit route resolves the platform backend's backing filename. The background mounted-space probe recognizes attached native directory partitions and distinct-device images.
- The graph reclaim takes the existing graph collector lease, gives cheap scoped recovery the first opportunity, then invokes the inventory census if pressure remains. The graph census holds the `repository-graph-facts` resource used by generation publication and the observed namespace writer resources for each removal batch. It recomputes references under that cut and checks the inventory's original stamp before unlinking. The new cut check also handles a newly observed namespace and honors cancellation after the proof scan. This retains the current generation and older referenced fragments without a graph load or manifest promotion in CAS.
