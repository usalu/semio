# Mesh Attribute and Rich IO Fidelity

## Canonical Ownership

The existing PolygonMesh schema declares vertex, corner, face and directed edge attributes, owned materials, and owned texture bytes. `MeshAttribute` lives once in the existing lower mesh-engine module, with optional `indices`. Its values remain owned once; effective domain cardinality is indices length when present, otherwise values length. Every reference must address a value, with 600000 samples/references maximum. Corner domains use polygon boundary order; edge domains use directed serialized halfedge ids. Flipped serialization composes separate corner and edge mappings.

The existing Brep `PolygonData` source was moved into the same lower owner as `PolygonMeshSource`; it was replaced rather than retained as a second representation. `parse_polygon_mesh_source` is the shared pure parser used by inference and the structured inspector. It checks exact fields, 16 MB text, finite f32 coordinates, bounded vertices/faces/corners, distinct in-range face indices, channel cardinality/semantics/interpolation, materials and texture ownership. Brep alone reconstructs HalfedgeMesh after parsing. Kernel setters delegate the same pure channel and asset validators. First-party ToValue/FromValue and encode preserve the source fields; no kernel dependency is introduced into the artifact command facet.

Known PBR fields validate baseColor4, metallic/roughness/alphaCutoff in 0..1, finite nonnegative emissive3, alphaMode and doubleSided. Custom owned material fields remain allowed; any field ending Texture must reference owned bytes. Names are limited to 128 Unicode scalar characters. Aggregate texture bytes are limited to 16 MB.

`HalfedgeMesh`, `MeshTransfer` and `MeshData` retain these same first-party channel records. Retained mesh JSON and preview field13 share `MeshMetadataCursor` within the existing mesh/output owners. Each generic node, Unicode character, index or texture byte is appended in a budgeted transition. Indexed custom data is never cloned per domain use. The existing mesh-record codec keeps its numeric fields and appends owned metadata, bounded by 16 MB and the overall preview limit.

## Transforms and Topology

Whole and component transforms use existing Work::Transform. Authored normal channels use inverse transpose and normalization. Indexed sample aliases split by source sample and affected domain; unselected groups keep authored values. Corner UV seams and multiple UV channels remain separate. Peer retained component selection, centroid, proportional/grid policies and memo retirement stay in this same owner.

Kernel tessellation samples authored normal/UV/color channels and expands vertex/corner references onto preview vertices, face references onto triangle face ids, and edge references onto the preview edge roster. It retains complete polygon channels in mesh JSON. Preview edge UV endpoints come from authored corner UVs; seam flags include explicit raw halfedge seams and discontinuous paired corner UVs. Interchange export must report channels its format cannot represent.

Common SourceAttributeRemap now finalizes Orient, Mirror, Subdivide, Knife, LoopCut and Triangulate through existing retained jobs. SourceVertex carries original, edge, face and weighted contributors. Nearest chooses the greatest weight with lowest source-domain id ties and retains arbitrary owned values by reference. Constant requires equal source values and returns a recoverable conflict. Linear requires compatible finite numeric dimensions; new normals normalize. Generated boundary edges inherit source edges; interior edges use start-corner weights in the declared source face. Original numeric values and sample memos retire one item per unit.

Inset and Extrude now retain original source vertex references for displaced vertices and source faces for top/border faces. Their corner channels follow original vertex identity in that source face. Vertical/interior directed edges use the source start corner; boundary edges inherit the source edge. The portable expandedAttributeJobs fixture states this rule and checks independent area plus cancellation.

FillHoles runs in the existing retained job and passed the current native suite: cap corners inherit the boundary use beginning at that vertex, reversed edge channels inherit the preceding boundary edge, and each boundary edge contributes one equal source-face weight. Linear face channels average; nearest ties choose the lowest face; constant conflicts refuse. Original samples remain indexed; generated numeric face samples append one per unit and indices finalize incrementally. Explicit seams follow cap and reconstructed source edges. Public orient/fill/extrude/inset methods drain the existing retained jobs, including accurate orientation/cap counts.
