# Retained Mesh Output Work

## Implementation

The existing flow `MeshOperatorJob` now retains mesh output through JSON vertex emission, boundary-corner traversal, polygon-index JSON emission, tessellation, preview edge-identity remapping, mesh-pack encoding and base64 encoding. It no longer reconstructs the entire halfedge mesh from polygon JSON for preview. The output retains its original kernel source until completion, including existing smooth normals and corner UVs in preview. All mesh-producing operators create this output job through their existing `step_plan`; bevel, decimation, mirror, vertex merging and subdivision continue their existing retained modeling job before handing ownership to these output stages.

Tessellation resides in the existing kernel mesh Export region. One unit traverses a corner, evaluates one Newell/projection/normalization/area contribution, checks one ear containment candidate, emits one triangle or emits one edge. Linked boundary cursors replace unbounded polygon-list removal. The shared flow mesh codec owns retained numeric mesh-pack emission of at most 1024 bytes per unit. Base64 emission advances at most 3072 input bytes per unit. Zero-budget stepping preserves work. Cancellation freezes operator progress and drops owned work during any output phase. Completion transfers the result once.

Admission limits reject empty geometry, more than 100000 vertices, more than 100000 faces or more than 600000 corners. Incremental JSON rejects more than 16000000 bytes; preview-buffer growth and pack admission reject more than 64000000 bytes. The numeric retained codec explicitly refuses paint textures instead of discarding them; current mesh output has no authored paint-texture field. Existing polygon contract and forthcoming authored attribute fidelity remain owned by the attribute lane.

Work budgets bound geometry/encoding units, not allocator wall time. Source capture, Rust vector growth and cleanup still use ordinary allocation behavior. Other mesh mutations and input decoding still execute synchronously before the retained output job is created. Whole final output dictionary/envelope serialization belongs to the existing graph/inference transport owner.

Mirroring, vertex merging and face subdivision now extend the existing kernel `MeshModelingJob::Work` owner and share its existing `Snapshot`/`Build` cursors. Their synchronous APIs delegate the same jobs. Mirroring visits side checks, reflection coordinates, paired polygon corners and reconstruction. Merging visits selection identities, distance pairs, one union-root link, remapped polygon corners and reconstruction. Face subdivision visits selection/convexity checks, uses the same retained tessellator for selected concave faces, emits centroid fans and reconstructs. Each has cancellation fixtures that advance actual work in every authored phase before cancelling. Selected-face tessellation stays in the existing mesh Export owner. These operations retain the same polygon topology behavior; authored attribute remapping remains the attribute lane's responsibility.

The reflected-preview regression test exposed a required identity transformation: logically reversed source faces serialize a different halfedge order. JSON emission now records each source halfedge's serialized identity per corner, and preview emission applies that mapping one edge per unit. This preserves preview selection compatibility with its own serialized result while retaining source preview channels.
