Read-only inspection on 2026-09-29. No tests or runtime were executed; findings below distinguish source defects from validation gaps. Read root, s, and procedural AGENTS.md. Ticket supplied by coordinator.

## Scope Paths

`P` below means `✏️s/🔌️plugins/🌀️procedural/🗿️artifacts/🧊️generation3d/🏅️standards/🔖️1/🪆️subsets/✳️any`.

## Concrete Defects

1. **Catalogue activation loses export format/action descriptor.** `P/✏️editor/📌️panels/🛍️catalogue/🦀️.rs` builds drag JSON containing kind, neuronKind, format, and action, but click action contains only `kind`; neuron operators use an encoded `neuron|operator` string. `P/✏️editor/🎮️commands/🧩️add-widget/🦀️.rs` accepts only kind/x/y and can never reconstruct the selected export format or action. This means keyboard/click activation cannot create the same widget as dragging the same catalogue row. Fix schema-first typed descriptor fields and shared descriptor construction. Generation2d already has typed neuron_kind/format/action fields in its counterpart command, offering an adjacent consistency reference.
2. **Add failure is swallowed.** The same add-widget handler maps `host.add_widget` failure to `Ok(Emit::default())`. Invalid/unsupported descriptor creation appears successful without a document change or fault. Surface the real error and verify no mutation is emitted on rejection.
3. **All clicked widgets share default graph position.** Add-widget defaults x/y to 120/120; repeated catalogue activation overlays nodes. Source confirms the collision policy; runtime visibility remains unverified. Use a deterministic layout placement policy rather than forcing users to drag each new node away before adding another.

## Existing UX Infrastructure

- App orchestration: `P/✏️editor/🦀️.rs`. Preview is a retained instance/session workflow with addressed transient window owners, publication, tick/eval/tessellate routes, cancellation release, supersession and rearm. It should be preserved and extended rather than replaced with standalone synchronous evaluation.
- Edit graph and preview: `P/✏️editor/🎭️modes/✏️edit/🪟️windows/{🕸️flow,👁️preview}/🦀️.rs`.
- Generate roster, form, preview: `P/✏️editor/🎭️modes/🧬️generate/🪟️windows/{🗂️generations,📝️form,👁️preview}/🦀️.rs`. Form derives its spec from graph and renders selected generation values; absent selection gives localized hint. Form definition has no window actions, so updateGenerationValues must be verified against app-wide action dispatch in a real host.
- Inspector and artifact keyboard representation: `P/✏️editor/📌️panels/{🔍️inspection,🗿️artifact}/🦀️.rs`.
- Catalogue is virtualized by TreeWindows, first group expanded and remaining groups lazily populated. Preserve row identity and viewport behavior when fixing activation.
- `P/✏️editor/🗣️terminology/🦀️.rs` declares English/German labels, including graph screen-reader alternative guidance, preview instructions, and evaluation status text. Translation and accessibility are present at contract level; accessible host runtime behavior is not proven here.
