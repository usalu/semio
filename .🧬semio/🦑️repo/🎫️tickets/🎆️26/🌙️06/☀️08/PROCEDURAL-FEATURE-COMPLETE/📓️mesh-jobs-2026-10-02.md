# Retained Mesh Modeling Jobs

## Kernel Contract

The existing `MeshModelingJob`, `MeshModelingProgress`, and `MeshModelingStep` APIs are present and compile. `HalfedgeMesh::bevel_job` and `HalfedgeMesh::decimate_job` own a source snapshot. `step(budget)` retains intermediate geometry and advances up to the requested number of units. `step(0)` preserves all work and progress. Cancellation freezes progress and never changes the caller's mesh. Completion transfers geometry exactly once, then retires the job. Synchronous bevel and decimation delegate to these same jobs.

Bevel performs actual vertex copying, polygon-corner traversal and normals, face/vertex convexity validation, edge closure checks, neighboring-face clearance sampling, profile-plane generation, polygon clipping, cap ordering, compacted halfedge reconstruction, normal generation and twin validation in retained stages. Decimation performs actual shortest-edge enumeration, candidate midpoint copying, polygon remapping, normals and winding checks, oriented incidence validation, closed vertex-link traversal and reconstruction. Candidate failures resume the next ranked edge; accepted collapses continue toward the target.

Work units bound geometry advancement rather than elapsed wall-clock time. Snapshot construction clones the source once, and allocation/collection cleanup still follows Rust's ordinary allocation behavior. Bevel continues to require an outward convex closed manifold. Decimation may finish above the requested vertex count when no valid collapse remains.

## Verification Changes

Portable job fixtures now define source vertex/face/corner counts, generated bevel-plane counts, candidate vertex counts and the number of units performed before phase cancellation. Cancellation tests advance inside each retained phase before cancelling. A new internal law checks actual retained state after one-unit steps: snapshot size, generated planes, completed clipping planes, collapse midpoint geometry and halfedge growth. It compares final volume with the existing test-only Parry3D implementation.
