## Ownership And Contracts

- `🧰️framework/🔨️modules/🧊️3d/📐️brep/💡️queries/🧩tessellation/🦀️.rs:183–215` owns its deduplication `BTreeSet<VertexId>` and transfer. `:376–384` emits each topology endpoint once with full persistent label and an independent point group. `detach_retirement` transfers the set through a one-pop frontier (`:204–214`), and `🧰️framework/🔨️modules/🧊️3d/📐️brep/⚙️engine/🧹️retirement/🦀️.rs:106–110` retires point POD and each group label through metadata frontier. These new payloads have an explicit retirement path.
- Direct `TessellationJob::cancel` (`:301–309`) clears cache and replaces transfer synchronously, retains vertices/edge_order/faces, and therefore does not satisfy its docstring claim that every partial buffer is dropped. This is distinct from ownership-detachment cancellation; avoid using direct cancel on the interactive bounded-retirement path. Per-unit work remains a whole edge/whole face (`:175–181`), not a bounded number of samples/corners.
- Native conversion validates full group coverage and labels (`brep/⚙️engine/🦀️.rs:563–590`) then marks all tessellated surface positions absent with `u32::MAX`; original points have dense group IDs. `🧰️framework/🔨️modules/🏗️mesh-engine/🦀️.rs:550–551` explicitly accepts only this vertex absence sentinel beyond label cardinality.
- TypeScript mirrors appended points and sentinel prefix (`🧰️framework/🔨️modules/🧊️3d/🟦️.ts:281–309`), but label validation differs: native bounds labels to 128 characters; TS checks only nonempty `entityId`, and its standalone renderability validator (`:256–269`) does not validate vertex groups. Unify fixture validation for malformed groups and labels; do not claim parity from happy-path output alone.
- React `geometryFromMesh` expands only draw samples (`World3dHost/🟦️.tsx:2143–2174`), while `buildVertexPickData` reads original MeshData positions. This separation preserves original point tails once sentinel filtering is fixed. `surfaceSample` (`:2118–2125`) indexes authored attributes and rejects invalid sample references; its sample index is unrelated to topology absence IDs. Keep the two contracts distinct.
