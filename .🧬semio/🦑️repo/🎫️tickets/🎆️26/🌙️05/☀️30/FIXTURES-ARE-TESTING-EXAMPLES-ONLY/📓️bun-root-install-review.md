# Root Native Install Timing Review

Retained standalone probe genuinely completed two packages in9.03s. Its argv is ordinary installed Bun1.3.14 install --ignore-scripts, cwd the nested ticket generated root, both streams drained concurrently. No timeout change or fake result. Current helper likewise drains stdout/stderr concurrently, so pipe backpressure is not the established explanation. Root bunfig only declares hoisted linker; no repository install hook or preload is present there.

All probes are nested physically inside the large real workspace. Product fixtures have additional package ancestors whereas root fixture does not; ancestor workspace discovery/config loading is a plausible explanation for root-specific cost, but current log does not identify traversal, function or syscall. Official [workspace documentation](https://bun.sh/docs/pm/workspaces) confirms installation resolves all workspace members; [configuration documentation](https://bun.sh/docs/runtime/bunfig) confirms local/global package-manager config loading. Neither establishes this9s cause. Current docs version is newer than installed1.3.14, so no undocumented optimization flag is justified.

Smallest honest diagnostic is an original test input/config boundary explicitly choosing a standalone install root without a real workspace ancestor, while retaining all temporary output under the ticket through a caller-owned filesystem location/lease allowed by repository policy. If that policy forbids an external root, do not silently move fixtures or infer isolation. Alternatively investigate installed Bun source/workspace-root discovery before any flag change. --filter could change tested root membership and should not replace complete root install proof; existing root no-dependencies fixture still tests real workspace expansion. No timeout waiver, warm-cache fake or dropping root cases.

A5000ms test rejection can leave the native child running. This does not justify changing test budget or terminating foreign jobs. No install/test/process intervention was performed in this audit.
