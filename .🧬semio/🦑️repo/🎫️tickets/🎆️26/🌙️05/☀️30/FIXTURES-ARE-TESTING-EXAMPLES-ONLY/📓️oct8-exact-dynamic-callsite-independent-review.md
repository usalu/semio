# Exact Dynamic Callsite Review

Independently reviewed current RuntimeDynamicImportOwnerV1 schema and source. The schema requires caller source SHA and nonnegative integer callsiteIndex alongside target path/SHA. Ecma extraction hashes the exact active source after production test exclusion transformation and assigns ordinals only to computed import/require calls. Runtime traversal filters declared owners by exact safe-integer ordinal, then refuses caller source hash mismatch and target bytes mismatch. An unclaimed callsite stays unresolved; no file-wide owner fallback remains. Multiple declared alternatives can belong to one exact computed callsite and each is traversed.

A caller edit or different transformation changes its hash; another active computed call cannot reuse the first call's owner unless it separately has an exact declaration. Target mismatch adds a refusal finding even though the graph continues traversal. This is bounded lexical computed import/require ownership enforcement, not proof of arbitrary eval or aliased loader semantics. Actual compiled runtime graph must still refuse other unknown sources/resources. Parent reports RED then GREEN11/84; this audit read source/contracts and did not rerun it.
