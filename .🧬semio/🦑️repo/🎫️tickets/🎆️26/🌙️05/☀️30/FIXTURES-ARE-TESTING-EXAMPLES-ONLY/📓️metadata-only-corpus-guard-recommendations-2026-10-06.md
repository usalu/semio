## Negative Neutral Parser Specimens

- Generic frozen seal event ledger `{contracts,later,catalogs}` with seal/revision/reason and reseal event rows over arbitrary registered authorities. It is a live source authority protocol, not a fixed historical test collection.
- Neutral schema parser example explicitly nested under test input, containing any of the above schema shapes as an input document; it must stay data. Exact placement/dataflow context needs recognition before classification.

## Boundary

These examples are regression witnesses for scoped structure checks, not a universal semantic oracle. Cross-language consumption ownership and the existence of actual produced-value/canonical input contracts require separate audit. A safe guard should emit a descriptive diagnostic for these structural signatures, then canonical-owner provenance must prevent false positives before destructive execution.
