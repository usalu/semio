# Scalar Declaration Registry Role Review

Read-only fresh source and generic-registry audit. Hashes in 🗑️generated/strict-scalar-role-inputs.json. No tests, Cargo, or production bundle executed.

The whole `retained/resident/scalar/🧬️schema/🔣️.json` exports exactly one definition, ScalarDeclaration. It defines the entire frozen source-oracle declaration including machine states, construction prefix trials, recorded child-fixture hashes/paths, registered test selectors, and proposed runtime interfaces. Scalar folder has only declaration JSON, schema JSON and ordinary fixture JSON; it has no implementation source or public runtime facade. No genuine separate scalar input, progress, receipt or wire-export schema exists here to delete accidentally. `ScalarState`, `ScalarProgress`, `ScalarReadReceipt` names occur as records inside the declared model, not independent exports.

Generic consumers do elevate this whole trial declaration to production domain authority:

- Repo library `🔣️schema-catalog.json` scope framework.ui.contract.retained.resident.scalar declares level framework-module, facetKind 🧬️data, export ScalarDeclaration, dependency framework.actor.page. Its generated Markdown catalog repeats it. Thus this is not inert schema text omitted from discovery.
- OS DSL derive `🗂️schema-document-index.json` maps scalar schema `$id` to its source path. Its producer `📦️packages/🦀️rust/📜️script.ts::schemaDocumentIndex` (74) walks schema JSON outside example collections and indexes `$id`. Its proc-macro consumer `✨️derive/🦀️.rs::mutation_schema_document_index` (761) and `parse_mutation_schema_document_index` (785) parse all indexed coordinates; schema resolution at :729 uses this index to resolve actual referenced contracts. Presence in the index alone is not proof that a production compiled unit opened scalar schema.

The three path selectors are genuine const data fields, not annotations: `/$defs/ScalarDeclaration/properties/closePlan/const/{reader,readerAlias,page}/path`. They enforce example coordinates for the declaration. Corresponding catalog `/closePlan/{reader,readerAlias,page}/path` fields are used by `UiDocumentStore/🧪️tests/🧪️typedwire/🟦️.tsx::runScalarCloseModelCold` to bind raw fixture bytes, match SHA-256 and compare grants. Direct consumer is guarded behind import.meta.vitest registration. Declaration states runtime-unmounted-source-declaration; registeredTestProposal says source-oracle-contract and test-only pure controllers.

Semantic conclusion: the schema is an independent whole source-trial declaration contract elevated through generic domain schema registry, rather than an actual scalar runtime input/output contract. The test-only evidence role explains why no runtime fixture edge is established, but does not justify publishing trial wrapper authority as a production data facet. Clean disposition: retain declaration/model/evidence as plain testing examples under scalar/🧪️tests/🧫️fixtures; remove the whole trial schema and its catalog/index export, update tests to compare plain examples and real domain constraints/oracles. Preserve genuine actor Word schema, existing resident payload/reader/page runtime schemas, production type/progress/receipt APIs elsewhere, and primitive scalar algorithm assertions. Avoid introducing a replacement schema for this corpus.

This conclusion uses full exported shape and observed generic registry enrollment, not the word Scalar or fixture paths alone. Production compiled fixture/schema input consumption remains unproven without selected compiler/build observation.
