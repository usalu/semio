# Fixture Schema Ownership Audit

Read-only investigation on 2026-10-06. No production files changed. Inventory uses `rg --files`; 329 JSON files have a schema directory below a fixture directory. Classification below is structural triage, not permission for automatic deletion.

## Architecture and Canonical Owners

The current taxonomy already calls fixtures opaque input data and bans schema contract scopes beneath both test and fixture collection trees. See `🧰️framework/🛍️products/🦑️repo/🔨️modules/📚️library/🔣️taxonomy.json` fixtureOwnerReason near line 28193, and discovery/🟦️.ts `schemaScopeCollectionPath` near line 3043. A module member named 🧪️test is explicitly exempted from collection classification.

`inventorySchemaScopes` starts at discovery/🟦️.ts line 3329. Its `inertSchemaDataKeyword` (`inertSchemaData`) permits declared schema-shaped parser inputs to stay fixture DATA. This carve-out must remain for negative parser/validator tests; it must not be used to silence fixture-owned actual contracts.

## User Examples and Consumers

- Hub shipped-fleet census/owners/dependencies are duplicated exact expectation wrappers. Package Rust 📜️script.ts lines 1291–1297 loads all three wrapper schemas and validates the same committed expected values. Source TS tests and Rust shipped_fleet tests consume the actual fixture data; preserve these checks and independent SQLite interoperability. No domain contract extraction is needed for these exact wrappers.
- Procedural generation2d public SQLite wrapper is a single root `const`, including metadata columns, native encodings, exact tables, positive rowid identity, independent SQL edit, and explicit retirement. Public Rust test `verify_and_edit` embeds Bun SQLite plus Ajv and passes wrapper JSON as process argument. Remove the redundant wrapper check/schema argument while preserving metadata, full table roster, rowid, integrity/foreign key and actual edit oracle. generation3d has the same pattern.
- MP4 control wrapper pins workload constants and exact semantic table widths/bytes. Snapshot SQLite TS suite imports it as `controlSchema` near line 24; Rust uses control data for actual cancellation and semantic cell checks. Remove wrapper validation while preserving exercised cancellation and independent SQL behavior.

## Actual Synthetic Implementation Contracts

That file assembles code, mutation metadata and payload schemas for demo/lossy/severity/timestamped/validated under fixtures/🧬️mutations. These are test implementation owners, not examples. Extract the synthetic support implementation into a fitting semantic module OUTSIDE 🧪️tests and 🧫️fixtures (both forbid contract ownership); keep cfg(test) assembly and wire-witness example values under fixtures.
