# Static Reader Binding Acceptance Constraints

Five exact current Source samples, source hashes and callsite sample hashes are retained in `📥️oct9-five-current-reader-binding-samples.json`. They are plain candidate inputs and observations, not a new fixture schema or authored Source.

Accept validator identity only from resolved imports: default Ajv/Ajv2020, namespace import with the actual constructor member, or named/aliased first-party semioSchemaAjvV1 from its genuine canonical source. Never accept a local identifier merely named Ajv or compile. Track constructor/factory result, compile return and const aliases through lexical binding identity. Shadowed bindings, reassignment, mutable aliases, unknown receiver methods or overwritten compile invalidate the chain. Namespace import does not make `new Namespace` a known Ajv constructor; actual Namespace.default must be established.

Resolve static JSON import paths; JSON.parse(readFileSync(literal new URL(path,import.meta.url),utf8)), joined/resolved literal import.meta.dir roots; await Bun.file(new URL(...)).json(); simple helper `load(path)=>JSON.parse(readFileSync(new URL(path,import.meta.url),utf8))` with constant literal caller arguments. Do not execute source. Decode escaped string literals with first-party ECMA decoder, retain original UTF16 token/call spans and original source byte digest. Escaped identifiers need semantic identifier identity, while original token text/span remains evidence. Helper closure capture and lexical function arguments must resolve; dynamic template paths such as contribution `${owner}.json` remain unresolved unless an exact finite source-derived value set is proved. Type casts and await are transparent only after syntactic recognition.

The five examples demonstrate default Ajv+row.value descriptor, Ajv2020+resolve root+accepted/rejected inventory rows, first-party Ajv+static JSON imports+constructed mutation object, Bun.file/newURL+local $ref Grant/Progress, and helper alias+literal schema with computed contribution reads. All are genuine per-domain or parser inputs; none should become whole-corpus findings merely because examples appear in their source. The schema-input specimen may be schema data, but actual validation is of an individual contribution value, not its enclosing test cases.

Record whole root aliases separately from property projections, loop row bindings and constructed domain values. Unknown spread/computed projection, array/destructuring alias, helper return, dynamic import/path, malformed/unsupported syntax or unresolved reassignments prevent a definitive classification. Emit an unresolved record rather than empty reader evidence. A whole value still needs schema content/real domain identity and runtime-reader joins to distinguish a real Request/Report from a trial envelope. Do not use proximity or test-only Ajv imports as sufficient authority.

Normalize repository-relative paths through the current source ownership APIs; preserve lexical and resolved real-path evidence and refuse traversal/out-of-owner identities, without resolving symlink aliases into authority silently. Normalize platform separators before comparison, retaining original spelling separately. Deduplicate evidence by schema path, reader path and call UTF16 span; sort paths and records by UTF8 bytes (current Discovery byteSort uses Buffer byte comparison), not localeCompare. Source SHA binds the complete original bytes; callsite SHA binds the exact original substring encoded UTF8, while UTF16 offsets remain separately named. Hashes do not establish authorship.

No source edits, tests, compilers or producers were run. Sample ranges are current observations and may drift with shared work.
