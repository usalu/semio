# Artifact Policy Authority

Production artifact schema discovery and field parity now inspect semantic source owners directly. The production parity law no longer reads the abstraction-ownership test example as its authority. Discovery excludes fixture and test collections while retaining actual semantic test-support implementations. JSON Schema declaration identity and fields are compared with the owned source facet extractors; missing declarations produce explicit source diagnostics.

The language-neutral field-parity examples now include forbidden runtime collection segments. Tests wrap the source-operation interface to fail if production owner discovery enters test collections or parity reads their data. An independent fast-glob owner inventory and independent schema-field parser remain the reference implementations. Emitted output directories are excluded from both inventories.

## Verification

Initial runs exposed the old title-based declaration mismatch and missing canonical domain contracts removed during wrapper cleanup. Affected domain authorities have been restored or extracted by the boundary agent. The final Nx source-law run passed 11 tests with no failures, including installed TypeScript compiler admission and independent field oracles. The all-owner audit now reports real semantic declarations rather than asserting the old fixture-curated inventory had no declaration diagnostics. Its source inventory and compiler costs use the shared quick test-level budget.
