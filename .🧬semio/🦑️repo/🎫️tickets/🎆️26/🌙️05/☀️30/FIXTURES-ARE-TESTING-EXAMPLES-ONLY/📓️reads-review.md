Read-only current source review, no tests or production execution. Hashes and six invented portable counterexamples are in `📥️reads-review.json`; no Source was copied. Confirmed implementation-level hazards: branch evaluation shares parent ReadBinding objects and executes both sides sequentially instead of merging; an unknown then write can be overwritten by the else fixture initializer. Conditional expression has the same sequential side-effect behavior. Return inside a branch is ignored by its surrounding statement runner, so later unconditional return can fabricate helper origin.

Unknown member calls taint argument documents, but not receiver documents. A fixture.cases.push(opaque()) receiver remains pristine in the cached document. JSON aliases share the ReadDocument, which correctly propagates explicit member-assignment taint; receiver mutation must join that same invalidation. Inline schema objects are constant data without shared taint identity: alias.type assignment does not update or invalidate the original schema. This can emit the wrong inlineSchema body and also choose the wrong registered $id/$ref.

Named helper declarations are invoked eagerly with absent arguments. Opaque callback carriers likewise invoke their helper arguments immediately. The function captures a live scope, but evidence already emitted at declaration time remains after later captured writes. These are potential read sites, not definitive origins at unknown callback execution. Retain site evidence with unresolved origin, or analyze all relevant captured writes before deriving a concrete origin; do not infer runtime execution from a declaration.

call evaluates all arguments before its callee/receiver, opposite JavaScript evaluation order. Side-effecting getter/helper receiver can invalidate an argument binding after the inspector has already captured it. Use lexical JS order and preserve unresolved side effects.

Constructor import shadowing is addressed by nearest scope lookup and predeclaration in ordinary blocks/functions. Unsupported source returns completeSyntax=false. Imported document aliases and explicit assignments propagate shared document taint. Static relative URL acquisition is conservative: only dot-prefixed strings resolve; legal non-dot relative paths currently remain unresolved. Direct strings to readFileSync/Bun.file, URL schemes/query normalization and helper destructured/default parameters are not proven. Do not broaden these without explicit source/path semantics.

Canonical TypeScript model has four DTOs matching the visible evidence concept: source origin, read, issue and report. Validate JSON required/optional fields independently with canonical inventory; this review provides no format admission credit. The current test uses TypeScript call spans for every read and checker symbol separation only for shadowed-validator. It does not independently prove the other origin chains or branch/capture reachability. Extend test-only checker/declaration/write oracles using the six candidates; runtime remains first-party.
