# Structural Plugin and Composition Corpus Closure

The expanded semantic audit identified 25 plugin/Hub corpus schema wrappers outside fixture folders. Exact Python consumer inspection found two additional mixed history wrappers. All 27 are closed: 20 schema documents removed and seven documents now contain genuine per-value domains, with no corpus admission. Two new semantic domain owners retain the extracted Drawing point and Puzzle history records. The exact scoped ledger records 58 source/schema paths; the existing ticket script adds read-only verification modes.

## Preserved Domain Authority

HTML and Markdown retain actual mutation address records; Text and Binary retain individual net mutation records. Each original jsdiff/parse5/markdown-it behavior comparison remains, and Ajv now validates each actual leaf rather than its before/after/expected example envelope. PDF retains recursive Cos/Entry and color/function/action/outline/form/date wire types; Ajv and owned validation operate on each wire value, including hostile value extensions. Puzzle board Row/Flush/Rectangle domains remain; Python validates actual event flushes and derived rectangles and retains every independent Shapely folding comparison.

DrawingPoint has one semantic geometry owner shared by Draw and renderer tests. Actual utility policy validation and unknown-utility checks remain; press and move points validate independently. Puzzle history retains actual outcome, mutation input, edit, localized-label, and folded-outcome records in the history owner. History edit leaves reference the canonical 36-kind Puzzle2dMutation schema, resolved by a test-only registry of canonical mutation docs, and existing individual native leaf validation remains. Scenario/Step/Expect/expected Head schemas are removed.

EPW examples now validate actual expected weather records against the existing weather domain. Every Stdio role/Cargo/TOML oracle, assembly removal behavior, hierarchy identity oracle, conversion dependency oracle, CAD/OpenCascade volume/refusal comparison, WFC SQLite/base64/hostile relation check, Draw Three.js bounds/i18next count projection, DWG controlled descriptor guard, service module build/AST guard, and Hub directory selection oracle remains. The already-retired framework snapshot-capability whole-corpus admission was removed from the Stdio assembly consumer while preserving all native/relational capability assertions. DWG source guards now name the actual canonical semio_framework_dsl_record owner and keep the same four controlled allocation/child-shape/producer requirements.
