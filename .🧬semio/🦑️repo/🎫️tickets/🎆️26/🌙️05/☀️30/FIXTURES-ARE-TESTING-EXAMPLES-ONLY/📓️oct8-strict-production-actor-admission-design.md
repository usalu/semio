# Strict Production Actor Admission Design

Read-only source-backed adapter design on 2026-10-08. No implementation or production execution performed.

The ordinary owner is Hub trusted-catalog-bootstrap. The adapter must consume its retained production ledger, not a neutral factory example or a copied historical generation. Existing Directory actor contracts remain path-free identity contracts; actual byte ownership is proved by the selected generation and producer receipts.

## Minimum Admission Conditions

1. Resolve the actual configured Hub data root through the existing production selection. Read `trusted-catalog/current.json`, bind exact generation ID and bundle digest to surviving `generations/<generation>/trusted-catalog.json`, and validate the existing generation identity and package record contract. Re-read pointer/bundle identities after asynchronous verification; changed selection refuses or restarts under cancellation. Do not pick a latest directory by timestamp.
2. Require one selected package actor of kind closed-browser-actor. Use the generation-owned exact `packages/<plugin>/browser/closed-actor.mjs` path, rejecting traversal, symlink escape, arbitrary caller paths or package disagreement. Verify actor current SHA and exact bounded byteLength. Verify corresponding component and descriptor surviving bytes, lengths and digests against that same record. Actor sourceComponentSha256/sourceDescriptorByteSha256 must equal those exact bytes; record/codegen/interface identity must match genuine domain admission.
3. Bind actor derivation to the retained successful fresh component invocation, package/root cdylib, wasm-release target/profile and exact args/cwd/manifest. Require original Cargo messages, same-unit resolved features, per-.d physical base, complete original input roster, actual compiler-consumed checksums, current config presence/absence, and build/proc-macro resource evidence. Selected staged component must equal the component bytes passed to actor derivation and survive with current SHA. FreshComponentReceipt's output hashes alone do not prove these inputs.
4. Retain the actual factory's `policyCanonical` bytes, require the existing canonical serializer's exact output and SHA equals both actor ledger and generation policySha256. Validate closed policy schema, revision, runtime, options, package lock rows and complete source roster. Map logical roots through actual declared producer owners, not caller-supplied aliases. Current fingerprints must equal captured SHA and byteLength for first-party host/wasi modules, browser factory/schema, repo execution/normalization, exact Bun executable, parser entry/manifest/lock row, admitted JCO package manifests/lock rows, and every compiled compiler input/core. Retain the actual compiled compiler.mjs identity from production capture; temporary deletion does not justify substituting a rebuilt compiler. Bundle output must be the captured factory result, not independently asserted text.
5. Bind exactly one computed child import: hash active production-transformed worker source using the existing Ecma extraction contract, select the exact computed-import ordinal, and verify the ordinary Store lease→Hub asset→parent child admission→private bound port→child SHA→Blob import value chain remains the source-backed owner route. The physical actor file and producer graph become that exact import's owner; Blob URL is ephemeral and carries no independent path authority. Another computed import in the same file must remain unresolved. When claiming actual execution, retain selected lease generation/admission and transferred/load SHA/length evidence; source tracing alone is not execution.
6. Traverse the verified closed actor's own source/compiler/resource graph. Closure forbids unresolved external imports/URLs; retain actual compiler/bundler roster rather than waiving opaque output. Actual fixture ancestry is refused in all original inputs and actor source provenance. Missing capture, incomplete entry, stale input, failed/cancelled invocation or contradictory package/unit evidence refuses.

## Source-Backed Neutral Negative Cases

- Pointer changes after hashing, stale bundle digest, substituted generation or package, record actor source component/descriptor mismatch, wrong actor path, actor symlink escape, same-length edited actor bytes, changed descriptor/component bytes.
- Valid old generation with absent current Cargo ledger; copy-source generation has matching bytes but wrong producer invocation; metadata feature union without selected actual unit; profile.test true; wrong target/package/features/cwd; null .d base, missing consumed-byte checksums, stale lock/config absence becomes presence; source/resource drift.
- Correct actor SHA but missing policyCanonical; altered canonical text with stale SHA; semantic policy copy that is not exact canonical form; changed host/wasi/factory/schema/compiler core/parser/tool executable/package manifest or lock row; omitted source row or logical path mapped outside exact declared owner.
- Correct actor owner assigned to another computed ordinal, worker source drift, a second uncovered computed import, incoming byteLength/SHA different from selected lease, revoked/changed generation, failed port binding, post-hash cancellation. Matching SHA-shaped strings without selected physical bytes never suffice.
- Fixture-owned actor input, copied fixture source in compiler roster, arbitrary dynamic-owner path, incomplete resource capture and empty inferred operation roster remain refusal controls.
- Positive controls: unchanged current generation with exact retained producer inputs; two different valid packages with their own complete records; changed generation accompanied by independently complete new producer evidence. Directory enumeration does not imply child-byte reads.

## Nondeterminism and Bounds

Factory scratch directories are mkdtemp-based, physical executable/package roots differ across machines, Cargo output paths and timestamps depend on invocation, and Blob URLs/port nonces/activation generations are runtime identities. Bind each actual observation rather than requiring these incidental values to be stable across runs. The factory fixes LANG/LC_ALL/TZ, tool/runtime versions and JCO options; policy logical input rows are sorted and canonicalized. No source inspection alone proves deterministic JCO/Bun output across platforms or versions. Require actual retained output SHA, not reproduction by expectation. Wall/monotonic time and random WASI behavior after activation are real runtime inputs, not compile-source proof. Cross-platform path ownership should follow existing native path and storage contracts; no Windows execution is claimed here.

The ledger shape is still producer-owned and pending. This design establishes minimum adapter requirements only and does not credit existing old Hub bytes as current compiler evidence.
