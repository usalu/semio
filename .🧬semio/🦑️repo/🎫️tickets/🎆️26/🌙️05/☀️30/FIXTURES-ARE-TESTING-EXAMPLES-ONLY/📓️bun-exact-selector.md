# Exact Native Selector Encoding

Read-only primary pinned Bun 1.3.14 review; no matcher/install execution or success claim.

Escaped literal path followed by `{,}` is supported by Bun matcher Source: matcher.zig318–360 calls matchBraceBranch at the first comma even when branch_index points immediately to that comma, then at closing brace for the second empty branch. globMatchImpl269–275 skips each remaining brace branch without consuming pathname characters. Thus both alternatives consume zero characters; the suffix preserves one exact directory and has no descendant wildcard. WorkspaceMap appends `/package.json`, so the complete matcher sees escapedPath{,}/package.json. GlobWalker1559–1599 marks braces as special, preventing the final component from being treated as a raw literal. detectGlobSyntax sees the unescaped suffix brace and selects this walker. Escaped earlier special components themselves contain special characters and go through matching rather than the raw literal optimization.

Prefer this uniform suffix trigger only when native escaping or leading-negation protection requires glob decoding. Prefix original leading `!` with `./`; otherwise do not mutate relative/external ancestry. Escape literal native glob metacharacters, including comma when a forced brace context could expose it, consistently with the actual matcher. Ordinary literal paths without special characters can remain exact directories. The suffix does not require choosing or rewriting a Unicode codepoint.

A singleton `[x]` also activates matching and Bun matcher205–254 decodes WTF8 codepoints, so a correctly escaped singleton can preserve Unicode. It is a more complicated general encoder: bracket-leading !/^ negation, ], -, backslash, surrogate/codepoint boundaries, and slash separators must be handled. Restricting wrapping to a known safe ASCII literal would avoid Unicode problems but is not universal. Empty-alternative suffix is therefore the cleaner candidate pending actual Bun and independent fast-glob corpus.

Required actual tests: literal []{}, star/question filenames on platforms admitting them, comma, leading !, ./!, external ../, non-BMP Unicode, existing empty/spare package directory, similarly named sibling, nested descendant package and true collection. Verify exact package-set equality, not only one positive link. Installed micromatch braceExpand delegates to braces with expand:true; actual fast-glob expansion and actual Bun remain required evidence, because Source matcher support alone is not installation proof.
