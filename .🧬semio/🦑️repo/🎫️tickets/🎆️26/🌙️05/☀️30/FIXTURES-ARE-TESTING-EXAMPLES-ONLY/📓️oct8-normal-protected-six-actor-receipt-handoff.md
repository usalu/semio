# Normal Protected Six-Actor Receipt Handoff

Source-only inspection defines the final proof to inspect after the real normal sweep. No execution, producer, test or source change occurred and no production credit is assigned.

The defining normal request is `LOCAL_HUB_DEVELOPMENT_CATALOG_PACKAGES = "stdio,gis,note,writer,draw,puzzle"`. Derive the six exact plugin/package/Cargo identities from the current `trustedBootstrapSelectPackages` owner, not a copied inferred package-ID table. Retained runtime `selectedActors.requested/profile/publication/witnesses`, bundle packages and generation producer packages must have that exact six-member set, one row per selected plugin/package, no duplicate, missing or extra row. Require **six actual closed-browser-actor witnesses**, not merely nonempty witness arrays or a loader allowing browserActor none. Each witness must join its same-package original factory producer, component and descriptor Cargo invocations, observed bytes, source inputs and closed graph; production features must exclude mutation-testing/artifact-app-testing.

The actual sweep output is `hub-sweep.json` under the declared output directory. Inspect finished nonnull, cancelled false, fatal absent, six selected kinds and exactly six passing corresponding rows, each with `publicationExecution`. Reject Nx success without those six records. Selection of kinds comes from actual offered Hub creation kinds, matching witness plugin identity. Require exactly six distinct execution scopes/groups joined to their actual selected plugin/package, rather than merely successful offered-kind enumeration. Each row must preserve actual activation/edit/reopen success and its fault/notice evidence.

Each publicationExecution must carry schema, pluginId, packageId, scope, publication, hubOwner, actorProducer, exactly two cargoInvocations, exactly four responses and child. All six rows must agree on actual publication path/hash/dataRoot/profileId/generationId/publicationRevision. Rehash the physical publication and original producer/receipt files; join each package's component/descriptor/actor SHA and byte lengths to generation/bundle/manifest claims. Do not replace original compiler/factory inputs with generated consumer paths.

Response assets must be the exact set manifest/component/descriptor/browser-actor, one each per group. Every response is authenticated POST/200 to the same normal Hub origin, no query/hash/credentials, correct execution-target path and identical intent scope. Require scope consistency with execution manifest and selected generation/package. Component bytes must also match declared BLAKE3; descriptor/actor byte claims and actor sourceComponentSha256/sourceDescriptorByteSha256/policySha256/codegenPolicy/schema/importInterfaces must join the same current producer. Bodies/tokens/auth headers must not be dumped; retained claims suffice for review alongside actual source-enforced network capture.

Require the real normal root and `trustedCatalogDataRootV1(root,"development")`, not a ticket/demo root. hubOwner binds normal hubUrl/dataRoot/live pid/acquiredAt and **both** physical port/data-root lease claims. Both lease contents must identify the same owner, current hashes/lengths unchanged before and after each execution; liveness and exact data root/port remain required. Child URL must be the fixed physical child owner via the same normal Dev filesystem origin, without replacing the child implementation.

Every child record must prove sourceDetached true, transferCount exactly one, stages including verified/imported/active, actual independently checked descriptor describe digest/length, cancelled true and capacityRestored true. Source implementation additionally requires closed phase and rejection of invoke after cancellation. Exactly six such actual records establish the six-package execution claim. Fresh selected source/cargo/resource/lease rechecks are performed around each capture/child; final Root review must preserve these current joins and count/set constraints. A successful private neutral test supplies no substitute for this normal execution.
