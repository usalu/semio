# Six Independent Control-Flow Oracles

The plain invented cases and original expected ASCII/UTF16 spans are in `📥️flow-oracle.json`. No checked-in Source text is copied; no tests were run. Resolve TypeScript AST node spans with getStart(sourceFile)/end and compare to these explicit ranges. Reject parse diagnostics before any flow assertion.

Create a test-only TypeScript Program with an in-memory host and synthetic Ajv/fs/JSON module declarations. Compare each symbol list by actual declaration identity; imported alias resolution uses getAliasedSymbol, local symbols remain local. Member property names are not binding symbols: resolve the receiver identifier, then independently track object identity and property chain. Expected declaration nodes must be compared against the exact original SourceFile/start, not a printed identifier name.

Use a small independent test evaluator over the TypeScript AST, separate from first-party EcmaExpression. States map symbol identities to KnownOrigin or Unknown, and object identities to clean/invalid content. const alias shares identity; captured mutable variables share slots. Expression order is receiver/callee first, arguments left-to-right, then call. Assignment changes the slot; member write invalidates the receiver object identity. Unknown method calls invalidate receiver content and escaped argument objects. Treat opaque return as Unknown.

For if, clone incoming states, execute both reachable alternatives, and join only equal origins; differing origins become Unknown. Return is a terminal completion carrying a value. Join function return completions independently of fallthrough states: a then return does not proceed into the following final return. The branch and early-return cases therefore cannot inherit the last syntactic fixture value.

A function declaration creates a closure, not an invocation. For captured-callback, the declaration retains the value slot and schedule receives the closure after reassignment; unknown invocation timing cannot prove clean fixture input. For callee-before-arguments, evaluating get must update the captured slot before evaluating the eventual validation argument. These are explicit schedule/order assertions, not TypeScript checker claims: checker establishes identity; the independent evaluator establishes this bounded flow.

Receiver mutation must join fixture import, method receiver and validation argument to one JSON document identity. Inline mutation joins schema declaration, alias initializer and member write; its tracked grammar is changed or unresolved, never the old type:object body. Constructor authority separately resolves genuine Ajv import at every new expression; same-named local constructors cannot create an Ajv identity.

Keep these assertions bounded to the six supported examples. Unsupported loops, dynamic calls, getters/proxies or computed writes are unresolved, not silently modeled as pure. TypeScript checker/internal undocumented flow fields are not a control-flow oracle. This harness uses third-party TypeScript only in tests and exports no external runtime API. Whole/projection findings do not classify schema policy. New paths are below256 characters.
