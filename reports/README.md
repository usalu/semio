# Reports

This folder contains generated reports from various linters and validation tools in JSON format.

Reports are automatically generated by husky pre-commit hooks.

## Available Reports

- `i18n.json` - i18n translation validation report
- `eslint.json` - ESLint linting report
- `typescript.json` - TypeScript compiler check report
- `ruff.json` - Python Ruff linter report

## Formatters vs Linters

**Formatters** (apply changes directly):
- Prettier - JavaScript/TypeScript/JSON/YAML/Markdown formatting
- Ruff Format - Python code formatting
- Ruff Fix - Auto-fixable Python linting issues

**Linters** (generate reports):
- i18n validation - Translation completeness
- ESLint - JavaScript/TypeScript code quality
- TypeScript - Type checking
- Ruff Check - Python code quality

## Generating Reports

Reports are automatically generated when committing:

```bash
git commit -m "your message"
```

Or run hooks manually:

```bash
# Formatters (apply changes)
npx tsx hooks/prettier.ts
npx tsx hooks/ruff.ts

# Linters (generate reports)
npx tsx hooks/i18n.ts
npx tsx hooks/eslint.ts
npx tsx hooks/typescript.ts
```

## Note

Report files (*.json) are gitignored except for this README.
